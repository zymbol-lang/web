How fast is Zymbol?

Sixteen programs, eight languages, the same printed answer — every figure against Zymbol v0.0.11. One machine, CPU time per process, start-up included, and the programs, their twins and the script that measured them are public.

Zymbol, Lua, PHP, Perl, Ruby and Python are interpreters: they run the program without turning it into machine code — PHP's opcache JIT is off on the command line, and Ruby's YJIT is off without --yjit, so both run here as interpreters. JavaScript (Node, V8) and Julia, marked JIT, compile it to machine code while it runs, and are here as the reference of what compiling buys. JavaScript is expected to win, and does. Julia compiles every function before it first runs it; on programs that take under a second, that compilation is most of what a run costs — Julia shines on longer computations, which these are not.

Said plainly: Zymbol is the third fastest of the six interpreters. Lua is faster on 13 of the sixteen and PHP is faster on 13 of the sixteen — both are mature virtual machines with decades of tuning behind them, and Lua's is a register machine like Zymbol's; they are the bar Zymbol is measured against now. Zymbol is ahead of Perl, Ruby and Python in the mean, and still behind one of them on a few programs: Perl on array_update, hof_chain, matmul, sort_cmp_300k, sort_cmp_4k; Ruby on collatz, fib_rec, matmul, nqueens, tak; Python on fib_rec, tak. The deep-recursion programs, fib_rec and tak, are where a call still costs Zymbol most, and that is the next thing being worked on. Zymbol is the fastest interpreter on 1 of the sixteen.

What changed in the VM, in short: a counted loop and a for-each that end each turn in one instruction, $> $| $< calling their lambda on the VM's own frames, a sort comparator that is a plain comparison evaluated without a call, an assignment written by the instruction that computes it, a text that keeps its character count, a dictionary found by a fast seeded hash, and a call that stopped paying for work it did not need. Nothing in the language changed: every program prints what it printed.

  • Twins. Each program is written once per language with the same algorithm and the same shape as the Python twin, and its printed line is compared with Python's before any figure is kept. Julia's twins put their code inside a main() function — a global in Julia is untyped, and measuring that would measure a use nobody writes.
  • CPU time is user + system time of the whole process as the kernel accounts it, median of 5 runs: start-up, parsing, compiling and running. Time varies a few percent between sessions; the figures that gate Zymbol's own development are counted in instructions, which do not.
