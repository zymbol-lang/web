How fast is Zymbol?

Sixteen programs, five languages, the same printed answer. One machine, CPU time per process, start-up included — and the programs, the twins and the script that measured them are public.

Zymbol, Python and Perl are interpreters: they run the program without turning it into machine code. Node (V8) and Julia are JIT compilers and are here as the reference of what compiling buys. Node is expected to win, and does. Julia compiles every function before it first runs it; on programs that take under a second, that compilation is most of what a run costs — Julia shines on longer computations, which these are not.

Where Zymbol is not first, said plainly: it is slower than Python on the two deep-recursion programs, fib_rec and tak — a call still costs Zymbol more than it costs CPython, and that is the next thing being worked on. Perl is faster on hof_chain, matmul, sort_cmp_300k, sort_cmp_4k. Zymbol is the fastest interpreter on 10 of the sixteen.

What changed in the VM, in short: a counted loop and a for-each that end each turn in one instruction, $> $| $< calling their lambda on the VM's own frames, a sort comparator that is a plain comparison evaluated without a call, an assignment written by the instruction that computes it, a text that keeps its character count, a dictionary found by a fast seeded hash, and a call that stopped paying for work it did not need. Nothing in the language changed: every program prints what it printed.

How it was measured

  • Twins. Each program is written once per language with the same algorithm and the same shape as the Python twin, and its printed line is compared with Python's before any figure is kept. Julia's twins put their code inside a main() function — a global in Julia is untyped, and measuring that would measure a use nobody writes.
  • CPU time is perf stat's task-clock for the whole process, median of 5 runs: start-up, parsing, compiling and running. Time varies a few percent between sessions; the figures that gate Zymbol's own development are counted in instructions, which do not.
