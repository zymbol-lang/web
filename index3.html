why zymbol

No words.
Just symbols.

Not no keywords — no words.
Nothing in the grammar is a word in any language.

A minimalist symbolic language: fourteen marks, one meaning each, and they agglutinate into everything else.

Identifiers in any human language. Symbols never change.

↓Start with the marks ▶Playground
01

The marks

Each one means one thing. Tap to see it used.

name = 5 binds a name to a value

None of those readings is another language's keyword. ? is not if — if is the word English picked for it. ? is a condition: the outcome hangs on a question. Same for the rest — @ heads the time context rather than being a loop, and _ binds no name rather than being an else. Glossing a mark with the keyword some other language chose would put the words straight back in.

Even Zymbol's own analyser files these under KEYWORD — the language server has no other slot to put them in. That is a convention inside a tokenizer, not a word in the language. Hence no words, which is exact, rather than no keywords, which is only nearly true.

02

They join

Agglutination, in the plain linguistic sense: one mark, one meaning, and the meanings stack. An operator is spelled, not coined.

$+# = $# how many
$++ = $+ append
$+^+- = $^- sort, descending
>>+! = >>! wipe the screen
<<+|+? = <<|? one key, if there is one

Five releases. One new mark. Everything else was spelled from the ones already here — the long version of why, if you want it.

03

Now read this

Every mark below is one you have already met.

graphics/mandelbrot/english.zy
// Outside the set: faint to solid, dark green to bright.
ramp  = " .:-=+*#%"
tints = [22, 28, 34, 40, 46, 82, 118, 154, 191]

// Steps survived before the orbit runs away; 0 if it never does.
// zr2 and zi2 are carried, so each step costs four products, not six.
escape(cr, ci) {
    zr  = 0.0
    zi  = 0.0
    zr2 = 0.0
    zi2 = 0.0
    @ i:1..36 {
        ? zr2 + zi2 > 4.0 { <~ i }
        zi  = 2.0 * zr * zi + ci
        zr  = zr2 - zi2 + cr
        zr2 = zr * zr
        zi2 = zi * zi
    }
    <~ 0
}

>>| {
    >>!
    (high, wide) = >>?
    rows = high - 2
    cols = wide - 1

    // A cell is ~2.5x taller than wide; the vertical span is
    // scaled by that so the set comes out round.
    width  = 2.7
    height = rows * width * 2.5 / cols
    middle = rows / 2 + 1

    @ y:1..middle {
        mirror = rows + 1 - y
        @ x:1..cols {
            cr = (x - 1) * width  / cols - 2.1
            ci = (y - 1) * height / rows - height / 2.0
            n  = escape(cr, ci)
            mark = "@"
            tint = 231
            ? n <> 0 {
                step = n / 4 + 1
                ? step > 9 { step = 9 }
                mark = ramp[step]
                tint = tints[step]
            }
            >>~ (y, x, 0, tint) > mark
            ? mirror > middle { >>~ (mirror, x, 0, tint) > mark }
        }
    }

    >>~ (high, 2, 0, 244) > "any key to leave"
    <<| _key
}

any key to leave

Not one word in any of it. The colours are the program's own: it picks an ANSI-256 index per escape step and writes each cell with >>~ on the canvas >>| opens. The tree-walker and the register VM draw it identically, cell for cell.
