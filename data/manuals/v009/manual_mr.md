## चल आणि स्थिरांक

```zymbol
चल = १०              // बदलण्यायोग्य चल
PI := ३.१४१५९       // स्थिरांक — पुन्हा नेमणूक ही रनटाइम त्रुटी आहे
नाव = "अमोल"
सक्रिय = #१         // बुलियन सत्य
👋 := "नमस्कार"
```

```zymbol
चल = १०    // १०
चल += ५    // १५
चल -= ३    // १२
चल *= २    // २४
चल /= ३    // ८
चल %= ३    // २
चल ^= २    // ४
चल++       // ५
चल--       // ४
```

`°` (अंश चिन्ह, U+00B0) पहिल्या वापरावर चल स्वयंचलितपणे त्याच्या तटस्थ मूल्यावर प्रारंभ करते:

```zymbol
अंक = [३, १, ४, १, ५]
@ n:अंक {
    °एकूण += n
}
>> एकूण ¶              // → 14
```

> `°चल` (उपसर्ग) लूपच्या वर अँकर करतो — निकाल `@` नंतर वाचनीय असतो.
> `चल°` (प्रत्यय) लूपच्या आत अँकर करतो — लूप संपल्यावर तो मरतो.

फक्त नाव असलेले विधान चल वाचते आणि मूल्य टाकून देते, म्हणून ते इशारा देते:

```zymbol
मोजणी = ५
मोजणी
```

कंपाइलर अशी इशारा देते (त्याचे संदेश नेहमी इंग्रजीत असतात):

```text
warning: this statement does nothing: 'मोजणी' is read and discarded
  = help: remove it, or use it — `>> name ¶` to print it
```

म्हणजे: *«हे विधान काहीही करत नाही: 'मोजणी' वाचले गेले आणि टाकून दिले गेले»*.

## डेटा प्रकार

| प्रकार | शब्दशः | `#?` टॅग | टिपा |
|------|---------|----------|-------|
| पूर्णांक | `४२`, `-७` | `###` | सुरक्षित पूर्णांक: ±(2⁵³ − 1) |
| दशांश | `३.१४`, `१.५e१०` | `##.` | IEEE-754 दुहेरी |
| अक्षरमाला | `"मजकूर"` | `##"` | आंतरवेशन: `"नमस्कार {नाव}"` |
| वर्ण | `'A'` | `##'` | एक युनिकोड कोड बिंदू |
| बुलियन | `#१`, `#०` | `##?` | अंकीय नाही — `#१ ≠ १` |
| अरे | `[१, २, ३]` | `##]` | एक प्रकार, तपासलेले |
| घोषित मिश्रण | `#[१, "दोन"]` | `##[` | `[…]` सारखाच प्रकार, तपासणी नाही |
| टपल | `(a, b)` | `##)` | स्थानिक, अपरिवर्तनीय |
| शब्दकोश | `#(a: १, b: २)` | `##(` | की-आधारित, बदलण्यायोग्य |
| फंक्शन | नामांकित फंक्शन संदर्भ | `##()` | प्रथम-श्रेणीचे; दाखवते `<funct/N>` |
| लॅम्ब्डा | `a -> a * २` | `##->` | प्रथम-श्रेणीचे; दाखवते `<lambd/N>` |
| एकक | `##_` | `##_` | अनुपस्थिती — null नाही |

```zymbol
>> ४२#? ¶               // → (###, 2, 42)
>> [१, २, ३]#? ¶        // → (##], 3, [1, 2, 3])
>> #(a: १)#? ¶          // → (##(, 1, #(a: 1))
```

सुरक्षित श्रेणीबाहेर जाणारा पूर्णांक ही पकडण्यायोग्य त्रुटी आहे, कधीही शांत गुंडाळणी नाही:

```zymbol
!? {
    >> (९००७१९९२५४७४०९९१ + १) ¶
} :! ##Range {
    >> "श्रेणीबाहेर" ¶ // → श्रेणीबाहेर
}
```

`##_` हा एक कार्यक्रम काही अनुपस्थित आहे का हे विचारण्याचा मार्ग आहे:

```zymbol
काहीही_नाही() { }
मूल्य = काहीही_नाही()
>> (मूल्य == ##_) ¶     // → #1
```

## आउटपुट आणि इनपुट

```zymbol
नाव = "अमोल"
एकूण = ३
>> "नमस्कार" ¶             // → नमस्कार
>> "a=" नाव " b=" एकूण ¶ // → a=अमोल b=3
>> एकूण#? ¶            // → (###, 1, 3)
```

```zymbol
<< नाव
<< "तुमचे नाव प्रविष्ट करा: " नाव
<< ###(४) "वय: " वय
```

**दोन चिन्हांचा आकार पहा.** `>>` बाहेरच्या दिशेने निर्देश करते: ते डेटा कार्यक्रमातून बाहेर काढते. `<<` आतील दिशेने निर्देश करते: ते डेटा कार्यक्रमात आणते. तिथे लक्षात ठेवण्यासारखे काहीही नाही — बाण माहिती कोणत्या दिशेने प्रवास करते हे दाखवतो, आणि तीच कल्पना काहीतरी हलवणाऱ्या प्रत्येक चिन्हात परत येते.

> `¶` आणि `\\` समतुल्य नवीन ओळी आहेत. `>>` कधीही एक जोडत नाही.
> प्रॉम्प्टच्या आधीचा प्रकार निर्दिष्टक वाचताना सत्यापित करतो आणि मूल्य वैध होईपर्यंत पुन्हा विचारतो:
> `##.` दशांश · `##.(T,D)` दशांश · `###(N)` पूर्णांक · `##"(N)" मजकूर · `##'` एक वर्ण.

फाइलच्या वरच्या स्तरावर, `<~>` कार्यक्रमाची निर्गमन स्थिती आहे:

```zymbol
>> "तपासत आहे" ¶      // → तपासत आहे
<~ ०
```

## TUI प्राथमिके

परस्परसंवादी कार्यक्रमांसाठी टर्मिनल UI ऑपरेटर. बहुतेकांना `>>| { }` ब्लॉक आवश्यक आहे (पर्यायी स्क्रीन + कच्चा मोड).

```zymbol
>>| {
    >>!
    >>~ (१, १, ०, १०) > "चालू आहे"
    @~ १०००
    >>~ (२, १) > "पूर्ण झाले."
}
```

```zymbol
>>| {
    [ओळी, स्तंभ] = >>?
    >>~ (१, १) > "टर्मिनल: " ओळी " x " स्तंभ
    <<| कळ
    >>~ (२, १) > "दाबले: " कळ
}
```

इथे तुम्ही पाहू शकता की चिन्हे का गुणल्या जाण्याऐवजी एकत्र केली जातात. तुम्हाला आधीच माहित आहे की `<<` इनपुट आहे आणि `?` वचनबद्धतेशिवाय विचारतो. फक्त एकच चिन्ह नवीन आहे:

- `|` हे **एक एकक** आहे, संपूर्ण प्रवाह नाही.

यासह, दोन्ही कीबोर्ड ऑपरेटर स्वतःला वाचतात:

```text
<<        |             ?
इनपुट     एक एकक      वचनबद्धतेशिवाय

<<|   एक कळ घ्या, आणि एक येईपर्यंत थांबा
<<|?  एक कळ आहे का ते पहा, आणि नसेल तर पुढे जा
```

दुसऱ्या बाजूला देखील तेच: `>>` पाठवते, `>>!` **जबरदस्तीने** पाठवते (संपूर्ण स्क्रीन साफ करते), तर `>>?` लिहिण्याऐवजी **विचारते** (टर्मिनल किती मोठे आहे). उजवीकडील चिन्ह हे मोड बदलणारे चिन्ह आहे, आणि ते नेहमी शेवटी येते.

> `>>!` स्क्रीन साफ करते. `>>?` `[ओळी, स्तंभ]` परत देते. `@~ N` N मिलिसेकंद झोपते.
> `<<|` एक कळ दाबणे वाचते (अडवणारे); `<<|?` न अडवता चौकशी करते (`'\0'` नसल्यास).
> बाण कळा `'↑' '↓' '←' '→'` म्हणून डीकोड होतात; ESC कोड बिंदू 27 आहे.
> स्थितीकृत आउटपुट टपल: `(ओळ, स्तंभ, BKS, पुढे, मागे)` — कोणताही स्लॉट स्वल्पविरामाने वगळला जाऊ शकतो (`>>~ (,,, १९६) > "लाल"`).
> BKS बिटमास्क: `1`=ठळक, `2`=तिर्यक, `4`=अधोरेखित. ANSI 256-रंग पॅलेट (`0`=टर्मिनल डीफॉल्ट).

## ऑपरेटर

```zymbol
a = १०
b = ३
न१ = a + b    // १३
न२ = a - b    // ७
न३ = a * b    // ३०
न४ = a / b    // ३  (पूर्णांक भागाकार)
न५ = a % b    // १
न६ = a ^ b    // १०००
```

```zymbol
a = १०
b = ३
त१ = a == b    // #०
त२ = a <> b    // #१
त३ = a < b     // #०
त४ = a >= b    // #१
ल१ = #१ && #०  // #०
ल२ = !#१       // #०
```

> `==` कधीही जबरदस्ती करत नाही: `"5" == 5` हे `#0` आहे. क्रम जबरदस्ती करतो: `"5" > 4` हे `#1` आहे, आणि `"४२" > 5` देखील — 69 लिपींपैकी कोणत्याही एकातील अंकीय मजकूर एक संख्या म्हणून तुलना करतो.
> एक फंक्शन फक्त स्वतःशी समान असते, त्याच शरीर असलेल्या दुसऱ्या फंक्शनशी कधीही समान नसते.

```zymbol
नाव = "अमोल"
n = ४२

```

```zymbol
s = "नमस्कार जग"
लांबी = s$#                  // १०
```

## नियंत्रण प्रवाह

```zymbol
a = ७
? a > १०० {
    >> "मोठे" ¶
} _? a > ० {
    >> "धनात्मक" ¶     // → धनात्मक
} _ {
    >> "ऋणात्मक" ¶
}
```

येथे दोन नवीन चिन्हे आहेत, आणि तिसरे त्यांना एकत्र ठेवल्याने येते:

- `?` **विचारणे** आहे: ते एक अट उघडते.
- `_` **जे निर्दिष्ट केले नाही** ते आहे: कोणताही प्रश्न जुळला नाही तेव्हा उरलेली शाखा.
- `_?` दोन्ही सलग: *काहीही जुळले नाही तर पुन्हा विचारा*.

म्हणूनच `_?` असे लिहिले जाते. हे शिकण्यासाठी नवीन चिन्ह नाही — हे `_` नंतर `?` आहे, आणि त्याचा अर्थ नेमका त्याच्या दोन भागांचा क्रमाने वाचलेला अर्थ आहे.

> कंस `{ }` एका विधानासाठी देखील **अनिवार्य** आहेत.

## जुळणी

```zymbol
गुण = ८५
श्रेणी = ?? गुण {
    ९०..१०० => 'A'
    ८०..८९  => 'B'
    _       => 'F'
}
>> श्रेणी ¶              // → B
```

```zymbol
तापमान = -५
स्थिती = ?? तापमान {
    < ०  => "बर्फ"
    < २० => "थंड"
    _    => "गरम"
}
>> स्थिती ¶              // → बर्फ
```

`?` म्हणजे "विचारणे" हे तुम्हाला आधीच माहित आहे. **`??` म्हणजे अनेक वेळा विचारणे**: भाषेत कुठेही एक चिन्ह दुप्पट करणे म्हणजे ते चिन्ह एकदा जे करते ते अनेक वेळा करणे. एक `?` एक अट तपासते; `??` प्रकरणांच्या यादीविरुद्ध तपासते.

पर्याय `||` ने जोडले जातात, आणि ते नमुना प्रकार मिसळू शकतात:

```zymbol
कळ = 'P'
क्रिया = ?? कळ {
    'p' || 'P' => "थांबवा"
    < ० || > १०० => "श्रेणीबाहेर"
    _ => "दुर्लक्षित"
}
>> क्रिया ¶             // → थांबवा
```

## लूप

```zymbol
@ i:१..४  { >> i " " }
>> ¶                    // → 1 2 3 4
@ i:१..९:२ { >> i " " }
>> ¶                    // → 1 3 5 7 9
@ i:५..१:१ { >> i " " }
>> ¶                    // → 5 4 3 2 1
```

```zymbol
n = १
@ n <= ६४ { n *= २ }
>> n ¶                  // → 128
```

```zymbol
फळे = ["सेब", "नाशपाती", "द्राक्ष"]
@ f:फळे { >> f " " }
>> ¶                    // → सेब नाशपाती द्राक्ष
@ c:"नमस्कार" { >> c "-" }
>> ¶                    // → न-म-स-्-क-ा-र-
```

```zymbol
@ i:१..१० {
    ? i % २ == ० { @> }
    ? i > ७ { @! }
    >> i " "
}
>> ¶                    // → 1 3 5 7
```

```zymbol
मोजणी = ०
@:बाह्य {
    मोजणी++
    ? मोजणी >= ३ { @:बाह्य! }
}
>> मोजणी ¶             // → 3
```

`@` हे **वेळेचे** चिन्ह आहे: पुनरावृत्ती होणारी प्रत्येक गोष्ट त्यात राहते. तो वेळ कापण्यासाठी तुम्ही त्याच्या शेजारी एक चिन्ह जोडता:

- `@!` — `!` **जबरदस्ती** आहे: आता लूप सोडा.
- `@>` — `>` पुढे ढकलते: पुढच्या फेरीत जा.
- `@:बाह्य!` — `:` **एक नाव बांधते**, म्हणून हे *बाह्य* नावाचा लूप कापते, जवळचा नाही.

तीन ऑपरेटर, आणि त्यांपैकी कोणताही स्वतंत्रपणे लक्षात ठेवावा लागला नाही: ते `@` अधिक एक चिन्ह जे ते काय करते ते आधीच सांगते.

> **निर्दिष्टक ही एक मोजणी किंवा एक अट आहे.** एक `पूर्णांक` एक मोजणी आहे, एकदा मूल्यांकन केली जाते — `@ 0` शरीर शून्य वेळा चालवते. बाकी सर्व काही एक अट आहे. सत्यता नाही: `@ []` आणि `@ 3.5` नाकारले जातात. संग्रहातून जाण्यासाठी `@ x:घटक` वापरा; तो मोजण्यासाठी, `@ घटक$#`.

## फंक्शन्स

```zymbol
बेरीज(a, b) { <~ a + b }
>> बेरीज(३, ४) ¶        // → 7
```

```zymbol
गुणनफळ(n) {
    ? n <= १ { <~ १ }
    <~ n * गुणनफळ(n - १)
}
>> गुणनफळ(५) ¶       // → 120
```

एक फंक्शन फाइलची चल मूल्यानुसार वाचते, आणि आतले लेखन आतच राहते:

```zymbol
मर्यादा = १००
आत(n) { <~ n < मर्यादा }
>> आत(४२) ¶         // → #1
```

दोन चिन्हे हे बदलतात, आणि दोन्ही **स्वाक्षरी आणि कॉल साइटवर** लिहिली जातात:

```zymbol
वाढवा(मोजणी<~) { मोजणी = मोजणी + १ }
एकूण = ०
वाढवा(एकूण<~)
>> एकूण ¶              // → 1
```

> `p~` ही कार्यरत प्रत आहे — शरीर ती पुन्हा नेमू शकते आणि कॉलर अबाधित राहतो.
> `p<~` हा आउटपुट पॅरामीटर आहे — बदल परत प्रवास करतो. चिन्हाशिवाय `वाढवा(एकूण)` ही अर्थपूर्ण त्रुटी आहे: भाष्य आणि स्वाक्षरी वेगळे होऊ शकत नाहीत.

## लॅम्ब्डा आणि क्लोजर

```zymbol
दुप्पट = a -> a * २
बेरीज = (a, b) -> a + b
>> दुप्पट(५) ¶          // → 10
>> बेरीज(३, ७) ¶          // → 10
```

```zymbol
वर्गीकरण = a -> {
    ? a > ० { <~ "धनात्मक" }
    _? a < ० { <~ "ऋणात्मक" }
    <~ "शून्य"
}
>> वर्गीकरण(-४) ¶         // → ऋणात्मक
```

```zymbol
घटक = ३
तिप्पट = a -> a * घटक
>> तिप्पट(७) ¶          // → 21
```

```zymbol
बेरजेक_बनवा(n) { <~ a -> a + n }
बेरीज१० = बेरजेक_बनवा(१०)
>> बेरीज१०(५) ¶           // → 15
```

लॅम्ब्डा कोणतेही पॅरामीटर घेऊ शकत नाही:

```zymbol
उत्तर = () -> ४२
>> उत्तर() ¶           // → 42
```

> लॅम्ब्डा फाइलची चल **तयार होताना** पकडते; नामांकित फंक्शन ती **कॉल केल्यावर** वाचते.

## अरे

```zymbol
अरे = [१, २, ३, ४, ५]
>> अरे[१] ¶       // → 1   निर्देशांक 1-आधारित आहे
>> अरे[-१] ¶      // → 5   ऋण शेवटपासून मोजतो
>> अरे$# ¶        // → 5   लांबी
```

```zymbol
अरे = [१, २, ३]
>> (अरे$+ ६) ¶          // → [1, 2, 3, 6]   जोडा
>> (अरे$+[२] ९९) ¶      // → [1, 99, 2, 3]  स्थान 2 वर घाला
>> (अरे$- ३) ¶          // → [1, 2]         पहिली घटना काढा
>> (अरे$-[१]) ¶         // → [2, 3]         निर्देशांक 1 वर काढा
>> (अरे$[१..२]) ¶       // → [1, 2]         तुकडा, दोन्ही टोके समाविष्ट
>> (अरे$? ३) ¶          // → #1             आहे
```

त्या सर्व `$` ने सुरू होतात, जे **संग्रहाचे** चिन्ह आहे, आणि त्यात काय केले जाते हे सांगणाऱ्या चिन्हाने सुरू राहतात: `#` किती, `+` जोडा, `-` काढा, `?` आहे का विचारा. आणि `??` प्रमाणे, चिन्ह दुप्पट करणे म्हणजे ते सर्वसमावेशकपणे करणे: `$?` एक मूल्य *आहे का* विचारते, `$??` *किती ठिकाणी* आहे विचारते आणि ती सर्व परत देते.

```zymbol
अरे = [३, १, २]
>> (अरे$^+) ¶     // → [1, 2, 3]   चढता
>> (अरे$^-) ¶     // → [3, 2, 1]   उतरता
```

**निकालाचा नियम.** एक ऑपरेटर, आणि आसपासचा कोड त्याच्याशी काय करतो हे ठरवते: वापरला तर तो **बांधतो** आणि मूळ अबाधित ठेवतो; टाकून दिला तर तो **बदलतो**.

```zymbol
अरे = [१, २, ३]
प्रत = अरे[२]$~ ९९
>> अरे ¶                // → [1, 2, 3]
>> प्रत ¶              // → [1, 99, 3]
अरे[२]$~ ९९
>> अरे ¶                // → [1, 99, 3]
```

> **`=` कधीही संग्रहात लिहित नाही.** `अरे[२] = ९९` हा Zymbol चा एक प्रकार नाही — `=` एका **नावाला** मूल्य देतो. संग्रहाचा भाग बदलणे हे `$~` आहे, प्रत्येक संग्रहात.

`[…]` एक प्रकार धरतो आणि तपासला जातो; जाणीवपूर्वक मिश्रण `#[…]` ने **घोषित** केले जाते:

```zymbol
मिश्रण = #[१, "दोन", #१]
>> मिश्रण ¶             // → [1, दोन, #1]
>> ([१, २] == #[१, २]) ¶ // → #1
```

## बहुआयामी निर्देशांक

`>` नेस्टेड संरचनेत खाली जातो. कंसांचा एक गट एका घटकाला संबोधित करतो, तो कितीही खोल असो.

```zymbol
m = [[१,२,३], [४,५,६], [७,८,९]]
>> m[२>३] ¶        // → 6   ओळ 2, स्तंभ 3
>> m[-१>-१] ¶      // → 9   शेवटची ओळ, शेवटचा स्तंभ
```

```zymbol
m = [[१,२,३], [४,५,६], [७,८,९]]
>> m[१>१ ; २>२ ; ३>३] ¶          // → [1, 5, 9]          सपाट: कर्ण
>> m[[१>१, १>३] ; [३>१, ३>३]] ¶  // → [[1, 3], [7, 9]]   संरचित: कोपरे
```

```zymbol
m = [[१,२,३], [४,५,६]]
>> (m[१>२]$~ ९९) ¶      // → [[1, 99, 3], [4, 5, 6]]
```

> `m[1][2]` हा Zymbol चा एक प्रकार **नाही**. शृंखलाबद्ध निर्देशांक वाचनासाठी आणि लेखनासाठी नाकारला जातो — प्रत्येक प्रवेशासाठी एक कंस गट, आणि `>` हे पायऱ्यांमध्ये जाते.

## शब्दकोश

नामांकित क्षेत्रांसह टपल हा शब्दकोश आहे, आणि v0.0.9 पासून तो `#(…)` असा लिहिला जातो.

```zymbol
व्यक्ती = #(नाव: "अमोल", वय: २५)
>> व्यक्ती.नाव ¶        // → अमोल
>> व्यक्ती["वय"] ¶    // → 25
```

```zymbol
व्यक्ती = #(नाव: "अमोल", वय: २५)
क्षेत्र = "नाव"
>> व्यक्ती[क्षेत्र] ¶     // → अमोल
```

तो बदलण्यायोग्य आहे, की जोडल्या जाऊ शकतात, आणि तो चालला जाऊ शकतो:

```zymbol
साठा = #(नाशपाती: ४)
साठा["सेब"]$~ १०
@ k:साठा { >> k "=" साठा[k] " " }
>> ¶                    // → नाशपाती=4 सेब=10
```

```zymbol
साठा = #(नाशपाती: ४, सेब: १०)
@ (k, v):साठा { >> k ":" v " " }
>> ¶                    // → नाशपाती:4 सेब:10
```

> `#()` हा रिकामा शब्दकोश आहे, जो `()` असू शकत नाही — त्याला रिकामे टपल देखील असावे लागेल. नग्न `(a: 1)` या संदेशासह नाकारला जातो: *a dictionary is written `#(…)`* — «शब्दकोश `#(…)` असा लिहिला जातो».
> शब्दकोश की ने संबोधित केला जातो, स्थानाने कधीही नाही, म्हणून `व्यक्ती[1]` ही त्रुटी आहे.

## टपल

टपल **अपरिवर्तनीय** क्रमबद्ध कंटेनर आहेत जे वेगवेगळ्या प्रकारची मूल्ये धरतात.

```zymbol
बिंदू = (१०, २०)
>> बिंदू[१] ¶           // → 10
डेटा = (४२, "नमस्कार", #१, ३.१४)
>> डेटा[३] ¶            // → #1
```

```zymbol
t = (१०, २०, ३०)
t2 = t[२]$~ ९९९
>> t ¶                  // → (10, 20, 30)
>> t2 ¶                 // → (10, 999, 30)
```

> टपल जागेवरच बदलण्याचा कोणताही प्रयत्न ही त्रुटी आहे, ऑपरेटर कोणताही असो — अपरिवर्तनीयता ही मूल्याची गुणधर्म आहे, प्रत्येक `$` मधील अपवाद नाही.

## विघटन

```zymbol
अरे = [१०, २०, ३०, ४०, ५०]
[a, b, c] = अरे
>> a " " b " " c ¶      // → 10 20 [30, 40, 50]
```

```zymbol
अरे = [१०, २०, ३०, ४०, ५०]
[पहिला, *उर्वरित] = अरे
>> पहिला ¶            // → 10
>> उर्वरित ¶              // → [20, 30, 40, 50]
```

```zymbol
बिंदू = (१००, २००)
(px, py) = बिंदू
>> px " " py ¶          // → 100 200
```

```zymbol
व्यक्ती = #(नाव: "स्नेहा", वय: २५)
```

## उच्च-क्रम फंक्शन्स

```zymbol
अंक = [१, २, ३, ४, ५]
>> (अंक$> (a -> a * २)) ¶ // → [2, 4, 6, 8, 10]
>> (अंक$| (a -> a % २ == ०)) ¶ // → [2, 4]
>> (अंक$< (०, (संचय, a) -> संचय + a)) ¶ // → 15
```

```zymbol
अंक = [१, २, ३, ४, ५, ६]
दुप्पट(a) { <~ a * २ }
मोठा(a) { <~ a > ३ }
>> (अंक$> दुप्पट) ¶    // → [2, 4, 6, 8, 10, 12]
>> (अंक$| मोठा) ¶    // → [4, 5, 6]
```

```zymbol
डेटाबेस = [#(नाव: "कार्ला", वय: २८), #(नाव: "स्नेहा", वय: २५)]
वयानुसार = डेटाबेस$^ (a, b -> a.वय < b.वय)
>> वयानुसार[१].नाव ¶     // → स्नेहा
```

> नामांकित फंक्शन HOF ला **कंसाशिवाय** जाते: `अंक$> दुप्पट`. `अंक$> (दुप्पट)` लिहिणे ही पार्स त्रुटी आहे, कारण `(` एक लॅम्ब्डा उघडते.

## त्रुटी हाताळणी

```zymbol
!? {
    a = १० / ०
} :! ##Div {
    >> "शून्याने भागाकार" ¶  // → शून्याने भागाकार
} :! {
    >> "इतर: " _err ¶
} :> {
    >> "नेहमी चालते" ¶        // → नेहमी चालते
}
```

| प्रकार | कधी |
|------|------|
| `##Div` | शून्याने भागाकार |
| `##Index` | निर्देशांक श्रेणीबाहेर |
| `##Key` | शब्दकोशात की नाही |
| `##Range` | सुरक्षित पूर्णांक श्रेणीबाहेर |
| `##Type` | प्रकार जुळत नाही |
| `##Parse` | डेटा पार्सिंग |
| `##IO` | फाइल / सिस्टम |
| `##Network` | नेटवर्क त्रुटी |
| `##DB` | डेटाबेस |
| `##Time` | अस्तित्वात नसलेली तारीख |
| `##_` | कोणतीही त्रुटी (सर्व पकडणारा) |

`!` हे **त्रुटी आणि जबरदस्तीचे** चिन्ह आहे, आणि ते दोन्ही कुटुंबांमध्ये सारखेच वाचले जाते: `$!` एका मूल्याला ती त्रुटी आहे का विचारते; `$!!`, चिन्ह दुप्पट करून, न विचारता ती वर पसरवते.

> मानक ग्रंथालयाच्या अयशस्वीता **मऊ त्रुटी मूल्ये** म्हणून परत येतात जी तुम्ही `$!` ने तपासता किंवा `!?` ने पकडता, संपवण्याऐवजी. `$!!` एक कॉलरला पसरवते.

## मॉड्यूल्स

```zymbol
# कॅल्क {
    #> { बेरीज, PI }

    PI := ३.१४१५९
    बेरीज(a, b) { <~ a + b }
}
```

```zymbol
<# ./कॅल्क => c

>> c::बेरीज(५, ३) ¶
>> c.PI ¶
```

```zymbol
# माझी_लायब्ररी {
    #> { अंतर्गत_बेरीज => एकूण }

    अंतर्गत_बेरीज(a, b) { <~ a + b }
}
```

दोन मॉड्यूल चिन्हे हीच कल्पना आहे, आता फाइलांना लागू: `#` ही **घोषणेची** पातळी आहे — एखादी गोष्ट *काय आहे*, तिचे मूल्य नाही — आणि बाण सांगतो की कोड कोणत्या दिशेने प्रवास करतो:

```text
<#   बाण आत येतो: आयात करा, दुसऱ्या फाइलमधून आणा
#>   बाण बाहेर जातो: निर्यात करा, इतर फाइलांना देऊ करा
```

दिशा चिन्ह नेहमी ज्या दिशेकडे निर्देश करते त्या काठावर बसते. `<~` डावीकडे परत येण्याचे (फंक्शनबाहेर) आणि `->` उजवीकडे प्रवेश करण्याचे (लॅम्ब्डाच्या शरीरात) हेच कारण आहे.

> **मॉड्यूल काय निर्यात करते ते घोषित करते.** `#>` ब्लॉक अनिवार्य आहे — तो वगळणे **E014** आहे, आणि `#> { }` हा मॉड्यूल त्याची पृष्ठभाग रिकामी आहे हे सांगण्याचा मार्ग आहे. `::` एक फंक्शन कॉल करते, `.` एक स्थिरांक वाचते. मॉड्यूल शरीरात फक्त आयात, निर्यात ब्लॉक, शब्दशः आरंभकर्ते आणि फंक्शन व्याख्या दिसू शकतात; कार्यान्वित करण्यायोग्य काहीही **E013** आहे.

## मानक ग्रंथालय

मूळ मॉड्यूल्स, इतरांसारखे आयात केले जातात:

| मॉड्यूल | फंक्शन्स |
|--------|-----------|
| `std/math` | `sqrt exp ln log pow abs ceil floor round min max sin cos tan asin acos atan atan2 sinh cosh tanh sigmoid` · `PI` `E` |
| `std/random` | `entero rango peso_f64` |
| `std/json` | `decode decode_map encode` |
| `std/io` | `read write append exists delete list mkdir` |
| `std/net` | `get post post_json head` |
| `std/db` | `connect exec query query_one tx commit rollback` … |
| `std/term` | `width pad_left pad_right center truncate` |
| `std/time` | `now today parts of format add diff` |

```zymbol
<# std/math => m

>> m::sqrt(१६.०) ¶      // → 4
>> m.PI ¶               // → 3.141592653589793
```

```zymbol
<# std/term => t

>> t::width("手番") ¶            // → 4   दोन ग्लिफ, चार स्तंभ
>> "|" t::center("go", 8) "|" ¶ // → |   go   |
```

```zymbol
<# std/time => T

दिवस = T::of(२०२६, १, ३१)
>> T::format(दिवस, "%Y-%m-%d") ¶ // → 2026-01-31
>> T::format(T::add(दिवस, १, "month"), "%Y-%m-%d") ¶ // → 2026-02-28
```

> `std/term` **प्रदर्शन स्तंभ** मोजते, अक्षरे नाही: CJK आणि बहुतेक इमोजी 2 स्तंभ आहेत, म्हणून `t::width` ने टेबल मांडा, कधीही `$#` नाही.
> `std/time` मध्ये एक क्षण युगापासून मिलिसेकंद आहे. एका दिवसापेक्षा कमी कालावधी आहे, एका दिवसापासून वर कॅलेंडर आहे — म्हणून एक महिना त्याच दिवशी पडतो, क्लॅम्प केलेला. `फरक(a, b)` `a - b` आहे, म्हणून आधीचा क्षण आधी दिल्यास ऋण उत्तर मिळते.

## पॅकेजेस

एक `.zyp` बहु-फाइल कार्यक्रम एका पोर्टेबल फाइलमध्ये बंडल करते. हे **स्रोताचे** संग्रहण आहे, बायनरी नाही, म्हणून ते `zymbol` बायनरी चालते तिथे चालते.

```bash
zymbol package माझा_प्रकल्प/ --script main.zy -o माझा_प्रकल्प.zyp
zymbol run माझा_प्रकल्प.zyp
```

> संग्रहणात एक मॅनिफेस्ट (`zyp.toml`) असतो जो त्याच्या प्रवेश स्क्रिप्ट आणि त्याला आवश्यक असलेली इंजिन आवृत्ती घोषित करतो. `zymbol run` ते तात्पुरत्या डिरेक्टरीत काढते आणि तिथून चालवते, म्हणून कोड डिस्पोजेबल आहे तर स्क्रिप्ट जे लिहिते ते तुमच्या वास्तविक कार्यरत डिरेक्टरीत पडते. प्लेग्राउंड देखील `.zyp` फाइल्स लोड करते.

## अंकीय मोड्स

Zymbol अंक **69 युनिकोड अंक लिपींमध्ये** लिहू शकते — देवनागरी, अरबी-भारतीय, थाई, क्लिंगॉन pIqaD, गणिती ठळक, LCD विभाग आणि बरेच काही. मोड प्रक्रियेसाठी जागतिक आहे आणि आउटपुटवर परिणाम करतो; अंकगणित बदलत नाही.

```zymbol
#०९#    // देवनागरी   (U+0966–U+096F)
#٠٩#    // अरबी-भारतीय (U+0660–U+0669)
#๐๙#    // थाई         (U+0E50–U+0E59)
#09#    // ASCII वर रीसेट
```

```zymbol
a = ४२
>> a ¶                  // → 42
#०९#
>> a ¶                  // → ४२
>> ३.१४ ¶               // → ३.१४
>> #१ ¶                 // → #१
#09#
```

कोणत्याही समर्थित लिपीचे अंक स्रोतात वैध शब्दशः आहेत:

```zymbol
#०९#
@ i:१..५ { >> i " " }
>> ¶                    // → १ २ ३ ४ ५
#09#
```

वाचन सममितीय आहे — एक अंक कोणत्याही लिपीत समजला जातो:

```zymbol
>> #|"٤٢"| ¶            // → 42
>> #|'٧'| ¶             // → 7
```

> `#` नेहमी ASCII आहे, म्हणून `#0` प्रत्येक लिपीत अंक शून्यापासून दृष्यदृष्ट्या वेगळा राहतो.
> `#,` आणि `#^` देखील त्यांचे अंक सक्रिय लिपीत लिहितात, आणि विभाजक त्याचे अनुसरण करतात — पण जोडी कधीही उलटत नाही: `,` गट करते आणि `.` विभाजित करते, प्रत्येक लिपीत.

## डेटा ऑपरेटर

```zymbol
f = ##.४२         // दशांशात
i = ###३.७        // पूर्णांकात, गोल  → 4
t = ##!३.७        // पूर्णांकात, कापा  → 3
>> f " " i " " t ¶      // → 42 4 3
>> f#? ¶                // → (##., 2, 42)
```

> एक दशांश अंकांमध्ये छापला जातो, कधीही घातांकात नाही, आणि शेवटचा `.0` वगळतो — `##.42` `42` लिहितो आणि तरीही दशांश आहे, जसे `f#?` दाखवते.

```zymbol
>> #|"42"| ¶       // → 42
>> #|"abc"| ¶      // → abc   अयशस्वी-सुरक्षित: इनपुट न बदलता परत करते
>> ##!'A' ¶        // → 65    वर्णाचा कोड बिंदू
```

```zymbol
pi = ३.१४१५९२६५
>> #.२|pi| ¶       // → 3.14          2 दशांश स्थानांपर्यंत गोल
>> #!२|pi| ¶       // → 3.14          2 दशांश स्थानांपर्यंत कापा
>> #,|१२३४५६७| ¶   // → 1,234,567     हजार विभाजक
>> #^|१२३४५.६७८| ¶ // → 1.2345678e4  वैज्ञानिक संकेतन
```

```zymbol
>> 0x41 ¶        // → A   षोडश
>> 0b01000001 ¶  // → A   द्वि
>> 0o101 ¶       // → A   अष्ट
>> 0d65 ¶        // → A   दश
```

> ASCII श्रेणीतील बेस शब्दशः हा एक **वर्ण** आहे: `0d65 == 'A'` हे `#1`, आणि `0d65 == 65` हे `#0`. चारही बेस एकच वर्ण स्पेल करतात.

## चिन्हे कशी एकत्र होतात

तुम्ही या संपूर्ण पुस्तिकेत एकच गोष्ट पाहत आहात: **ऑपरेटर हे लक्षात ठेवण्यासाठी एक चित्र नाही, ते एका रांगेत अनेक चिन्हे आहेत, आणि प्रत्येक आपला अर्थ देतो.** आता तुम्हाला ती सर्व माहित आहेत, हा संपूर्ण नमुना आहे.

प्रथम येते **आपण कोणत्या जगात आहोत**:

| चिन्ह | जग | तुम्ही ते कुठे पाहिले |
|--------|-------|----------------------------|
| `$` | एक संग्रह | `$#` `$+` `$?` `$^-` |
| `@` | वेळ, पुनरावृत्ती होणारे काहीही | `@!` `@>` `@~` |
| `#` | एखादी गोष्ट *काय आहे*, तिचे मूल्य नाही | `#?` `#(…)` `<#` `#>` |
| `>>` | कार्यक्रमाबाहेर | `>>` `>>!` `>>?` |
| `<<` | कार्यक्रमात आत | `<<` `<<\|` `<<\|?` |
| `?` | विचारणे, वचनबद्धतेशिवाय | `?` `_?` `??` `$?` |
| `!` | जबरदस्ती, किंवा त्रुटी | `@!` `$!` `!?` |

नंतर येते **तेथे काय केले जाते**: `+` जोडा, `-` काढा, `^` क्रम, `~` बदला, `#` मोजा, `|` एक एकक, `:` नाव बांधा.

आणि दोन नियम जे कधीही अयशस्वी होत नाहीत:

**चिन्ह दुप्पट करणे ते सर्वसमावेशक करते.** `?` एकदा विचारते, `??` अनेक प्रकरणे तपासते. `$?` एक मूल्य आहे का विचारते, `$??` ते जिथे आहे तिथे प्रत्येक ठिकाण परत देते. `!` त्रुटी चिन्हांकित करते, `!!` न विचारता ती पसरवते.

**मोड चिन्ह नेहमी शेवटी येते.** जेव्हा `?` किंवा `!` काहीतरी *कसे* केले जाते — संकोचाने किंवा जबरदस्तीने — हे सांगण्यासाठी दिसतात, तेव्हा ती ऑपरेटरची शेवटची चिन्हे असतात: `$??`, `$!!`, `<<|?`, `@!`, `##!`, `>>!`, `>>?`, `@:बाह्य!`. त्यांच्यानंतर कधीही क्रिया नसते.

यातून एक व्यावहारिक गोष्ट येते: **तुम्ही कधीही न पाहिलेले संयोजन, ते शोधण्यापूर्वीच अर्थपूर्ण असते.** जर `$` संग्रह आणि `^` क्रम आणि `-` उलटा असेल, तर `$^-` उतरत्या क्रमाने लावतो, आणि कोणालाही तुम्हाला सांगण्याची गरज नव्हती.

संपूर्ण यादी अशी काम करत नाही, आणि ते सांगणे नाटक करण्यापेक्षा चांगले. बहुतेक ऑपरेटर स्वच्छपणे विभक्त होतात. सहा विभक्त होतात पण त्यांच्या भागांपेक्षा जास्त अर्थ देतात: `!?` `:!` `:>` `|>` `::` `$++`. आणि दहा लक्षात ठेवावे लागतात कारण ते अजिबात विभक्त होत नाहीत: `¶` `><` `#1` `#0` `0x` `0b` `0o` `0d` `###` `°`.

> अस्पष्ट गोष्टी मोजणे, त्या कमी आहेत असे गृहीत धरण्यापेक्षा जाणीवपूर्वक केले आहे: त्या भाषेची खरी स्मरण किंमत आहेत. संपूर्ण संदर्भ — यादी, घोषित समानाक्षरी आणि नवीन ऑपरेटरला अस्तित्वात राहण्यासाठी पूर्ण करावी लागणारी नियमे — इंटरप्रिटर रेपॉझिटरीमध्ये `SYMBOLS.md` मध्ये आहे.

| `\ var` | चल नष्ट करा | `°x` / `x°` | गरम व्याख्या |

| `>>!` | स्क्रीन साफ करा | `>>?` | टर्मिनल आकार विचारा |
| `<<\|` | अडवणारे कळ दाबणे | `<<\|?` | न अडवणारे कळ दाबणे |
| `@~ N` | N मिलिसेकंद झोपा | `0d` `0x` `0o` `0b` | बेस शब्दशः |

## प्रकाशन बदल लॉग

### v0.0.9 — संग्रहांनी निर्णय घेतला _(सप्टेंबर 2026)_

- **ब्रेकिंग** शब्दकोशाची स्वतःची नोटेशन आहे: `#(की: मूल्य)`. नग्न `(a: 1)` नाकारला जातो, आणि `#()` हा रिकामा शब्दकोश आहे — जो `()` कधीही असू शकत नाही
- **ब्रेकिंग** अनुक्रमित नेमणूक काढली: `अरे[i] = v` आणि सर्व संयुक्त प्रकार. `=` एका **नावाला** मूल्य देतो; संग्रहाचा भाग बदलणे हे `$~` आहे
- **ब्रेकिंग** शृंखलाबद्ध निर्देशांक `m[i][j]` वाचनासाठी आणि लेखनासाठी नाकारला जातो — `>` हे पायऱ्यांमध्ये जाते
- **ब्रेकिंग** मॉड्यूलने काय निर्यात करते ते घोषित करणे आवश्यक आहे (**E014**); `#> { }` हा मॉड्यूल त्याची पृष्ठभाग रिकामी आहे हे सांगण्याचा मार्ग आहे
- **ब्रेकिंग** लूप निर्दिष्टक ही एक मोजणी किंवा अट आहे — सत्यता नाही. `@ []` आणि `@ 3.5` नाकारले जातात
- **जोडले** `##_` — एकक शब्दशः, आणि कार्यक्रम काही अनुपस्थित आहे का हे विचारण्याचा मार्ग
- **जोडले** `#[…]` — एक अरे ज्याच्या घटक प्रकारांचे मिश्रण घोषित आहे
- **जोडले** `#?` चार संग्रह वेगळे करते: `##]` `##[` `##)` `##(`
- **जोडले** `std/time` — घड्याळ आणि नागरी कॅलेंडर, झोन आणि कॅलेंडर अंकगणितासह
- **जोडले** वरच्या स्तरावरील `<~>` कार्यक्रमाची निर्गमन स्थिती आहे
- **जोडले** `@ (k, v):जोड्या` — लूप हेडरमध्ये एक नमुना
- **जोडले** `#|c|` 69 लिपींपैकी कोणत्याही एकात एक अंक वाचते; `#,` आणि `#^` सक्रिय लिपीत त्यांचे अंक लिहितात
- **बदलले** `पूर्णांक` एक सुरक्षित पूर्णांक आहे, ±(2⁵³ − 1), प्रत्येक इंजिनमध्ये अयशस्वी-बंद
- **बदलले** नामांकित फंक्शन कॉलच्या वेळी फाइलची चल मूल्यानुसार वाचते
- **बदलले** फक्त नाव वाचणारे विधान गपचूप पुढे जाण्याऐवजी इशारा देते
- **इंजिन** 666 कॉर्पस फाइल्सपैकी 660 तीन इंजिनांमध्ये सहमत, 0 भिन्न

### v0.0.8 — स्वयं-मुक्ती, `std/term` आणि पॅकेजेस _(ऑगस्ट 2026)_

- **जोडले** शेवटच्या वापरावर स्वयंचलित नाश — अदृश्य; फक्त शिखर स्मृती कमी करते
- **जोडले** `std/term` — टर्मिनल स्तंभांमध्ये प्रदर्शन मेट्रिक्स
- **जोडले** एका `वर्ण` वर `##!` — त्याचा युनिकोड कोड बिंदू
- **जोडले** जुळणीत किंवा-नमुना: `'p' || 'P' => …`, कोणत्याही प्रकारचे पर्याय एका शाखेत
- **जोडले** Zymbol पॅकेजेस (`.zyp`) — `zymbol package` / `zymbol run pkg.zyp`
- **जोडले** कॉल साइटवर `<~>` अनिवार्य आहे जिथे कॅली आउटपुट पॅरामीटर घोषित करतो
- **दुरुस्त** रजिस्टर VM मध्ये मॉड्यूल सिस्टम समानता
