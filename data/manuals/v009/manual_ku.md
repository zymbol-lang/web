# دەستنووسی Zymbol-Lang

> **پێداچوونەوەکراو بۆ v0.0.9 — 2026-09-07**

**Zymbol-Lang** زمانێکی بەرنامەسازی هێماییە. هیچ وشەیەک لە ڕێزمانەکەیدا نییە — هەموو دروستکردنێک نیشانەیەکە. بە هەمان شێوە کاردەکات لە هەر زمانی مرۆییدا.

## گۆڕاوەکان و نەگۆڕەکان

```zymbol
x = ۱۰              // گۆڕاوی گۆڕدراو
PI := ۳.۱۴۱۵۹       // نەگۆڕ — دووبارە دیاریکردنەوە هەڵەی کاتی جێبەجێکردنە
ناو = "ئاراس"
چالاک = #۱         // بولیەنی ڕاست
👋 := "سڵاو"
```

```zymbol
x = ۱۰    // ۱۰
x += ۵    // ۱۵
x -= ۳    // ۱۲
x *= ۲    // ۲۴
x /= ۳    // ۸
x %= ۳    // ۲
x ^= ۲    // ۴
x++       // ۵
x--       // ۴
```

`°` (نیشانەی پلە، U+00B0) بە شێوەی خۆکار گۆڕاوێک بۆ نرخی بێلایەنی دەستپێدەکات لە یەکەم بەکارهێناندا:

```zymbol
ژمارەکان = [۳, ۱, ۴, ۱, ۵]
@ n:ژمارەکان {
    °کۆ += n
}
>> کۆ ¶              // → 14
```

> `°گۆڕاو` (پێشگر) لە سەرووی خولەکە دەوەستێت — ئەنجامەکە دوای `@` خوێندنەوەی دەکرێت.
> `گۆڕاو°` (پاشگر) لە ناو خولەکەدا دەوەستێت — کاتێک خولەکە تەواو دەبێت دەمرێت.

ئەو ڕاگەیەنانەی کە تەنها ناوێکە گۆڕاوەکە دەخوێنێتەوە و نرخەکە فڕێدەدات، بۆیە ئاگاداری دەداتەوە:

```zymbol
ژماردن = ۵
ژماردن
```


## جۆرەکانی داتا

| جۆر | نووسین | تاگی `#?` | تێبینی |
|------|---------|----------|-------|
| ژمارەی تەواو | `۴۲`, `-۷` | `###` | ژمارەی تەواوی پارێزراو: ±(2⁵³ − 1) |
| ژمارەی ئەشکەوت | `۳.۱۴`, `۱.۵e۱۰` | `##.` | IEEE-754 دووهەند |
| ڕیزبەند | `"دەق"` | `##"` | ناوەکێشان: `"سڵاو {ناو}"` |
| پیت | `'A'` | `##'` | یەک خاڵی کۆدی یونیکۆد |
| بولیەن | `#۱`, `#۰` | `##?` | ژمارەیی نییە — `#۱ ≠ ۱` |
| ڕیز | `[۱, ۲, ۳]` | `##]` | یەک جۆر، پشکنراو |
| تێکەڵی ڕاگەیەنراو | `#[۱, "دوو"]` | `##[` | هەمان جۆری `[…]`، پشنەکراو |
| تاپڵ | `(a, b)` | `##)` | شوێنی، نەگۆڕاو |
| فەرهەنگ | `#(x: ۱, y: ۲)` | `##(` | بە کلیل، گۆڕدراو |
| فەنکشن | ئاماژەی فەنکشنی ناونراو | `##()` | پلەی یەکەم؛ پیشان دەدات `<funct/N>` |
| لامبدا | `x -> x * ۲` | `##->` | پلەی یەکەم؛ پیشان دەدات `<lambd/N>` |
| یەکە | `##_` | `##_` | نەبوون — هیچ null نییە |

```zymbol
>> ۴۲#? ¶               // → (###, 2, 42)
>> [۱, ۲, ۳]#? ¶        // → (##], 3, [1, 2, 3])
>> #(x: ۱)#? ¶          // → (##(, 1, #(x: 1))
```

ژمارەیەکی تەواو کە لە مەودای پارێزراو دەردەچێت هەڵەیەکی گرتنییە، هەرگیز پێچانەوەی بێدەنگ نییە:

```zymbol
!? {
    >> (۹۰۰۷۱۹۹۲۵۴۷۴۰۹۹۱ + ۱) ¶
} :! ##Range {
    >> "لە مەودا دەرەوە" ¶ // → لە مەودا دەرەوە
}
```

`##_` ڕێگایەکە کە بەرنامەیەک پرسیار دەکات ئایا شتێک نەماوە:

```zymbol
هیچ() { }
نرخ = هیچ()
>> (نرخ == ##_) ¶     // → #1
```

## دەرچوون و چوونەژوورەوە

```zymbol
ناو = "ئاراس"
کۆ = ۳
>> "سڵاو" ¶             // → سڵاو
>> "a=" ناو " b=" کۆ ¶ // → a=ئاراس b=3
>> کۆ#? ¶            // → (###, 1, 3)
```

```zymbol
<< ناو
<< "ناوت بنووسە: " ناو
<< ###(۴) "تەمەن: " تەمەن
```

**شێوەی دوو نیشانەکە تەماشا بکە.** `>>` بۆ دەرەوە ئاماژە دەکات: داتا لە بەرنامەکە دەردەهێنێت. `<<` بۆ ناوەوە ئاماژە دەکات: داتا دەهێنێتە ناو بەرنامەکە. هیچ شتێک نییە بۆ لەبەرکردن لێرە — تیرەکە ئاراستەی گەشتکردنی زانیاری پیشان دەدات، و هەمان ئەم بیرۆکەیە دەگەڕێتەوە لە هەموو نیشانەیەکدا کە شتێک دەجوڵێنێت.

> `¶` و `\\` هێڵی نوێی یەکسانن. `>>` هەرگیز یەکێکیان زیاد ناکات.
> دیاریکەری جۆر پێش داواکاری پشتڕاست دەکاتەوە کاتی خوێندنەوە و دووبارە پرسیار دەکات تاکو نرخەکە دروست بێت:
> `##.` ئەشکەوت · `##.(T,D)` دەیەیی · `###(N)` ژمارەی تەواو · `##"(N)"` دەق · `##'` یەک پیت.

لە ئاستی سەرەوەی فایلێک، `<~` دۆخی دەرچوونی بەرنامەیە:

```zymbol
>> "پشکنین" ¶      // → پشکنین
<~ ۰
```

## بنەڕەتەکانی TUI

کردارەکانی ڕووکاری تێرمیناڵ بۆ بەرنامە کارلێکەرەکان. زۆربەیان بلۆکی `>>| { }` پێویستە (شاشەی جێگرەوە + دۆخی خاو).

```zymbol
>>| {
    >>!
    >>~ (۱, ۱, ۰, ۱۰) > "لە کارکردندا"
    @~ ۱۰۰۰
    >>~ (۲, ۱) > "تەواو."
}
```

```zymbol
>>| {
    [ڕیزەکان, ستوونەکان] = >>?
    >>~ (۱, ۱) > "تێرمیناڵ: " ڕیزەکان " x " ستوونەکان
    <<| دوگمە
    >>~ (۲, ۱) > "داتاشرا: " دوگمە
}
```

لێرەدا دەتوانیت ببینیت بۆچی نیشانەکان یەکدەگرن لە جیاتی لێکدان. دەزانیت کە `<<` چوونەژوورەوەیە و `?` بەبێ پابەندبوون دەپرسێت. تەنها یەک نیشانە نوێیە:

- `|` **یەکەیەکی تاکە**، نەک هەموو ڕژێنەکە.

لەگەڵ ئەمەدا، هەردوو کردارەکانی تەختەکلیل خۆیان دەخوێننەوە:

```text
<<        |             ?
چوونەژوورەوە  یەکەیەکی تاکە  بەبێ پابەندبوون

<<|   یەک دوگمە بگرە، و چاوەڕێ بکە تاکو یەکێک بێت
<<|?  ببینە ئایا دوگمەیەک هەیە، و بەردەوام بە ئەگەر نییە
```

هەمان شت لە لایەکی دیکەوە: `>>` دەنێرێت، `>>!` **بە زۆر** دەنێرێت (هەموو شاشەکە پاک دەکاتەوە)، لە کاتێکدا `>>?` دەپرسێت لە جیاتی نووسین (تێرمیناڵ چەند گەورەیە). نیشانەی لای ڕاست ئەوەیە کە دۆخەکە دەگۆڕێت، و هەمیشە لە کۆتاییدا دێت.

> `>>!` شاشەکە پاک دەکاتەوە. `>>?` `[ڕیزەکان, ستوونەکان]` دەگەڕێنێتەوە. `@~ N` N میلیچرکە دەخەوێت.
> `<<|` یەک داتاشینی دوگمە دەخوێنێتەوە (بلۆککەر)؛ `<<|?` بەبێ بلۆککردن دەپشکنێت (`'\0'` ئەگەر هیچ نییە).
> دوگمەکانی تیر وەک `'↑' '↓' '←' '→'` دەکۆدەکرێنەوە؛ ESC کۆدی خاڵی 27 ە.
> تاپڵی دەرچوونی شوێنکراو: `(ڕیز, ستوون, BKS, پێشەوە, دواوە)` — هەر کونجێک دەتوانرێت بە کۆما بەجێبخرێت (`>>~ (,,, ۱۹۶) > "سوور"`).
> ماسکی بیتی BKS: `1`=قەڵەو, `2`=خوار, `4`=ژێرهێڵ. پاڵێتی 256 ڕەنگی ANSI (`0`=بنەڕەتی تێرمیناڵ).

```zymbol
a = ۱۰
b = ۳
ئ۱ = a + b    // ۱۳
ئ۲ = a - b    // ۷
ئ۳ = a * b    // ۳۰
ئ۴ = a / b    // ۳  (دابەشکردنی تەواو)
ئ۵ = a % b    // ۱
ئ۶ = a ^ b    // ۱۰۰۰
```

```zymbol
a = ۱۰
b = ۳
ب۱ = a == b    // #۰
ب۲ = a <> b    // #۱
ب۳ = a < b     // #۰
ب۴ = a >= b    // #۱
ل۱ = #۱ && #۰  // #۰
```

## کۆنترۆڵی ڕژێن

```zymbol
x = ۷
? x > ۱۰۰ {
    >> "گەورە" ¶
} _? x > ۰ {
    >> "ئەرێنی" ¶     // → ئەرێنی
} _ {
    >> "نەرێنی" ¶
}
```

لێرەدا دوو نیشانەی نوێ هەیە، و یەکێکی سێیەم کە لە کۆکردنەوەیانەوە دێت:

- `?` **پرسیارکردنە**: مەرجێک دەکاتەوە.
- `_` **ئەوەی دیارینەکراوە**: ئەو لقەی دەمێنێتەوە کاتێک هیچ پرسیارێک ناگونجێت.
- `_?` هەردووکیان بە یەکەوە: *ئەگەر هیچ نەگونجا، دووبارە بپرسە*.

لەبەر ئەوەیە `_?` بەم شێوەیە نووسراوە. نیشانەیەکی نوێ نییە بۆ فێربوون — `_` ە کە `?` ی دوایە، و بە تەواوی ئەوە دەگەیەنێت کە دوو بەشەکەی دەیگەیەنن، بە ڕیز خوێندراوەتەوە.

> کەوانەکان `{ }` **ناچارن** تەنانەت بۆ یەک ڕاگەیەنان.

## گونجان

```zymbol
نمرە = ۸۵
پلە = ?? نمرە {
    ۹۰..۱۰۰ => 'A'
    ۸۰..۸۹  => 'B'
    _       => 'F'
}
>> پلە ¶              // → B
```

```zymbol
پلەی_گەرمی = -۵
دۆخ = ?? پلەی_گەرمی {
    < ۰  => "سەهۆڵ"
    < ۲۰ => "سارد"
    _    => "گەرم"
}
>> دۆخ ¶              // → سەهۆڵ
```

دەزانیت کە `?` "پرسیارکردن"ە. **`??` پرسیارکردنی چەندین جارە**: دووهەندکردنی نیشانەیەک، لە هەر شوێنێکی زمانەکەدا، بریتییە لە کردنی چەندین جار ئەوەی نیشانەکە جارێک دەیکات. یەک `?` یەک مەرج تاقی دەکاتەوە؛ `??` دژی لیستێک لە حاڵەتەکان تاقی دەکاتەوە.

جێگرەوەکان بە `||` یەکدەگرن، و دەتوانن جۆرەکانی شێواز تێکەڵ بکەن:

```zymbol
دوگمە = 'P'
کردار = ?? دوگمە {
    'p' || 'P' => "وەستان"
    < ۰ || > ۱۰۰ => "لە مەودا دەرەوە"
    _ => "پشتگوێخراو"
}
>> کردار ¶             // → وەستان
```

## خولەکان

```zymbol
@ i:۱..۴  { >> i " " }
>> ¶                    // → 1 2 3 4
@ i:۱..۹:۲ { >> i " " }
>> ¶                    // → 1 3 5 7 9
@ i:۵..۱:۱ { >> i " " }
>> ¶                    // → 5 4 3 2 1
```

```zymbol
n = ۱
@ n <= ۶۴ { n *= ۲ }
>> n ¶                  // → 128
```

```zymbol
میوەکان = ["سێو", "هەرمێ", "ترێ"]
@ م:میوەکان { >> م " " }
>> ¶                    // → سێو هەرمێ ترێ
@ پ:"سڵاو" { >> پ "-" }
>> ¶                    // → س-ڵ-ا-و-
```

```zymbol
@ i:۱..۱۰ {
    ? i % ۲ == ۰ { @> }
    ? i > ۷ { @! }
    >> i " "
}
>> ¶                    // → 1 3 5 7
```

```zymbol
ژماردن = ۰
@:دەرەوە {
    ژماردن++
    ? ژماردن >= ۳ { @:دەرەوە! }
}
>> ژماردن ¶             // → 3
```

`@` نیشانەی **کات**ە: هەموو شتێک کە دووبارە دەبێتەوە لە ناوی دەژی. بۆ کورتکردنەوەی ئەو کاتە نیشانەیەک زیاد دەکەیت لە تەنیشتیەوە:

- `@!` — `!` **زۆر**ە: ئێستا خولەکە بەجێبهێڵە.
- `@>` — `>` بۆ پێشەوە پاڵ دەنێت: بڕۆ بۆ خولی داهاتوو.
- `@:دەرەوە!` — `:` **ناوێک دەبەستێت**، بۆیە ئەمە ئەو خولە دەبڕێت کە *ناوی* دەرەوەیە، نەک نزیکترین.

سێ کردار، و هیچیان پێویست نەبوو بە جیا لەبەر بکرێت: ئەوانە `@` ن لەگەڵ نیشانەیەک کە پێشوەخت دەڵێت چی دەکات.

> **دیاریکەر ژماردنێک یان مەرجێکە.** `ژمارەی تەواو` ژماردنێکە، جارێک هەڵدەسەنگێنرێت — `@ ۰` لەشەکە سفر جار دەجوڵێنێت. هەر شتێکی دیکە مەرجێکە. هیچ ڕاستییەک نییە: `@ []` و `@ ۳.۵` ڕەت دەکرێنەوە. بۆ گەشتکردن بە کۆمەڵێکدا `@ x:شتەکان` بەکاربهێنە؛ بۆ ژماردنی `@ شتەکان$#`.

## فەنکشنەکان

```zymbol
کۆکردنەوە(a, b) { <~ a + b }
>> کۆکردنەوە(۳, ۴) ¶        // → 7
```

```zymbol
فاکتۆریاڵ(n) {
    ? n <= ۱ { <~ ۱ }
    <~ n * فاکتۆریاڵ(n - ۱)
}
>> فاکتۆریاڵ(۵) ¶       // → 120
```

فەنکشنێک گۆڕاوەکانی فایلەکە بە نرخ دەخوێنێتەوە، و نووسینەکە لە ناوەوە لە ناوەوە دەمێنێتەوە:

```zymbol
سنوور = ۱۰۰
لەناو(n) { <~ n < سنوور }
>> لەناو(۴۲) ¶         // → #1
```

دوو نیشانە ئەمە دەگۆڕن، و هەردووکیان **لە واژوو و شوێنی بانگکردن** نووسراون:

```zymbol
زیادکردن(ژماردن<~) { ژماردن = ژماردن + ۱ }
کۆ = ۰
زیادکردن(کۆ<~)
>> کۆ ¶              // → 1
```

> `p~` کۆپی کارە — لەشەکە دەتوانێت دووبارە دیاری بکاتەوە و بانگکەر دەستنەکەوێت.
> `p<~` پارامیتەری دەرچوونە — گۆڕانکارییەکە دەگەڕێتەوە. `زیادکردن(کۆ)` بەبێ نیشانە هەڵەیەکی واتاییە: تێبینی و واژوو ناتوانن جیا ببنەوە.

---

## لامبداکان و داخراوەکان

```zymbol
دووهەند = x -> x * ۲
کۆی_گشتی = (a, b) -> a + b
>> دووهەند(۵) ¶          // → 10
>> کۆی_گشتی(۳, ۷) ¶          // → 10
```

```zymbol
پۆلێنکردن = x -> {
    ? x > ۰ { <~ "ئەرێنی" }
    _? x < ۰ { <~ "نەرێنی" }
    <~ "سفر"
}
>> پۆلێنکردن(-۴) ¶         // → نەرێنی
```

```zymbol
هۆکار = ۳
سێهەند = x -> x * هۆکار
>> سێهەند(۷) ¶          // → 21
```

```zymbol
دروستکردنی_کۆکەر(n) { <~ x -> x + n }
کۆکردنی۱۰ = دروستکردنی_کۆکەر(۱۰)
>> کۆکردنی۱۰(۵) ¶           // → 15
```

لامبدا دەتوانێت هیچ پارامیتەرێک نەگرێت:

```zymbol
وەڵام = () -> ۴۲
>> وەڵام() ¶           // → 42
```

> لامبدا گۆڕاوەکانی فایلەکە **کاتێک دروست دەکرێت** دەگرێت؛ فەنکشنی ناونراو ئەوانە **کاتێک بانگ دەکرێت** دەخوێنێتەوە.

## ڕیزەکان

```zymbol
ڕیز = [۱, ۲, ۳, ۴, ۵]
>> ڕیز[۱] ¶       // → 1   ئیندێکس لە 1 دەست پێدەکات
>> ڕیز[-۱] ¶      // → 5   نەرێنی لە کۆتاییەوە دەژمێرێت
>> ڕیز$# ¶        // → 5   درێژی
```

```zymbol
ڕیز = [۱, ۲, ۳]
>> (ڕیز$+ ۶) ¶          // → [1, 2, 3, 6]   زیادکردن
>> (ڕیز$+[۲] ۹۹) ¶      // → [1, 99, 2, 3]  دانان لە شوێنی 2
>> (ڕیز$- ۳) ¶          // → [1, 2]         سڕینەوەی یەکەم ڕووداو
>> (ڕیز$-[۱]) ¶         // → [2, 3]         سڕینەوە لە ئیندێکسی 1
>> (ڕیز$[۱..۲]) ¶       // → [1, 2]         بڕین، هەردوو سەرەکان لەگەڵ
>> (ڕیز$? ۳) ¶          // → #1             تێداکەوتووە
```

هەموویان بە `$` دەست پێدەکەن، نیشانەی **کۆمەڵە**، و بەردەوام دەبن بە نیشانەیەک کە دەڵێت چی دەکرێت تێیدا: `#` چەند، `+` زیادکردن، `-` سڕینەوە، `?` پرسیارکردن ئەگەر هەیە. و وەک `??`، دووهەندکردنی نیشانەکە بە واتای کردنی بە تەواوی دێت: `$?` دەپرسێت *ئایا* نرخێک هەیە، `$??` دەپرسێت *لە چەند شوێن* و هەموویان دەگەڕێنێتەوە.

```zymbol
ڕیز = [۳, ۱, ۲]
>> (ڕیز$^+) ¶     // → [1, 2, 3]   بەرزبوونەوە
>> (ڕیز$^-) ¶     // → [3, 2, 1]   نزمبوونەوە
```

**یاسای ئەنجام.** یەک کردار، و ئەوەی کۆدەکەی دەوروبەری پێی دەکات بڕیار دەدات: ئەگەر بەکارهێنرێت، **دروست دەکات** و ڕەسەنەکە بەجێدەهێڵێت؛ ئەگەر فڕێبدرێت، **دەگۆڕێت**.

```zymbol
ڕیز = [۱, ۲, ۳]
کۆپی = ڕیز[۲]$~ ۹۹
>> ڕیز ¶                // → [1, 2, 3]
>> کۆپی ¶              // → [1, 99, 3]
ڕیز[۲]$~ ۹۹
>> ڕیز ¶                // → [1, 99, 3]
```

> **`=` هەرگیز نانووسێت لە کۆمەڵەدا.** `ڕیز[۲] = ۹۹` شێوازێکی Zymbol نییە — `=` نرخێک بە **ناوێک** دەدات. گۆڕینی بەشێکی کۆمەڵە `$~` ە، لە هەموو کۆمەڵەکاندا.

`[…]` یەک جۆر دەگرێت و پشکنین دەکرێت؛ تێکەڵی بەئەنقەست بە `#[…]` **ڕادەگەیەنرێت**:

```zymbol
تێکەڵ = #[۱, "دوو", #۱]
>> تێکەڵ ¶             // → [1, دوو, #1]
>> ([۱, ۲] == #[۱, ۲]) ¶ // → #1
```

---

## ئیندێکسی چەند ئاراستەیی

`>` بەرەو خوارەوە دەچێت لە پێکهاتەیەکی ناوەکیدا. یەک گروپی کەوانە ئاماژە بە یەک توخم دەکات، چەند قووڵیش بێت.

```zymbol
m = [[۱,۲,۳], [۴,۵,۶], [۷,۸,۹]]
>> m[۲>۳] ¶        // → 6   ڕیزی 2، ستوونی 3
>> m[-۱>-۱] ¶      // → 9   کۆتا ڕیز، کۆتا ستوون
```

```zymbol
m = [[۱,۲,۳], [۴,۵,۶], [۷,۸,۹]]
>> m[۱>۱ ; ۲>۲ ; ۳>۳] ¶          // → [1, 5, 9]          تەخت: ئەستێرەیی
>> m[[۱>۱, ۱>۳] ; [۳>۱, ۳>۳]] ¶  // → [[1, 3], [7, 9]]   پێکهاتوو: گۆشەکان
```

```zymbol
m = [[۱,۲,۳], [۴,۵,۶]]
>> (m[۱>۲]$~ ۹۹) ¶      // → [[1, 99, 3], [4, 5, 6]]
```

> `m[۱][۲]` شێوازێکی Zymbol **نییە**. ئیندێکسی زنجیرەیی ڕەت دەکرێتەوە بۆ خوێندنەوە و نووسین — یەک گروپی کەوانە بۆ هەر دەستگەیشتنێک، و `>` ئەوەیە کە لە نێوان هەنگاوەکاندا دەچێت.

## فەرهەنگەکان

تاپڵێک بە خانەی ناونراو فەرهەنگێکە، و لە v0.0.9 ەوە بە `#(…)` نووسراوە.

```zymbol
کەس = #(ناو: "ئاراس", تەمەن: ۲۵)
>> کەس.ناو ¶        // → ئاراس
>> کەس["تەمەن"] ¶    // → 25
```

```zymbol
کەس = #(ناو: "ئاراس", تەمەن: ۲۵)
خانە = "ناو"
>> کەس[خانە] ¶     // → ئاراس
```

گۆڕدراوە، دەتوانرێت کلیل زیاد بکرێت، و دەتوانرێت بەسەریدا بگەڕێیت:

```zymbol
کۆگە = #(هەرمێ: ۴)
کۆگە["سێو"]$~ ۱۰
@ k:کۆگە { >> k "=" کۆگە[k] " " }
>> ¶                    // → هەرمێ=4 سێو=10
```

```zymbol
کۆگە = #(هەرمێ: ۴, سێو: ۱۰)
@ (k, v):کۆگە { >> k ":" v " " }
>> ¶                    // → هەرمێ:4 سێو:10
```

> `#()` فەرهەنگی بەتاڵە، کە `()` نەیدەتوانی بێت — دەبوو تاپڵی بەتاڵیش بێت. `(x: 1)` ڕووت ڕەت دەکرێتەوە بەم نامەیە: *a dictionary is written `#(…)`* — «فەرهەنگێک بە `#(…)` نووسراوە».
> فەرهەنگ بە کلیل ئاماژەی پێدەکرێت، هەرگیز بە شوێن نا، بۆیە `کەس[1]` هەڵەیە.

## تاپڵەکان

تاپڵەکان کۆنتەینەری ڕیزکراوی **نەگۆڕاو**ن کە نرخی جۆراوجۆر هەڵدەگرن.

```zymbol
خاڵ = (۱۰, ۲۰)
>> خاڵ[۱] ¶           // → 10
داتا = (۴۲, "سڵاو", #۱, ۳.۱۴)
>> داتا[۳] ¶            // → #1
```

```zymbol
t = (۱۰, ۲۰, ۳۰)
t2 = t[۲]$~ ۹۹۹
>> t ¶                  // → (10, 20, 30)
>> t2 ¶                 // → (10, 999, 30)
```

> هەر هەوڵێک بۆ گۆڕینی تاپڵێک لە شوێنی خۆیدا هەڵەیە، هەر کردارێک بێت — نەگۆڕاوی تایبەتمەندی نرخەکەیە، نەک دەرچوونێک لە ناو هەر `$` ێکدا.

## هەڵوەشاندنەوە

```zymbol
ڕیز = [۱۰, ۲۰, ۳۰, ۴۰, ۵۰]
[a, b, c] = ڕیز
>> a " " b " " c ¶      // → 10 20 [30, 40, 50]
```

```zymbol
ڕیز = [۱۰, ۲۰, ۳۰, ۴۰, ۵۰]
[یەکەم, *ئەوانەیتر] = ڕیز
>> یەکەم ¶            // → 10
>> ئەوانەیتر ¶              // → [20, 30, 40, 50]
```

```zymbol
خاڵ = (۱۰۰, ۲۰۰)
(px, py) = خاڵ
>> px " " py ¶          // → 100 200
```

```zymbol
کەس = #(ناو: "شیلا", تەمەن: ۲۵)
#(ناو: n, تەمەن: a) = کەس
>> n " " a ¶            // → شیلا 25
```

> شێوەی کەوانەکە جۆرکراوە: `[…]` ڕیز دەگرێت، `(…)` تاپڵ، `#(…)` فەرهەنگ. ناوی کۆتایی **ئەوانەیتر هەڵدەمژێت**، بۆیە هەڵوەشاندنەوە هەرگیز بەهۆی درێژییەوە شکست ناهێنێت — `(a, b, c) = (1,2,3,4,5)` `c = (3,4,5)` دەدات، و `##_` کاتێک هیچ نەماوە.

## فەنکشنەکانی ئاستی بەرز

```zymbol
ژمارەکان = [۱, ۲, ۳, ۴, ۵]
>> (ژمارەکان$> (x -> x * ۲)) ¶ // → [2, 4, 6, 8, 10]
>> (ژمارەکان$| (x -> x % ۲ == ۰)) ¶ // → [2, 4]
>> (ژمارەکان$< (۰, (کۆکەرەوە, x) -> کۆکەرەوە + x)) ¶ // → 15
```

```zymbol
ژمارەکان = [۱, ۲, ۳, ۴, ۵, ۶]
دووهەند(x) { <~ x * ۲ }
گەورە(x) { <~ x > ۳ }
>> (ژمارەکان$> دووهەند) ¶    // → [2, 4, 6, 8, 10, 12]
>> (ژمارەکان$| گەورە) ¶    // → [4, 5, 6]
```

```zymbol
بنکە = [#(ناو: "کارلا", تەمەن: ۲۸), #(ناو: "شیلا", تەمەن: ۲۵)]
بەپێی_تەمەن = بنکە$^ (a, b -> a.تەمەن < b.تەمەن)
>> بەپێی_تەمەن[۱].ناو ¶     // → شیلا
```

> فەنکشنی ناونراو بۆ HOF دەچێت **بەبێ کەوانە**: `ژمارەکان$> دووهەند`. نووسینی `ژمارەکان$> (دووهەند)` هەڵەیەکی شیکارییە، چونکە `(` لامبدایەک دەکاتەوە.

```zymbol
دووهەند = x -> x * ۲
کۆکردنەوە = (a, b) -> a + b
یەک_زیادکردن = x -> x + ۱
>> (۵ |> دووهەند(_)) ¶    // → 10
>> (۱۰ |> کۆکردنەوە(_, ۵)) ¶  // → 15
>> (۵ |> دووهەند(_) |> یەک_زیادکردن(_)) ¶ // → 11
```

## بەڕێوەبردنی هەڵە

```zymbol
!? {
    a = ۱۰ / ۰
} :! ##Div {
    >> "دابەشکردن بە سفر" ¶  // → دابەشکردن بە سفر
} :! {
    >> "هیتر: " _err ¶
} :> {
    >> "هەمیشە دەجوڵێت" ¶        // → هەمیشە دەجوڵێت
}
```

| جۆر | کەی |
|------|------|
| `##Div` | دابەشکردن بە سفر |
| `##Index` | ئیندێکس لە سنوور دەرەوە |
| `##Key` | کلیل لە فەرهەنگدا نییە |
| `##Range` | لە مەودای ژمارەی تەواوی پارێزراو دەرەوە |
| `##Type` | ناگونجانی جۆر |
| `##Parse` | شیکاری داتا |
| `##IO` | فایل / سیستەم |
| `##Network` | هەڵەکانی تۆڕ |
| `##DB` | بنکەی دراو |
| `##Time` | بەروارێک کە بوونی نییە |
| `##_` | هەر هەڵەیەک (هەمووی دەگرێت) |

`!` نیشانەی **هەڵە و زۆر**ە، و بە هەمان شێوە دەخوێندرێتەوە لە هەردوو خێزانەکاندا: `$!` لە نرخێک دەپرسێت ئایا هەڵەیە؛ `$!!`، بە نیشانەی دووهەند، بەبێ پرسیار بەرەو سەرەوە بڵاوی دەکاتەوە.

> شکستهێنانی کتێبخانەی ستاندارد وەک **نرخی هەڵەی نەرم** دەگەڕێنەوە کە بە `$!` تاقی دەکەیتەوە یان بە `!?` دەیگریت، لە جیاتی هەڵوەشاندنەوە. `$!!` یەکێک بە بانگکەرەکە بڵاو دەکاتەوە.

## مۆدیوولەکان

```zymbol
# حیساب {
    #> { کۆکردنەوە, PI }

    PI := ۳.۱۴۱۵۹
    کۆکردنەوە(a, b) { <~ a + b }
}
```

```zymbol
<# ./حیساب => ح

>> ح::کۆکردنەوە(۵, ۳) ¶
>> ح.PI ¶
```

```zymbol
# کتێبخانەی_من {
    #> { ناوەکی_کۆکردنەوە => کۆی_گشتی }

    ناوەکی_کۆکردنەوە(a, b) { <~ a + b }
}
```

دوو نیشانەی مۆدیوول هەمان بیرۆکەن، ئێستا بۆ فایلەکان: `#` ئاستی **ڕاگەیاندن**ە — ئەوەی شتێک *چییە*، نەک نرخەکەی — و تیرەکە دەڵێت کۆدەکە بۆ کوێ دەچێت:

```text
<#   تیرەکە دەچێتە ژوورەوە: هاوردەکردن، لە فایلێکی دیکەوە بهێنە
#>   تیرەکە دەچێتە دەرەوە: هەناردەکردن، پێشکەشی فایلەکانی دیکە بکە
```

نیشانەی ئاراستە هەمیشە لەو لێوارەدا دانیشتووە کە ڕووی لە ئاراستەکەیە کە ئاماژەی پێدەکات. هەمان هۆکارە کە `<~` بۆ چەپ دەگەڕێتەوە (لە فەنکشنەکەوە) و `->` بۆ ڕاست دەچێتە ژوورەوە (بۆ لەشی لامبدا).

> **مۆدیوولێک ڕادەگەیەنێت چی هەناردە دەکات.** بلۆکی `#>` ناچارە — بەجێهێشتنی **E014** ە، و `#> { }` ڕێگایەکە کە مۆدیوولێک دەڵێت ڕووکەشەکەی بەتاڵە. `::` فەنکشنێک بانگ دەکات، `.` نەگۆڕێک دەخوێنێتەوە. تەنها هاوردەکردنەکان، بلۆکی هەناردەکردن، دەستپێکەرە ڕاستەقینەکان و پێناسەکانی فەنکشن دەتوانن دەربکەون لە لەشی مۆدیوولدا؛ هەر شتێک کە جێبەجێبکرێت **E013** ە.

## کتێبخانەی ستاندارد

مۆدیوولە ڕەسەنەکان، وەک هەر یەکێکی دیکە هاوردە دەکرێن:

| مۆدیوول | فەنکشنەکان |
|--------|-----------|
| `std/math` | `sqrt exp ln log pow abs ceil floor round min max sin cos tan asin acos atan atan2 sinh cosh tanh sigmoid` · `PI` `E` |
| `std/random` | `entero rango peso_f64` |
| `std/json` | `decode decode_map encode` |
| `std/io` | `read write append exists delete list mkdir` |
| `std/net` | `get post post_json head` |
| `std/db` | `connect exec query query_one tx commit rollback` … |
| `std/term` | `width pad_left pad_right center truncate` |
| `std/time` | `now today parts of format add diff` |

```zymbol
<# std/math => m

>> m::sqrt(۱۶.۰) ¶      // → 4
>> m.PI ¶               // → 3.141592653589793
```

```zymbol
<# std/term => t

>> t::width("手番") ¶            // → 4   دوو گلیف، چوار ستوون
>> "|" t::center("go", 8) "|" ¶ // → |   go   |
```

```zymbol
<# std/time => T

ڕۆژ = T::of(۲۰۲۶, ۱, ۳۱)
>> T::format(ڕۆژ, "%Y-%m-%d") ¶ // → 2026-01-31
>> T::format(T::add(ڕۆژ, ۱, "month"), "%Y-%m-%d") ¶ // → 2026-02-28
```

> `std/term` **ستوونەکانی پیشاندان** دەپێوێت، نەک پیتەکان: CJK و زۆربەی ئیمۆجیەکان 2 ستوونن، بۆیە خشتەیەک ڕێکبخە بە `t::width`، هەرگیز `$#`.
> لە `std/time` ساتێک میلیچرکەیە لە سەردەمەوە. کەمتر لە ڕۆژێک ماوەیە، لە ڕۆژێکەوە بەرەو سەرەوە ڕۆژژمێرە — بۆیە مانگێک دەکەوێتە هەمان ڕۆژی مانگەکە، کۆکراوەتەوە. `جیاوازی(a, b)` `a - b` ە، بۆیە ساتی پێشووتر یەکەم وەڵامی نەرێنی دەدات.

## پاکێجەکان

`.zyp` بەرنامەیەکی چەند فایلێک دەپێچێتەوە بۆ یەک فایلی گواستنەوە. ئەرشیڤی **سەرچاوەیە**، نەک باینەری، بۆیە لە هەر شوێنێک کە باینەری `zymbol` کاردەکات ئەویش کاردەکات.

```bash
zymbol package پڕۆژەکەم/ --script main.zy -o پڕۆژەکەم.zyp
zymbol run پڕۆژەکەم.zyp
```

> ئەرشیڤەکە مانیفێستێک (`zyp.toml`) هەڵدەگرێت کە سکریپتەکانی چوونەژوورەوە و وەشانی ئەندازیاری پێویست ڕادەگەیەنێت. `zymbol run` دەیخاتە دەرەوە بۆ دایرێکتۆرییەکی کاتی و لەوێوە جێبەجێی دەکات، بۆیە کۆدەکە فرێدراوە لە کاتێکدا ئەوەی سکریپتەکە دەینووسێت دەکەوێتە دایرێکتۆری کاری ڕاستەقینەت. یاریگاکەش فایلی `.zyp` بار دەکات.

## دۆخەکانی ژمارە

Zymbol دەتوانێت ژمارەکان بنووسێت لە **69 نووسەری ژمارەی یونیکۆد** دا — دیڤاناگەری، عەرەبی-هیندی، تایلەندی، کلینگۆنی pIqaD، ئەستووری بیرکاری، پارچەکانی LCD، و زیاتر. دۆخەکە جیهانییە بۆ پرۆسەکە و کاریگەری دەکاتە سەر دەرچوون؛ ژمێرکاری ناگۆڕێت.

```zymbol
#٠٩#    // عەرەبی-هیندی (U+0660–U+0669)
#०९#    // دیڤاناگەری   (U+0966–U+096F)
#๐๙#    // تایلەندی     (U+0E50–U+0E59)
#09#    // ڕێکخستنەوە بۆ ASCII
```

```zymbol
a = ۴۲
>> a ¶                  // → 42
#٠٩#
>> a ¶                  // → ٤٢
>> ۳.۱۴ ¶               // → ٣٫١٤
>> #۱ ¶                 // → #١
#09#
```

ژمارەکانی هەر نووسەرێکی پشتگیریکراو نووسینی دروستن لە سەرچاوەکەدا:

```zymbol
#٠٩#
@ i:۱..۵ { >> i " " }
>> ¶                    // → ١ ٢ ٣ ٤ ٥
#09#
```

خوێندنەوە هاوتایە — ژمارەیەک لە هەر نووسەرێکدا تێدەگەیشترێت:

```zymbol
>> #|"४२"| ¶            // → 42
>> #|'७'| ¶             // → 7
```

> `#` هەمیشە ASCII ە، بۆیە `#0` لە هەموو نووسەرەکاندا بە بینراو جیاوازە لە ژمارەی سفر.
> `#,` و `#^` ژمارەکانی خۆشیان لە نووسەری چالاکدا دەنووسن، و جیاکەرەوەکان شوێنی دەکەون — بەڵام جووتەکە هەرگیز پێچەوانە نابێتەوە: `,` کۆدەکاتەوە و `.` جیاکاتەوە، لە هەموو نووسەرێکدا.

## کردارەکانی داتا

```zymbol
f = ##.۴۲         // بۆ ئەشکەوت
i = ###۳.۷        // بۆ ژمارەی تەواو، خڕکردنەوە  → 4
t = ##!۳.۷        // بۆ ژمارەی تەواو، بڕین  → 3
>> f " " i " " t ¶      // → 42 4 3
>> f#? ¶                // → (##., 2, 42)
```

> ئەشکەوت وەک ژمارە چاپ دەکرێت، هەرگیز وەک توانا نا، و `.0` ی کۆتایی فڕێدەدات — `##.42` `42` دەنووسێت و هێشتا ئەشکەوتە، وەک `f#?` پیشانی دەدات.

```zymbol
>> #|"42"| ¶       // → 42
>> #|"abc"| ¶      // → abc   پارێزراو: دەرچوونەکە بەبێ گۆڕان دەگەڕێنێتەوە
>> ##!'A' ¶        // → 65    کۆدی خاڵی پیتێک
```

```zymbol
pi = ۳.۱۴۱۵۹۲۶۵
>> #.۲|pi| ¶       // → 3.14          خڕکردنەوە بۆ 2 دەیەیی
>> #!۲|pi| ¶       // → 3.14          بڕین بۆ 2 دەیەیی
>> #,|۱۲۳۴۵۶۷| ¶   // → 1,234,567     جیاکەرەوەی هەزار
>> #^|۱۲۳۴۵.۶۷۸| ¶ // → 1.2345678e4  نیشانەی زانستی
```

```zymbol
>> 0x41 ¶        // → A   شانزە
>> 0b01000001 ¶  // → A   دووانە
>> 0o101 ¶       // → A   هەشت
>> 0d65 ¶        // → A   دە
```

> نووسینی بنەڕەت لە مەودای ASCII دا **پیتێکە**: `0d65 == 'A'` `#1` ە، و `0d65 == 65` `#0` ە. هەر چوار بنەڕەتەکە هەمان پیت هجی دەکەن.

## چۆن نیشانەکان یەکدەگرن

لە هەموو ئەم دەستنووسەدا هەمان شتت بینیوە: **کردارێک وێنەیەک نییە بۆ لەبەرکردن، چەند نیشانەیەکن بە یەک ڕیزدا، و هەر یەکێکیان واتاکەی خۆی دەبەخشێت.** ئێستا کە هەموویان دەزانیت، ئەمە شێوازە تەواوەکەیە.

یەکەم **لە چ جیهانێکداین**:

| نیشانە | جیهان | بینیوتە لە |
|--------|-------|----------------------------|
| `$` | کۆمەڵەیەک | `$#` `$+` `$?` `$^-` |
| `@` | کات، هەر شتێک کە دووبارە دەبێتەوە | `@!` `@>` `@~` |
| `#` | ئەوەی شتێک *چییە*، نەک نرخەکەی | `#?` `#(…)` `<#` `#>` |
| `>>` | لە بەرنامەکەوە | `>>` `>>!` `>>?` |
| `<<` | بۆ بەرنامەکە | `<<` `<<\|` `<<\|?` |
| `?` | پرسیارکردن، بەبێ پابەندبوون | `?` `_?` `??` `$?` |
| `!` | زۆر، یان هەڵە | `@!` `$!` `!?` |

پاشان **چی دەکرێت لەوێ**: `+` زیادکردن، `-` سڕینەوە، `^` ڕیزکردن، `~` گۆڕین، `#` ژماردن، `|` یەکەیەک، `:` بەستنی ناو.

و دوو یاسا کە هەرگیز شکست ناهێنن:

**دووهەندکردنی نیشانەیەک وای لێدەکات بە تەواوی.** `?` جارێک دەپرسێت، `??` چەند حاڵەت تاقی دەکاتەوە. `$?` دەپرسێت ئایا نرخێک هەیە، `$??` هەموو شوێنەکانی دەگەڕێنێتەوە. `!` هەڵەیەک نیشان دەکات، `!!` بەبێ پرسیار بڵاوی دەکاتەوە.

**نیشانەی دۆخ هەمیشە لە کۆتاییدا دێت.** کاتێک `?` یان `!` دەردەکەون بۆ ئەوەی بڵێن شتێک *چۆن* دەکرێت — بە دوودڵی یان بە زۆر — ئەوان نیشانەی کۆتایی کردارەکەن: `$??`، `$!!`، `<<|?`، `@!`، `##!`، `>>!`، `>>?`، `@:دەرەوە!`. هەرگیز هیچ کارێک لەدوای ئەوانەوە نییە.

شتێکی کرداری لێوە دەردەچێت: **تێکەڵەیەک کە هەرگیز نەتبینیوە پێش ئەوەی بگەڕێی بۆی واتای هەیە.** ئەگەر `$` کۆمەڵە بێت و `^` ڕیز بێت و `-` پێچەوانە بێت، ئەوا `$^-` بە نزمی ڕیز دەکات، و کەس پێویست نەبوو پێت بڵێت.

هەموو لیستەکە بەم شێوەیە کار ناکات، و گوتنی باشترە لە خۆنواندن. زۆربەی کردارەکان بە پاکی جیادەبنەوە. شەش جیادەبنەوە بەڵام لە بەشەکانیان زیاتر واتا دەگەیەنن: `!?` `:!` `:>` `|>` `::` `$++`. و دەیان دەبێت لەبەر بکرێن چونکە هەرگیز جیاناابنەوە: `¶` `><` `#1` `#0` `0x` `0b` `0o` `0d` `###` `°`.

> ژماردنی ئەوانەی ناڕوون لە جیاتی گریمانەکردنیان کەمە بەئەنقەستە: ئەوان نرخی ڕاستەقینەی لەبەرکردنی زمانەکەن. ئاماژەی تەواو — لیستەکە، هۆمۆگرافی ڕاگەیەنراوەکان، و ئەو یاسایانەی کە کردارێکی نوێ دەبێت جێبەجێیان بکات بۆ بوونی — لە `SYMBOLS.md` دایە، لە کۆگای وەرگێڕەکە.

### v0.0.9 — کۆمەڵەکان بڕیاریان دا _(ئەیلوول 2026)_

- **شکێنەر** فەرهەنگ نووسینی تایبەتی خۆی هەیە: `#(کلیل: نرخ)`. `(x: 1)` ی ڕووت ڕەت دەکرێتەوە، و `#()` فەرهەنگی بەتاڵە — کە `()` هەرگیز نەیدەتوانی بێت
- **شکێنەر** دیاریکردنی ئیندێکسی کشاندەوە: `ڕیز[i] = v` و هەموو شێوازە تێکەڵەکان. `=` نرخێک بە **ناوێک** دەدات؛ گۆڕینی بەشێکی کۆمەڵە `$~` ە
- **شکێنەر** ئیندێکسی زنجیرەیی `m[i][j]` ڕەت دەکرێتەوە بۆ خوێندنەوە و نووسین — `>` لە نێوان هەنگاوەکاندا دەچێت
- **شکێنەر** مۆدیوولێک دەبێت ڕابگەیەنێت چی هەناردە دەکات (**E014**)؛ `#> { }` ڕێگایەکە کە مۆدیوولێک دەڵێت ڕووکەشەکەی بەتاڵە
- **شکێنەر** دیاریکەری خول ژماردنێک یان مەرجێکە — هیچ ڕاستییەک نییە. `@ []` و `@ 3.5` ڕەت دەکرێنەوە
- **زیادکرا** `##_` — نووسینی یەکە، و ڕێگای پرسیاری بەرنامە ئەگەر شتێک نەماوە
- **زیادکرا** `#[…]` — ڕیزێک کە تێکەڵی جۆری توخمەکانی ڕاگەیەنراوە
- **زیادکرا** `#?` چوار کۆمەڵە جیا دەکاتەوە: `##]` `##[` `##)` `##(`
- **زیادکرا** `std/time` — کاتژمێر و ڕۆژژمێری شارستانی، لەگەڵ ناوچەکان و ژمێرکاری ڕۆژژمێر

- **زیادکرا** `@ (k, v):جووتەکان` — شێوازێک لە سەری خولەکە
