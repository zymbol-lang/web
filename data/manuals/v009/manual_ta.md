# Zymbol-Lang கையேடு

> **v0.0.9 க்காக திருத்தப்பட்டது — 2026-09-07**

**Zymbol-Lang** என்பது ஒரு குறியீட்டு நிரலாக்க மொழி. அதன் இலக்கணத்தில் சொற்கள் இல்லை — ஒவ்வொரு கட்டுமானமும் ஒரு குறியீடு. எந்த மனித மொழியிலும் ஒரே மாதிரியாக செயல்படுகிறது.

- முழு யூனிகோடு — எந்த மொழியிலும் அல்லது உணர்ச்சிக்குறியிலும் அடையாளங்காட்டிகள்
- மனித மொழியைச் சாராதது — குறியீடு எல்லா இடங்களிலும் ஒரே மாதிரியானது

## மாறிகள் மற்றும் மாறிலிகள்

```zymbol
மாறி = ௧௦              // மாறக்கூடிய மாறி
PI := ௩.௧௪௧௫௯       // மாறிலி — மீண்டும் ஒதுக்கீடு இயக்க நேர பிழை
பெயர் = "அமுதன்"
செயலில் = #௧         // பூலியன் உண்மை
👋 := "வணக்கம்"
```

```zymbol
மாறி = ௧௦    // ௧௦
மாறி += ௫    // ௧௫
மாறி -= ௩    // ௧௨
மாறி *= ௨    // ௨௪
மாறி /= ௩    // ௮
மாறி %= ௩    // ௨
மாறி ^= ௨    // ௪
மாறி++       // ௫
மாறி--       // ௪
```

`°` (பட்டம் குறி, U+00B0) முதல் பயன்பாட்டில் ஒரு மாறியை அதன் நடுநிலை மதிப்பிற்கு தானாக துவக்குகிறது:

```zymbol
எண்கள் = [௩, ௧, ௪, ௧, ௫]
@ n:எண்கள் {
    °மொத்தம் += n
}
>> மொத்தம் ¶              // → 14
```

> `°மாறி` (முன்னொட்டு) சுழற்சிக்கு மேலே நங்கூரமிடுகிறது — முடிவு `@` க்குப் பிறகு படிக்கக்கூடியது.
> `மாறி°` (பின்னொட்டு) சுழற்சிக்குள் நங்கூரமிடுகிறது — சுழற்சி முடியும் போது அது இறந்துவிடும்.

ஒரு பெயர் மட்டுமே உள்ள கூற்று மாறியைப் படித்து மதிப்பை நிராகரிக்கிறது, எனவே இது எச்சரிக்கிறது:

```zymbol
எண்ணிக்கை = ௫
எண்ணிக்கை
```

தொகுப்பி இவ்வாறு எச்சரிக்கிறது (அதன் செய்திகள் எப்போதும் ஆங்கிலத்தில் இருக்கும்):

```text
warning: this statement does nothing: 'எண்ணிக்கை' is read and discarded
  = help: remove it, or use it — `>> name ¶` to print it
```

அதாவது: *«இந்த கூற்று எதுவும் செய்யவில்லை: 'எண்ணிக்கை' படிக்கப்பட்டு நிராகரிக்கப்பட்டது»*.

## தரவு வகைகள்

| வகை | உண்மையெழுத்து | `#?` குறிச்சொல் | குறிப்புகள் |
|------|---------------|----------------|-------------|
| முழு எண் | `௪௨`, `-௭` | `###` | பாதுகாப்பான முழு எண்: ±(2⁵³ − 1) |
| மிதவை | `௩.௧௪`, `௧.௫e௧௦` | `##.` | IEEE-754 இரட்டை |
| சரம் | `"உரை"` | `##"` | இடைச்செருகல்: `"வணக்கம் {பெயர்}"` |
| எழுத்து | `'A'` | `##'` | ஒரு யூனிகோட் குறியீட்டுப் புள்ளி |
| பூலியன் | `#௧`, `#௦` | `##?` | எண் அல்ல — `#௧ ≠ ௧` |
| தொகுப்பு | `[௧, ௨, ௩]` | `##]` | ஒரு வகை, சரிபார்க்கப்பட்டது |
| அறிவிக்கப்பட்ட கலவை | `#[௧, "இரண்டு"]` | `##[` | `[…]` போன்ற அதே வகை, சரிபார்ப்பு இல்லை |
| டப்பிள் | `(a, b)` | `##)` | இடநிலை, மாற்றமுடியாது |
| அகராதி | `#(a: ௧, b: ௨)` | `##(` | சாவி அடிப்படையிலானது, மாறக்கூடியது |
| செயல்பாடு | பெயரிடப்பட்ட செயல்பாடு குறிப்பு | `##()` | முதல்-வகுப்பு; காட்டுகிறது `<funct/N>` |
| லாம்ப்டா | `a -> a * ௨` | `##->` | முதல்-வகுப்பு; காட்டுகிறது `<lambd/N>` |
| அலகு | `##_` | `##_` | இல்லாமை — null இல்லை |

```zymbol
>> ௪௨#? ¶               // → (###, 2, 42)
>> [௧, ௨, ௩]#? ¶        // → (##], 3, [1, 2, 3])
>> #(a: ௧)#? ¶          // → (##(, 1, #(a: 1))
```

பாதுகாப்பான வரம்பிற்கு வெளியே செல்லும் ஒரு முழு எண், பிடிக்கக்கூடிய பிழை, ஒருபோதும் அமைதியான மடக்கல் அல்ல:

```zymbol
!? {
    >> (௯௦௦௭௧௯௯௨௫௪௭௪௦௯௯௧ + ௧) ¶
} :! ##Range {
    >> "வரம்பிற்கு வெளியே" ¶ // → வரம்பிற்கு வெளியே
}
```

`##_` என்பது ஒரு நிரல் ஏதாவது இல்லையா என்று கேட்கும் விதம்:

```zymbol
ஒன்றுமில்லை() { }
மதிப்பு = ஒன்றுமில்லை()
>> (மதிப்பு == ##_) ¶     // → #1
```

## வெளியீடு மற்றும் உள்ளீடு

```zymbol
பெயர் = "அமுதன்"
மொத்தம் = ௩
>> "வணக்கம்" ¶             // → வணக்கம்
>> "a=" பெயர் " b=" மொத்தம் ¶ // → a=அமுதன் b=3
>> மொத்தம்#? ¶            // → (###, 1, 3)
```

```zymbol
<< பெயர்
<< "உங்கள் பெயரை உள்ளிடவும்: " பெயர்
<< ###(௪) "வயது: " வயது
```

**இரண்டு குறிகளின் வடிவத்தைப் பாருங்கள்.** `>>` வெளியே சுட்டிக்காட்டுகிறது: இது தரவை நிரலில் இருந்து வெளியே எடுக்கிறது. `<<` உள்ளே சுட்டிக்காட்டுகிறது: இது தரவை நிரலுக்குள் கொண்டுவருகிறது. அங்கே நினைவில் கொள்ள எதுவும் இல்லை — அம்பு தகவல் எந்த திசையில் பயணிக்கிறது என்பதைக் காட்டுகிறது, அதே யோசனை எதையாவது நகர்த்தும் ஒவ்வொரு குறியிலும் திரும்பி வருகிறது.

> `¶` மற்றும் `\\` சமமான புதிய வரிகள். `>>` ஒருபோதும் ஒன்றைச் சேர்க்காது.
> உயர்த்திக்கு முன் ஒரு வகை குறிப்பிடி படிக்கும் போது சரிபார்த்து, மதிப்பு செல்லுபடியாகும் வரை மீண்டும் கேட்கும்:
> `##.` மிதவை · `##.(T,D)` தசம · `###(N)` முழு எண் · `##"(N)" உரை · `##'` ஒரு எழுத்து.

ஒரு கோப்பின் உயர் மட்டத்தில், `<~>` நிரலின் வெளியேறும் நிலை:

```zymbol
>> "சரிபார்க்கிறது" ¶      // → சரிபார்க்கிறது
<~ ௦
```

## TUI அடிப்படைகள்

ஊடாட்ட நிரல்களுக்கான முனைய UI செயலிகள். பெரும்பாலானவை `>>| { }` தொகுதி தேவைப்படுகிறது (மாற்றுத் திரை + மூல பயன்முறை).

```zymbol
>>| {
    >>!
    >>~ (௧, ௧, ௦, ௧௦) > "இயங்குகிறது"
    @~ ௧௦௦௦
    >>~ (௨, ௧) > "முடிந்தது."
}
```

```zymbol
>>| {
    [வரிசைகள், நெடுவரிசைகள்] = >>?
    >>~ (௧, ௧) > "முனையம்: " வரிசைகள் " x " நெடுவரிசைகள்
    <<| சாவி
    >>~ (௨, ௧) > "அழுத்தியது: " சாவி
}
```

இங்குதான் குறிகள் ஏன் பெருக்கப்படுவதற்குப் பதிலாக இணைக்கப்படுகின்றன என்பதை நீங்கள் காணலாம். `<<` உள்ளீடு மற்றும் `?` உறுதிப்பாடு இல்லாமல் கேட்கிறது என்பதை நீங்கள் ஏற்கனவே அறிவீர்கள். ஒரே ஒரு புதிய குறி:

- `|` **ஒரு அலகு**, முழு ஓட்டம் அல்ல.

அதனுடன், இரண்டு விசைப்பலகை செயலிகளும் தங்களைத் தாங்களே படித்துக்கொள்கின்றன:

```text
<<        |             ?
உள்ளீடு   ஒரு அலகு    உறுதிப்பாடு இல்லாமல்

<<|   ஒரு சாவியை எடுத்து, ஒன்று வரும் வரை காத்திருக்கவும்
<<|?  ஒரு சாவி இருக்கிறதா என்று பார்த்து, இல்லையென்றால் தொடரவும்
```

மறுபக்கமும் இதே: `>>` அனுப்புகிறது, `>>!` **வலுக்கட்டாயமாக** அனுப்புகிறது (முழு திரையையும் அழிக்கிறது), அதே சமயம் `>>?` எழுதுவதற்குப் பதிலாக **கேட்கிறது** (முனையம் எவ்வளவு பெரியது). வலதுபுறத்தில் உள்ள குறி பயன்முறையை மாற்றும் ஒன்றாகும், அது எப்போதும் கடைசியாக வரும்.

> `>>!` திரையை அழிக்கிறது. `>>?` `[வரிசைகள், நெடுவரிசைகள்]` ஐ திருப்பித் தருகிறது. `@~ N` N மில்லி விநாடிகள் உறங்குகிறது.
> `<<|` ஒரு சாவி அழுத்தத்தைப் படிக்கிறது (தடுக்கும்); `<<|?` தடுக்காமல் விசாரிக்கிறது (`'\0'` இல்லையென்றால்).
> அம்பு விசைகள் `'↑' '↓' '←' '→'` ஆக குறிவிலக்கம் செய்யப்படுகின்றன; ESC குறியீட்டுப் புள்ளி 27.
> நிலைப்படுத்தப்பட்ட வெளியீட்டு டப்பிள்: `(வரிசை, நெடுவரிசை, BKS, முன், பின்)` — எந்த இடமும் கமாவுடன் தவிர்க்கப்படலாம் (`>>~ (,,, ௧௯௬) > "சிவப்பு"`).
> BKS பிட்மாஸ்க்: `1`=தடிமன், `2`=சாய்வு, `4`=அடிக்கோடு. ANSI 256-வண்ண தட்டு (`0`=முனைய இயல்புநிலை).

## சரங்கள்

```zymbol
பெயர் = "அமுதன்"
n = ௪௨
>> "வணக்கம் " பெயர் " உங்களிடம் " n " உள்ளது" ¶ // → வணக்கம் அமுதன் உங்களிடம் 42 உள்ளது

```

```zymbol
s = "வணக்கம் உலகம்"
நீளம் = s$#                  // ௧௩
துணை = s$[௧..௭]             // "வணக்கம்"
உள்ளது = s$? "உலகம்"          // #௧
பகுதிகள் = "a,b,c,d"$/ ','    // [a, b, c, d]
மாற்று = s$~~["ம":"ன"]        // "வணக்கன் உலகன்"
கோடு = "─" $* ௨௦
```

> `+` எண்களுக்கு மட்டுமே. சரங்களுக்கு அருகருகே வைப்பது அல்லது இடைச்செருகல் பயன்படுத்தவும்.
> `\{` மற்றும் `\}` உண்மையான பிரேஸ்கள் — தப்பித்தல் சமச்சீர்.

## கட்டுப்பாட்டு ஓட்டம்

```zymbol
a = ௭
? a > ௧௦௦ {
    >> "பெரியது" ¶
} _? a > ௦ {
    >> "நேர்மறை" ¶     // → நேர்மறை
} _ {
    >> "எதிர்மறை" ¶
}
```

இங்கே இரண்டு புதிய குறிகள் உள்ளன, மூன்றாவது அவற்றை ஒன்றாக இணைப்பதிலிருந்து வருகிறது:

- `?` **கேட்பது**: இது ஒரு நிபந்தனையைத் திறக்கிறது.
- `_` **குறிப்பிடப்படாதது**: எந்த கேள்வியும் பொருந்தாதபோது எஞ்சியிருக்கும் கிளை.
- `_?` இரண்டும் தொடர்ச்சியாக: *எதுவும் பொருந்தவில்லை என்றால், மீண்டும் கேளுங்கள்*.

அதனால்தான் `_?` அப்படி எழுதப்பட்டுள்ளது. இது கற்க ஒரு புதிய குறியீடு அல்ல — இது `_` அதைத் தொடர்ந்து `?`, மேலும் அதன் இரண்டு பகுதிகளும் வரிசையில் படிக்கும்போது என்ன அர்த்தமாகிறதோ அதைத்தான் சரியாகக் குறிக்கிறது.

> பிரேஸ்கள் `{ }` ஒரு கூற்றுக்கு கூட **கட்டாயம்**.

## பொருத்தம்

```zymbol
மதிப்பெண் = ௮௫
தரம் = ?? மதிப்பெண் {
    ௯௦..௧௦௦ => 'A'
    ௮௦..௮௯  => 'B'
    _       => 'F'
}
>> தரம் ¶              // → B
```

```zymbol
வெப்பநிலை = -௫
நிலை = ?? வெப்பநிலை {
    < ௦  => "பனி"
    < ௨௦ => "குளிர்"
    _    => "வெப்பம்"
}
>> நிலை ¶              // → பனி
```

`?` "கேட்பது" என்பது உங்களுக்கு ஏற்கனவே தெரியும். **`??` பலமுறை கேட்பது**: ஒரு குறியீட்டை இரட்டிப்பாக்குவது, மொழியில் எங்கும், அந்த குறியீடு ஒருமுறை செய்வதை பலமுறை செய்வதாகும். ஒரு `?` ஒரு நிபந்தனையை சோதிக்கிறது; `??` வழக்குகளின் பட்டியலுக்கு எதிராக சோதிக்கிறது.

மாற்றுகள் `||` உடன் இணைகின்றன, மேலும் அவை வடிவ வகைகளை கலக்கலாம்:

```zymbol
சாவி = 'P'
செயல் = ?? சாவி {
    'p' || 'P' => "இடைநிறுத்து"
    < ௦ || > ௧௦௦ => "வரம்பிற்கு வெளியே"
    _ => "புறக்கணிக்கப்பட்டது"
}
>> செயல் ¶             // → இடைநிறுத்து
```

## சுழற்சிகள்

```zymbol
@ i:௧..௪  { >> i " " }
>> ¶                    // → 1 2 3 4
@ i:௧..௯:௨ { >> i " " }
>> ¶                    // → 1 3 5 7 9
@ i:௫..௧:௧ { >> i " " }
>> ¶                    // → 5 4 3 2 1
```

```zymbol
n = ௧
@ n <= ௬௪ { n *= ௨ }
>> n ¶                  // → 128
```

```zymbol
பழங்கள் = ["ஆப்பிள்", "பேரிக்காய்", "திராட்சை"]
@ p:பழங்கள் { >> p " " }
>> ¶                    // → ஆப்பிள் பேரிக்காய் திராட்சை
@ c:"வணக்கம்" { >> c "-" }
>> ¶                    // → வ-ண-க-்-க-ம-்-
```

```zymbol
@ i:௧..௧௦ {
    ? i % ௨ == ௦ { @> }
    ? i > ௭ { @! }
    >> i " "
}
>> ¶                    // → 1 3 5 7
```

```zymbol
எண்ணிக்கை = ௦
@:வெளி {
    எண்ணிக்கை++
    ? எண்ணிக்கை >= ௩ { @:வெளி! }
}
>> எண்ணிக்கை ¶             // → 3
```

`@` **நேரத்தின்** குறி: மீண்டும் மீண்டும் நிகழும் அனைத்தும் அதில் வாழ்கின்றன. அந்த நேரத்தை குறைக்க நீங்கள் அதன் அருகில் ஒரு குறியை சேர்க்கிறீர்கள்:

- `@!` — `!` **வலுக்கட்டாயம்**: இப்போது சுழற்சியை விட்டு வெளியேறவும்.
- `@>` — `>` முன்னோக்கி தள்ளுகிறது: அடுத்த சுற்றுக்குச் செல்லவும்.
- `@:வெளி!` — `:` **ஒரு பெயரை பிணைக்கிறது**, எனவே இது *வெளி* என்ற பெயரிடப்பட்ட சுழற்சியை வெட்டுகிறது, அருகிலுள்ளதை அல்ல.

மூன்று செயலிகள், அவற்றில் எதையும் தனித்தனியாக மனப்பாடம் செய்ய வேண்டியதில்லை: அவை `@` மற்றும் அது என்ன செய்கிறது என்பதை ஏற்கனவே கூறும் ஒரு குறியீடு.

> **ஒரு குறிப்பிடி என்பது ஒரு எண்ணிக்கை அல்லது நிபந்தனை.** ஒரு `முழு எண்` ஒரு எண்ணிக்கை, ஒருமுறை மதிப்பிடப்படுகிறது — `@ 0` உடலை பூஜ்யம் முறை இயக்குகிறது. மற்ற அனைத்தும் ஒரு நிபந்தனை. உண்மைத்தன்மை இல்லை: `@ []` மற்றும் `@ 3.5` நிராகரிக்கப்படுகின்றன. ஒரு தொகுப்பை கடக்க `@ x:உருப்படிகள்` பயன்படுத்தவும்; அதை எண்ண, `@ உருப்படிகள்$#`.

## செயல்பாடுகள்

```zymbol
கூட்டு(a, b) { <~ a + b }
>> கூட்டு(௩, ௪) ¶        // → 7
```

```zymbol
தொகையியல்(n) {
    ? n <= ௧ { <~ ௧ }
    <~ n * தொகையியல்(n - ௧)
}
>> தொகையியல்(௫) ¶       // → 120
```

ஒரு செயல்பாடு கோப்பின் மாறிகளை மதிப்பின் மூலம் படிக்கிறது, மேலும் உள்ளே எழுதுவது உள்ளேயே இருக்கும்:

```zymbol
வரம்பு = ௧௦௦
உள்ளே(n) { <~ n < வரம்பு }
>> உள்ளே(௪௨) ¶         // → #1
```

இரண்டு குறிகள் அதை மாற்றுகின்றன, மேலும் இரண்டும் **கையொப்பத்திலும் அழைப்பு இடத்திலும்** எழுதப்படுகின்றன:

```zymbol
அதிகரி(எண்ணிக்கை<~) { எண்ணிக்கை = எண்ணிக்கை + ௧ }
மொத்தம் = ௦
அதிகரி(மொத்தம்<~)
>> மொத்தம் ¶              // → 1
```

> `p~` ஒரு வேலை செய்யும் நகல் — உடல் அதை மீண்டும் ஒதுக்கலாம் மற்றும் அழைப்பவர் பாதிக்கப்படாமல் இருக்கும்.
> `p<~` ஒரு வெளியீட்டு அளவுரு — மாற்றம் திரும்பிச் செல்கிறது. குறி இல்லாமல் `அதிகரி(மொத்தம்)` ஒரு சொற்பொருள் பிழை: குறிப்பும் கையொப்பமும் பிரிந்து செல்ல முடியாது.

```zymbol
கூட்டுத்தொகை = (a, b) -> a + b
```

```zymbol
வகைப்படுத்து = a -> {
    ? a > ௦ { <~ "நேர்மறை" }
    _? a < ௦ { <~ "எதிர்மறை" }

}
>> வகைப்படுத்து(-௪) ¶         // → எதிர்மறை
```

```zymbol
காரணி = ௩
மும்மடங்கு = a -> a * காரணி
```

ஒரு லாம்ப்டா எந்த அளவுருக்களையும் எடுக்காமல் இருக்கலாம்:

> ஒரு லாம்ப்டா கோப்பின் மாறிகளை **உருவாக்கப்படும் போது** கைப்பற்றுகிறது; பெயரிடப்பட்ட செயல்பாடு அவற்றை **அழைக்கப்படும் போது** படிக்கிறது.

## தொகுப்புகள்

```zymbol
தொகுப்பு = [௧, ௨, ௩, ௪, ௫]
>> தொகுப்பு[௧] ¶       // → 1   குறியீட்டு எண்ணிக்கை 1-அடிப்படையானது
>> தொகுப்பு[-௧] ¶      // → 5   எதிர்மறை இறுதியிலிருந்து எண்ணுகிறது
>> தொகுப்பு$# ¶        // → 5   நீளம்
```

```zymbol
தொகுப்பு = [௧, ௨, ௩]
>> (தொகுப்பு$+ ௬) ¶          // → [1, 2, 3, 6]   சேர்க்கவும்
>> (தொகுப்பு$+[௨] ௯௯) ¶      // → [1, 99, 2, 3]  நிலை 2 இல் செருகவும்
>> (தொகுப்பு$- ௩) ¶          // → [1, 2]         முதல் தோற்றத்தை நீக்கு
>> (தொகுப்பு$-[௧]) ¶         // → [2, 3]         குறியீடு 1 இல் நீக்கு
>> (தொகுப்பு$[௧..௨]) ¶       // → [1, 2]         துண்டு, இரு முனைகளும் சேர்க்கப்பட்டன
>> (தொகுப்பு$? ௩) ¶          // → #1             உள்ளது
```

இவை அனைத்தும் `$` உடன் தொடங்குகின்றன, இது **தொகுப்பின்** குறி, மேலும் அதில் என்ன செய்யப்படுகிறது என்பதைக் கூறும் ஒரு குறியுடன் தொடர்கிறது: `#` எத்தனை, `+` சேர்க்கவும், `-` நீக்கு, `?` உள்ளதா என்று கேள். மற்றும் `??` போல, குறியை இரட்டிப்பாக்குவது அதை முழுமையாக செய்வதாகும்: `$?` ஒரு மதிப்பு *உள்ளதா* என்று கேட்கிறது, `$??` *எத்தனை இடங்களில்* உள்ளது என்று கேட்டு அவை அனைத்தையும் திருப்பித் தருகிறது.

```zymbol
தொகுப்பு = [௩, ௧, ௨]
>> (தொகுப்பு$^+) ¶     // → [1, 2, 3]   ஏறு
>> (தொகுப்பு$^-) ¶     // → [3, 2, 1]   இறங்கு
```

**முடிவின் விதி.** ஒரு செயலி, மற்றும் அதைச் சுற்றியுள்ள குறியீடு அதனுடன் என்ன செய்கிறது என்பது முடிவு செய்கிறது: பயன்படுத்தப்பட்டால், அது **கட்டமைக்கிறது** மற்றும் அசலை அப்படியே விட்டுவிடுகிறது; நிராகரிக்கப்பட்டால், அது **மாற்றியமைக்கிறது**.

```zymbol
தொகுப்பு = [௧, ௨, ௩]
நகல் = தொகுப்பு[௨]$~ ௯௯
>> தொகுப்பு ¶                // → [1, 2, 3]
>> நகல் ¶              // → [1, 99, 3]
தொகுப்பு[௨]$~ ௯௯
>> தொகுப்பு ¶                // → [1, 99, 3]
```

> **`=` ஒருபோதும் ஒரு தொகுப்பில் எழுதாது.** `தொகுப்பு[2] = 99` என்பது Zymbol இன் ஒரு வடிவம் அல்ல — `=` ஒரு **பெயருக்கு** மதிப்பை அளிக்கிறது. ஒரு தொகுப்பின் ஒரு பகுதியை மாற்றுவது `$~` ஆகும், ஒவ்வொரு தொகுப்பிலும்.

`[…]` ஒரு வகையைக் கொண்டுள்ளது மற்றும் சரிபார்க்கப்படுகிறது; ஒரு வேண்டுமென்றே கலவை `#[…]` உடன் **அறிவிக்கப்படுகிறது**:

```zymbol
கலவை = #[௧, "இரண்டு", #௧]
>> கலவை ¶             // → [1, இரண்டு, #1]
>> ([௧, ௨] == #[௧, ௨]) ¶ // → #1
```

## பலபரிமாண குறியீட்டு

`>` ஒரு உள்ளமைக்கப்பட்ட கட்டமைப்பிற்குள் இறங்குகிறது. ஒரு அடைப்புக்குறி குழு ஒரு உறுப்பை குறிப்பிடுகிறது, அது எவ்வளவு ஆழமாக இருந்தாலும் சரி.

```zymbol
m = [[௧,௨,௩], [௪,௫,௬], [௭,௮,௯]]
>> m[௨>௩] ¶        // → 6   வரிசை 2, நெடுவரிசை 3
>> m[-௧>-௧] ¶      // → 9   கடைசி வரிசை, கடைசி நெடுவரிசை
```

```zymbol
m = [[௧,௨,௩], [௪,௫,௬], [௭,௮,௯]]
>> m[௧>௧ ; ௨>௨ ; ௩>௩] ¶          // → [1, 5, 9]          தட்டையானது: மூலைவிட்டம்
>> m[[௧>௧, ௧>௩] ; [௩>௧, ௩>௩]] ¶  // → [[1, 3], [7, 9]]   கட்டமைக்கப்பட்டது: மூலைகள்
```

```zymbol
m = [[௧,௨,௩], [௪,௫,௬]]
>> (m[௧>௨]$~ ௯௯) ¶      // → [[1, 99, 3], [4, 5, 6]]
```

> `m[1][2]` Zymbol இன் ஒரு வடிவம் **அல்ல**. சங்கிலி குறியீடு படிப்பதற்கும் எழுதுவதற்கும் நிராகரிக்கப்படுகிறது — ஒவ்வொரு அணுகலுக்கும் ஒரு அடைப்புக்குறி குழு, மற்றும் `>` என்பது படிகளுக்கு இடையில் செல்வது.

## அகராதி

பெயரிடப்பட்ட புலங்களைக் கொண்ட ஒரு டப்பிள் ஒரு அகராதி, மற்றும் v0.0.9 முதல் இது `#(…)` என எழுதப்படுகிறது.

```zymbol
நபர் = #(பெயர்: "அமுதன்", வயது: ௨௫)
>> நபர்.பெயர் ¶        // → அமுதன்
>> நபர்["வயது"] ¶    // → 25
```

```zymbol
நபர் = #(பெயர்: "அமுதன்", வயது: ௨௫)
புலம் = "பெயர்"
>> நபர்[புலம்] ¶     // → அமுதன்
```

இது மாறக்கூடியது, சாவிகளை சேர்க்கலாம், மேலும் இது கடக்கக்கூடியது:

```zymbol
இருப்பு = #(பேரிக்காய்: ௪)
இருப்பு["ஆப்பிள்"]$~ ௧௦
@ k:இருப்பு { >> k "=" இருப்பு[k] " " }
>> ¶                    // → பேரிக்காய்=4 ஆப்பிள்=10
```

```zymbol
இருப்பு = #(பேரிக்காய்: ௪, ஆப்பிள்: ௧௦)
@ (k, v):இருப்பு { >> k ":" v " " }
>> ¶                    // → பேரிக்காய்:4 ஆப்பிள்:10
```

> `#()` காலி அகராதி, இது `()` ஆக முடியாது — அது காலி டப்பிளாகவும் இருக்க வேண்டும். நிர்வாண `(a: 1)` இந்த செய்தியுடன் நிராகரிக்கப்படுகிறது: *a dictionary is written `#(…)`* — «ஒரு அகராதி `#(…)` என எழுதப்படுகிறது».
> ஒரு அகராதி சாவியால் குறிப்பிடப்படுகிறது, ஒருபோதும் நிலையால் அல்ல, எனவே `நபர்[1]` ஒரு பிழை.

## டப்பிள்கள்

டப்பிள்கள் **மாற்றமுடியாத** வரிசைப்படுத்தப்பட்ட கொள்கலன்கள், அவை வெவ்வேறு வகையான மதிப்புகளைக் கொண்டுள்ளன.

```zymbol
புள்ளி = (௧௦, ௨௦)
>> புள்ளி[௧] ¶           // → 10
தரவு = (௪௨, "வணக்கம்", #௧, ௩.௧௪)
>> தரவு[௩] ¶            // → #1
```

```zymbol
t = (௧௦, ௨௦, ௩௦)
t2 = t[௨]$~ ௯௯௯
>> t ¶                  // → (10, 20, 30)
>> t2 ¶                 // → (10, 999, 30)
```

> ஒரு டப்பிளை அதன் இடத்தில் மாற்றும் எந்த முயற்சியும் ஒரு பிழை, செயலி எதுவாக இருந்தாலும் — மாற்றமுடியாதது மதிப்பின் ஒரு பண்பு, ஒவ்வொரு `$` க்குள்ளும் ஒரு விதிவிலக்கு அல்ல.

```zymbol
தொகுப்பு = [௧௦, ௨௦, ௩௦, ௪௦, ௫௦]
[a, b, c] = தொகுப்பு
```

```zymbol
தொகுப்பு = [௧௦, ௨௦, ௩௦, ௪௦, ௫௦]
[முதல், *எஞ்சிய] = தொகுப்பு
>> முதல் ¶            // → 10
>> எஞ்சிய ¶              // → [20, 30, 40, 50]
```

```zymbol
புள்ளி = (௧௦௦, ௨௦௦)
(px, py) = புள்ளி
```

```zymbol
நபர் = #(பெயர்: "கௌசிக்", வயது: ௨௫)
#(பெயர்: n, வயது: v) = நபர்
```

## உயர்-வரிசை செயல்பாடுகள்

```zymbol
எண்கள் = [௧, ௨, ௩, ௪, ௫]
>> (எண்கள்$> (a -> a * ௨)) ¶ // → [2, 4, 6, 8, 10]
>> (எண்கள்$| (a -> a % ௨ == ௦)) ¶ // → [2, 4]
>> (எண்கள்$< (௦, (குவி, a) -> குவி + a)) ¶ // → 15
```

```zymbol
எண்கள் = [௧, ௨, ௩, ௪, ௫, ௬]
இரட்டிப்பு(a) { <~ a * ௨ }
பெரியது(a) { <~ a > ௩ }
>> (எண்கள்$> இரட்டிப்பு) ¶    // → [2, 4, 6, 8, 10, 12]
>> (எண்கள்$| பெரியது) ¶    // → [4, 5, 6]
```

```zymbol
தரவுத்தளம் = [#(பெயர்: "கார்லா", வயது: ௨௮), #(பெயர்: "கௌசிக்", வயது: ௨௫)]
வயதுப்படி = தரவுத்தளம்$^ (a, b -> a.வயது < b.வயது)
>> வயதுப்படி[௧].பெயர் ¶     // → கௌசிக்
```

> பெயரிடப்பட்ட ஒரு செயல்பாடு HOF க்கு **அடைப்புக்குறிகள் இல்லாமல்** செல்கிறது: `எண்கள்$> இரட்டிப்பு`. `எண்கள்$> (இரட்டிப்பு)` என எழுதுவது ஒரு பாகுபடுத்தல் பிழை, ஏனெனில் `(` ஒரு லாம்ப்டாவைத் திறக்கிறது.

## பிழை கையாளுதல்

```zymbol
!? {
    a = ௧௦ / ௦
} :! ##Div {
    >> "சுழியால் வகுத்தல்" ¶  // → சுழியால் வகுத்தல்
} :! {
    >> "மற்றவை: " _err ¶
} :> {
    >> "எப்போதும் இயங்கும்" ¶        // → எப்போதும் இயங்கும்
}
```

| வகை | எப்போது |
|------|---------|
| `##Div` | சுழியால் வகுத்தல் |
| `##Index` | குறியீடு வரம்பிற்கு வெளியே |
| `##Key` | அகராதியில் சாவி இல்லை |
| `##Range` | பாதுகாப்பான முழு எண் வரம்பிற்கு வெளியே |
| `##Type` | வகை பொருந்தாமை |
| `##Parse` | தரவு பாகுபடுத்தல் |
| `##IO` | கோப்பு / அமைப்பு |
| `##Network` | வலையமைப்பு பிழைகள் |
| `##DB` | தரவுத்தளம் |
| `##Time` | இல்லாத தேதி |
| `##_` | எந்த பிழையும் (அனைத்தையும் பிடிக்கும்) |

`!` **பிழை மற்றும் வலுக்கட்டாயத்தின்** குறி, மேலும் இது இரண்டு குடும்பங்களிலும் ஒரே மாதிரியாக படிக்கப்படுகிறது: `$!` ஒரு மதிப்பு பிழையா என்று கேட்கிறது; `$!!`, குறியை இரட்டிப்பாக்குவதன் மூலம், கேட்காமல் அதை மேல்நோக்கி பரப்புகிறது.

> நிலையான நூலக தோல்விகள், நிறுத்துவதற்குப் பதிலாக, `$!` மூலம் சோதிக்கும் அல்லது `!?` மூலம் பிடிக்கும் **மென்மையான பிழை மதிப்புகளாக** திரும்பும். `$!!` ஒன்றை அழைப்பவருக்கு பரப்புகிறது.

## தொகுதிகள்

```zymbol
# கால்க் {
    #> { கூட்டு, PI }

    PI := ௩.௧௪௧௫௯
    கூட்டு(a, b) { <~ a + b }
}
```

```zymbol
<# ./கால்க் => c

>> c::கூட்டு(௫, ௩) ¶
>> c.PI ¶
```

```zymbol
# எனது_நூலகம் {
    #> { உள்_கூட்டு => கூட்டுத்தொகை }

    உள்_கூட்டு(a, b) { <~ a + b }
}
```

இரண்டு தொகுதி குறிகளும் ஒரே யோசனை, இப்போது கோப்புகளுக்குப் பயன்படுத்தப்படுகிறது: `#` **அறிவிப்பின்** நிலை — ஒரு விஷயம் *என்ன*, அதன் மதிப்பு அல்ல — மற்றும் அம்பு குறியீடு எந்த திசையில் பயணிக்கிறது என்பதைக் கூறுகிறது:

```text
<#   அம்பு உள்ளே செல்கிறது: இறக்குமதி செய், மற்றொரு கோப்பிலிருந்து கொண்டுவா
#>   அம்பு வெளியே செல்கிறது: ஏற்றுமதி செய், மற்ற கோப்புகளுக்கு வழங்கு
```

ஒரு திசை குறி எப்போதும் அது சுட்டிக்காட்டும் திசையை எதிர்கொள்ளும் விளிம்பில் அமர்ந்திருக்கும். `<~>` இடதுபுறம் திரும்புவதற்கும் (செயல்பாட்டின் வெளியே) மற்றும் `->` வலதுபுறம் நுழைவதற்கும் (லாம்ப்டாவின் உடலுக்குள்) இதுவே காரணம்.

> **ஒரு தொகுதி அது என்ன ஏற்றுமதி செய்கிறது என்பதை அறிவிக்கிறது.** `#>` தொகுதி கட்டாயம் — அதைத் தவிர்ப்பது **E014** ஆகும், மேலும் `#> { }` என்பது ஒரு தொகுதி அதன் மேற்பரப்பு காலியாக உள்ளது என்று கூறும் விதம். `::` ஒரு செயல்பாட்டை அழைக்கிறது, `.` ஒரு மாறிலியைப் படிக்கிறது. தொகுதி உடலில் இறக்குமதிகள், ஏற்றுமதி தொகுதி, உண்மையான துவக்கிகள் மற்றும் செயல்பாடு வரையறைகள் மட்டுமே தோன்றக்கூடும்; இயக்கக்கூடிய எதுவும் **E013** ஆகும்.

## நிலையான நூலகம்

உள்ளமை தொகுதிகள், மற்றவற்றைப் போல இறக்குமதி செய்யப்படுகின்றன:

| தொகுதி | செயல்பாடுகள் |
|--------|--------------|
| `std/math` | `sqrt exp ln log pow abs ceil floor round min max sin cos tan asin acos atan atan2 sinh cosh tanh sigmoid` · `PI` `E` |
| `std/random` | `entero rango peso_f64` |
| `std/json` | `decode decode_map encode` |
| `std/io` | `read write append exists delete list mkdir` |
| `std/net` | `get post post_json head` |
| `std/db` | `connect exec query query_one tx commit rollback` … |
| `std/term` | `width pad_left pad_right center truncate` |
| `std/time` | `now today parts of format add diff` |

```zymbol
<# std/math => m

>> m::sqrt(௧௬.௦) ¶      // → 4
>> m.PI ¶               // → 3.141592653589793
```

```zymbol
<# std/term => t

>> t::width("手番") ¶            // → 4   இரண்டு உருவங்கள், நான்கு நெடுவரிசைகள்
>> "|" t::center("go", 8) "|" ¶ // → |   go   |
```

```zymbol
<# std/time => T

நாள் = T::of(௨௦௨௬, ௧, ௩௧)
>> T::format(நாள், "%Y-%m-%d") ¶ // → 2026-01-31
>> T::format(T::add(நாள், ௧, "month"), "%Y-%m-%d") ¶ // → 2026-02-28
```

> `std/term` **காட்சி நெடுவரிசைகளை** அளவிடுகிறது, எழுத்துக்களை அல்ல: CJK மற்றும் பெரும்பாலான உணர்ச்சிக்குறிகள் 2 நெடுவரிசைகள், எனவே `t::width` உடன் ஒரு அட்டவணையை அமைக்கவும், ஒருபோதும் `$#` இல்லை.
> `std/time` இல் ஒரு கணம் ஊழியிலிருந்து மில்லி விநாடிகள். ஒரு நாளுக்குக் குறைவானது கால அளவு, ஒரு நாளிலிருந்து மேல் காலண்டர் — எனவே ஒரு மாதம் அதே நாளில் விழுகிறது, இறுக்கப்பட்டது. `வேறுபாடு(a, b)` என்பது `a - b`, எனவே முந்தைய கணத்தை முதலில் கொடுப்பது எதிர்மறை பதிலைத் தரும்.

## பொதிகள்

ஒரு `.zyp` பல-கோப்பு நிரலை ஒரு கையடக்க கோப்பில் மூட்டை கட்டுகிறது. இது **மூலத்தின்** ஒரு காப்பகம், இருமம் அல்ல, எனவே `zymbol` இருமம் இயங்கும் எல்லா இடங்களிலும் இது இயங்குகிறது.

```bash
zymbol package எனது_திட்டம்/ --script main.zy -o எனது_திட்டம்.zyp
zymbol run எனது_திட்டம்.zyp
```

> காப்பகம் ஒரு அறிக்கையை (`zyp.toml`) கொண்டுள்ளது, அது அதன் நுழைவு உரையாடல்களையும் அதற்கு தேவையான பொறி பதிப்பையும் அறிவிக்கிறது. `zymbol run` அதை ஒரு தற்காலிக கோப்பகத்திற்கு பிரித்தெடுத்து அங்கிருந்து இயக்குகிறது, எனவே குறியீடு அப்புறப்படுத்தக்கூடியது, அதே நேரத்தில் உரையாடல் எழுதுவது உங்கள் உண்மையான வேலை கோப்பகத்தில் விழுகிறது. விளையாட்டுத்திடலும் `.zyp` கோப்புகளை ஏற்றுகிறது.

## எண் பயன்முறைகள்

Zymbol எண்களை **69 யூனிகோட் இலக்க எழுத்துமுறைகளில்** எழுதலாம் — தமிழ், தேவநாகரி, அரபு-இந்திய, தாய், கிளிங்கன் pIqaD, கணித தடிமன், LCD பிரிவுகள் மற்றும் பல. பயன்முறை செயல்முறைக்கு உலகளாவியது மற்றும் வெளியீட்டை பாதிக்கிறது; கணிதம் மாறாது.

```zymbol
#௦௯#    // தமிழ்   (U+0BE6–U+0BEF)
#०९#    // தேவநாகரி   (U+0966–U+096F)
#٠٩#    // அரபு-இந்திய (U+0660–U+0669)
#09#    // ASCII க்கு மீட்டமை
```

```zymbol
a = ௪௨
>> a ¶                  // → 42
#௦௯#
>> a ¶                  // → ௪௨
>> ௩.௧௪ ¶               // → ௩.௧௪
>> #௧ ¶                 // → #௧
#09#
```

எந்த ஆதரிக்கப்பட்ட எழுத்துமுறையின் இலக்கங்களும் மூலத்தில் செல்லுபடியாகும் உண்மையெழுத்துக்கள்:

```zymbol
#௦௯#
@ i:௧..௫ { >> i " " }
>> ¶                    // → ௧ ௨ ௩ ௪ ௫
#09#
```

படிப்பது சமச்சீர் — ஒரு இலக்கம் எந்த எழுத்துமுறையிலும் புரிந்து கொள்ளப்படுகிறது:

```zymbol
>> #|"४२"| ¶            // → 42
>> #|'७'| ¶             // → 7
```

> `#` எப்போதும் ASCII, எனவே `#0` ஒவ்வொரு எழுத்துமுறையிலும் இலக்கம் பூஜ்ஜியத்திலிருந்து காட்சி ரீதியாக வேறுபட்டு இருக்கும்.
> `#,` மற்றும் `#^` தங்கள் இலக்கங்களை செயலில் உள்ள எழுத்துமுறையில் எழுதுகின்றன, மற்றும் பிரிப்பான்கள் அதைப் பின்பற்றுகின்றன — ஆனால் இந்த ஜோடி ஒருபோதும் தலைகீழாகாது: `,` குழுவாக்குகிறது மற்றும் `.` பிரிக்கிறது, ஒவ்வொரு எழுத்துமுறையிலும்.

## தரவு செயலிகள்

```zymbol
f = ##.௪௨         // மிதவைக்கு
i = ###௩.௭        // முழு எண்ணுக்கு, வட்டமிடு  → 4
t = ##!௩.௭        // முழு எண்ணுக்கு, துண்டி  → 3
>> f " " i " " t ¶      // → 42 4 3
>> f#? ¶                // → (##., 2, 42)
```

> ஒரு மிதவை இலக்கங்களாக அச்சிடப்படுகிறது, ஒருபோதும் அடுக்காக அல்ல, மேலும் இறுதி `.0` ஐ கைவிடுகிறது — `##.42` `42` ஐ எழுதுகிறது மற்றும் இன்னும் மிதவைதான், `f#?` காட்டுவது போல.

```zymbol
>> #|"42"| ¶       // → 42
>> #|"abc"| ¶      // → abc   தோல்வி-பாதுகாப்பு: உள்ளீட்டை மாற்றாமல் திருப்பித் தருகிறது
>> ##!'A' ¶        // → 65    ஒரு எழுத்தின் குறியீட்டுப் புள்ளி
```

```zymbol
pi = ௩.௧௪௧௫௯௨௬௫
>> #.௨|pi| ¶       // → 3.14          2 தசம இடங்களுக்கு வட்டமிடு
>> #!௨|pi| ¶       // → 3.14          2 தசம இடங்களுக்கு துண்டி
>> #,|௧௨௩௪௫௬௭| ¶   // → 1,234,567     ஆயிரம் பிரிப்பான்கள்
>> #^|௧௨௩௪௫.௬௭௮| ¶ // → 1.2345678e4  அறிவியல் குறியீடு
```

```zymbol
>> 0x41 ¶        // → A   பதின்அறும்புள்ளி
>> 0b01000001 ¶  // → A   இருமம்
>> 0o101 ¶       // → A   எண்மம்
>> 0d65 ¶        // → A   பதின்மம்
```

> ASCII வரம்பில் உள்ள ஒரு அடிப்படை உண்மையெழுத்து ஒரு **எழுத்து**: `0d65 == 'A'` என்பது `#1`, மற்றும் `0d65 == 65` என்பது `#0`. நான்கு அடிப்படைகளும் ஒரே எழுத்தை உச்சரிக்கின்றன.

## குறிகள் எவ்வாறு இணைகின்றன

இந்த கையேடு முழுவதும் நீங்கள் ஒரே விஷயத்தைப் பார்த்துக் கொண்டிருக்கிறீர்கள்: **ஒரு செயலி என்பது மனப்பாடம் செய்ய வேண்டிய ஒரு வரைபடம் அல்ல, அது ஒரு வரிசையில் பல குறிகள், மேலும் ஒவ்வொன்றும் அதன் பொருளைப் பங்களிக்கிறது.** இப்போது நீங்கள் அவை அனைத்தையும் அறிவீர்கள், இதோ முழுமையான மாதிரி.

முதலில் **நாம் எந்த உலகத்தில் இருக்கிறோம்** என்பது வருகிறது:

| குறி | உலகம் | நீங்கள் அதை எங்கே பார்த்தீர்கள் |
|------|-------|------------------------------|
| `$` | ஒரு தொகுப்பு | `$#` `$+` `$?` `$^-` |
| `@` | நேரம், திரும்பத் திரும்ப வரும் எது | `@!` `@>` `@~` |
| `#` | ஒரு விஷயம் *என்ன*, அதன் மதிப்பு அல்ல | `#?` `#(…)` `<#` `#>` |
| `>>` | நிரலில் இருந்து வெளியே | `>>` `>>!` `>>?` |
| `<<` | நிரலுக்குள் | `<<` `<<\|` `<<\|?` |
| `?` | கேட்பது, உறுதிப்பாடு இல்லாமல் | `?` `_?` `??` `$?` |
| `!` | வலுக்கட்டாயம், அல்லது பிழை | `@!` `$!` `!?` |

பின்னர் **அங்கு என்ன செய்யப்படுகிறது** என்பது வருகிறது: `+` சேர்க்கவும், `-` நீக்கு, `^` வரிசைப்படுத்து, `~` மாற்று, `#` எண்ணு, `|` ஒரு அலகு, `:` பெயரை பிணைக்கவும்.

மேலும் ஒருபோதும் தோல்வியடையாத இரண்டு விதிகள்:

**ஒரு குறியை இரட்டிப்பாக்குவது அதை முழுமையானதாக்குகிறது.** `?` ஒருமுறை கேட்கிறது, `??` பல வழக்குகளை சோதிக்கிறது. `$?` ஒரு மதிப்பு இருக்கிறதா என்று கேட்கிறது, `$??` அது இருக்கும் ஒவ்வொரு இடத்தையும் திருப்பித் தருகிறது. `!` ஒரு பிழையை குறிக்கிறது, `!!` கேட்காமல் அதை பரப்புகிறது.

**பயன்முறை குறி எப்போதும் கடைசியாக வருகிறது.** `?` அல்லது `!` எப்படி *எப்படி* ஒன்று செய்யப்படுகிறது — தயக்கத்துடன் அல்லது வலுக்கட்டாயமாக — என்று சொல்ல தோன்றும் போது, அவை செயலியின் கடைசி குறிகள்: `$??`, `$!!`, `<<|?`, `@!`, `##!`, `>>!`, `>>?`, `@:வெளி!`. அவற்றிற்குப் பிறகு ஒருபோதும் ஒரு செயல்பாடு இருக்காது.

இதிலிருந்து ஒரு நடைமுறை விஷயம் வருகிறது: **நீங்கள் ஒருபோதும் பார்த்திராத ஒரு கலவையானது, அதை நீங்கள் தேடுவதற்கு முன்பே அர்த்தமுள்ளதாக இருக்கிறது.** `$` தொகுப்பு, `^` வரிசை மற்றும் `-` தலைகீழ் என்றால், `$^-` இறங்கு வரிசையில் வரிசைப்படுத்துகிறது, மேலும் யாரும் உங்களுக்கு சொல்ல வேண்டியதில்லை.

முழு பட்டியலும் இப்படி வேலை செய்யாது, அதைச் சொல்வது நடிப்பதை விட நல்லது. பெரும்பாலான செயலிகள் தெளிவாக பிரிகின்றன. ஆறு பிரிகின்றன ஆனால் அவற்றின் பகுதிகளை விட அதிகமாக பொருள்படுகின்றன: `!?` `:!` `:>` `|>` `::` `$++`. மேலும் பத்து மனப்பாடம் செய்யப்பட வேண்டும், ஏனெனில் அவை முற்றிலும் பிரிவதில்லை: `¶` `><` `#1` `#0` `0x` `0b` `0o` `0d` `###` `°`.

> ஒளிபுகாவற்றை எண்ணுவது, அவை குறைவு என்று கருதுவதற்குப் பதிலாக வேண்டுமென்றே செய்யப்படுகிறது: அவை மொழியின் உண்மையான மனப்பாட செலவு. முழுமையான குறிப்பு — பட்டியல், அறிவிக்கப்பட்ட ஒத்தெழுத்துகள் மற்றும் ஒரு புதிய செயலி இருப்பதற்கு பூர்த்தி செய்ய வேண்டிய விதிகள் — மொழிபெயர்ப்பாளர் களஞ்சியத்தில் `SYMBOLS.md` இல் உள்ளது.

### v0.0.9 — தொகுப்புகள் முடிவு செய்கின்றன _(செப்டம்பர் 2026)_

- **முறிவு** அகராதி அதன் சொந்த குறியீட்டைக் கொண்டுள்ளது: `#(சாவி: மதிப்பு)`. நிர்வாண `(a: 1)` நிராகரிக்கப்படுகிறது, மேலும் `#()` காலி அகராதி — இது `()` ஆக ஒருபோதும் இருக்க முடியாது
- **முறிவு** குறியீட்டு ஒதுக்கீடு திரும்பப் பெறப்பட்டது: `தொகுப்பு[i] = v` மற்றும் அனைத்து கூட்டு வடிவங்கள். `=` ஒரு **பெயருக்கு** மதிப்பை அளிக்கிறது; ஒரு தொகுப்பின் ஒரு பகுதியை மாற்றுவது `$~` ஆகும்
- **முறிவு** சங்கிலி குறியீடு `m[i][j]` படிப்பதற்கும் எழுதுவதற்கும் நிராகரிக்கப்படுகிறது — `>` என்பது படிகளுக்கு இடையில் செல்வது
- **முறிவு** ஒரு தொகுதி அது என்ன ஏற்றுமதி செய்கிறது என்பதை அறிவிக்க வேண்டும் (**E014**); `#> { }` என்பது ஒரு தொகுதி அதன் மேற்பரப்பு காலியாக உள்ளது என்று கூறும் விதம்
- **முறிவு** ஒரு சுழற்சி குறிப்பிடி என்பது ஒரு எண்ணிக்கை அல்லது நிபந்தனை — உண்மைத்தன்மை இல்லை. `@ []` மற்றும் `@ 3.5` நிராகரிக்கப்படுகின்றன
- **சேர்க்கப்பட்டது** `##_` — அலகு உண்மையெழுத்து மற்றும் ஒரு நிரல் ஏதாவது இல்லையா என்று கேட்கும் விதம்
- **சேர்க்கப்பட்டது** `#[…]` — ஒரு தொகுப்பு அதன் உறுப்பு வகைகளின் கலவை அறிவிக்கப்பட்டுள்ளது
- **சேர்க்கப்பட்டது** `#?` நான்கு தொகுப்புகளை வேறுபடுத்துகிறது: `##]` `##[` `##)` `##(`
