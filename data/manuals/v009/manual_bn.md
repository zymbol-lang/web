## চলক ও ধ্রুবক

```zymbol
ক = ১০              // পরিবর্তনশীল চলক
PI := ৩.১৪১৫৯       // ধ্রুবক — পুনরায় নির্ধারণ রানটাইম ত্রুটি
নাম = "আলিস"
সক্রিয় = #১         // বুলিয়ান সত্য
👋 := "হ্যালো"
```

```zymbol
ক = ১০    // ১০
ক += ৫    // ১৫
ক -= ৩    // ১২
ক *= ২    // ২৪
ক /= ৩    // ৮
ক %= ৩    // ২
ক ^= ২    // ৪
ক++       // ৫
ক--       // ৪
```

`°` (ডিগ্রি চিহ্ন, U+00B0) প্রথম ব্যবহারে একটি চলককে তার নিরপেক্ষ মানে স্বয়ংক্রিয়ভাবে আরম্ভ করে:

```zymbol
সংখ্যাসমূহ = [৩, ১, ৪, ১, ৫]
@ n:সংখ্যাসমূহ {
    °মোট += n
}
>> মোট ¶              // → 14
```

> `°চলক` (উপসর্গ) লুপের উপরে নোঙর করে — ফলাফল `@`-এর পরে পঠনযোগ্য।
> `চলক°` (প্রত্যয়) লুপের ভিতরে নোঙর করে — লুপ শেষ হলে এটি মারা যায়।

যে বিবৃতিটি শুধুমাত্র একটি নাম, তা চলকটি পড়ে এবং মানটি বাতিল করে, তাই এটি সতর্ক করে:

```zymbol
গণনা = ৫
গণনা
```

কম্পাইলার এইভাবে সতর্ক করে (এর বার্তাগুলি সর্বদা ইংরেজিতে):

```text
warning: this statement does nothing: 'গণনা' is read and discarded
  = help: remove it, or use it — `>> name ¶` to print it
```

অর্থ: *«এই বিবৃতিটি কিছুই করে না: 'গণনা' পড়া হয়েছে এবং বাতিল করা হয়েছে»*।

## ডেটা টাইপ

| টাইপ | লিটেরাল | `#?` ট্যাগ | নোট |
|------|---------|------------|------|
| পূর্ণসংখ্যা | `৪২`, `-৭` | `###` | নিরাপদ পূর্ণসংখ্যা: ±(2⁵³ − 1) |
| ফ্লোট | `৩.১৪`, `১.৫e১০` | `##.` | IEEE-754 দ্বিগুণ |
| স্ট্রিং | `"পাঠ্য"` | `##"` | ইন্টারপোলেশন: `"হ্যালো {নাম}"` |
| ক্যারেক্টার | `'অ'` | `##'` | একটি ইউনিকোড গ্রাফিম |
| বুলিয়ান | `#১`, `#০` | `##?` | সংখ্যাসূচক নয় — `#১ ≠ ১` |
| অ্যারে | `[১, ২, ৩]` | `##]` | একক টাইপ, পরীক্ষিত |
| ঘোষিত মিশ্রণ | `#[১, "দুই"]` | `##[` | `[…]`-এর মতোই টাইপ, পরীক্ষিত নয় |
| টাপল | `(ক, খ)` | `##)` | অবস্থানগত, অপরিবর্তনীয় |
| অভিধান | `#(ক: ১, খ: ২)` | `##(` | চাবিযুক্ত, পরিবর্তনশীল |
| ফাংশন | নামযুক্ত ফাংশন রেফারেন্স | `##()` | প্রথম-শ্রেণি; প্রদর্শন `<funct/N>` |
| ল্যাম্বডা | `ক -> ক * ২` | `##->` | প্রথম-শ্রেণি; প্রদর্শন `<lambd/N>` |
| ইউনিট | `##_` | `##_` | অনুপস্থিতি — কোনো null নেই |

```zymbol
>> ৪২#? ¶               // → (###, 2, 42)
>> [১, ২, ৩]#? ¶        // → (##], 3, [1, 2, 3])
>> #(ক: ১)#? ¶          // → (##(, 1, #(ক: 1))
```

নিরাপদ সীমার বাইরে গেলে একটি পূর্ণসংখ্যা ধরা-যোগ্য ত্রুটি, কখনো নীরব আবরণ নয়:

```zymbol
!? {
    >> (৯০০৭১৯৯২৫৪৭৪০৯৯১ + ১) ¶
} :! ##Range {
    >> "সীমার বাইরে" ¶ // → সীমার বাইরে
}
```

`##_` হল কীভাবে একটি প্রোগ্রাম জিজ্ঞাসা করে যে কোনো কিছু অনুপস্থিত কিনা:

```zymbol
কিছুই_নয়() { }
মান = কিছুই_নয়()
>> (মান == ##_) ¶     // → #1
```

## আউটপুট ও ইনপুট

```zymbol
নাম = "আলিস"
মোট = ৩
>> "হ্যালো" ¶             // → হ্যালো
>> "ক=" নাম " খ=" মোট ¶ // → ক=আলিস খ=3
>> মোট#? ¶            // → (###, 1, 3)
```

```zymbol
<< নাম
<< "আপনার নাম লিখুন: " নাম
<< ###(৪) "বয়স: " বয়স
```

**দুটি চিহ্নের আকৃতি দেখুন।** `>>` বাইরের দিকে নির্দেশ করে: এটি প্রোগ্রাম থেকে ডেটা বের করে নেয়। `<<` ভিতরের দিকে নির্দেশ করে: এটি ডেটা প্রোগ্রামে নিয়ে আসে। সেখানে মনে রাখার কিছু নেই — তীরটি দেখায় যে তথ্যটি কোন দিকে ভ্রমণ করে, এবং সেই একই ধারণা প্রতিটি চিহ্নে ফিরে আসে যা কিছু স্থানান্তর করে।

> `¶` এবং `\\` সমতুল্য নতুন লাইন। `>>` কখনো একটি যোগ করে না।
> প্রম্পটের আগে একটি টাইপ স্পেসিফায়ার পড়ার সময় বৈধতা দেয় এবং বৈধ না হওয়া পর্যন্ত পুনরায় প্রম্পট করে:
> `##.` ফ্লোট · `##.(T,D)` দশমিক · `###(N)` পূর্ণসংখ্যা · `##"(N)` পাঠ্য · `##'` একটি ক্যারেক্টার।

একটি ফাইলের শীর্ষ স্তরে, `<~` হল প্রোগ্রামের প্রস্থান অবস্থা:

```zymbol
>> "পরীক্ষা করা হচ্ছে" ¶      // → পরীক্ষা করা হচ্ছে
<~ ০
```

## টিইউআই আদিম

ইন্টারঅ্যাকটিভ প্রোগ্রামের জন্য টার্মিনাল UI অপারেটর। বেশিরভাগের জন্য `>>| { }` ব্লক প্রয়োজন (বিকল্প স্ক্রিন + কাঁচা মোড)।

```zymbol
>>| {
    >>!
    >>~ (১, ১, ০, ১০) > "চলছে"
    @~ ১০০০
    >>~ (২, ১) > "সমাপ্ত।"
}
```

```zymbol
>>| {
    [সারি, কলাম] = >>?
    >>~ (১, ১) > "টার্মিনাল: " সারি " x " কলাম
    <<| চাবি
    >>~ (২, ১) > "চাপা: " চাবি
}
```

এখানে আপনি দেখতে পারেন কেন চিহ্নগুলি গুণিত হওয়ার পরিবর্তে সংযুক্ত হয়। আপনি ইতিমধ্যে জানেন যে `<<` ইনপুট এবং `?` প্রতিশ্রুতি ছাড়াই জিজ্ঞাসা করে। শুধুমাত্র একটি চিহ্ন নতুন:

- `|` হল **একটি একক ইউনিট**, পুরো স্ট্রিম নয়।

এতে, উভয় কীবোর্ড অপারেটর নিজেরাই পড়া যায়:

```text
<<        |             ?
ইনপুট    একক ইউনিট     প্রতিশ্রুতি ছাড়া

<<|   একটি চাবি নিন, এবং একটি না আসা পর্যন্ত অপেক্ষা করুন
<<|?  দেখুন একটি চাবি আছে কিনা, এবং না থাকলে এগিয়ে যান
```

অন্য দিকেও একই: `>>` পাঠায়, `>>!` **জোর করে** পাঠায় (পুরো স্ক্রিন পরিষ্কার করে), আর `>>?` লেখার পরিবর্তে **জিজ্ঞাসা করে** (টার্মিনাল কত বড়)। ডানদিকের চিহ্নটি মোড পরিবর্তন করে এবং এটি সর্বদা শেষে আসে।

> `>>!` স্ক্রিন পরিষ্কার করে। `>>?` `(সারি, কলাম)` ফেরত দেয়। `@~ N` N মিলিসেকেন্ড ঘুমায়।
> `<<|` একটি কীপ্রেস পড়ে (ব্লকিং); `<<|?` ব্লক না করে পোল করে (`'\0'` যদি কিছু না থাকে)।
> তীর চাবিগুলো `'↑' '↓' '←' '→'` হিসাবে ডিকোড হয়; ESC হল কোড পয়েন্ট 27।
> অবস্থানগত আউটপুট টাপল: `(সারি, কলাম, BKS, সামনে, পিছনে)` — যেকোনো স্লট কমা দিয়ে বাদ দেওয়া যায় (`>>~ (,,, ১৯৬) > "লাল"`)।
> BKS বিটমাস্ক: `1`=গাঢ়, `2`=তির্যক, `4`=আন্ডারলাইন। ANSI ২৫৬-রঙের প্যালেট (`0`=টার্মিনাল ডিফল্ট)।

## নিয়ন্ত্রণ প্রবাহ

```zymbol
ক = ৭
? ক > ১০০ {
    >> "বড়" ¶
} _? ক > ০ {
    >> "ধনাত্মক" ¶     // → ধনাত্মক
} _ {
    >> "ঋণাত্মক" ¶
}
```

এখানে দুটি নতুন চিহ্ন রয়েছে এবং তৃতীয়টি সেগুলোকে একসাথে রাখা থেকে আসে:

- `?` হল **জিজ্ঞাসা করা**: এটি একটি শর্ত খোলে।
- `_` হল **যা নির্দিষ্ট করা হয়নি**: যে শাখাটি কোনো প্রশ্ন মেলেনি তখন বাকি থাকে।
- `_?` হল পরপর দুটি: *যদি কিছু মেলেনি, আবার জিজ্ঞাসা করুন*।

এজন্যই `_?` এভাবে লেখা। এটি শেখার জন্য একটি নতুন প্রতীক নয় — এটি `_` এর পরে `?`, এবং এর অর্থ ঠিক তার দুটি অংশের অর্থ, ক্রমান্বয়ে পড়া।

> `{ }` ব্রেস এমনকি একটি বিবৃতির জন্যও **অপরিহার্য**।

## মিল (ম্যাচ)

```zymbol
স্কোর = ৮৫
গ্রেড = ?? স্কোর {
    ৯০..১০০ => 'ক'
    ৮০..৮৯  => 'খ'
    _       => 'গ'
}
>> গ্রেড ¶              // → খ
```

```zymbol
তাপমাত্রা = -৫
অবস্থা = ?? তাপমাত্রা {
    < ০  => "বরফ"
    < ২০ => "ঠান্ডা"
    _    => "গরম"
}
>> অবস্থা ¶              // → বরফ
```

আপনি ইতিমধ্যে জানেন যে `?` হল "জিজ্ঞাসা করা"। **`??` হল বারবার জিজ্ঞাসা করা**: ভাষার যেকোনো জায়গায় একটি চিহ্ন দ্বিগুণ করা, তা একবার যা করে তা কয়েকবার করা। একটি `?` একটি শর্ত পরীক্ষা করে; `??` ক্ষেত্রের একটি তালিকার বিরুদ্ধে পরীক্ষা করে।

বিকল্পগুলি `||` দিয়ে যুক্ত হয় এবং তারা প্যাটার্নের ধরন মিশ্রিত করতে পারে:

```zymbol
চাবি = 'P'
ক্রিয়া = ?? চাবি {
    'p' || 'P' => "বিরাম"
    < ০ || > ১০০ => "সীমার বাইরে"
    _ => "উপেক্ষিত"
}
>> ক্রিয়া ¶             // → বিরাম
```

## লুপ

```zymbol
@ i:১..৪  { >> i " " }
>> ¶                    // → 1 2 3 4
@ i:১..৯:২ { >> i " " }
>> ¶                    // → 1 3 5 7 9
@ i:৫..১:১ { >> i " " }
>> ¶                    // → 5 4 3 2 1
```

```zymbol
n = ১
@ n <= ৬৪ { n *= ২ }
>> n ¶                  // → 128
```

```zymbol
ফল = ["আপেল", "নাশপাতি", "আঙ্গুর"]
@ ফ:ফল { >> ফ " " }
>> ¶                    // → আপেল নাশপাতি আঙ্গুর
@ অ:"হ্যালো" { >> অ "-" }
>> ¶                    // → হ-্-য-া-ল-ো-
```

```zymbol
@ i:১..১০ {
    ? i % ২ == ০ { @> }
    ? i > ৭ { @! }
    >> i " "
}
>> ¶                    // → 1 3 5 7
```

```zymbol
গণনা = ০
@:বাহ্যিক {
    গণনা++
    ? গণনা >= ৩ { @:বাহ্যিক! }
}
>> গণনা ¶             // → 3
```

`@` হল **সময়ের** প্রতীক: যা কিছু পুনরাবৃত্তি হয় তা এর মধ্যে বাস করে। সেই সময় কাটানোর জন্য আপনি এর পাশে একটি চিহ্ন যোগ করেন:

- `@!` — `!` হল **বল**: এখনই লুপ ছেড়ে যান।
- `@>` — `>` সামনে ঠেলে দেয়: পরবর্তী পালায় যান।
- `@:বাহ্যিক!` — `:` **একটি নাম বাঁধে**, তাই এটি *বাহ্যিক* নামক লুপটি কাটে, নিকটতমটি নয়।

তিনটি অপারেটর, এবং এগুলোর কোনোটিকেই আলাদাভাবে মনে রাখতে হয়নি: এগুলো হলো `@` এবং একটি চিহ্ন যা ইতিমধ্যেই বলে যে এটি কী করে।

> **একটি স্পেসিফায়ার হল একটি গণনা বা একটি শর্ত।** একটি `পূর্ণসংখ্যা` হল একটি গণনা, একবার মূল্যায়ন করা হয় — `@ ০` বডিটি শূন্য বার চালায়। অন্য সবকিছু একটি শর্ত। কোনো সত্যতা নেই: `@ []` এবং `@ ৩.৫` প্রত্যাখ্যান করা হয়। একটি সংগ্রহ অতিক্রম করতে `@ x:আইটেম` ব্যবহার করুন; এটি গণনা করতে `@ আইটেম$#`।

## ফাংশন

```zymbol
যোগ(ক, খ) { <~ ক + খ }
>> যোগ(৩, ৪) ¶        // → 7
```

```zymbol
ফ্যাক্টোরিয়াল(n) {
    ? n <= ১ { <~ ১ }
    <~ n * ফ্যাক্টোরিয়াল(n - ১)
}
>> ফ্যাক্টোরিয়াল(৫) ¶       // → 120
```

একটি ফাংশন ফাইলের চলকগুলি মান দ্বারা পড়ে এবং ভিতরের একটি লেখা ভিতরেই থাকে:

```zymbol
সীমা = ১০০
ভিতরে(n) { <~ n < সীমা }
>> ভিতরে(৪২) ¶         // → #1
```

দুটি চিহ্ন এটি পরিবর্তন করে এবং উভয়ই **স্বাক্ষর এবং কল সাইটে** লেখা হয়:

```zymbol
বাড়ান(গণক<~) { গণক = গণক + ১ }
মোট = ০
বাড়ান(মোট<~)
>> মোট ¶              // → 1
```

> `p~` হল একটি কর্মক্ষম কপি — বডি এটি পুনরায় নির্ধারণ করতে পারে এবং কলার অপরিবর্তিত থাকে।
> `p<~` হল একটি আউটপুট প্যারামিটার — পরিবর্তনটি ফিরে যায়। চিহ্ন ছাড়া `বাড়ান(মোট)` একটি শব্দার্থিক ত্রুটি: অ্যানোটেশন এবং স্বাক্ষর পৃথক হতে পারে না।

## ল্যাম্বডা ও ক্লোজার

```zymbol
দ্বিগুণ = ক -> ক * ২
যোগফল = (ক, খ) -> ক + খ
>> দ্বিগুণ(৫) ¶          // → 10
>> যোগফল(৩, ৭) ¶          // → 10
```

```zymbol
শ্রেণীবিভাগ = ক -> {
    ? ক > ০ { <~ "ধনাত্মক" }
    _? ক < ০ { <~ "ঋণাত্মক" }
    <~ "শূন্য"
}
>> শ্রেণীবিভাগ(-৪) ¶         // → ঋণাত্মক
```

```zymbol
গুণক = ৩
তিগুণ = ক -> ক * গুণক
>> তিগুণ(৭) ¶          // → 21
```

```zymbol
যোগ_নির্মাতা(n) { <~ ক -> ক + n }
যোগ১০ = যোগ_নির্মাতা(১০)
```

একটি ল্যাম্বডা কোনো প্যারামিটার নিতে পারে না:

```zymbol
উত্তর = () -> ৪২
>> উত্তর() ¶           // → 42
```

> একটি ল্যাম্বডা ফাইলের চলকগুলি **তৈরির সময়** ক্যাপচার করে; একটি নামযুক্ত ফাংশন সেগুলি **কল করার সময়** পড়ে।

## অ্যারে

```zymbol
অ্যারে = [১, ২, ৩, ৪, ৫]
>> অ্যারে[১] ¶       // → 1   সূচীকরণ ১-ভিত্তিক
>> অ্যারে[-১] ¶      // → 5   ঋণাত্মক শেষ থেকে গণনা করে
>> অ্যারে$# ¶        // → 5   দৈর্ঘ্য
```

```zymbol
অ্যারে = [১, ২, ৩]
>> (অ্যারে$+ ৬) ¶          // → [1, 2, 3, 6]   যোগ
>> (অ্যারে$+[২] ৯৯) ¶      // → [1, 99, 2, 3]  অবস্থান 2-এ সন্নিবেশ
>> (অ্যারে$- ৩) ¶          // → [1, 2]         প্রথম উপস্থিতি মুছে ফেলুন
>> (অ্যারে$-[১]) ¶         // → [2, 3]         সূচক 1-এ মুছুন
>> (অ্যারে$[১..২]) ¶       // → [1, 2]         স্লাইস, উভয় প্রান্ত অন্তর্ভুক্ত
>> (অ্যারে$? ৩) ¶          // → #1             আছে কিনা
```

এগুলো সব `$` দিয়ে শুরু হয়, যা **সংগ্রহের** প্রতীক, এবং তার সাথে একটি চিহ্ন যা বলে যে এতে কী করা হয়: `#` কতটি, `+` যোগ, `-` মুছুন, `?` জিজ্ঞাসা করুন আছে কিনা। এবং যেমন `??`-এর সাথে, চিহ্নটি দ্বিগুণ করার অর্থ হল এটি সম্পূর্ণরূপে করা: `$?` জিজ্ঞাসা করে *কোনো* মান আছে কিনা, `$??` জিজ্ঞাসা করে *কতটি জায়গায়* এবং সেগুলো সব ফেরত দেয়।

```zymbol
অ্যারে = [৩, ১, ২]
>> (অ্যারে$^+) ¶     // → [1, 2, 3]   ঊর্ধ্বক্রম
>> (অ্যারে$^-) ¶     // → [3, 2, 1]   নিম্নক্রম
```

**ফলাফলের নিয়ম।** একটি অপারেটর, এবং চারপাশের কোড এটি দিয়ে কী করে তা নির্ধারণ করে: ব্যবহার করলে, এটি **নির্মাণ** করে এবং মূলকে অপরিবর্তিত রাখে; বাতিল করলে, এটি **পরিবর্তন** করে।

```zymbol
অ্যারে = [১, ২, ৩]
কপি = অ্যারে[২]$~ ৯৯
>> অ্যারে ¶                // → [1, 2, 3]
>> কপি ¶              // → [1, 99, 3]
অ্যারে[২]$~ ৯৯
>> অ্যারে ¶                // → [1, 99, 3]
```

> **`=` কখনো কোনো সংগ্রহে লেখে না।** `অ্যারে[২] = ৯৯` Zymbol-এর একটি রূপ নয় — `=` একটি নামকে একটি মান দেয়। একটি সংগ্রহের অংশ পরিবর্তন করা হল `$~`, প্রতিটি সংগ্রহে।

`[…]` একটি টাইপ ধারণ করে এবং পরীক্ষা করা হয়; একটি ইচ্ছাকৃত মিশ্রণ `#[…]` দিয়ে **ঘোষিত** হয়:

```zymbol
মিশ্রণ = #[১, "দুই", #১]
>> মিশ্রণ ¶             // → [1, দুই, #1]
>> ([১, ২] == #[১, ২]) ¶ // → #1
```

## বহুমাত্রিক সূচীকরণ

`>` একটি নেস্টেড কাঠামোতে নিচে নামে। বন্ধনীর একটি গ্রুপ একটি উপাদানকে ঠিকানা দেয়, যত গভীরই হোক।

```zymbol
ম = [[১,২,৩], [৪,৫,৬], [৭,৮,৯]]
>> ম[২>৩] ¶        // → 6   সারি 2, কলাম 3
>> ম[-১>-১] ¶      // → 9   শেষ সারি, শেষ কলাম
```

```zymbol
ম = [[১,২,৩], [৪,৫,৬], [৭,৮,৯]]
>> ম[১>১ ; ২>২ ; ৩>৩] ¶          // → [1, 5, 9]          সমতল: কর্ণ
>> ম[[১>১, ১>৩] ; [৩>১, ৩>৩]] ¶  // → [[1, 3], [7, 9]]   গঠিত: কোণ
```

```zymbol
ম = [[১,২,৩], [৪,৫,৬]]
>> (ম[১>২]$~ ৯৯) ¶      // → [[1, 99, 3], [4, 5, 6]]
```

> `ম[১][২]` Zymbol-এর একটি রূপ **নয়**। শৃঙ্খলিত সূচক পড়া এবং লেখা উভয়ের জন্যই প্রত্যাখ্যান করা হয় — প্রতি প্রবেশে একটি বন্ধনী গ্রুপ, এবং `>` হল যা ধাপগুলির মধ্যে যায়।

## অভিধান

নামযুক্ত ক্ষেত্র সহ একটি টাপল একটি অভিধান, এবং v0.0.9 থেকে এটি `#(…)` লেখা হয়।

```zymbol
ব্যক্তি = #(নাম: "আলিস", বয়স: ২৫)
>> ব্যক্তি.নাম ¶        // → আলিস
>> ব্যক্তি["বয়স"] ¶    // → 25
```

```zymbol
ব্যক্তি = #(নাম: "আলিস", বয়স: ২৫)
ক্ষেত্র = "নাম"
>> ব্যক্তি[ক্ষেত্র] ¶     // → আলিস
```

এটি পরিবর্তনশীল, চাবি যোগ করা যেতে পারে, এবং এটি অতিক্রম করা যেতে পারে:

```zymbol
স্টক = #(নাশপাতি: ৪)
স্টক["আপেল"]$~ ১০
@ চ:স্টক { >> চ "=" স্টক[চ] " " }
>> ¶                    // → নাশপাতি=4 আপেল=10
```

```zymbol
স্টক = #(নাশপাতি: ৪, আপেল: ১০)
@ (চ, মান):স্টক { >> চ ":" মান " " }
>> ¶                    // → নাশপাতি:4 আপেল:10
```

> `#()` হল খালি অভিধান, যা `()` হতে পারে না — এটি খালি টাপলও হতে হতো। নগ্ন `(ক: ১)` এই বার্তা সহ প্রত্যাখ্যান করা হয়: *a dictionary is written `#(…)`* — «একটি অভিধান `#(…)` লেখা হয়»।
> একটি অভিধান চাবি দ্বারা ঠিকানা দেওয়া হয়, কখনো অবস্থান দ্বারা নয়, তাই `ব্যক্তি[১]` একটি ত্রুটি।

## টাপল

টাপল হল **অপরিবর্তনীয়** ক্রমযুক্ত পাত্র যা বিভিন্ন টাইপের মান ধারণ করে।

```zymbol
বিন্দু = (১০, ২০)
>> বিন্দু[১] ¶           // → 10
উপাত্ত = (৪২, "হ্যালো", #১, ৩.১৪)
>> উপাত্ত[৩] ¶            // → #1
```

```zymbol
t = (১০, ২০, ৩০)
t২ = t[২]$~ ৯৯৯
>> t ¶                  // → (10, 20, 30)
>> t২ ¶                 // → (10, 999, 30)
```

> কোনো টাপলকে স্থানে পরিবর্তন করার যে কোনো প্রচেষ্টা একটি ত্রুটি, অপারেটর যাই হোক না কেন — অপরিবর্তনীয়তা মানের একটি বৈশিষ্ট্য, প্রতিটি `$`-এর ভিতরে কোনো ব্যতিক্রম নয়।

## ডিস্ট্রাকচারিং

```zymbol
অ্যারে = [১০, ২০, ৩০, ৪০, ৫০]
[ক, খ, গ] = অ্যারে
>> ক " " খ " " গ ¶      // → 10 20 [30, 40, 50]
```

```zymbol
অ্যারে = [১০, ২০, ৩০, ৪০, ৫০]
[প্রথম, *বাকি] = অ্যারে
>> প্রথম ¶            // → 10
>> বাকি ¶              // → [20, 30, 40, 50]
```

```zymbol
বিন্দু = (১০০, ২০০)
(ক, খ) = বিন্দু
>> ক " " খ ¶          // → 100 200
```

```zymbol
ব্যক্তি = #(নাম: "আনা", বয়স: ২৫)
#(নাম: n, বয়স: b) = ব্যক্তি
>> n " " b ¶            // → আনা 25
```

> বন্ধনীর আকৃতি টাইপযুক্ত: `[…]` একটি অ্যারে নেয়, `(…)` একটি টাপল, `#(…)` একটি অভিধান। শেষ নামটি **বাকি অংশ শোষণ** করে, তাই ডিস্ট্রাকচারিং কখনো দৈর্ঘ্যে ব্যর্থ হয় না — `(ক, খ, গ) = (১,২,৩,৪,৫)` দেয় `গ = (৩,৪,৫)`, এবং যখন কিছু বাকি থাকে না তখন `##_`।

## উচ্চ-ক্রম ফাংশন

```zymbol
সংখ্যা = [১, ২, ৩, ৪, ৫]
>> (সংখ্যা$> (ক -> ক * ২)) ¶ // → [2, 4, 6, 8, 10]
>> (সংখ্যা$| (ক -> ক % ২ == ০)) ¶ // → [2, 4]
>> (সংখ্যা$< (০, (সঞ্চয়ক, ক) -> সঞ্চয়ক + ক)) ¶ // → 15
```

```zymbol
সংখ্যা = [১, ২, ৩, ৪, ৫, ৬]
দ্বিগুণ(ক) { <~ ক * ২ }
বড়(ক) { <~ ক > ৩ }
>> (সংখ্যা$> দ্বিগুণ) ¶    // → [2, 4, 6, 8, 10, 12]
>> (সংখ্যা$| বড়) ¶    // → [4, 5, 6]
```

```zymbol
ডেটাবেস = [#(নাম: "কার্লা", বয়স: ২৮), #(নাম: "আনা", বয়স: ২৫)]
বয়স_অনুযায়ী = ডেটাবেস$^ (ক, খ -> ক.বয়স < খ.বয়স)
>> বয়স_অনুযায়ী[১].নাম ¶     // → আনা
```

> একটি নামযুক্ত ফাংশন HOF-এ **বন্ধনী ছাড়া** যায়: `সংখ্যা$> দ্বিগুণ`। `সংখ্যা$> (দ্বিগুণ)` লেখা একটি পার্স ত্রুটি, কারণ `(` একটি ল্যাম্বডা খোলে।

## ত্রুটি পরিচালনা

```zymbol
!? {
    ক = ১০ / ০
} :! ##Div {
    >> "শূন্য দ্বারা ভাগ" ¶  // → শূন্য দ্বারা ভাগ
} :! {
    >> "অন্যান্য: " _err ¶
} :> {
    >> "সর্বদা চলে" ¶        // → সর্বদা চলে
}
```

| ধরন | কখন |
|------|------|
| `##Div` | শূন্য দ্বারা ভাগ |
| `##Index` | সূচক সীমার বাইরে |
| `##Key` | অভিধানে চাবি নেই |
| `##Range` | নিরাপদ পূর্ণসংখ্যা সীমার বাইরে |
| `##Type` | টাইপ অমিল |
| `##Parse` | ডেটা পার্সিং |
| `##IO` | ফাইল / সিস্টেম |
| `##Network` | নেটওয়ার্ক ত্রুটি |
| `##DB` | ডেটাবেস |
| `##Time` | একটি তারিখ যা বিদ্যমান নেই |
| `##_` | যেকোনো ত্রুটি (সব-ধরা) |

`!` হল **ত্রুটি ও বলের** প্রতীক, এবং এটি উভয় পরিবারে একইভাবে পড়া হয়: `$!` একটি মানকে জিজ্ঞাসা করে এটি ত্রুটি কিনা; `$!!`, চিহ্নটি দ্বিগুণ হলে, জিজ্ঞাসা না করেই এটি উপরের দিকে প্রসারিত করে।

> স্ট্যান্ডার্ড লাইব্রেরির ব্যর্থতাগুলি **নরম ত্রুটি মান** হিসাবে ফিরে আসে যা আপনি `$!` দিয়ে পরীক্ষা করেন বা `!?` দিয়ে ধরে ফেলেন, বাতিল করার পরিবর্তে। `$!!` একটি কলার কাছে প্রসারিত করে।

## মডিউল

```zymbol
# ক্যালক {
    #> { যোগ, PI }

    PI := ৩.১৪১৫৯
    যোগ(ক, খ) { <~ ক + খ }
}
```

```zymbol
<# ./ক্যালক => গ

>> গ::যোগ(৫, ৩) ¶
>> গ.PI ¶
```

```zymbol
# মাইলাইব {
    #> { অভ্যন্তরীণ_যোগ => যোগফল }

    অভ্যন্তরীণ_যোগ(ক, খ) { <~ ক + খ }
}
```

দুটি মডিউল চিহ্ন আবার একই ধারণা, এখন ফাইলের ক্ষেত্রে প্রয়োগ করা হয়েছে: `#` হল **ঘোষণার** স্তর — একটি জিনিস *কী*, তার মান নয় — এবং তীরটি বলে যে কোডটি কোন দিকে ভ্রমণ করে:

```text
<#   তীর প্রবেশ করে: আমদানি করুন, অন্য ফাইল থেকে আনুন
#>   তীর বের হয়: রপ্তানি করুন, অন্যান্য ফাইলকে অফার করুন
```

একটি দিক চিহ্ন সর্বদা যে প্রান্তে এটি নির্দেশ করে সেখানে বসে। এটি একই কারণ যে কারণে `<~` বাম দিকে ফিরে যায় (ফাংশনের বাইরে) এবং `->` ডান দিকে প্রবেশ করে (ল্যাম্বডার বডিতে)।

> **একটি মডিউল ঘোষণা করে যে এটি কী রপ্তানি করে।** `#>` ব্লকটি অপরিহার্য — এটি বাদ দেওয়া **E014**, এবং `#> { }` হল কীভাবে একটি মডিউল বলে যে এর পৃষ্ঠটি খালি। `::` একটি ফাংশন কল করে, `.` একটি ধ্রুবক পড়ে। মডিউল বডিতে শুধুমাত্র আমদানি, রপ্তানি ব্লক, আক্ষরিক আরম্ভকারী এবং ফাংশন সংজ্ঞা উপস্থিত হতে পারে; যে কোনো নির্বাহযোগ্য জিনিস **E013**।

নেটিভ মডিউল, অন্যদের মতো আমদানি করা হয়:

```zymbol
<# std/math => m

>> m.PI ¶               // → 3.141592653589793
```

```zymbol
<# std/term => t

>> t::width("手番") ¶            // → 4   দুইটি গ্লিফ, চার কলাম

```

```zymbol
<# std/time => T

দিন = T::of(২০২৬, ১, ৩১)

>> T::format(T::add(দিন, ১, "month"), "%Y-%m-%d") ¶ // → 2026-02-28
```

## সংখ্যা মোড

Zymbol **৬৯টি ইউনিকোড সংখ্যা লিপিতে** সংখ্যা লিখতে পারে — দেবনাগরী, আরবি-ভারতীয়, থাই, ক্লিঙ্গন pIqaD, গাণিতিক গাঢ়, LCD সেগমেন্ট এবং আরও অনেক কিছু। মোডটি প্রক্রিয়ার জন্য বৈশ্বিক এবং আউটপুটকে প্রভাবিত করে; পাটিগণিত অপরিবর্তিত।

```zymbol
#০৯#    // বাংলা   (U+09E6–U+09EF)
#٠٩#    // আরবি-ভারতীয় (U+0660–U+0669)
#๐๙#    // থাই         (U+0E50–U+0E59)
#09#    // ASCII-তে রিসেট
```

```zymbol
ক = ৪২
>> ক ¶                  // → 42
#০৯#
>> ক ¶                  // → ৪২
>> ৩.১৪ ¶               // → ৩.১৪
>> #১ ¶                 // → #১
#09#
```

যেকোনো সমর্থিত লিপির অঙ্কগুলি সোর্সে বৈধ লিটেরাল:

```zymbol
#০৯#
@ i:১..৫ { >> i " " }
>> ¶                    // → ১ ২ ৩ ৪ ৫
#09#
```

পড়া প্রতিসম — যেকোনো লিপিতে একটি অঙ্ক বোঝা যায়:

```zymbol
>> #|"৪২"| ¶            // → 42
>> #|'৭'| ¶             // → 7
```

> `#` সর্বদা ASCII, তাই `#0` প্রতিটি লিপিতে শূন্য অঙ্ক থেকে দৃশ্যত আলাদা থাকে।
> `#,` এবং `#^` তাদের অঙ্কগুলি সক্রিয় লিপিতেও লেখে এবং বিভাজকগুলি তা অনুসরণ করে — কিন্তু যুগলটি কখনো বিপরীত হয় না: `,` গ্রুপ করে এবং `.` বিভক্ত করে, প্রতিটি লিপিতে।

## ডেটা অপারেটর

```zymbol
ফ = ##.৪২         // ফ্লোটে
প = ###৩.৭        // পূর্ণসংখ্যায়, গোল  → 4
ছ = ##!৩.৭        // পূর্ণসংখ্যায়, ছাঁটা  → 3
>> ফ " " প " " ছ ¶      // → 42 4 3
>> ফ#? ¶                // → (##., 2, 42)
```

> একটি ফ্লোট অঙ্ক হিসাবে মুদ্রিত হয়, কখনো সূচক হিসাবে নয়, এবং শেষের `.0` বাদ দেয় — `##.42` `42` লেখে এবং তা এখনও ফ্লোট, যেমন `ফ#?` দেখায়।

```zymbol
>> #|"৪২"| ¶       // → 42
>> #|"abc"| ¶      // → abc   ব্যর্থ-নিরাপদ: ইনপুট অপরিবর্তিত ফেরত দেয়
>> ##!'অ' ¶        // → 2437    একটি ক্যারেক্টারের কোড পয়েন্ট
```

```zymbol
পাই = ৩.১৪১৫৯২৬৫
>> #.২|পাই| ¶       // → 3.14          ২ দশমিক স্থানে গোল
>> #!২|পাই| ¶       // → 3.14          ২ দশমিক স্থানে ছাঁটা
>> #,|১২৩৪৫৬৭| ¶   // → 1,234,567    হাজার বিভাজক
>> #^|১২৩৪৫.৬৭৮| ¶ // → 1.2345678e4  বৈজ্ঞানিক সংকেত
```

```zymbol
>> 0x41 ¶        // → A   ষোড়শিক
>> 0b01000001 ¶  // → A   বাইনারি
>> 0o101 ¶       // → A   অক্টাল
>> 0d65 ¶        // → A   দশমিক
```

> ASCII সীমার মধ্যে একটি বেস লিটেরাল একটি **ক্যারেক্টার**: `0d65 == 'A'` হল `#1`, এবং `0d65 == 65` হল `#0`। চারটি বেসই একই ক্যারেক্টার বানান।


> `<\ … \>` stdout এবং stderr ক্যাপচার করে, শেষের নতুন লাইনটি সরিয়ে।
> `>< আর্গস` কমান্ড-লাইন আর্গুমেন্টগুলিকে স্ট্রিং অ্যারে হিসাবে ক্যাপচার করে।

## কীভাবে চিহ্নগুলি সংযুক্ত হয়

আপনি এই ম্যানুয়াল জুড়ে একই জিনিস দেখেছেন: **একটি অপারেটর মনে রাখার জন্য একটি অঙ্কন নয়, এটি একটি সারিতে একাধিক চিহ্ন, এবং প্রতিটি তার অর্থ অবদান রাখে।** এখন যেহেতু আপনি এগুলো সব জানেন, এখানে সম্পূর্ণ প্যাটার্ন।

প্রথমে আসে **আমরা কোন জগতে আছি**:

| চিহ্ন | জগত | আপনি এটি কোথায় দেখেছেন |
|------|------|-------------------------|
| `$` | একটি সংগ্রহ | `$#` `$+` `$?` `$^-` |
| `@` | সময়, যা কিছু পুনরাবৃত্তি হয় | `@!` `@>` `@~` |
| `#` | একটি জিনিস *কী*, তার মান নয় | `#?` `#(…)` `<#` `#>` |
| `>>` | প্রোগ্রামের বাইরে | `>>` `>>!` `>>?` |
| `<<` | প্রোগ্রামের ভিতরে | `<<` `<<\|` `<<\|?` |
| `?` | জিজ্ঞাসা করা, প্রতিশ্রুতি ছাড়া | `?` `_?` `??` `$?` |
| `!` | বল, বা ত্রুটি | `@!` `$!` `!?` |

তারপর আসে **সেখানে কী করা হয়**: `+` যোগ, `-` মুছুন, `^` ক্রম, `~` পরিবর্তন, `#` গণনা, `|` একটি একক ইউনিট, `:` নাম বাঁধা।

এবং দুটি নিয়ম যা কখনো ব্যর্থ হয় না:

**একটি চিহ্ন দ্বিগুণ করলে তা সম্পূর্ণ হয়।** `?` একবার জিজ্ঞাসা করে, `??` একাধিক ক্ষেত্রে পরীক্ষা করে। `$?` জিজ্ঞাসা করে একটি মান আছে কিনা, `$??` প্রতিটি স্থান ফেরত দেয় যেখানে এটি আছে। `!` একটি ত্রুটি চিহ্নিত করে, `!!` জিজ্ঞাসা না করেই তা প্রসারিত করে।

**মোড চিহ্ন সর্বদা শেষে আসে।** যখন `?` বা `!` উপস্থিত হয় *কীভাবে* কিছু করা হয় — সন্দেহজনকভাবে বা জোরপূর্বক — তারা অপারেটরের শেষ চিহ্ন: `$??`, `$!!`, `<<|?`, `@!`, `##!`, `>>!`, `>>?`, `@:বাহ্যিক!`। তাদের পরে আর কোনো অপারেশন থাকে না।

এটি থেকে একটি ব্যবহারিক বিষয় বেরিয়ে আসে: **একটি সংমিশ্রণ যা আপনি কখনও দেখেননি তা আপনি এটি খোঁজার আগেই বোঝা যায়।** যদি `$` সংগ্রহ এবং `^` ক্রম এবং `-` বিপরীত হয়, তাহলে `$^-` নিম্নক্রমে সাজায়, এবং কাউকে আপনাকে বলতে হয়নি।

পুরো তালিকাটি এভাবে কাজ করে না, এবং তা বলা ভালো। বেশিরভাগ অপারেটর পরিষ্কারভাবে বিভক্ত হয়। ছয়টি বিভক্ত হয় তবে তাদের অংশগুলির চেয়ে বেশি অর্থ বহন করে: `!?` `:!` `:>` `|>` `::` `$++`। এবং দশটি মুখস্থ করতে হয় কারণ তারা মোটেও বিভক্ত হয় না: `¶` `><` `#1` `#0` `0x` `0b` `0o` `0d` `###` `°`।

> অস্বচ্ছগুলি গণনা করা বরং সেগুলি কম বলে ধরে নেওয়া ইচ্ছাকৃত: এগুলো ভাষার প্রকৃত স্মরণ খরচ। সম্পূর্ণ রেফারেন্স — তালিকা, ঘোষিত সমোচ্চারিত শব্দ, এবং একটি নতুন অপারেটরের জন্য প্রয়োজনীয় নিয়ম — ইন্টারপ্রেটার রিপোজিটরিতে `SYMBOLS.md`-তে রয়েছে।

### v0.0.9 — সংগ্রহগুলি সিদ্ধান্ত নেয় _(সেপ্টেম্বর ২০২৬)_

- **ব্রেকিং** অভিধানের নিজস্ব স্বরলিপি রয়েছে: `#(চাবি: মান)`। নগ্ন `(ক: ১)` প্রত্যাখ্যান করা হয়, এবং `#()` হল খালি অভিধান — যা `()` কখনো হতে পারে না
- **ব্রেকিং** সূচীকৃত নির্ধারণ প্রত্যাহার করা হয়েছে: `অ্যারে[i] = মান` এবং সব যৌগিক রূপ। `=` একটি **নামকে** একটি মান দেয়; একটি সংগ্রহের অংশ পরিবর্তন করা হল `$~`
- **ব্রেকিং** শৃঙ্খলিত সূচক `ম[i][j]` পড়া এবং লেখা উভয়ের জন্যই প্রত্যাখ্যান করা হয় — `>` হল যা ধাপগুলির মধ্যে যায়
- **ব্রেকিং** একটি মডিউলকে ঘোষণা করতে হবে যে এটি কী রপ্তানি করে (**E014**); `#> { }` হল কীভাবে একটি মডিউল বলে যে এর পৃষ্ঠটি খালি
- **ব্রেকিং** একটি লুপ স্পেসিফায়ার হল একটি গণনা বা একটি শর্ত — কোনো সত্যতা নেই। `@ []` এবং `@ ৩.৫` প্রত্যাখ্যান করা হয়
- **যোগ** `##_` — ইউনিট লিটেরাল, এবং কীভাবে একটি প্রোগ্রাম জিজ্ঞাসা করে যে কোনো কিছু অনুপস্থিত কিনা
- **যোগ** `#[…]` — একটি অ্যারে যার উপাদান টাইপের মিশ্রণ ঘোষিত
- **যোগ** `#?` চারটি সংগ্রহকে আলাদা করে: `##]` `##[` `##)` `##(`
- **যোগ** `std/time` — ঘড়ি এবং নাগরিক ক্যালেন্ডার, অঞ্চল এবং ক্যালেন্ডার পাটিগণিত সহ
- **যোগ** একটি শীর্ষ-স্তরের `<~` হল প্রোগ্রামের প্রস্থান অবস্থা
- **যোগ** `@ (চ, মান):জোড়া` — লুপের শিরোনামে একটি প্যাটার্ন
- **যোগ** `#|অ|` ৬৯টি লিপির যেকোনোটিতে একটি অঙ্ক পড়ে; `#,` এবং `#^` সক্রিয় লিপিতে তাদের অঙ্ক লেখে
- **পরিবর্তন** `পূর্ণসংখ্যা` একটি নিরাপদ পূর্ণসংখ্যা, ±(2⁵³ − 1), প্রতিটি ইঞ্জিনে ব্যর্থ-বন্ধ
- **পরিবর্তন** একটি নামযুক্ত ফাংশন ফাইলের চলকগুলি কলের সময়, মান দ্বারা পড়ে
- **পরিবর্তন** একটি বিবৃতি যা শুধুমাত্র একটি নাম পড়ে, নীরবে পাস করার পরিবর্তে সতর্ক করে
- **ইঞ্জিন** 666টি কর্পাস ফাইলের মধ্যে 660টি তিনটি ইঞ্জিনে সম্মত, 0টি ভিন্ন

### v0.0.7 — নেটিভ স্ট্যান্ডার্ড লাইব্রেরি _(জুলাই ২০২৬)_

- **যোগ** `std/json`, `std/io`, `std/net`, `std/db` (ODBC) — সবগুলি নরম ত্রুটি মান সহ
- **যোগ** টাইপ/যাচাইকৃত ইনপুট: `<< ##.(৫,২) "দাম: " দাম`
- **যোগ** `>>`-এ সরাসরি পোস্টফিক্স অপারেটর — বন্ধনীর প্রয়োজন নেই
- **পরিবর্তন** ব্যর্থ-বন্ধ ফর্ম্যাটার: এটি এমন আউটপুট লেখা প্রত্যাখ্যান করে যা এটি পুনরায় পড়তে পারে না

### v0.0.6 — পরিশোধন এবং বৈজ্ঞানিক Stdlib _(জুন ২০২৬)_

- **ব্রেকিং** `=>` মিল শাখায় `:` এবং আমদানি/রপ্তানি উপনামে `<=` প্রতিস্থাপন করে
- **যোগ** `std/math` এবং `std/random`
- **যোগ** চাবি দ্বারা অভিধান আপডেট: `অভিধান["চাবি"]$~ মান`

### v0.0.5 — টিইউআই আদিম এবং গরম সংজ্ঞা _(মে ২০২৬)_

- **যোগ** TUI ব্লক `>>| { }`, অবস্থানগত আউটপুট `>>~`, চাবি ইনপুট `<<|` এবং `<<|?`
- **যোগ** `>>!` স্ক্রিন পরিষ্কার, `>>?` টার্মিনাল আকার, `@~ N` ঘুম
- **যোগ** গরম সংজ্ঞা `°ক` / `ক°`, এবং স্ট্রিং পুনরাবৃত্তি `$*`

### v0.0.4 — ১-ভিত্তিক সূচীকরণ এবং প্রথম-শ্রেণি ফাংশন _(এপ্রিল ২০২৬)_

- **ব্রেকিং** সব সূচীকরণ **১-ভিত্তিক** — `অ্যারে[১]` হল প্রথম উপাদান
- **যোগ** নামযুক্ত ফাংশন প্রথম-শ্রেণির মান হিসাবে; মডিউল ব্লক সিনট্যাক্স `# নাম { }`
- **যোগ** বহুমাত্রিক সূচীকরণ `অ্যারে[i>j>k]` এবং সমতল নিষ্কাশন `অ্যারে[p ; q]`

### v0.0.3 — ইউনিকোড সংখ্যা পদ্ধতি _(এপ্রিল ২০২৬)_

- **যোগ** ৬৯টি ইউনিকোড অঙ্ক ব্লক মোড-সুইচ টোকেন `#d0d9#` সহ
- **যোগ** যেকোনো লিপিতে বুলিয়ান লিটেরাল — `#१` / `#०`

### v0.0.2 — সংগ্রহ এপিআই পুনঃনকশা _(মার্চ ২০২৬)_

- **যোগ** অ্যারে এবং স্ট্রিংয়ের জন্য `$` অপারেটর পরিবার
- **যোগ** ডিস্ট্রাকচারিং নির্ধারণ, এবং ঋণাত্মক সূচক

### v0.0.1 — প্রাথমিক সর্বজনীন রিলিজ _(মার্চ ২০২৬)_

- REPL, LSP, VS Code এক্সটেনশন, ফর্ম্যাটার (`zymbol fmt`)
