## चर र स्थिरांकहरू

```zymbol
x = १०              // परिवर्तनशील चर
PI := ३.१४१५९       // स्थिरांक — पुनः निर्धारण रनटाइम त्रुटि हो
नाम = "अर्जुन"
सक्रिय = #१         // बुलियन सत्य
👋 := "नमस्ते"
```

```zymbol
x = १०    // १०
x += ५    // १५
x -= ३    // १२
x *= २    // २४
x /= ३    // ८
x %= ३    // २
x ^= २    // ४
x++       // ५
x--       // ४
```

`°` (डिग्री चिन्ह, U+00B0) पहिलो प्रयोगमा चरलाई यसको तटस्थ मानमा स्वचालित रूपमा सुरु गर्दछ:

```zymbol
संख्याहरू = [३, १, ४, १, ५]
@ n:संख्याहरू {
    °जम्मा += n
}
>> जम्मा ¶              // → 14
```

> `°चर` (उपसर्ग) लूपको माथि एङ्कर गर्दछ — नतिजा `@` पछि पढ्न सकिन्छ।
> `चर°` (प्रत्यय) लूपको भित्र एङ्कर गर्दछ — लूप सकिएपछि मर्दछ।

केवल नाम भएको कथनले चर पढ्छ र मान फालिदिन्छ, त्यसैले चेतावनी दिन्छ:

```zymbol
गणना = ५
गणना
```

कम्पाइलर यसरी चेतावनी दिन्छ (यसका सन्देशहरू सधैं अंग्रेजीमा हुन्छन्):

```text
warning: this statement does nothing: 'गणना' is read and discarded
  = help: remove it, or use it — `>> name ¶` to print it
```

अर्थ: *«यो कथनले केही गर्दैन: 'गणना' पढियो र फालियो»*।

## डाटा प्रकारहरू

| प्रकार | शाब्दिक | `#?` ट्याग | टिप्पणी |
|------|---------|----------|-------|
| पूर्णांक | `४२`, `-७` | `###` | सुरक्षित पूर्णांक: ±(2⁵³ − 1) |
| दशमलव | `३.१४`, `१.५e१०` | `##.` | IEEE-754 दोहोरो |
| स्ट्रिङ | `"पाठ"` | `##"` | अन्तर्निवेश: `"नमस्ते {नाम}"` |
| अक्षर | `'A'` | `##'` | एउटा युनिकोड कोड बिन्दु |
| बुलियन | `#१`, `#०` | `##?` | संख्यात्मक होइन — `#१ ≠ १` |
| एरे | `[१, २, ३]` | `##]` | एउटा प्रकार, जाँचिएको |
| घोषित मिश्रण | `#[१, "दुई"]` | `##[` | `[…]` जस्तै प्रकार, जाँच नगरिएको |
| टपल | `(a, b)` | `##)` | स्थानीय, अपरिवर्तनीय |
| शब्दकोश | `#(x: १, y: २)` | `##(` | कुञ्जी-आधारित, परिवर्तनशील |
| फंक्शन | नामित फंक्शन सन्दर्भ | `##()` | प्रथम-श्रेणी; देखाउँछ `<funct/N>` |
| ल्याम्डा | `x -> x * २` | `##->` | प्रथम-श्रेणी; देखाउँछ `<lambd/N>` |
| एकाइ | `##_` | `##_` | अनुपस्थिति — null छैन |

```zymbol
>> ४२#? ¶               // → (###, 2, 42)
>> [१, २, ३]#? ¶        // → (##], 3, [1, 2, 3])
>> #(x: १)#? ¶          // → (##(, 1, #(x: 1))
```

सुरक्षित दायराबाट बाहिर जाने पूर्णांक पक्रन सकिने त्रुटि हो, कहिल्यै मौन र्‍यापिङ होइन:

```zymbol
!? {
    >> (९००७१९९२५४७४०९९१ + १) ¶
} :! ##Range {
    >> "दायरा बाहिर" ¶ // → दायरा बाहिर
}
```

`##_` कार्यक्रमले कुनै कुरा अनुपस्थित छ कि भनी सोध्ने तरिका हो:

```zymbol
केही_छैन() { }
मान = केही_छैन()
>> (मान == ##_) ¶     // → #1
```

## आउटपुट र इनपुट

```zymbol
नाम = "अर्जुन"
जम्मा = ३
>> "नमस्ते" ¶             // → नमस्ते
>> "a=" नाम " b=" जम्मा ¶ // → a=अर्जुन b=3
>> जम्मा#? ¶            // → (###, 1, 3)
```

```zymbol
<< नाम
<< "तपाईंको नाम लेख्नुहोस्: " नाम
<< ###(४) "उमेर: " उमेर
```

**दुई चिन्हहरूको आकार हेर्नुहोस्।** `>>` बाहिरतिर औंल्याउँछ: डाटा कार्यक्रमबाट बाहिर निकाल्छ। `<<` भित्रतिर औंल्याउँछ: डाटा कार्यक्रममा भित्र ल्याउँछ। यहाँ सम्झनु पर्ने केही छैन — बाणले जानकारी कुन दिशामा यात्रा गर्छ भनी देखाउँछ, र त्यही विचार प्रत्येक चिन्हमा फर्किन्छ जसले केही सार्छ।

> `¶` र `\\` समान नयाँ लाइनहरू हुन्। `>>` कहिल्यै एउटा थप्दैन।
> प्रम्प्ट अगाडि प्रकार निर्दिष्टकर्ताले पढ्दा प्रमाणित गर्छ र मान मान्य नभएसम्म फेरि सोध्छ:
> `##.` दशमलव · `##.(T,D)` दशमलव · `###(N)` पूर्णांक · `##"(N)"` पाठ · `##'` एउटा अक्षर।

फाइलको शीर्ष स्तरमा, `<~` कार्यक्रमको निकास स्थिति हो:

```zymbol
>> "जाँच गर्दै" ¶      // → जाँच गर्दै
<~ ०
```

## TUI आदिमहरू

अन्तरक्रियात्मक कार्यक्रमहरूको लागि टर्मिनल UI अपरेटरहरू। धेरैलाई `>>| { }` ब्लक चाहिन्छ (वैकल्पिक स्क्रिन + कच्चा मोड)।

```zymbol
>>| {
    >>!
    >>~ (१, १, ०, १०) > "चलिरहेको"
    @~ १०००
    >>~ (२, १) > "सम्पन्न।"
}
```

```zymbol
>>| {
    [पङ्क्तिहरू, स्तम्भहरू] = >>?
    >>~ (१, १) > "टर्मिनल: " पङ्क्तिहरू " x " स्तम्भहरू
    <<| कुञ्जी
    >>~ (२, १) > "थिचियो: " कुञ्जी
}
```

यहाँ तपाईंले देख्न सक्नुहुन्छ किन चिन्हहरू गुणनको सट्टा संयोजन हुन्छन्। तपाईंलाई पहिले नै थाहा छ कि `<<` इनपुट हो र `?` प्रतिबद्धता बिना सोध्छ। केवल एउटा चिन्ह नयाँ छ:

- `|` **एउटा एकाइ** हो, सम्पूर्ण प्रवाह होइन।

यससँग, दुवै किबोर्ड अपरेटरहरू आफैं पढ्छन्:

```text
<<        |             ?
इनपुट     एउटा एकाइ    प्रतिबद्धता बिना

<<|   एउटा कुञ्जी लिनुहोस्, र एउटा नआउन्जेल पर्खनुहोस्
<<|?  कुञ्जी छ कि भनी हेर्नुहोस्, र छैन भने जारी राख्नुहोस्
```

अर्कोतिर पनि उही: `>>` पठाउँछ, `>>!` **जबरजस्ती** पठाउँछ (सम्पूर्ण स्क्रिन खाली गर्छ), जबकि `>>?` लेख्नुको सट्टा **सोध्छ** (टर्मिनल कति ठूलो छ)। दायाँतिरको चिन्ह मोड परिवर्तन गर्ने हो, र यो सधैं अन्तिममा आउँछ।

> `>>!` स्क्रिन खाली गर्छ। `>>?` `[पङ्क्तिहरू, स्तम्भहरू]` फर्काउँछ। `@~ N` N मिलिसेकेन्ड सुत्छ।
> `<<|` एउटा कुञ्जी थिचाइ पढ्छ (अवरोधक); `<<|?` अवरोध नगरी जाँच्छ (`'\0'` कुनै छैन भने)।
> बाण कुञ्जीहरू `'↑' '↓' '←' '→'` को रूपमा डिकोड हुन्छन्; ESC कोड बिन्दु 27 हो।
> स्थितिगत आउटपुट टपल: `(पङ्क्ति, स्तम्भ, BKS, अगाडि, पछाडि)` — कुनै पनि स्लट कमाले छोड्न सकिन्छ (`>>~ (,,, १९६) > "रातो"`)।
> BKS बिटमास्क: `1`=बोल्ड, `2`=इटालिक, `4`=रेखाङ्कित। ANSI २५६ रङ प्यालेट (`0`=टर्मिनल पूर्वनिर्धारित)।

## नियन्त्रण प्रवाह

```zymbol
x = ७
? x > १०० {
    >> "ठूलो" ¶
} _? x > ० {
    >> "सकारात्मक" ¶     // → सकारात्मक
} _ {
    >> "नकारात्मक" ¶
}
```

यहाँ दुई नयाँ चिन्हहरू छन्, र तेस्रो ती दुईलाई सँगै राख्दा आउँछ:

- `?` **सोध्नु** हो: यसले सर्त खोल्छ।
- `_` **निर्दिष्ट नगरिएको** हो: कुनै प्रश्न मिलेन भने बाँकी रहने शाखा।
- `_?` दुवै क्रमशः: *केही मिलेन भने, फेरि सोध्नुहोस्*।

यसैकारण `_?` यसरी लेखिएको छ। यो सिक्नुपर्ने नयाँ चिन्ह होइन — यो `_` पछि `?` हो, र यसले दुई भागहरूले क्रममा पढ्दा जे अर्थ दिन्छन् ठ्याक्कै त्यही अर्थ दिन्छ।

> ब्रेसहरू `{ }` एउटा कथनको लागि पनि **अनिवार्य** छन्।

## मिलान

```zymbol
अंक = ८५
श्रेणी = ?? अंक {
    ९०..१०० => 'A'
    ८०..८९  => 'B'
    _       => 'F'
}
>> श्रेणी ¶              // → B
```

```zymbol
तापक्रम = -५
अवस्था = ?? तापक्रम {
    < ०  => "बरफ"
    < २० => "चिसो"
    _    => "तातो"
}
>> अवस्था ¶              // → बरफ
```

तपाईंलाई पहिले नै थाहा छ कि `?` "सोध्नु" हो। **`??` धेरै पटक सोध्नु** हो: भाषामा जताततै एउटा चिन्ह दोब्बर गर्नु भनेको त्यो चिन्हले एक पटक गर्ने काम धेरै पटक गर्नु हो। एउटा `?` एउटा सर्त जाँच्छ; `??` धेरै घटनाहरूको सूची विरुद्ध जाँच्छ।

विकल्पहरू `||` सँग जोडिन्छन्, र तिनीहरूले ढाँचा प्रकारहरू मिसाउन सक्छन्:

```zymbol
कुञ्जी = 'P'
कार्य = ?? कुञ्जी {
    'p' || 'P' => "रोक्नुहोस्"
    < ० || > १०० => "दायरा बाहिर"
    _ => "बेवास्ता"
}
>> कार्य ¶             // → रोक्नुहोस्
```

```zymbol
@ i:१..१० {
    ? i % २ == ० { @> }
    ? i > ७ { @! }
    >> i " "
}
>> ¶                    // → 1 3 5 7
```

```zymbol
गणना = ०
@:बाहिर {
    गणना++
    ? गणना >= ३ { @:बाहिर! }
}
>> गणना ¶             // → 3
```

`@` **समय**को चिन्ह हो: दोहोरिने सबै कुरा यसमा बस्छ। त्यो समय छोटो पार्न तपाईं यसको छेउमा एउटा चिन्ह थप्नुहुन्छ:

- `@!` — `!` **बल** हो: अहिले लूप छोड्नुहोस्।
- `@>` — `>` अगाडि धकेल्छ: अर्को चक्करमा जानुहोस्।
- `@:बाहिर!` — `:` **नाम बाँध्छ**, त्यसैले यसले *बाहिर* नामको लूप काट्छ, नजिकको होइन।

तीन अपरेटरहरू, र कुनै पनि छुट्टै सम्झनु परेन: तिनीहरू `@` र एउटा चिन्ह हुन् जसले पहिले नै के गर्छ भनी भन्छ।

> **निर्दिष्टकर्ता गणना वा सर्त हो।** `पूर्णांक` एउटा गणना हो, एक पटक मूल्याङ्कन गरिन्छ — `@ ०` शरीर शून्य पटक चलाउँछ। अरू सबै सर्त हो। सत्यता छैन: `@ []` र `@ ३.५` अस्वीकार गरिन्छ। कुनै संग्रह पार गर्न `@ x:वस्तुहरू` प्रयोग गर्नुहोस्; गणना गर्न, `@ वस्तुहरू$#`।

## फंक्शनहरू

```zymbol
जोड्नु(a, b) { <~ a + b }
>> जोड्नु(३, ४) ¶        // → 7
```

```zymbol
क्रमगुणन(n) {
    ? n <= १ { <~ १ }
    <~ n * क्रमगुणन(n - १)
}
>> क्रमगुणन(५) ¶       // → 120
```

फंक्शनले फाइलका चरहरू मानद्वारा पढ्छ, र भित्रको लेखाइ भित्रै रहन्छ:

```zymbol
सीमा = १००
भित्र(n) { <~ n < सीमा }
>> भित्र(४२) ¶         // → #1
```

दुई चिन्हहरूले यसलाई परिवर्तन गर्छन्, र दुवै **हस्ताक्षर र कल साइटमा** लेखिन्छन्:

```zymbol
बढाउनु(गणना<~) { गणना = गणना + १ }
जम्मा = ०
बढाउनु(जम्मा<~)
>> जम्मा ¶              // → 1
```

> `p~` कार्य प्रतिलिपि हो — शरीरले यसलाई पुनः निर्धारण गर्न सक्छ र कल गर्ने अछुतो रहन्छ।
> `p<~` आउटपुट प्यारामिटर हो — परिवर्तन फर्किन्छ। `बढाउनु(जम्मा)` चिन्ह बिना अर्थ त्रुटि हो: एनोटेसन र हस्ताक्षर अलग हुन सक्दैनन्।

## ल्याम्डा र क्लोजरहरू

```zymbol
दोब्बर = x -> x * २
जोड = (a, b) -> a + b
```

```zymbol
वर्गीकरण = x -> {

    <~ "शून्य"
}
>> वर्गीकरण(-४) ¶         // → नकारात्मक
```

## एरेहरू

```zymbol
एरे = [१, २, ३, ४, ५]
>> एरे[१] ¶       // → 1   सूचक 1-आधारित छ
>> एरे[-१] ¶      // → 5   ऋणात्मक अन्त्यबाट गन्छ
>> एरे$# ¶        // → 5   लम्बाइ
```

```zymbol
एरे = [१, २, ३]
>> (एरे$+ ६) ¶          // → [1, 2, 3, 6]   थप्नुहोस्
>> (एरे$+[२] ९९) ¶      // → [1, 99, 2, 3]  स्थान 2 मा राख्नुहोस्
>> (एरे$- ३) ¶          // → [1, 2]         पहिलो घटना हटाउनुहोस्
>> (एरे$-[१]) ¶         // → [2, 3]         सूचक 1 मा हटाउनुहोस्
>> (एरे$[१..२]) ¶       // → [1, 2]         टुक्रा, दुवै छेउ समावेश
>> (एरे$? ३) ¶          // → #1             समावेश छ
```

सबै `$` बाट सुरु हुन्छन्, जो **संग्रह**को चिन्ह हो, र त्यसमा के गरिन्छ भनी बताउने चिन्हसँग जारी रहन्छन्: `#` कति, `+` थप्नुहोस्, `-` हटाउनुहोस्, `?` छ कि भनी सोध्नुहोस्। र `??` जस्तै, चिन्ह दोब्बर गर्नु भनेको यसलाई पूर्ण रूपमा गर्नु हो: `$?` *छ* भनी सोध्छ, `$??` *कति स्थानमा* छ भनी सोध्छ र सबै फर्काउँछ।

```zymbol
एरे = [३, १, २]
>> (एरे$^+) ¶     // → [1, 2, 3]   आरोही
>> (एरे$^-) ¶     // → [3, 2, 1]   अवरोही
```

**नतिजाको नियम।** एउटा अपरेटर, र वरपरको कोडले यससँग के गर्छ भन्नेले निर्णय गर्छ: प्रयोग गरियो भने, यसले **बनाउँछ** र मूललाई अस्पर्शित छोड्छ; फालियो भने, यसले **परिवर्तन गर्छ**।

```zymbol
एरे = [१, २, ३]
प्रतिलिपि = एरे[२]$~ ९९
>> एरे ¶                // → [1, 2, 3]
>> प्रतिलिपि ¶              // → [1, 99, 3]
एरे[२]$~ ९९
>> एरे ¶                // → [1, 99, 3]
```

> **`=` कहिल्यै संग्रहमा लेख्दैन।** `एरे[२] = ९९` Zymbol को रूप होइन — `=` ले **नाम**लाई मान दिन्छ। संग्रहको भाग परिवर्तन गर्नु `$~` हो, हरेक संग्रहमा।

`[…]` एउटा प्रकार राख्छ र जाँचिन्छ; जानाजान मिसावट `#[…]` सँग **घोषित** गरिन्छ:

```zymbol
मिसावट = #[१, "दुई", #१]
>> मिसावट ¶             // → [1, दुई, #1]
>> ([१, २] == #[१, २]) ¶ // → #1
```

## बहु-आयामी सूचकाङ्कन

`>` नेस्टेड संरचनामा तल जान्छ। एउटा कोष्ठक समूहले एउटा तत्वलाई सम्बोधन गर्छ, जति गहिरो भए पनि।

```zymbol
m = [[१,२,३], [४,५,६], [७,८,९]]
>> m[२>३] ¶        // → 6   पङ्क्ति 2, स्तम्भ 3
>> m[-१>-१] ¶      // → 9   अन्तिम पङ्क्ति, अन्तिम स्तम्भ
```

```zymbol
m = [[१,२,३], [४,५,६], [७,८,९]]
>> m[१>१ ; २>२ ; ३>३] ¶          // → [1, 5, 9]          समतल: विकर्ण
>> m[[१>१, १>३] ; [३>१, ३>३]] ¶  // → [[1, 3], [7, 9]]   संरचित: कुना
```

```zymbol
m = [[१,२,३], [४,५,६]]
>> (m[१>२]$~ ९९) ¶      // → [[1, 99, 3], [4, 5, 6]]
```

> `m[१][२]` Zymbol को रूप **होइन**। शृङ्खलाबद्ध सूचक पढ्न र लेख्न दुवैको लागि अस्वीकार गरिन्छ — प्रत्येक पहुँचको लागि एउटा कोष्ठक समूह, र `>` चरणहरू बीच जाने हो।

## शब्दकोशहरू

नामित फिल्डहरू भएको टपल एउटा शब्दकोश हो, र v0.0.9 देखि यो `#(…)` लेखिन्छ।

```zymbol
व्यक्ति = #(नाम: "अर्जुन", उमेर: २५)
>> व्यक्ति.नाम ¶        // → अर्जुन
>> व्यक्ति["उमेर"] ¶    // → 25
```

```zymbol
व्यक्ति = #(नाम: "अर्जुन", उमेर: २५)
फिल्ड = "नाम"
>> व्यक्ति[फिल्ड] ¶     // → अर्जुन
```

यो परिवर्तनशील छ, कुञ्जीहरू थप्न सकिन्छ, र यसलाई पार गर्न सकिन्छ:

```zymbol
भण्डार = #(नास्पाती: ४)
भण्डार["स्याउ"]$~ १०
@ k:भण्डार { >> k "=" भण्डार[k] " " }
>> ¶                    // → नास्पाती=4 स्याउ=10
```

```zymbol
भण्डार = #(नास्पाती: ४, स्याउ: १०)
@ (k, v):भण्डार { >> k ":" v " " }
>> ¶                    // → नास्पाती:4 स्याउ:10
```

> `#()` खाली शब्दकोश हो, जो `()` हुन सक्दैन — यो खाली टपल पनि हुनुपर्थ्यो। नाङ्गो `(x: 1)` यो सन्देशसँग अस्वीकार गरिन्छ: *a dictionary is written `#(…)`* — «शब्दकोश `#(…)` लेखिन्छ»।
> शब्दकोश कुञ्जीद्वारा सम्बोधन गरिन्छ, कहिल्यै स्थानद्वारा होइन, त्यसैले `व्यक्ति[1]` त्रुटि हो।

```zymbol
बिन्दु = (१०, २०)
```

## उच्च-क्रम फंक्शनहरू

```zymbol
संख्याहरू = [१, २, ३, ४, ५]
>> (संख्याहरू$> (x -> x * २)) ¶ // → [2, 4, 6, 8, 10]
>> (संख्याहरू$| (x -> x % २ == ०)) ¶ // → [2, 4]
>> (संख्याहरू$< (०, (सञ्चय, x) -> सञ्चय + x)) ¶ // → 15
```

```zymbol
संख्याहरू = [१, २, ३, ४, ५, ६]
दोब्बर(x) { <~ x * २ }
ठूलो(x) { <~ x > ३ }
>> (संख्याहरू$> दोब्बर) ¶    // → [2, 4, 6, 8, 10, 12]
>> (संख्याहरू$| ठूलो) ¶    // → [4, 5, 6]
```

```zymbol
आधार = [#(नाम: "कार्ला", उमेर: २८), #(नाम: "सीता", उमेर: २५)]
उमेर_अनुसार = आधार$^ (a, b -> a.उमेर < b.उमेर)
>> उमेर_अनुसार[१].नाम ¶     // → सीता
```

> नामित फंक्शन HOF मा **कोष्ठक बिना** जान्छ: `संख्याहरू$> दोब्बर`। `संख्याहरू$> (दोब्बर)` लेख्नु पार्स त्रुटि हो, किनभने `(` ले ल्याम्डा खोल्छ।

## त्रुटि व्यवस्थापन

```zymbol
!? {
    a = १० / ०
} :! ##Div {
    >> "शून्यले भाग" ¶  // → शून्यले भाग
} :! {
    >> "अन्य: " _err ¶
} :> {
    >> "सधैं चल्छ" ¶        // → सधैं चल्छ
}
```

| प्रकार | कहिले |
|------|------|
| `##Div` | शून्यले भाग |
| `##Index` | सूचक सीमा बाहिर |
| `##Key` | शब्दकोशमा कुञ्जी छैन |
| `##Range` | सुरक्षित पूर्णांक सीमा बाहिर |
| `##Type` | प्रकार बेमेल |
| `##Parse` | डाटा पार्सिङ |
| `##IO` | फाइल / प्रणाली |
| `##Network` | नेटवर्क त्रुटिहरू |
| `##DB` | डाटाबेस |
| `##Time` | अवस्थित नभएको मिति |
| `##_` | कुनै पनि त्रुटि (सबै समात्ने) |

`!` **त्रुटि र बल**को चिन्ह हो, र दुवै परिवारमा समान पढिन्छ: `$!` मानलाई त्रुटि हो कि भनी सोध्छ; `$!!`, चिन्ह दोब्बर भएपछि, नसोधी माथि फैलाउँछ।

> मानक पुस्तकालयका असफलताहरू रद्द गर्नुको सट्टा **नरम त्रुटि मानहरू** को रूपमा फर्किन्छन् जसलाई तपाईं `$!` ले जाँच्नुहुन्छ वा `!?` ले समात्नुहुन्छ। `$!!` एउटालाई कल गर्नेलाई फैलाउँछ।

## मोड्युलहरू

```zymbol
# क्याल्क {
    #> { जोड्नु, PI }

    PI := ३.१४१५९
    जोड्नु(a, b) { <~ a + b }
}
```

```zymbol
<# ./क्याल्क => क

>> क::जोड्नु(५, ३) ¶
>> क.PI ¶
```

```zymbol
# मेरो_पुस्तकालय {
    #> { भित्री_जोड्नु => जम्मा }

    भित्री_जोड्नु(a, b) { <~ a + b }
}
```

दुई मोड्युल चिन्हहरू उही विचार हुन्, अहिले फाइलहरूमा लागू गरिएको: `#` **घोषणा**को स्तर हो — कुनै वस्तु *के हो*, यसको मान होइन — र बाणले कोड कुन दिशामा जान्छ भनी बताउँछ:

```text
<#   बाण भित्र पस्छ: आयात, अर्को फाइलबाट ल्याउनुहोस्
#>   बाण बाहिर निस्कन्छ: निर्यात, अरू फाइलहरूलाई प्रस्ताव गर्नुहोस्
```

दिशा चिन्ह सधैं जुन दिशातिर औंल्याउँछ त्यही छेउमा बस्छ। `<~` बायाँ फर्किनु (फंक्शनबाट बाहिर) र `->` दायाँ पस्नु (ल्याम्डाको शरीरमा) यही कारण हो।

> **मोड्युलले निर्यात गर्ने कुरा घोषणा गर्छ।** `#>` ब्लक अनिवार्य छ — यसलाई छोड्नु **E014** हो, र `#> { }` मोड्युलले आफ्नो सतह खाली छ भनी भन्ने तरिका हो। `::` फंक्शन बोलाउँछ, `.` स्थिरांक पढ्छ। मोड्युल शरीरमा आयात, निर्यात ब्लक, शाब्दिक आरम्भकर्ता र फंक्शन परिभाषाहरू मात्र देखा पर्न सक्छन्; कुनै पनि कार्यान्वयनयोग्य कुरा **E013** हो।

## मानक पुस्तकालय

मूल मोड्युलहरू, अरू जस्तै आयात गरिन्छन्:

| मोड्युल | फंक्शनहरू |
|--------|-----------|
| `std/math` | `sqrt exp ln log pow abs ceil floor round min max sin cos tan asin acos atan atan2 sinh cosh tanh sigmoid` · `PI` `E` |
| `std/random` | `entero rango peso_f64` |
| `std/json` | `decode decode_map encode` |
| `std/io` | `read write append exists delete list mkdir` |
| `std/net` | `get post post_json head` |
| `std/db` | `connect exec query query_one tx commit rollback` … |
| `std/term` | `width pad_left pad_right center truncate` |
| `std/time` | `now today parts of format add diff` |

```zymbol
<# std/math => m

>> m::sqrt(१६.०) ¶      // → 4
>> m.PI ¶               // → 3.141592653589793
```

```zymbol
<# std/term => t

>> t::width("手番") ¶            // → 4   दुई ग्लिफ, चार स्तम्भ
>> "|" t::center("go", 8) "|" ¶ // → |   go   |
```

```zymbol
<# std/time => T

दिन = T::of(२०२६, १, ३१)
>> T::format(दिन, "%Y-%m-%d") ¶ // → 2026-01-31
>> T::format(T::add(दिन, १, "month"), "%Y-%m-%d") ¶ // → 2026-02-28
```

> `std/term` ले **प्रदर्शन स्तम्भहरू** नाप्छ, अक्षरहरू होइन: CJK र धेरै इमोजीहरू २ स्तम्भ हुन्, त्यसैले `t::width` ले तालिका राख्नुहोस्, कहिल्यै `$#` होइन।
> `std/time` मा एक क्षण युगदेखि मिलिसेकेन्ड हो। एक दिनभन्दा कम अवधि हो, एक दिनदेखि माथि पात्रो हो — त्यसैले एक महिना त्यही महिनाको दिनमा पर्छ, क्ल्याम्प गरिएको। `भिन्नता(a, b)` `a - b` हो, त्यसैले पहिलेको क्षण पहिले दिँदा ऋणात्मक जवाफ दिन्छ।

## प्याकेजहरू

`.zyp` ले बहु-फाइल कार्यक्रमलाई एउटा पोर्टेबल फाइलमा बन्डल गर्छ। यो **स्रोत**को अभिलेख हो, बाइनरी होइन, त्यसैले `zymbol` बाइनरी चल्ने जताततै चल्छ।

```bash
zymbol package मेरो_परियोजना/ --script main.zy -o मेरो_परियोजना.zyp
zymbol run मेरो_परियोजना.zyp
```

> अभिलेखले यसको प्रवेश स्क्रिप्टहरू र आवश्यक इन्जिन संस्करण घोषणा गर्ने म्यानिफेस्ट (`zyp.toml`) राख्छ। `zymbol run` ले यसलाई अस्थायी निर्देशिकामा निकाल्छ र त्यहींबाट चलाउँछ, त्यसैले कोड डिस्पोजेबल छ जबकि स्क्रिप्टले लेख्ने कुरा तपाईंको वास्तविक कार्य निर्देशिकामा पर्छ। प्लेग्राउन्डले पनि `.zyp` फाइलहरू लोड गर्छ।

## अंकीय मोडहरू

Zymbol ले संख्याहरू **६९ युनिकोड अंक लिपिहरूमा** लेख्न सक्छ — देवनागरी, अरबी-भारतीय, थाई, क्लिङ्गन pIqaD, गणित मोटो, LCD खण्डहरू र थप। मोड प्रक्रियाको लागि विश्वव्यापी छ र आउटपुटलाई असर गर्छ; अंकगणित परिवर्तन हुँदैन।

```zymbol
#०९#    // देवनागरी   (U+0966–U+096F)
#٠٩#    // अरबी-भारतीय (U+0660–U+0669)
#๐๙#    // थाई         (U+0E50–U+0E59)
#09#    // ASCII मा रिसेट
```

```zymbol
a = ४२
>> a ¶                  // → 42
#०९#
>> a ¶                  // → ४२
>> ३.१४ ¶               // → ३.१४
>> #१ ¶                 // → #१
#09#
```

कुनै पनि समर्थित लिपिका अंकहरू स्रोतमा मान्य शाब्दिक हुन्:

```zymbol
#०९#
@ i:१..५ { >> i " " }
>> ¶                    // → १ २ ३ ४ ५
#09#
```

पढाइ सममित छ — अंक कुनै पनि लिपिमा बुझिन्छ:

```zymbol
>> #|"٤٢"| ¶            // → 42
>> #|'٧'| ¶             // → 7
```

> `#` सधैं ASCII हो, त्यसैले `#0` प्रत्येक लिपिमा शून्य अंकबाट दृश्यात्मक रूपमा भिन्न रहन्छ।
> `#,` र `#^` ले पनि आफ्ना अंकहरू सक्रिय लिपिमा लेख्छन्, र विभाजकहरूले यसलाई पछ्याउँछन् — तर जोडी कहिल्यै उल्टिँदैन: `,` समूह बनाउँछ र `.` विभाजन गर्छ, प्रत्येक लिपिमा।

## डाटा अपरेटरहरू

```zymbol
f = ##.४२         // दशमलवमा
i = ###३.७        // पूर्णांकमा, गोल  → 4
t = ##!३.७        // पूर्णांकमा, काट्नु  → 3
>> f " " i " " t ¶      // → 42 4 3
>> f#? ¶                // → (##., 2, 42)
```

> दशमलव अंकहरूको रूपमा छापिन्छ, कहिल्यै घातको रूपमा होइन, र अन्तिम `.0` छोड्छ — `##.42` ले `42` लेख्छ र अझै दशमलव हो, जस्तै `f#?` ले देखाउँछ।

```zymbol
>> #|"42"| ¶       // → 42
>> #|"abc"| ¶      // → abc   असफल-सुरक्षित: इनपुटलाई अपरिवर्तित फर्काउँछ
>> ##!'A' ¶        // → 65    अक्षरको कोड बिन्दु
```

```zymbol
pi = ३.१४१५९२६५
>> #.२|pi| ¶       // → 3.14          २ दशमलव स्थानमा गोल
>> #!२|pi| ¶       // → 3.14          २ दशमलव स्थानमा काट्नु
>> #,|१२३४५६७| ¶   // → 1,234,567     हजार विभाजकहरू
>> #^|१२३४५.६७८| ¶ // → 1.2345678e4  वैज्ञानिक सङ्केत
```

```zymbol
>> 0x41 ¶        // → A   हेक्साडेसिमल
>> 0b01000001 ¶  // → A   द्विआधारी
>> 0o101 ¶       // → A   अष्टाधारी
>> 0d65 ¶        // → A   दशमलव
```

> ASCII दायरामा आधार शाब्दिक एउटा **अक्षर** हो: `0d65 == 'A'` `#1` हो, र `0d65 == 65` `#0` हो। चारै आधारहरूले उही अक्षर लेख्छन्।

## चिन्हहरू कसरी संयोजन हुन्छन्

तपाईंले यो निर्देशिकाभरि उही कुरा देख्नुभयो: **एक अपरेटर सम्झनुपर्ने चित्र होइन, यो एक पङ्क्तिमा धेरै चिन्हहरू हुन्, र प्रत्येकले आफ्नो अर्थ योगदान गर्छ।** अब तपाईंले सबै जान्नुभयो, यो पूर्ण ढाँचा हो।

पहिले आउँछ **हामी कुन संसारमा छौं**:

| चिन्ह | संसार | तपाईंले देख्नुभयो |
|--------|-------|----------------------------|
| `$` | संग्रह | `$#` `$+` `$?` `$^-` |
| `@` | समय, दोहोरिने सबै | `@!` `@>` `@~` |
| `#` | कुनै वस्तु *के हो*, यसको मान होइन | `#?` `#(…)` `<#` `#>` |
| `>>` | कार्यक्रमबाट बाहिर | `>>` `>>!` `>>?` |
| `<<` | कार्यक्रममा भित्र | `<<` `<<\|` `<<\|?` |
| `?` | सोध्नु, प्रतिबद्धता बिना | `?` `_?` `??` `$?` |
| `!` | बल, वा त्रुटि | `@!` `$!` `!?` |

त्यसपछि आउँछ **त्यहाँ के गरिन्छ**: `+` थप्नु, `-` हटाउनु, `^` क्रम, `~` परिवर्तन, `#` गणना, `|` एउटा एकाइ, `:` नाम बाँध्नु।

र दुई नियम जो कहिल्यै असफल हुँदैनन्:

**एउटा चिन्ह दोब्बर गर्नु यसलाई पूर्ण बनाउँछ।** `?` एक पटक सोध्छ, `??` धेरै घटनाहरू जाँच्छ। `$?` मान छ कि भनी सोध्छ, `$??` जहाँ छ त्यहाँ सबै फर्काउँछ। `!` त्रुटि चिन्ह लगाउँछ, `!!` नसोधी फैलाउँछ।

**मोड चिन्ह सधैं अन्तिममा आउँछ।** जब `?` वा `!` कुनै कुरा *कसरी* गरिन्छ — हिचकिचाउँदै वा जबरजस्ती — भन्न देखा पर्छ, तिनीहरू अपरेटरका अन्तिम चिन्हहरू हुन्: `$??`, `$!!`, `<<|?`, `@!`, `##!`, `>>!`, `>>?`, `@:बाहिर!`। तिनीहरू पछि कहिल्यै कुनै कार्य हुँदैन।

यसबाट एउटा व्यावहारिक कुरा निस्कन्छ: **तपाईंले कहिल्यै नदेखेको संयोजन, खोज्नु अघि नै अर्थपूर्ण हुन्छ।** यदि `$` संग्रह हो र `^` क्रम हो र `-` उल्टो हो, तब `$^-` अवरोही क्रममा मिलाउँछ, र कसैले तपाईंलाई भन्नु परेन।

सम्पूर्ण सूची यसरी काम गर्दैन, र यो भन्नु नाटक गर्नुभन्दा राम्रो हो। धेरै अपरेटरहरू सफा रूपमा छुट्टिन्छन्। छ अपरेटरहरू छुट्टिन्छन् तर तिनीहरूका भागहरूभन्दा बढी अर्थ राख्छन्: `!?` `:!` `:>` `|>` `::` `$++`। र दस अपरेटरहरू सम्झनु पर्छ किनभने तिनीहरू बिल्कुल छुट्टिँदैनन्: `¶` `><` `#1` `#0` `0x` `0b` `0o` `0d` `###` `°`।

> अस्पष्टहरूलाई कम छन् भनी अनुमान गर्नुभन्दा गन्नु जानाजान गरिएको हो: तिनीहरू भाषाको वास्तविक सम्झने लागत हुन्। पूर्ण सन्दर्भ — सूची, घोषित होमोग्राफहरू, र नयाँ अपरेटरले अवस्थित हुन पूरा गर्नुपर्ने नियमहरू — अनुवादक भण्डारमा `SYMBOLS.md` मा छ।

| `\ var` | चर नष्ट | `°x` / `x°` | तातो परिभाषा |
| `>>\|` | TUI ब्लक (वैकल्पिक स्क्रिन) | `>>~` | स्थितिगत आउटपुट |
| `>>!` | स्क्रिन खाली | `>>?` | टर्मिनल आकार सोध्नु |
| `<<\|` | अवरोधक कुञ्जी थिचाइ | `<<\|?` | गैर-अवरोधक कुञ्जी थिचाइ |
| `@~ N` | N मिलिसेकेन्ड सुत्नु | `0d` `0x` `0o` `0b` | आधार शाब्दिकहरू |

## रिलिज परिवर्तन लग

### v0.0.9 — संग्रहहरूले निर्णय गरे _(सेप्टेम्बर २०२६)_

- **ब्रेकिङ** शब्दकोशको आफ्नै सङ्केत छ: `#(कुञ्जी: मान)`। नाङ्गो `(x: 1)` अस्वीकार गरिन्छ, र `#()` खाली शब्दकोश हो — जो `()` कहिल्यै हुन सक्दैन
- **ब्रेकिङ** सूचकाङ्कित निर्धारण फिर्ता लिइयो: `एरे[i] = v` र सबै मिश्रित रूपहरू। `=` ले **नाम**लाई मान दिन्छ; संग्रहको भाग परिवर्तन गर्नु `$~` हो
- **ब्रेकिङ** शृङ्खलाबद्ध सूचक `m[i][j]` पढ्न र लेख्न दुवैको लागि अस्वीकार गरिन्छ — `>` चरणहरू बीच जान्छ
- **ब्रेकिङ** मोड्युलले निर्यात गर्ने कुरा घोषणा गर्नुपर्छ (**E014**); `#> { }` मोड्युलले आफ्नो सतह खाली छ भनी भन्ने तरिका हो
- **ब्रेकिङ** लूप निर्दिष्टकर्ता गणना वा सर्त हो — सत्यता छैन। `@ []` र `@ 3.5` अस्वीकार गरिन्छ
- **थपियो** `##_` — एकाइ शाब्दिक, र कार्यक्रमले कुनै कुरा अनुपस्थित छ कि भनी सोध्ने तरिका
- **थपियो** `#[…]` — एरे जसको तत्व प्रकारहरूको मिसावट घोषित छ
- **थपियो** `#?` चार संग्रहहरू छुट्याउँछ: `##]` `##[` `##)` `##(`
- **थपियो** `std/time` — घडी र नागरिक पात्रो, क्षेत्र र पात्रो अंकगणितसँग
- **थपियो** शीर्ष-स्तरको `<~>` कार्यक्रमको निकास स्थिति हो
- **थपियो** `@ (k, v):जोडीहरू` — लूप हेडरमा ढाँचा
- **थपियो** `#|c|` ६९ लिपिहरूमध्ये कुनैमा अंक पढ्छ; `#,` र `#^` सक्रिय लिपिमा लेख्छन्
- **परिवर्तन** `पूर्णांक` सुरक्षित पूर्णांक हो, ±(2⁵³ − 1), प्रत्येक इन्जिनमा असफल-बन्द
- **परिवर्तन** नामित फंक्शनले कल समयमा फाइलका चरहरू मानद्वारा पढ्छ
- **परिवर्तन** केवल नाम पढ्ने कथन चुपचाप पार हुनुको सट्टा चेतावनी दिन्छ
- **इन्जिनहरू** ६६६ कर्पस फाइलहरूमध्ये ६६० तीन इन्जिनहरूमा सहमत, 0 भिन्न

### v0.0.8 — स्वतः-मुक्ति, `std/term` र प्याकेजहरू _(अगस्ट २०२६)_

- **थपियो** अन्तिम प्रयोगमा स्वचालित विनाश — अदृश्य; केवल शिखर मेमोरी घटाउँछ
- **थपियो** `std/term` — टर्मिनल स्तम्भहरूमा प्रदर्शन मेट्रिक्स
- **थपियो** `अक्षर` मा `##!` — यसको युनिकोड कोड बिन्दु
- **थपियो** मिलानमा वा-ढाँचा: `'p' || 'P' => …`, कुनै पनि प्रकारका विकल्पहरू एउटा शाखामा
- **थपियो** Zymbol प्याकेजहरू (`.zyp`) — `zymbol package` / `zymbol run pkg.zyp`
- **थपियो** कल साइटमा `<~>` अनिवार्य छ जहाँ कल गरिएकोले आउटपुट प्यारामिटर घोषणा गर्छ
- **ठीक** रजिस्टर VM मा मोड्युल प्रणाली समानता

### v0.0.7 — मूल मानक पुस्तकालय _(जुलाई २०२६)_

- **थपियो** `std/json`, `std/io`, `std/net`, `std/db` (ODBC) — सबै नरम त्रुटि मानहरूसँग
- **थपियो** टाइप/प्रमाणित इनपुट: `<< ##.(5,2) "मूल्य: " p`
- **थपियो** `>>` मा सिधै पोस्टफिक्स अपरेटरहरू — कोष्ठक आवश्यक छैन
- **परिवर्तन** असफल-बन्द ढाँचाकर्ता: पुनः पढ्न नसकिने आउटपुट लेख्न अस्वीकार गर्छ

### v0.0.6 — परिष्करण र वैज्ञानिक Stdlib _(जुन २०२६)_

- **ब्रेकिङ** `=>` ले मिलान शाखाहरूमा `:` र आयात/निर्यात उपनामहरूमा `<=` प्रतिस्थापन गर्छ
- **थपियो** `std/math` र `std/random`
- **थपियो** कुञ्जीद्वारा शब्दकोश अद्यावधिक: `d["k"]$~ मान`

### v0.0.5 — TUI आदिमहरू र तातो परिभाषा _(मे २०२६)_

- **थपियो** TUI ब्लक `>>| { }`, स्थितिगत आउटपुट `>>~`, कुञ्जी इनपुट `<<|` र `<<|?`
- **थपियो** `>>!` स्क्रिन खाली, `>>?` टर्मिनल आकार, `@~ N` सुत्नु
- **थपियो** तातो परिभाषा `°x` / `x°`, र स्ट्रिङ दोहोर्याउनु `$*`

### v0.0.4 — 1-आधारित सूचकाङ्कन र प्रथम-श्रेणी फंक्शनहरू _(अप्रिल २०२६)_

- **ब्रेकिङ** सबै सूचकाङ्कन **1-आधारित** — `एरे[1]` पहिलो तत्व हो
- **थपियो** नामित फंक्शनहरू प्रथम-श्रेणी मानहरूको रूपमा; मोड्युल ब्लक सिन्ट्याक्स `# नाम { }`
- **थपियो** बहु-आयामी सूचकाङ्कन `एरे[i>j>k]` र समतल निष्कर्षण `एरे[p ; q]`

### v0.0.3 — युनिकोड अंक प्रणालीहरू _(अप्रिल २०२६)_

- **थपियो** कुनै पनि लिपिमा बुलियन शाब्दिकहरू — `#१` / `#०`
