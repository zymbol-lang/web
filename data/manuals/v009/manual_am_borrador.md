## ተለዋዋጮች እና ቋሚዎች

```zymbol
x = ፲              // ሊለወጥ የሚችል ተለዋዋጭ
PI := ፫.፲፬፩፭፱       // ቋሚ — እንደገና መስጠት የአሂድ ጊዜ ስህተት ነው
ስም = "አበበ"
ንቁ = #፩         // ቡሊያን እውነት
👋 := "ሰላም"
```

```zymbol
x = ፲    // ፲
x += ፭    // ፲፭
x -= ፫    // ፲፪
x *= ፪    // ፳፬
x /= ፫    // ፰
x %= ፫    // ፪
x ^= ፪    // ፬
x++       // ፭
x--       // ፬
```

`°` (የዲግሪ ምልክት፣ U+00B0) በመጀመሪያ አጠቃቀም ላይ አንድን ተለዋዋጭ ወደ ገለልተኛ እሴቱ በራስ-ሰር ያስጀምራል:

```zymbol
ቁጥሮች = [፫, ፩, ፬, ፩, ፭]
@ n:ቁጥሮች {
    °ድምር += n
}
>> ድምር ¶              // → ፲፬
```

> `°ተለዋዋጭ` (ቅድመ ቅጥያ) ከዑደቱ በላይ ይሰካል — ውጤቱ ከ `@` በኋላ ሊነበብ ይችላል።
> `ተለዋዋጭ°` (ድህረ ቅጥያ) በዑደቱ ውስጥ ይሰካል — ዑደቱ ሲያልቅ ይሞታል።

በስም ብቻ የሚሠራ አረፍተ ነገር ተለዋዋጩን አንብቦ እሴቱን ይጥላል፣ ስለዚህ ያስጠነቅቃል:

```zymbol
ቁጥር = ፭
ቁጥር
```

አቀናባሪው እንዲህ ያስጠነቅቃል (መልዕክቶቹ ሁልጊዜ በእንግሊዝኛ ናቸው):

## የውሂብ ዓይነቶች

| ዓይነት | ቀጥተኛ | `#?` መለያ | ማስታወሻ |
|------|---------|----------|-------|
| ኢንቲጀር | `፵፪`, `-፯` | `###` | ደረጃው የተጠበቀ ኢንቲጀር፦ ±(2⁵³ − 1) |
| ተንሳፋፊ | `፫.፲፬`, `፩.፭e፲` | `##.` | IEEE-754 ድርብ |
| ገመድ | `"ጽሑፍ"` | `##"` | ማስገቢያ፦ `"ሰላም {ስም}"` |
| ቁምፊ | `'A'` | `##'` | አንድ የዩኒኮድ ግራፊም |
| ቡሊያን | `#፩`, `#0` | `##?` | ቁጥር አይደለም — `#፩ ≠ ፩` |
| ድርድር | `[፩, ፪, ፫]` | `##]` | አንድ ዓይነት፣ ተፈትሯል |
| የተገለጸ ድብልቅ | `#[፩, "ሁለት"]` | `##[` | እንደ `[…]` ዓይነት፣ አልተፈተሸም |
| ቱፕል | `(a, b)` | `##)` | በቦታ፣ የማይለወጥ |
| መዝገብ ቃላት | `#(x: ፩, y: ፪)` | `##(` | በቁልፍ፣ ሊለወጥ የሚችል |
| ተግባር | የተሰየመ ተግባር ማጣቀሻ | `##()` | አንደኛ ደረጃ፤ ያሳያል `<funct/N>` |
| ላምዳ | `x -> x * ፪` | `##->` | አንደኛ ደረጃ፤ ያሳያል `<lambd/N>` |
| አሃድ | `##_` | `##_` | አለመኖር — null የለም |

```zymbol
>> ፵፪#? ¶               // → (###, ፪, ፵፪)
>> [፩, ፪, ፫]#? ¶        // → (##], ፫, [፩, ፪, ፫])
>> #(x: ፩)#? ¶          // → (##(, ፩, #(x: ፩))
```

ከደህንነቱ ክልል የሚወጣ ኢንቲጀር ሊያዝ የሚችል ስህተት ነው፣ በጭራሽ ጸጥ ያለ ጥቅልል አይደለም፦

```zymbol
!? {

} :! ##Range {
    >> "ከክልል ውጭ" ¶ // → ከክልል ውጭ
```

```zymbol
ስም = "አበበ"
ድምር = ፫
```

```zymbol
<< ###(፬) "ዕድሜ፦ " ዕድሜ
```

**የሁለቱን ምልክቶች ቅርጽ ተመልከት።** `>>` ወደ ውጭ ይጠቁማል፦ ውሂብን ከፕሮግራሙ ያወጣል። `<<` ወደ ውስጥ ይጠቁማል፦ ውሂብን ወደ ፕሮግራሙ ያስገባል። እዚህ ለማስታወስ ምንም የለም — ቀስቱ መረጃው የሚጓዝበትን አቅጣጫ ያሳያል፣ እና ይኼው ሃሳብ አንድን ነገር በሚያንቀሳቅስ ምልክት ሁሉ ውስጥ ይመለሳል።

> `¶` እና `\\` ተመጣጣኝ አዲስ መስመሮች ናቸው። `>>` በጭራሽ አንዱን አይጨምርም።
> ከጥያቄው በፊት ያለው የዓይነት ገላጭ በሚያነብበት ጊዜ ያረጋግጣል እና እሴቱ ትክክል እስኪሆን ድረስ እንደገና ይጠይቃል፦
> `##.` ተንሳፋፊ · `##.(T,D)` አስርዮሽ · `###(N)` ኢንቲጀር · `##"(N)"` ጽሑፍ · `##'` አንድ ቁምፊ።

በአንድ ፋይል የላይኛው ደረጃ ላይ፣ `<~` የፕሮግራሙ መውጫ ሁኔታ ነው፦

```zymbol
>> "በማረጋገጥ ላይ" ¶      // → በማረጋገጥ ላይ
<~ 0
```

## የ TUI መሠረታዊ ነገሮች

ለተግባራዊ ፕሮግራሞች የተርሚናል UI ኦፕሬተሮች። አብዛኞቹ `>>| { }` ብሎክ ይፈልጋሉ (ተለዋጭ ማያ ገጽ + ጥሬ ሁነታ)።

```zymbol
>>| {
    >>!
    >>~ (፩, ፩, 0, ፲) > "በማሄድ ላይ"
    @~ ፲፻
    >>~ (፪, ፩) > "ተጠናቅቋል።"
}
```

```zymbol
>>| {
    [ረድፎች, አምዶች] = >>?
    >>~ (፩, ፩) > "ተርሚናል፦ " ረድፎች " x " አምዶች
    <<| ቁልፍ
    >>~ (፪, ፩) > "ተጫነ፦ " ቁልፍ
}
```

እዚህ ምልክቶቹ ለምን ከመባዛት ይልቅ እንደሚዋሃዱ ማየት ትችላለህ። `<<` ግብዓት መሆኑን እና `?` ያለ ቁርጠኝነት መጠየቁን አስቀድመህ ታውቃለህ። አንድ ምልክት ብቻ ነው አዲሱ፦

- `|` **አንድ አሃድ** ነው፣ ሙሉው ፍሰት አይደለም።

በዚህም፣ ሁለቱም የቁልፍ ሰሌዳ ኦፕሬተሮች ራሳቸውን ያነባሉ፦

```text
<<        |             ?
ግብዓት     አንድ አሃድ      ያለ ቁርጠኝነት

<<|   አንድ ቁልፍ ውሰድ፣ አንዱ እስኪመጣ ድረስ ጠብቅ
<<|?  አንድ ቁልፍ እንዳለ ተመልከት፣ ከሌለም ቀጥል
```

በሌላኛው ወገንም ተመሳሳይ ነው፦ `>>` ይልካል፣ `>>!` **በኃይል** ይልካል (ሙሉውን ማያ ገጽ ያጸዳል)፣ `>>?` ግን ከመጻፍ ይልቅ **ይጠይቃል** (ተርሚናሉ ምን ያህል ትልቅ ነው)። በቀኝ በኩል ያለው ምልክት ሁነታውን የሚቀይረው ነው፣ እና ሁልጊዜ መጨረሻ ላይ ይመጣል።

> `>>!` ማያ ገጹን ያጸዳል። `>>?` `[ረድፎች, አምዶች]` ይመልሳል። `@~ N` N ሚሊሰከንድ ያንቀላፋል።
> `<<|` አንድ የቁልፍ ጫና ያነባል (የሚዘጋ)፤ `<<|?` ሳይዘጋ ይመረምራል (`'\0'` ከሌለ)።
> የቀስት ቁልፎች `'↑' '↓' '←' '→'` ተብለው ይገለበጣሉ፤ ESC የኮድ ነጥብ 27 ነው።
> በቦታ የተቀመጠ ውጤት ቱፕል፦ `(ረድፍ, አምድ, BKS, ፊት, ጀርባ)` — ማንኛውም ክፍተት በኮማ ሊተው ይችላል (`>>~ (,,, ፻፺፮) > "ቀይ"`)።
> BKS ቢት ማስክ፦ `1`=ደማቅ, `2`=ዘንበል, `4`=ከስር መስመር። ANSI 256 ቀለም ፓሌት (`0`=የተርሚናል ነባሪ)።

> `==` በጭራሽ አያስገድድም፦ `"5" == 5` `#0` ነው። ቅደም ተከተል ያስገድዳል፦ `"5" > 4` `#1` ነው፣ `"४२" > 5` እንዲሁ — በ 69 ስክሪፕቶች ውስጥ ያለ የቁጥር ጽሑፍ እንደ ቁጥር ይነጻጸራል።
> አንድ ተግባር ከራሱ ጋር ብቻ እኩል ነው፣ ከተመሳሳይ አካል ካለው ሌላ ተግባር ጋር በጭራሽ እኩል አይደለም።

እዚህ ሁለት አዲስ ምልክቶች አሉ፣ ሦስተኛው ደግሞ ሁለቱን በአንድ ላይ በማስቀመጥ ይመጣል፦

- `?` **መጠየቅ** ነው፦ አንድ ቅድመ ሁኔታ ይከፍታል።
- `_` **ያልተገለጸው** ነው፦ ምንም ጥያቄ ሳይመሳሰል ሲቀር የሚቀረው ቅርንጫፍ።
- `_?` ሁለቱም ተከታታይ፦ *ምንም ካልተመሳሰለ፣ እንደገና ጠይቅ*።

ለዚህም ነው `_?` እንዲህ የተጻፈው። አዲስ ምልክት አይደለም — `_` ተከትሎ `?` ነው፣ እና ሁለቱ ክፍሎቹ በቅደም ተከተል ሲነበቡ የሚያመለክቱትን በትክክል ያመለክታል።

> ቅንፎች `{ }` ለአንድ አረፍተ ነገርም **ግዴታ** ናቸው።

## ዑደቶች

```zymbol

    ቁጥር++
```

`@` የ **ጊዜ** ምልክት ነው፦ የሚደጋገም ሁሉ በውስጡ ይኖራል። ያንን ጊዜ ለማሳጠር ከጎኑ አንድ ምልክት ትጨምራለህ፦

- `@!` — `!` **ኃይል** ነው፦ አሁን ከዑደቱ ውጣ።
- `@>` — `>` ወደፊት ይገፋል፦ ወደ ቀጣዩ ዙር ተሸጋገር።
- `@:ውጭ!` — `:` **አንድ ስም ያስራል**፣ ስለዚህ ይህ *ውጭ* የሚባለውን ዑደት ይቆርጣል፣ በቅርብ ያለውን አይደለም።

ሦስት ኦፕሬተሮች፣ አንዳቸውም ለብቻቸው መታወስ አልነበረባቸውም፦ እነሱ `@` ሲደመር ምን እንደሚያደርግ አስቀድሞ የሚናገር ምልክት ናቸው።

> **ገላጭ ቁጥር ወይም ቅድመ ሁኔታ ነው።** `ኢንቲጀር` አንድ ቁጥር ነው፣ አንድ ጊዜ ይገመገማል — `@ 0` አካሉን ዜሮ ጊዜ ያካሂዳል። ሌላው ሁሉ ቅድመ ሁኔታ ነው። እውነተኝነት የለም፦ `@ []` እና `@ 3.5` ውድቅ ይደረጋሉ። አንድን ስብስብ ለመሻገር `@ x:ንጥሎች` ተጠቀም፤ ለመቁጠር፣ `@ ንጥሎች$#`።

```zymbol
ገደብ = ፻

```

ሁለት ምልክቶች ይህን ይለውጣሉ፣ ሁለቱም **በፊርማው እና በጥሪ ቦታው** ይጻፋሉ፦

```zymbol
ጨምር(ቁጥር<~) { ቁጥር = ቁጥር + ፩ }
ድምር = 0
ጨምር(ድምር<~)
>> ድምር ¶              // → ፩
```

> `p~` የሥራ ቅጂ ነው — አካሉ እንደገና ሊመድበው ይችላል፣ ጠሪው ግን አይጎዳም።
> `p<~` የውጤት ግቤት ነው — ለውጡ ይመለሳል። `ጨምር(ድምር)` ያለ ምልክት የትርጉም ስህተት ነው፦ ማብራሪያውና ፊርማው ሊለያዩ አይችሉም።

## ድርድሮች

```zymbol
ድርድር = [፩, ፪, ፫, ፬, ፭]
>> ድርድር[፩] ¶       // → 1   መረጃ ጠቋሚ ከ 1 ይጀምራል
>> ድርድር[-፩] ¶      // → 5   አሉታዊ ከመጨረሻ ይቆጥራል
>> ድርድር$# ¶        // → 5   ርዝመት
```

```zymbol
ድርድር = [፩, ፪, ፫]
>> (ድርድር$+ ፮) ¶          // → [1, 2, 3, 6]   ጨምር
>> (ድርድር$+[፪] ፺፱) ¶      // → [1, 99, 2, 3]  በቦታ 2 አስገባ
>> (ድርድር$- ፫) ¶          // → [1, 2]         የመጀመሪያውን አጥፋ
>> (ድርድር$-[፩]) ¶         // → [2, 3]         በመረጃ ጠቋሚ 1 አጥፋ
>> (ድርድር$[፩..፪]) ¶       // → [1, 2]         ቁራጭ፣ ሁለቱም ጫፎች ተካተዋል
>> (ድርድር$? ፫) ¶          // → #1             ይዟል
```

ሁሉም በ `$` ይጀምራሉ፣ እሱም የ **ስብስብ** ምልክት ነው፣ እና በውስጡ ምን እንደሚደረግ በሚናገር ምልክት ይቀጥላሉ፦ `#` ስንት፣ `+` ጨምር፣ `-` አጥፋ፣ `?` እንዳለ ጠይቅ። እና እንደ `??`፣ ምልክትን ማንባት ማለት በተሟላ ሁኔታ ማድረግ ነው፦ `$?` *እንዳለ* ይጠይቃል፣ `$??` *በስንት ቦታ* እንዳለ ጠይቆ ሁሉንም ይመልሳል።

```zymbol
ድርድር = [፫, ፩, ፪]
>> (ድርድር$^+) ¶     // → [1, 2, 3]   ወደ ላይ
>> (ድርድር$^-) ¶     // → [3, 2, 1]   ወደ ታች
```

**የውጤቱ ሕግ።** አንድ ኦፕሬተር፣ በዙሪያው ያለው ኮድ በእሱ ላይ የሚያደርገው ይወስናል፦ ከተጠቀመ **ይገነባል** እና ዋናውን እንዳለ ይተዋል፤ ከተጣለ **ይለውጣል**።

```zymbol
ድርድር = [፩, ፪, ፫]
ቅጂ = ድርድር[፪]$~ ፺፱
>> ድርድር ¶                // → [1, 2, 3]
>> ቅጂ ¶              // → [1, 99, 3]
ድርድር[፪]$~ ፺፱
>> ድርድር ¶                // → [1, 99, 3]
```

> **`=` በጭራሽ ወደ ስብስብ አይጽፍም።** `ድርድር[፪] = ፺፱` የ Zymbol ቅርጽ አይደለም — `=` **ለስም** እሴት ይሰጣል። የአንድን ስብስብ ክፍል መለወጥ `$~` ነው፣ በሁሉም ስብስብ።

`[…]` አንድ ዓይነት ይይዛል እና ይፈተሻል፤ ሆን ተብሎ የተደባለቀ **በ `#[…]` ይገለጻል**፦

```zymbol
ድብልቅ = #[፩, "ሁለት", #፩]
>> ድብልቅ ¶             // → [1, ሁለት, #1]
>> ([፩, ፪] == #[፩, ፪]) ¶ // → #1
```

## ብዙ-ልኬት መረጃ ጠቋሚ

`>` ወደ ጎጆ አወቃቀር ውስጥ ይወርዳል። አንድ የቅንፍ ቡድን አንድን ክፍል ይጠቁማል፣ ምንም ያህል ጥልቅ ቢሆን።

```zymbol
m = [[፩,፪,፫], [፬,፭,፮], [፯,፰,፱]]
>> m[፪>፫] ¶        // → 6   ረድፍ 2፣ አምድ 3
>> m[-፩>-፩] ¶      // → 9   የመጨረሻ ረድፍ፣ የመጨረሻ አምድ
```

```zymbol
m = [[፩,፪,፫], [፬,፭,፮], [፯,፰,፱]]
>> m[፩>፩ ; ፪>፪ ; ፫>፫] ¶          // → [1, 5, 9]          ጠፍጣፋ፦ ዲያጎናል
>> m[[፩>፩, ፩>፫] ; [፫>፩, ፫>፫]] ¶  // → [[1, 3], [7, 9]]   አወቃቀራዊ፦ ማዕዘኖች
```

```zymbol
m = [[፩,፪,፫], [፬,፭,፮]]
>> (m[፩>፪]$~ ፺፱) ¶      // → [[1, 99, 3], [4, 5, 6]]
```

> `m[፩][፪]` የ Zymbol ቅርጽ **አይደለም**። ተከታታይ መረጃ ጠቋሚ ለማንበብም ለመጻፍም ውድቅ ይደረጋል — ለአንድ መዳረሻ አንድ የቅንፍ ቡድን፣ እና `>` በደረጃዎች መካከል የሚሄደው ነው።

## መዝገብ ቃላት

የተሰየሙ መስኮች ያሉት ቱፕል መዝገብ ቃላት ነው፣ ከ v0.0.9 ጀምሮም `#(…)` ተብሎ ይጻፋል።

```zymbol
ሰው = #(ስም: "አበበ", ዕድሜ: ፳፭)
>> ሰው.ስም ¶        // → አበበ
>> ሰው["ዕድሜ"] ¶    // → 25
```

```zymbol
ሰው = #(ስም: "አበበ", ዕድሜ: ፳፭)
መስክ = "ስም"
>> ሰው[መስክ] ¶     // → አበበ
```

ሊለወጥ ይችላል፣ ቁልፎች ሊጨመሩ ይችላሉ፣ እና ሊሻገር ይችላል፦

```zymbol
ክምችት = #(ፕሪ: ፬)
ክምችት["ፖም"]$~ ፲
@ k:ክምችት { >> k "=" ክምችት[k] " " }
>> ¶                    // → ፕሪ=4 ፖም=10
```

```zymbol
ክምችት = #(ፕሪ: ፬, ፖም: ፲)
@ (k, v):ክምችት { >> k ":" v " " }
>> ¶                    // → ፕሪ:4 ፖም:10
```

> `#()` ባዶ መዝገብ ቃላት ነው፣ `()` መሆን የማይችለው — ባዶ ቱፕልም መሆን ነበረበት። ባዶ `(x: 1)` በዚህ መልዕክት ውድቅ ይደረጋል፦ *a dictionary is written `#(…)`* — «መዝገብ ቃላት `#(…)` ተብሎ ይጻፋል»።
> መዝገብ ቃላት በቁልፍ ይጠቀሳል፣ በቦታ በጭራሽ፣ ስለዚህ `ሰው[1]` ስህተት ነው።

## ከፍተኛ-ደረጃ ተግባሮች

## ሞጁሎች

```zymbol
# ማስያ {
    #> { ደምር, PI }

    PI := ፫.፲፬፩፭፱
    ደምር(a, b) { <~ a + b }
}
```

```zymbol
<# ./ማስያ => ማ

>> ማ::ደምር(፭, ፫) ¶
>> ማ.PI ¶
```

```zymbol
# የእኔ_ቤተ_መጻሕፍት {
    #> { ውስጣዊ_ደምር => ድምር }

    ውስጣዊ_ደምር(a, b) { <~ a + b }
}
```

ሁለቱ የሞጁል ምልክቶች ተመሳሳይ ሃሳብ ናቸው፣ አሁን በፋይሎች ላይ ተተግብረዋል፦ `#` የ **ማወጃ** ደረጃ ነው — አንድ ነገር *ምን እንደሆነ*፣ እሴቱ ሳይሆን — ቀስቱ ደግሞ ኮዱ የሚጓዝበትን አቅጣጫ ይናገራል፦

```text
<#   ቀስት ይገባል፦ አስመጣ፣ ከሌላ ፋይል አምጣ
#>   ቀስት ይወጣል፦ ላክ፣ ለሌሎች ፋይሎች አቅርብ
```

የአቅጣጫ ምልክት ሁልጊዜ የሚጠቁምበትን አቅጣጫ በሚያይ ጠርዝ ላይ ይቀመጣል። `<~` ወደ ግራ የሚመለስበት (ከተግባሩ ውጭ) እና `->` ወደ ቀኝ የሚገባበት (ወደ ላምዳው አካል) ተመሳሳይ ምክንያት ነው።

> **ሞጁል የሚልከውን ያውጃል።** `#>` ብሎክ ግዴታ ነው — መተው **E014** ነው፣ `#> { }` ደግሞ ሞጁሉ ገጹ ባዶ መሆኑን የሚናገርበት መንገድ ነው። `::` አንድን ተግባር ይጠራል፣ `.` አንድን ቋሚ ያነባል። በሞጁል አካል ውስጥ የሚታዩት አስመጣዎች፣ የመላኪያ ብሎክ፣ ቃል በቃል ጀማሪዎች እና የተግባር ትርጓሜዎች ብቻ ናቸው፤ ሊካሄድ የሚችል ማንኛውም ነገር **E013** ነው።


```zymbol
>> #|"42"| ¶       // → 42
>> #|"abc"| ¶      // → abc   ደህንነቱ የተጠበቀ፦ ግብዓቱን ሳይለውጥ ይመልሳል
```

## ምልክቶች እንዴት እንደሚዋሃዱ

በዚህ መመሪያ ሙሉ ተመሳሳይ ነገር አየህ፦ **ኦፕሬተር ለማስታወስ ስዕል አይደለም፣ በአንድ ረድፍ ውስጥ በርካታ ምልክቶች ናቸው፣ እያንዳንዱም ትርጉሙን ያበረክታል።** አሁን ሁሉንም ስለምታውቅ፣ ሙሉው ንድፍ ይኸው።

|--------|-------|----------------------------|
