# دليل Zymbol-Lang

> **تم المراجعة للإصدار v0.0.9 — 2026-09-07**

**Zymbol-Lang** هي لغة برمجة رمزية. لا توجد كلمات في قواعدها — كل تركيب هو رمز. تعمل بشكل متماثل في أي لغة بشرية.

- لا يوجد `if`، `while`، `return` — فقط `?`، `@`، `<~`
- يونيكود كامل — معرفات في أي لغة أو إيموجي
- محايدة للغة البشرية — الكود نفسه في كل مكان

**إصدار المُفسِّر**: v0.0.9 | **تغطية الاختبارات**: 660/666 (ثلاثة محركات متفق عليها، 0 اختلاف)

## المتغيرات والثوابت

```zymbol
س = ١٠              // متغير قابل للتغيير
PI := ٣.١٤١٥٩       // ثابت — إعادة التعيين خطأ في وقت التشغيل
اسم = "ليلى"
نشط = #١           // قيمة منطقية صحيحة
👋 := "مرحباً"
```

```zymbol
س = ١٠    // ١٠
س += ٥    // ١٥
س -= ٣    // ١٢
س *= ٢    // ٢٤
س /= ٣    // ٨
س %= ٣    // ٢
س ^= ٢    // ٤
س++       // ٥
س--       // ٤
```

`°` (علامة الدرجة، U+00B0) تُهيئ المتغير تلقائياً إلى قيمته المحايدة عند أول استخدام:

```zymbol
أرقام = [٣, ١, ٤, ١, ٥]
@ ن:أرقام {
    °إجمالي += ن
}
>> إجمالي ¶              // → 14
```

> `°متغير` (بادئة) يثبت فوق الحلقة — النتيجة قابلة للقراءة بعد `@`.
> `متغير°` (لاحقة) يثبت داخل الحلقة — يموت عندما تنتهي الحلقة.

العبارة التي هي مجرد اسم تقرأ المتغير وتتجاهل القيمة، لذا تُحذّر:

```zymbol
عدد = ٥
عدد
```

يُصدر المُترجم التحذير التالي (رسائله دائماً بالإنكليزية):

```text
warning: this statement does nothing: 'عدد' is read and discarded
  = help: remove it, or use it — `>> name ¶` to print it
```

أي: *«هذه العبارة لا تفعل شيئاً: تمت قراءة 'عدد' وتجاهلها»*.

## أنواع البيانات

| النوع | القيمة الحرفية | وسم `#?` | ملاحظات |
|------|---------|----------|---------|
| عدد صحيح | `٤٢`, `-٧` | `###` | عدد صحيح آمن: ±(2⁵³ − 1) |
| عدد عشري | `٣.١٤`, `١.٥e١٠` | `##.` | دقة مزدوجة IEEE-754 |
| سلسلة نصية | `"نص"` | `##"` | استيفاء: `"مرحباً {اسم}"` |
| حرف | `'أ'` | `##'` | مقطع يونيكود واحد |
| منطقي | `#١`, `#٠` | `##?` | ليس رقمياً — `#١ ≠ ١` |
| مصفوفة | `[١, ٢, ٣]` | `##]` | نوع واحد، مُفحص |
| مزيج مُصرَّح | `#[١, "اثنان"]` | `##[` | نفس نوع `[…]`، غير مُفحص |
| صف | `(أ, ب)` | `##)` | موضعي، غير قابل للتغيير |
| قاموس | `#(أ: ١, ب: ٢)` | `##(` | مفتاحي، قابل للتغيير |
| دالة | مرجع دالة مسماة | `##()` | مواطن من الدرجة الأولى; يُعرض `<funct/N>` |
| لامدا | `أ -> أ * ٢` | `##->` | مواطن من الدرجة الأولى; يُعرض `<lambd/N>` |
| وحدة | `##_` | `##_` | غياب — لا يوجد null |

```zymbol
>> ٤٢#? ¶               // → (###, 2, 42)
>> [١, ٢, ٣]#? ¶        // → (##], 3, [1, 2, 3])
>> #(أ: ١)#? ¶          // → (##(, 1, #(أ: 1))
```

العدد الصحيح الذي يخرج عن النطاق الآمن هو خطأ قابل للالتقاط، وليس التفافاً صامتاً أبداً:

```zymbol
!? {
    >> (٩٠٠٧١٩٩٢٥٤٧٤٠٩٩١ + ١) ¶
} :! ##Range {
    >> "خارج النطاق" ¶ // → خارج النطاق
}
```

`##_` هي الطريقة التي يسأل بها البرنامج عما إذا كان شيء ما غائباً:

```zymbol
لا_شيء() { }
قيمة = لا_شيء()
>> (قيمة == ##_) ¶     // → #1
```

## الإخراج والإدخال

```zymbol
اسم = "ليلى"
إجمالي = ٣
>> "مرحباً" ¶             // → مرحباً
>> "أ=" اسم " ب=" إجمالي ¶ // → أ=ليلى ب=3
>> إجمالي#? ¶            // → (###, 1, 3)
```

```zymbol
<< اسم
<< "أدخل اسمك: " اسم
<< ###(٤) "العمر: " عمر
```

**انظر إلى شكل الرمزين.** `>>` يشير إلى الخارج: يأخذ البيانات خارج البرنامج. `<<` يشير إلى الداخل: يُدخل البيانات إلى البرنامج. لا يوجد شيء لحفظه هنا — السهم يُظهر الاتجاه الذي تنتقل فيه المعلومات، وتعود الفكرة نفسها في كل رمز ينقل شيئاً.

> `¶` و `\\` هما سطران جديدان متكافئان. `>>` لا يضيف أبداً واحداً.
> محدد النوع قبل المطالبة يتحقق أثناء القراءة ويعيد المطالبة حتى يصبح صالحاً:
> `##.` عدد عشري · `##.(T,D)` عدد عشري · `###(N)` عدد صحيح · `##"(N)` نص · `##'` حرف واحد.

في المستوى الأعلى من الملف، `<~` هي حالة خروج البرنامج:

```zymbol
>> "جاري التحقق" ¶      // → جاري التحقق
<~ ٠
```

## أوليات واجهة الطرفية (TUI)

عوامل تشغيل واجهة الطرفية للبرامج التفاعلية. تتطلب معظمها كتلة `>>| { }` (شاشة بديلة + وضع خام).

```zymbol
>>| {
    >>!
    >>~ (١, ١, ٠, ١٠) > "جاري التنفيذ"
    @~ ١٠٠٠
    >>~ (٢, ١) > "تم."
}
```

```zymbol
>>| {
    [صفوف, أعمدة] = >>?
    >>~ (١, ١) > "الطرفية: " صفوف " x " أعمدة
    <<| مفتاح
    >>~ (٢, ١) > "ضغطت: " مفتاح
}
```

هنا يمكنك أن ترى لماذا تتحد الرموز بدلاً من أن تتضاعف. أنت تعرف بالفعل أن `<<` هو إدخال و `?` يسأل دون التزام. رمز واحد فقط جديد:

- `|` هو **وحدة واحدة**، وليس التدفق بأكمله.

بذلك، يقرأ عاملا لوحة المفاتيح أنفسهما:

```text
<<        |             ?
إدخال     وحدة واحدة    دون التزام

<<|   خذ مفتاحاً واحداً، وانتظر حتى يتوفر
<<|?  انظر ما إذا كان هناك مفتاح، وتابع إذا لم يكن هناك
```

نفس الشيء على الجانب الآخر: `>>` يُخرج، و `>>!` يُخرج **بقوة** (يمسح الشاشة بأكملها)، بينما `>>?` **يسأل** بدلاً من الكتابة (ما هو حجم الطرفية). الرمز الموجود على اليمين هو الذي يغير الوضع، وهو دائماً في النهاية.

> `>>!` يمسح الشاشة. `>>?` يُرجع `(صفوف, أعمدة)`. `@~ ن` ينام ن ميلي ثانية.
> `<<|` يقرأ ضغطة مفتاح واحدة (محظور); `<<|?` يستقصي دون حظر (`'\0'` إذا لم يكن هناك).
> تصل مفاتيح الأسهم مفكوكة كـ `'↑' '↓' '←' '→'`; ESC هي نقطة الكود 27.
> صف الإخراج الموضعي: `(صف, عمود, BKS, أمامي, خلفي)` — يمكن حذف أي خانة بفاصلة (`>>~ (,,, ١٩٦) > "أحمر"`).
> قناع BKS: `1`=غامق, `2`=مائل, `4`=مسطر. لوحة ANSI 256 لوناً (`0`=افتراضي الطرفية).

## العوامل

```zymbol
أ = ١٠
ب = ٣
ن١ = أ + ب    // ١٣
ن٢ = أ - ب    // ٧
ن٣ = أ * ب    // ٣٠
ن٤ = أ / ب    // ٣  (قسمة صحيحة)
ن٥ = أ % ب    // ١
ن٦ = أ ^ ب    // ١٠٠٠
```

```zymbol
أ = ١٠
ب = ٣
م١ = أ == ب    // #٠
م٢ = أ <> ب    // #١
م٣ = أ < ب     // #٠
م٤ = أ >= ب    // #١
ل١ = #١ && #٠  // #٠
ل٢ = !#١       // #٠
```

> `==` لا يجبر أبداً: `"٥" == ٥` هي `#٠`. الترتيب يجبر: `"٥" > ٤` هي `#١`، وكذلك `"४२" > ٥` — النص الرقمي في أي من الخطوط الـ 69 يُقارن كرقم.
> الدالة تساوي نفسها فقط، ولا تساوي أبداً دالة أخرى بنفس النص.

```zymbol
اسم = "ليلى"
ن = ٤٢
>> "مرحباً " اسم " لديك " ن ¶ // → مرحباً ليلى لديك 42
وصف = "مرحباً {اسم}، لديك {ن}"
>> وصف ¶              // → مرحباً ليلى، لديك 42
```

```zymbol
س = "مرحباً يا عالم"
طول = س$#                  // ١١
جزء = س$[١..٥]             // "مرحباً"
يحتوي = س$? "عالم"          // #١
```

## تدفق التحكم

```zymbol
س = ٧
? س > ١٠٠ {
    >> "كبير" ¶
} _? س > ٠ {
    >> "موجب" ¶     // → موجب
} _ {
    >> "سالب" ¶
}
```

هنا رمزان جديدان، وثالث يأتي من وضعهما معاً:

- `?` هو **السؤال**: يفتح شرطاً.
- `_` هو **ما لم يُحدد**: الفرع المتبقي عندما لم يطابق أي سؤال.
- `_?` كلاهما على التوالي: *إذا لم يطابق شيء، اسأل مرة أخرى*.

لهذا كتب `_?` بهذه الطريقة. إنه ليس رمزاً جديداً للتعلم — إنه `_` متبوعاً بـ `?`، ويعني بالضبط ما يعنيه جزؤه مقروءين بالترتيب.

> الأقواس `{ }` **إلزامية** حتى لو كانت عبارة واحدة.

## المطابقة

```zymbol
درجة = ٨٥
تقدير = ?? درجة {
    ٩٠..١٠٠ => 'م'
    ٨٠..٨٩  => 'ج'
    _       => 'ر'
}
>> تقدير ¶              // → ج
```

```zymbol
حرارة = -٥
حالة = ?? حرارة {
    < ٠  => "جليد"
    < ٢٠ => "بارد"
    _    => "ساخن"
}
>> حالة ¶              // → جليد
```

أنت تعرف بالفعل أن `?` تعني "اسأل". **`??` هي السؤال عدة مرات**: مضاعفة رمز، في أي مكان في اللغة، يعني القيام عدة مرات بما يفعله الرمز مرة واحدة. `?` واحد يختبر شرطاً؛ `??` يختبر ضد قائمة من الحالات.

تتحد البدائل بـ `||`، ويمكنها مزج أنواع الأنماط:

```zymbol
مفتاح = 'P'
إجراء = ?? مفتاح {
    'p' || 'P' => "إيقاف مؤقت"
    < ٠ || > ١٠٠ => "خارج النطاق"
    _ => "مهمل"
}
>> إجراء ¶             // → إيقاف مؤقت
```

## الحلقات

```zymbol
@ م:١..٤  { >> م " " }
>> ¶                    // → 1 2 3 4
@ م:١..٩:٢ { >> م " " }
>> ¶                    // → 1 3 5 7 9
@ م:٥..١:١ { >> م " " }
>> ¶                    // → 5 4 3 2 1
```

```zymbol
ن = ١
@ ن <= ٦٤ { ن *= ٢ }
>> ن ¶                  // → 128
```

```zymbol
فواكه = ["تفاح", "كمثرى", "عنب"]
@ ف:فواكه { >> ف " " }
>> ¶                    // → تفاح كمثرى عنب
@ ح:"مرحباً" { >> ح "-" }
>> ¶                    // → م-ر-ح-ب-ا-ً-
```

```zymbol
@ م:١..١٠ {
    ? م % ٢ == ٠ { @> }
    ? م > ٧ { @! }
    >> م " "
}
>> ¶                    // → 1 3 5 7
```

```zymbol
عدد = ٠
@:خارجي {
    عدد++
    ? عدد >= ٣ { @:خارجي! }
}
>> عدد ¶             // → 3
```

`@` هو رمز **الزمن**: كل ما يتكرر يعيش فيه. لقطع هذا الزمن تضيف رمزاً بجانبه:

- `@!` — `!` هي **قوة**: اترك الحلقة الآن.
- `@>` — `>` تدفع للأمام: انتقل إلى الدورة التالية.
- `@:خارجي!` — `:` **تربط اسماً**، لذا تقطع الحلقة *المسماة* خارجي، وليس الأقرب.

ثلاثة عوامل، ولم يكن على أي منها أن يُحفظ بشكل منفصل: هي `@` بالإضافة إلى رمز يقول بالفعل ما يفعله.

> **المُحدِّد هو عدد أو شرط.** `عدد صحيح` هو عدد، يُقيّم مرة واحدة — `@ ٠` ينفذ النص صفر مرة. أي شيء آخر هو شرط. لا يوجد صدق: `@ []` و `@ ٣.٥` مرفوضان. لاجتياز مجموعة استخدم `@ س:عناصر`; لعدها، `@ عناصر$#`.

## الدوال

```zymbol
جمع(أ, ب) { <~ أ + ب }
>> جمع(٣, ٤) ¶        // → 7
```

```zymbol
مضروب(ن) {
    ? ن <= ١ { <~ ١ }
    <~ ن * مضروب(ن - ١)
}
>> مضروب(٥) ¶       // → 120
```

الدالة تقرأ متغيرات الملف بالقيمة، والكتابة داخلها تبقى داخلها:

```zymbol
حد = ١٠٠
داخل(ن) { <~ ن < حد }
>> داخل(٤٢) ¶         // → #1
```

رمزان يغيران ذلك، وكلاهما يُكتب **في التوقيع وفي موقع الاستدعاء**:

```zymbol
زد(عداد<~) { عداد = عداد + ١ }
إجمالي = ٠
زد(إجمالي<~)
>> إجمالي ¶              // → 1
```

> `p~` هي نسخة عمل — يمكن للنص إعادة تعيينها والمستدعي يبقى دون تغيير.
> `p<~` هي معامل إخراج — التغيير يعود. `زد(إجمالي)` بدون الرمز هو خطأ دلالي: لا يمكن للتعليق والتوقيع أن يتباعدا.

## المصفوفات

```zymbol
مصفوفة = [١, ٢, ٣, ٤, ٥]
>> مصفوفة[١] ¶       // → 1   الفهرسة تبدأ من ١
>> مصفوفة[-١] ¶      // → 5   السالب يعد من النهاية
>> مصفوفة$# ¶        // → 5   الطول
```

```zymbol
مصفوفة = [١, ٢, ٣]
>> (مصفوفة$+ ٦) ¶          // → [1, 2, 3, 6]   إلحاق
>> (مصفوفة$+[٢] ٩٩) ¶      // → [1, 99, 2, 3]  إدراج في الموضع 2
>> (مصفوفة$- ٣) ¶          // → [1, 2]         حذف أول ظهور
>> (مصفوفة$-[١]) ¶         // → [2, 3]         حذف عند الفهرس 1
>> (مصفوفة$[١..٢]) ¶       // → [1, 2]         شريحة، كلا الطرفين مشمولان
>> (مصفوفة$? ٣) ¶          // → #1             يحتوي
```

كلها تبدأ بـ `$`، رمز **المجموعة**، وتستمر برمز يقول ما يُفعل بها: `#` كم عدد، `+` إضافة، `-` حذف، `?` سؤال عما إذا كان موجوداً. وكما هو الحال مع `??`، مضاعفة الرمز تعني القيام به بشكل استقصائي: `$?` يسأل *هل* القيمة موجودة، `$??` يسأل *في كم موضع* ويعيدها كلها.

```zymbol
مصفوفة = [٣, ١, ٢]
>> (مصفوفة$^+) ¶     // → [1, 2, 3]   تصاعدي
>> (مصفوفة$^-) ¶     // → [3, 2, 1]   تنازلي
```

**قاعدة النتيجة.** عامل واحد، وما يفعله الكود المحيط به يقرر: إذا استُخدم، فإنه **يبني** ويترك الأصل دون تغيير؛ إذا أُهمل، فإنه **يعدّل**.

```zymbol
مصفوفة = [١, ٢, ٣]
نسخة = مصفوفة[٢]$~ ٩٩
>> مصفوفة ¶                // → [1, 2, 3]
>> نسخة ¶              // → [1, 99, 3]
مصفوفة[٢]$~ ٩٩
>> مصفوفة ¶                // → [1, 99, 3]
```

> **`=` لا يكتب أبداً داخل مجموعة.** `مصفوفة[٢] = ٩٩` ليس شكلاً من أشكال Zymbol — `=` يعطي قيمة لـ **اسم**. تغيير جزء من مجموعة هو `$~`، في كل مجموعة.

`[…]` يحتوي على نوع واحد ويُفحص؛ المزيج المتعمد **يُصرَّح** بـ `#[…]`:

```zymbol
مزيج = #[١, "اثنان", #١]
>> مزيج ¶             // → [1, اثنان, #1]
>> ([١, ٢] == #[١, ٢]) ¶ // → #1
```

---

## الفهرسة متعددة الأبعاد

`>` ينزل إلى هيكل متداخل. مجموعة أقواس واحدة تعالج عنصراً واحداً، مهما كان عميقاً.

```zymbol
م = [[١,٢,٣], [٤,٥,٦], [٧,٨,٩]]
>> م[٢>٣] ¶        // → 6   الصف 2، العمود 3
>> م[-١>-١] ¶      // → 9   الصف الأخير، العمود الأخير
```

```zymbol
م = [[١,٢,٣], [٤,٥,٦], [٧,٨,٩]]
>> م[١>١ ; ٢>٢ ; ٣>٣] ¶          // → [1, 5, 9]          مسطح: القطر
>> م[[١>١, ١>٣] ; [٣>١, ٣>٣]] ¶  // → [[1, 3], [7, 9]]   منظم: الزوايا
```

```zymbol
م = [[١,٢,٣], [٤,٥,٦]]
>> (م[١>٢]$~ ٩٩) ¶      // → [[1, 99, 3], [4, 5, 6]]
```

> `م[١][٢]` **ليس** شكلاً من أشكال Zymbol. الفهرس المتسلسل مرفوض سواء للقراءة أو الكتابة — مجموعة أقواس واحدة لكل وصول، و `>` هو ما يذهب بين الخطوات.

---

## القواميس

صف يحتوي على حقول مسماة هو قاموس، ومنذ v0.0.9 يُكتب `#(…)`.

```zymbol
شخص = #(اسم: "ليلى", عمر: ٢٥)
>> شخص.اسم ¶        // → ليلى
>> شخص["عمر"] ¶    // → 25
```

```zymbol
شخص = #(اسم: "ليلى", عمر: ٢٥)
حقل = "اسم"
>> شخص[حقل] ¶     // → ليلى
```

هو قابل للتغيير، ويمكن إضافة مفاتيح، ويمكن اجتيازه:

```zymbol
مخزون = #(كمثرى: ٤)
مخزون["تفاح"]$~ ١٠
@ ك:مخزون { >> ك "=" مخزون[ك] " " }
>> ¶                    // → كمثرى=4 تفاح=10
```

```zymbol
مخزون = #(كمثرى: ٤, تفاح: ١٠)
@ (ك, ق):مخزون { >> ك ":" ق " " }
>> ¶                    // → كمثرى:4 تفاح:10
```

> `#()` هو القاموس الفارغ، الذي لم يستطع `()` أن يكونه — سيكون عليه أن يكون الصف الفارغ أيضاً. الشكل المجرد `(أ: ١)` مرفوض مع هذه الرسالة: *a dictionary is written `#(…)`* — «يكتب القاموس `#(…)`».
> يُعنون القاموس بالمفتاح، وليس بالموضع أبداً، لذا `شخص[١]` هو خطأ.

## الصفوف

الصفوف هي حاويات مرتبة **غير قابلة للتغيير** تحمل قيماً من أنواع مختلفة.

```zymbol
نقطة = (١٠, ٢٠)
>> نقطة[١] ¶           // → 10
بيانات = (٤٢, "مرحباً", #١, ٣.١٤)
>> بيانات[٣] ¶            // → #1
```

```zymbol
ص = (١٠, ٢٠, ٣٠)
ص٢ = ص[٢]$~ ٩٩٩
>> ص ¶                  // → (10, 20, 30)
>> ص٢ ¶                 // → (10, 999, 30)
```

> أي محاولة لتعديل صف في مكانه هي خطأ، مهما كان العامل — عدم القابلية للتغيير هي خاصية للقيمة، وليست استثناء داخل كل `$`.

## التفكيك

```zymbol
مصفوفة = [١٠, ٢٠, ٣٠, ٤٠, ٥٠]
[أ, ب, ج] = مصفوفة
>> أ " " ب " " ج ¶      // → 10 20 [30, 40, 50]
```

```zymbol
مصفوفة = [١٠, ٢٠, ٣٠, ٤٠, ٥٠]
[أول, *باقي] = مصفوفة
>> أول ¶              // → 10
>> باقي ¶              // → [20, 30, 40, 50]
```

```zymbol
نقطة = (١٠٠, ٢٠٠)
(س, ص) = نقطة
>> س " " ص ¶          // → 100 200
```

```zymbol
شخص = #(اسم: "آنا", عمر: ٢٥)
#(اسم: ن, عمر: ع) = شخص
>> ن " " ع ¶            // → آنا 25
```

> شكل القوس محدد النوع: `[…]` يأخذ مصفوفة، `(…)` يأخذ صفاً، `#(…)` يأخذ قاموساً. الاسم الأخير **يمتص الباقي**، لذا لا يفشل التفكيك أبداً بسبب الطول — `(أ, ب, ج) = (١,٢,٣,٤,٥)` يعطي `ج = (٣,٤,٥)`، و `##_` عندما لا يتبقى شيء.

## دوال الرتبة العليا

```zymbol
أرقام = [١, ٢, ٣, ٤, ٥]
>> (أرقام$> (س -> س * ٢)) ¶ // → [2, 4, 6, 8, 10]
>> (أرقام$| (س -> س % ٢ == ٠)) ¶ // → [2, 4]
>> (أرقام$< (٠, (تراكمي, س) -> تراكمي + س)) ¶ // → 15
```

```zymbol
أرقام = [١, ٢, ٣, ٤, ٥, ٦]
ضعف(س) { <~ س * ٢ }
كبير(س) { <~ س > ٣ }
>> (أرقام$> ضعف) ¶    // → [2, 4, 6, 8, 10, 12]
>> (أرقام$| كبير) ¶    // → [4, 5, 6]
```

```zymbol
قاعدة = [#(اسم: "كارلا", عمر: ٢٨), #(اسم: "آنا", عمر: ٢٥)]
بالعمر = قاعدة$^ (أ, ب -> أ.عمر < ب.عمر)
>> بالعمر[١].اسم ¶     // → آنا
```

> الدالة المسماة تذهب إلى دالة رتبة عليا **بدون أقواس**: `أرقام$> ضعف`. كتابة `أرقام$> (ضعف)` هي خطأ تحليلي، لأن `(` تفتح لامدا.

```zymbol
ضعف = س -> س * ٢

>> (٥ |> ضعف(_)) ¶    // → 10
```

## معالجة الأخطاء

```zymbol
!? {
    س = ١٠ / ٠
} :! ##Div {
    >> "قسمة على صفر" ¶  // → قسمة على صفر
} :! {
    >> "أخرى: " _err ¶
} :> {
    >> "تُنفذ دائماً" ¶        // → تُنفذ دائماً
}
```

| النوع | متى |
|------|------|
| `##Div` | القسمة على صفر |
| `##Index` | الفهرس خارج النطاق |
| `##Key` | المفتاح غير موجود في القاموس |
| `##Range` | خارج نطاق العدد الصحيح الآمن |
| `##Type` | عدم تطابق النوع |
| `##Parse` | تحليل البيانات |
| `##IO` | ملف / نظام |
| `##Network` | أخطاء الشبكة |
| `##DB` | قاعدة البيانات |
| `##Time` | تاريخ غير موجود |
| `##_` | أي خطأ (يلتقط الكل) |

`!` هو رمز **الخطأ والقوة**، ويُقرأ بنفس الطريقة في كلا العائلتين: `$!` يسأل القيمة عما إذا كانت خطأ؛ `$!!`، مع مضاعفة الرمز، ينشرها لأعلى دون سؤال.

> تأتي إخفاقات المكتبة القياسية كـ **قيم خطأ لينة** تختبرها بـ `$!` أو تلتقطها بـ `!?`، بدلاً من الإجهاض. `$!!` ينشر واحداً إلى المستدعي.

## الوحدات (الموديلات)

```zymbol
# آلة_حاسبة {
    #> { جمع, PI }

    PI := ٣.١٤١٥٩
    جمع(أ, ب) { <~ أ + ب }
}
```

```zymbol
<# ./آلة_حاسبة => ج

>> ج::جمع(٥, ٣) ¶
>> ج.PI ¶
```

```zymbol
# مكتبتي {
    #> { جمع_داخلي => مجموع }

    جمع_داخلي(أ, ب) { <~ أ + ب }
}
```

رمزا الوحدة هما الفكرة نفسها مرة أخرى، مطبقة الآن على الملفات: `#` هو مستوى **الإعلان** — ما *هو* الشيء، وليس قيمته — والسهم يقول في أي اتجاه يذهب الكود:

```text
<#   السهم يدخل: استيراد، إحضار من ملف آخر
#>   السهم يخرج: تصدير، تقديم لملفات أخرى
```

رمز الاتجاه يجلس دائماً على الحافة التي تتجه إليها. هذا هو نفس السبب الذي يجعل `<~` يعود إلى اليسار (خارج الدالة) و `->` يدخل إلى اليمين (إلى نص اللامدا).

> **الوحدة تعلن ما تُصدّره.** كتلة `#>` إلزامية — حذفها هو **E014**، و `#> { }` هي الطريقة التي تقول بها الوحدة أن سطحها فارغ. `::` تستدعي دالة، `.` تقرأ ثابتاً. فقط الاستيرادات، كتلة التصدير، المُهيئات الحرفية وتعريفات الدوال قد تظهر في نص الوحدة؛ أي شيء قابل للتنفيذ هو **E013**.

## المكتبة القياسية

وحدات أصلية، تُستورد مثل أي وحدة أخرى:

| الوحدة | الدوال |
|--------|-----------|
| `std/math` | `sqrt exp ln log pow abs ceil floor round min max sin cos tan` · `PI` `E` |
| `std/random` | `entero rango peso_f64` |
| `std/json` | `decode decode_map encode` |
| `std/io` | `read write append exists delete list mkdir` |
| `std/net` | `get post post_json head` |
| `std/db` | `connect exec query query_one tx commit rollback` … |
| `std/term` | `width pad_left pad_right center truncate` |
| `std/time` | `now today parts of format add diff` |

```zymbol
<# std/math => ر

>> ر::sqrt(١٦.٠) ¶      // → 4
>> ر.PI ¶               // → 3.141592653589793
```

```zymbol
<# std/term => ط

>> ط::width("手番") ¶          // → 4   رمزان، أربعة أعمدة
>> "|" ط::center("go", 8) "|" ¶ // → |   go   |
```

```zymbol
<# std/time => ز

يوم = ز::of(٢٠٢٦, ١, ٣١)
>> ز::format(يوم, "%Y-%m-%d") ¶ // → 2026-01-31
>> ز::format(ز::add(يوم, 1, "month"), "%Y-%m-%d") ¶ // → 2026-02-28
```

> `std/term` يقيس **أعمدة العرض**، وليس الأحرف: CJK ومعظم الإيموجي عمودان، لذا ضع جدولاً بـ `ط::width`، وليس `$#` أبداً.
> في `std/time` اللحظة هي ميلي ثانية منذ العصر. أقل من يوم هو مدة، من يوم فصاعداً هو تقويم — لذا يقع الشهر في نفس اليوم من الشهر، مقيداً. `فرق(أ, ب)` هي `أ - ب`، لذا اللحظة الأقدم أولاً تعطي إجابة سالبة.

```bash
zymbol package مشروعي/ --script main.zy -o مشروعي.zyp

```

> يحمل الأرشيف بياناً (`zyp.toml`) يعلن نصوص الدخول وإصدار المحرك الذي يحتاجه. `zymbol run` يستخرجه إلى دليل مؤقت ويشغله من هناك، لذا الكود قابل للتصرف بينما ما يكتبه النص يقع في دليل العمل الحقيقي الخاص بك. الملعب (playground) يحمّل ملفات `.zyp` أيضاً.

## أوضاع الأرقام

يمكن لـ Zymbol كتابة الأرقام في **69 خطاً رقمياً يونيكودياً** — الديفاناغاري، العربي-الهندي، التايلندي، pIqaD الكلينغوني، الجريء الرياضي، قطع LCD، والمزيد. الوضع عام للعملية ويؤثر على الإخراج؛ الحساب لا يتغير.

```zymbol
#०९#    // ديفاناغاري   (U+0966–U+096F)
#٠٩#    // عربي-هندي (U+0660–U+0669)
#๐๙#    // تايلندي     (U+0E50–U+0E59)
#09#    // إعادة تعيين إلى ASCII
```

```zymbol
س = ٤٢
>> س ¶                  // → 42
#٠٩#
>> س ¶                  // → ٤٢
>> ٣.١٤ ¶               // → ٣٫١٤
>> #١ ¶                 // → #١
#09#
```

أرقام أي خط مدعوم هي قيم حرفية صالحة في المصدر:

```zymbol
#٠٩#
@ م:١..٥ { >> م " " }
>> ¶                    // → ١ ٢ ٣ ٤ ٥
#09#
```

القراءة متماثلة — الرقم مفهوم في أي خط:

```zymbol
>> #|"٤٢"| ¶            // → 42
>> #|'٧'| ¶             // → 7
```

> `#` دائماً ASCII، لذا يبقى `#0` متميزاً بصرياً عن الرقم صفر في كل خط.
> `#,` و `#^` يكتبان أرقامهما بالخط النشط أيضاً، وتتبعهما الفواصل — لكن الزوج لا ينعكس أبداً: `,` تجميع و `.` قسمة، في كل خط.

## عوامل البيانات

```zymbol
ع = ##.٤٢         // إلى عشري
ص = ###٣.٧        // إلى صحيح، مقرب  → 4
م = ##!٣.٧        // إلى صحيح، مقطوع  → 3
>> ع " " ص " " م ¶      // → 42 4 3
>> ع#? ¶                // → (##., 2, 42)
```

> الرقم العشري يُطبع كأرقام، ليس كأس أبداً، ويحذف `.0` النهائي — `##.42` يكتب `42` ولا يزال عشرياً، كما يظهر `ع#?`.

```zymbol
>> #|"٤٢"| ¶       // → 42
>> #|"abc"| ¶      // → abc   آمن: يعيد الإدخال دون تغيير
>> ##!'أ' ¶        // → 1571    نقطة كود الحرف
```

```zymbol
ط = ٣.١٤١٥٩٢٦٥
>> #.٢|ط| ¶       // → 3.14          تقريب إلى منزلتين عشريتين
>> #!٢|ط| ¶       // → 3.14          قطع إلى منزلتين عشريتين
>> #,|١٢٣٤٥٦٧| ¶   // → 1,234,567    فواصل الآلاف
>> #^|١٢٣٤٥.٦٧٨| ¶ // → 1.2345678e4  تدوين علمي
```

```zymbol
>> 0x41 ¶        // → A   ستة عشري
>> 0b01000001 ¶  // → A   ثنائي
>> 0o101 ¶       // → A   ثماني
>> 0d65 ¶        // → A   عشري
```

> القيمة الحرفية الأساسية في نطاق ASCII هي **حرف**: `0d65 == 'A'` هي `#1`، و `0d65 == 65` هي `#0`. جميع القواعد الأربع تهجئ نفس الحرف.

## كيفية اتحاد الرموز

كنت ترى الشيء نفسه طوال هذا الدليل: **العامل ليس رسمة لحفظها، بل هو عدة رموز في صف واحد، ويساهم كل منها بمعناه.** الآن بعد أن عرفتهم جميعاً، ها هو النمط الكامل.

أولاً يأتي **في أي عالم نحن**:

| الرمز | العالم | رأيته في |
|------|-------|-------------|
| `$` | مجموعة | `$#` `$+` `$?` `$^-` |
| `@` | الزمن، كل ما يتكرر | `@!` `@>` `@~` |
| `#` | ما *هو* الشيء، وليس ما يساوي | `#?` `#(…)` `<#` `#>` |
| `>>` | خارج البرنامج | `>>` `>>!` `>>?` |
| `<<` | داخل البرنامج | `<<` `<<\|` `<<\|?` |
| `?` | السؤال، دون التزام | `?` `_?` `??` `$?` |
| `!` | القوة، أو الخطأ | `@!` `$!` `!?` |

ثم يأتي **ما يُفعل هناك**: `+` إضافة، `-` حذف، `^` ترتيب، `~` تعديل، `#` عد، `|` وحدة واحدة، `:` ربط اسم.

وقاعدتان لا تفشلان أبداً:

**مضاعفة رمز تجعله استقصائياً.** `?` يسأل مرة واحدة، `??` يختبر عدة حالات. `$?` يسأل عما إذا كانت القيمة موجودة، `$??` يعيد كل مكان توجد فيه. `!` يعلن خطأ، `!!` ينشره دون سؤال.

**رمز الوضع يأتي دائماً في النهاية.** عندما يظهر `?` أو `!` ليقول *كيف* يُفعل شيء — بشكل ترددي أو قسري — هما الرمز الأخير للعامل: `$??`, `$!!`, `<<|?`, `@!`, `##!`, `>>!`, `>>?`, `@:خارجي!`. لا يوجد أبداً عملية بعدهما.

يترتب على ذلك شيء عملي: **تركيبة لم ترها من قبل تصبح ذات معنى قبل أن تبحث عنها.** إذا كان `$` مجموعة و `^` ترتيب و `-` عكس، فإن `$^-` ترتب تنازلياً، ولم يكن على أحد أن يخبرك.

ليست القائمة بأكملها تعمل بهذه الطريقة، وقول ذلك أفضل من التظاهر. معظم العوامل تتفكك بشكل نظيف. ستة تتفكك لكنها تعني أكثر من أجزائها: `!?` `:!` `:>` `|>` `::` `$++`. وعشرة يجب حفظها عن ظهر قلب لأنها لا تتفكك على الإطلاق: `¶` `><` `#1` `#0` `0x` `0b` `0o` `0d` `###` `°`.

> عد المعتمة بدلاً من افتراض أنها قليلة هو مقصود: هي تكلفة الحفظ الحقيقية للغة. المرجع الكامل — القائمة، والمتجانسات المعلنة، والقواعد التي يجب أن يفي بها عامل جديد ليكون موجوداً — هو `SYMBOLS.md`، في مستودع المُفسِّر.

| الرمز | العملية | الرمز | العملية |
|--------|-----------|--------|-----------|
| `=` | متغير | `$#` | الطول |
| `:=` | ثابت | `$+` | إلحاق |
| `>>` | إخراج | `$+[i]` | إدراج عند الفهرس (1-أساس) |
| `<<` | إدخال | `$-` | حذف الأول بالقيمة |
| `¶` / `\\` | سطر جديد | `$--` | حذف الكل بالقيمة |
| `?` | إذا | `$-[i]` | حذف عند الفهرس (1-أساس) |
| `_?` | وإلا-إذا | `$-[i..j]` | حذف نطاق (1-أساس) |
| `_` | وإلا / بدل | `$?` | يحتوي |
| `??` | مطابقة | `$??` | إيجاد كل الفهارس (1-أساس) |
| `\|\|` | نمط أو في فرع المطابقة | `$[s..e]` | شريحة (1-أساس) |
| `@` | حلقة | `$>` | خريطة |
| `@ ن { }` | حلقة ن مرات | `$\|` | تصفية |
| `@!` | كسر | `$<` | اختزال |
| `@>` | متابعة | `$/ محدد` | تقسيم سلسلة |
| `@:اسم { }` | حلقة موسومة | `$++ أ ب ج` | بناء بالدمج |
| `@:اسم!` | كسر الوسم | `$~~[p:r]` | استبدال سلسلة |
| `@:اسم>` | متابعة الوسم | `$*` | تكرار سلسلة |
| `->` | لامدا | `مصفوفة[i]$~ ق` | صيغة التحديث الوحيدة |
| `<~` | إرجاع / معامل إخراج | `~` | معامل نسخة عمل |
| `مصفوفة[i>j]` | فهرس تنقل | `مصفوفة[p ; q]` | استخراج مسطح |
| `$^+` | ترتيب تصاعدي | `$^-` | ترتيب تنازلي |
| `$^` | ترتيب بمقارن | `\|>` | أنبوب |
| `!?` | محاولة | `:!` | التقاط |
| `:>` | أخيراً | `$!` | هل هو خطأ |
| `$!!` | نشر الخطأ | `#1` / `#0` | صحيح / خاطئ |
| `##_` | وحدة — غياب | `[…]` | مصفوفة، نوع واحد |
| `#[…]` | مصفوفة، مزيج مصرح | `#(…)` | قاموس |
| `(…)` | صف موضعي | `#()` | قاموس فارغ |
| `<#` | استيراد | `#>` | تصدير |
| `#` | إعلان وحدة | `::` | استدعاء وحدة |
| `.` | وصول حقل / ثابت | `#?` | بيانات وصف النوع |
| `#\|..\|` | تحليل رقم | `##.` | تحويل إلى عشري |
| `###` | تحويل إلى صحيح (تقريب) | `##!` | تحويل إلى صحيح (قطع) |
| `#.ن\|..\|` | تقريب | `#!ن\|..\|` | قطع |
| `#,\|..\|` | فواصل الآلاف | `#^\|..\|` | علمي |
| `#d0d9#` | تبديل الوضع الرقمي | `#09#` | إعادة تعيين إلى ASCII |
| `<\ ..\>` | تنفيذ شل | `><` | معطيات سطر الأوامر |
| `\ متغير` | تدمير متغير | `°س` / `س°` | تعريف ساخن |
| `>>\|` | كتلة TUI (شاشة بديلة) | `>>~` | إخراج موضعي |
| `>>!` | مسح الشاشة | `>>?` | استعلام حجم الطرفية |
| `<<\|` | ضغطة مفتاح محظورة | `<<\|?` | ضغطة مفتاح غير محظورة |
| `@~ ن` | النوم ن ميلي ثانية | `0d` `0x` `0o` `0b` | قيم حرفية أساسية |

## سجل التغييرات

### v0.0.9 — المجموعات تقرر _(سبتمبر 2026)_

- **تغيير جذري** أصبح للقاموس ترميزه الخاص: `#(مفتاح: قيمة)`. الشكل المجرد `(أ: ١)` مرفوض، و `#()` هو القاموس الفارغ — الذي لم يستطع `()` أن يكونه أبداً
- **تغيير جذري** سحب الإسناد المفهرس: `مصفوفة[i] = ق` وكل الصيغ المركبة. `=` يعطي قيمة **لاسم**; تغيير جزء من مجموعة هو `$~`
- **تغيير جذري** الفهرس المتسلسل `م[i][j]` مرفوض للقراءة والكتابة — `>` هو ما يذهب بين الخطوات
- **تغيير جذري** يجب على الوحدة أن تعلن ما تُصدّره (**E014**); `#> { }` هو كيف تقول الوحدة أن سطحها فارغ
- **تغيير جذري** محدد الحلقة هو عدد أو شرط — لا صدق. `@ []` و `@ ٣.٥` مرفوضان
- **أضيف** `##_` — القيمة الحرفية للوحدة، وكيف يسأل البرنامج عما إذا كان شيء غائباً
- **أضيف** `#[…]` — مصفوفة يُصرح فيها بمزيج أنواع العناصر
- **أضيف** `#?` يخبر المجموعات الأربع: `##]` `##[` `##)` `##(`
- **أضيف** `std/time` — الساعة والتقويم المدني، مع المناطق والحساب التقويمي
- **أضيف** `<~` في المستوى الأعلى هو حالة خروج البرنامج
- **أضيف** `@ (ك, ق):أزواج` — نمط في رأس الحلقة
- **أضيف** `#|ح|` يقرأ رقماً في أي من الخطوط الـ 69; `#,` و `#^` يكتبان بالخط النشط
- **تغيير** `عدد صحيح` هو عدد صحيح آمن، ±(2⁵³ − 1)، مغلق عند الفشل في كل محرك
- **تغيير** الدالة المسماة تقرأ متغيرات الملف عند الاستدعاء، بالقيمة
- **تغيير** العبارة التي تقرأ اسماً فقط تحذر بدلاً من المرور بصمت
- **المحركات** 660 من 666 ملفاً في المجموعة متفق عليها في المحركات الثلاثة، 0 متباعدة

### v0.0.8 — التحرير التلقائي، `std/term` والحزم _(أغسطس 2026)_

- **أضيف** التدمير التلقائي عند آخر استخدام — غير مرئي; يخفض فقط الذروة
- **أضيف** `std/term` — مقاييس العرض في أعمدة الطرفية
- **أضيف** `##!` على `حرف` — نقطة كود اليونيكود الخاصة به
- **أضيف** أنماط أو في المطابقة: `'p' || 'P' => …`، بدائل من أي نوع في فرع واحد
- **أضيف** حزم Zymbol (`.zyp`) — `zymbol package` / `zymbol run pkg.zyp`
- **أضيف** `<~` في موقع الاستدعاء مطلوب حيث يعلن المُستدعى معامل إخراج
- **أصلح** تكافؤ نظام الوحدات في VM السجلات

### v0.0.7 — المكتبة القياسية الأصلية _(يوليو 2026)_

- **أضيف** `std/json`، `std/io`، `std/net`، `std/db` (ODBC) — جميعها بقيم خطأ لينة
- **أضيف** إدخال بنوع / مُتحقق منه: `<< ##.(٥,٢) "السعر: " ع`
- **أضيف** عوامل لاحقة مباشرة في `>>` — لا حاجة لأقواس
- **تغيير** مصمم مغلق عند الفشل: يرفض كتابة مخرجات لا يستطيع إعادة قراءتها

### v0.0.6 — التحسين والمكتبة العلمية _(يونيو 2026)_

- **تغيير جذري** `=>` يحل محل `:` في فروع المطابقة و `<=` في اسماء الاستيراد/التصدير المستعارة
- **أضيف** `std/math` و `std/random`
- **أضيف** تحديث القاموس بالمفتاح: `ق["ك"]$~ قيمة`

### v0.0.5 — أوليات TUI والتعريف الساخن _(مايو 2026)_

- **أضيف** كتلة TUI `>>| { }`، إخراج موضعي `>>~`، إدخال مفاتيح `<<|` و `<<|?`
- **أضيف** `>>!` مسح الشاشة، `>>?` حجم الطرفية، `@~ ن` النوم
- **أضيف** تعريف ساخن `°س` / `س°`، وتكرار السلسلة `$*`

### v0.0.4 — فهرسة 1-أساس ودوال من الدرجة الأولى _(أبريل 2026)_

- **تغيير جذري** كل الفهرسة **1-أساس** — `مصفوفة[١]` هو العنصر الأول
- **أضيف** دوال مسماة كقيم من الدرجة الأولى; صيغة كتلة الوحدة `# اسم { }`
- **أضيف** فهرسة متعددة الأبعاد `مصفوفة[i>j>k]` واستخراج مسطح `مصفوفة[p ; q]`

### v0.0.3 — أنظمة الأرقام اليونيكودية _(أبريل 2026)_

- **أضيف** 69 كتلة أرقام يونيكود مع رمز تبديل الوضع `#d0d9#`
- **أضيف** قيم منطقية حرفية في أي خط — `#१` / `#०`

### v0.0.2 — إعادة تصميم API للمجموعات _(مارس 2026)_

- **أضيف** عائلة العوامل `$` للمصفوفات والسلاسل
- **أضيف** إسناد التفكيك، والفهارس السالبة

### v0.0.1 — الإصدار العام الأولي _(مارس 2026)_

- مُفسِّر اجتياز الشجرة + VM السجلات (`--vm`)
- كل التركيبات الأساسية: `?` `@` `<~` `->` `>>` `<<` `¶` `??`
- معرفات يونيكود كاملة، نظام وحدات، لامدا، إغلاقات، معالجة أخطاء
- REPL, LSP, إضافة VS Code, مُنسق (`zymbol fmt`)
