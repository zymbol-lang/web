# Zymbol-Lang మాన్యువల్

> **v0.0.9 కోసం సవరించబడింది — 2026-09-07**

**Zymbol-Lang** అనేది సింబాలిక్ ప్రోగ్రామింగ్ భాష. దీని వ్యాకరణంలో పదాలు లేవు — ప్రతి నిర్మాణం ఒక గుర్తు. ఏ మానవ భాషలోనైనా ఒకేలా పనిచేస్తుంది.

- పూర్తి యూనికోడ్ — ఏ భాషలోనైనా లేదా ఎమోజీలో గుర్తింపుదారులు

## వేరియబుల్స్ మరియు కాన్స్టెంట్లు

```zymbol
వేరియబుల్ = ౧౦              // మార్చగల వేరియబుల్
PI := ౩.౧౪౧౫౯       // కాన్స్టెంట్ — తిరిగి కేటాయించడం రన్టైమ్ దోషం
పేరు = "రమేష్"
క్రియాశీల = #౧         // బూలియన్ సత్యం
👋 := "నమస్కారం"
```

```zymbol
వేరియబుల్ = ౧౦    // ౧౦
వేరియబుల్ += ౫    // ౧౫
వేరియబుల్ -= ౩    // ౧౨
వేరియబుల్ *= ౨    // ౨౪
వేరియబుల్ /= ౩    // ౮
వేరియబుల్ %= ౩    // ౨
వేరియబుల్ ^= ౨    // ౪
వేరియబుల్++       // ౫
వేరియబుల్--       // ౪
```

`°` (డిగ్రీ గుర్తు, U+00B0) మొదటి ఉపయోగంలో వేరియబుల్ను దాని తటస్థ విలువకు స్వయంచాలకంగా ప్రారంభిస్తుంది:

```zymbol
సంఖ్యలు = [౩, ౧, ౪, ౧, ౫]
@ n:సంఖ్యలు {
    °మొత్తం += n
}
>> మొత్తం ¶              // → 14
```

> `°వేరియబుల్` (ఉపసర్గ) లూప్ పైన యాంకర్ చేస్తుంది — ఫలితం `@` తర్వాత చదవగలిగేది.
> `వేరియబుల్°` (ప్రత్యయం) లూప్ లోపల యాంకర్ చేస్తుంది — లూప్ ముగిసినప్పుడు ఇది చనిపోతుంది.

కేవలం పేరు మాత్రమే ఉన్న స్టేట్మెంట్ వేరియబుల్ను చదివి విలువను విస్మరిస్తుంది, కాబట్టి ఇది హెచ్చరిస్తుంది:

```zymbol
లెక్క = ౫
లెక్క
```

కంపైలర్ ఈ విధంగా హెచ్చరిస్తుంది (దాని సందేశాలు ఎల్లప్పుడూ ఆంగ్లంలో ఉంటాయి):

```text
warning: this statement does nothing: 'లెక్క' is read and discarded
  = help: remove it, or use it — `>> name ¶` to print it
```

అర్థం: *«ఈ స్టేట్మెంట్ ఏమీ చేయదు: 'లెక్క' చదవబడింది మరియు విస్మరించబడింది»*.

## డేటా రకాలు

| రకం | లిటరల్ | `#?` ట్యాగ్ | గమనికలు |
|------|---------|------------|-------|
| పూర్ణాంకం | `౪౨`, `-౭` | `###` | సురక్షిత పూర్ణాంకం: ±(2⁵³ − 1) |
| ఫ్లోట్ | `౩.౧౪`, `౧.౫e౧౦` | `##.` | IEEE-754 డబుల్ |
| స్ట్రింగ్ | `"పాఠ్యం"` | `##"` | ఇంటర్పోలేషన్: `"నమస్కారం {పేరు}"` |
| అక్షరం | `'A'` | `##'` | ఒక యూనికోడ్ కోడ్ పాయింట్ |
| బూలియన్ | `#౧`, `#౦` | `##?` | సంఖ్యాత్మకం కాదు — `#౧ ≠ ౧` |
| శ్రేణి | `[౧, ౨, ౩]` | `##]` | ఒక రకం, తనిఖీ చేయబడింది |
| ప్రకటించిన మిశ్రమం | `#[౧, "రెండు"]` | `##[` | `[…]` వలె అదే రకం, తనిఖీ లేదు |
| టపుల్ | `(a, b)` | `##)` | స్థానిక, మార్చలేని |
| నిఘంటువు | `#(a: ౧, b: ౨)` | `##(` | కీలతో, మార్చగలిగే |
| ఫంక్షన్ | పేరున్న ఫంక్షన్ సూచన | `##()` | ప్రథమ-శ్రేణి; చూపుతుంది `<funct/N>` |
| లాంబ్డా | `a -> a * ౨` | `##->` | ప్రథమ-శ్రేణి; చూపుతుంది `<lambd/N>` |
| యూనిట్ | `##_` | `##_` | లేకపోవడం — null లేదు |

```zymbol
>> ౪౨#? ¶               // → (###, 2, 42)
>> [౧, ౨, ౩]#? ¶        // → (##], 3, [1, 2, 3])
>> #(a: ౧)#? ¶          // → (##(, 1, #(a: 1))
```

సురక్షిత పరిధి నుండి బయటకు వెళ్ళే పూర్ణాంకం పట్టుకోగలిగే దోషం, ఎప్పుడూ నిశ్శబ్ద చుట్టివేత కాదు:

```zymbol
!? {
    >> (౯౦౦౭౧౯౯౨౫౪౭౪౦౯౯౧ + ౧) ¶
} :! ##Range {
    >> "పరిధి వెలుపల" ¶ // → పరిధి వెలుపల
}
```

`##_` అనేది ప్రోగ్రామ్ ఏదైనా లేదో లేదో అడిగే విధానం:

```zymbol
ఏమీ_లేదు() { }
విలువ = ఏమీ_లేదు()
>> (విలువ == ##_) ¶     // → #1
```

## అవుట్పుట్ మరియు ఇన్పుట్

```zymbol
పేరు = "రమేష్"
మొత్తం = ౩
>> "నమస్కారం" ¶             // → నమస్కారం
>> "a=" పేరు " b=" మొత్తం ¶ // → a=రమేష్ b=3
>> మొత్తం#? ¶            // → (###, 1, 3)
```

```zymbol
<< పేరు
<< "మీ పేరు నమోదు చేయండి: " పేరు
<< ###(౪) "వయస్సు: " వయస్సు
```

**రెండు గుర్తుల ఆకారాన్ని చూడండి.** `>>` బయటికి సూచిస్తుంది: ఇది డేటాను ప్రోగ్రామ్ నుండి బయటకు తీసుకువెళుతుంది. `<<` లోపలికి సూచిస్తుంది: ఇది డేటాను ప్రోగ్రామ్లోకి తెస్తుంది. అక్కడ గుర్తుంచుకోవడానికి ఏమీ లేదు — బాణం సమాచారం ఏ దిశలో ప్రయాణిస్తుందో చూపిస్తుంది మరియు ఆ అదే ఆలోచన ఏదైనా కదిలించే ప్రతి గుర్తులో తిరిగి వస్తుంది.

> `¶` మరియు `\\` సమానమైన కొత్త పంక్తులు. `>>` ఎప్పుడూ ఒకదానిని జోడించదు.
> ప్రాంప్ట్కు ముందు రకం నిర్దేశకం చదివేటప్పుడు ధృవీకరిస్తుంది మరియు విలువ చెల్లుబాటు అయ్యే వరకు మళ్ళీ ప్రాంప్ట్ చేస్తుంది:
> `##.` ఫ్లోట్ · `##.(T,D)` దశాంశం · `###(N)` పూర్ణాంకం · `##"(N)" పాఠ్యం · `##'` ఒక అక్షరం.

ఫైల్ యొక్క టాప్ స్థాయిలో, `<~` ప్రోగ్రామ్ యొక్క నిష్క్రమణ స్థితి:

```zymbol
>> "తనిఖీ చేస్తోంది" ¶      // → తనిఖీ చేస్తోంది
<~ ౦
```

## TUI ప్రాథమికాంశాలు

ఇంటరాక్టివ్ ప్రోగ్రామ్ల కోసం టెర్మినల్ UI ఆపరేటర్లు. చాలా వరకు `>>| { }` బ్లాక్ అవసరం (ప్రత్యామ్నాయ స్క్రీన్ + రా మోడ్).

```zymbol
>>| {
    >>!
    >>~ (౧, ౧, ౦, ౧౦) > "నడుస్తోంది"
    @~ ౧౦౦౦
    >>~ (౨, ౧) > "పూర్తయింది."
}
```

```zymbol
>>| {
    [వరుసలు, నిలువులు] = >>?
    >>~ (౧, ౧) > "టెర్మినల్: " వరుసలు " x " నిలువులు
    <<| కీ
    >>~ (౨, ౧) > "నొక్కారు: " కీ
}
```

ఇక్కడ మీరు గుర్తులు ఎందుకు గుణించబడకుండా కలిపి ఉంటాయో చూడవచ్చు. మీకు ఇప్పటికే `<<` ఇన్పుట్ అని మరియు `?` నిబద్ధత లేకుండా అడుగుతుందని తెలుసు. ఒకే ఒక గుర్తు కొత్తది:

- `|` **ఒక యూనిట్**, మొత్తం స్ట్రీమ్ కాదు.

దానితో, రెండు కీబోర్డ్ ఆపరేటర్లు తమను తాము చదివించుకుంటాయి:

```text
<<        |             ?
ఇన్పుట్   ఒక యూనిట్    నిబద్ధత లేకుండా

<<|   ఒక కీ తీసుకోండి మరియు ఒకటి వచ్చేవరకు వేచి ఉండండి
<<|?  ఒక కీ ఉందో లేదో చూడండి మరియు లేకపోతే కొనసాగండి
```

ఇతర వైపు కూడా అదే: `>>` పంపిస్తుంది, `>>!` **బలవంతంగా** పంపిస్తుంది (మొత్తం స్క్రీన్ను క్లియర్ చేస్తుంది), అయితే `>>?` రాయడానికి బదులుగా **అడుగుతుంది** (టెర్మినల్ ఎంత పెద్దది). కుడి వైపున ఉన్న గుర్తు మోడ్ను మార్చేది మరియు ఇది ఎల్లప్పుడూ చివరిదిగా వస్తుంది.

> `>>!` స్క్రీన్ను క్లియర్ చేస్తుంది. `>>?` `[వరుసలు, నిలువులు]` తిరిగి ఇస్తుంది. `@~ N` N మిల్లీసెకన్లు నిద్రిస్తుంది.
> `<<|` ఒక కీనొక్కడాన్ని చదువుతుంది (బ్లాకింగ్); `<<|?` బ్లాక్ చేయకుండా పోల్ చేస్తుంది (`'\0'` ఏదీ లేకపోతే).
> బాణం కీలు `'↑' '↓' '←' '→'` గా డీకోడ్ అవుతాయి; ESC కోడ్ పాయింట్ 27.
> స్థానీకరించిన అవుట్పుట్ టపుల్: `(వరుస, నిలువు, BKS, ముందు, వెనుక)` — ఏదైనా స్లాట్ను కామాతో వదిలివేయవచ్చు (`>>~ (,,, ౧౯౬) > "ఎరుపు"`).
> BKS బిట్మాస్క్: `1`=బోల్డ్, `2`=ఇటాలిక్, `4`=అండర్లైన్. ANSI 256-రంగుల పాలెట్ (`0`=టెర్మినల్ డిఫాల్ట్).

## ఆపరేటర్లు

```zymbol
a = ౧౦
b = ౩
f1 = a + b    // ౧౩
f2 = a - b    // ౭
f3 = a * b    // ౩౦
f4 = a / b    // ౩  (పూర్ణాంక భాగాహారం)
f5 = a % b    // ౧
f6 = a ^ b    // ౧౦౦౦
```

```zymbol
a = ౧౦
b = ౩
c1 = a == b    // #౦
c2 = a <> b    // #౧
c3 = a < b     // #౦
c4 = a >= b    // #౧
l1 = #౧ && #౦  // #౦
l2 = !#౧       // #౦
```

> `==` ఎప్పుడూ బలవంతం చేయదు: `"5" == 5` `#0`. క్రమం బలవంతం చేస్తుంది: `"5" > 4` `#1`, మరియు `"४२" > 5` కూడా — 69 లిపులలో ఏదైనా సంఖ్యా పాఠ్యం సంఖ్యగా పోల్చబడుతుంది.
> ఒక ఫంక్షన్ తనకు తాను మాత్రమే సమానం, అదే శరీరంతో మరొక ఫంక్షన్కు ఎప్పుడూ సమానం కాదు.

## స్ట్రింగ్లు

```zymbol
పేరు = "రమేష్"
n = ౪౨
>> "నమస్కారం " పేరు " మీ దగ్గర " n " ఉంది" ¶ // → నమస్కారం రమేష్ మీ దగ్గర 42 ఉంది
వివరణ = "నమస్కారం {పేరు}, మీ దగ్గర {n} ఉంది"
>> వివరణ ¶              // → నమస్కారం రమేష్, మీ దగ్గర 42 ఉంది
```

```zymbol
s = "నమస్కారం ప్రపంచం"
పొడవు = s$#                  // ౧౬
ఉప = s$[౧..౮]             // "నమస్కారం"
ఉందా = s$? "ప్రపంచం"          // #౧
భాగాలు = "a,b,c,d"$/ ','    // [a, b, c, d]
మార్చు = s$~~["ా":"ీ"]        // "నమస్కీరం ప్రపంచం"
రేఖ = "─" $* ౨౦
```

> `+` సంఖ్యలకు మాత్రమే. స్ట్రింగ్ల కోసం ప్రక్కన ఉంచడం లేదా ఇంటర్పోలేషన్ ఉపయోగించండి.
> `\{` మరియు `\}` అక్షర బ్రేస్లు — ఎస్కేప్ సౌష్ఠవంగా ఉంటుంది.

## నియంత్రణ ప్రవాహం

```zymbol
a = ౭
? a > ౧౦౦ {
    >> "పెద్దది" ¶
} _? a > ౦ {
    >> "ధనాత్మకం" ¶     // → ధనాత్మకం
} _ {
    >> "ఋణాత్మకం" ¶
}
```

ఇక్కడ రెండు కొత్త గుర్తులు ఉన్నాయి మరియు వాటిని కలిపి ఉంచడం నుండి వచ్చే మూడవది:

- `?` **అడగడం**: ఇది ఒక షరతును తెరుస్తుంది.
- `_` **పేర్కొనబడనిది**: ఏ ప్రశ్న కూడా సరిపోలనప్పుడు మిగిలిపోయిన శాఖ.
- `_?` రెండూ వరుసగా: *ఏమీ సరిపోలకపోతే, మళ్ళీ అడగండి*.

అందుకే `_?` ఆ విధంగా వ్రాయబడింది. ఇది నేర్చుకోవడానికి కొత్త చిహ్నం కాదు — ఇది `_` తర్వాత `?`, మరియు దీని అర్థం దాని రెండు భాగాల అర్థం, క్రమంలో చదవబడినది.

> బ్రేస్లు `{ }` ఒకే స్టేట్మెంట్కు కూడా **తప్పనిసరి**.

## సరిపోలిక

```zymbol
స్కోరు = ౮౫
గ్రేడ్ = ?? స్కోరు {
    ౯౦..౧౦౦ => 'A'
    ౮౦..౮౯  => 'B'
    _       => 'F'
}
>> గ్రేడ్ ¶              // → B
```

```zymbol
ఉష్ణోగ్రత = -౫
స్థితి = ?? ఉష్ణోగ్రత {
    < ౦  => "మంచు"
    < ౨౦ => "చల్లని"
    _    => "వేడి"
}
>> స్థితి ¶              // → మంచు
```

`?` "అడగడం" అని మీకు ఇప్పటికే తెలుసు. **`??` అనేది చాలాసార్లు అడగడం**: ఒక గుర్తును రెట్టింపు చేయడం, భాషలో ఎక్కడైనా, ఆ గుర్తు ఒకసారి చేసేదాన్ని చాలాసార్లు చేయడం. ఒక `?` ఒక షరతును పరీక్షిస్తుంది; `??` కేసుల జాబితాతో పరీక్షిస్తుంది.

ప్రత్యామ్నాయాలు `||` తో కలుస్తాయి మరియు అవి నమూనా రకాలను మిళితం చేయగలవు:

```zymbol
కీ = 'P'
చర్య = ?? కీ {
    'p' || 'P' => "పాజ్"
    < ౦ || > ౧౦౦ => "పరిధి వెలుపల"
    _ => "విస్మరించబడింది"
}
>> చర్య ¶             // → పాజ్
```

## లూప్లు

```zymbol
@ i:౧..౪  { >> i " " }
>> ¶                    // → 1 2 3 4
@ i:౧..౯:౨ { >> i " " }
>> ¶                    // → 1 3 5 7 9
@ i:౫..౧:౧ { >> i " " }
>> ¶                    // → 5 4 3 2 1
```

```zymbol
n = ౧
@ n <= ౬౪ { n *= ౨ }
>> n ¶                  // → 128
```

```zymbol
పండ్లు = ["ఆపిల్", "బేరి", "ద్రాక్ష"]
@ p:పండ్లు { >> p " " }
>> ¶                    // → ఆపిల్ బేరి ద్రాక్ష
@ c:"నమస్కారం" { >> c "-" }
>> ¶                    // → న-మ-స-్-క-ా-ర-ం-
```

```zymbol
@ i:౧..౧౦ {
    ? i % ౨ == ౦ { @> }
    ? i > ౭ { @! }
    >> i " "
}
>> ¶                    // → 1 3 5 7
```

```zymbol
లెక్క = ౦
@:బాహ్య {
    లెక్క++
    ? లెక్క >= ౩ { @:బాహ్య! }
}
>> లెక్క ¶             // → 3
```

`@` **సమయం** యొక్క గుర్తు: పునరావృతమయ్యే ప్రతిదీ దానిలో నివసిస్తుంది. ఆ సమయాన్ని తగ్గించడానికి మీరు దాని పక్కన ఒక గుర్తును జోడిస్తారు:

- `@!` — `!` **బలవంతం**: ఇప్పుడే లూప్ నుండి నిష్క్రమించండి.
- `@>` — `>` ముందుకు నెట్టివేస్తుంది: తదుపరి రౌండ్కు వెళ్ళండి.
- `@:బాహ్య!` — `:` **ఒక పేరును బంధిస్తుంది**, కాబట్టి ఇది *బాహ్య* అనే పేరు గల లూప్ను కట్ చేస్తుంది, దగ్గరిది కాదు.

మూడు ఆపరేటర్లు మరియు వాటిలో దేనినీ విడిగా గుర్తుంచుకోవలసిన అవసరం లేదు: అవి `@` ప్లస్ ఇది ఏమి చేస్తుందో ఇప్పటికే చెప్పే గుర్తు.

> **నిర్దేశకం ఒక గణన లేదా షరతు.** `పూర్ణాంకం` ఒక గణన, ఒకసారి మూల్యాంకనం చేయబడుతుంది — `@ 0` శరీరాన్ని సున్నా సార్లు అమలు చేస్తుంది. మిగతా అన్నీ షరతు. సత్యత్వం లేదు: `@ []` మరియు `@ 3.5` తిరస్కరించబడతాయి. సేకరణను దాటడానికి `@ x:అంశాలు` ఉపయోగించండి; దానిని లెక్కించడానికి, `@ అంశాలు$#`.

## ఫంక్షన్లు

```zymbol
కూడు(a, b) { <~ a + b }
>> కూడు(౩, ౪) ¶        // → 7
```

```zymbol
కారణాంకం(n) {
    ? n <= ౧ { <~ ౧ }
    <~ n * కారణాంకం(n - ౧)
}
>> కారణాంకం(౫) ¶       // → 120
```

ఒక ఫంక్షన్ ఫైల్ యొక్క వేరియబుల్లను విలువ ద్వారా చదువుతుంది మరియు లోపల వ్రాయడం లోపలే ఉంటుంది:

```zymbol
పరిమితి = ౧౦౦
లోపల(n) { <~ n < పరిమితి }
>> లోపల(౪౨) ¶         // → #1
```

రెండు గుర్తులు దాన్ని మారుస్తాయి మరియు రెండూ **సంతకం మరియు కాల్ సైట్** వద్ద వ్రాయబడతాయి:

```zymbol
పెంచు(లెక్క<~) { లెక్క = లెక్క + ౧ }
మొత్తం = ౦
పెంచు(మొత్తం<~)
>> మొత్తం ¶              // → 1
```

> `p~` అనేది పని చేసే కాపీ — శరీరం దానిని తిరిగి కేటాయించవచ్చు మరియు కాల్ చేసినవారు ప్రభావితం కారు.
> `p<~` అనేది అవుట్పుట్ పారామీటర్ — మార్పు తిరిగి ప్రయాణిస్తుంది. గుర్తు లేకుండా `పెంచు(మొత్తం)` అనేది అర్థపరమైన దోషం: సూచన మరియు సంతకం విభేదించలేవు.

## లాంబ్డాలు మరియు క్లోజర్లు

```zymbol
రెట్టింపు = a -> a * ౨
మొత్తం = (a, b) -> a + b
>> రెట్టింపు(౫) ¶          // → 10
>> మొత్తం(౩, ౭) ¶          // → 10
```

```zymbol
వర్గీకరణ = a -> {
    ? a > ౦ { <~ "ధనాత్మకం" }
    _? a < ౦ { <~ "ఋణాత్మకం" }
    <~ "సున్నా"
}
>> వర్గీకరణ(-౪) ¶         // → ఋణాత్మకం
```

```zymbol
గుణకం = ౩
మూడింతలు = a -> a * గుణకం
>> మూడింతలు(౭) ¶          // → 21
```

```zymbol
కూడిక_నిర్మాత(n) { <~ a -> a + n }
కూడు౧౦ = కూడిక_నిర్మాత(౧౦)
>> కూడు౧౦(౫) ¶           // → 15
```

ఒక లాంబ్డా పారామీటర్లను అస్సలు తీసుకోకపోవచ్చు:

```zymbol
జవాబు = () -> ౪౨
>> జవాబు() ¶           // → 42
```

> ఒక లాంబ్డా ఫైల్ యొక్క వేరియబుల్లను **సృష్టించేటప్పుడు** సంగ్రహిస్తుంది; పేరున్న ఫంక్షన్ వాటిని **పిలిచేటప్పుడు** చదువుతుంది.

## శ్రేణులు

```zymbol
శ్రేణి = [౧, ౨, ౩, ౪, ౫]
>> శ్రేణి[౧] ¶       // → 1   సూచిక 1-ఆధారితం
>> శ్రేణి[-౧] ¶      // → 5   ఋణాత్మకం చివరి నుండి లెక్కిస్తుంది
>> శ్రేణి$# ¶        // → 5   పొడవు
```

```zymbol
శ్రేణి = [౧, ౨, ౩]
>> (శ్రేణి$+ ౬) ¶          // → [1, 2, 3, 6]   జోడించు
>> (శ్రేణి$+[౨] ౯౯) ¶      // → [1, 99, 2, 3]  స్థానం 2 వద్ద ఇన్సర్ట్
>> (శ్రేణి$- ౩) ¶          // → [1, 2]         మొదటి సంభవాన్ని తొలగించు
>> (శ్రేణి$-[౧]) ¶         // → [2, 3]         సూచిక 1 వద్ద తొలగించు
>> (శ్రేణి$[౧..౨]) ¶       // → [1, 2]         ముక్క, రెండు చివరలు చేర్చబడ్డాయి
>> (శ్రేణి$? ౩) ¶          // → #1             ఉందా
```

ఇవన్నీ `$` తో ప్రారంభమవుతాయి, ఇది **సేకరణ** యొక్క గుర్తు మరియు దానిలో ఏమి చేయబడుతుందో చెప్పే గుర్తుతో కొనసాగుతాయి: `#` ఎన్ని, `+` జోడించు, `-` తొలగించు, `?` ఉందా అని అడుగు. మరియు `??` వలె, గుర్తును రెట్టింపు చేయడం అంటే దానిని సమగ్రంగా చేయడం: `$?` ఒక విలువ *ఉందా* అని అడుగుతుంది, `$??` *ఎన్ని ప్రదేశాలలో* ఉంది మరియు వాటన్నింటినీ తిరిగి ఇస్తుంది.

```zymbol
శ్రేణి = [౩, ౧, ౨]
>> (శ్రేణి$^+) ¶     // → [1, 2, 3]   ఆరోహణ
>> (శ్రేణి$^-) ¶     // → [3, 2, 1]   అవరోహణ
```

**ఫలితం యొక్క నియమం.** ఒక ఆపరేటర్ మరియు చుట్టుపక్కల కోడ్ దానితో ఏమి చేస్తుందో నిర్ణయిస్తుంది: ఉపయోగించినట్లయితే, అది **నిర్మిస్తుంది** మరియు అసలు దానిని అలాగే ఉంచుతుంది; విస్మరించబడితే, అది **సవరిస్తుంది**.

```zymbol
శ్రేణి = [౧, ౨, ౩]
కాపీ = శ్రేణి[౨]$~ ౯౯
>> శ్రేణి ¶                // → [1, 2, 3]
>> కాపీ ¶              // → [1, 99, 3]
శ్రేణి[౨]$~ ౯౯
>> శ్రేణి ¶                // → [1, 99, 3]
```

> **`=` ఎప్పుడూ సేకరణలో వ్రాయదు.** `శ్రేణి[2] = 99` Zymbol యొక్క రూపం కాదు — `=` ఒక **పేరుకు** విలువను ఇస్తుంది. సేకరణలో కొంత భాగాన్ని మార్చడం `$~`, ప్రతి సేకరణలో.

`[…]` ఒక రకాన్ని కలిగి ఉంటుంది మరియు తనిఖీ చేయబడుతుంది; ఉద్దేశపూర్వక మిశ్రమం `#[…]` తో **ప్రకటించబడుతుంది**:

```zymbol
మిశ్రమం = #[౧, "రెండు", #౧]
>> మిశ్రమం ¶             // → [1, రెండు, #1]
>> ([౧, ౨] == #[౧, ౨]) ¶ // → #1
```

## బహుమితీయ సూచిక

`>` ఒక గూడులో ఉన్న నిర్మాణంలోకి దిగుతుంది. ఒక బ్రాకెట్ల సమూహం ఒక మూలకాన్ని సూచిస్తుంది, అది ఎంత లోతుగా ఉన్నా.

```zymbol
m = [[౧,౨,౩], [౪,౫,౬], [౭,౮,౯]]
>> m[౨>౩] ¶        // → 6   వరుస 2, నిలువు 3
>> m[-౧>-౧] ¶      // → 9   చివరి వరుస, చివరి నిలువు
```

```zymbol
m = [[౧,౨,౩], [౪,౫,౬], [౭,౮,౯]]
>> m[౧>౧ ; ౨>౨ ; ౩>౩] ¶          // → [1, 5, 9]          చదును: వికర్ణం
>> m[[౧>౧, ౧>౩] ; [౩>౧, ౩>౩]] ¶  // → [[1, 3], [7, 9]]   నిర్మిత: మూలలు
```

```zymbol
m = [[౧,౨,౩], [౪,౫,౬]]
>> (m[౧>౨]$~ ౯౯) ¶      // → [[1, 99, 3], [4, 5, 6]]
```

> `m[1][2]` Zymbol యొక్క రూపం **కాదు**. గొలుసు సూచిక చదవడానికి మరియు వ్రాయడానికి రెండింటికీ తిరస్కరించబడుతుంది — ప్రతి ప్రాప్యతకు ఒక బ్రాకెట్ల సమూహం మరియు `>` అనేది దశల మధ్య వెళ్ళేది.

## నిఘంటువు

పేరున్న ఫీల్డ్లతో కూడిన టపుల్ ఒక నిఘంటువు మరియు v0.0.9 నుండి దీనిని `#(…)` అని వ్రాస్తారు.

```zymbol
వ్యక్తి = #(పేరు: "రమేష్", వయస్సు: ౨౫)
>> వ్యక్తి.పేరు ¶        // → రమేష్
>> వ్యక్తి["వయస్సు"] ¶    // → 25
```

```zymbol
వ్యక్తి = #(పేరు: "రమేష్", వయస్సు: ౨౫)
ఫీల్డ్ = "పేరు"
>> వ్యక్తి[ఫీల్డ్] ¶     // → రమేష్
```

ఇది మార్చగలిగేది, కీలను జోడించవచ్చు మరియు దీనిని దాటవచ్చు:

```zymbol
స్టాక్ = #(బేరి: ౪)
స్టాక్["ఆపిల్"]$~ ౧౦
@ k:స్టాక్ { >> k "=" స్టాక్[k] " " }
>> ¶                    // → బేరి=4 ఆపిల్=10
```

```zymbol
స్టాక్ = #(బేరి: ౪, ఆపిల్: ౧౦)
@ (k, v):స్టాక్ { >> k ":" v " " }
>> ¶                    // → బేరి:4 ఆపిల్:10
```

> `#()` ఖాళీ నిఘంటువు, ఇది `()` కాలేదు — అది ఖాళీ టపుల్ కూడా అయి ఉండాలి. నగ్న `(a: 1)` ఈ సందేశంతో తిరస్కరించబడుతుంది: *a dictionary is written `#(…)`* — «ఒక నిఘంటువు `#(…)` అని వ్రాయబడుతుంది».
> ఒక నిఘంటువు కీ ద్వారా సూచించబడుతుంది, ఎప్పుడూ స్థానం ద్వారా కాదు, కాబట్టి `వ్యక్తి[1]` ఒక దోషం.

## టపుల్స్

టపుల్స్ **మార్చలేని** క్రమబద్ధమైన కంటైనర్లు, ఇవి వివిధ రకాల విలువలను కలిగి ఉంటాయి.

```zymbol
బిందువు = (౧౦, ౨౦)
>> బిందువు[౧] ¶           // → 10
డేటా = (౪౨, "నమస్కారం", #౧, ౩.౧౪)
>> డేటా[౩] ¶            // → #1
```

```zymbol
t = (౧౦, ౨౦, ౩౦)
t2 = t[౨]$~ ౯౯౯
>> t ¶                  // → (10, 20, 30)
>> t2 ¶                 // → (10, 999, 30)
```

> టపుల్ను దాని స్థానంలో సవరించే ఏ ప్రయత్నం అయినా దోషం, ఆపరేటర్ ఏదైనా — మార్చలేనిది విలువ యొక్క లక్షణం, ప్రతి `$` లోపల మినహాయింపు కాదు.

## డీస్ట్రక్చరింగ్

```zymbol
శ్రేణి = [౧౦, ౨౦, ౩౦, ౪౦, ౫౦]
[a, b, c] = శ్రేణి
>> a " " b " " c ¶      // → 10 20 [30, 40, 50]
```

```zymbol
శ్రేణి = [౧౦, ౨౦, ౩౦, ౪౦, ౫౦]
[మొదటి, *మిగిలినవి] = శ్రేణి
>> మొదటి ¶            // → 10
>> మిగిలినవి ¶              // → [20, 30, 40, 50]
```

```zymbol
బిందువు = (౧౦౦, ౨౦౦)
(px, py) = బిందువు
>> px " " py ¶          // → 100 200
```

```zymbol
వ్యక్తి = #(పేరు: "సురేష్", వయస్సు: ౨౫)
#(పేరు: n, వయస్సు: v) = వ్యక్తి
>> n " " v ¶            // → సురేష్ 25
```

> బ్రాకెట్ ఆకారం టైప్ చేయబడింది: `[…]` ఒక శ్రేణిని తీసుకుంటుంది, `(…)` టపుల్, `#(…)` నిఘంటువు. చివరి పేరు **మిగిలిన వాటిని గ్రహిస్తుంది**, కాబట్టి డీస్ట్రక్చరింగ్ ఎప్పుడూ పొడవుతో విఫలం కాదు — `(a, b, c) = (1,2,3,4,5)` `c = (3,4,5)` ఇస్తుంది మరియు ఏమీ మిగలనప్పుడు `##_`.

## ఉన్నత-క్రమ ఫంక్షన్లు

```zymbol
సంఖ్యలు = [౧, ౨, ౩, ౪, ౫]
>> (సంఖ్యలు$> (a -> a * ౨)) ¶ // → [2, 4, 6, 8, 10]
>> (సంఖ్యలు$| (a -> a % ౨ == ౦)) ¶ // → [2, 4]
>> (సంఖ్యలు$< (౦, (జమ, a) -> జమ + a)) ¶ // → 15
```

```zymbol
సంఖ్యలు = [౧, ౨, ౩, ౪, ౫, ౬]
రెట్టింపు(a) { <~ a * ౨ }
పెద్దది(a) { <~ a > ౩ }
>> (సంఖ్యలు$> రెట్టింపు) ¶    // → [2, 4, 6, 8, 10, 12]
>> (సంఖ్యలు$| పెద్దది) ¶    // → [4, 5, 6]
```

```zymbol
డేటాబేస్ = [#(పేరు: "కార్లా", వయస్సు: ౨౮), #(పేరు: "సురేష్", వయస్సు: ౨౫)]
వయస్సు_ప్రకారం = డేటాబేస్$^ (a, b -> a.వయస్సు < b.వయస్సు)
>> వయస్సు_ప్రకారం[౧].పేరు ¶     // → సురేష్
```

> ఒక పేరున్న ఫంక్షన్ HOFకి **బ్రాకెట్లు లేకుండా** వెళుతుంది: `సంఖ్యలు$> రెట్టింపు`. `సంఖ్యలు$> (రెట్టింపు)` అని వ్రాయడం పార్స్ దోషం, ఎందుకంటే `(` ఒక లాంబ్డాను తెరుస్తుంది.

## దోష నిర్వహణ

```zymbol
!? {
    a = ౧౦ / ౦
} :! ##Div {
    >> "సున్నాతో భాగాహారం" ¶  // → సున్నాతో భాగాహారం
} :! {
    >> "ఇతర: " _err ¶
} :> {
    >> "ఎల్లప్పుడూ నడుస్తుంది" ¶        // → ఎల్లప్పుడూ నడుస్తుంది
}
```

| రకం | ఎప్పుడు |
|------|--------|
| `##Div` | సున్నాతో భాగాహారం |
| `##Index` | సూచిక పరిధి వెలుపల |
| `##Key` | నిఘంటువులో కీ లేదు |
| `##Range` | సురక్షిత పూర్ణాంక పరిధి వెలుపల |
| `##Type` | రకం అసమానత |
| `##Parse` | డేటా పార్సింగ్ |
| `##IO` | ఫైల్ / సిస్టమ్ |
| `##Network` | నెట్వర్క్ దోషాలు |
| `##DB` | డేటాబేస్ |
| `##Time` | ఉనికిలో లేని తేదీ |
| `##_` | ఏదైనా దోషం (అన్నీ పట్టేది) |

`!` **దోషం మరియు బలవంతం** యొక్క గుర్తు మరియు ఇది రెండు కుటుంబాలలో ఒకేలా చదవబడుతుంది: `$!` ఒక విలువ దోషమా అని అడుగుతుంది; `$!!`, గుర్తును రెట్టింపు చేయడంతో, అడగకుండా దానిని పైకి వ్యాపిస్తుంది.

> ప్రామాణిక లైబ్రరీ వైఫల్యాలు **మృదు దోష విలువలుగా** తిరిగి వస్తాయి, వీటిని మీరు `$!` తో పరీక్షించవచ్చు లేదా `!?` తో పట్టుకోవచ్చు, ఆపివేయడానికి బదులుగా. `$!!` ఒకదానిని కాల్ చేసినవారికి వ్యాపిస్తుంది.

## మాడ్యూల్స్

```zymbol
# కాల్క్ {
    #> { కూడు, PI }

    PI := ౩.౧౪౧౫౯
    కూడు(a, b) { <~ a + b }
}
```

```zymbol
<# ./కాల్క్ => c

>> c::కూడు(౫, ౩) ¶
>> c.PI ¶
```

```zymbol
# నా_లైబ్రరీ {
    #> { అంతర్గత_కూడు => మొత్తం }

    అంతర్గత_కూడు(a, b) { <~ a + b }
}
```

రెండు మాడ్యూల్ గుర్తులు ఒకే ఆలోచన, ఇప్పుడు ఫైల్లకు వర్తింపజేయబడింది: `#` **ప్రకటన** యొక్క స్థాయి — ఒక వస్తువు *ఏమిటి*, దాని విలువ కాదు — మరియు బాణం కోడ్ ఏ దిశలో ప్రయాణిస్తుందో చెబుతుంది:

```text
<#   బాణం లోపలికి వెళుతుంది: దిగుమతి చేయండి, మరొక ఫైల్ నుండి తీసుకురండి
#>   బాణం బయటకు వెళుతుంది: ఎగుమతి చేయండి, ఇతర ఫైల్లకు అందించండి
```

దిశ గుర్తు ఎల్లప్పుడూ అది సూచించే దిశను ఎదుర్కొంటూ అంచున ఉంటుంది. `<>` ఎడమవైపుకు తిరిగి రావడానికి (ఫంక్షన్ నుండి బయటకు) మరియు `->` కుడివైపుకు వెళ్ళడానికి (లాంబ్డా శరీరంలోకి) ఇదే కారణం.

> **ఒక మాడ్యూల్ ఏమి ఎగుమతి చేస్తుందో ప్రకటిస్తుంది.** `#>` బ్లాక్ తప్పనిసరి — దానిని వదిలివేయడం **E014** మరియు `#> { }` అనేది ఒక మాడ్యూల్ దాని ఉపరితలం ఖాళీగా ఉందని చెప్పే విధానం. `::` ఒక ఫంక్షన్ను పిలుస్తుంది, `.` ఒక కాన్స్టెంట్ను చదువుతుంది. మాడ్యూల్ శరీరంలో దిగుమతులు, ఎగుమతి బ్లాక్, అక్షర ప్రారంభకర్తలు మరియు ఫంక్షన్ నిర్వచనాలు మాత్రమే కనిపించగలవు; అమలు చేయగల ఏదైనా **E013**.

## ప్రామాణిక లైబ్రరీ

స్థానిక మాడ్యూల్స్, ఇతరుల వలె దిగుమతి చేయబడతాయి:

| మాడ్యూల్ | ఫంక్షన్లు |
|--------|-----------|
| `std/math` | `sqrt exp ln log pow abs ceil floor round min max sin cos tan asin acos atan atan2 sinh cosh tanh sigmoid` · `PI` `E` |
| `std/random` | `entero rango peso_f64` |
| `std/json` | `decode decode_map encode` |
| `std/io` | `read write append exists delete list mkdir` |
| `std/net` | `get post post_json head` |
| `std/db` | `connect exec query query_one tx commit rollback` … |
| `std/term` | `width pad_left pad_right center truncate` |
| `std/time` | `now today parts of format add diff` |

```zymbol
<# std/math => m

>> m::sqrt(౧౬.౦) ¶      // → 4
>> m.PI ¶               // → 3.141592653589793
```

```zymbol
<# std/term => t

>> t::width("手番") ¶            // → 4   రెండు గ్లిఫ్లు, నాలుగు నిలువులు
>> "|" t::center("go", 8) "|" ¶ // → |   go   |
```

```zymbol
<# std/time => T

రోజు = T::of(౨౦౨౬, ౧, ౩౧)
>> T::format(రోజు, "%Y-%m-%d") ¶ // → 2026-01-31
>> T::format(T::add(రోజు, ౧, "month"), "%Y-%m-%d") ¶ // → 2026-02-28
```

> `std/term` **ప్రదర్శన నిలువులను** కొలుస్తుంది, అక్షరాలను కాదు: CJK మరియు చాలా ఎమోజీలు 2 నిలువులు, కాబట్టి `t::width` తో పట్టికను వేయండి, ఎప్పుడూ `$#` కాదు.
> `std/time` లో ఒక క్షణం యుగం నుండి మిల్లీసెకన్లు. ఒక రోజు కంటే తక్కువ వ్యవధి, ఒక రోజు నుండి పైకి క్యాలెండర్ — కాబట్టి ఒక నెల అదే రోజున పడుతుంది, క్లాంప్ చేయబడి ఉంటుంది. `తేడా(a, b)` `a - b` కాబట్టి ముందు క్షణం ముందు ఇవ్వడం ప్రతికూల సమాధానం ఇస్తుంది.

## ప్యాకేజీలు

ఒక `.zyp` బహుళ-ఫైల్ ప్రోగ్రామ్ను ఒక పోర్టబుల్ ఫైల్లో బండిల్ చేస్తుంది. ఇది **మూలం** యొక్క ఆర్కైవ్, బైనరీ కాదు, కాబట్టి ఇది `zymbol` బైనరీ నడిచే చోట నడుస్తుంది.

```bash
zymbol package నా_ప్రాజెక్ట్/ --script main.zy -o నా_ప్రాజెక్ట్.zyp
zymbol run నా_ప్రాజెక్ట్.zyp
```

> ఆర్కైవ్ ఒక మానిఫెస్ట్ (`zyp.toml`) కలిగి ఉంటుంది, ఇది దాని ఎంట్రీ స్క్రిప్ట్లు మరియు దానికి అవసరమైన ఇంజన్ వెర్షన్ను ప్రకటిస్తుంది. `zymbol run` దానిని తాత్కాలిక డైరెక్టరీకి సంగ్రహిస్తుంది మరియు అక్కడ నుండి నడుపుతుంది, కాబట్టి కోడ్ పారవశ్యం చేయదగినది, అయితే స్క్రిప్ట్ వ్రాసేది మీ నిజమైన పని డైరెక్టరీలో పడుతుంది. ప్లేగ్రౌండ్ కూడా `.zyp` ఫైల్లను లోడ్ చేస్తుంది.

## సంఖ్యా మోడ్లు

Zymbol సంఖ్యలను **69 యూనికోడ్ అంకెల లిపులు**లో వ్రాయగలదు — తెలుగు, దేవనాగరి, అరబిక్-ఇండిక్, థాయ్, క్లింగాన్ pIqaD, గణిత బోల్డ్, LCD విభాగాలు మరియు మరిన్ని. మోడ్ ప్రక్రియకు ప్రపంచవ్యాప్తంగా ఉంటుంది మరియు అవుట్పుట్ను ప్రభావితం చేస్తుంది; అంకగణితం మారదు.

```zymbol
#౦౯#    // తెలుగు   (U+0C66–U+0C6F)
#०९#    // దేవనాగరి   (U+0966–U+096F)
#٠٩#    // అరబిక్-ఇండిక్ (U+0660–U+0669)
#09#    // ASCII కు రీసెట్
```

```zymbol
a = ౪౨
>> a ¶                  // → 42
#౦౯#
>> a ¶                  // → ౪౨
>> ౩.౧౪ ¶               // → ౩.౧౪
>> #౧ ¶                 // → #౧
#09#
```

ఏదైనా మద్దతు ఉన్న లిపి యొక్క అంకెలు మూలంలో చెల్లుబాటు అయ్యే లిటరల్స్:

```zymbol
#౦౯#
@ i:౧..౫ { >> i " " }
>> ¶                    // → ౧ ౨ ౩ ౪ ౫
#09#
```

చదవడం సౌష్ఠవంగా ఉంటుంది — ఒక అంకె ఏ లిపిలోనైనా అర్థం అవుతుంది:

```zymbol
>> #|"४२"| ¶            // → 42
>> #|'७'| ¶             // → 7
```

> `#` ఎల్లప్పుడూ ASCII, కాబట్టి `#0` ప్రతి లిపిలో అంకె సున్నా నుండి దృశ్యపరంగా వేరుగా ఉంటుంది.
> `#,` మరియు `#^` తమ అంకెలను క్రియాశీల లిపిలో కూడా వ్రాస్తాయి మరియు విభజనలు దానిని అనుసరిస్తాయి — కానీ జత ఎప్పుడూ తారుమారు కాదు: `,` సమూహం చేస్తుంది మరియు `.` విభజిస్తుంది, ప్రతి లిపిలో.

## డేటా ఆపరేటర్లు

```zymbol
f = ##.౪౨         // ఫ్లోట్ కు
i = ###౩.౭        // పూర్ణాంకానికి, గుండ్రంగా  → 4
t = ##!౩.౭        // పూర్ణాంకానికి, కత్తిరించు  → 3
>> f " " i " " t ¶      // → 42 4 3
>> f#? ¶                // → (##., 2, 42)
```

> ఒక ఫ్లోట్ అంకెలుగా ముద్రించబడుతుంది, ఎప్పుడూ ఘాతాంకంగా కాదు మరియు చివరి `.0` ను వదిలివేస్తుంది — `##.42` `42` అని వ్రాస్తుంది మరియు ఇప్పటికీ ఫ్లోట్, `f#?` చూపినట్లు.

```zymbol
>> #|"42"| ¶       // → 42
>> #|"abc"| ¶      // → abc   వైఫల్య-సురక్షితం: ఇన్పుట్ను మార్చకుండా తిరిగి ఇస్తుంది
>> ##!'A' ¶        // → 65    ఒక అక్షరం యొక్క కోడ్ పాయింట్
```

```zymbol
pi = ౩.౧౪౧౫౯౨౬౫
>> #.౨|pi| ¶       // → 3.14          2 దశాంశ స్థానాలకు గుండ్రంగా
>> #!౨|pi| ¶       // → 3.14          2 దశాంశ స్థానాలకు కత్తిరించు
>> #,|౧౨౩౪౫౬౭| ¶   // → 1,234,567     వేల విభజనలు
>> #^|౧౨౩౪౫.౬౭౮| ¶ // → 1.2345678e4  శాస్త్రీయ సంజ్ఞామానం
```

```zymbol
>> 0x41 ¶        // → A   హెక్సాడెసిమల్
>> 0b01000001 ¶  // → A   బైనరీ
>> 0o101 ¶       // → A   ఆక్టల్
>> 0d65 ¶        // → A   దశాంశం
```

> ASCII పరిధిలోని బేస్ లిటరల్ ఒక **అక్షరం**: `0d65 == 'A'` `#1` మరియు `0d65 == 65` `#0`. నాలుగు బేస్లు ఒకే అక్షరాన్ని అక్షరక్రమం చేస్తాయి.

## గుర్తులు ఎలా కలుస్తాయి

మీరు ఈ మాన్యువల్ అంతటా ఒకే విషయాన్ని చూస్తున్నారు: **ఒక ఆపరేటర్ గుర్తుంచుకోవడానికి డ్రాయింగ్ కాదు, ఇది ఒక వరుసలో అనేక గుర్తులు మరియు ప్రతి ఒక్కటి దాని అర్థాన్ని అందిస్తుంది.** ఇప్పుడు మీకు అవన్నీ తెలుసు, ఇక్కడ పూర్తి నమూనా ఉంది.

మొదట **మనం ఏ ప్రపంచంలో ఉన్నాము** అనేది వస్తుంది:

| గుర్తు | ప్రపంచం | మీరు దీన్ని ఎక్కడ చూశారు |
|--------|---------|----------------------------|
| `$` | సేకరణ | `$#` `$+` `$?` `$^-` |
| `@` | సమయం, పునరావృతమయ్యేది | `@!` `@>` `@~` |
| `#` | ఒక వస్తువు *ఏమిటి*, దాని విలువ కాదు | `#?` `#(…)` `<#` `#>` |
| `>>` | ప్రోగ్రామ్ నుండి బయటకు | `>>` `>>!` `>>?` |
| `<<` | ప్రోగ్రామ్ లోపలికి | `<<` `<<\|` `<<\|?` |
| `?` | అడగడం, నిబద్ధత లేకుండా | `?` `_?` `??` `$?` |
| `!` | బలవంతం లేదా దోషం | `@!` `$!` `!?` |

తరువాత **అక్కడ ఏమి చేయబడుతుంది** అనేది వస్తుంది: `+` జోడించు, `-` తొలగించు, `^` క్రమం, `~` సవరించు, `#` లెక్క, `|` ఒక యూనిట్, `:` పేరు బంధించు.

మరియు ఎప్పుడూ విఫలం కాని రెండు నియమాలు:

**ఒక గుర్తును రెట్టింపు చేయడం దానిని సమగ్రంగా చేస్తుంది.** `?` ఒకసారి అడుగుతుంది, `??` అనేక కేసులను పరీక్షిస్తుంది. `$?` ఒక విలువ ఉందా అని అడుగుతుంది, `$??` అది ఉన్న ప్రతి ప్రదేశాన్ని తిరిగి ఇస్తుంది. `!` దోషాన్ని సూచిస్తుంది, `!!` అడగకుండా దానిని వ్యాపిస్తుంది.

**మోడ్ గుర్తు ఎల్లప్పుడూ చివరిదిగా వస్తుంది.** `?` లేదా `!` ఏదైనా *ఎలా* చేయబడుతుందో చెప్పడానికి కనిపించినప్పుడు — సంశయంతో లేదా బలవంతంగా — అవి ఆపరేటర్ యొక్క చివరి గుర్తులు: `$??`, `$!!`, `<<|?`, `@!`, `##!`, `>>!`, `>>?`, `@:బాహ్య!`. వాటి తర్వాత ఎప్పుడూ ఆపరేషన్ ఉండదు.

దీని నుండి ఒక ఆచరణాత్మక విషయం వస్తుంది: **మీరు ఎప్పుడూ చూడని కలయిక, మీరు దానిని చూసే ముందే అర్థవంతంగా ఉంటుంది.** `$` సేకరణ మరియు `^` క్రమం మరియు `-` వ్యతిరేకం అయితే, `$^-` అవరోహణ క్రమంలో క్రమబద్ధీకరిస్తుంది మరియు ఎవరూ మీకు చెప్పవలసిన అవసరం లేదు.

మొత్తం జాబితా ఈ విధంగా పని చేయదు మరియు అది చెప్పడం నటించడం కంటే మంచిది. చాలా ఆపరేటర్లు స్పష్టంగా విడిపోతాయి. ఆరు విడిపోతాయి కానీ వాటి భాగాల కంటే ఎక్కువ అర్థం చేసుకుంటాయి: `!?` `:!` `:>` `|>` `::` `$++`. మరియు పది గుర్తుంచుకోవలసి ఉంటుంది ఎందుకంటే అవి అస్సలు విడిపోవు: `¶` `><` `#1` `#0` `0x` `0b` `0o` `0d` `###` `°`.

> అస్పష్టమైన వాటిని లెక్కించడం, అవి తక్కువ అని ఊహించడం కంటే ఉద్దేశపూర్వకంగా చేయబడింది: అవి భాష యొక్క నిజమైన జ్ఞాపక వ్యయం. పూర్తి సూచన — జాబితా, ప్రకటించబడిన సమానాక్షరాలు మరియు కొత్త ఆపరేటర్ ఉనికిలో ఉండటానికి తీర్చవలసిన నియమాలు — ఇంటర్ప్రెటర్ రిపోజిటరీలో `SYMBOLS.md` లో ఉంది.

## విడుదల మార్పుల చరిత్ర

### v0.0.9 — సేకరణలు నిర్ణయించుకున్నాయి _(సెప్టెంబర్ 2026)_

- **బ్రేకింగ్** నిఘంటువుకు దాని స్వంత సంజ్ఞామానం ఉంది: `#(కీ: విలువ)`. నగ్న `(a: 1)` తిరస్కరించబడింది మరియు `#()` ఖాళీ నిఘంటువు — ఇది `()` ఎప్పుడూ కాలేదు
- **బ్రేకింగ్** సూచిక కేటాయింపు ఉపసంహరించబడింది: `శ్రేణి[i] = v` మరియు అన్ని సమ్మేళన రూపాలు. `=` ఒక **పేరుకు** విలువను ఇస్తుంది; సేకరణలో కొంత భాగాన్ని మార్చడం `$~`
- **బ్రేకింగ్** గొలుసు సూచిక `m[i][j]` చదవడానికి మరియు వ్రాయడానికి రెండింటికీ తిరస్కరించబడింది — `>` అనేది దశల మధ్య వెళ్ళేది
- **బ్రేకింగ్** ఒక మాడ్యూల్ అది ఏమి ఎగుమతి చేస్తుందో ప్రకటించాలి (**E014**); `#> { }` అనేది ఒక మాడ్యూల్ దాని ఉపరితలం ఖాళీగా ఉందని చెప్పే విధానం
- **బ్రేకింగ్** ఒక లూప్ నిర్దేశకం ఒక గణన లేదా షరతు — సత్యత్వం లేదు. `@ []` మరియు `@ 3.5` తిరస్కరించబడతాయి
- **జోడించబడింది** `##_` — యూనిట్ లిటరల్ మరియు ప్రోగ్రామ్ ఏదైనా లేదో అడిగే విధానం
- **జోడించబడింది** `#[…]` — ఒక శ్రేణి దాని మూలక రకాల మిశ్రమం ప్రకటించబడింది
- **జోడించబడింది** `#?` నాలుగు సేకరణలను వేరు చేస్తుంది: `##]` `##[` `##)` `##(`
- **జోడించబడింది** `std/time` — గడియారం మరియు పౌర క్యాలెండర్, మండలాలు మరియు క్యాలెండర్ అంకగణితంతో
- **జోడించబడింది** టాప్-స్థాయి `<~>` ప్రోగ్రామ్ యొక్క నిష్క్రమణ స్థితి
- **జోడించబడింది** `@ (k, v):జతలు` — లూప్ శీర్షికలో ఒక నమూనా
- **జోడించబడింది** `#|c|` 69 లిపులలో ఏదైనా ఒక అంకెను చదువుతుంది; `#,` మరియు `#^` క్రియాశీల లిపిలో వాటి అంకెలను వ్రాస్తాయి
- **మార్చబడింది** `పూర్ణాంకం` ఒక సురక్షిత పూర్ణాంకం, ±(2⁵³ − 1), ప్రతి ఇంజన్లో వైఫల్య-మూసివేత
- **మార్చబడింది** ఒక పేరున్న ఫంక్షన్ కాల్ సమయంలో ఫైల్ యొక్క వేరియబుల్లను విలువ ద్వారా చదువుతుంది
- **మార్చబడింది** ఒక పేరును మాత్రమే చదివే స్టేట్మెంట్ నిశ్శబ్దంగా పాస్ అయ్యే బదులు హెచ్చరిస్తుంది
- **ఇంజన్లు** 666 కార్పస్ ఫైళ్లలో 660 మూడు ఇంజన్లలో ఏకీభవించాయి, 0 విభేదిస్తున్నాయి

### v0.0.8 — స్వయం-విముక్తి, `std/term` మరియు ప్యాకేజీలు _(ఆగస్ట్ 2026)_

- **జోడించబడింది** చివరి ఉపయోగంలో స్వయంచాలక నాశనం — కనిపించదు; కేవలం పీక్ మెమరీని తగ్గిస్తుంది
- **జోడించబడింది** `std/term` — టెర్మినల్ నిలువులలో ప్రదర్శన కొలమానాలు
- **జోడించబడింది** ఒక `అక్షరం` పై `##!` — దాని యూనికోడ్ కోడ్ పాయింట్
- **జోడించబడింది** సరిపోలిక లేదా-నమూనా: `'p' || 'P' => …`, ఏ రకమైన ప్రత్యామ్నాయాలు ఒక శాఖలో
- **జోడించబడింది** Zymbol ప్యాకేజీలు (`.zyp`) — `zymbol package` / `zymbol run pkg.zyp`
- **జోడించబడింది** కాల్ సైట్ వద్ద `<~>` తప్పనిసరి, కాలీ అవుట్పుట్ పారామీటర్ను ప్రకటించినప్పుడు
- **సరిచేయబడింది** రిజిస్టర్ VMలో మాడ్యూల్ సిస్టమ్ సమానత్వం

### v0.0.7 — స్థానిక ప్రామాణిక లైబ్రరీ _(జూలై 2026)_

- **జోడించబడింది** `std/json`, `std/io`, `std/net`, `std/db` (ODBC) — అన్నీ మృదు దోష విలువలతో
