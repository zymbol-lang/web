# คู่มือ Zymbol-Lang

> **ปรับปรุงสำหรับ v0.0.9 — 2026-09-07**

**Zymbol-Lang** เป็นภาษาโปรแกรมเชิงสัญลักษณ์ ไม่มีคำใดในไวยากรณ์ — ทุกโครงสร้างคือสัญลักษณ์ ทำงานเหมือนกันในทุกภาษามนุษย์

- ไม่มี `if`, `while`, `return` — มีเพียง `?`, `@`, `<~`
- Unicode เต็มรูปแบบ — ตัวระบุในภาษาใดหรืออีโมจิใดก็ได้
- ไม่ขึ้นกับภาษามนุษย์ — โค้ดเหมือนกันทุกที่

**เวอร์ชันตัวแปลภาษา**: v0.0.9 | **ความครอบคลุมการทดสอบ**: 660/666 (สามเอนจินเห็นตรงกัน, 0 แตกต่าง)

## ตัวแปรและค่าคงที่

```zymbol
x = ๑๐              // ตัวแปรที่เปลี่ยนแปลงได้
PI := ๓.๑๔๑๕๙       // ค่าคงที่ — การกำหนดใหม่เป็นข้อผิดพลาดรันไทม์
ชื่อ = "สมชาย"
ใช้งาน = #๑         // บูลีนจริง
👋 := "สวัสดี"
```

```zymbol
x = ๑๐    // ๑๐
x += ๕    // ๑๕
x -= ๓    // ๑๒
x *= ๒    // ๒๔
x /= ๓    // ๘
x %= ๓    // ๒
x ^= ๒    // ๔
x++       // ๕
x--       // ๔
```

`°` (เครื่องหมายองศา, U+00B0) จะเริ่มต้นตัวแปรโดยอัตโนมัติเป็นค่ากลางเมื่อใช้งานครั้งแรก:

```zymbol
ตัวเลข = [๓, ๑, ๔, ๑, ๕]
@ n:ตัวเลข {
    °ผลรวม += n
}
>> ผลรวม ¶              // → 14
```

> `°ตัวแปร` (คำนำหน้า) ยึดเหนี่ยวเหนือลูป — ผลลัพธ์อ่านได้หลัง `@`
> `ตัวแปร°` (คำต่อท้าย) ยึดเหนี่ยวในลูป — ตายเมื่อลูปสิ้นสุด

ข้อความที่เป็นเพียงชื่อจะอ่านตัวแปรและทิ้งค่า ดังนั้นจึงเตือน:

```zymbol
ตัวนับ = ๕
ตัวนับ
```

ตัวคอมไพล์จะเตือนดังนี้ (ข้อความของมันเป็นภาษาอังกฤษเสมอ):

```text
warning: this statement does nothing: 'ตัวนับ' is read and discarded
  = help: remove it, or use it — `>> name ¶` to print it
```

หมายความว่า: *«ข้อความนี้ไม่ทำอะไรเลย: 'ตัวนับ' ถูกอ่านและทิ้งไป»*

## ชนิดข้อมูล

| ชนิด | ค่าตรงตัว | แท็ก `#?` | หมายเหตุ |
|------|-----------|-----------|----------|
| จำนวนเต็ม | `๔๒`, `-๗` | `###` | จำนวนเต็มปลอดภัย: ±(2⁵³ − 1) |
| ทศนิยม | `๓.๑๔`, `๑.๕e๑๐` | `##.` | IEEE-754 แบบ double |
| สตริง | `"ข้อความ"` | `##"` | การแทรก: `"สวัสดี {ชื่อ}"` |
| อักขระ | `'A'` | `##'` | จุดรหัส Unicode หนึ่งจุด |
| บูลีน | `#๑`, `#๐` | `##?` | ไม่ใช่ตัวเลข — `#๑ ≠ ๑` |
| อาร์เรย์ | `[๑, ๒, ๓]` | `##]` | ชนิดเดียว ตรวจสอบแล้ว |
| ผสมที่ประกาศ | `#[๑, "สอง"]` | `##[` | ชนิดเดียวกับ `[…]` ไม่ตรวจสอบ |
| ทูเพิล | `(a, b)` | `##)` | ตามตำแหน่ง ไม่เปลี่ยนรูป |
| พจนานุกรม | `#(x: ๑, y: ๒)` | `##(` | ตามคีย์ เปลี่ยนแปลงได้ |
| ฟังก์ชัน | การอ้างอิงฟังก์ชันตั้งชื่อ | `##()` | ชั้นหนึ่ง; แสดง `<funct/N>` |
| แลมบ์ดา | `x -> x * ๒` | `##->` | ชั้นหนึ่ง; แสดง `<lambd/N>` |
| หน่วย | `##_` | `##_` | ไม่มี — ไม่มี null |

```zymbol
>> ๔๒#? ¶               // → (###, 2, 42)
>> [๑, ๒, ๓]#? ¶        // → (##], 3, [1, 2, 3])
>> #(x: ๑)#? ¶          // → (##(, 1, #(x: 1))
```

จำนวนเต็มที่ออกนอกช่วงปลอดภัยเป็นข้อผิดพลาดที่จับได้ ไม่ใช่การห่อแบบเงียบ:

```zymbol
!? {
    >> (๙๐๐๗๑๙๙๒๕๔๗๔๐๙๙๑ + ๑) ¶
} :! ##Range {
    >> "นอกช่วง" ¶ // → นอกช่วง
}
```

`##_` เป็นวิธีที่โปรแกรมถามว่ามีบางสิ่งหายไปหรือไม่:

```zymbol
ไม่มีอะไร() { }
ค่า = ไม่มีอะไร()
>> (ค่า == ##_) ¶     // → #1
```

## เอาต์พุตและอินพุต

```zymbol
ชื่อ = "สมชาย"
ผลรวม = ๓
>> "สวัสดี" ¶             // → สวัสดี
>> "a=" ชื่อ " b=" ผลรวม ¶ // → a=สมชาย b=3
>> ผลรวม#? ¶            // → (###, 1, 3)
```

```zymbol
<< ชื่อ
<< "ใส่ชื่อของคุณ: " ชื่อ
<< ###(๔) "อายุ: " อายุ
```

**ดูรูปร่างของสองสัญลักษณ์** `>>` ชี้ออกด้านนอก: ดึงข้อมูลออกจากโปรแกรม `<<` ชี้เข้าด้านใน: นำข้อมูลเข้าโปรแกรม ไม่มีอะไรให้จำตรงนี้ — ลูกศรแสดงทิศทางที่ข้อมูลเดินทาง และแนวคิดเดียวกันนี้กลับมาในทุกสัญลักษณ์ที่เคลื่อนย้ายสิ่งใด

> `¶` และ `\\` เป็นการขึ้นบรรทัดใหม่ที่เทียบเท่ากัน `>>` ไม่เพิ่มให้เลย
> ตัวระบุชนิดก่อนพรอมป์จะตรวจสอบขณะอ่านและถามซ้ำจนกว่าค่าจะถูกต้อง:
> `##.` ทศนิยม · `##.(T,D)` ทศนิยมตำแหน่ง · `###(N)` จำนวนเต็ม · `##"(N)"` ข้อความ · `##'` อักขระหนึ่งตัว

ที่ระดับบนสุดของไฟล์ `<~` คือสถานะการออกของโปรแกรม:

```zymbol
>> "กำลังตรวจสอบ" ¶      // → กำลังตรวจสอบ
<~ ๐
```

## องค์ประกอบ TUI

โอเปอเรเตอร์อินเทอร์เฟซเทอร์มินัลสำหรับโปรแกรมแบบโต้ตอบ ส่วนใหญ่ต้องใช้บล็อก `>>| { }` (หน้าจอทางเลือก + โหมดดิบ)

```zymbol
>>| {
    >>!
    >>~ (๑, ๑, ๐, ๑๐) > "กำลังทำงาน"
    @~ ๑๐๐๐
    >>~ (๒, ๑) > "เสร็จแล้ว"
}
```

```zymbol
>>| {
    [แถว, คอลัมน์] = >>?
    >>~ (๑, ๑) > "เทอร์มินัล: " แถว " x " คอลัมน์
    <<| ปุ่ม
    >>~ (๒, ๑) > "กด: " ปุ่ม
}
```

ที่นี่คุณจะเห็นว่าทำไมสัญลักษณ์จึงรวมกันแทนที่จะคูณกัน คุณรู้อยู่แล้วว่า `<<` คืออินพุตและ `?` ถามโดยไม่ผูกมัด มีเพียงสัญลักษณ์เดียวที่ใหม่:

- `|` คือ **หน่วยเดียว** ไม่ใช่ทั้งกระแส

ด้วยเหตุนี้ โอเปอเรเตอร์แป้นพิมพ์ทั้งสองจึงอ่านตัวเองได้:

```text
<<        |             ?
อินพุต    หน่วยเดียว     โดยไม่ผูกมัด

<<|   รับปุ่มหนึ่งปุ่ม และรอจนกว่าจะมี
<<|?  ดูว่ามีปุ่มอยู่ไหม และดำเนินการต่อถ้าไม่มี
```

เช่นเดียวกันอีกด้าน: `>>` ส่งออก `>>!` ส่งออก **ด้วยกำลัง** (ล้างทั้งหน้าจอ) ขณะที่ `>>?` **ถาม** แทนที่จะเขียน (เทอร์มินัลใหญ่แค่ไหน) สัญลักษณ์ทางขวาคือตัวที่เปลี่ยนโหมด และมันมาสุดท้ายเสมอ

> `>>!` ล้างหน้าจอ `>>?` ส่งคืน `[แถว, คอลัมน์]` `@~ N` นอน N มิลลิวินาที
> `<<|` อ่านการกดปุ่มหนึ่งครั้ง (บล็อก); `<<|?` ตรวจสอบโดยไม่บล็อก (`'\0'` ถ้าไม่มี)
> ปุ่มลูกศรจะถูกถอดรหัสเป็น `'↑' '↓' '←' '→'`; ESC คือรหัสจุด 27
> ทูเพิลเอาต์พุตตามตำแหน่ง: `(แถว, คอลัมน์, BKS, หน้า, หลัง)` — ช่องใดก็ได้ละเว้นด้วยจุลภาค (`>>~ (,,, ๑๙๖) > "แดง"`)
> บิตมาสก์ BKS: `1`=หนา, `2`=เอียง, `4`=ขีดเส้นใต้ พาเลต ANSI 256 สี (`0`=ค่าเริ่มต้นของเทอร์มินัล)

## การควบคุมกระแส

```zymbol
x = ๗
? x > ๑๐๐ {
    >> "ใหญ่" ¶
} _? x > ๐ {
    >> "บวก" ¶     // → บวก
} _ {
    >> "ลบ" ¶
}
```

ที่นี่มีสองสัญลักษณ์ใหม่ และสัญลักษณ์ที่สามมาจากการรวมเข้าด้วยกัน:

- `?` คือ **การถาม**: เปิดเงื่อนไข
- `_` คือ **สิ่งที่ไม่ได้ระบุ**: สาขาที่เหลือเมื่อไม่มีคำถามใดตรงกัน
- `_?` คือทั้งสองติดกัน: *ถ้าไม่มีอะไรตรง ถามอีกครั้ง*

นี่คือเหตุผลที่ `_?` เขียนแบบนี้ มันไม่ใช่สัญลักษณ์ใหม่ให้เรียน — มันคือ `_` ตามด้วย `?` และมันหมายถึงสิ่งที่สองส่วนของมันหมายถึง อ่านตามลำดับ

> ปีกกา `{ }` เป็น **ข้อบังคับ** แม้กระทั่งสำหรับข้อความเดียว

```zymbol

    ตัวนับ++
    ? ตัวนับ >= ๓ { @:นอก! }
}
>> ตัวนับ ¶             // → 3
```

`@` คือสัญลักษณ์ของ **เวลา**: ทุกสิ่งที่ซ้ำอยู่ในนั้น ในการตัดเวลานั้นให้สั้นลง คุณเพิ่มสัญลักษณ์ข้างๆ:

- `@!` — `!` คือ **กำลัง**: ออกจากลูปทันที
- `@>` — `>` ดันไปข้างหน้า: ไปรอบถัดไป
- `@:นอก!` — `:` **ผูกชื่อ** ดังนั้นนี่ตัดลูปที่ *ชื่อ* นอก ไม่ใช่ที่ใกล้ที่สุด

โอเปอเรเตอร์สามตัว และไม่มีตัวใดต้องจำแยก: มันคือ `@` บวกกับสัญลักษณ์ที่บอกแล้วว่ามันทำอะไร

> **ตัวระบุคือจำนวนหรือเงื่อนไข** `จำนวนเต็ม` คือจำนวน ประเมินครั้งเดียว — `@ 0` ทำเนื้อความศูนย์ครั้ง อื่นๆ คือเงื่อนไข ไม่มีความจริง: `@ []` และ `@ 3.5` ถูกปฏิเสธ ในการสำรวจคอลเลกชันใช้ `@ x:รายการ`; ในการนับ `@ รายการ$#`

## ฟังก์ชัน

```zymbol
บวก(a, b) { <~ a + b }
>> บวก(๓, ๔) ¶        // → 7
```

```zymbol
แฟกทอเรียล(n) {
    ? n <= ๑ { <~ ๑ }
    <~ n * แฟกทอเรียล(n - ๑)
}
>> แฟกทอเรียล(๕) ¶       // → 120
```

ฟังก์ชันอ่านตัวแปรของไฟล์ตามค่า และการเขียนข้างในก็อยู่ข้างใน:

```zymbol
ขีดจำกัด = ๑๐๐
ข้างใน(n) { <~ n < ขีดจำกัด }
>> ข้างใน(๔๒) ¶         // → #1
```

สองสัญลักษณ์เปลี่ยนสิ่งนั้น และทั้งคู่เขียน **ในลายเซ็นและที่จุดเรียกใช้**:

```zymbol
เพิ่ม(ตัวนับ<~) { ตัวนับ = ตัวนับ + ๑ }
ผลรวม = ๐
เพิ่ม(ผลรวม<~)
>> ผลรวม ¶              // → 1
```

> `p~` คือสำเนาที่ใช้งานได้ — เนื้อความสามารถกำหนดใหม่ได้ และผู้เรียกไม่ได้รับผลกระทบ
> `p<~` คือพารามิเตอร์เอาต์พุต — การเปลี่ยนแปลงกลับไป การเรียก `เพิ่ม(ผลรวม)` โดยไม่มีสัญลักษณ์เป็นข้อผิดพลาดทางความหมาย: คำอธิบายและลายเซ็นไม่สามารถแยกจากกันได้

```zymbol
สองเท่า = x -> x * ๒
บวก = (a, b) -> a + b

>> บวก(๓, ๗) ¶          // → 10
```

```zymbol
จำแนก = x -> {
    ? x > ๐ { <~ "บวก" }
    _? x < ๐ { <~ "ลบ" }
    <~ "ศูนย์"
```

## อาร์เรย์

```zymbol
อาร์เรย์ = [๑, ๒, ๓, ๔, ๕]
>> อาร์เรย์[๑] ¶       // → 1   การจัด ดัชนี เริ่มจาก 1
>> อาร์เรย์[-๑] ¶      // → 5   ค่าลบนับจากท้าย
>> อาร์เรย์$# ¶        // → 5   ความยาว
```

```zymbol
อาร์เรย์ = [๑, ๒, ๓]
>> (อาร์เรย์$+ ๖) ¶          // → [1, 2, 3, 6]   เพิ่ม
>> (อาร์เรย์$+[๒] ๙๙) ¶      // → [1, 99, 2, 3]  แทรกที่ตำแหน่ง 2
>> (อาร์เรย์$- ๓) ¶          // → [1, 2]         ลบรายการแรกที่ตรง
>> (อาร์เรย์$-[๑]) ¶         // → [2, 3]         ลบที่ ดัชนี 1
>> (อาร์เรย์$[๑..๒]) ¶       // → [1, 2]         ชิ้น ส่วนทั้งสองปลายรวม
>> (อาร์เรย์$? ๓) ¶          // → #1             มี
```

ทั้งหมดเริ่มด้วย `$` ซึ่งเป็นสัญลักษณ์ของ **คอลเลกชัน** และดำเนินด้วยสัญลักษณ์ที่บอกว่าทำอะไรในนั้น: `#` กี่รายการ, `+` เพิ่ม, `-` ลบ, `?` ถามว่ามีหรือไม่ และเช่นเดียวกับ `??` การเพิ่มสัญลักษณ์เป็นสองเท่าคือการทำอย่างละเอียด: `$?` ถาม *ว่ามี* ค่าหรือไม่, `$??` ถาม *ที่กี่ตำแหน่ง* และคืนทั้งหมด

```zymbol
อาร์เรย์ = [๓, ๑, ๒]
>> (อาร์เรย์$^+) ¶     // → [1, 2, 3]   ขึ้น
>> (อาร์เรย์$^-) ¶     // → [3, 2, 1]   ลง
```

**กฎของผลลัพธ์** โอเปอเรเตอร์เดียว และสิ่งที่โค้ดโดยรอบทำกับมันเป็นตัวตัดสิน: ถ้าใช้ **สร้าง** และปล่อยต้นฉบับไว้; ถ้าทิ้ง **แก้ไข**

```zymbol
อาร์เรย์ = [๑, ๒, ๓]
สำเนา = อาร์เรย์[๒]$~ ๙๙
>> อาร์เรย์ ¶                // → [1, 2, 3]
>> สำเนา ¶              // → [1, 99, 3]
อาร์เรย์[๒]$~ ๙๙
>> อาร์เรย์ ¶                // → [1, 99, 3]
```

> **`=` ไม่เคยเขียนในคอลเลกชัน** `อาร์เรย์[๒] = ๙๙` ไม่ใช่รูปแบบของ Zymbol — `=` ให้ค่าแก่ **ชื่อ** การเปลี่ยนส่วนหนึ่งของคอลเลกชันคือ `$~` ในทุกคอลเลกชัน

`[…]` มีชนิดเดียวและถูกตรวจสอบ; การผสมโดยเจตนา **ประกาศ** ด้วย `#[…]`:

```zymbol
ผสม = #[๑, "สอง", #๑]
>> ผสม ¶             // → [1, สอง, #1]
>> ([๑, ๒] == #[๑, ๒]) ¶ // → #1
```

## การจัด ดัชนี แบบหลายมิติ

`>` เดินลงในโครงสร้างที่ซ้อนกัน กลุ่มวงเล็บเหลี่ยมหนึ่งกลุ่มกล่าวถึงองค์ประกอบหนึ่ง ไม่ว่ามันจะลึกแค่ไหน

```zymbol
ม = [[๑,๒,๓], [๔,๕,๖], [๗,๘,๙]]
>> ม[๒>๓] ¶        // → 6   แถว 2, คอลัมน์ 3
>> ม[-๑>-๑] ¶      // → 9   แถวสุดท้าย, คอลัมน์สุดท้าย
```

```zymbol
ม = [[๑,๒,๓], [๔,๕,๖], [๗,๘,๙]]
>> ม[๑>๑ ; ๒>๒ ; ๓>๓] ¶          // → [1, 5, 9]          แบน: เส้นทแยง
>> ม[[๑>๑, ๑>๓] ; [๓>๑, ๓>๓]] ¶  // → [[1, 3], [7, 9]]   มีโครงสร้าง: มุม
```

```zymbol
ม = [[๑,๒,๓], [๔,๕,๖]]
>> (ม[๑>๒]$~ ๙๙) ¶      // → [[1, 99, 3], [4, 5, 6]]
```

> `ม[๑][๒]` **ไม่ใช่** รูปแบบของ Zymbol ดัชนี แบบลูกโซ่ถูกปฏิเสธทั้งการอ่านและการเขียน — กลุ่มวงเล็บเหลี่ยมหนึ่งต่อการเข้าถึงหนึ่ง และ `>` คือสิ่งที่อยู่ระหว่างขั้น

## พจนานุกรม

ทูเพิลที่มีฟิลด์ตั้งชื่อคือพจนานุกรม และตั้งแต่ v0.0.9 เขียนเป็น `#(…)`

```zymbol
บุคคล = #(ชื่อ: "สมชาย", อายุ: ๒๕)
>> บุคคล.ชื่อ ¶        // → สมชาย
>> บุคคล["อายุ"] ¶    // → 25
```

```zymbol
บุคคล = #(ชื่อ: "สมชาย", อายุ: ๒๕)
ฟิลด์ = "ชื่อ"
>> บุคคล[ฟิลด์] ¶     // → สมชาย
```

มันเปลี่ยนแปลงได้ เพิ่มคีย์ได้ และสามารถสำรวจได้:

```zymbol
สต็อก = #(ลูกแพร์: ๔)
สต็อก["แอปเปิล"]$~ ๑๐
@ k:สต็อก { >> k "=" สต็อก[k] " " }
>> ¶                    // → ลูกแพร์=4 แอปเปิล=10
```

```zymbol
สต็อก = #(ลูกแพร์: ๔, แอปเปิล: ๑๐)
@ (k, v):สต็อก { >> k ":" v " " }
>> ¶                    // → ลูกแพร์:4 แอปเปิล:10
```

> `#()` คือพจนานุกรมว่าง ซึ่ง `()` ไม่สามารถเป็นได้ — มันจะต้องเป็นทูเพิลว่างด้วย `(x: 1)` เปล่าๆ ถูกปฏิเสธด้วยข้อความนี้: *a dictionary is written `#(…)`* — «พจนานุกรมเขียนเป็น `#(…)`»
> พจนานุกรมเข้าถึงด้วยคีย์ ไม่เคยด้วยตำแหน่ง ดังนั้น `บุคคล[1]` เป็นข้อผิดพลาด

## การจัดการข้อผิดพลาด

```zymbol
!? {
    x = ๑๐ / ๐
} :! ##Div {
    >> "หารด้วยศูนย์" ¶  // → หารด้วยศูนย์
} :! {
    >> "อื่นๆ: " _err ¶
} :> {
    >> "ทำงานเสมอ" ¶        // → ทำงานเสมอ
}
```

| ชนิด | เมื่อ |
|------|------|
| `##Div` | หารด้วยศูนย์ |
| `##Index` | ดัชนี นอกขอบเขต |
| `##Key` | ไม่มีคีย์ในพจนานุกรม |
| `##Range` | นอกช่วงจำนวนเต็มปลอดภัย |
| `##Type` | ชนิดไม่ตรงกัน |
| `##Parse` | การแยกวิเคราะห์ข้อมูล |
| `##IO` | ไฟล์ / ระบบ |
| `##Network` | ข้อผิดพลาดเครือข่าย |
| `##DB` | ฐานข้อมูล |
| `##Time` | วันที่ที่ไม่มีอยู่ |
| `##_` | ข้อผิดพลาดใด (จับทั้งหมด) |

`!` เป็นสัญลักษณ์ของ **ข้อผิดพลาดและกำลัง** และอ่านเหมือนกันในทั้งสองตระกูล: `$!` ถามค่าว่าเป็นข้อผิดพลาดหรือไม่; `$!!` ที่สัญลักษณ์เป็นสองเท่า แพร่ขึ้นโดยไม่ถาม

> ความล้มเหลวของไลบรารีมาตรฐานกลับมาเป็น **ค่าข้อผิดพลาดแบบอ่อน** ที่คุณทดสอบด้วย `$!` หรือจับด้วย `!?` แทนที่จะยกเลิก `$!!` แพร่หนึ่งไปยังผู้เรียก

## โมดูล

```zymbol
# เครื่องคิด {
    #> { บวก, PI }

    PI := ๓.๑๔๑๕๙
    บวก(a, b) { <~ a + b }
}
```

```zymbol
<# ./เครื่องคิด => ค

>> ค::บวก(๕, ๓) ¶
>> ค.PI ¶
```

```zymbol
# ห้องสมุดของฉัน {
    #> { บวกภายใน => รวม }

    บวกภายใน(a, b) { <~ a + b }
}
```

สองสัญลักษณ์ของโมดูลคือแนวคิดเดียวกัน ตอนนี้ใช้กับไฟล์: `#` คือระดับของ **การประกาศ** — สิ่งที่ *เป็น* ไม่ใช่ค่าของมัน — และลูกศรบอกว่าทิศทางที่โค้ดเดินทาง:

```text
<#   ลูกศรเข้า: นำเข้า, ดึงจากไฟล์อื่น
#>   ลูกศรออก: ส่งออก, เสนอให้ไฟล์อื่น
```

สัญลักษณ์ทิศทางอยู่ที่ขอบที่หันไปทางทิศที่ชี้เสมอ นี่คือเหตุผลเดียวกับที่ `<~` กลับซ้าย (ออกจากฟังก์ชัน) และ `->` เข้าขวา (เข้าสู่เนื้อความแลมบ์ดา)

> **โมดูลประกาศสิ่งที่มันส่งออก** บล็อก `#>` เป็นข้อบังคับ — การละเว้นเป็น **E014** และ `#> { }` คือวิธีที่โมดูลบอกว่าพื้นผิวของมันว่างเปล่า `::` เรียกฟังก์ชัน `.` อ่านค่าคงที่ เฉพาะการนำเข้า บล็อกการส่งออก ตัวเริ่มต้นตรงตัว และนิยามฟังก์ชันเท่านั้นที่ปรากฏในเนื้อความโมดูล; สิ่งใดที่รันได้เป็น **E013**

## โหมดตัวเลข

Zymbol เขียนตัวเลขใน **69 ระบบตัวอักษรของ Unicode** — เทวนาครี อาหรับ-อินเดีย ไทย คลิงออน pIqaD ตัวหนาคณิตศาสตร์ ส่วน LCD และอื่นๆ โหมดเป็นแบบทั่วทั้งโปรเซสและส่งผลต่อเอาต์พุต; การคำนวณไม่เปลี่ยน

```zymbol
#๐๙#    // ไทย   (U+0E50–U+0E59)
#०९#    // เทวนาครี   (U+0966–U+096F)
#٠٩#    // อาหรับ-อินเดีย (U+0660–U+0669)
#09#    // รีเซ็ตเป็น ASCII
```

```zymbol
x = ๔๒
>> x ¶                  // → 42
#๐๙#
>> x ¶                  // → ๔๒
>> ๓.๑๔ ¶               // → ๓.๑๔
>> #๑ ¶                 // → #๑
#09#
```

ตัวเลขของระบบตัวอักษรใดที่รองรับเป็นค่าตรงตัวที่ถูกต้องในซอร์ส:

```zymbol
#๐๙#
@ i:๑..๕ { >> i " " }
>> ¶                    // → ๑ ๒ ๓ ๔ ๕
#09#
```

การอ่านสมมาตร — ตัวเลขเข้าใจได้ในระบบตัวอักษรใด:

```zymbol
>> #|"४२"| ¶            // → 42
>> #|'७'| ¶             // → 7
```

> `#` เป็น ASCII เสมอ ดังนั้น `#0` ยังมองแยกจากเลขศูนย์ในทุกระบบตัวอักษร
> `#,` และ `#^` เขียนตัวเลขในระบบตัวอักษรที่ใช้งานอยู่ และตัวคั่นตามมา — แต่คู่ไม่เคยกลับ: `,` จัดกลุ่ม และ `.` แบ่ง ในทุกระบบตัวอักษร

## สัญลักษณ์รวมกันอย่างไร

คุณเห็นสิ่งเดียวกันตลอดคู่มือนี้: **โอเปอเรเตอร์ไม่ใช่ภาพวาดให้จำ แต่เป็นสัญลักษณ์หลายตัวเรียงกัน และแต่ละตัวให้ความหมายของมัน** ตอนนี้คุณรู้จักทั้งหมดแล้ว นี่คือรูปแบบเต็ม

ก่อนอื่น **เราอยู่ในโลกไหน**:

| สัญลักษณ์ | โลก | คุณเห็นที่ |
|-----------|-----|-----------|
| `$` | คอลเลกชัน | `$#` `$+` `$?` `$^-` |
| `@` | เวลา ทุกสิ่งที่ซ้ำ | `@!` `@>` `@~` |
| `#` | สิ่งที่ *เป็น* ไม่ใช่ค่าของมัน | `#?` `#(…)` `<#` `#>` |
| `>>` | ออกจากโปรแกรม | `>>` `>>!` `>>?` |
| `<<` | เข้าโปรแกรม | `<<` `<<\|` `<<\|?` |
| `?` | ถาม โดยไม่ผูกมัด | `?` `_?` `??` `$?` |
| `!` | กำลัง หรือข้อผิดพลาด | `@!` `$!` `!?` |

แล้ว **ทำอะไรที่นั่น**: `+` เพิ่ม, `-` ลบ, `^` เรียงลำดับ, `~` แก้ไข, `#` นับ, `|` หนึ่งหน่วย, `:` ผูกชื่อ

และกฎสองข้อที่ไม่เคยล้มเหลว:

**การเพิ่มสัญลักษณ์เป็นสองเท่าทำให้ละเอียดถี่ถ้วน** `?` ถามครั้งเดียว `??` ทดสอบหลายกรณี `$?` ถามว่ามีค่าหรือไม่ `$??` คืนทุกตำแหน่งที่มี `!` ระบุข้อผิดพลาด `!!` แพร่โดยไม่ถาม

**สัญลักษณ์โหมดมาสุดท้ายเสมอ** เมื่อ `?` หรือ `!` ปรากฏเพื่อบอกว่า *อย่างไร* — ลังเลหรือบังคับ — พวกมันเป็นสัญลักษณ์สุดท้ายของโอเปอเรเตอร์: `$??`, `$!!`, `<<|?`, `@!`, `##!`, `>>!`, `>>?`, `@:นอก!` ไม่มีโอเปอเรชันหลังจากนั้น

สิ่งที่เป็นประโยชน์ตามมา: **การรวมที่คุณไม่เคยเห็นก็มีความหมายก่อนที่คุณจะค้นหา** ถ้า `$` คือคอลเลกชัน และ `^` คือลำดับ และ `-` คือย้อนกลับ แล้ว `$^-` เรียงจากมากไปน้อย และไม่มีใครต้องบอก

ไม่ใช่ทุกอย่างในบัญชีทำงานแบบนี้ และพูดมันออกมาดีกว่าแกล้งทำ ส่วนใหญ่แยกออกได้สะอาด หกแยกได้แต่หมายถึงมากกว่าส่วนของมัน: `!?` `:!` `:>` `|>` `::` `$++` และสิบต้องจำเพราะไม่แยกเลย: `¶` `><` `#1` `#0` `0x` `0b` `0o` `0d` `###` `°`

> การนับที่ทึบแสงแทนที่จะสันนิษฐานว่ามีน้อยเป็นเจตนา: เป็นค่าใช้จ่ายการจำจริงของภาษา เอกสารอ้างอิงเต็ม — บัญชี, โฮโมกราฟที่ประกาศ, และกฎที่โอเปอเรเตอร์ใหม่ต้องพอใจจึงจะมีอยู่ — อยู่ที่ `SYMBOLS.md` ในที่เก็บตัวแปลภาษา

### v0.0.9 — คอลเลกชันตัดสินใจ _(กันยายน ๒๐๒๖)_

- **ทำลาย** พจนานุกรมมีสัญกรณ์ของตัวเอง: `#(คีย์: ค่า)` `(x: 1)` เปล่าถูกปฏิเสธ และ `#()` เป็นพจนานุกรมว่าง — ซึ่ง `()` ไม่เคยเป็นได้
- **ทำลาย** การกำหนด ดัชนี ถูกถอน: `อาร์เรย์[i] = v` และทุกรูปแบบผสม `=` ให้ค่าแก่ **ชื่อ**; การเปลี่ยนส่วนหนึ่งของคอลเลกชันคือ `$~`
- **ทำลาย** ดัชนี ลูกโซ่ `m[i][j]` ถูกปฏิเสธทั้งการอ่านและการเขียน — `>` คือสิ่งที่อยู่ระหว่างขั้น
- **ทำลาย** โมดูลต้องประกาศสิ่งที่มันส่งออก (**E014**); `#> { }` คือวิธีที่โมดูลบอกว่าพื้นผิวว่าง
- **ทำลาย** ตัวระบุลูปคือจำนวนหรือเงื่อนไข — ไม่มีความจริง `@ []` และ `@ 3.5` ถูกปฏิเสธ
- **เพิ่ม** `##_` — ค่าตรงตัวหน่วย และวิธีที่โปรแกรมถามว่าบางสิ่งหายไป
- **เพิ่ม** `#[…]` — อาร์เรย์ที่การผสมชนิดขององค์ประกอบถูกประกาศ
- **เพิ่ม** `#?` แยกสี่คอลเลกชัน: `##]` `##[` `##)` `##(`
- **เพิ่ม** `std/time` — นาฬิกาและปฏิทินพลเรือน พร้อมเขตเวลาและการคำนวณปฏิทิน
- **เพิ่ม** `<~>` ที่ระดับบนสุดคือสถานะการออกของโปรแกรม
- **เพิ่ม** `@ (k, v):คู่` — แพทเทิร์นในหัวลูป
- **เพิ่ม** `#|c|` อ่านตัวเลขในหนึ่งใน 69 ระบบตัวอักษร; `#,` และ `#^` เขียนในระบบที่ใช้งาน
- **เปลี่ยน** `จำนวนเต็ม` เป็นจำนวนเต็มปลอดภัย ±(2⁵³ − 1) ปิดเมื่อล้มเหลวในทุกเอนจิน
- **เปลี่ยน** ฟังก์ชันตั้งชื่ออ่านตัวแปรของไฟล์ในเวลาที่เรียก ตามค่า
- **เปลี่ยน** ข้อความที่อ่านเพียงชื่อเตือนแทนที่จะผ่านเงียบ
- **เอนจิน** 660 จาก 666 ไฟล์คลังเห็นตรงกันในทั้งสามเอนจิน 0 แตกต่าง

### v0.0.8 — ปล่อยอัตโนมัติ, `std/term` และแพ็กเกจ _(สิงหาคม ๒๐๒๖)_

- **เพิ่ม** การทำลายอัตโนมัติในการใช้ครั้งสุดท้าย — มองไม่เห็น; ลดความจำสูงสุดเท่านั้น
- **เพิ่ม** `std/term` — มาตรวัดการแสดงในคอลัมน์เทอร์มินัล
- **เพิ่ม** `##!` บน `อักขระ` — จุดรหัส Unicode
- **เพิ่ม** แพทเทิร์นหรือในการจับคู่: `'p' || 'P' => …` ทางเลือกใดชนิดในสาขาเดียว
- **เพิ่ม** แพ็กเกจ Zymbol (`.zyp`) — `zymbol package` / `zymbol run pkg.zyp`
- **เพิ่ม** `<~>` ที่จุดเรียกใช้เป็นข้อบังคับเมื่อผู้ถูกเรียกประกาศพารามิเตอร์เอาต์พุต
- **แก้ไข** ความเท่าเทียมของระบบโมดูลใน VM รีจิสเตอร์

### v0.0.7 — ไลบรารีมาตรฐานพื้นเมือง _(กรกฎาคม ๒๐๒๖)_

- **เพิ่ม** `std/json`, `std/io`, `std/net`, `std/db` (ODBC) — ทั้งหมดมีค่าข้อผิดพลาดอ่อน
- **เพิ่ม** อินพุตชนิด/ตรวจสอบ: `<< ##.(5,2) "ราคา: " p`
- **เพิ่ม** โอเปอเรเตอร์คำต่อท้ายใน `>>` โดยตรง — ไม่ต้องวงเล็บ
- **เปลี่ยน** ตัวจัดรูปแบบปิดเมื่อล้มเหลว: ปฏิเสธเขียนเอาต์พุตที่อ่านซ้ำไม่ได้

### v0.0.6 — การขัดเกลาและไลบรารีวิทยาศาสตร์ _(มิถุนายน ๒๐๒๖)_

- **ทำลาย** `=>` แทน `:` ในสาขาจับคู่และ `<=` ในนามแฝงนำเข้า/ส่งออก
- **เพิ่ม** `std/math` และ `std/random`
- **เพิ่ม** การอัปเดตพจนานุกรมด้วยคีย์: `d["k"]$~ ค่า`

### v0.0.5 — องค์ประกอบ TUI และนิยามร้อน _(พฤษภาคม ๒๐๒๖)_

- **เพิ่ม** บล็อก TUI `>>| { }` เอาต์พุตตามตำแหน่ง `>>~` อินพุตปุ่ม `<<|` และ `<<|?`
- **เพิ่ม** `>>!` ล้างหน้าจอ, `>>?` ขนาดเทอร์มินัล, `@~ N` นอน
- **เพิ่ม** นิยามร้อน `°x` / `x°` และสตริงซ้ำ `$*`

### v0.0.4 — ดัชนี เริ่ม 1 และฟังก์ชันชั้นหนึ่ง _(เมษายน ๒๐๒๖)_

- **ทำลาย** ดัชนี ทั้งหมด **เริ่ม 1** — `อาร์เรย์[1]` เป็นองค์ประกอบแรก
- **เพิ่ม** ฟังก์ชันตั้งชื่อเป็นค่าชั้นหนึ่ง; ไวยากรณ์บล็อกโมดูล `# ชื่อ { }`
- **เพิ่ม** ดัชนี หลายมิติ `อาร์เรย์[i>j>k]` และดึงแบบแบน `อาร์เรย์[p ; q]`

### v0.0.3 — ระบบตัวเลข Unicode _(เมษายน ๒๐๒๖)_

- **เพิ่ม** 69 บล็อกตัวเลข Unicode พร้อมโทเค็นเปลี่ยนโหมด `#d0d9#`
- **เพิ่ม** ค่าตรงตัวบูลีนในระบบตัวอักษรใด — `#१` / `#०`

### v0.0.2 — ออกแบบ API คอลเลกชันใหม่ _(มีนาคม ๒๐๒๖)_

- **เพิ่ม** ตระกูลโอเปอเรเตอร์ `$` สำหรับอาร์เรย์และสตริง
- **เพิ่ม** การกำหนดทำลายโครงสร้าง และ ดัชนี ลบ

### v0.0.1 — รุ่นสาธารณะครั้งแรก _(มีนาคม ๒๐๒๖)_
