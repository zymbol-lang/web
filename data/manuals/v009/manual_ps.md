> `بدلونکی°` (وروستی) د لوپ دننه لنګر وهي — کله چې لوپ پای ته ورسیږي مړ کیږي.

## د معلوماتو ډولونه

| ډول | لغوي | `#?` نښه | یادښتونه |
|------|---------|----------|-------|
| بشپړ عدد | `۴۲`, `-۷` | `###` | خوندي بشپړ عدد: ±(2⁵³ − 1) |
| اعشاري | `۳.۱۴`, `۱.۵e۱۰` | `##.` | IEEE-754 دوه ګونی |
| تار | `"متن"` | `##"` | دننه کول: `"سلام {نوم}"` |
| توری | `'A'` | `##'` | یو یونیکوډ کوډ نقطه |
| بولین | `#۱`, `#۰` | `##?` | عددي نه دی — `#۱ ≠ ۱` |
| لړ | `[۱, ۲, ۳]` | `##]` | یو ډول، څیړل شوی |
| اعلان شوی ګډ | `#[۱, "دوه"]` | `##[` | د `[…]` په څیر ډول، نه څیړل شوی |
| ټپل | `(a, b)` | `##)` | موقعیتي، نه بدلیدونکی |
| قاموس | `#(x: ۱, y: ۲)` | `##(` | د کیلي سره، بدلیدونکی |
| فنکشن | نومول شوی فنکشن حواله | `##()` | لومړی درجې؛ ښیي `<funct/N>` |
| لامبدا | `x -> x * ۲` | `##->` | لومړی درجې؛ ښیي `<lambd/N>` |
| واحد | `##_` | `##_` | نشتوالی — null نشته |

```zymbol
>> ۴۲#? ¶               // → (###, 2, 42)
>> [۱, ۲, ۳]#? ¶        // → (##], 3, [1, 2, 3])
>> #(x: ۱)#? ¶          // → (##(, 1, #(x: 1))
```

هغه بشپړ عدد چې د خوندي حد څخه ووځي د نیول کیدونکې تېروتنې وړ دی، هیڅکله غلی پوښ نه دی:

```zymbol
!? {
    >> (۹۰۰۷۱۹۹۲۵۴۷۴۰۹۹۱ + ۱) ¶
} :! ##Range {
    >> "د حد څخه بهر" ¶ // → د حد څخه بهر
}
```

`##_` د دې لپاره ده چې پروګرام پوښتنه کوي چې ایا یو شی نشته:

```zymbol
هیڅ_شی() { }
ارزښت = هیڅ_شی()
>> (ارزښت == ##_) ¶     // → #1
```

## وتنه او ننوتنه

```zymbol
نوم = "احمد"
ټول = ۳
>> "سلام" ¶             // → سلام
>> "a=" نوم " b=" ټول ¶ // → a=احمد b=3
>> ټول#? ¶            // → (###, 1, 3)
```

```zymbol
<< نوم
<< "خپل نوم ولیکئ: " نوم
<< ###(۴) "عمر: " عمر
```

**د دواړو نښو بڼه وګورئ.** `>>` د باندې خواته اشاره کوي: معلومات د پروګرام څخه باندې راوباسي. `<<` دننه خواته اشاره کوي: معلومات پروګرام ته راوړي. دلته د یادولو لپاره هیڅ نشته — غشی ښیي چې معلومات کوم لوري ته ځي، او همدا مفکوره په هر هغه نښه کې بیرته راځي چې یو شی خوځوي.

> `¶` او `\\` مساوي نوي کرښې دي. `>>` هیڅکله یو نه زیاتوي.
> د پوښتنې دمخه د ډول ټاکونکی د لوستلو پر مهال تصدیق کوي او تر هغې بیا پوښتنه کوي چې ارزښت سم شي:
> `##.` اعشاري · `##.(T,D)` لسیزه · `###(N)` بشپړ عدد · `##"(N)"` متن · `##'` یو توری.

د یوې فایل په لوړه کچه، `<~>` د پروګرام د وتلو حالت دی:

```zymbol
>> "ګوري" ¶      // → ګوري
<~ ۰
```

## د TUI بنسټیز شیان

د متقابل پروګرامونو لپاره د ټرمینل UI عملیات. ډیری یې `>>| { }` بلاک ته اړتیا لري (بدیل سکرین + خام حالت).

```zymbol
>>| {
    >>!
    >>~ (۱, ۱, ۰, ۱۰) > "ګرځي"
    @~ ۱۰۰۰
    >>~ (۲, ۱) > "بشپړ شو."
}
```

```zymbol
>>| {
    [کرښې, ستنې] = >>?
    >>~ (۱, ۱) > "ټرمینل: " کرښې " x " ستنې
    <<| کیلي
    >>~ (۲, ۱) > "ووهل شو: " کیلي
}
```

دلته تاسو ګورئ چې ولې نښې د ضرب کیدو پرځای یوځای کیږي. تاسو دمخه پوهیږئ چې `<<` ننوتنه ده او `?` پرته د ژمنې پوښتنه کوي. یوازې یوه نښه نوې ده:

- `|` **یو واحد** دی، نه ټول بهیر.

د دې سره، دواړه د کیبورډ عملیات خپل ځان لولي:

```text
<<        |             ?
ننوتنه    یو واحد       پرته د ژمنې

<<|   یوه کیلي واخلئ، او تر هغې انتظار وکړئ چې یوه راشي
<<|?  وګورئ چې کیلي شته، او که نشته نو دوام ورکړئ
```

په بل اړخ کې همدا: `>>` لیږي، `>>!` **په زور** لیږي (ټول سکرین پاکوي)، پداسې حال کې چې `>>?` د لیکلو پرځای **پوښتنه کوي** (ټرمینل څومره لوی دی). ښي اړخ نښه هغه ده چې حالت بدلوي، او هغه تل په پای کې راځي.

> `>>!` سکرین پاکوي. `>>?` `[کرښې, ستنې]` بیرته ورکوي. `@~ N` N ملی ثانیې ویده کیږي.
> `<<|` یو کیلي فشار لولي (بندیدونکی); `<<|?` پرته د بندیدو پلټنه کوي (`'\0'` که هیڅ نشته).
> د غشي کیلي د `'↑' '↓' '←' '→'` په توګه ډیکوډ کیږي; ESC د کوډ نقطې 27 دی.
> د موقعیت د وتنې ټپل: `(کرښه, ستنه, BKS, مخ, شا)` — هر سلاټ د کامې سره پریښودل کیدای شي (`>>~ (,,, ۱۹۶) > "سور"`).
> BKS بټ ماسک: `1`=غټ, `2`=مورب, `4`=لاندې کرښه. ANSI 256 رنګ پالیټ (`0`=د ټرمینل اصلي).

## د کنټرول جریان

```zymbol
x = ۷
? x > ۱۰۰ {
    >> "لوی" ¶
} _? x > ۰ {
    >> "مثبت" ¶     // → مثبت
} _ {
    >> "منفي" ¶
}
```

دلته دوه نوې نښې دي، او دریمه د دوی د یوځای کیدو څخه راځي:

- `?` **پوښتنه** ده: یو شرط پرانیزي.
- `_` **هغه څه دي چې نه دي ټاکل شوي**: هغه څانګه چې پاتې کیږي کله چې هیڅ پوښتنه سمه نه وي.
- `_?` دواړه په پرله پسې ډول: *که هیڅ سره سم نه شو، بیا پوښتنه وکړه*.

له همدې امله `_?` داسې لیکل کیږي. دا زده کولو لپاره نوې نښه نه ده — دا `_` ده چې `?` وروسته راځي، او د هغې د دواړو برخو معنی په ترتیب سره لوستل کیږي.

> قوسونه `{ }` حتی د یو بیان لپاره **اړین** دي.

## سمون

```zymbol
نمرې = ۸۵
درجه = ?? نمرې {
    ۹۰..۱۰۰ => 'A'
    ۸۰..۸۹  => 'B'
    _       => 'F'
}

```

```zymbol
تودوخه = -۵
حالت = ?? تودوخه {
    < ۰  => "یخ"
    < ۲۰ => "ساړه"
    _    => "ګرم"
}
```

تاسو دمخه پوهیږئ چې `?` "پوښتنه" ده. **`??` څو ځله پوښتنه کول دي**: په ژبه کې هر چیرې د یوې نښې دوه چنده کول، هغه څه چې نښه یو ځل کوي څو ځله کول دي. یو `?` یو شرط ازمويي; `??` د قضیو لیست سره ازمويي.

```zymbol

    شمېر++
    ? شمېر >= ۳ { @:بهر! }

```

`@` د **وخت** نښه ده: هر هغه څه چې تکرار کیږي په هغې کې ژوند کوي. د دې وخت د کموالي لپاره تاسو د هغې څنګ ته یوه نښه اضافه کوئ:

- `@!` — `!` **زور** دی: اوس لوپ پریږدئ.
- `@>` — `>` مخته ټېل وهل: بل ګرد ته لاړ شئ.
- `@:بهر!` — `:` **یو نوم تړي**، نو دا د *بهر* په نوم لوپ پرې کوي، نه نږدې یو.

درې عملیات، او هیڅ یو یې جلا زده کول نه غوښتل: دوی `@` دي او یوه نښه چې دمخه وايي چې څه کوي.

> **ټاکونکی یو شمېر یا یو شرط دی.** یو `بشپړ عدد` یو شمېر دی، یو ځل ارزول کیږي — `@ ۰` بدن صفر ځله چلوي. هر بل شی یو شرط دی. رښتیا نشته: `@ []` او `@ ۳.۵` رد کیږي. د یوې ټولګې د تیریدو لپاره `@ x:توکي` وکاروئ; د شمېرلو لپاره `@ توکي$#`.

```zymbol
لړ = [۱, ۲, ۳, ۴, ۵]
>> لړ[۱] ¶       // → 1   د نښې ایښودل د 1 څخه پیل کیږي
>> لړ[-۱] ¶      // → 5   منفي د پای څخه شمېري
>> لړ$# ¶        // → 5   اوږدوالی
```

```zymbol
لړ = [۱, ۲, ۳]
>> (لړ$+ ۶) ¶          // → [1, 2, 3, 6]   اضافه کول
>> (لړ$+[۲] ۹۹) ¶      // → [1, 99, 2, 3]  په موقعیت ۲ کې دننه کول
>> (لړ$- ۳) ¶          // → [1, 2]         لومړی واقع حذف کول
>> (لړ$-[۱]) ¶         // → [2, 3]         په نښه ۱ حذف کول
>> (لړ$[۱..۲]) ¶       // → [1, 2]         ټوټه، دواړه پایونه شامل
>> (لړ$? ۳) ¶          // → #1             لري
```

ټول د `$` سره پیل کیږي، چې د **ټولګې** نښه ده، او د یوې نښې سره دوام کوي چې وايي په هغې کې څه کیږي: `#` څو، `+` اضافه کول، `-` حذف کول، `?` پوښتنه چې ایا شته. او لکه د `??` سره، د نښې دوه چنده کول یې بشپړ کول دي: `$?` پوښتنه کوي *ایا* ارزښت شته، `$??` پوښتنه کوي *په څو ځایونو کې* او ټول بیرته ورکوي.

```zymbol
لړ = [۳, ۱, ۲]
>> (لړ$^+) ¶     // → [1, 2, 3]   صعودي
>> (لړ$^-) ¶     // → [3, 2, 1]   نزولي
```

**د پایلې قاعده.** یو عملیات، او هغه څه چې شاوخوا کوډ ورسره کوي پریکړه کوي: که وکارول شي، **جوړوي** او اصلي پریږدي؛ که وغورځول شي، **بدلوي**.

```zymbol
لړ = [۱, ۲, ۳]
کاپي = لړ[۲]$~ ۹۹
>> لړ ¶                // → [1, 2, 3]
>> کاپي ¶              // → [1, 99, 3]
لړ[۲]$~ ۹۹
>> لړ ¶                // → [1, 99, 3]
```

> **`=` هیڅکله په ټولګه کې نه لیکي.** `لړ[۲] = ۹۹` د Zymbol یوه بڼه نه ده — `=` یو **نوم** ته ارزښت ورکوي. د ټولګې یوه برخه بدلول `$~` دی، په هرې ټولګه کې.

`[…]` یو ډول لري او څیړل کیږي; قصدي ګډول د `#[…]` سره **اعلان** کیږي:

```zymbol
ګډ = #[۱, "دوه", #۱]
>> ګډ ¶             // → [1, دوه, #1]
>> ([۱, ۲] == #[۱, ۲]) ¶ // → #1
```

## څو اړخیزه نښه ایښودل

`>` په یو تړلي جوړښت کې ښکته ځي. یوه قوس ډله یو عنصر ته اشاره کوي، څومره ژور چې وي.

```zymbol
m = [[۱,۲,۳], [۴,۵,۶], [۷,۸,۹]]
>> m[۲>۳] ¶        // → 6   کرښه 2، ستنه 3
>> m[-۱>-۱] ¶      // → 9   وروستۍ کرښه، وروستۍ ستنه
```

```zymbol
m = [[۱,۲,۳], [۴,۵,۶], [۷,۸,۹]]
>> m[۱>۱ ; ۲>۲ ; ۳>۳] ¶          // → [1, 5, 9]          هوار: قطر
>> m[[۱>۱, ۱>۳] ; [۳>۱, ۳>۳]] ¶  // → [[1, 3], [7, 9]]   جوړښت: کونجونه
```

```zymbol
m = [[۱,۲,۳], [۴,۵,۶]]
>> (m[۱>۲]$~ ۹۹) ¶      // → [[1, 99, 3], [4, 5, 6]]
```

> `m[۱][۲]` د Zymbol یوه بڼه **نه ده**. زنځیري نښه د لوستلو او لیکلو دواړو لپاره رد کیږي — د هر لاسرسي لپاره یوه قوس ډله، او `>` هغه څه دي چې د ګامونو ترمنځ ځي.

## قاموسونه

د نومول شویو برخو سره یو ټپل یو قاموس دی، او د v0.0.9 څخه دا `#(…)` لیکل کیږي.

```zymbol
کس = #(نوم: "احمد", عمر: ۲۵)
>> کس.نوم ¶        // → احمد
>> کس["عمر"] ¶    // → 25
```

```zymbol
کس = #(نوم: "احمد", عمر: ۲۵)
برخه = "نوم"
>> کس[برخه] ¶     // → احمد
```

دا بدلیدونکی دی، کیلي کولای شي اضافه شي، او دا تیریدل کیدای شي:

```zymbol
ذخیره = #(ناشپاتې: ۴)
ذخیره["مڼه"]$~ ۱۰
@ k:ذخیره { >> k "=" ذخیره[k] " " }
>> ¶                    // → ناشپاتې=4 مڼه=10
```

```zymbol
ذخیره = #(ناشپاتې: ۴, مڼه: ۱۰)
@ (k, v):ذخیره { >> k ":" v " " }
>> ¶                    // → ناشپاتې:4 مڼه:10
```

> `#()` خالي قاموس دی، کوم چې `()` نه شو کیدای — دا باید خالي ټپل هم وي. بربنډ `(x: 1)` د دې پیغام سره رد کیږي: *a dictionary is written `#(…)`* — «یو قاموس `#(…)` لیکل کیږي».
> یو قاموس د کیلي سره اشاره کیږي، هیڅکله د موقعیت سره نه، نو `کس[۱]` یوه تېروتنه ده.

## ټپلونه

ټپلونه **نه بدلیدونکي** ترتیب شوي کانټینرونه دي چې د مختلف ډولونو ارزښتونه لري.

```zymbol
نقطه = (۱۰, ۲۰)
>> نقطه[۱] ¶           // → 10
ډاټا = (۴۲, "سلام", #۱, ۳.۱۴)
>> ډاټا[۳] ¶            // → #1
```

```zymbol
t = (۱۰, ۲۰, ۳۰)
t۲ = t[۲]$~ ۹۹۹
>> t ¶                  // → (10, 20, 30)
>> t۲ ¶                 // → (10, 999, 30)
```

> په یوه ټپل کې په ځای بدلون هره هڅه یوه تېروتنه ده، هر عملیات چې وي — نه بدلیدنه د ارزښت ملکیت دی، نه د هر `$` دننه استثنا.

```zymbol
لړ = [۱۰, ۲۰, ۳۰, ۴۰, ۵۰]

```

```zymbol
لړ = [۱۰, ۲۰, ۳۰, ۴۰, ۵۰]
[لومړی, *پاتې] = لړ
>> لومړی ¶            // → 10
>> پاتې ¶              // → [20, 30, 40, 50]
```

```zymbol
نقطه = (۱۰۰, ۲۰۰)
```

```zymbol
کس = #(نوم: "زرغونه", عمر: ۲۵)
```

> د قوس بڼه ټاکل شوې ده: `[…]` لړ اخلي، `(…)` ټپل، `#(…)` قاموس. وروستی نوم **پاتې جذبوي**، نو جوړښت ماتول هیڅکله د اوږدوالی له امله ناکام نه کیږي — `(a, b, c) = (1,2,3,4,5)` `c = (3,4,5)` ورکوي، او `##_` کله چې هیڅ پاتې نه وي.

## د لوړې کچې فنکشنونه

```zymbol
شمېرې = [۱, ۲, ۳, ۴, ۵]
>> (شمېرې$> (x -> x * ۲)) ¶ // → [2, 4, 6, 8, 10]
>> (شمېرې$| (x -> x % ۲ == ۰)) ¶ // → [2, 4]
>> (شمېرې$< (۰, (راټول, x) -> راټول + x)) ¶ // → 15
```

```zymbol
شمېرې = [۱, ۲, ۳, ۴, ۵, ۶]
دوه_چنده(x) { <~ x * ۲ }
لوی(x) { <~ x > ۳ }
>> (شمېرې$> دوه_چنده) ¶    // → [2, 4, 6, 8, 10, 12]
>> (شمېرې$| لوی) ¶    // → [4, 5, 6]
```

```zymbol
بنسټ = [#(نوم: "کارلا", عمر: ۲۸), #(نوم: "زرغونه", عمر: ۲۵)]
د_عمر_له_مخې = بنسټ$^ (a, b -> a.عمر < b.عمر)
>> د_عمر_له_مخې[۱].نوم ¶     // → زرغونه
```

> نومول شوی فنکشن HOF ته **پرته له قوسونو** ځي: `شمېرې$> دوه_چنده`. `شمېرې$> (دوه_چنده)` لیکل د تجزیې تېروتنه ده، ځکه `(` یوه لامبدا پرانیزي.

## د تېروتنو اداره

```zymbol
!? {
    x = ۱۰ / ۰
} :! ##Div {
    >> "په صفر ویشل" ¶  // → په صفر ویشل
} :! {
    >> "بل: " _err ¶
} :> {
    >> "تل ګرځي" ¶        // → تل ګرځي
}
```

| ډول | کله |
|------|------|
| `##Div` | په صفر ویشل |
| `##Index` | نښه د حد څخه بهر |
| `##Key` | په قاموس کې کیلي نشته |
| `##Range` | د خوندي بشپړ عدد حد څخه بهر |
| `##Type` | د ډول نه سمون |
| `##Parse` | د معلوماتو تجزیه |
| `##IO` | فایل / سیسټم |
| `##Network` | د شبکې تېروتنې |
| `##DB` | ډاټابیس |
| `##Time` | هغه نیټه چې نشته |
| `##_` | هره تېروتنه (ټول نیول) |

`!` د **تېروتنې او زور** نښه ده، او په دواړو کورنیو کې یو شان لوستل کیږي: `$!` له یو ارزښت څخه پوښتنه کوي چې ایا تېروتنه ده; `$!!`، د نښې دوه چنده سره، پرته له پوښتنې یې پورته خپروي.

> د معیاري کتابتون ناکامۍ د **نرمو تېروتنې ارزښتونو** په توګه بیرته راځي چې تاسو یې د `$!` سره ازموئ یا د `!?` سره نیسئ، د بندیدو پرځای. `$!!` یو بلونکي ته خپروي.

## ماډلونه

```zymbol
# کیلک {
    #> { جمع, PI }

    PI := ۳.۱۴۱۵۹
    جمع(a, b) { <~ a + b }
}
```

```zymbol
<# ./کیلک => ک

>> ک::جمع(۵, ۳) ¶
>> ک.PI ¶
```

```zymbol
# زما_کتابتون {
    #> { داخلي_جمع => مجموعه }

    داخلي_جمع(a, b) { <~ a + b }
}
```

دوه ماډل نښې همدا مفکوره ده، اوس په فایلونو تطبیق شوې: `#` د **اعلان** کچه ده — هغه څه چې یو شی *دی*، نه د هغې ارزښت — او غشی وايي چې کوډ کوم لوري ته ځي:

```text
<#   غشی ننوځي: وارد کول، د بل فایل څخه راوړل
#>   غشی وځي: صادرول، نورو فایلونو ته وړاندې کول
```

د لوري نښه تل په هغه څنډه ناسته ده چې د هغې لوري ته مخه کوي. دا هماغه دلیل دی چې ولې `<~` کیڼ ته بیرته راځي (د فنکشن څخه بهر) او `->` ښي ته ننوځي (د لامبدا بدن ته).

> **یو ماډل اعلانوي چې څه صادروي.** د `#>` بلاک اړین دی — پریښودل یې **E014** دی، او `#> { }` هغه طریقه ده چې یو ماډل وايي چې سطح یې خالي ده. `::` یو فنکشن بولي، `.` یو ثابت لولي. یوازې واردات، د صادراتو بلاک، حقیقي پیل کوونکي او د فنکشن تعریفونه کولای شي د ماډل بدن کې ښکاره شي; هر هغه څه چې اجرا کیدای شي **E013** دی.

## بنډلونه

یو `.zyp` یو څو فایله پروګرام په یو وړوکي فایل کې بنډل کوي. دا د **سرچینې** آرشیف دی، بائنري نه، نو چیرې چې `zymbol` بائنري ګرځي هلته ګرځي.

```bash
zymbol package زما_پروژه/ --script main.zy -o زما_پروژه.zyp
zymbol run زما_پروژه.zyp
```

> آرشیف یو منشور (`zyp.toml`) لري چې د هغې د ننوتلو سکریپټونه او اړین انجن نسخه اعلانوي. `zymbol run` هغه یوې لنډمهاله ډایرکټرۍ ته وباسي او له هغه ځایه ګرځوي، نو کوډ یو ځل کارول کیږي پداسې حال کې چې سکریپټ څه لیکي ستاسو ریښتینې کاري ډایرکټرۍ ته ځي. د لوبې ډګر هم `.zyp` فایلونه پورته کوي.

## عددي حالتونه

Zymbol کولای شي شمېرې په **د Unicode 69 عددي لیکلړونو** کې ولیکي — دیوناګري، عربي-هندي، تایلنډي، کلینګن pIqaD، د ریاضي غټ، د LCD برخې، او نور. حالت د پروسې لپاره نړیوال دی او وتنې ته اغیزه کوي; ریاضي نه بدلیږي.

```zymbol
#०९#    // دیوناګري   (U+0966–U+096F)
#٠٩#    // عربي-هندي (U+0660–U+0669)
#๐๙#    // تایلنډي     (U+0E50–U+0E59)
#09#    // ASCII ته بیا تنظیم
```

```zymbol
a = ۴۲
>> a ¶                  // → 42
#٠٩#
>> a ¶                  // → ٤٢
>> ۳.۱۴ ¶               // → ٣٫١٤
>> #۱ ¶                 // → #١
#09#
```

د هر ملاتړ شوي لیکلړ عددونه په سرچینه کې معتبر لغوي دي:

```zymbol
#٠٩#
@ i:۱..۵ { >> i " " }
>> ¶                    // → ١ ٢ ٣ ٤ ٥
#09#
```

لوستل متناظر دي — یو عدد په هر لیکلړ کې پوهیدل کیږي:

```zymbol
>> #|"४२"| ¶            // → 42
>> #|'७'| ¶             // → 7
```

> `#` تل ASCII دی، نو `#0` په هر لیکلړ کې د صفر عدد څخه لیدلتو توپیر لري.
> `#,` او `#^` هم خپل عددونه په فعال لیکلړ کې لیکي، او جلا کوونکي یې تعقیبوي — مګر جوړه هیڅکله نه بدلیږي: `,` ډله کوي او `.` جلا کوي، په هر لیکلړ کې.

## د معلوماتو عملیات

```zymbol
f = ##.۴۲         // اعشاري ته
i = ###۳.۷        // بشپړ عدد ته، ګرد  → 4
t = ##!۳.۷        // بشپړ عدد ته، پرې  → 3
>> f " " i " " t ¶      // → 42 4 3
>> f#? ¶                // → (##., 2, 42)
```

> اعشاري د عددونو په توګه چاپ کیږي، هیڅکله د قوت په توګه نه، او پای `.0` غورځوي — `##.42` `42` لیکي او بیا هم اعشاري دی، لکه `f#?` ښیي.

```zymbol
>> #|"42"| ¶       // → 42
>> #|"abc"| ¶      // → abc   د ناکامۍ خوندي: ننوتنه بې بدلون بیرته ورکوي
>> ##!'A' ¶        // → 65    د یو توري کوډ نقطه
```

```zymbol
pi = ۳.۱۴۱۵۹۲۶۵
>> #.۲|pi| ¶       // → 3.14          2 لسیزې ځایونو ته ګرد
>> #!۲|pi| ¶       // → 3.14          2 لسیزې ځایونو ته پرې
>> #,|۱۲۳۴۵۶۷| ¶   // → 1,234,567     د زرو جلا کوونکي
>> #^|۱۲۳۴۵.۶۷۸| ¶ // → 1.2345678e4   ساینسي نښه
```

```zymbol
>> 0x41 ¶        // → A   شپاړسی
>> 0b01000001 ¶  // → A   دوه ګونی
>> 0o101 ¶       // → A   اتړسی
>> 0d65 ¶        // → A   لسیزه
```

> په ASCII حد کې یو بنسټیز لغوي یو **توری** دی: `0d65 == 'A'` `#1` دی، او `0d65 == 65` `#0` دی. څلور واړه بنسټونه همدا توری لیکي.

```zymbol
//   FizzBuzz · 16 · 17 · Fizz · 19 · Buzz   (په هر کرښه یو)
```

## نښې څنګه یوځای کیږي

تاسو په دې ټول لارښود کې همدا یو شی لیدلی: **یو عملیات د یادولو لپاره انځور نه دی، دا په یو قطار کې څو نښې دي، او هر یو خپله معنی ورکوي.** اوس چې تاسو ټول پیژنئ، دا بشپړ نمونه ده.

لومړی راځي **په کومه نړۍ کې یو**:

| نښه | نړۍ | تاسو یې چیرته لیدلی |
|--------|-------|----------------------------|
| `$` | یوه ټولګه | `$#` `$+` `$?` `$^-` |
| `@` | وخت، هر هغه څه چې تکرار کیږي | `@!` `@>` `@~` |
| `#` | هغه څه چې یو شی *دی*، نه ارزښت یې | `#?` `#(…)` `<#` `#>` |
| `>>` | له پروګرام څخه بهر | `>>` `>>!` `>>?` |
| `<<` | پروګرام ته دننه | `<<` `<<\|` `<<\|?` |
| `?` | پوښتنه، پرته د ژمنې | `?` `_?` `??` `$?` |
| `!` | زور، یا تېروتنه | `@!` `$!` `!?` |

بیا راځي **هلته څه کیږي**: `+` اضافه، `-` حذف، `^` ترتیب، `~` بدلون، `#` شمېر، `|` یو واحد، `:` نوم تړل.

او دوه قواعد چې هیڅکله نه ناکام کیږي:

**د یوې نښې دوه چنده کول یې بشپړ کوي.** `?` یو ځل پوښتنه کوي، `??` ډیری قضیې ازمويي. `$?` پوښتنه کوي چې ایا ارزښت شته، `$??` هره هغه ځای بیرته ورکوي چې شته. `!` تېروتنه په نښه کوي، `!!` پرته له پوښتنې خپروي.

**د حالت نښه تل په پای کې راځي.** کله چې `?` یا `!` ښکاره شي ترڅو ووايي چې یو شی *څنګه* کیږي — په شک یا په زور — دوی د عملیات وروستۍ نښې دي: `$??`, `$!!`, `<<|?`, `@!`, `##!`, `>>!`, `>>?`, `@:بهر!`. د دوی وروسته هیڅکله عملیات نشته.

له دې څخه یو عملي شی راځي: **هغه ترکیب چې تاسو هیڅکله نه دی لیدلی، دمخه یې معنی لري مخکې لدې چې تاسو یې وګورئ.** که `$` ټولګه ده او `^` ترتیب دی او `-` بدل دی، نو `$^-` نزولي ترتیب کوي، او هیچا ته اړ نه وه چې تاسو ته یې ووايي.

ټول لیست داسې کار نه کوي، او دا ویل د تظاهر کولو څخه غوره دي. ډیری عملیات پاک جلا کیږي. شپږ جلا کیږي مګر د خپلو برخو څخه ډیر معنی لري: `!?` `:!` `:>` `|>` `::` `$++`. او لس باید زړه له حده کیږي ځکه چې دوی هیڅ نه جلا کیږي: `¶` `><` `#1` `#0` `0x` `0b` `0o` `0d` `###` `°`.

> د ناڅرګندو شمېرل د دې پرځای چې فرض کړو لږ دي قصدي ده: دوی د ژبې ریښتینې د حفظ کولو لګښت دی. بشپړ مرجع — لیست، اعلان شوي هوموګرافونه، او هغه قواعد چې یو نوی عملیات باید پوره کړي ترڅو شتون ولري — په ژباړونکي ذخیره کې `SYMBOLS.md` کې دی.
