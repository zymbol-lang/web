> `¶` اور `\\` مساوی نئی لائنیں ہیں۔ `>>` کبھی بھی ایک نہیں جوڑتا۔
> پرامپٹ سے پہلے ایک قسم کا مخصوص کنندہ پڑھتے وقت توثیق کرتا ہے اور درست ہونے تک دوبارہ پرامپٹ کرتا ہے:
> `##.` اعشاری · `##.(T,D)` اعشاری · `###(N)` عدد صحیح · `##"(N)` متن · `##'` ایک حرف۔

کسی فائل کی اعلیٰ سطح پر، `<~` پروگرام کی خارجی حالت ہے:


## TUI ابتدائیات

انٹرایکٹو پروگراموں کے لیے ٹرمینل UI آپریٹرز۔ زیادہ تر کو `>>| { }` بلاک کی ضرورت ہوتی ہے (متبادل اسکرین + خام موڈ)۔

```zymbol
>>| {
    >>!
    >>~ (۱, ۱, ۰, ۱۰) > "چل رہا ہے"
    @~ ۱۰۰۰
    >>~ (۲, ۱) > "مکمل۔"
}
```

```zymbol
>>| {
    [قطاریں, کالم] = >>?
    >>~ (۱, ۱) > "ٹرمینل: " قطاریں " x " کالم
    <<| کلید
    >>~ (۲, ۱) > "دبایا: " کلید
}
```

یہاں آپ دیکھ سکتے ہیں کہ علامتیں کیوں ضرب ہونے کے بجائے یکجا ہوتی ہیں۔ آپ پہلے سے جانتے ہیں کہ `<<` ان پٹ ہے اور `?` بغیر وابستگی کے پوچھتا ہے۔ صرف ایک علامت نئی ہے:

- `|` ایک **اکائی** ہے، پورا سلسلہ نہیں۔

اس کے ساتھ، دونوں کی بورڈ آپریٹرز خود پڑھے جاتے ہیں:

```text
<<        |             ?
ان پٹ     ایک اکائی    بغیر وابستگی

<<|   ایک کلید لیں، اور اس وقت تک انتظار کریں جب تک ایک نہ آ جائے
<<|?  دیکھیں کہ کوئی کلید ہے، اور اگر نہیں تو آگے بڑھیں
```

دوسری طرف بھی یہی: `>>` بھیجتا ہے، `>>!` **زبردستی** بھیجتا ہے (پوری اسکرین صاف کرتا ہے)، جبکہ `>>?` لکھنے کے بجائے **پوچھتا** ہے (ٹرمینل کتنا بڑا ہے)۔ دائیں طرف کی علامت وہ ہے جو موڈ کو تبدیل کرتی ہے، اور یہ ہمیشہ آخر میں آتی ہے۔

> `>>!` اسکرین صاف کرتا ہے۔ `>>?` `(قطاریں, کالم)` لوٹاتا ہے۔ `@~ N` N ملی سیکنڈ سوتا ہے۔
> `<<|` ایک کی پریس پڑھتا ہے (مسدود)؛ `<<|?` بغیر مسدود کے پول کرتا ہے (`'\0'` اگر کوئی نہیں)۔
> تیر والی کلیدیں `'↑' '↓' '←' '→'` کے طور پر ڈی کوڈ ہوتی ہیں؛ ESC کوڈ پوائنٹ 27 ہے۔
> پوزیشنی آؤٹ پٹ ٹپل: `(قطار, کالم, BKS, اگلا, پچھلا)` — کوئی بھی خانہ کوما سے چھوڑا جا سکتا ہے (`>>~ (,,, ۱۹۶) > "سرخ"`)۔
> BKS بٹ ماسک: `1`=موٹا, `2`=ترچھا, `4`=زیرخط۔ ANSI 256 رنگ پیلیٹ (`0`=ٹرمینل طے شدہ)۔

## کنٹرول فلو

```zymbol
x = ۷
? x > ۱۰۰ {
    >> "بڑا" ¶
} _? x > ۰ {
    >> "مثبت" ¶     // → مثبت
} _ {
    >> "منفی" ¶
}
```

یہاں دو نئی علامتیں ہیں، اور تیسری جو انہیں ایک ساتھ رکھنے سے آتی ہے:

- `?` **پوچھنا** ہے: یہ ایک شرط کھولتا ہے۔
- `_` **وہ ہے جو متعین نہیں کیا گیا**: وہ شاخ جو جب کوئی سوال مماثل نہیں ہوتا تو باقی رہ جاتی ہے۔
- `_?` دونوں ایک قطار میں: *اگر کچھ مماثل نہیں ہوا، تو دوبارہ پوچھیں*۔

اسی لیے `_?` اس طرح لکھا جاتا ہے۔ یہ سیکھنے کے لیے ایک نیا نشان نہیں ہے — یہ `_` ہے جس کے بعد `?` ہے، اور اس کا مطلب بالکل وہی ہے جو اس کے دو حصوں کا مطلب ہے، ترتیب سے پڑھا جائے۔

> بریکٹ `{ }` ایک بیان کے لیے بھی **لازمی** ہیں۔

```zymbol
حد = ۱۰۰
اندر(n) { <~ n < حد }
>> اندر(۴۲) ¶         // → #1
```

دو نشانات اسے تبدیل کرتے ہیں، اور دونوں **دستخط اور کال سائٹ** پر لکھے جاتے ہیں:

```zymbol
بڑھائیں(شمار<~) { شمار = شمار + ۱ }
کل = ۰
بڑھائیں(کل<~)
>> کل ¶              // → 1
```

> `p~` ایک کام کرنے والی کاپی ہے — جسم اسے دوبارہ تفویض کر سکتا ہے اور کال کرنے والا برقرار رہتا ہے۔
> `p<~` ایک آؤٹ پٹ پیرامیٹر ہے — تبدیلی واپس سفر کرتی ہے۔ نشان کے بغیر `بڑھائیں(کل)` ایک معنوی خرابی ہے: تشریح اور دستخط الگ نہیں ہو سکتے۔

## لیمبڈا اور بندش

```zymbol
دوگنا = x -> x * ۲
مجموعہ = (a, b) -> a + b
>> دوگنا(۵) ¶          // → 10
>> مجموعہ(۳, ۷) ¶          // → 10
```

```zymbol
درجہ_بندی = x -> {
    ? x > ۰ { <~ "مثبت" }
    _? x < ۰ { <~ "منفی" }
    <~ "صفر"
}
>> درجہ_بندی(-۴) ¶         // → منفی
```

```zymbol
ضارب = ۳
تگنا = x -> x * ضارب
>> تگنا(۷) ¶          // → 21
```

```zymbol
بنانے_والا_جمع(n) { <~ x -> x + n }
جمع۱۰ = بنانے_والا_جمع(۱۰)
>> جمع۱۰(۵) ¶           // → 15
```

ایک لیمبڈا کوئی پیرامیٹر نہیں لے سکتا:

```zymbol
جواب = () -> ۴۲
>> جواب() ¶           // → 42
```

> ایک لیمبڈا فائل کے متغیرات کو **بناتے وقت** پکڑتا ہے؛ ایک نامزد فنکشن انہیں **کال کرتے وقت** پڑھتا ہے۔

## ایریز

```zymbol
arr = [۱, ۲, ۳, ۴, ۵]
>> arr[۱] ¶       // → 1   انڈیکسنگ 1-بنیاد ہے
>> arr[-۱] ¶      // → 5   منفی آخر سے شمار کرتا ہے
>> arr$# ¶        // → 5   لمبائی
```

```zymbol
arr = [۱, ۲, ۳]
>> (arr$+ ۶) ¶          // → [1, 2, 3, 6]   شامل کریں
>> (arr$+[۲] ۹۹) ¶      // → [1, 99, 2, 3]  پوزیشن 2 پر داخل کریں
>> (arr$- ۳) ¶          // → [1, 2]         پہلی موجودگی کو ہٹائیں
>> (arr$-[۱]) ¶         // → [2, 3]         انڈیکس 1 پر ہٹائیں
>> (arr$[۱..۲]) ¶       // → [1, 2]         سلائس، دونوں سرے شامل
>> (arr$? ۳) ¶          // → #1             شامل ہے
```

یہ سب `$` سے شروع ہوتے ہیں، جو **مجموعہ** کا نشان ہے، اور اس نشان کے ساتھ جاری رہتے ہیں جو بتاتا ہے کہ اس میں کیا کیا جاتا ہے: `#` کتنے، `+` شامل کریں، `-` ہٹائیں، `?` پوچھیں کہ آیا ہے۔ اور جیسے `??` کے ساتھ، نشان کو دہرانا اسے مکمل طور پر کرنا ہے: `$?` پوچھتا ہے *کیا* کوئی قدر موجود ہے، `$??` پوچھتا ہے *کتنی جگہوں پر* اور ان سب کو لوٹاتا ہے۔

```zymbol
arr = [۳, ۱, ۲]
>> (arr$^+) ¶     // → [1, 2, 3]   صعودی
>> (arr$^-) ¶     // → [3, 2, 1]   نزولی
```

**نتیجہ کا اصول۔** ایک آپریٹر، اور ارد گرد کا کوڈ اس کے ساتھ کیا کرتا ہے فیصلہ کرتا ہے: استعمال کیا گیا، یہ **تعمیر** کرتا ہے اور اصل کو اکیلا چھوڑ دیتا ہے؛ ضائع کیا گیا، یہ **ترمیم** کرتا ہے۔

```zymbol
arr = [۱, ۲, ۳]
نقل = arr[۲]$~ ۹۹
>> arr ¶                // → [1, 2, 3]
>> نقل ¶              // → [1, 99, 3]
arr[۲]$~ ۹۹
>> arr ¶                // → [1, 99, 3]
```

> **`=` کبھی کسی مجموعہ میں نہیں لکھتا۔** `arr[۲] = ۹۹` Zymbol کی ایک شکل نہیں ہے — `=` ایک **نام** کو قدر دیتا ہے۔ کسی مجموعہ کے حصے کو تبدیل کرنا `$~` ہے، ہر مجموعہ میں۔

`[…]` ایک قسم رکھتا ہے اور جانچا جاتا ہے؛ ایک جان بوجھ کر ملاوٹ `#[…]` کے ساتھ **اعلان** کی جاتی ہے:

```zymbol
مخلوط = #[۱, "دو", #۱]
>> مخلوط ¶             // → [1, دو, #1]
>> ([۱, ۲] == #[۱, ۲]) ¶ // → #1
```

## کثیر جہتی انڈیکسنگ

`>` ایک نیسٹڈ ڈھانچے میں نیچے جاتا ہے۔ بریکٹ کا ایک گروپ ایک عنصر کو مخاطب کرتا ہے، چاہے وہ کتنا ہی گہرا ہو۔

```zymbol
m = [[۱,۲,۳], [۴,۵,۶], [۷,۸,۹]]
>> m[۲>۳] ¶        // → 6   قطار 2، کالم 3
>> m[-۱>-۱] ¶      // → 9   آخری قطار، آخری کالم
```

```zymbol
m = [[۱,۲,۳], [۴,۵,۶], [۷,۸,۹]]
>> m[۱>۱ ; ۲>۲ ; ۳>۳] ¶          // → [1, 5, 9]          ہموار: وتر
>> m[[۱>۱, ۱>۳] ; [۳>۱, ۳>۳]] ¶  // → [[1, 3], [7, 9]]   ساختہ: کونے
```

```zymbol
m = [[۱,۲,۳], [۴,۵,۶]]
>> (m[۱>۲]$~ ۹۹) ¶      // → [[1, 99, 3], [4, 5, 6]]
```

> `m[۱][۲]` Zymbol کی ایک شکل **نہیں** ہے۔ زنجیر والا انڈیکس پڑھنے اور لکھنے دونوں کے لیے مسترد کر دیا جاتا ہے — ہر رسائی کے لیے بریکٹ کا ایک گروپ، اور `>` وہ ہے جو مراحل کے درمیان جاتا ہے۔

## لغات

نامزد فیلڈز والا ایک ٹپل ایک لغت ہے، اور v0.0.9 کے بعد سے اسے `#(…)` لکھا جاتا ہے۔

```zymbol
شخص = #(نام: "عالیہ", عمر: ۲۵)
>> شخص.نام ¶        // → عالیہ
>> شخص["عمر"] ¶    // → 25
```

```zymbol
شخص = #(نام: "عالیہ", عمر: ۲۵)
فیلڈ = "نام"
>> شخص[فیلڈ] ¶     // → عالیہ
```

یہ قابل تغیر ہے، کلیدیں شامل کی جا سکتی ہیں، اور اسے طے کیا جا سکتا ہے:

```zymbol
اسٹاک = #(ناشپاتی: ۴)
اسٹاک["سیب"]$~ ۱۰
@ ک:اسٹاک { >> ک "=" اسٹاک[ک] " " }
>> ¶                    // → ناشپاتی=4 سیب=10
```

```zymbol
اسٹاک = #(ناشپاتی: ۴, سیب: ۱۰)
@ (ک, ق):اسٹاک { >> ک ":" ق " " }
>> ¶                    // → ناشپاتی:4 سیب:10
```

> `#()` خالی لغت ہے، جو `()` نہیں ہو سکتی — اسے خالی ٹپل بھی ہونا پڑتا۔ ننگی `(x: 1)` کو اس پیغام کے ساتھ مسترد کر دیا جاتا ہے: *a dictionary is written `#(…)`* — «ایک لغت `#(…)` لکھی جاتی ہے»۔
> ایک لغت کلید کے ذریعے مخاطب کی جاتی ہے، کبھی پوزیشن کے ذریعے نہیں، لہذا `شخص[۱]` ایک خرابی ہے۔

## ٹپلز

ٹپلز **ناقابل تغیر** ترتیب شدہ کنٹینر ہیں جو مختلف اقسام کی قدریں رکھتے ہیں۔

```zymbol
نقطہ = (۱۰, ۲۰)
>> نقطہ[۱] ¶           // → 10
ڈیٹا = (۴۲, "ہیلو", #۱, ۳.۱۴)
>> ڈیٹا[۳] ¶            // → #1
```

```zymbol
t = (۱۰, ۲۰, ۳۰)
t2 = t[۲]$~ ۹۹۹
>> t ¶                  // → (10, 20, 30)
>> t2 ¶                 // → (10, 999, 30)
```

> کسی ٹپل کو اس کی جگہ پر تبدیل کرنے کی کوئی بھی کوشش ایک خرابی ہے، چاہے آپریٹر کوئی بھی ہو — ناقابل تغیر قدر کی ایک خاصیت ہے، ہر `$` کے اندر کوئی استثنا نہیں۔

```zymbol
نقطہ = (۱۰۰, ۲۰۰)
```

## اعلیٰ درجہ کے فنکشنز

```zymbol
اعداد = [۱, ۲, ۳, ۴, ۵]
>> (اعداد$> (x -> x * ۲)) ¶ // → [2, 4, 6, 8, 10]
>> (اعداد$| (x -> x % ۲ == ۰)) ¶ // → [2, 4]
>> (اعداد$< (۰, (اکٹھا, x) -> اکٹھا + x)) ¶ // → 15
```

```zymbol
اعداد = [۱, ۲, ۳, ۴, ۵, ۶]
دوگنا(x) { <~ x * ۲ }
بڑا(x) { <~ x > ۳ }
>> (اعداد$> دوگنا) ¶    // → [2, 4, 6, 8, 10, 12]
>> (اعداد$| بڑا) ¶    // → [4, 5, 6]
```

```zymbol
بیس = [#(نام: "کارلا", عمر: ۲۸), #(نام: "آنا", عمر: ۲۵)]
عمر_کے_اعتبار_سے = بیس$^ (a, b -> a.عمر < b.عمر)
>> عمر_کے_اعتبار_سے[۱].نام ¶     // → آنا
```

> ایک نامزد فنکشن HOF میں **بریکٹ کے بغیر** جاتا ہے: `اعداد$> دوگنا`۔ `اعداد$> (دوگنا)` لکھنا ایک پارس خرابی ہے، کیونکہ `(` ایک لیمبڈا کھولتا ہے۔

## خرابیوں کا انتظام

```zymbol
!? {
    x = ۱۰ / ۰
} :! ##Div {
    >> "صفر سے تقسیم" ¶  // → صفر سے تقسیم
} :! {
    >> "دیگر: " _err ¶
} :> {
    >> "ہمیشہ چلتا ہے" ¶        // → ہمیشہ چلتا ہے
}
```

| قسم | کب |
|------|------|
| `##Div` | صفر سے تقسیم |
| `##Index` | انڈیکس حد سے باہر |
| `##Key` | لغت میں کلید نہیں |
| `##Range` | محفوظ عدد صحیح کی حد سے باہر |
| `##Type` | قسم کا عدم مطابقت |
| `##Parse` | ڈیٹا پارسنگ |
| `##IO` | فائل / سسٹم |
| `##Network` | نیٹ ورک کی خرابیاں |
| `##DB` | ڈیٹا بیس |
| `##Time` | ایک تاریخ جو موجود نہیں |
| `##_` | کوئی بھی خرابی (سب کو پکڑنے والا) |

`!` **خرابی اور زور** کا نشان ہے، اور یہ دونوں خاندانوں میں یکساں پڑھا جاتا ہے: `$!` کسی قدر سے پوچھتا ہے کہ کیا یہ خرابی ہے؛ `$!!`، نشان کو دہرانے سے، بغیر پوچھے اسے اوپر پھیلا دیتا ہے۔

> معیاری لائبریری کی ناکامیاں **نرم خرابی کی قدروں** کے طور پر واپس آتی ہیں جنہیں آپ `$!` سے جانچتے ہیں یا `!?` سے پکڑتے ہیں، بجائے اس کے کہ روک دیں۔ `$!!` ایک کو کال کرنے والے تک پھیلاتا ہے۔

## ماڈیولز

```zymbol
# کیلک {
    #> { جمع, PI }

    PI := ۳.۱۴۱۵۹
    جمع(a, b) { <~ a + b }
}
```

```zymbol
<# ./کیلک => c

>> c::جمع(۵, ۳) ¶
>> c.PI ¶
```

```zymbol
# میری_لائبریری {
    #> { اندرونی_جمع => مجموعہ }

    اندرونی_جمع(a, b) { <~ a + b }
}
```

دو ماڈیول نشانات ایک ہی خیال ہیں، اب فائلوں پر لاگو: `#` **اعلان** کی سطح ہے — ایک چیز *کیا ہے*، اس کی قدر نہیں — اور تیر بتاتا ہے کہ کوڈ کس سمت سفر کرتا ہے:

```text
<#   تیر داخل ہوتا ہے: درآمد کریں، دوسری فائل سے لائیں
#>   تیر باہر نکلتا ہے: برآمد کریں، دوسری فائلوں کو پیش کریں
```

ایک سمت کا نشان ہمیشہ اس کنارے پر بیٹھتا ہے جس کی طرف وہ اشارہ کرتا ہے۔ یہی وجہ ہے کہ `<~` بائیں طرف واپس آتا ہے (فنکشن سے باہر) اور `->` دائیں طرف داخل ہوتا ہے (لیمبڈا کے جسم میں)۔

> **ایک ماڈیول اعلان کرتا ہے کہ وہ کیا برآمد کرتا ہے۔** `#>` بلاک لازمی ہے — اسے چھوڑنا **E014** ہے، اور `#> { }` وہ طریقہ ہے جس سے ایک ماڈیول کہتا ہے کہ اس کی سطح خالی ہے۔ `::` ایک فنکشن کو کال کرتا ہے، `.` ایک مستقل پڑھتا ہے۔ ماڈیول کے جسم میں صرف درآمدات، برآمدی بلاک، لغوی ابتدا کار اور فنکشن تعریفیں ظاہر ہو سکتی ہیں؛ کوئی بھی قابل عمل چیز **E013** ہے۔

```bash
zymbol run myproject.zyp
```

## عددی موڈز

Zymbol اعداد کو **69 یونیکوڈ ہندسوں کی رسم الخط** میں لکھ سکتا ہے — دیوناگری، عربی-ہندی، تھائی، کلنگن pIqaD، ریاضیاتی بولڈ، LCD حصے، اور بہت کچھ۔ موڈ عمل کے لیے عالمی ہے اور آؤٹ پٹ کو متاثر کرتا ہے؛ حسابات میں کوئی تبدیلی نہیں۔

```zymbol
#०९#    // دیوناگری   (U+0966–U+096F)
#۰۹#    // اردو       (U+06F0–U+06F9)
#๐๙#    // تھائی         (U+0E50–U+0E59)
#09#    // ASCII پر ری سیٹ
```

```zymbol
x = ۴۲
>> x ¶                  // → 42
#۰۹#
>> x ¶                  // → ۴۲
>> ۳.۱۴ ¶               // → ۳٫۱۴
>> #۱ ¶                 // → #۱
#09#
```

کسی بھی تعاون یافتہ رسم الخط کے ہندسے ماخذ میں درست لٹرل ہیں:

```zymbol
#۰۹#
@ i:۱..۵ { >> i " " }
>> ¶                    // → ۱ ۲ ۳ ۴ ۵
#09#
```

پڑھنا ہم آہنگ ہے — ایک ہندسہ کسی بھی رسم الخط میں سمجھا جاتا ہے:

```zymbol
>> #|"४२"| ¶            // → 42
>> #|'७'| ¶             // → 7
```

> `#` ہمیشہ ASCII ہے، لہذا `#0` ہر رسم الخط میں ہندسہ صفر سے بصری طور پر الگ رہتا ہے۔
> `#,` اور `#^` بھی اپنے ہندسے فعال رسم الخط میں لکھتے ہیں، اور الگ کرنے والے اس کی پیروی کرتے ہیں — لیکن جوڑا کبھی الٹ نہیں ہوتا: `,` گروپ کرتا ہے اور `.` تقسیم کرتا ہے، ہر رسم الخط میں۔

## ڈیٹا آپریٹرز

```zymbol
f = ##.۴۲         // اعشاری میں
i = ###۳.۷        // عدد صحیح میں، گول  → 4
t = ##!۳.۷        // عدد صحیح میں، کاٹیں  → 3
>> f " " i " " t ¶      // → 42 4 3
>> f#? ¶                // → (##., 2, 42)
```

> ایک اعشاری ہندسوں کے طور پر پرنٹ ہوتا ہے، کبھی اس کے طور پر نہیں، اور آخری `.0` کو ہٹا دیتا ہے — `##.42` `42` لکھتا ہے اور پھر بھی اعشاری ہے، جیسا کہ `f#?` دکھاتا ہے۔

```zymbol
>> #|"۴۲"| ¶       // → 42
>> #|"abc"| ¶      // → abc   ناکام-محفوظ: ان پٹ کو بغیر تبدیلی کے لوٹاتا ہے
>> ##!'A' ¶        // → 65    ایک حرف کا کوڈ پوائنٹ
```

```zymbol
pi = ۳.۱۴۱۵۹۲۶۵
>> #.۲|pi| ¶       // → 3.14          2 اعشاری مقامات پر گول
>> #!۲|pi| ¶       // → 3.14          2 اعشاری مقامات پر کاٹیں
>> #,|۱۲۳۴۵۶۷| ¶   // → 1,234,567    ہزاروں کے الگ کرنے والے
>> #^|۱۲۳۴۵.۶۷۸| ¶ // → 1.2345678e4  سائنسی نوٹیشن
```

```zymbol
>> 0x41 ¶        // → A   ہیکساڈیسیمل
>> 0b01000001 ¶  // → A   بائنری
>> 0o101 ¶       // → A   آکٹل
>> 0d65 ¶        // → A   ڈیسیمل
```

> ASCII رینج میں ایک بنیاد لٹرل ایک **حرف** ہے: `0d65 == 'A'` `#1` ہے، اور `0d65 == 65` `#0` ہے۔ چاروں بنیادیں ایک ہی حرف کو ہجے کرتی ہیں۔

## مکمل مثال: FizzBuzz

```zymbol
درجہ_بندی(عدد) {

//   FizzBuzz · 16 · 17 · Fizz · 19 · Buzz   (ایک فی لائن)
```

## علامات کیسے یکجا ہوتی ہیں

آپ اس پورے دستورالعمل میں ایک ہی چیز دیکھ رہے ہیں: **ایک آپریٹر یاد رکھنے کے لیے کوئی تصویر نہیں ہے، یہ ایک قطار میں کئی علامات ہیں، اور ہر ایک اپنا معنی دیتی ہے۔** اب جب آپ ان سب کو جانتے ہیں، یہ ہے مکمل پیٹرن۔

پہلے آتا ہے **ہم کس دنیا میں ہیں**:

| علامت | دنیا | آپ نے اسے کہاں دیکھا |
|--------|-------|----------------------|
| `$` | ایک مجموعہ | `$#` `$+` `$?` `$^-` |
| `@` | وقت، جو کچھ دہراتا ہے | `@!` `@>` `@~` |
| `#` | ایک چیز *کیا ہے*، اس کی قدر نہیں | `#?` `#(…)` `<#` `#>` |
| `>>` | پروگرام سے باہر | `>>` `>>!` `>>?` |
| `<<` | پروگرام میں اندر | `<<` `<<\|` `<<\|?` |
| `?` | پوچھنا، بغیر وابستگی | `?` `_?` `??` `$?` |
| `!` | زور، یا خرابی | `@!` `$!` `!?` |

پھر آتا ہے **وہاں کیا کیا جاتا ہے**: `+` شامل کریں، `-` ہٹائیں، `^` ترتیب، `~` ترمیم کریں، `#` شمار، `|` ایک اکائی، `:` نام باندھیں۔

اور دو اصول جو کبھی ناکام نہیں ہوتے:

**کسی نشان کو دہرانا اسے مکمل بنا دیتا ہے۔** `?` ایک بار پوچھتا ہے، `??` کئی معاملات جانچتا ہے۔ `$?` پوچھتا ہے کہ آیا کوئی قدر موجود ہے، `$??` ہر جگہ لوٹاتا ہے جہاں یہ ہے۔ `!` ایک خرابی کو نشان زد کرتا ہے، `!!` بغیر پوچھے اسے پھیلا دیتا ہے۔

**موڈ کا نشان ہمیشہ آخر میں آتا ہے۔** جب `?` یا `!` یہ کہنے کے لیے ظاہر ہوتے ہیں کہ کوئی چیز *کیسے* کی جاتی ہے — غیر یقینی طور پر یا زبردستی — وہ آپریٹر کے آخری نشان ہیں: `$??`, `$!!`, `<<|?`, `@!`, `##!`, `>>!`, `>>?`, `@:بیرونی!`۔ ان کے بعد کبھی کوئی آپریشن نہیں ہوتا۔

اس سے ایک عملی نتیجہ نکلتا ہے: **ایک مجموعہ جو آپ نے کبھی نہیں دیکھا، اسے دیکھنے سے پہلے ہی سمجھ آ جاتا ہے۔** اگر `$` مجموعہ ہے اور `^` ترتیب ہے اور `-` الٹا ہے، تو `$^-` نزولی ترتیب دیتا ہے، اور کسی کو آپ کو بتانے کی ضرورت نہیں تھی۔

پوری فہرست اس طرح کام نہیں کرتی، اور یہ کہنا بہتر ہے کہ دکھاوا کریں۔ زیادہ تر آپریٹرز صاف طور پر الگ ہو جاتے ہیں۔ چھ الگ ہو جاتے ہیں لیکن اپنے حصوں سے زیادہ معنی رکھتے ہیں: `!?` `:!` `:>` `|>` `::` `$++`۔ اور دس کو زبانی یاد کرنا پڑتا ہے کیونکہ وہ بالکل بھی الگ نہیں ہوتے: `¶` `><` `#1` `#0` `0x` `0b` `0o` `0d` `###` `°`۔

> مبہم کو شمار کرنا بجائے یہ فرض کرنا کہ وہ کم ہیں، جان بوجھ کر کیا گیا ہے: وہ زبان کی حقیقی حفظ کی لاگت ہیں۔ مکمل حوالہ — فہرست، اعلان شدہ ہم صورت الفاظ، اور وہ اصول جنہیں ایک نیا آپریٹر پورا کرنا چاہیے — انٹرپریٹر ریپوزٹری میں `SYMBOLS.md` میں ہے۔

### v0.0.7 — مقامی معیاری لائبریری _(جولائی 2026)_

- **شامل** `std/json`، `std/io`، `std/net`، `std/db` (ODBC) — سب نرم خرابی کی قدروں کے ساتھ
- **شامل** ٹائپ شدہ/توثیق شدہ ان پٹ: `<< ##.(5,2) "قیمت: " p`
