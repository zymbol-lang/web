## ਵੇਰੀਏਬਲ ਅਤੇ ਕੌਂਸਟੈਂਟ

```zymbol
ਵੇਰੀਏਬਲ = ੧੦              // ਪਰਿਵਰਤਨਸ਼ੀਲ ਵੇਰੀਏਬਲ
PI := ੩.੧੪੧੫੯       // ਕੌਂਸਟੈਂਟ — ਮੁੜ ਨਿਰਧਾਰਨ ਰਨਟਾਈਮ ਗ਼ਲਤੀ ਹੈ
ਨਾਮ = "ਅਮਨ"
ਸਰਗਰਮ = #੧         // ਬੂਲੀਅਨ ਸੱਚ
👋 := "ਸਤ ਸ੍ਰੀ ਅਕਾਲ"
```

```zymbol
ਵੇਰੀਏਬਲ = ੧੦    // ੧੦
ਵੇਰੀਏਬਲ += ੫    // ੧੫
ਵੇਰੀਏਬਲ -= ੩    // ੧੨
ਵੇਰੀਏਬਲ *= ੨    // ੨੪
ਵੇਰੀਏਬਲ /= ੩    // ੮
ਵੇਰੀਏਬਲ %= ੩    // ੨
ਵੇਰੀਏਬਲ ^= ੨    // ੪
ਵੇਰੀਏਬਲ++       // ੫
ਵੇਰੀਏਬਲ--       // ੪
```

`°` (ਡਿਗਰੀ ਚਿੰਨ੍ਹ, U+00B0) ਪਹਿਲੀ ਵਰਤੋਂ 'ਤੇ ਇੱਕ ਵੇਰੀਏਬਲ ਨੂੰ ਇਸਦੇ ਨਿਰਪੱਖ ਮੁੱਲ 'ਤੇ ਆਪਣੇ ਆਪ ਸ਼ੁਰੂ ਕਰਦਾ ਹੈ:

```zymbol
ਅੰਕ = [੩, ੧, ੪, ੧, ੫]
@ n:ਅੰਕ {
    °ਕੁੱਲ += n
}
>> ਕੁੱਲ ¶              // → 14
```

> `°ਵੇਰੀਏਬਲ` (ਪ੍ਰੀਫਿਕਸ) ਲੂਪ ਦੇ ਉੱਪਰ ਲੰਗਰ ਲਾਉਂਦਾ ਹੈ — ਨਤੀਜਾ `@` ਤੋਂ ਬਾਅਦ ਪੜ੍ਹਨ ਯੋਗ ਹੈ।
> `ਵੇਰੀਏਬਲ°` (ਪੋਸਟਫਿਕਸ) ਲੂਪ ਦੇ ਅੰਦਰ ਲੰਗਰ ਲਾਉਂਦਾ ਹੈ — ਇਹ ਲੂਪ ਖ਼ਤਮ ਹੋਣ 'ਤੇ ਮਰ ਜਾਂਦਾ ਹੈ।

ਇੱਕ ਬਿਆਨ ਜੋ ਸਿਰਫ਼ ਇੱਕ ਨਾਮ ਹੈ, ਵੇਰੀਏਬਲ ਨੂੰ ਪੜ੍ਹਦਾ ਹੈ ਅਤੇ ਮੁੱਲ ਨੂੰ ਰੱਦ ਕਰ ਦਿੰਦਾ ਹੈ, ਇਸ ਲਈ ਇਹ ਚੇਤਾਵਨੀ ਦਿੰਦਾ ਹੈ:

```zymbol
ਗਿਣਤੀ = ੫
ਗਿਣਤੀ
```

ਕੰਪਾਈਲਰ ਇਸ ਤਰ੍ਹਾਂ ਚੇਤਾਵਨੀ ਦਿੰਦਾ ਹੈ (ਇਸਦੇ ਸੰਦੇਸ਼ ਹਮੇਸ਼ਾ ਅੰਗਰੇਜ਼ੀ ਵਿੱਚ ਹੁੰਦੇ ਹਨ):

```text
warning: this statement does nothing: 'ਗਿਣਤੀ' is read and discarded
  = help: remove it, or use it — `>> name ¶` to print it
```

ਭਾਵ: *«ਇਹ ਬਿਆਨ ਕੁਝ ਨਹੀਂ ਕਰਦਾ: 'ਗਿਣਤੀ' ਪੜ੍ਹਿਆ ਗਿਆ ਅਤੇ ਰੱਦ ਕਰ ਦਿੱਤਾ ਗਿਆ»*।

## ਡਾਟਾ ਕਿਸਮਾਂ

| ਕਿਸਮ | ਲਿਟਰਲ | `#?` ਟੈਗ | ਨੋਟਸ |
|------|---------|----------|-------|
| ਪੂਰਨ ਅੰਕ | `੪੨`, `-੭` | `###` | ਸੁਰੱਖਿਅਤ ਪੂਰਨ ਅੰਕ: ±(2⁵³ − 1) |
| ਫਲੋਟ | `੩.੧੪`, `੧.੫e੧੦` | `##.` | IEEE-754 ਡਬਲ |
| ਸਤਰ | `"ਪਾਠ"` | `##"` | ਅੰਤਰ-ਸੰਦੇਸ਼: `"ਸਤ ਸ੍ਰੀ ਅਕਾਲ {ਨਾਮ}"` |
| ਅੱਖਰ | `'A'` | `##'` | ਇੱਕ ਯੂਨੀਕੋਡ ਕੋਡ ਬਿੰਦੂ |
| ਬੂਲੀਅਨ | `#੧`, `#੦` | `##?` | ਸੰਖਿਆਤਮਕ ਨਹੀਂ — `#੧ ≠ ੧` |
| ਐਰੇ | `[੧, ੨, ੩]` | `##]` | ਇੱਕ ਕਿਸਮ, ਜਾਂਚਿਆ ਗਿਆ |
| ਐਲਾਨਿਆ ਮਿਸ਼ਰਣ | `#[੧, "ਦੋ"]` | `##[` | `[…]` ਵਰਗੀ ਹੀ ਕਿਸਮ, ਜਾਂਚ ਨਹੀਂ |
| ਟਪਲ | `(a, b)` | `##)` | ਸਥਿਤੀਕਾਰੀ, ਅਟੁੱਟ |
| ਡਿਕਸ਼ਨਰੀ | `#(a: ੧, b: ੨)` | `##(` | ਕੁੰਜੀ ਵਾਲੀ, ਪਰਿਵਰਤਨਸ਼ੀਲ |
| ਫੰਕਸ਼ਨ | ਨਾਮ ਵਾਲਾ ਫੰਕਸ਼ਨ ਹਵਾਲਾ | `##()` | ਪਹਿਲੀ-ਸ਼੍ਰੇਣੀ; ਦਿਖਾਉਂਦਾ `<funct/N>` |
| ਲਾਂਬਡਾ | `a -> a * ੨` | `##->` | ਪਹਿਲੀ-ਸ਼੍ਰੇਣੀ; ਦਿਖਾਉਂਦਾ `<lambd/N>` |
| ਯੂਨਿਟ | `##_` | `##_` | ਗੈਰ-ਮੌਜੂਦਗੀ — ਕੋਈ null ਨਹੀਂ |

```zymbol
>> ੪੨#? ¶               // → (###, 2, 42)
>> [੧, ੨, ੩]#? ¶        // → (##], 3, [1, 2, 3])
>> #(a: ੧)#? ¶          // → (##(, 1, #(a: 1))
```

ਇੱਕ ਪੂਰਨ ਅੰਕ ਜੋ ਸੁਰੱਖਿਅਤ ਸੀਮਾ ਤੋਂ ਬਾਹਰ ਜਾਂਦਾ ਹੈ, ਇੱਕ ਫੜਨ ਯੋਗ ਗ਼ਲਤੀ ਹੈ, ਕਦੇ ਵੀ ਚੁੱਪ ਲਪੇਟ ਨਹੀਂ:

```zymbol
!? {
    >> (੯੦੦੭੧੯੯੨੫੪੭੪੦੯੯੧ + ੧) ¶
} :! ##Range {
    >> "ਸੀਮਾ ਤੋਂ ਬਾਹਰ" ¶ // → ਸੀਮਾ ਤੋਂ ਬਾਹਰ
}
```

`##_` ਉਹ ਤਰੀਕਾ ਹੈ ਜਿਸ ਨਾਲ ਇੱਕ ਪ੍ਰੋਗਰਾਮ ਪੁੱਛਦਾ ਹੈ ਕਿ ਕੀ ਕੁਝ ਗੈਰ-ਮੌਜੂਦ ਹੈ:

```zymbol
ਕੁਝ_ਨਹੀਂ() { }
ਮੁੱਲ = ਕੁਝ_ਨਹੀਂ()
>> (ਮੁੱਲ == ##_) ¶     // → #1
```

## ਆਉਟਪੁੱਟ ਅਤੇ ਇਨਪੁੱਟ

```zymbol
ਨਾਮ = "ਅਮਨ"
ਕੁੱਲ = ੩
>> "ਸਤ ਸ੍ਰੀ ਅਕਾਲ" ¶             // → ਸਤ ਸ੍ਰੀ ਅਕਾਲ
>> "a=" ਨਾਮ " b=" ਕੁੱਲ ¶ // → a=ਅਮਨ b=3
>> ਕੁੱਲ#? ¶            // → (###, 1, 3)
```

```zymbol
<< ਨਾਮ
<< "ਆਪਣਾ ਨਾਮ ਦਾਖਲ ਕਰੋ: " ਨਾਮ
<< ###(੪) "ਉਮਰ: " ਉਮਰ
```

**ਦੋ ਚਿੰਨ੍ਹਾਂ ਦੀ ਸ਼ਕਲ ਵੇਖੋ।** `>>` ਬਾਹਰ ਵੱਲ ਇਸ਼ਾਰਾ ਕਰਦਾ ਹੈ: ਇਹ ਡਾਟਾ ਨੂੰ ਪ੍ਰੋਗਰਾਮ ਤੋਂ ਬਾਹਰ ਕੱਢਦਾ ਹੈ। `<<` ਅੰਦਰ ਵੱਲ ਇਸ਼ਾਰਾ ਕਰਦਾ ਹੈ: ਇਹ ਡਾਟਾ ਨੂੰ ਪ੍ਰੋਗਰਾਮ ਵਿੱਚ ਲਿਆਉਂਦਾ ਹੈ। ਉੱਥੇ ਯਾਦ ਰੱਖਣ ਲਈ ਕੁਝ ਨਹੀਂ — ਤੀਰ ਦਿਖਾਉਂਦਾ ਹੈ ਕਿ ਜਾਣਕਾਰੀ ਕਿਸ ਦਿਸ਼ਾ ਵਿੱਚ ਯਾਤਰਾ ਕਰਦੀ ਹੈ, ਅਤੇ ਉਹੀ ਵਿਚਾਰ ਹਰ ਉਸ ਚਿੰਨ੍ਹ ਵਿੱਚ ਵਾਪਸ ਆਉਂਦਾ ਹੈ ਜੋ ਕੁਝ ਖਿਸਕਾਉਂਦਾ ਹੈ।

> `¶` ਅਤੇ `\\` ਬਰਾਬਰ ਨਵੀਆਂ ਲਾਈਨਾਂ ਹਨ। `>>` ਕਦੇ ਵੀ ਇੱਕ ਨਹੀਂ ਜੋੜਦਾ।
> ਪ੍ਰੌਂਪਟ ਤੋਂ ਪਹਿਲਾਂ ਇੱਕ ਕਿਸਮ ਨਿਰਧਾਰਕ ਪੜ੍ਹਦੇ ਸਮੇਂ ਪ੍ਰਮਾਣਿਤ ਕਰਦਾ ਹੈ ਅਤੇ ਉਦੋਂ ਤੱਕ ਮੁੜ ਪ੍ਰੌਂਪਟ ਕਰਦਾ ਹੈ ਜਦੋਂ ਤੱਕ ਮੁੱਲ ਯੋਗ ਨਾ ਹੋਵੇ:
> `##.` ਫਲੋਟ · `##.(T,D)` ਦਸ਼ਮਲਵ · `###(N)` ਪੂਰਨ ਅੰਕ · `##"(N)` ਪਾਠ · `##'` ਇੱਕ ਅੱਖਰ।

ਫਾਈਲ ਦੇ ਉੱਚੇ ਪੱਧਰ 'ਤੇ, `<~>` ਪ੍ਰੋਗਰਾਮ ਦੀ ਬਾਹਰੀ ਸਥਿਤੀ ਹੈ:

```zymbol
>> "ਜਾਂਚ ਕੀਤੀ ਜਾ ਰਹੀ ਹੈ" ¶      // → ਜਾਂਚ ਕੀਤੀ ਜਾ ਰਹੀ ਹੈ
<~ ੦
```

## TUI ਪ੍ਰਾਈਮਿਟਿਵ

ਇੰਟਰਐਕਟਿਵ ਪ੍ਰੋਗਰਾਮਾਂ ਲਈ ਟਰਮੀਨਲ UI ਓਪਰੇਟਰ। ਬਹੁਤਿਆਂ ਨੂੰ `>>| { }` ਬਲਾਕ ਦੀ ਲੋੜ ਹੁੰਦੀ ਹੈ (ਬਦਲਵੀਂ ਸਕ੍ਰੀਨ + ਕੱਚਾ ਮੋਡ)।

```zymbol
>>| {
    >>!
    >>~ (੧, ੧, ੦, ੧੦) > "ਚੱਲ ਰਿਹਾ ਹੈ"
    @~ ੧੦੦੦
    >>~ (੨, ੧) > "ਮੁਕੰਮਲ।"
}
```

```zymbol
>>| {
    [ਕਤਾਰਾਂ, ਕਾਲਮ] = >>?
    >>~ (੧, ੧) > "ਟਰਮੀਨਲ: " ਕਤਾਰਾਂ " x " ਕਾਲਮ
    <<| ਕੁੰਜੀ
    >>~ (੨, ੧) > "ਦਬਾਇਆ: " ਕੁੰਜੀ
}
```

ਇੱਥੇ ਤੁਸੀਂ ਦੇਖ ਸਕਦੇ ਹੋ ਕਿ ਚਿੰਨ੍ਹ ਕਿਉਂ ਗੁਣਾ ਹੋਣ ਦੀ ਬਜਾਏ ਜੋੜੇ ਜਾਂਦੇ ਹਨ। ਤੁਸੀਂ ਪਹਿਲਾਂ ਹੀ ਜਾਣਦੇ ਹੋ ਕਿ `<<` ਇਨਪੁੱਟ ਹੈ ਅਤੇ `?` ਵਚਨਬੱਧਤਾ ਤੋਂ ਬਿਨਾਂ ਪੁੱਛਦਾ ਹੈ। ਸਿਰਫ਼ ਇੱਕ ਚਿੰਨ੍ਹ ਨਵਾਂ ਹੈ:

- `|` **ਇੱਕ ਇਕਾਈ** ਹੈ, ਪੂਰੀ ਧਾਰਾ ਨਹੀਂ।

ਇਸ ਨਾਲ, ਦੋਵੇਂ ਕੀਬੋਰਡ ਓਪਰੇਟਰ ਆਪਣੇ ਆਪ ਪੜ੍ਹੇ ਜਾਂਦੇ ਹਨ:

```text
<<        |             ?
ਇਨਪੁੱਟ    ਇੱਕ ਇਕਾਈ    ਵਚਨਬੱਧਤਾ ਤੋਂ ਬਿਨਾਂ

<<|   ਇੱਕ ਕੁੰਜੀ ਲਓ, ਅਤੇ ਉਦੋਂ ਤੱਕ ਉਡੀਕ ਕਰੋ ਜਦੋਂ ਤੱਕ ਇੱਕ ਨਾ ਆ ਜਾਵੇ
<<|?  ਦੇਖੋ ਕਿ ਕੀ ਇੱਕ ਕੁੰਜੀ ਹੈ, ਅਤੇ ਜੇਕਰ ਨਹੀਂ ਤਾਂ ਅੱਗੇ ਵਧੋ
```

ਦੂਜੇ ਪਾਸੇ ਵੀ ਇਹੀ: `>>` ਭੇਜਦਾ ਹੈ, `>>!` **ਜ਼ੋਰ ਨਾਲ** ਭੇਜਦਾ ਹੈ (ਪੂਰੀ ਸਕ੍ਰੀਨ ਸਾਫ਼ ਕਰਦਾ ਹੈ), ਜਦੋਂ ਕਿ `>>?` ਲਿਖਣ ਦੀ ਬਜਾਏ **ਪੁੱਛਦਾ** ਹੈ (ਟਰਮੀਨਲ ਕਿੰਨਾ ਵੱਡਾ ਹੈ)। ਸੱਜੇ ਪਾਸੇ ਦਾ ਚਿੰਨ੍ਹ ਉਹ ਹੈ ਜੋ ਮੋਡ ਬਦਲਦਾ ਹੈ, ਅਤੇ ਇਹ ਹਮੇਸ਼ਾ ਆਖਰੀ ਆਉਂਦਾ ਹੈ।

> `>>!` ਸਕ੍ਰੀਨ ਸਾਫ਼ ਕਰਦਾ ਹੈ। `>>?` `(ਕਤਾਰਾਂ, ਕਾਲਮ)` ਮੁੜ-ਭੇਜਦਾ ਹੈ। `@~ N` N ਮਿਲੀਸਕਿੰਟ ਸੌਂਦਾ ਹੈ।
> `<<|` ਇੱਕ ਕੁੰਜੀ ਦਬਾਓ ਪੜ੍ਹਦਾ ਹੈ (ਬਲਾਕਿੰਗ); `<<|?` ਬਲਾਕ ਕੀਤੇ ਬਿਨਾਂ ਪੋਲ ਕਰਦਾ ਹੈ (`'\0'` ਜੇਕਰ ਕੋਈ ਨਹੀਂ)।
> ਤੀਰ ਵਾਲੀਆਂ ਕੁੰਜੀਆਂ `'↑' '↓' '←' '→'` ਵਜੋਂ ਡੀਕੋਡ ਹੁੰਦੀਆਂ ਹਨ; ESC ਕੋਡ ਬਿੰਦੂ 27 ਹੈ।
> ਸਥਿਤੀ ਆਉਟਪੁੱਟ ਟਪਲ: `(ਕਤਾਰ, ਕਾਲਮ, BKS, ਅਗਲਾ, ਪਿਛਲਾ)` — ਕੋਈ ਵੀ ਸਲਾਟ ਕਾਮੇ ਨਾਲ ਛੱਡਿਆ ਜਾ ਸਕਦਾ ਹੈ (`>>~ (,,, ੧੯੬) > "ਲਾਲ"`)।
> BKS ਬਿਟਮਾਸਕ: `1`=ਮੋਟਾ, `2`=ਤਿਰਛਾ, `4`=ਹੇਠਾਂ ਲਕੀਰ। ANSI 256-ਰੰਗ ਪੈਲੇਟ (`0`=ਟਰਮੀਨਲ ਮੂਲ)।


```zymbol

l2 = !#੧       // #੦
```

> `==` ਕਦੇ ਵੀ ਜਬਰ ਨਹੀਂ ਕਰਦਾ: `"5" == 5` `#0` ਹੈ। ਕ੍ਰਮ ਜਬਰ ਕਰਦਾ ਹੈ: `"5" > 4` `#1` ਹੈ, ਅਤੇ `"४२" > 5` ਵੀ — 69 ਲਿਪੀਆਂ ਵਿੱਚੋਂ ਕਿਸੇ ਵਿੱਚ ਸੰਖਿਆਤਮਕ ਪਾਠ ਇੱਕ ਸੰਖਿਆ ਦੇ ਤੌਰ 'ਤੇ ਤੁਲਨਾ ਕਰਦਾ ਹੈ।
> ਇੱਕ ਫੰਕਸ਼ਨ ਸਿਰਫ਼ ਆਪਣੇ ਆਪ ਦੇ ਬਰਾਬਰ ਹੈ, ਕਦੇ ਵੀ ਕਿਸੇ ਹੋਰ ਫੰਕਸ਼ਨ ਦੇ ਬਰਾਬਰ ਨਹੀਂ, ਭਾਵੇਂ ਉਸ ਦਾ ਸਰੀਰ ਇੱਕੋ ਹੋਵੇ।

## ਕੰਟਰੋਲ ਫਲੋ

```zymbol
a = ੭
? a > ੧੦੦ {
    >> "ਵੱਡਾ" ¶
} _? a > ੦ {
    >> "ਸਕਾਰਾਤਮਕ" ¶     // → ਸਕਾਰਾਤਮਕ
} _ {
    >> "ਨਕਾਰਾਤਮਕ" ¶
}
```

ਇੱਥੇ ਦੋ ਨਵੇਂ ਚਿੰਨ੍ਹ ਹਨ, ਅਤੇ ਤੀਜਾ ਜੋ ਉਹਨਾਂ ਨੂੰ ਇਕੱਠੇ ਰੱਖਣ ਨਾਲ ਆਉਂਦਾ ਹੈ:

- `?` **ਪੁੱਛਣਾ** ਹੈ: ਇਹ ਇੱਕ ਸ਼ਰਤ ਖੋਲ੍ਹਦਾ ਹੈ।
- `_` **ਉਹ ਹੈ ਜੋ ਨਿਰਧਾਰਤ ਨਹੀਂ ਕੀਤਾ ਗਿਆ**: ਉਹ ਸ਼ਾਖ ਜੋ ਬਾਕੀ ਰਹਿ ਜਾਂਦੀ ਹੈ ਜਦੋਂ ਕੋਈ ਸਵਾਲ ਮੇਲ ਨਹੀਂ ਖਾਂਦਾ।
- `_?` ਦੋਵੇਂ ਇਕੋ ਪੰਕਤੀ ਵਿੱਚ: *ਜੇਕਰ ਕੁਝ ਮੇਲ ਨਹੀਂ ਖਾਧਾ, ਤਾਂ ਮੁੜ ਪੁੱਛੋ*।

ਇਸੇ ਲਈ `_?` ਇਸ ਤਰ੍ਹਾਂ ਲਿਖਿਆ ਜਾਂਦਾ ਹੈ। ਇਹ ਸਿੱਖਣ ਲਈ ਕੋਈ ਨਵਾਂ ਚਿੰਨ੍ਹ ਨਹੀਂ ਹੈ — ਇਹ `_` ਹੈ ਜਿਸ ਦੇ ਬਾਅਦ `?` ਆਉਂਦਾ ਹੈ, ਅਤੇ ਇਸ ਦਾ ਮਤਲਬ ਬਿਲਕੁਲ ਉਹੀ ਹੈ ਜੋ ਇਸ ਦੇ ਦੋ ਹਿੱਸਿਆਂ ਦਾ ਮਤਲਬ ਹੈ, ਕ੍ਰਮ ਵਿੱਚ ਪੜ੍ਹਿਆ ਗਿਆ।

> ਬਰੈਕਟ `{ }` ਇੱਕ ਬਿਆਨ ਲਈ ਵੀ **ਲਾਜ਼ਮੀ** ਹਨ।

## ਮੇਲ

```zymbol
ਸਕੋਰ = ੮੫
ਗਰੇਡ = ?? ਸਕੋਰ {

    ੮੦..੮੯  => 'B'
    _       => 'F'
```

```zymbol
ਤਾਪਮਾਨ = -੫
ਸਥਿਤੀ = ?? ਤਾਪਮਾਨ {
    < ੦  => "ਬਰਫ਼"
    < ੨੦ => "ਠੰਡਾ"
    _    => "ਗਰਮ"
}
>> ਸਥਿਤੀ ¶              // → ਬਰਫ਼
```

ਤੁਸੀਂ ਪਹਿਲਾਂ ਹੀ ਜਾਣਦੇ ਹੋ ਕਿ `?` "ਪੁੱਛਣਾ" ਹੈ। **`??` ਵਾਰ-ਵਾਰ ਪੁੱਛਣਾ ਹੈ**: ਇੱਕ ਚਿੰਨ੍ਹ ਨੂੰ ਦੁੱਗਣਾ ਕਰਨਾ, ਭਾਸ਼ਾ ਵਿੱਚ ਕਿਤੇ ਵੀ, ਉਹ ਚਿੰਨ੍ਹ ਜੋ ਇੱਕ ਵਾਰ ਕਰਦਾ ਹੈ ਉਸ ਨੂੰ ਕਈ ਵਾਰ ਕਰਨਾ ਹੈ। ਇੱਕ `?` ਇੱਕ ਸ਼ਰਤ ਦੀ ਜਾਂਚ ਕਰਦਾ ਹੈ; `??` ਕੇਸਾਂ ਦੀ ਇੱਕ ਸੂਚੀ ਦੇ ਵਿਰੁੱਧ ਜਾਂਚ ਕਰਦਾ ਹੈ।

ਵਿਕਲਪ `||` ਨਾਲ ਜੁੜਦੇ ਹਨ, ਅਤੇ ਉਹ ਪੈਟਰਨ ਕਿਸਮਾਂ ਨੂੰ ਮਿਕਸ ਕਰ ਸਕਦੇ ਹਨ:

```zymbol
ਕੁੰਜੀ = 'P'
ਕਿਰਿਆ = ?? ਕੁੰਜੀ {
    'p' || 'P' => "ਵਿਰਾਮ"
    < ੦ || > ੧੦੦ => "ਸੀਮਾ ਤੋਂ ਬਾਹਰ"
    _ => "ਅਣਡਿੱਠ"
}
>> ਕਿਰਿਆ ¶             // → ਵਿਰਾਮ
```

## ਲੂਪ

```zymbol
@ i:੧..੪  { >> i " " }
>> ¶                    // → 1 2 3 4

>> ¶                    // → 1 3 5 7 9

```

```zymbol
n = ੧
@ n <= ੬੪ { n *= ੨ }
>> n ¶                  // → 128
```

```zymbol
ਫਲ = ["ਸੇਬ", "ਨਾਸ਼ਪਾਤੀ", "ਅੰਗੂਰ"]
@ f:ਫਲ { >> f " " }
>> ¶                    // → ਸੇਬ ਨਾਸ਼ਪਾਤੀ ਅੰਗੂਰ
@ c:"ਸਤ ਸ੍ਰੀ ਅਕਾਲ" { >> c "-" }
>> ¶                    // → ਸ-ਤ- -ਸ-੍-ਰ-ੀ- -ਅ-ਕ-ਾ-ਲ-
```

```zymbol
    ? i % ੨ == ੦ { @> }
    ? i > ੭ { @! }
    >> i " "

>> ¶                    // → 1 3 5 7
```

```zymbol
ਗਿਣਤੀ = ੦
@:ਬਾਹਰੀ {
    ਗਿਣਤੀ++
    ? ਗਿਣਤੀ >= ੩ { @:ਬਾਹਰੀ! }
}
>> ਗਿਣਤੀ ¶             // → 3
```

`@` **ਸਮੇਂ** ਦਾ ਚਿੰਨ੍ਹ ਹੈ: ਜੋ ਕੁਝ ਵੀ ਦੁਹਰਾਉਂਦਾ ਹੈ ਉਹ ਇਸ ਵਿੱਚ ਰਹਿੰਦਾ ਹੈ। ਉਸ ਸਮੇਂ ਨੂੰ ਛੋਟਾ ਕਰਨ ਲਈ ਤੁਸੀਂ ਇਸ ਦੇ ਕੋਲ ਇੱਕ ਚਿੰਨ੍ਹ ਜੋੜਦੇ ਹੋ:

- `@!` — `!` **ਜ਼ੋਰ** ਹੈ: ਹੁਣੇ ਲੂਪ ਛੱਡੋ।
- `@>` — `>` ਅੱਗੇ ਧੱਕਦਾ ਹੈ: ਅਗਲੇ ਗੇੜ 'ਤੇ ਜਾਓ।
- `@:ਬਾਹਰੀ!` — `:` **ਇੱਕ ਨਾਮ ਬੰਨ੍ਹਦਾ** ਹੈ, ਇਸ ਲਈ ਇਹ *ਬਾਹਰੀ* ਨਾਮ ਵਾਲੇ ਲੂਪ ਨੂੰ ਕੱਟਦਾ ਹੈ, ਨਜ਼ਦੀਕੀ ਨੂੰ ਨਹੀਂ।

ਤਿੰਨ ਓਪਰੇਟਰ, ਅਤੇ ਉਹਨਾਂ ਵਿੱਚੋਂ ਕਿਸੇ ਨੂੰ ਵੱਖਰੇ ਤੌਰ 'ਤੇ ਯਾਦ ਕਰਨ ਦੀ ਲੋੜ ਨਹੀਂ ਸੀ: ਉਹ `@` ਹਨ ਅਤੇ ਇੱਕ ਚਿੰਨ੍ਹ ਜੋ ਪਹਿਲਾਂ ਹੀ ਦੱਸਦਾ ਹੈ ਕਿ ਇਹ ਕੀ ਕਰਦਾ ਹੈ।

> **ਇੱਕ ਨਿਰਧਾਰਕ ਇੱਕ ਗਿਣਤੀ ਜਾਂ ਇੱਕ ਸ਼ਰਤ ਹੈ।** ਇੱਕ `ਪੂਰਨ ਅੰਕ` ਇੱਕ ਗਿਣਤੀ ਹੈ, ਇੱਕ ਵਾਰ ਮੁਲਾਂਕਣ ਕੀਤੀ ਜਾਂਦੀ ਹੈ — `@ 0` ਸਰੀਰ ਨੂੰ ਜ਼ੀਰੋ ਵਾਰ ਚਲਾਉਂਦਾ ਹੈ। ਬਾਕੀ ਸਭ ਕੁਝ ਇੱਕ ਸ਼ਰਤ ਹੈ। ਕੋਈ ਸੱਚਾਈ ਨਹੀਂ: `@ []` ਅਤੇ `@ 3.5` ਨੂੰ ਰੱਦ ਕਰ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ। ਕਿਸੇ ਸੰਗ੍ਰਹਿ ਨੂੰ ਪਾਰ ਕਰਨ ਲਈ `@ x:ਆਈਟਮ` ਵਰਤੋ; ਇਸ ਨੂੰ ਗਿਣਨ ਲਈ, `@ ਆਈਟਮ$#`।

## ਫੰਕਸ਼ਨ

```zymbol
ਜੋੜ(a, b) { <~ a + b }
>> ਜੋੜ(੩, ੪) ¶        // → 7
```

```zymbol
ਫੈਕਟੋਰੀਅਲ(n) {
    ? n <= ੧ { <~ ੧ }
    <~ n * ਫੈਕਟੋਰੀਅਲ(n - ੧)
}
>> ਫੈਕਟੋਰੀਅਲ(੫) ¶       // → 120
```

ਇੱਕ ਫੰਕਸ਼ਨ ਫਾਈਲ ਦੇ ਵੇਰੀਏਬਲਾਂ ਨੂੰ ਮੁੱਲ ਦੁਆਰਾ ਪੜ੍ਹਦਾ ਹੈ, ਅਤੇ ਅੰਦਰ ਇੱਕ ਲਿਖਤ ਅੰਦਰ ਹੀ ਰਹਿੰਦੀ ਹੈ:

```zymbol
ਸੀਮਾ = ੧੦੦
ਅੰਦਰ(n) { <~ n < ਸੀਮਾ }
>> ਅੰਦਰ(੪੨) ¶         // → #1
```

ਦੋ ਚਿੰਨ੍ਹ ਇਸ ਨੂੰ ਬਦਲਦੇ ਹਨ, ਅਤੇ ਦੋਵੇਂ **ਦਸਤਖ਼ਤ ਅਤੇ ਕਾਲ ਸਾਈਟ** 'ਤੇ ਲਿਖੇ ਜਾਂਦੇ ਹਨ:

```zymbol
ਵਧਾਓ(ਗਿਣਤੀ<~) { ਗਿਣਤੀ = ਗਿਣਤੀ + ੧ }
ਕੁੱਲ = ੦
ਵਧਾਓ(ਕੁੱਲ<~)
>> ਕੁੱਲ ¶              // → 1
```

> `p~` ਇੱਕ ਕੰਮ ਕਰਨ ਵਾਲੀ ਕਾਪੀ ਹੈ — ਸਰੀਰ ਇਸ ਨੂੰ ਮੁੜ ਨਿਰਧਾਰਤ ਕਰ ਸਕਦਾ ਹੈ ਅਤੇ ਕਾਲ ਕਰਨ ਵਾਲਾ ਅਛੂਤ ਰਹਿੰਦਾ ਹੈ।
> `p<~` ਇੱਕ ਆਉਟਪੁੱਟ ਪੈਰਾਮੀਟਰ ਹੈ — ਤਬਦੀਲੀ ਵਾਪਸ ਯਾਤਰਾ ਕਰਦੀ ਹੈ। ਚਿੰਨ੍ਹ ਤੋਂ ਬਿਨਾਂ `ਵਧਾਓ(ਕੁੱਲ)` ਇੱਕ ਅਰਥ ਸੰਬੰਧੀ ਗ਼ਲਤੀ ਹੈ: ਐਨੋਟੇਸ਼ਨ ਅਤੇ ਦਸਤਖ਼ਤ ਵੱਖ ਨਹੀਂ ਹੋ ਸਕਦੇ।

## ਐਰੇ

```zymbol
ਐਰੇ = [੧, ੨, ੩, ੪, ੫]
>> ਐਰੇ[੧] ¶       // → 1   ਇੰਡੈਕਸ 1-ਅਧਾਰਿਤ ਹੈ
>> ਐਰੇ[-੧] ¶      // → 5   ਨਕਾਰਾਤਮਕ ਅੰਤ ਤੋਂ ਗਿਣਦਾ ਹੈ
>> ਐਰੇ$# ¶        // → 5   ਲੰਬਾਈ
```

```zymbol
ਐਰੇ = [੧, ੨, ੩]
>> (ਐਰੇ$+ ੬) ¶          // → [1, 2, 3, 6]   ਜੋੜੋ
>> (ਐਰੇ$+[੨] ੯੯) ¶      // → [1, 99, 2, 3]  ਸਥਿਤੀ 2 'ਤੇ ਪਾਓ
>> (ਐਰੇ$- ੩) ¶          // → [1, 2]         ਪਹਿਲੀ ਵਾਰ ਆਉਣ ਨੂੰ ਹਟਾਓ
>> (ਐਰੇ$-[੧]) ¶         // → [2, 3]         ਇੰਡੈਕਸ 1 'ਤੇ ਹਟਾਓ
>> (ਐਰੇ$[੧..੨]) ¶       // → [1, 2]         ਟੁਕੜਾ, ਦੋਵੇਂ ਸਿਰੇ ਸ਼ਾਮਲ
>> (ਐਰੇ$? ੩) ¶          // → #1             ਹੈ
```

ਇਹ ਸਾਰੇ `$` ਨਾਲ ਸ਼ੁਰੂ ਹੁੰਦੇ ਹਨ, ਜੋ **ਸੰਗ੍ਰਹਿ** ਦਾ ਚਿੰਨ੍ਹ ਹੈ, ਅਤੇ ਇੱਕ ਚਿੰਨ੍ਹ ਨਾਲ ਜਾਰੀ ਰਹਿੰਦੇ ਹਨ ਜੋ ਦੱਸਦਾ ਹੈ ਕਿ ਇਸ ਵਿੱਚ ਕੀ ਕੀਤਾ ਜਾਂਦਾ ਹੈ: `#` ਕਿੰਨੇ, `+` ਜੋੜੋ, `-` ਹਟਾਓ, `?` ਪੁੱਛੋ ਕਿ ਕੀ ਹੈ। ਅਤੇ ਜਿਵੇਂ `??` ਦੇ ਨਾਲ, ਚਿੰਨ੍ਹ ਨੂੰ ਦੁੱਗਣਾ ਕਰਨ ਦਾ ਮਤਲਬ ਹੈ ਇਸ ਨੂੰ ਪੂਰੀ ਤਰ੍ਹਾਂ ਕਰਨਾ: `$?` ਪੁੱਛਦਾ ਹੈ *ਕੀ* ਕੋਈ ਮੁੱਲ ਮੌਜੂਦ ਹੈ, `$??` ਪੁੱਛਦਾ ਹੈ *ਕਿੰਨੀਆਂ ਥਾਵਾਂ 'ਤੇ* ਅਤੇ ਉਹਨਾਂ ਸਾਰਿਆਂ ਨੂੰ ਵਾਪਸ ਭੇਜਦਾ ਹੈ।

```zymbol
ਐਰੇ = [੩, ੧, ੨]
>> (ਐਰੇ$^+) ¶     // → [1, 2, 3]   ਚੜ੍ਹਦਾ
>> (ਐਰੇ$^-) ¶     // → [3, 2, 1]   ਲਹਿੰਦਾ
```

**ਨਤੀਜੇ ਦਾ ਨਿਯਮ।** ਇੱਕ ਓਪਰੇਟਰ, ਅਤੇ ਆਸ-ਪਾਸ ਦਾ ਕੋਡ ਇਸ ਨਾਲ ਕੀ ਕਰਦਾ ਹੈ, ਇਹ ਫੈਸਲਾ ਕਰਦਾ ਹੈ: ਵਰਤਿਆ ਗਿਆ, ਇਹ **ਬਣਾਉਂਦਾ** ਹੈ ਅਤੇ ਮੂਲ ਨੂੰ ਇਕੱਲਾ ਛੱਡ ਦਿੰਦਾ ਹੈ; ਰੱਦ ਕੀਤਾ ਗਿਆ, ਇਹ **ਸੋਧ** ਕਰਦਾ ਹੈ।

```zymbol
ਐਰੇ = [੧, ੨, ੩]
ਕਾਪੀ = ਐਰੇ[੨]$~ ੯੯
>> ਐਰੇ ¶                // → [1, 2, 3]
>> ਕਾਪੀ ¶              // → [1, 99, 3]
ਐਰੇ[੨]$~ ੯੯
>> ਐਰੇ ¶                // → [1, 99, 3]
```

> **`=` ਕਦੇ ਵੀ ਕਿਸੇ ਸੰਗ੍ਰਹਿ ਵਿੱਚ ਨਹੀਂ ਲਿਖਦਾ।** `ਐਰੇ[2] = 99` Zymbol ਦਾ ਇੱਕ ਰੂਪ ਨਹੀਂ ਹੈ — `=` ਇੱਕ **ਨਾਮ** ਨੂੰ ਇੱਕ ਮੁੱਲ ਦਿੰਦਾ ਹੈ। ਕਿਸੇ ਸੰਗ੍ਰਹਿ ਦੇ ਇੱਕ ਹਿੱਸੇ ਨੂੰ ਬਦਲਣਾ `$~` ਹੈ, ਹਰ ਸੰਗ੍ਰਹਿ ਵਿੱਚ।

`[…]` ਇੱਕ ਕਿਸਮ ਰੱਖਦਾ ਹੈ ਅਤੇ ਜਾਂਚਿਆ ਜਾਂਦਾ ਹੈ; ਇੱਕ ਜਾਣਬੁੱਝ ਕੇ ਮਿਸ਼ਰਣ `#[…]` ਨਾਲ **ਐਲਾਨਿਆ** ਜਾਂਦਾ ਹੈ:

```zymbol
ਮਿਸ਼ਰਣ = #[੧, "ਦੋ", #੧]
>> ਮਿਸ਼ਰਣ ¶             // → [1, ਦੋ, #1]
>> ([੧, ੨] == #[੧, ੨]) ¶ // → #1
```

## ਬਹੁ-ਅਯਾਮੀ ਇੰਡੈਕਸਿੰਗ

`>` ਇੱਕ ਨੇਸਟਡ ਢਾਂਚੇ ਵਿੱਚ ਹੇਠਾਂ ਜਾਂਦਾ ਹੈ। ਬਰੈਕਟਾਂ ਦਾ ਇੱਕ ਸਮੂਹ ਇੱਕ ਤੱਤ ਨੂੰ ਸੰਬੋਧਿਤ ਕਰਦਾ ਹੈ, ਭਾਵੇਂ ਇਹ ਕਿੰਨਾ ਵੀ ਡੂੰਘਾ ਹੋਵੇ।

```zymbol
m = [[੧,੨,੩], [੪,੫,੬], [੭,੮,੯]]
>> m[੨>੩] ¶        // → 6   ਕਤਾਰ 2, ਕਾਲਮ 3
>> m[-੧>-੧] ¶      // → 9   ਆਖਰੀ ਕਤਾਰ, ਆਖਰੀ ਕਾਲਮ
```

```zymbol
m = [[੧,੨,੩], [੪,੫,੬], [੭,੮,੯]]
>> m[੧>੧ ; ੨>੨ ; ੩>੩] ¶          // → [1, 5, 9]          ਸਮਤਲ: ਵਿਕਰਣ
>> m[[੧>੧, ੧>੩] ; [੩>੧, ੩>੩]] ¶  // → [[1, 3], [7, 9]]   ਢਾਂਚਾਗਤ: ਕੋਨੇ
```

```zymbol
m = [[੧,੨,੩], [੪,੫,੬]]
>> (m[੧>੨]$~ ੯੯) ¶      // → [[1, 99, 3], [4, 5, 6]]
```

> `m[1][2]` Zymbol ਦਾ ਇੱਕ ਰੂਪ **ਨਹੀਂ** ਹੈ। ਲੜੀਬੱਧ ਇੰਡੈਕਸ ਨੂੰ ਪੜ੍ਹਨ ਅਤੇ ਲਿਖਣ ਦੋਵਾਂ ਲਈ ਰੱਦ ਕਰ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ — ਪ੍ਰਤੀ ਪਹੁੰਚ ਬਰੈਕਟਾਂ ਦਾ ਇੱਕ ਸਮੂਹ, ਅਤੇ `>` ਉਹ ਹੈ ਜੋ ਕਦਮਾਂ ਦੇ ਵਿਚਕਾਰ ਜਾਂਦਾ ਹੈ।

## ਡਿਕਸ਼ਨਰੀ

ਇੱਕ ਨਾਮ ਵਾਲੇ ਖੇਤਰਾਂ ਵਾਲਾ ਟਪਲ ਇੱਕ ਡਿਕਸ਼ਨਰੀ ਹੈ, ਅਤੇ v0.0.9 ਤੋਂ ਇਸ ਨੂੰ `#(…)` ਲਿਖਿਆ ਜਾਂਦਾ ਹੈ।

```zymbol
ਵਿਅਕਤੀ = #(ਨਾਮ: "ਅਮਨ", ਉਮਰ: ੨੫)
>> ਵਿਅਕਤੀ.ਨਾਮ ¶        // → ਅਮਨ
>> ਵਿਅਕਤੀ["ਉਮਰ"] ¶    // → 25
```

```zymbol
ਵਿਅਕਤੀ = #(ਨਾਮ: "ਅਮਨ", ਉਮਰ: ੨੫)
ਖੇਤਰ = "ਨਾਮ"
>> ਵਿਅਕਤੀ[ਖੇਤਰ] ¶     // → ਅਮਨ
```

ਇਹ ਪਰਿਵਰਤਨਸ਼ੀਲ ਹੈ, ਕੁੰਜੀਆਂ ਜੋੜੀਆਂ ਜਾ ਸਕਦੀਆਂ ਹਨ, ਅਤੇ ਇਸ ਨੂੰ ਪਾਰ ਕੀਤਾ ਜਾ ਸਕਦਾ ਹੈ:

```zymbol
ਸਟਾਕ = #(ਨਾਸ਼ਪਾਤੀ: ੪)
ਸਟਾਕ["ਸੇਬ"]$~ ੧੦
@ k:ਸਟਾਕ { >> k "=" ਸਟਾਕ[k] " " }
>> ¶                    // → ਨਾਸ਼ਪਾਤੀ=4 ਸੇਬ=10
```

```zymbol
ਸਟਾਕ = #(ਨਾਸ਼ਪਾਤੀ: ੪, ਸੇਬ: ੧੦)
@ (k, v):ਸਟਾਕ { >> k ":" v " " }
>> ¶                    // → ਨਾਸ਼ਪਾਤੀ:4 ਸੇਬ:10
```

> `#()` ਖਾਲੀ ਡਿਕਸ਼ਨਰੀ ਹੈ, ਜੋ `()` ਨਹੀਂ ਹੋ ਸਕਦੀ ਸੀ — ਇਸ ਨੂੰ ਖਾਲੀ ਟਪਲ ਵੀ ਹੋਣਾ ਪੈਂਦਾ। ਨੰਗੀ `(a: 1)` ਨੂੰ ਇਸ ਸੰਦੇਸ਼ ਨਾਲ ਰੱਦ ਕਰ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ: *a dictionary is written `#(…)`* — «ਇੱਕ ਡਿਕਸ਼ਨਰੀ `#(…)` ਲਿਖੀ ਜਾਂਦੀ ਹੈ»।
> ਇੱਕ ਡਿਕਸ਼ਨਰੀ ਨੂੰ ਕੁੰਜੀ ਦੁਆਰਾ ਸੰਬੋਧਿਤ ਕੀਤਾ ਜਾਂਦਾ ਹੈ, ਕਦੇ ਵੀ ਸਥਿਤੀ ਦੁਆਰਾ ਨਹੀਂ, ਇਸ ਲਈ `ਵਿਅਕਤੀ[1]` ਇੱਕ ਗ਼ਲਤੀ ਹੈ।

## ਟਪਲ

ਟਪਲ **ਅਟੁੱਟ** ਕ੍ਰਮਬੱਧ ਕੰਟੇਨਰ ਹਨ ਜੋ ਵੱਖ-ਵੱਖ ਕਿਸਮਾਂ ਦੇ ਮੁੱਲ ਰੱਖਦੇ ਹਨ।

```zymbol
ਬਿੰਦੂ = (੧੦, ੨੦)
>> ਬਿੰਦੂ[੧] ¶           // → 10
ਡਾਟਾ = (੪੨, "ਸਤ ਸ੍ਰੀ ਅਕਾਲ", #੧, ੩.੧੪)
>> ਡਾਟਾ[੩] ¶            // → #1
```

```zymbol
t = (੧੦, ੨੦, ੩੦)
t2 = t[੨]$~ ੯੯੯
>> t ¶                  // → (10, 20, 30)
>> t2 ¶                 // → (10, 999, 30)
```

> ਕਿਸੇ ਟਪਲ ਨੂੰ ਉਸ ਦੀ ਥਾਂ 'ਤੇ ਸੋਧਣ ਦੀ ਕੋਈ ਵੀ ਕੋਸ਼ਿਸ਼ ਇੱਕ ਗ਼ਲਤੀ ਹੈ, ਭਾਵੇਂ ਓਪਰੇਟਰ ਕੋਈ ਵੀ ਹੋਵੇ — ਅਟੁੱਟਤਾ ਮੁੱਲ ਦੀ ਇੱਕ ਵਿਸ਼ੇਸ਼ਤਾ ਹੈ, ਹਰ `$` ਦੇ ਅੰਦਰ ਕੋਈ ਅਪਵਾਦ ਨਹੀਂ।

## ਡੀਸਟ੍ਰਕਚਰਿੰਗ

```zymbol
ਐਰੇ = [੧੦, ੨੦, ੩੦, ੪੦, ੫੦]
[a, b, c] = ਐਰੇ
>> a " " b " " c ¶      // → 10 20 [30, 40, 50]
```

```zymbol
ਐਰੇ = [੧੦, ੨੦, ੩੦, ੪੦, ੫੦]
[ਪਹਿਲਾ, *ਬਾਕੀ] = ਐਰੇ
>> ਪਹਿਲਾ ¶            // → 10
>> ਬਾਕੀ ¶              // → [20, 30, 40, 50]
```

```zymbol
ਬਿੰਦੂ = (੧੦੦, ੨੦੦)
(px, py) = ਬਿੰਦੂ
>> px " " py ¶          // → 100 200
```

```zymbol
ਵਿਅਕਤੀ = #(ਨਾਮ: "ਗੁਰਮੀਤ", ਉਮਰ: ੨੫)
#(ਨਾਮ: n, ਉਮਰ: u) = ਵਿਅਕਤੀ
>> n " " u ¶            // → ਗੁਰਮੀਤ 25
```

> ਬਰੈਕਟ ਦੀ ਸ਼ਕਲ ਟਾਈਪ ਕੀਤੀ ਗਈ ਹੈ: `[…]` ਇੱਕ ਐਰੇ ਲੈਂਦਾ ਹੈ, `(…)` ਇੱਕ ਟਪਲ, `#(…)` ਇੱਕ ਡਿਕਸ਼ਨਰੀ। ਆਖਰੀ ਨਾਮ **ਬਾਕੀ ਨੂੰ ਜਜ਼ਬ** ਕਰਦਾ ਹੈ, ਇਸ ਲਈ ਡੀਸਟ੍ਰਕਚਰਿੰਗ ਕਦੇ ਵੀ ਲੰਬਾਈ 'ਤੇ ਅਸਫਲ ਨਹੀਂ ਹੁੰਦੀ — `(a, b, c) = (1,2,3,4,5)` `c = (3,4,5)` ਦਿੰਦਾ ਹੈ, ਅਤੇ `##_` ਜਦੋਂ ਕੁਝ ਨਹੀਂ ਬਚਦਾ।

## ਉੱਚ-ਕ੍ਰਮ ਫੰਕਸ਼ਨ

```zymbol
ਅੰਕ = [੧, ੨, ੩, ੪, ੫]
>> (ਅੰਕ$> (a -> a * ੨)) ¶ // → [2, 4, 6, 8, 10]
>> (ਅੰਕ$| (a -> a % ੨ == ੦)) ¶ // → [2, 4]
>> (ਅੰਕ$< (੦, (ਇਕੱਠਾ, a) -> ਇਕੱਠਾ + a)) ¶ // → 15
```

```zymbol
ਅੰਕ = [੧, ੨, ੩, ੪, ੫, ੬]
ਦੁੱਗਣਾ(a) { <~ a * ੨ }
ਵੱਡਾ(a) { <~ a > ੩ }
>> (ਅੰਕ$> ਦੁੱਗਣਾ) ¶    // → [2, 4, 6, 8, 10, 12]
>> (ਅੰਕ$| ਵੱਡਾ) ¶    // → [4, 5, 6]
```

```zymbol
ਡਾਟਾਬੇਸ = [#(ਨਾਮ: "ਕਾਰਲਾ", ਉਮਰ: ੨੮), #(ਨਾਮ: "ਗੁਰਮੀਤ", ਉਮਰ: ੨੫)]
ਉਮਰ_ਅਨੁਸਾਰ = ਡਾਟਾਬੇਸ$^ (a, b -> a.ਉਮਰ < b.ਉਮਰ)
>> ਉਮਰ_ਅਨੁਸਾਰ[੧].ਨਾਮ ¶     // → ਗੁਰਮੀਤ
```

> ਇੱਕ ਨਾਮ ਵਾਲਾ ਫੰਕਸ਼ਨ HOF ਵਿੱਚ **ਬਰੈਕਟ ਤੋਂ ਬਿਨਾਂ** ਜਾਂਦਾ ਹੈ: `ਅੰਕ$> ਦੁੱਗਣਾ`। `ਅੰਕ$> (ਦੁੱਗਣਾ)` ਲਿਖਣਾ ਇੱਕ ਪਾਰਸ ਗ਼ਲਤੀ ਹੈ, ਕਿਉਂਕਿ `(` ਇੱਕ ਲਾਂਬਡਾ ਖੋਲ੍ਹਦਾ ਹੈ।

## ਗ਼ਲਤੀ ਹੈਂਡਲਿੰਗ

```zymbol
!? {
    a = ੧੦ / ੦
} :! ##Div {
    >> "ਜ਼ੀਰੋ ਨਾਲ ਭਾਗ" ¶  // → ਜ਼ੀਰੋ ਨਾਲ ਭਾਗ
} :! {
    >> "ਹੋਰ: " _err ¶
} :> {
    >> "ਹਮੇਸ਼ਾ ਚੱਲਦਾ ਹੈ" ¶        // → ਹਮੇਸ਼ਾ ਚੱਲਦਾ ਹੈ
}
```

| ਕਿਸਮ | ਕਦੋਂ |
|------|------|
| `##Div` | ਜ਼ੀਰੋ ਨਾਲ ਭਾਗ |
| `##Index` | ਇੰਡੈਕਸ ਸੀਮਾ ਤੋਂ ਬਾਹਰ |
| `##Key` | ਡਿਕਸ਼ਨਰੀ ਵਿੱਚ ਕੁੰਜੀ ਨਹੀਂ |
| `##Range` | ਸੁਰੱਖਿਅਤ ਪੂਰਨ ਅੰਕ ਸੀਮਾ ਤੋਂ ਬਾਹਰ |
| `##Type` | ਕਿਸਮ ਬੇਮੇਲ |
| `##Parse` | ਡਾਟਾ ਪਾਰਸਿੰਗ |
| `##IO` | ਫਾਈਲ / ਸਿਸਟਮ |
| `##Network` | ਨੈੱਟਵਰਕ ਗ਼ਲਤੀਆਂ |
| `##DB` | ਡਾਟਾਬੇਸ |
| `##Time` | ਇੱਕ ਮਿਤੀ ਜੋ ਮੌਜੂਦ ਨਹੀਂ |
| `##_` | ਕੋਈ ਵੀ ਗ਼ਲਤੀ (ਸਭ ਫੜਨ ਵਾਲਾ) |

`!` **ਗ਼ਲਤੀ ਅਤੇ ਜ਼ੋਰ** ਦਾ ਚਿੰਨ੍ਹ ਹੈ, ਅਤੇ ਇਹ ਦੋਵੇਂ ਪਰਿਵਾਰਾਂ ਵਿੱਚ ਇੱਕੋ ਜਿਹਾ ਪੜ੍ਹਿਆ ਜਾਂਦਾ ਹੈ: `$!` ਇੱਕ ਮੁੱਲ ਨੂੰ ਪੁੱਛਦਾ ਹੈ ਕਿ ਕੀ ਇਹ ਗ਼ਲਤੀ ਹੈ; `$!!`, ਚਿੰਨ੍ਹ ਨੂੰ ਦੁੱਗਣਾ ਕਰਨ ਨਾਲ, ਬਿਨਾਂ ਪੁੱਛੇ ਇਸ ਨੂੰ ਉੱਪਰ ਪ੍ਰਸਾਰਿਤ ਕਰਦਾ ਹੈ।

> ਸਟੈਂਡਰਡ ਲਾਇਬ੍ਰੇਰੀ ਦੀਆਂ ਅਸਫਲਤਾਵਾਂ **ਨਰਮ ਗ਼ਲਤੀ ਮੁੱਲਾਂ** ਦੇ ਰੂਪ ਵਿੱਚ ਵਾਪਸ ਆਉਂਦੀਆਂ ਹਨ ਜਿਨ੍ਹਾਂ ਨੂੰ ਤੁਸੀਂ `$!` ਨਾਲ ਟੈਸਟ ਕਰਦੇ ਹੋ ਜਾਂ `!?` ਨਾਲ ਫੜਦੇ ਹੋ, ਰੋਕਣ ਦੀ ਬਜਾਏ। `$!!` ਇੱਕ ਨੂੰ ਕਾਲ ਕਰਨ ਵਾਲੇ ਨੂੰ ਪ੍ਰਸਾਰਿਤ ਕਰਦਾ ਹੈ।

## ਮੋਡੀਊਲ

```zymbol
# ਕੈਲਕ {
    #> { ਜੋੜ, PI }

    PI := ੩.੧੪੧੫੯
    ਜੋੜ(a, b) { <~ a + b }
}
```

```zymbol
<# ./ਕੈਲਕ => c

>> c::ਜੋੜ(੫, ੩) ¶
>> c.PI ¶
```

```zymbol
# ਮੇਰੀ_ਲਾਇਬ {
    #> { ਅੰਦਰੂਨੀ_ਜੋੜ => ਜੋੜਫਲ }

    ਅੰਦਰੂਨੀ_ਜੋੜ(a, b) { <~ a + b }
}
```

ਦੋ ਮੋਡੀਊਲ ਚਿੰਨ੍ਹ ਇੱਕੋ ਵਿਚਾਰ ਹਨ, ਹੁਣ ਫਾਈਲਾਂ 'ਤੇ ਲਾਗੂ: `#` **ਐਲਾਨ** ਦਾ ਪੱਧਰ ਹੈ — ਕੋਈ ਚੀਜ਼ *ਕੀ ਹੈ*, ਉਸ ਦਾ ਮੁੱਲ ਨਹੀਂ — ਅਤੇ ਤੀਰ ਦੱਸਦਾ ਹੈ ਕਿ ਕੋਡ ਕਿਸ ਦਿਸ਼ਾ ਵਿੱਚ ਯਾਤਰਾ ਕਰਦਾ ਹੈ:

```text
<#   ਤੀਰ ਅੰਦਰ ਆਉਂਦਾ ਹੈ: ਇੰਪੋਰਟ ਕਰੋ, ਦੂਜੀ ਫਾਈਲ ਤੋਂ ਲਿਆਓ
#>   ਤੀਰ ਬਾਹਰ ਨਿਕਲਦਾ ਹੈ: ਐਕਸਪੋਰਟ ਕਰੋ, ਦੂਜੀਆਂ ਫਾਈਲਾਂ ਨੂੰ ਪੇਸ਼ ਕਰੋ
```

ਇੱਕ ਦਿਸ਼ਾ ਚਿੰਨ੍ਹ ਹਮੇਸ਼ਾ ਉਸ ਕਿਨਾਰੇ 'ਤੇ ਬੈਠਦਾ ਹੈ ਜਿਸ ਦਿਸ਼ਾ ਵਿੱਚ ਇਹ ਇਸ਼ਾਰਾ ਕਰਦਾ ਹੈ। ਇਹ ਉਹੀ ਕਾਰਨ ਹੈ ਕਿ `<~` ਖੱਬੇ ਪਾਸੇ ਵਾਪਸ ਆਉਂਦਾ ਹੈ (ਫੰਕਸ਼ਨ ਤੋਂ ਬਾਹਰ) ਅਤੇ `->` ਸੱਜੇ ਪਾਸੇ ਅੰਦਰ ਆਉਂਦਾ ਹੈ (ਲਾਂਬਡਾ ਦੇ ਸਰੀਰ ਵਿੱਚ)।

> **ਇੱਕ ਮੋਡੀਊਲ ਐਲਾਨ ਕਰਦਾ ਹੈ ਕਿ ਇਹ ਕੀ ਐਕਸਪੋਰਟ ਕਰਦਾ ਹੈ।** `#>` ਬਲਾਕ ਲਾਜ਼ਮੀ ਹੈ — ਇਸ ਨੂੰ ਛੱਡਣਾ **E014** ਹੈ, ਅਤੇ `#> { }` ਉਹ ਤਰੀਕਾ ਹੈ ਜਿਸ ਨਾਲ ਇੱਕ ਮੋਡੀਊਲ ਕਹਿੰਦਾ ਹੈ ਕਿ ਇਸ ਦੀ ਸਤ੍ਹਾ ਖਾਲੀ ਹੈ। `::` ਇੱਕ ਫੰਕਸ਼ਨ ਨੂੰ ਕਾਲ ਕਰਦਾ ਹੈ, `.` ਇੱਕ ਕੌਂਸਟੈਂਟ ਪੜ੍ਹਦਾ ਹੈ। ਮੋਡੀਊਲ ਸਰੀਰ ਵਿੱਚ ਸਿਰਫ਼ ਇੰਪੋਰਟ, ਐਕਸਪੋਰਟ ਬਲਾਕ, ਸ਼ਾਬਦਿਕ ਆਰੰਭਕ ਅਤੇ ਫੰਕਸ਼ਨ ਪਰਿਭਾਸ਼ਾਵਾਂ ਹੀ ਦਿਖਾਈ ਦੇ ਸਕਦੀਆਂ ਹਨ; ਕੋਈ ਵੀ ਚੱਲਣ ਯੋਗ ਚੀਜ਼ **E013** ਹੈ।

## ਸਟੈਂਡਰਡ ਲਾਇਬ੍ਰੇਰੀ

ਮੂਲ ਮੋਡੀਊਲ, ਬਾਕੀਆਂ ਵਾਂਗ ਇੰਪੋਰਟ ਕੀਤੇ ਜਾਂਦੇ ਹਨ:

## ਅੰਕੀ ਮੋਡ

Zymbol ਅੰਕਾਂ ਨੂੰ **69 ਯੂਨੀਕੋਡ ਅੰਕ ਲਿਪੀਆਂ** ਵਿੱਚ ਲਿਖ ਸਕਦਾ ਹੈ — ਗੁਰਮੁਖੀ, ਦੇਵਨਾਗਰੀ, ਅਰਬੀ-ਭਾਰਤੀ, ਥਾਈ, ਕਲਿੰਗਨ pIqaD, ਗਣਿਤਿਕ ਬੋਲਡ, LCD ਭਾਗ, ਅਤੇ ਹੋਰ। ਮੋਡ ਪ੍ਰਕਿਰਿਆ ਲਈ ਵਿਸ਼ਵਵਿਆਪੀ ਹੈ ਅਤੇ ਆਉਟਪੁੱਟ ਨੂੰ ਪ੍ਰਭਾਵਿਤ ਕਰਦਾ ਹੈ; ਗਣਿਤ ਬਦਲਿਆ ਨਹੀਂ ਰਹਿੰਦਾ।

```zymbol
#੦੯#    // ਗੁਰਮੁਖੀ   (U+0A66–U+0A6F)
#०९#    // ਦੇਵਨਾਗਰੀ   (U+0966–U+096F)
#٠٩#    // ਅਰਬੀ-ਭਾਰਤੀ (U+0660–U+0669)
#09#    // ASCII 'ਤੇ ਮੁੜ-ਸੈੱਟ
```

```zymbol
a = ੪੨
>> a ¶                  // → 42
#੦੯#
>> a ¶                  // → ੪੨
>> ੩.੧੪ ¶               // → ੩.੧੪
>> #੧ ¶                 // → #੧
#09#
```

ਕਿਸੇ ਵੀ ਸਮਰਥਿਤ ਲਿਪੀ ਦੇ ਅੰਕ ਸਰੋਤ ਵਿੱਚ ਯੋਗ ਲਿਟਰਲ ਹਨ:

```zymbol
#੦੯#
@ i:੧..੫ { >> i " " }
>> ¶                    // → ੧ ੨ ੩ ੪ ੫
#09#
```

ਪੜ੍ਹਨਾ ਸਮਮਿਤੀ ਹੈ — ਇੱਕ ਅੰਕ ਕਿਸੇ ਵੀ ਲਿਪੀ ਵਿੱਚ ਸਮਝਿਆ ਜਾਂਦਾ ਹੈ:

```zymbol
>> #|"४२"| ¶            // → 42
>> #|'७'| ¶             // → 7
```

> `#` ਹਮੇਸ਼ਾ ASCII ਹੈ, ਇਸ ਲਈ `#0` ਹਰ ਲਿਪੀ ਵਿੱਚ ਅੰਕ ਜ਼ੀਰੋ ਤੋਂ ਵਿਜ਼ੂਅਲ ਤੌਰ 'ਤੇ ਵੱਖਰਾ ਰਹਿੰਦਾ ਹੈ।
> `#,` ਅਤੇ `#^` ਵੀ ਆਪਣੇ ਅੰਕ ਸਰਗਰਮ ਲਿਪੀ ਵਿੱਚ ਲਿਖਦੇ ਹਨ, ਅਤੇ ਵੱਖ ਕਰਨ ਵਾਲੇ ਇਸ ਦੀ ਪਾਲਣਾ ਕਰਦੇ ਹਨ — ਪਰ ਜੋੜਾ ਕਦੇ ਉਲਟ ਨਹੀਂ ਹੁੰਦਾ: `,` ਸਮੂਹ ਬਣਾਉਂਦਾ ਹੈ ਅਤੇ `.` ਵੰਡਦਾ ਹੈ, ਹਰ ਲਿਪੀ ਵਿੱਚ।

## ਡਾਟਾ ਓਪਰੇਟਰ

```zymbol
f = ##.੪੨         // ਫਲੋਟ ਵਿੱਚ
i = ###੩.੭        // ਪੂਰਨ ਅੰਕ ਵਿੱਚ, ਗੋਲ  → 4

>> f#? ¶                // → (##., 2, 42)
```

> ਇੱਕ ਫਲੋਟ ਅੰਕਾਂ ਦੇ ਰੂਪ ਵਿੱਚ ਪ੍ਰਿੰਟ ਹੁੰਦਾ ਹੈ, ਕਦੇ ਵੀ ਘਾਤਕ ਦੇ ਰੂਪ ਵਿੱਚ ਨਹੀਂ, ਅਤੇ ਅੰਤਲੇ `.0` ਨੂੰ ਛੱਡ ਦਿੰਦਾ ਹੈ — `##.42` `42` ਲਿਖਦਾ ਹੈ ਅਤੇ ਫਿਰ ਵੀ ਫਲੋਟ ਹੈ, ਜਿਵੇਂ `f#?` ਦਿਖਾਉਂਦਾ ਹੈ।

```zymbol
>> #|"੪੨"| ¶       // → 42
>> #|"abc"| ¶      // → abc   ਅਸਫਲ-ਸੁਰੱਖਿਅਤ: ਇਨਪੁੱਟ ਨੂੰ ਬਿਨਾਂ ਬਦਲੇ ਵਾਪਸ ਕਰਦਾ ਹੈ
>> ##!'A' ¶        // → 65    ਇੱਕ ਅੱਖਰ ਦਾ ਕੋਡ ਬਿੰਦੂ
```

```zymbol
pi = ੩.੧੪੧੫੯੨੬੫
>> #.੨|pi| ¶       // → 3.14          2 ਦਸ਼ਮਲਵ ਸਥਾਨਾਂ 'ਤੇ ਗੋਲ
>> #!੨|pi| ¶       // → 3.14          2 ਦਸ਼ਮਲਵ ਸਥਾਨਾਂ 'ਤੇ ਕੱਟੋ
>> #,|੧੨੩੪੫੬੭| ¶   // → 1,234,567     ਹਜ਼ਾਰਾਂ ਵੱਖ ਕਰਨ ਵਾਲੇ
>> #^|੧੨੩੪੫.੬੭੮| ¶ // → 1.2345678e4   ਵਿਗਿਆਨਕ ਨੋਟੇਸ਼ਨ
```

```zymbol
>> 0x41 ¶        // → A   ਹੈਕਸਾਡੈਸੀਮਲ
>> 0b01000001 ¶  // → A   ਬਾਈਨਰੀ
>> 0o101 ¶       // → A   ਅਕਟਲ
```

> ASCII ਰੇਂਜ ਵਿੱਚ ਇੱਕ ਬੇਸ ਲਿਟਰਲ ਇੱਕ **ਅੱਖਰ** ਹੈ: `0d65 == 'A'` `#1` ਹੈ, ਅਤੇ `0d65 == 65` `#0` ਹੈ। ਚਾਰੇ ਬੇਸ ਇੱਕੋ ਅੱਖਰ ਦੀ ਸਪੈਲਿੰਗ ਕਰਦੇ ਹਨ।

## ਚਿੰਨ੍ਹ ਕਿਵੇਂ ਜੁੜਦੇ ਹਨ

ਤੁਸੀਂ ਇਸ ਪੂਰੇ ਮੈਨੂਅਲ ਵਿੱਚ ਇੱਕੋ ਚੀਜ਼ ਦੇਖ ਰਹੇ ਹੋ: **ਇੱਕ ਓਪਰੇਟਰ ਯਾਦ ਰੱਖਣ ਲਈ ਇੱਕ ਡਰਾਇੰਗ ਨਹੀਂ ਹੈ, ਇਹ ਇੱਕ ਕਤਾਰ ਵਿੱਚ ਕਈ ਚਿੰਨ੍ਹ ਹਨ, ਅਤੇ ਹਰ ਇੱਕ ਆਪਣਾ ਅਰਥ ਯੋਗਦਾਨ ਪਾਉਂਦਾ ਹੈ।** ਹੁਣ ਜਦੋਂ ਤੁਸੀਂ ਉਹਨਾਂ ਸਾਰਿਆਂ ਨੂੰ ਜਾਣਦੇ ਹੋ, ਇਹ ਹੈ ਪੂਰਾ ਪੈਟਰਨ।

ਪਹਿਲਾਂ ਆਉਂਦਾ ਹੈ **ਅਸੀਂ ਕਿਸ ਸੰਸਾਰ ਵਿੱਚ ਹਾਂ**:

| ਚਿੰਨ੍ਹ | ਸੰਸਾਰ | ਤੁਸੀਂ ਇਸ ਨੂੰ ਕਿੱਥੇ ਦੇਖਿਆ |
|--------|-------|----------------------------|
| `$` | ਇੱਕ ਸੰਗ੍ਰਹਿ | `$#` `$+` `$?` `$^-` |
| `@` | ਸਮਾਂ, ਜੋ ਕੁਝ ਦੁਹਰਾਉਂਦਾ ਹੈ | `@!` `@>` `@~` |
| `#` | ਇੱਕ ਚੀਜ਼ *ਕੀ ਹੈ*, ਉਸ ਦਾ ਮੁੱਲ ਨਹੀਂ | `#?` `#(…)` `<#` `#>` |
| `>>` | ਪ੍ਰੋਗਰਾਮ ਤੋਂ ਬਾਹਰ | `>>` `>>!` `>>?` |
| `<<` | ਪ੍ਰੋਗਰਾਮ ਵਿੱਚ ਅੰਦਰ | `<<` `<<\|` `<<\|?` |
| `?` | ਪੁੱਛਣਾ, ਵਚਨਬੱਧਤਾ ਤੋਂ ਬਿਨਾਂ | `?` `_?` `??` `$?` |
| `!` | ਜ਼ੋਰ, ਜਾਂ ਗ਼ਲਤੀ | `@!` `$!` `!?` |

ਫਿਰ ਆਉਂਦਾ ਹੈ **ਉੱਥੇ ਕੀ ਕੀਤਾ ਜਾਂਦਾ ਹੈ**: `+` ਜੋੜੋ, `-` ਹਟਾਓ, `^` ਕ੍ਰਮ, `~` ਸੋਧ, `#` ਗਿਣਤੀ, `|` ਇੱਕ ਇਕਾਈ, `:` ਨਾਮ ਬੰਨ੍ਹੋ।

ਅਤੇ ਦੋ ਨਿਯਮ ਜੋ ਕਦੇ ਅਸਫਲ ਨਹੀਂ ਹੁੰਦੇ:

**ਇੱਕ ਚਿੰਨ੍ਹ ਨੂੰ ਦੁੱਗਣਾ ਕਰਨਾ ਇਸ ਨੂੰ ਪੂਰਾ ਬਣਾਉਂਦਾ ਹੈ।** `?` ਇੱਕ ਵਾਰ ਪੁੱਛਦਾ ਹੈ, `??` ਬਹੁਤ ਸਾਰੇ ਕੇਸਾਂ ਦੀ ਜਾਂਚ ਕਰਦਾ ਹੈ। `$?` ਪੁੱਛਦਾ ਹੈ ਕਿ ਕੀ ਕੋਈ ਮੁੱਲ ਮੌਜੂਦ ਹੈ, `$??` ਹਰ ਥਾਂ ਵਾਪਸ ਭੇਜਦਾ ਹੈ ਜਿੱਥੇ ਇਹ ਹੈ। `!` ਇੱਕ ਗ਼ਲਤੀ ਨੂੰ ਚਿੰਨ੍ਹਿਤ ਕਰਦਾ ਹੈ, `!!` ਬਿਨਾਂ ਪੁੱਛੇ ਇਸ ਨੂੰ ਪ੍ਰਸਾਰਿਤ ਕਰਦਾ ਹੈ।

**ਮੋਡ ਚਿੰਨ੍ਹ ਹਮੇਸ਼ਾ ਆਖਰੀ ਆਉਂਦਾ ਹੈ।** ਜਦੋਂ `?` ਜਾਂ `!` ਇਹ ਕਹਿਣ ਲਈ ਪ੍ਰਗਟ ਹੁੰਦੇ ਹਨ ਕਿ ਕੁਝ *ਕਿਵੇਂ* ਕੀਤਾ ਜਾਂਦਾ ਹੈ — ਝਿਜਕ ਨਾਲ ਜਾਂ ਜ਼ੋਰ ਨਾਲ — ਉਹ ਓਪਰੇਟਰ ਦੇ ਆਖਰੀ ਚਿੰਨ੍ਹ ਹੁੰਦੇ ਹਨ: `$??`, `$!!`, `<<|?`, `@!`, `##!`, `>>!`, `>>?`, `@:ਬਾਹਰੀ!`। ਉਹਨਾਂ ਤੋਂ ਬਾਅਦ ਕਦੇ ਵੀ ਕੋਈ ਓਪਰੇਸ਼ਨ ਨਹੀਂ ਹੁੰਦਾ।

ਇਸ ਤੋਂ ਇੱਕ ਵਿਹਾਰਕ ਚੀਜ਼ ਨਿਕਲਦੀ ਹੈ: **ਇੱਕ ਸੰਜੋਗ ਜੋ ਤੁਸੀਂ ਕਦੇ ਨਹੀਂ ਦੇਖਿਆ, ਉਸ ਨੂੰ ਦੇਖਣ ਤੋਂ ਪਹਿਲਾਂ ਹੀ ਸਮਝ ਆ ਜਾਂਦਾ ਹੈ।** ਜੇਕਰ `$` ਸੰਗ੍ਰਹਿ ਹੈ ਅਤੇ `^` ਕ੍ਰਮ ਹੈ ਅਤੇ `-` ਉਲਟ ਹੈ, ਤਾਂ `$^-` ਲਹਿੰਦੇ ਕ੍ਰਮ ਵਿੱਚ ਕ੍ਰਮਬੱਧ ਕਰਦਾ ਹੈ, ਅਤੇ ਕਿਸੇ ਨੂੰ ਤੁਹਾਨੂੰ ਦੱਸਣ ਦੀ ਲੋੜ ਨਹੀਂ ਸੀ।

ਪੂਰੀ ਸੂਚੀ ਇਸ ਤਰ੍ਹਾਂ ਕੰਮ ਨਹੀਂ ਕਰਦੀ, ਅਤੇ ਇਹ ਕਹਿਣਾ ਬਿਹਤਰ ਹੈ। ਜ਼ਿਆਦਾਤਰ ਓਪਰੇਟਰ ਸਾਫ਼-ਸਾਫ਼ ਵੱਖ ਹੋ ਜਾਂਦੇ ਹਨ। ਛੇ ਵੱਖ ਹੋ ਜਾਂਦੇ ਹਨ ਪਰ ਆਪਣੇ ਹਿੱਸਿਆਂ ਤੋਂ ਵੱਧ ਅਰਥ ਰੱਖਦੇ ਹਨ: `!?` `:!` `:>` `|>` `::` `$++`। ਅਤੇ ਦਸ ਨੂੰ ਯਾਦ ਕਰਨਾ ਪੈਂਦਾ ਹੈ ਕਿਉਂਕਿ ਉਹ ਬਿਲਕੁਲ ਵੱਖ ਨਹੀਂ ਹੁੰਦੇ: `¶` `><` `#1` `#0` `0x` `0b` `0o` `0d` `###` `°`।

> ਅਸਪਸ਼ਟਾਂ ਨੂੰ ਗਿਣਨਾ ਬਨਾਮ ਇਹ ਮੰਨਣਾ ਕਿ ਉਹ ਘੱਟ ਹਨ, ਜਾਣਬੁੱਝ ਕੇ ਹੈ: ਉਹ ਭਾਸ਼ਾ ਦੀ ਅਸਲ ਯਾਦਗਾਰੀ ਲਾਗਤ ਹਨ। ਪੂਰਾ ਹਵਾਲਾ — ਸੂਚੀ, ਐਲਾਨੇ ਗਏ ਸਮ-ਉਚਾਰਣ, ਅਤੇ ਨਿਯਮ ਜੋ ਇੱਕ ਨਵੇਂ ਓਪਰੇਟਰ ਨੂੰ ਮੌਜੂਦ ਹੋਣ ਲਈ ਪੂਰੇ ਕਰਨੇ ਚਾਹੀਦੇ ਹਨ — ਵਿਆਖਿਆਕਾਰ ਰਿਪੋਜ਼ਟਰੀ ਵਿੱਚ `SYMBOLS.md` ਵਿੱਚ ਹੈ।

- **ਸ਼ਾਮਲ** ਕਾਲ ਸਾਈਟ 'ਤੇ `<~>` ਲਾਜ਼ਮੀ ਹੈ ਜਿੱਥੇ ਕਾਲੀ ਇੱਕ ਆਉਟਪੁੱਟ ਪੈਰਾਮੀਟਰ ਐਲਾਨ ਕਰਦਾ ਹੈ
- **ਸੁਧਾਰਿਆ** ਰਜਿਸਟਰ VM ਵਿੱਚ ਮੋਡੀਊਲ ਸਿਸਟਮ ਸਮਾਨਤਾ

### v0.0.7 — ਮੂਲ ਸਟੈਂਡਰਡ ਲਾਇਬ੍ਰੇਰੀ _(ਜੁਲਾਈ 2026)_

- **ਸ਼ਾਮਲ** `std/json`, `std/io`, `std/net`, `std/db` (ODBC) — ਸਭ ਨਰਮ ਗ਼ਲਤੀ ਮੁੱਲਾਂ ਦੇ ਨਾਲ
- **ਸ਼ਾਮਲ** ਟਾਈਪ/ਪ੍ਰਮਾਣਿਤ ਇਨਪੁੱਟ: `<< ##.(5,2) "ਕੀਮਤ: " p`
- **ਸ਼ਾਮਲ** `>>` ਵਿੱਚ ਸਿੱਧੇ ਪੋਸਟਫਿਕਸ ਓਪਰੇਟਰ — ਬਰੈਕਟਾਂ ਦੀ ਲੋੜ ਨਹੀਂ
- **ਬਦਲਿਆ** ਅਸਫਲ-ਬੰਦ ਫਾਰਮੈਟਰ: ਉਹ ਆਉਟਪੁੱਟ ਲਿਖਣ ਤੋਂ ਇਨਕਾਰ ਕਰਦਾ ਹੈ ਜਿਸ ਨੂੰ ਉਹ ਮੁੜ ਨਹੀਂ ਪੜ੍ਹ ਸਕਦਾ

### v0.0.6 — ਸੁਧਾਰ ਅਤੇ ਵਿਗਿਆਨਕ Stdlib _(ਜੂਨ 2026)_

- **ਬ੍ਰੇਕਿੰਗ** `=>` ਮੇਲ ਸ਼ਾਖਾਵਾਂ ਵਿੱਚ `:` ਅਤੇ ਇੰਪੋਰਟ/ਐਕਸਪੋਰਟ ਉਪਨਾਮਾਂ ਵਿੱਚ `<=` ਦੀ ਥਾਂ ਲੈਂਦਾ ਹੈ
- **ਸ਼ਾਮਲ** `std/math` ਅਤੇ `std/random`
- **ਸ਼ਾਮਲ** ਕੁੰਜੀ ਦੁਆਰਾ ਡਿਕਸ਼ਨਰੀ ਅਪਡੇਟ: `d["k"]$~ ਮੁੱਲ`

### v0.0.5 — TUI ਪ੍ਰਾਈਮਿਟਿਵ ਅਤੇ ਗਰਮ ਪਰਿਭਾਸ਼ਾ _(ਮਈ 2026)_

- **ਸ਼ਾਮਲ** TUI ਬਲਾਕ `>>| { }`, ਸਥਿਤੀ ਆਉਟਪੁੱਟ `>>~`, ਕੁੰਜੀ ਇਨਪੁੱਟ `<<|` ਅਤੇ `<<|?`
- **ਸ਼ਾਮਲ** `>>!` ਸਕ੍ਰੀਨ ਸਾਫ਼ ਕਰੋ, `>>?` ਟਰਮੀਨਲ ਆਕਾਰ, `@~ N` ਸੌਂਵ
- **ਸ਼ਾਮਲ** ਗਰਮ ਪਰਿਭਾਸ਼ਾ `°x` / `x°`, ਅਤੇ ਸਤਰ ਦੁਹਰਾਓ `$*`

### v0.0.4 — 1-ਅਧਾਰਿਤ ਇੰਡੈਕਸਿੰਗ ਅਤੇ ਪਹਿਲੀ-ਸ਼੍ਰੇਣੀ ਫੰਕਸ਼ਨ _(ਅਪ੍ਰੈਲ 2026)_
