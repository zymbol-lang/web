# Посібник Zymbol-Lang

> **Переглянуто для v0.0.9 — 2026-09-07**

**Zymbol-Lang** — це символьна мова програмування. У її граматиці немає слів — кожна конструкція є знаком. Працює однаково будь-якою людською мовою.

- Немає `if`, `while`, `return` — лише `?`, `@`, `<~`
- Повний Unicode — ідентифікатори будь-якою мовою чи емодзі
- Незалежність від людської мови — код однаковий усюди

**Версія інтерпретатора**: v0.0.9 | **Покриття тестами**: 660/666 (три рушії згодні, 0 розбіжностей)

## Змінні та Константи

```zymbol
x = 10              // змінна, що змінюється
PI := 3.14159       // константа — повторне присвоєння є помилкою виконання
імʼя = "Оксана"
активний = #1       // логічне істинне
👋 := "Привіт"
```

```zymbol
x = 10    // 10
x += 5    // 15
x -= 3    // 12
x *= 2    // 24
x /= 3    // 8
x %= 3    // 2
x ^= 2    // 4
x++       // 5
x--       // 4
```

`°` (знак градуса, U+00B0) автоматично ініціалізує змінну її нейтральним значенням при першому використанні:

```zymbol
числа = [3, 1, 4, 1, 5]
@ n:числа {
    °сума += n
}
>> сума ¶              // → 14
```

> `°змінна` (префікс) закріплюється над циклом — результат читається після `@`.
> `змінна°` (суфікс) закріплюється всередині циклу — вона помирає, коли цикл завершується.

Інструкція, що складається лише з імені, читає змінну й відкидає значення, тому вона попереджає:

```zymbol
лічильник = 5
лічильник
```

Компілятор попереджає так (його повідомлення завжди англійською):

```text
warning: this statement does nothing: 'лічильник' is read and discarded
  = help: remove it, or use it — `>> name ¶` to print it
```

Тобто: *«ця інструкція нічого не робить: 'лічильник' прочитано й відкинуто»*.

## Типи Даних

| Тип | Літерал | Тег `#?` | Примітки |
|------|---------|----------|----------|
| Ціле | `42`, `-7` | `###` | Безпечне ціле: ±(2⁵³ − 1) |
| Дійсне | `3.14`, `1.5e10` | `##.` | IEEE-754 подвійне |
| Рядок | `"текст"` | `##"` | Інтерполяція: `"Привіт {імʼя}"` |
| Символ | `'A'` | `##'` | Одна кодова точка Unicode |
| Логічне | `#1`, `#0` | `##?` | НЕ число — `#1 ≠ 1` |
| Масив | `[1, 2, 3]` | `##]` | Один тип, перевіряється |
| Оголошена суміш | `#[1, "два"]` | `##[` | Той самий тип, що `[…]`, не перевіряється |
| Кортеж | `(a, b)` | `##)` | Позиційний, незмінний |
| Словник | `#(x: 1, y: 2)` | `##(` | За ключем, змінний |
| Функція | посилання на іменовану функцію | `##()` | Першокласна; показує `<funct/N>` |
| Лямбда | `x -> x * 2` | `##->` | Першокласна; показує `<lambd/N>` |
| Одиниця | `##_` | `##_` | Відсутність — null не існує |

```zymbol
>> 42#? ¶               // → (###, 2, 42)
>> [1, 2, 3]#? ¶        // → (##], 3, [1, 2, 3])
>> #(x: 1)#? ¶          // → (##(, 1, #(x: 1))
```

Ціле, що виходить за безпечний діапазон, є помилкою, яку можна зловити, а не тихим переповненням:

```zymbol
!? {
    >> (9007199254740991 + 1) ¶
} :! ##Range {
    >> "поза діапазоном" ¶ // → поза діапазоном
}
```

`##_` — це спосіб, яким програма запитує, чи щось відсутнє:

```zymbol
нічого() { }
значення = нічого()
>> (значення == ##_) ¶     // → #1
```

## Виведення та Введення

```zymbol
імʼя = "Оксана"
сума = 3
>> "Привіт" ¶             // → Привіт
>> "a=" імʼя " b=" сума ¶ // → a=Оксана b=3
>> сума#? ¶            // → (###, 1, 3)
```

```zymbol
<< імʼя
<< "Введіть ваше імʼя: " імʼя
<< ###(4) "Вік: " вік
```

**Подивіться на форму двох знаків.** `>>` вказує назовні: він виводить дані з програми. `<<` вказує всередину: він вводить дані в програму. Тут немає чого запам'ятовувати — стрілка показує, у якому напрямку рухається інформація, і ця сама ідея повертається в кожному знакові, що щось переміщує.

> `¶` та `\\` — еквівалентні символи нового рядка. `>>` ніколи його не додає.
> Специфікатор типу перед запрошенням перевіряє введення й запитує знову, доки значення не стане допустимим:
> `##.` Дійсне · `##.(T,D)` десяткове · `###(N)` Ціле · `##"(N)"` текст · `##'` один Символ.

На верхньому рівні файлу `<~` — це код виходу програми:

```zymbol
>> "перевіряю" ¶      // → перевіряю
<~ 0
```

## Примітиви TUI

Оператори термінального інтерфейсу для інтерактивних програм. Більшість вимагає блоку `>>| { }` (альтернативний екран + сирий режим).

```zymbol
>>| {
    >>!
    >>~ (1, 1, 0, 10) > "Виконується"
    @~ 1000
    >>~ (2, 1) > "Готово."
}
```

```zymbol
>>| {
    [рядки, стовпці] = >>?
    >>~ (1, 1) > "Термінал: " рядки " x " стовпці
    <<| клавіша
    >>~ (2, 1) > "Натиснуто: " клавіша
}
```

Тут видно, чому знаки комбінуються, а не множаться. Ви вже знаєте, що `<<` — це введення, а `?` запитує без зобов'язання. Лише один знак новий:

- `|` — це **одна одиниця**, а не весь потік.

Із цим обидва клавіатурні оператори читаються самі:

```text
<<        |             ?
введення  одна одиниця   без зобов'язання

<<|   взяти ОДНУ клавішу й чекати, доки вона з'явиться
<<|?  перевірити, чи Є клавіша, і продовжити, якщо немає
```

Те саме з іншого боку: `>>` надсилає, `>>!` надсилає **примусово** (очищає весь екран), тоді як `>>?` **запитує** замість запису (який розмір термінала). Знак праворуч — це той, що змінює режим, і він завжди йде останнім.

> `>>!` очищає екран. `>>?` повертає `[рядки, стовпці]`. `@~ N` спить N мілісекунд.
> `<<|` читає одне натискання клавіші (блокувальне); `<<|?` опитує без блокування (`'\0'`, якщо немає).
> Клавіші-стрілки приходять декодованими як `'↑' '↓' '←' '→'`; ESC — кодова точка 27.
> Кортеж позиційного виведення: `(рядок, стовпець, BKS, передній, задній)` — будь-яке поле можна пропустити комою (`>>~ (,,, 196) > "червоний"`).
> Бітова маска BKS: `1`=Жирний, `2`=Курсив, `4`=Підкреслений. Палітра ANSI 256 кольорів (`0`=типове для термінала).

## Оператори

```zymbol
a = 10
b = 3
р1 = a + b    // 13
р2 = a - b    // 7
р3 = a * b    // 30
р4 = a / b    // 3  (цілочисельне ділення)
р5 = a % b    // 1
р6 = a ^ b    // 1000
```

```zymbol
a = 10
b = 3
п1 = a == b    // #0
п2 = a <> b    // #1
п3 = a < b     // #0
п4 = a >= b    // #1
л1 = #1 && #0  // #0
л2 = !#1       // #0
```

> `==` ніколи не змушує: `"5" == 5` — це `#0`. Порядок змушує: `"5" > 4` — це `#1`, як і `"४२" > 5` — числовий текст у будь-якій із 69 систем числення порівнюється як число.
> Функція дорівнює лише собі, ніколи іншій функції з тим самим тілом.

## Рядки

```zymbol
імʼя = "Оксана"
n = 42
>> "Привіт " імʼя " у вас " n ¶ // → Привіт Оксана у вас 42
опис = "Привіт {імʼя}, у вас {n}"
>> опис ¶              // → Привіт Оксана, у вас 42
```

```zymbol
s = "Привіт світ"
довжина = s$#                  // 11
підрядок = s$[1..6]             // "Привіт"
містить = s$? "світ"          // #1
частини = "a,b,c,d"$/ ','    // [a, b, c, d]
заміна = s$~~["і":"и"]        // "Привит свит"
лінія = "─" $* 20
```

> `+` призначений лише для чисел. Для рядків використовуйте прилягання або інтерполяцію.
> `\{` і `\}` — це буквальні фігурні дужки — екранування симетричне.

## Потік Керування

```zymbol
x = 7
? x > 100 {
    >> "велике" ¶
} _? x > 0 {
    >> "додатне" ¶     // → додатне
} _ {
    >> "від'ємне" ¶
}
```

Тут два нових знаки, і третій, що виникає з їх поєднання:

- `?` — це **запитувати**: він відкриває умову.
- `_` — це **те, що не вказано**: гілка, що залишається, коли жодне питання не збіглося.
- `_?` — це обидва підряд: *якщо ніщо не збіглося, запитай знову*.

Ось чому `_?` пишеться саме так. Це не новий знак для вивчення — це `_`, за яким іде `?`, і він означає саме те, що означають обидві його частини, прочитані по порядку.

> Фігурні дужки `{ }` **обов'язкові** навіть для однієї інструкції.

## Зіставлення

```zymbol
бал = 85
оцінка = ?? бал {
    90..100 => 'A'
    80..89  => 'B'
    _       => 'F'
}
>> оцінка ¶              // → B
```

```zymbol
температура = -5
стан = ?? температура {
    < 0  => "лід"
    < 20 => "холодно"
    _    => "спекотно"
}
>> стан ¶              // → лід
```

Ви вже знаєте, що `?` — це «запитувати». **`??` — це запитувати багато разів**: подвоєння знака будь-де в мові означає виконання того, що знак робить один раз, кілька разів. Один `?` перевіряє одну умову; `??` перевіряє список випадків.

Альтернативи з'єднуються через `||`, і вони можуть змішувати види шаблонів:

```zymbol
клавіша = 'P'
дія = ?? клавіша {
    'p' || 'P' => "пауза"
    < 0 || > 100 => "поза діапазоном"
    _ => "ігнорується"
}
>> дія ¶             // → пауза
```

## Цикли

```zymbol
@ i:1..4  { >> i " " }
>> ¶                    // → 1 2 3 4
@ i:1..9:2 { >> i " " }
>> ¶                    // → 1 3 5 7 9
@ i:5..1:1 { >> i " " }
>> ¶                    // → 5 4 3 2 1
```

```zymbol
n = 1
@ n <= 64 { n *= 2 }
>> n ¶                  // → 128
```

```zymbol
фрукти = ["яблуко", "груша", "виноград"]
@ ф:фрукти { >> ф " " }
>> ¶                    // → яблуко груша виноград
@ л:"Привіт" { >> л "-" }
>> ¶                    // → П-р-и-в-і-т-
```

```zymbol
@ i:1..10 {
    ? i % 2 == 0 { @> }
    ? i > 7 { @! }
    >> i " "
}
>> ¶                    // → 1 3 5 7
```

```zymbol
лічильник = 0
@:зовнішній {
    лічильник++
    ? лічильник >= 3 { @:зовнішній! }
}
>> лічильник ¶             // → 3
```

`@` — це знак **часу**: усе, що повторюється, живе в ньому. Щоб скоротити цей час, ви додаєте знак поруч:

- `@!` — `!` — це **сила**: вийти з циклу негайно.
- `@>` — `>` штовхає вперед: перейти до наступного оберту.
- `@:зовнішній!` — `:` **зв'язує імʼя**, тож це перериває цикл *із назвою* зовнішній, а не найближчий.

Три оператори, і жоден не довелося запам'ятовувати окремо: це `@` плюс знак, що вже каже, що він робить.

> **Специфікатор — це кількість або умова.** `Ціле` — це кількість, обчислюється один раз — `@ 0` виконує тіло нуль разів. Усе інше — умова. Істинності немає: `@ []` і `@ 3.5` відхиляються. Щоб пройти колекцію, використовуйте `@ x:елементи`; щоб порахувати її, `@ елементи$#`.

## Функції

```zymbol
додати(a, b) { <~ a + b }
>> додати(3, 4) ¶        // → 7
```

```zymbol
факторіал(n) {
    ? n <= 1 { <~ 1 }
    <~ n * факторіал(n - 1)
}
>> факторіал(5) ¶       // → 120
```

Функція читає змінні файлу за значенням, і запис усередині залишається всередині:

```zymbol
межа = 100
усередині(n) { <~ n < межа }
>> усередині(42) ¶         // → #1
```

Два знаки змінюють це, і обидва записуються **в сигнатурі та в місці виклику**:

```zymbol
збільшити(лічильник<~) { лічильник = лічильник + 1 }
сума = 0
збільшити(сума<~)
>> сума ¶              // → 1
```

> `p~` — це робоча копія — тіло може перепризначити її, а викликач залишається незмінним.
> `p<~` — це вихідний параметр — зміна повертається назад. `збільшити(сума)` без знака — семантична помилка: анотація й сигнатура не можуть розходитися.

## Лямбди та Замикання

```zymbol
подвоїти = x -> x * 2
сума = (a, b) -> a + b
>> подвоїти(5) ¶          // → 10
>> сума(3, 7) ¶          // → 10
```

```zymbol
класифікувати = x -> {
    ? x > 0 { <~ "додатне" }
    _? x < 0 { <~ "від'ємне" }
    <~ "нуль"
}
>> класифікувати(-4) ¶         // → від'ємне
```

```zymbol
множник = 3
потроїти = x -> x * множник
>> потроїти(7) ¶          // → 21
```

```zymbol
створити_додавач(n) { <~ x -> x + n }
додати10 = створити_додавач(10)
>> додати10(5) ¶           // → 15
```

Лямбда може не брати жодних параметрів:

```zymbol
відповідь = () -> 42
>> відповідь() ¶           // → 42
```

> Лямбда захоплює змінні файлу **під час створення**; іменована функція читає їх **під час виклику**.

## Масиви

```zymbol
масив = [1, 2, 3, 4, 5]
>> масив[1] ¶       // → 1   індексація з 1
>> масив[-1] ¶      // → 5   від'ємне рахує з кінця
>> масив$# ¶        // → 5   довжина
```

```zymbol
масив = [1, 2, 3]
>> (масив$+ 6) ¶          // → [1, 2, 3, 6]   додати
>> (масив$+[2] 99) ¶      // → [1, 99, 2, 3]  вставити на позицію 2
>> (масив$- 3) ¶          // → [1, 2]         вилучити перше входження
>> (масив$-[1]) ¶         // → [2, 3]         вилучити за індексом 1
>> (масив$[1..2]) ¶       // → [1, 2]         зріз, обидва кінці включно
>> (масив$? 3) ¶          // → #1             містить
```

Усі вони починаються з `$` — знака **колекції** — і продовжуються знаком, що каже, що в ній робиться: `#` скільки, `+` додати, `-` вилучити, `?` запитати, чи є. І як із `??`, подвоєння знака означає виконати це вичерпно: `$?` питає, *чи* значення присутнє, `$??` питає, *у скількох місцях*, і повертає їх усі.

```zymbol
масив = [3, 1, 2]
>> (масив$^+) ¶     // → [1, 2, 3]   за зростанням
>> (масив$^-) ¶     // → [3, 2, 1]   за спаданням
```

**Правило результату.** Один оператор, і те, що робить із ним навколишній код, вирішує: використаний — він **будує** й залишає оригінал незмінним; відкинутий — він **змінює**.

```zymbol
масив = [1, 2, 3]
копія = масив[2]$~ 99
>> масив ¶                // → [1, 2, 3]
>> копія ¶              // → [1, 99, 3]
масив[2]$~ 99
>> масив ¶                // → [1, 99, 3]
```

> **`=` ніколи не пише в колекцію.** `масив[2] = 99` не є формою Zymbol — `=` дає значення **ІМЕНІ**. Зміна частини колекції — це `$~`, у кожній колекції.

`[…]` містить один тип і перевіряється; навмисна суміш **оголошується** через `#[…]`:

```zymbol
суміш = #[1, "два", #1]
>> суміш ¶             // → [1, два, #1]
>> ([1, 2] == #[1, 2]) ¶ // → #1
```

## Багатовимірна Індексація

`>` спускається вкладеною структурою. Одна група дужок адресує один елемент, якою б глибокою вона не була.

```zymbol
m = [[1,2,3], [4,5,6], [7,8,9]]
>> m[2>3] ¶        // → 6   рядок 2, стовпець 3
>> m[-1>-1] ¶      // → 9   останній рядок, останній стовпець
```

```zymbol
m = [[1,2,3], [4,5,6], [7,8,9]]
>> m[1>1 ; 2>2 ; 3>3] ¶          // → [1, 5, 9]          плаский: діагональ
>> m[[1>1, 1>3] ; [3>1, 3>3]] ¶  // → [[1, 3], [7, 9]]   структурований: кути
```

```zymbol
m = [[1,2,3], [4,5,6]]
>> (m[1>2]$~ 99) ¶      // → [[1, 99, 3], [4, 5, 6]]
```

> `m[1][2]` **не є** формою Zymbol. Ланцюговий індекс відхиляється як для читання, так і для запису — одна група дужок на одне звернення, а `>` стоїть між кроками.

## Словники

Кортеж із названими полями — це словник, і від v0.0.9 його пишуть `#(…)`.

```zymbol
особа = #(імʼя: "Оксана", вік: 25)
>> особа.імʼя ¶        // → Оксана
>> особа["вік"] ¶    // → 25
```

```zymbol
особа = #(імʼя: "Оксана", вік: 25)
поле = "імʼя"
>> особа[поле] ¶     // → Оксана
```

Він змінний, ключі можна додавати, і його можна обходити:

```zymbol
запас = #(груша: 4)
запас["яблуко"]$~ 10
@ k:запас { >> k "=" запас[k] " " }
>> ¶                    // → груша=4 яблуко=10
```

```zymbol
запас = #(груша: 4, яблуко: 10)
@ (k, v):запас { >> k ":" v " " }
>> ¶                    // → груша:4 яблуко:10
```

> `#()` — це порожній словник, чим `()` не могло бути — воно мусило б бути також порожнім кортежем. Голий `(x: 1)` відхиляється з цим повідомленням: *a dictionary is written `#(…)`* — «словник пишеться `#(…)`».
> Словник адресується за ключем, ніколи за позицією, тож `особа[1]` — це помилка.

## Кортежі

Кортежі — це **незмінні** впорядковані контейнери, що зберігають значення різних типів.

```zymbol
точка = (10, 20)
>> точка[1] ¶           // → 10
дані = (42, "Привіт", #1, 3.14)
>> дані[3] ¶            // → #1
```

```zymbol
t = (10, 20, 30)
t2 = t[2]$~ 999
>> t ¶                  // → (10, 20, 30)
>> t2 ¶                 // → (10, 999, 30)
```

> Будь-яка спроба змінити кортеж на місці — це помилка, яким би не був оператор — незмінність є властивістю значення, а не винятком усередині кожного `$`.

## Деструктуризація

```zymbol
масив = [10, 20, 30, 40, 50]
[a, b, c] = масив
>> a " " b " " c ¶      // → 10 20 [30, 40, 50]
```

```zymbol
масив = [10, 20, 30, 40, 50]
[перший, *решта] = масив
>> перший ¶            // → 10
>> решта ¶              // → [20, 30, 40, 50]
```

```zymbol
точка = (100, 200)
(px, py) = точка
>> px " " py ¶          // → 100 200
```

```zymbol
особа = #(імʼя: "Анна", вік: 25)
#(імʼя: n, вік: v) = особа
>> n " " v ¶            // → Анна 25
```

> Форма дужок типізована: `[…]` бере масив, `(…)` — кортеж, `#(…)` — словник. Останнє імʼя **поглинає залишок**, тож деструктуризація ніколи не зазнає невдачі через довжину — `(a, b, c) = (1,2,3,4,5)` дає `c = (3,4,5)`, а `##_` — коли нічого не залишилось.

## Функції Вищого Порядку

```zymbol
числа = [1, 2, 3, 4, 5]
>> (числа$> (x -> x * 2)) ¶ // → [2, 4, 6, 8, 10]
>> (числа$| (x -> x % 2 == 0)) ¶ // → [2, 4]
>> (числа$< (0, (накопичувач, x) -> накопичувач + x)) ¶ // → 15
```

```zymbol
числа = [1, 2, 3, 4, 5, 6]
подвоїти(x) { <~ x * 2 }
великий(x) { <~ x > 3 }
>> (числа$> подвоїти) ¶    // → [2, 4, 6, 8, 10, 12]
>> (числа$| великий) ¶    // → [4, 5, 6]
```

```zymbol
база = [#(імʼя: "Карла", вік: 28), #(імʼя: "Анна", вік: 25)]
за_віком = база$^ (a, b -> a.вік < b.вік)
>> за_віком[1].імʼя ¶     // → Анна
```

> Іменована функція передається до HOF **без дужок**: `числа$> подвоїти`. Запис `числа$> (подвоїти)` — це помилка розбору, бо `(` відкриває лямбду.

## Оператор Конвеєра

```zymbol
подвоїти = x -> x * 2
додати = (a, b) -> a + b
inc = x -> x + 1
>> (5 |> подвоїти(_)) ¶    // → 10
>> (10 |> додати(_, 5)) ¶  // → 15
>> (5 |> подвоїти(_) |> inc(_)) ¶ // → 11
```

## Обробка Помилок

```zymbol
!? {
    x = 10 / 0
} :! ##Div {
    >> "ділення на нуль" ¶  // → ділення на нуль
} :! {
    >> "інше: " _err ¶
} :> {
    >> "завжди виконується" ¶        // → завжди виконується
}
```

| Вид | Коли |
|------|------|
| `##Div` | Ділення на нуль |
| `##Index` | Індекс поза межами |
| `##Key` | Ключ відсутній у словнику |
| `##Range` | Поза безпечним цілим діапазоном |
| `##Type` | Невідповідність типів |
| `##Parse` | Розбір даних |
| `##IO` | Файл / система |
| `##Network` | Помилки мережі |
| `##DB` | База даних |
| `##Time` | Дата, що не існує |
| `##_` | Будь-яка помилка (ловить усе) |

`!` — це знак **помилки та сили**, і читається він однаково в обох родинах: `$!` питає в значення, чи це помилка; `$!!`, із подвоєним знаком, поширює її вгору без запитання.

> Збої стандартної бібліотеки повертаються як **м'які значення помилок**, які ви перевіряєте через `$!` або ловите через `!?`, замість аварійного завершення. `$!!` поширює одну до викликача.

## Модулі

```zymbol
# кальк {
    #> { додати, PI }

    PI := 3.14159
    додати(a, b) { <~ a + b }
}
```

```zymbol
<# ./кальк => к

>> к::додати(5, 3) ¶
>> к.PI ¶
```

```zymbol
# моя_біб {
    #> { внутрішнє_додавання => сума }

    внутрішнє_додавання(a, b) { <~ a + b }
}
```

Два знаки модуля — це та сама ідея, тепер застосована до файлів: `#` — це рівень **оголошення** — що річ *є*, а не її значення — а стрілка каже, у якому напрямку рухається код:

```text
<#   стрілка входить: імпортувати, принести з іншого файлу
#>   стрілка виходить: експортувати, запропонувати іншим файлам
```

Знак напрямку завжди сидить на краю, оберненому в той бік, куди він указує. Це та сама причина, чому `<~` повертається ліворуч (з функції), а `->` входить праворуч (у тіло лямбди).

> **Модуль оголошує те, що експортує.** Блок `#>` обов'язковий — його пропуск — це **E014**, а `#> { }` — це спосіб, яким модуль каже, що його поверхня порожня. `::` викликає функцію, `.` читає константу. У тілі модуля можуть з'являтися лише імпорти, блок експорту, буквальні ініціалізатори та визначення функцій; усе виконуване — це **E013**.

## Стандартна Бібліотека

Вбудовані модулі, що імпортуються як будь-які інші:

| Модуль | Функції |
|--------|-----------|
| `std/math` | `sqrt exp ln log pow abs ceil floor round min max sin cos tan asin acos atan atan2 sinh cosh tanh sigmoid` · `PI` `E` |
| `std/random` | `entero rango peso_f64` |

| `std/io` | `read write append exists delete list mkdir` |

| `std/term` | `width pad_left pad_right center truncate` |
| `std/time` | `now today parts of format add diff` |

```zymbol
<# std/math => m

>> m::sqrt(16.0) ¶      // → 4
>> m.PI ¶               // → 3.141592653589793
```

```zymbol
<# std/term => t

>> t::width("手番") ¶            // → 4   два глифи, чотири стовпці
>> "|" t::center("go", 8) "|" ¶ // → |   go   |
```

<# std/time => T

день = T::of(2026, 1, 31)
>> T::format(день, "%Y-%m-%d") ¶ // → 2026-01-31
>> T::format(T::add(день, 1, "month"), "%Y-%m-%d") ¶ // → 2026-02-28

> У `std/time` момент — це мілісекунди від епохи. Менше ніж доба — це тривалість, від доби й більше — календар, тож місяць потрапляє на той самий день місяця з обмеженням. `різниця(a, b)` — це `a - b`, тож раніший момент першим дає від'ємну відповідь.

## Пакети

`.zyp` пакує багатофайлову програму в один портативний файл. Це архів **вихідного коду**, а не двійковий файл, тож він працює всюди, де працює двійковий файл `zymbol`.

```bash
zymbol package мійпроєкт/ --script main.zy -o мійпроєкт.zyp
zymbol run мійпроєкт.zyp
```

> Архів містить маніфест (`zyp.toml`), що оголошує його вхідні скрипти та потрібну версію рушія. `zymbol run` розпаковує його в тимчасовий каталог і запускає звідти, тож код одноразовий, а те, що пише скрипт, потрапляє у ваш справжній робочий каталог. Пісочниця також завантажує файли `.zyp`.

## Числові Режими

Zymbol може писати числа в **69 системах цифр Unicode** — деванагарі, арабо-індійській, тайській, клінгонській pIqaD, математичному жирному, сегментах LCD тощо. Режим глобальний для процесу та впливає на виведення; арифметика не змінюється.

```zymbol
#०९#    // деванагарі   (U+0966–U+096F)
#٠٩#    // арабо-індійська (U+0660–U+0669)
#๐๙#    // тайська         (U+0E50–U+0E59)
#09#    // скинути до ASCII
```

```zymbol
x = 42
>> x ¶                  // → 42
#०९#
>> x ¶                  // → ४२
>> 3.14 ¶               // → ३.१४
>> #1 ¶                 // → #१
#09#
```

Цифри з будь-якої підтримуваної системи письма є допустимими літералами в коді:

```zymbol
#०९#
@ i:१..५ { >> i " " }
>> ¶                    // → १ २ ३ ४ ५
#09#
```

Читання симетричне — цифра розуміється в будь-якій системі письма:

```zymbol
>> #|"४२"| ¶            // → 42
>> #|'७'| ¶             // → 7
```

> `#` завжди ASCII, тож `#0` залишається візуально відмінним від цифри нуль у кожній системі письма.
> `#,` і `#^` також пишуть свої цифри в активній системі письма, і розділювачі слідують за нею — але пара ніколи не обертається: `,` групує, а `.` розділяє, в кожній системі письма.

## Оператори Даних

```zymbol
f = ##.42         // до Дійсного
i = ###3.7        // до Цілого, округлено  → 4
t = ##!3.7        // до Цілого, обрізано  → 3
>> f " " i " " t ¶      // → 42 4 3
>> f#? ¶                // → (##., 2, 42)
```

> Дійсне виводиться цифрами, ніколи як експонента, і скидає кінцевий `.0` — `##.42` пише `42` і все ще є Дійсним, як показує `f#?`.

```zymbol
>> #|"42"| ¶       // → 42
>> #|"abc"| ¶      // → abc   безпечне: повертає введення незміненим
>> ##!'A' ¶        // → 65    кодова точка Символа
```

```zymbol
pi = 3.14159265
>> #.2|pi| ¶       // → 3.14          округлити до 2 знаків
>> #!2|pi| ¶       // → 3.14          обрізати до 2 знаків
>> #,|1234567| ¶   // → 1,234,567     розділювачі тисяч
>> #^|12345.678| ¶ // → 1.2345678e4   науковий запис
```

```zymbol
>> 0x41 ¶        // → A   шістнадцяткове
>> 0b01000001 ¶  // → A   двійкове
>> 0o101 ¶       // → A   вісімкове
>> 0d65 ¶        // → A   десяткове
```

> Літерал основи в діапазоні ASCII є **символом**: `0d65 == 'A'` — це `#1`, а `0d65 == 65` — це `#0`. Усі чотири основи записують той самий символ.

## Як Поєднуються Знаки

Ви бачили те саме впродовж усього посібника: **оператор — це не малюнок для запам'ятовування, а кілька знаків підряд, і кожен додає свій смисл.** Тепер, коли ви знаєте їх усі, ось повний шаблон.

Спочатку йде **у якому ми світі**:

| Знак | Світ | Ви бачили його в |
|------|------|------------------|
| `$` | колекція | `$#` `$+` `$?` `$^-` |
| `@` | час, усе, що повторюється | `@!` `@>` `@~` |
| `#` | те, чим річ *є*, а не її значення | `#?` `#(…)` `<#` `#>` |
| `>>` | з програми | `>>` `>>!` `>>?` |
| `<<` | у програму | `<<` `<<\|` `<<\|?` |
| `?` | запитати, без зобов'язання | `?` `_?` `??` `$?` |
| `!` | сила або помилка | `@!` `$!` `!?` |

Потім іде **що там робиться**: `+` додати, `-` вилучити, `^` упорядкувати, `~` змінити, `#` порахувати, `|` одна одиниця, `:` звʼязати імʼя.

І два правила, що ніколи не підводять:

**Подвоєння знака робить його вичерпним.** `?` питає один раз, `??` перевіряє багато випадків. `$?` питає, чи значення присутнє, `$??` повертає кожне місце, де воно є. `!` позначає помилку, `!!` поширює її без запитання.

**Знак режиму завжди йде останнім.** Коли `?` або `!` з'являються, щоб сказати, *як* щось робиться — невпевнено чи примусово — вони є останнім знаком оператора: `$??`, `$!!`, `<<|?`, `@!`, `##!`, `>>!`, `>>?`, `@:зовнішній!`. Після них ніколи немає операції.

Із цього випливає практична річ: **комбінація, якої ви ніколи не бачили, вже має сенс, перш ніж ви її подивитесь.** Якщо `$` — колекція, `^` — порядок, а `-` — обернене, то `$^-` сортує за спаданням, і ніхто не мусив вам це казати.

Не весь інвентар працює так, і сказати це краще, ніж вдавати. Більшість операторів чисто розкладаються. Шість розкладаються, але означають більше за свої частини: `!?` `:!` `:>` `|>` `::` `$++`. І десять треба вивчити напам'ять, бо вони зовсім не розкладаються: `¶` `><` `#1` `#0` `0x` `0b` `0o` `0d` `###` `°`.

> Рахувати непрозорі, а не припускати, що їх мало, — це навмисно: вони є справжньою ціною запам'ятовування мови. Повний довідник — інвентар, оголошені омографи та правила, які має задовольнити новий оператор, щоб існувати — це `SYMBOLS.md` у репозиторії інтерпретатора.

## Довідник Знаків

| Знак | Операція | Знак | Операція |
|--------|-----------|--------|-----------|
| `=` | змінна | `$#` | довжина |
| `:=` | константа | `$+` | додати |
| `>>` | виведення | `$+[i]` | вставити за індексом (з 1) |
| `<<` | введення | `$-` | вилучити перше за значенням |
| `¶` / `\\` | новий рядок | `$--` | вилучити всі за значенням |
| `?` | якщо | `$-[i]` | вилучити за індексом (з 1) |
| `_?` | інакше-якщо | `$-[i..j]` | вилучити діапазон (з 1) |
| `_` | інакше / шаблон | `$?` | містить |
| `??` | зіставлення | `$??` | знайти всі індекси (з 1) |
| `\|\|` | або-шаблон у гілці match | `$[s..e]` | зріз (з 1) |
| `@` | цикл | `$>` | відобразити |
| `@ N { }` | цикл N разів | `$\|` | фільтрувати |
| `@!` | перервати | `$<` | згорнути |
| `@>` | продовжити | `$/ розділювач` | розділити рядок |
| `@:імʼя { }` | іменований цикл | `$++ a b c` | побудувати конкатенацією |
| `@:імʼя!` | перервати за іменем | `$~~[p:r]` | замінити в рядку |
| `@:імʼя>` | продовжити за іменем | `$*` | повторити рядок |

## Журнал Змін Випуску

### v0.0.9 — Колекції Вирішили _(вересень 2026)_

- **Ламальна** Словник має власну нотацію: `#(ключ: значення)`. Голий `(x: 1)` відхиляється, а `#()` — це порожній словник, чим `()` ніколи не могло бути
- **Ламальна** Індексоване присвоєння відкликано: `масив[i] = v` і всі складені форми. `=` дає значення **ІМЕНІ**; зміна частини колекції — це `$~`
- **Ламальна** Ланцюговий індекс `m[i][j]` відхиляється як для читання, так і для запису — `>` стоїть між кроками
- **Ламальна** Модуль має оголошувати те, що експортує (**E014**); `#> { }` — це спосіб, яким модуль каже, що його поверхня порожня
- **Ламальна** Специфікатор циклу — це кількість або умова — без істинності. `@ []` і `@ 3.5` відхиляються
- **Додано** `##_` — літерал Одиниці та спосіб, яким програма питає, чи щось відсутнє
- **Додано** `#[…]` — масив, суміш типів елементів якого оголошена
- **Додано** `#?` розрізняє чотири колекції: `##]` `##[` `##)` `##(`
- **Додано** `std/time` — годинник і цивільний календар, із зонами та календарною арифметикою
- **Додано** `<~>` на верхньому рівні — це код виходу програми
- **Додано** `@ (k, v):пари` — шаблон у заголовку циклу
- **Додано** `#|c|` читає цифру в будь-якій із 69 систем письма; `#,` і `#^` пишуть в активній
- **Змінено** `Ціле` — безпечне ціле, ±(2⁵³ − 1), з відмовою при помилці в кожному рушії
- **Змінено** Іменована функція читає змінні файлу під час виклику, за значенням
- **Змінено** Інструкція, що лише читає імʼя, попереджає, а не проходить тихо
- **Рушії** 660 із 666 файлів корпусу згодні в усіх трьох рушіях, 0 розбіжностей

### v0.0.8 — Автозвільнення, `std/term` та Пакети _(серпень 2026)_

- **Додано** Автоматичне знищення при останньому використанні — невидиме; лише знижує пікову пам'ять
- **Додано** `std/term` — метрики відображення у стовпцях термінала
- **Додано** `##!` до `Символа` — його кодова точка Unicode
- **Додано** Або-шаблони в match: `'p' || 'P' => …`, альтернативи будь-якого виду в одній гілці
- **Додано** Пакети Zymbol (`.zyp`) — `zymbol package` / `zymbol run pkg.zyp`
- **Додано** `<~>` у місці виклику обов'язковий там, де викликаний оголошує вихідний параметр
- **Виправлено** Паритет системи модулів у регістровій VM

### v0.0.7 — Вбудована Стандартна Бібліотека _(липень 2026)_

- **Додано** `std/json`, `std/io`, `std/net`, `std/db` (ODBC) — усі з м'якими значеннями помилок
- **Додано** Типізоване/перевірене введення: `<< ##.(5,2) "ціна: " p`
- **Додано** Постфіксні оператори безпосередньо в `>>` — дужки не потрібні
- **Змінено** Форматувальник із відмовою при помилці: відмовляється писати вивід, який не може перечитати

### v0.0.6 — Уточнення та Наукова Бібліотека _(червень 2026)_

- **Ламальна** `=>` замінює `:` у гілках match і `<=` у псевдонімах імпорту/експорту
- **Додано** `std/math` і `std/random`
- **Додано** Оновлення словника за ключем: `d["k"]$~ значення`

### v0.0.5 — Примітиви TUI та Гаряче Визначення _(травень 2026)_

- **Додано** Гаряче визначення `°x` / `x°` і повторення рядка `$*`

### v0.0.4 — Індексація з 1 і Першокласні Функції _(квітень 2026)_
