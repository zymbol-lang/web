## විචල්‍යයන් සහ නියතයන්

```zymbol
x = ෧෦              // වෙනස් වන විචල්‍යය

නම = "අමල්"
සක්‍රීය = #෧         // බූලීය සත්‍යය
👋 := "හෙලෝ"
```

`°` (අංශක ලකුණ, U+00B0) පළමු භාවිතයේදී විචල්‍යයක් ස්වයංක්‍රීයව එහි මධ්‍යස්ථ අගයට ආරම්භ කරයි:

```zymbol
සංඛ්‍යා = [෩, ෧, ෪, ෧, ෫]
@ n:සංඛ්‍යා {
    °එකතුව += n
}
>> එකතුව ¶              // → 14
```

> `°විචල්‍යය` (පූර්වාක්ෂරය) ලූපයට ඉහළින් නැංගුරම් ලා ගනී — ප්‍රතිඵලය `@` ට පසුව කියවිය හැකිය.
> `විචල්‍යය°` (අනුප්‍රත්‍යය) ලූපය තුළ නැංගුරම් ලා ගනී — ලූපය අවසන් වූ විට මිය යයි.

නමක් පමණක් වන ප්‍රකාශයක් විචල්‍යය කියවා අගය ඉවතට විසි කරයි, එබැවින් එය අනතුරු අඟවයි:

```zymbol
ගණනය = ෫
ගණනය
```

සම්පාදකය මෙසේ අනතුරු අඟවයි (එහි පණිවිඩ සැමවිටම ඉංග්‍රීසියෙන්):

```text
warning: this statement does nothing: 'ගණනය' is read and discarded
  = help: remove it, or use it — `>> name ¶` to print it
```

එනම්: *«මෙම ප්‍රකාශය කිසිවක් නොකරයි: 'ගණනය' කියවා ඉවතට විසි කරන ලදී»*.

## දත්ත වර්ග

| අකුර | `'A'` | `##'` | එක් යුනිකෝඩ් කේත ලක්ෂ්‍යයක් |
| බූලීය | `#෧`, `#෦` | `##?` | සංඛ්‍යාත්මක නොවේ — `#෧ ≠ ෧` |

| ටූපලය | `(a, b)` | `##)` | ස්ථානීය, වෙනස් කළ නොහැකි |
| ශබ්දකෝෂය | `#(x: ෧, y: ෨)` | `##(` | යතුරු සහිත, වෙනස් කළ හැකි |

ආරක්ෂිත පරාසයෙන් බැහැර වන පූර්ණ සංඛ්‍යාවක් අල්ලා ගත හැකි දෝෂයකි, කිසිවිටෙක නිශ්ශබ්ද ආවරණයක් නොවේ:

```zymbol

    >> (෯෦෦෭෧෯෯෨෫෪෭෪෦෯෯෧ + ෧) ¶
```

## ප්‍රතිදානය සහ ආදානය

```zymbol
නම = "අමල්"
එකතුව = ෩
>> "හෙලෝ" ¶             // → හෙලෝ
>> "a=" නම " b=" එකතුව ¶ // → a=අමල් b=3
>> එකතුව#? ¶            // → (###, 1, 3)
```

```zymbol
<< නම
<< "ඔබේ නම ඇතුළත් කරන්න: " නම
<< ###(෪) "වයස: " වයස
```

**ලකුණු දෙකේ හැඩය බලන්න.** `>>` පිටතට යොමු කරයි: දත්ත වැඩසටහනෙන් ඉවත් කරයි. `<<` ඇතුළට යොමු කරයි: දත්ත වැඩසටහනට ගෙන එයි. මෙහි මතක තබා ගැනීමට කිසිවක් නොමැත — ඊතලය තොරතුරු ගමන් කරන දිශාව පෙන්වයි, එම අදහසම යමක් චලනය කරන සෑම ලකුණකම නැවත පැමිණේ.

> `¶` සහ `\\` සමාන නව රේඛා වේ. `>>` කිසිවිටෙක එකක් එකතු නොකරයි.
> ඉල්ලීමට පෙර වර්ග නිර්දේශකය කියවන අතරතුර වලංගු කරයි සහ අගය වලංගු වන තෙක් නැවත අසයි:
> `##.` දශම · `##.(T,D)` දශම · `###(N)` පූර්ණ සංඛ්‍යාව · `##"(N)"` පෙළ · `##'` එක් අකුරක්.

ගොනුවක ඉහළම මට්ටමේදී, `<~` යනු වැඩසටහනේ පිටවීමේ තත්ත්වයයි:

```zymbol
>> "පරීක්ෂා කරමින්" ¶      // → පරීක්ෂා කරමින්
<~ ෦
```

```zymbol
}
```

මෙහිදී ලකුණු ගුණ නොකර ඒකාබද්ධ වන්නේ මන්දැයි ඔබට පෙනෙනු ඇත. `<<` ආදානය බවත් `?` කැපවීමකින් තොරව අසන බවත් ඔබ දැනටමත් දන්නවා. එකම ලකුණක් පමණක් නවයි:

- `|` යනු **එක් ඒකකයක්**, මුළු ප්‍රවාහය නොවේ.

එයින්, යතුරුපුවරු ක්‍රියාකරුවන් දෙදෙනාම තමන්ම කියවති:

```text
<<        |             ?
ආදානය    එක් ඒකකයක්    කැපවීමකින් තොරව

<<|   එක් යතුරක් ගන්න, එකක් එන තෙක් රැඳී සිටින්න
<<|?  යතුරක් තිබේදැයි බලන්න, නැත්නම් ඉදිරියට යන්න
```

අනෙක් පැත්තෙන්ද එසේම: `>>` යවයි, `>>!` **බලයෙන්** යවයි (මුළු තිරයම හිස් කරයි), `>>?` ලියනවා වෙනුවට **අසයි** (ටර්මිනලය කොතරම් විශාලද). දකුණු පස ලකුණ ප්‍රකාරය වෙනස් කරන ලකුණයි, එය සැමවිටම අවසානයේ පැමිණේ.

> `>>!` තිරය හිස් කරයි. `>>?` `[පේළි, තීරු]` ලබා දෙයි. `@~ N` N මිලි තත්පර නිදාගනී.
> `<<|` එක් යතුරු එබීමක් කියවයි (අවහිර කරන); `<<|?` අවහිර නොකර මැන බලයි (`'\0'` කිසිවක් නොමැති නම්).
> ඊතල යතුරු `'↑' '↓' '←' '→' ලෙස විකේතනය වේ; ESC කේත ලක්ෂ්‍යය 27 වේ.
> ස්ථානගත ප්‍රතිදාන ටූපලය: `(පේළිය, තීරුව, BKS, ඉදිරිපස, පසුපස)` — ඕනෑම ස්ථානයක් කොමාවකින් ඉවත් කළ හැක (`>>~ (,,, ෧෯෬) > "රතු"`).
> BKS බිට්මාස්ක්: `1`=තද, `2`=ඇල, `4`=යටින් ඉරි. ANSI 256 වර්ණ පැලටය (`0`=ටර්මිනල පෙරනිමිය).

## පාලන ප්‍රවාහය

```zymbol
x = ෭
? x > ෧෦෦ {
    >> "විශාල" ¶
} _? x > ෦ {
    >> "ධන" ¶     // → ධන
} _ {
    >> "ඍණ" ¶
}
```

මෙහි නව ලකුණු දෙකක් ඇත, තුන්වැන්න ඒවා එකට තැබීමෙන් පැමිණේ:

- `?` යනු **ඇසීමයි**: එය කොන්දේසියක් විවෘත කරයි.
- `_` යනු **නිශ්චිතව දක්වා නැති දේයි**: කිසිදු ප්‍රශ්නයක් නොගැළපුණු විට ඉතිරි වන ශාඛාවයි.
- `_?` යනු දෙකම පිළිවෙලින්: *කිසිවක් නොගැළපුණොත්, නැවත අසන්න*.

එබැවින් `_?` එසේ ලියා ඇත. එය ඉගෙන ගැනීමට නව සංකේතයක් නොවේ — එය `_` පසුව `?` ය, එහි කොටස් දෙක පිළිවෙලින් කියවූ විට අදහස් කරන දේ හරියටම අදහස් කරයි.

> වරහන් `{ }` එක් ප්‍රකාශයක් සඳහා වුවද **අනිවාර්යයි**.

## ගැළපීම

```zymbol
ලකුණු = ෮෫
ශ්‍රේණිය = ?? ලකුණු {
    ෯෦..෧෦෦ => 'A'
    ෮෦..෮෯  => 'B'
    _       => 'F'
}
>> ශ්‍රේණිය ¶              // → B
```

```zymbol
උෂ්ණත්වය = -෫
තත්ත්වය = ?? උෂ්ණත්වය {
    < ෦  => "අයිස්"
    < ෨෦ => "සීතල"
    _    => "උණුසුම්"
}
>> තත්ත්වය ¶              // → අයිස්
```

`?` යනු "ඇසීම" බව ඔබ දැනටමත් දන්නවා. **`??` යනු බොහෝ වාරයක් ඇසීමයි**: භාෂාවේ ඕනෑම තැනක ලකුණක් දෙගුණ කිරීම යනු එම ලකුණ එක් වරක් කරන දේ බොහෝ වාරයක් කිරීමයි. එක් `?` එක් කොන්දේසියක් පරීක්ෂා කරයි; `??` අවස්ථා ලැයිස්තුවක් සමඟ පරීක්ෂා කරයි.

විකල්ප `||` සමඟ එකතු වේ, ඒවා රටා වර්ග මිශ්‍ර කළ හැකිය:

```zymbol
යතුර = 'P'
ක්‍රියාව = ?? යතුර {
    'p' || 'P' => "විරාමය"
    < ෦ || > ෧෦෦ => "පරාසයෙන් බැහැර"
    _ => "නොසලකා හරින ලදී"
}
>> ක්‍රියාව ¶             // → විරාමය
```

## ලූප


```zymbol

@ ප:පළතුරු { >> ප " " }
>> ¶                    // → ඇපල් පෙයාර්ස් මිදි
```

```zymbol

    ? i % ෨ == ෦ { @> }
    ? i > ෭ { @! }
    >> i " "

```

```zymbol
ගණනය = ෦
@:පිටත {
    ගණනය++
    ? ගණනය >= ෩ { @:පිටත! }
}
>> ගණනය ¶             // → 3
```

`@` යනු **කාලයේ** ලකුණයි: පුනරාවර්තනය වන සියල්ල එහි ජීවත් වේ. එම කාලය කැපීමට ඔබ එය අසල ලකුණක් එකතු කරන්න:

- `@!` — `!` යනු **බලයයි**: දැන් ලූපයෙන් ඉවත් වන්න.
- `@>` — `>` ඉදිරියට තල්ලු කරයි: ඊළඟ වටයට යන්න.
- `@:පිටත!` — `:` **නමක් බැඳ** ගනී, එබැවින් මෙය *පිටත* නම් ලූපය කපා දමයි, ආසන්නතම එක නොවේ.

ක්‍රියාකරුවන් තුනක්, ඒවායින් එකක්වත් වෙන වෙනම මතක තබා ගැනීමට සිදු නොවීය: ඒවා `@` සහ එය කරන දේ දැනටමත් පවසන ලකුණකි.

> **නිර්දේශකයක් යනු ගණනක් හෝ කොන්දේසියක්.** `පූර්ණ සංඛ්‍යාව` යනු ගණනක්, එක් වරක් ඇගයේ — `@ 0` ශරීරය බින්දු වාරයක් ක්‍රියාත්මක කරයි. අනෙක් සියල්ල කොන්දේසියක්. සත්‍යතාවක් නොමැත: `@ []` සහ `@ 3.5` ප්‍රතික්ෂේප වේ. එකතුවක් හරහා යාමට `@ x:අයිතම` භාවිතා කරන්න; එය ගණන් කිරීමට, `@ අයිතම$#`.

## ශ්‍රිත

```zymbol
එකතුකරන්න(a, b) { <~ a + b }
>> එකතුකරන්න(෩, ෪) ¶        // → 7
```

```zymbol
සාධකය(n) {
    ? n <= ෧ { <~ ෧ }
    <~ n * සාධකය(n - ෧)
}
>> සාධකය(෫) ¶       // → 120
```

ශ්‍රිතයක් ගොනුවේ විචල්‍යයන් අගයෙන් කියවයි, ඇතුළත ලිවීම ඇතුළතම රැඳී සිටී:

```zymbol
සීමාව = ෧෦෦
ඇතුළත(n) { <~ n < සීමාව }
>> ඇතුළත(෪෨) ¶         // → #1
```

ලකුණු දෙකක් මෙය වෙනස් කරයි, දෙකම **අත්සනේ සහ ඇමතුම් ස්ථානයේ** ලියා ඇත:

```zymbol
වැඩිකරන්න(ගණනය<~) { ගණනය = ගණනය + ෧ }
එකතුව = ෦
වැඩිකරන්න(එකතුව<~)
>> එකතුව ¶              // → 1
```

> `p~` යනු ක්‍රියාකාරී පිටපතකි — ශරීරයට එය නැවත පැවරිය හැකි අතර ඇමතුම්කරු ස්පර්ශ නොවේ.
> `p<~` යනු ප්‍රතිදාන පරාමිතියකි — වෙනස්කම් ආපසු ගමන් කරයි. ලකුණක් නොමැතිව `වැඩිකරන්න(එකතුව)` අර්ථ දෝෂයකි: විවරණය සහ අත්සන වෙන් කළ නොහැක.

## ලැම්ඩා සහ සංවෘත

```zymbol
දෙගුණය = x -> x * ෨
එකතුව = (a, b) -> a + b
>> දෙගුණය(෫) ¶          // → 10
>> එකතුව(෩, ෭) ¶          // → 10
```

```zymbol
වර්ගීකරණය = x -> {
    ? x > ෦ { <~ "ධන" }
    _? x < ෦ { <~ "ඍණ" }
    <~ "ශුන්‍ය"
}
>> වර්ගීකරණය(-෪) ¶         // → ඍණ
```

```zymbol
සාධකය = ෩
තෙගුණය = x -> x * සාධකය
>> තෙගුණය(෭) ¶          // → 21
```

```zymbol
එකතුකරන්නා_සාදන්න(n) { <~ x -> x + n }
එකතු෧෦ = එකතුකරන්නා_සාදන්න(෧෦)
>> එකතු෧෦(෫) ¶           // → 15
```

ලැම්ඩාවකට කිසිදු පරාමිතියක් නොගත හැක:

```zymbol
පිළිතුර = () -> ෪෨
>> පිළිතුර() ¶           // → 42
```

> ලැම්ඩාවක් ගොනුවේ විචල්‍යයන් **නිර්මාණය වන විට** අල්ලා ගනී; නම් කළ ශ්‍රිතයක් ඒවා **ඇමතූ විට** කියවයි.

## අරා

```zymbol
අරාව = [෧, ෨, ෩, ෪, ෫]
>> අරාව[෧] ¶       // → 1   දර්ශකය 1 න් ආරම්භ වේ
>> අරාව[-෧] ¶      // → 5   ඍණ අගය අවසානයේ සිට ගණන් කරයි
>> අරාව$# ¶        // → 5   දිග
```

```zymbol
අරාව = [෧, ෨, ෩]
>> (අරාව$+ ෬) ¶          // → [1, 2, 3, 6]   එකතු කරන්න
>> (අරාව$+[෨] ෯෯) ¶      // → [1, 99, 2, 3]  ස්ථානය 2 ට ඇතුළු කරන්න
>> (අරාව$- ෩) ¶          // → [1, 2]         පළමු සිදුවීම ඉවත් කරන්න
>> (අරාව$-[෧]) ¶         // → [2, 3]         දර්ශකය 1 ට ඉවත් කරන්න
>> (අරාව$[෧..෨]) ¶       // → [1, 2]         පෙත්ත, දෙකෙළවරම ඇතුළත්
>> (අරාව$? ෩) ¶          // → #1             අඩංගු වේ
```

සියල්ල `$` න් ආරම්භ වේ, එය **එකතුවේ** ලකුණයි, සහ එහි ඇතුළත කුමක් කරන දේ පවසන ලකුණක් සමඟ ඉදිරියට යයි: `#` කීයක්, `+` එකතු කරන්න, `-` ඉවත් කරන්න, `?` තිබේදැයි අසන්න. සහ `??` මෙන්, ලකුණ දෙගුණ කිරීම එය සවිස්තරව කිරීමයි: `$?` අගයක් *තිබේදැයි* අසයි, `$??` *ස්ථාන කීයක* තිබේදැයි අසා සියල්ල ලබා දෙයි.

```zymbol
අරාව = [෩, ෧, ෨]
>> (අරාව$^+) ¶     // → [1, 2, 3]   ආරෝහණ
>> (අරාව$^-) ¶     // → [3, 2, 1]   අවරෝහණ
```

**ප්‍රතිඵලයේ නීතිය.** එක් ක්‍රියාකරුවෙක්, සහ වටා ඇති කේතය එය සමඟ කරන දේ තීරණය කරයි: භාවිතා කළහොත්, එය **ගොඩනඟා** මුල් පිටපත ස්පර්ශ නොකර තබයි; ඉවතට විසි කළහොත්, එය **වෙනස් කරයි**.

```zymbol
අරාව = [෧, ෨, ෩]
පිටපත = අරාව[෨]$~ ෯෯
>> අරාව ¶                // → [1, 2, 3]
>> පිටපත ¶              // → [1, 99, 3]
අරාව[෨]$~ ෯෯
>> අරාව ¶                // → [1, 99, 3]
```

> **`=` කිසිවිටෙක එකතුවකට ලියන්නේ නැත.** `අරාව[෨] = ෯෯` Zymbol හි ආකාරයක් නොවේ — `=` **නමකට** අගයක් දෙයි. එකතුවක කොටසක් වෙනස් කිරීම සෑම එකතුවකම `$~` ය.

`[…]` එක් වර්ගයක් රඳවා ගනී සහ පරීක්ෂා කරයි; හිතාමතා මිශ්‍රණයක් `#[…]` සමඟ **ප්‍රකාශ කරයි**:

```zymbol
මිශ්‍රණය = #[෧, "දෙක", #෧]
>> මිශ්‍රණය ¶             // → [1, දෙක, #1]
>> ([෧, ෨] == #[෧, ෨]) ¶ // → #1
```

## බහු-මාන දර්ශකකරණය

`>` කැදලි ව්‍යුහයකට බසී. එක් වරහන් කණ්ඩායමක් එක් අංගයක් ආමන්ත්‍රණය කරයි, කොතරම් ගැඹුරු වුවද.

```zymbol
m = [[෧,෨,෩], [෪,෫,෬], [෭,෮,෯]]
>> m[෨>෩] ¶        // → 6   පේළිය 2, තීරුව 3
>> m[-෧>-෧] ¶      // → 9   අවසාන පේළිය, අවසාන තීරුව
```

```zymbol
m = [[෧,෨,෩], [෪,෫,෬], [෭,෮,෯]]
>> m[෧>෧ ; ෨>෨ ; ෩>෩] ¶          // → [1, 5, 9]          පැතලි: විකර්ණය
>> m[[෧>෧, ෧>෩] ; [෩>෧, ෩>෩]] ¶  // → [[1, 3], [7, 9]]   ව්‍යුහගත: කොන්
```

```zymbol
m = [[෧,෨,෩], [෪,෫,෬]]
>> (m[෧>෨]$~ ෯෯) ¶      // → [[1, 99, 3], [4, 5, 6]]
```

> `m[෧][෨]` Zymbol හි ආකාරයක් **නොවේ**. දාම දර්ශකය කියවීමට සහ ලිවීමට දෙකටම ප්‍රතික්ෂේප කරයි — එක් ප්‍රවේශයකට එක් වරහන් කණ්ඩායමක්, සහ පියවර අතර යන්නේ `>` ය.

## ශබ්දකෝෂ

නම් කළ ක්ෂේත්‍ර සහිත ටූපලයක් ශබ්දකෝෂයකි, සහ v0.0.9 සිට එය `#(…)` ලෙස ලියා ඇත.

```zymbol
පුද්ගලයා = #(නම: "අමල්", වයස: ෨෫)
>> පුද්ගලයා.නම ¶        // → අමල්
>> පුද්ගලයා["වයස"] ¶    // → 25
```

```zymbol
පුද්ගලයා = #(නම: "අමල්", වයස: ෨෫)
ක්ෂේත්‍රය = "නම"
>> පුද්ගලයා[ක්ෂේත්‍රය] ¶     // → අමල්
```

එය වෙනස් කළ හැකි අතර, යතුරු එකතු කළ හැකි අතර, එය හරහා යා හැකිය:

```zymbol
තොගය = #(පෙයාර්ස්: ෪)
තොගය["ඇපල්"]$~ ෧෦
@ k:තොගය { >> k "=" තොගය[k] " " }
>> ¶                    // → පෙයාර්ස්=4 ඇපල්=10
```

```zymbol
තොගය = #(පෙයාර්ස්: ෪, ඇපල්: ෧෦)
@ (k, v):තොගය { >> k ":" v " " }
>> ¶                    // → පෙයාර්ස්:4 ඇපල්:10
```

> `#()` හිස් ශබ්දකෝෂයයි, එය `()` විය නොහැකි දෙයකි — එය හිස් ටූපලයද විය යුතුය. නිරුවත් `(x: 1)` මෙම පණිවිඩය සමඟ ප්‍රතික්ෂේප වේ: *a dictionary is written `#(…)`* — «ශබ්දකෝෂයක් `#(…)` ලෙස ලියා ඇත».
> ශබ්දකෝෂයක් යතුරකින් ආමන්ත්‍රණය කරයි, කිසිවිටෙක ස්ථානයකින් නොවේ, එබැවින් `පුද්ගලයා[1]` දෝෂයකි.

## ටූපල

ටූපල **වෙනස් කළ නොහැකි** ඇණවුම් කළ බහාලුම් වන අතර විවිධ වර්ගවල අගයන් රඳවා ගනී.

```zymbol
ලක්ෂ්‍යය = (෧෦, ෨෦)
>> ලක්ෂ්‍යය[෧] ¶           // → 10
දත්ත = (෪෨, "හෙලෝ", #෧, ෩.෧෪)
```

```zymbol
t = (෧෦, ෨෦, ෩෦)
t2 = t[෨]$~ ෯෯෯
>> t ¶                  // → (10, 20, 30)
>> t2 ¶                 // → (10, 999, 30)
```

> ටූපලයක් එහි ස්ථානයේම වෙනස් කිරීමට ඕනෑම උත්සාහයක් දෝෂයකි, ක්‍රියාකරු කුමක් වුවද — වෙනස් නොවන බව අගයේ ගුණාංගයකි, සෑම `$` තුළම ව්‍යතිරේකයක් නොවේ.

## විග්‍රහ කිරීම

```zymbol
අරාව = [෧෦, ෨෦, ෩෦, ෪෦, ෫෦]
[a, b, c] = අරාව
>> a " " b " " c ¶      // → 10 20 [30, 40, 50]
```

```zymbol
අරාව = [෧෦, ෨෦, ෩෦, ෪෦, ෫෦]
[පළමු, *ඉතිරි] = අරාව
>> පළමු ¶            // → 10
>> ඉතිරි ¶              // → [20, 30, 40, 50]
```

```zymbol
ලක්ෂ්‍යය = (෧෦෦, ෨෦෦)
(px, py) = ලක්ෂ්‍යය
```

```zymbol
#(නම: n, වයස: v) = පුද්ගලයා
>> n " " v ¶            // → සීතා 25
```

> වරහන් හැඩය වර්ග කර ඇත: `[…]` අරාවක් ගනී, `(…)` ටූපලයක්, `#(…)` ශබ්දකෝෂයක්. අවසාන නම **ඉතිරිය අවශෝෂණය කරයි**, එබැවින් විග්‍රහ කිරීම කිසිවිටෙක දිග නිසා අසාර්ථක නොවේ — `(a, b, c) = (1,2,3,4,5)` `c = (3,4,5)` ලබා දෙයි, කිසිවක් නොතිබෙන විට `##_`.

## උසස් අනුපිළිවෙල ශ්‍රිත

```zymbol
සංඛ්‍යා = [෧, ෨, ෩, ෪, ෫]
>> (සංඛ්‍යා$> (x -> x * ෨)) ¶ // → [2, 4, 6, 8, 10]
>> (සංඛ්‍යා$| (x -> x % ෨ == ෦)) ¶ // → [2, 4]
>> (සංඛ්‍යා$< (෦, (සමුච්චය, x) -> සමුච්චය + x)) ¶ // → 15
```

```zymbol
සංඛ්‍යා = [෧, ෨, ෩, ෪, ෫, ෬]
දෙගුණය(x) { <~ x * ෨ }
විශාල(x) { <~ x > ෩ }
>> (සංඛ්‍යා$> දෙගුණය) ¶    // → [2, 4, 6, 8, 10, 12]
>> (සංඛ්‍යා$| විශාල) ¶    // → [4, 5, 6]
```

```zymbol
පාදම = [#(නම: "කාර්ලා", වයස: ෨෮), #(නම: "සීතා", වයස: ෨෫)]
වයස_අනුව = පාදම$^ (a, b -> a.වයස < b.වයස)
>> වයස_අනුව[෧].නම ¶     // → සීතා
```

> නම් කළ ශ්‍රිතයක් HOF වෙත **වරහන් නොමැතිව** යයි: `සංඛ්‍යා$> දෙගුණය`. `සංඛ්‍යා$> (දෙගුණය)` ලිවීම විග්‍රහ දෝෂයකි, මන්ද `(` ලැම්ඩාවක් විවෘත කරයි.

```zymbol
} :! ##Div {
```

| `##Range` | ආරක්ෂිත පූර්ණ සංඛ්‍යා පරාසයෙන් බැහැර |

| `##Time` | නොපවතින දිනයක් |

`!` යනු **දෝෂයේ සහ බලයේ** ලකුණයි, සහ පවුල් දෙකේම එකම ආකාරයෙන් කියවයි: `$!` අගයකින් එය දෝෂයක්දැයි අසයි; `$!!`, ලකුණ දෙගුණ කර, නොඅසා ඉහළට ප්‍රචාරණය කරයි.

> සම්මත පුස්තකාලයේ අසාර්ථකත්වයන් අත්හිටුවීම වෙනුවට `$!` සමඟ පරීක්ෂා කරන හෝ `!?` සමඟ අල්ලා ගන්නා **මෘදු දෝෂ අගයන්** ලෙස ආපසු පැමිණේ. `$!!` එකක් ඇමතුම්කරුට ප්‍රචාරණය කරයි.

## මොඩියුල

```zymbol
# ගණක {
    #> { එකතුකරන්න, PI }

    PI := ෩.෧෪෧෫෯
    එකතුකරන්න(a, b) { <~ a + b }
}
```

```zymbol
<# ./ගණක => ග

>> ග::එකතුකරන්න(෫, ෩) ¶
>> ග.PI ¶
```

```zymbol
# මගේ_පුස්තකාලය {
    #> { අභ්‍යන්තර_එකතුව => එකතුව }

    අභ්‍යන්තර_එකතුව(a, b) { <~ a + b }
}
```

මොඩියුල ලකුණු දෙක එකම අදහසයි, දැන් ගොනු සඳහා යොදා ඇත: `#` යනු **ප්‍රකාශයේ** මට්ටමයි — දෙයක් *කුමක්ද*, එහි අගය නොවේ — සහ ඊතලය කේතය ගමන් කරන දිශාව පවසයි:

```text
<#   ඊතලය ඇතුළු වේ: ආනයනය, වෙනත් ගොනුවකින් ගෙන එන්න
#>   ඊතලය පිටවේ: අපනයනය, වෙනත් ගොනුවලට ඉදිරිපත් කරන්න
```

දිශා ලකුණක් සැමවිටම එය යොමු කරන දිශාවට මුහුණලා ඇති දාරයේ වාඩි වේ. `<~` වමට ආපසු එන්නේ (ශ්‍රිතයෙන් පිටතට) සහ `->` දකුණට ඇතුළු වන්නේ (ලැම්ඩාවේ ශරීරයට) එකම හේතුවයි.

> **මොඩියුලයක් අපනයනය කරන දේ ප්‍රකාශ කරයි.** `#>` කොටස අනිවාර්යයි — එය ඉවත් කිරීම **E014** ය, සහ `#> { }` යනු මොඩියුලයක් එහි මතුපිට හිස් බව පවසන ක්‍රමයයි. `::` ශ්‍රිතයක් අමතයි, `.` නියතයක් කියවයි. මොඩියුල ශරීරයේ දිස්විය හැක්කේ ආනයන, අපනයන කොටස, වචනාර්ථ ආරම්භකයන් සහ ශ්‍රිත නිර්වචන පමණි; ක්‍රියාත්මක කළ හැකි ඕනෑම දෙයක් **E013** ය.

## සම්මත පුස්තකාලය

ස්වදේශීය මොඩියුල, වෙනත් ඕනෑම එකක් මෙන් ආනයනය කරයි:

| `std/json` | `decode decode_map encode` |

> `std/time` හි මොහොතක් යුගයේ සිට මිලි තත්පර වේ. දිනකට අඩුව ම කාල පරාසයකි, දිනක සිට ඉහළට දින දර්ශනයයි — එබැවින් මාසයක් එම මාසයේ එම දිනයටම වැටේ, සීමා කර ඇත. `වෙනස(a, b)` යනු `a - b` ය, එබැවින් කලින් මොහොත පළමුව දුන් විට ඍණ පිළිතුරක් ලබා දෙයි.

## සංඛ්‍යා ප්‍රකාර

Zymbol **යුනිකෝඩ් අංක අක්ෂර ක්‍රම 69** කින් සංඛ්‍යා ලිවිය හැකිය — දේවනාගරී, අරාබි-ඉන්දියානු, තායි, ක්ලින්ගොන් pIqaD, ගණිත තද, LCD කොටස්, සහ තවත්. ප්‍රකාරය ක්‍රියාවලියට ගෝලීය වන අතර ප්‍රතිදානයට බලපායි; අංක ගණිතය වෙනස් නොවේ.

```zymbol
#०९#    // දේවනාගරී   (U+0966–U+096F)
#٠٩#    // අරාබි-ඉන්දියානු (U+0660–U+0669)
#๐๙#    // තායි         (U+0E50–U+0E59)
#09#    // ASCII වෙත නැවත සකසන්න
```

```zymbol
x = 42
>> x ¶                  // → 42
#०९#
>> x ¶                  // → ४२
>> 3.14 ¶               // → ३.१४
>> #1 ¶                 // → #१
#09#
```

ඕනෑම ආධාරක අක්ෂර ක්‍රමයක අංක මූලාශ්‍රයේ වලංගු වචනාර්ථ වේ:

```zymbol
#०९#
@ i:१..५ { >> i " " }
>> ¶                    // → १ २ ३ ४ ५
#09#
```

කියවීම සමමිතිකයි — අංකයක් ඕනෑම අක්ෂර ක්‍රමයකින් තේරුම් ගනී:

```zymbol
>> #|"४२"| ¶            // → 42
>> #|'७'| ¶             // → 7
```

> `#` සැමවිටම ASCII ය, එබැවින් `#0` සෑම අක්ෂර ක්‍රමයකම ශුන්‍ය අංකයෙන් දෘශ්‍යමය වශයෙන් වෙනස්ව පවතී.
> `#,` සහ `#^` ද ඒවායේ අංක සක්‍රීය අක්ෂර ක්‍රමයෙන් ලියයි, සහ බෙදුම්කරුවන් එය අනුගමනය කරයි — නමුත් යුගලය කිසිවිටෙක ප්‍රතිලෝම නොවේ: `,` කණ්ඩායම් කරයි සහ `.` බෙදයි, සෑම අක්ෂර ක්‍රමයකම.

## දත්ත ක්‍රියාකරුවන්

```zymbol
f = ##.෪෨         // දශම වෙත
i = ###෩.෭        // පූර්ණ සංඛ්‍යාවට, වට කර ඇත  → 4
t = ##!෩.෭        // පූර්ණ සංඛ්‍යාවට, කපා ඇත  → 3
>> f " " i " " t ¶      // → 42 4 3
>> f#? ¶                // → (##., 2, 42)
```

> දශමයක් අංක ලෙස මුද්‍රණය වේ, කිසිවිටෙක ඝාතකයක් ලෙස නොවේ, සහ අවසාන `.0` ඉවත් කරයි — `##.42` `42` ලියයි සහ තවමත් දශමයකි, `f#?` පෙන්වන පරිදි.

```zymbol
>> #|"42"| ¶       // → 42
>> #|"abc"| ¶      // → abc   ආරක්ෂිත: ආදානය නොවෙනස්ව ආපසු දෙයි
>> ##!'A' ¶        // → 65    අකුරක කේත ලක්ෂ්‍යය
```

```zymbol
pi = ෩.෧෪෧෫෯෨෬෫
>> #.෨|pi| ¶       // → 3.14          2 දශම ස්ථානවලට වට කරන්න
>> #!෨|pi| ¶       // → 3.14          2 දශම ස්ථානවලට කපන්න
>> #,|෧෨෩෪෫෬෭| ¶   // → 1,234,567     දහස් බෙදුම්කරුවන්
>> #^|෧෨෩෪෫.෬෭෮| ¶ // → 1.2345678e4  විද්‍යාත්මක අංකනය
```

```zymbol
>> 0x41 ¶        // → A   ෂඩ්දශාංශික
>> 0b01000001 ¶  // → A   ද්විමය
>> 0o101 ¶       // → A   අෂ්ටමය
>> 0d65 ¶        // → A   දශම
```

> ASCII පරාසයේ පාදම් වචනාර්ථයක් **අකුරකි**: `0d65 == 'A'` යනු `#1` ය, සහ `0d65 == 65` යනු `#0` ය. පාදම් හතරම එකම අකුර අක්ෂර වින්‍යාසය කරයි.

## ලකුණු ඒකාබද්ධ වන ආකාරය

ඔබ මෙම අත්පොත පුරාම එකම දෙය දුටුවා: **ක්‍රියාකරුවෙක් කටපාඩම් කිරීමට චිත්‍රයක් නොවේ, එය පේළියක ලකුණු කිහිපයක්, සහ එක් එක් එහි අර්ථය දායක කරයි.** දැන් ඔබ ඒ සියල්ල දන්නා බැවින්, මෙන්න සම්පූර්ණ රටාව.

මුලින්ම එන්නේ **අපි කුමන ලෝකයක සිටිනවාද**:

| ලකුණ | ලෝකය | ඔබ එය දුටුවේ |
|--------|-------|----------------------------|
| `$` | එකතුවක් | `$#` `$+` `$?` `$^-` |
| `@` | කාලය, පුනරාවර්තනය වන සියල්ල | `@!` `@>` `@~` |
| `#` | දෙයක් *කුමක්ද*, එහි අගය නොවේ | `#?` `#(…)` `<#` `#>` |
| `>>` | වැඩසටහනෙන් පිටතට | `>>` `>>!` `>>?` |
| `<<` | වැඩසටහනට ඇතුළට | `<<` `<<\|` `<<\|?` |
| `?` | ඇසීම, කැපවීමකින් තොරව | `?` `_?` `??` `$?` |
| `!` | බලය, හෝ දෝෂය | `@!` `$!` `!?` |

ඉන්පසු එන්නේ **එහි කුමක් කරනවාද**: `+` එකතු කරන්න, `-` ඉවත් කරන්න, `^` අනුපිළිවෙල, `~` වෙනස් කරන්න, `#` ගණන් කරන්න, `|` එක් ඒකකයක්, `:` නමක් බැඳ ගන්න.

සහ කිසිවිටෙක අසාර්ථක නොවන නීති දෙකක්:

**ලකුණක් දෙගුණ කිරීම එය සවිස්තර කරයි.** `?` එක් වරක් අසයි, `??` බොහෝ අවස්ථා පරීක්ෂා කරයි. `$?` අගයක් තිබේදැයි අසයි, `$??` එය ඇති සෑම ස්ථානයක්ම ආපසු දෙයි. `!` දෝෂයක් සලකුණු කරයි, `!!` නොඅසා එය ප්‍රචාරණය කරයි.

**ප්‍රකාර ලකුණ සැමවිටම අවසානයේ පැමිණේ.** `?` හෝ `!` යමක් *කෙසේ* කරනවාද — අවිශ්වාසයෙන් හෝ බලයෙන් — පැවසීමට දිස්වන විට, ඒවා ක්‍රියාකරුවාගේ අවසාන ලකුණයි: `$??`, `$!!`, `<<|?`, `@!`, `##!`, `>>!`, `>>?`, `@:පිටත!`. ඒවාට පසුව කිසිවිටෙක ක්‍රියාවක් නොමැත.

එයින් ප්‍රායෝගික දෙයක් පැමිණේ: **ඔබ කිසිවිටෙක නොදුටු සංයෝගයක්, ඔබ එය සොයා බැලීමට පෙර දැනටමත් අර්ථවත් ය.** `$` එකතුවක් නම් සහ `^` අනුපිළිවෙල නම් සහ `-` ප්‍රතිලෝම නම්, එවිට `$^-` අවරෝහණව වර්ග කරයි, කිසිවෙකු ඔබට කීමට සිදු නොවීය.

සම්පූර්ණ ලැයිස්තුව එසේ ක්‍රියා නොකරයි, එය පැවසීම රඟපෑමට වඩා හොඳය. බොහෝ ක්‍රියාකරුවන් පිරිසිදුව වෙන් වේ. හයක් වෙන් වන නමුත් ඒවායේ කොටස්වලට වඩා අර්ථ දරයි: `!?` `:!` `:>` `|>` `::` `$++`. සහ දහයක් කටපාඩම් කළ යුතුය මන්ද ඒවා කිසිසේත් වෙන් නොවේ: `¶` `><` `#1` `#0` `0x` `0b` `0o` `0d` `###` `°`.

> අපැහැදිලි ඒවා ගණන් කිරීම, ඒවා ස්වල්පයක් යැයි උපකල්පනය කිරීම වෙනුවට, හිතාමතා කර ඇත: ඒවා භාෂාවේ සැබෑ කටපාඩම් පිරිවැයයි. සම්පූර්ණ යොමුව — ලැයිස්තුව, ප්‍රකාශිත සමානාක්ෂර, සහ නව ක්‍රියාකරුවෙකු පැවතීමට සපුරාලිය යුතු නීති — අර්ථ නිරූපණ ගබඩාවේ `SYMBOLS.md` හි ඇත.
