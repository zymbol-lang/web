# Εγχειρίδιο Zymbol-Lang

> **Αναθεωρημένο για v0.0.9 — 2026-09-07**

Η **Zymbol-Lang** είναι μια συμβολική γλώσσα προγραμματισμού. Καμία λέξη στη γραμματική της — κάθε κατασκευή είναι ένα σημάδι. Λειτουργεί πανομοιότυπα σε οποιαδήποτε ανθρώπινη γλώσσα.

- Χωρίς `if`, `while`, `return` — μόνο `?`, `@`, `<~`
- Πλήρες Unicode — αναγνωριστικά σε οποιαδήποτε γλώσσα ή emoji
- Ανεξάρτητη από ανθρώπινη γλώσσα — ο κώδικας είναι ίδιος παντού

**Έκδοση διερμηνευτή**: v0.0.9 | **Κάλυψη δοκιμών**: 660/666 (τρεις μηχανές συμφωνούν, 0 αποκλίνουν)

## Μεταβλητές και Σταθερές

```zymbol
x = 10              // μεταβλητή που αλλάζει
PI := 3.14159       // σταθερά — η εκ νέου ανάθεση είναι σφάλμα χρόνου εκτέλεσης
όνομα = "Ελένη"
ενεργό = #1         // boolean αληθές
👋 := "Γεια"
```

```zymbol
x = 10    // 10
x += 5    // 15
x -= 3    // 12
x *= 2    // 24
x /= 3    // 8
x %= 3    // 2
x ^= 2    // 4
x++       // 5
x--       // 4
```

`°` (σύμβολο μοίρας, U+00B0) αρχικοποιεί αυτόματα μια μεταβλητή στην ουδέτερη τιμή της κατά την πρώτη χρήση:

```zymbol
αριθμοί = [3, 1, 4, 1, 5]
@ n:αριθμοί {
    °άθροισμα += n
}
>> άθροισμα ¶              // → 14
```

> `°μεταβλητή` (πρόθεμα) αγκυρώνει πάνω από τον βρόχο — το αποτέλεσμα διαβάζεται μετά το `@`.
> `μεταβλητή°` (επίθημα) αγκυρώνει μέσα στον βρόχο — πεθαίνει όταν τελειώνει ο βρόχος.

Μια δήλωση που είναι μόνο ένα όνομα διαβάζει τη μεταβλητή και πετάει την τιμή, γι' αυτό προειδοποιεί:

```zymbol
μετρητής = 5
μετρητής
```

Ο μεταγλωττιστής προειδοποιεί ως εξής (τα μηνύματά του είναι πάντα στα αγγλικά):

```text
warning: this statement does nothing: 'μετρητής' is read and discarded
  = help: remove it, or use it — `>> name ¶` to print it
```

Δηλαδή: *«αυτή η δήλωση δεν κάνει τίποτα: το 'μετρητής' διαβάστηκε και πετάχτηκε»*.

## Τύποι Δεδομένων

| Τύπος | Λεκτικό | Ετικέτα `#?` | Σημειώσεις |
|------|---------|--------------|------------|
| Ακέραιος | `42`, `-7` | `###` | Ασφαλής ακέραιος: ±(2⁵³ − 1) |
| Κινητής υποδιαστολής | `3.14`, `1.5e10` | `##.` | IEEE-754 διπλής ακρίβειας |
| Συμβολοσειρά | `"κείμενο"` | `##"` | Παρεμβολή: `"Γεια {όνομα}"` |
| Χαρακτήρας | `'A'` | `##'` | Ένα σημείο κώδικα Unicode |
| Boolean | `#1`, `#0` | `##?` | ΟΧΙ αριθμητικό — `#1 ≠ 1` |
| Πίνακας | `[1, 2, 3]` | `##]` | Ένας τύπος, ελεγμένος |
| Δηλωμένη μίξη | `#[1, "δύο"]` | `##[` | Ίδιος τύπος με `[…]`, μη ελεγμένος |
| Πλειάδα | `(a, b)` | `##)` | Θέσης, αμετάβλητη |
| Λεξικό | `#(x: 1, y: 2)` | `##(` | Με κλειδιά, μεταβλητό |
| Συνάρτηση | αναφορά σε ονομασμένη συνάρτηση | `##()` | Πρώτης τάξης; εμφανίζει `<funct/N>` |
| Lambda | `x -> x * 2` | `##->` | Πρώτης τάξης; εμφανίζει `<lambd/N>` |
| Μονάδα | `##_` | `##_` | Απουσία — δεν υπάρχει null |

```zymbol
>> 42#? ¶               // → (###, 2, 42)
>> [1, 2, 3]#? ¶        // → (##], 3, [1, 2, 3])
>> #(x: 1)#? ¶          // → (##(, 1, #(x: 1))
```

Ένας ακέραιος που βγαίνει από το ασφαλές εύρος είναι πιάσιμο σφάλμα, ποτέ σιωπηλή υπερχείλιση:

```zymbol
!? {
    >> (9007199254740991 + 1) ¶
} :! ##Range {
    >> "εκτός εύρους" ¶ // → εκτός εύρους
}
```

Το `##_` είναι ο τρόπος με τον οποίο ένα πρόγραμμα ρωτά αν κάτι απουσιάζει:

```zymbol
τίποτα() { }
τιμή = τίποτα()
>> (τιμή == ##_) ¶     // → #1
```

## Έξοδος και Είσοδος

```zymbol
όνομα = "Ελένη"
άθροισμα = 3
>> "Γεια" ¶             // → Γεια
>> "a=" όνομα " b=" άθροισμα ¶ // → a=Ελένη b=3
>> άθροισμα#? ¶            // → (###, 1, 3)
```

```zymbol
<< όνομα
<< "Εισάγετε το όνομά σας: " όνομα
<< ###(4) "Ηλικία: " ηλικία
```

**Κοιτάξτε το σχήμα των δύο σημαδιών.** Το `>>` δείχνει προς τα έξω: βγάζει δεδομένα από το πρόγραμμα. Το `<<` δείχνει προς τα μέσα: φέρνει δεδομένα στο πρόγραμμα. Δεν υπάρχει τίποτα να απομνημονεύσετε εδώ — το βέλος δείχνει προς ποια κατεύθυνση ταξιδεύει η πληροφορία, και η ίδια ιδέα επιστρέφει σε κάθε σημάδι που μετακινεί κάτι.

> `¶` και `\\` είναι ισοδύναμες νέες γραμμές. Το `>>` δεν προσθέτει ποτέ μία.
> Ένας προσδιοριστής τύπου πριν από το μήνυμα επικυρώνει κατά την ανάγνωση και επαναλαμβάνει μέχρι η τιμή να είναι έγκυρη:
> `##.` Κινητής υποδιαστολής · `##.(T,D)` δεκαδικός · `###(N)` Ακέραιος · `##"(N)"` κείμενο · `##'` ένας Χαρακτήρας.

Στο υψηλότερο επίπεδο ενός αρχείου, το `<~` είναι η κατάσταση εξόδου του προγράμματος:

```zymbol
>> "έλεγχος" ¶      // → έλεγχος
<~ 0
```

## Πρωτόγονα TUI

Χειριστές διεπαφής τερματικού για διαδραστικά προγράμματα. Τα περισσότερα απαιτούν μπλοκ `>>| { }` (εναλλακτική οθόνη + ακατέργαστη λειτουργία).

```zymbol
>>| {
    >>!
    >>~ (1, 1, 0, 10) > "Εκτελείται"
    @~ 1000
    >>~ (2, 1) > "Έτοιμο."
}
```

```zymbol
>>| {
    [γραμμές, στήλες] = >>?
    >>~ (1, 1) > "Τερματικό: " γραμμές " x " στήλες
    <<| πλήκτρο
    >>~ (2, 1) > "Πατήθηκε: " πλήκτρο
}
```

Εδώ μπορείτε να δείτε γιατί τα σημάδια συνδυάζονται αντί να πολλαπλασιάζονται. Ξέρετε ήδη ότι το `<<` είναι είσοδος και το `?` ρωτά χωρίς δέσμευση. Μόνο ένα σημάδι είναι νέο:

- `|` είναι **μία μονάδα**, όχι ολόκληρη η ροή.

Με αυτό, και οι δύο χειριστές πληκτρολογίου διαβάζονται μόνοι τους:

```text
<<        |             ?
είσοδος   μία μονάδα    χωρίς δέσμευση

<<|   πάρε ΕΝΑ πλήκτρο, και περίμενε μέχρι να υπάρξει ένα
<<|?  δες αν ΥΠΑΡΧΕΙ ένα πλήκτρο, και συνέχισε αν δεν υπάρχει
```

Το ίδιο στην άλλη πλευρά: το `>>` στέλνει, το `>>!` στέλνει **με δύναμη** (καθαρίζει ολόκληρη την οθόνη), ενώ το `>>?` **ρωτά** αντί να γράφει (πόσο μεγάλο είναι το τερματικό). Το σημάδι στα δεξιά είναι αυτό που αλλάζει τη λειτουργία, και έρχεται πάντα τελευταίο.

> `>>!` καθαρίζει την οθόνη. `>>?` επιστρέφει `[γραμμές, στήλες]`. `@~ N` κοιμάται N χιλιοστά του δευτερολέπτου.
> `<<|` διαβάζει ένα πάτημα πλήκτρου (μπλοκάροντας); `<<|?` ερευνά χωρίς μπλοκάρισμα (`'\0'` αν δεν υπάρχει).
> Τα βελάκια έρχονται αποκωδικοποιημένα ως `'↑' '↓' '←' '→'`; το ESC είναι σημείο κώδικα 27.
> Πλειάδα τοποθετημένης εξόδου: `(γραμμή, στήλη, BKS, μπροστινό, πίσω)` — οποιοδήποτε πεδίο μπορεί να παραλειφθεί με κόμμα (`>>~ (,,, 196) > "κόκκινο"`).
> Μάσκα bit BKS: `1`=Έντονα, `2`=Πλάγια, `4`=Υπογραμμισμένα. Παλέτα ANSI 256 χρωμάτων (`0`=προεπιλογή τερματικού).

## Χειριστές

```zymbol
a = 10
b = 3
απ1 = a + b    // 13
απ2 = a - b    // 7
απ3 = a * b    // 30
απ4 = a / b    // 3  (ακέραια διαίρεση)
απ5 = a % b    // 1
απ6 = a ^ b    // 1000
```

```zymbol
a = 10
b = 3
σ1 = a == b    // #0
σ2 = a <> b    // #1
σ3 = a < b     // #0
σ4 = a >= b    // #1
λ1 = #1 && #0  // #0
λ2 = !#1       // #0
```

> Το `==` δεν εξαναγκάζει ποτέ: `"5" == 5` είναι `#0`. Η διάταξη εξαναγκάζει: `"5" > 4` είναι `#1`, και το `"४२" > 5` επίσης — αριθμητικό κείμενο σε οποιοδήποτε από τα 69 σενάρια συγκρίνεται ως αριθμός.
> Μια συνάρτηση είναι ίση μόνο με τον εαυτό της, ποτέ με άλλη συνάρτηση με το ίδιο σώμα.

## Συμβολοσειρές

```zymbol
όνομα = "Ελένη"
n = 42
>> "Γεια " όνομα " έχεις " n ¶ // → Γεια Ελένη έχεις 42
περιγραφή = "Γεια {όνομα}, έχεις {n}"
>> περιγραφή ¶              // → Γεια Ελένη, έχεις 42
```

```zymbol
s = "Γεια κόσμε"
μήκος = s$#                  // 10
υποσυμβολοσειρά = s$[1..4]             // "Γεια"
περιέχει = s$? "κόσμε"          // #1
μέρη = "a,b,c,d"$/ ','    // [a, b, c, d]
αντικατάσταση = s$~~["ε":"α"]        // "Γαια κόσμα"
γραμμή = "─" $* 20
```

> Το `+` είναι μόνο για αριθμούς. Για συμβολοσειρές χρησιμοποιήστε παράθεση ή παρεμβολή.
> `\{` και `\}` είναι κυριολεκτικά άγκιστρα — η διαφυγή είναι συμμετρική.

## Έλεγχος Ροής

```zymbol
x = 7
? x > 100 {
    >> "μεγάλο" ¶
} _? x > 0 {
    >> "θετικό" ¶     // → θετικό
} _ {
    >> "αρνητικό" ¶
}
```

Εδώ υπάρχουν δύο νέα σημάδια, και ένα τρίτο που προκύπτει από τον συνδυασμό τους:

- `?` είναι **ερώτηση**: ανοίγει μια συνθήκη.
- `_` είναι **αυτό που δεν προσδιορίστηκε**: ο κλάδος που μένει όταν καμία ερώτηση δεν ταιριάζει.
- `_?` είναι και τα δύο στη σειρά: *αν τίποτα δεν ταίριαξε, ρώτα ξανά*.

Γι' αυτό το `_?` γράφεται έτσι. Δεν είναι νέο σύμβολο για εκμάθηση — είναι `_` ακολουθούμενο από `?`, και σημαίνει ακριβώς αυτό που σημαίνουν τα δύο μέρη του, διαβασμένα με τη σειρά.

> Τα άγκιστρα `{ }` είναι **υποχρεωτικά** ακόμη και για μία δήλωση.

## Αντιστοίχιση

```zymbol
βαθμολογία = 85
βαθμός = ?? βαθμολογία {
    90..100 => 'A'
    80..89  => 'B'
    _       => 'F'
}
>> βαθμός ¶              // → B
```

```zymbol
θερμοκρασία = -5
κατάσταση = ?? θερμοκρασία {
    < 0  => "πάγος"
    < 20 => "κρύο"
    _    => "ζέστη"
}
>> κατάσταση ¶              // → πάγος
```

Ξέρετε ήδη ότι το `?` είναι «ρωτώ». **Το `??` είναι ρωτώ πολλές φορές**: το διπλασιασμό ενός σημαδιού, οπουδήποτε στη γλώσσα, είναι να κάνεις πολλές φορές αυτό που το σημάδι κάνει μία. Ένα `?` δοκιμάζει μία συνθήκη; το `??` δοκιμάζει εναντίον μιας λίστας περιπτώσεων.

Οι εναλλακτικές ενώνονται με `||`, και μπορούν να αναμειγνύουν τύπους μοτίβων:

```zymbol
πλήκτρο = 'P'
ενέργεια = ?? πλήκτρο {
    'p' || 'P' => "παύση"
    < 0 || > 100 => "εκτός εύρους"
    _ => "αγνοήθηκε"
}
>> ενέργεια ¶             // → παύση
```

## Βρόχοι

```zymbol
@ i:1..4  { >> i " " }
>> ¶                    // → 1 2 3 4
@ i:1..9:2 { >> i " " }
>> ¶                    // → 1 3 5 7 9
@ i:5..1:1 { >> i " " }
>> ¶                    // → 5 4 3 2 1
```

```zymbol
n = 1
@ n <= 64 { n *= 2 }
>> n ¶                  // → 128
```

```zymbol
φρούτα = ["μήλο", "αχλάδι", "σταφύλι"]
@ φ:φρούτα { >> φ " " }
>> ¶                    // → μήλο αχλάδι σταφύλι
@ χ:"Γεια" { >> χ "-" }
>> ¶                    // → Γ-ε-ι-α-
```

```zymbol
@ i:1..10 {
    ? i % 2 == 0 { @> }
    ? i > 7 { @! }
    >> i " "
}
>> ¶                    // → 1 3 5 7
```

```zymbol
μετρητής = 0
@:εξωτερικός {
    μετρητής++
    ? μετρητής >= 3 { @:εξωτερικός! }
}
>> μετρητής ¶             // → 3
```

Το `@` είναι το σημάδι του **χρόνου**: ό,τι επαναλαμβάνεται ζει μέσα σε αυτό. Για να κόψετε αυτόν τον χρόνο προσθέτετε ένα σημάδι δίπλα του:

- `@!` — το `!` είναι **δύναμη**: βγες από τον βρόχο τώρα.
- `@>` — το `>` σπρώχνει μπροστά: πήγαινε στον επόμενο κύκλο.
- `@:εξωτερικός!` — το `:` **δένει ένα όνομα**, οπότε αυτό κόβει τον βρόχο *με το όνομα* εξωτερικός, όχι τον πλησιέστερο.

Τρεις χειριστές, και κανένας δεν χρειάστηκε να απομνημονευθεί ξεχωριστά: είναι `@` συν ένα σημάδι που λέει ήδη τι κάνει.

> **Ένας προσδιοριστής είναι ένα πλήθος ή μια συνθήκη.** Ένας `Ακέραιος` είναι ένα πλήθος, υπολογισμένο μία φορά — το `@ 0` εκτελεί το σώμα μηδέν φορές. Οτιδήποτε άλλο είναι συνθήκη. Δεν υπάρχει αληθεύτητα: τα `@ []` και `@ 3.5` απορρίπτονται. Για να διατρέξετε μια συλλογή χρησιμοποιήστε `@ x:στοιχεία`; για να τη μετρήσετε, `@ στοιχεία$#`.

## Συναρτήσεις

```zymbol
πρόσθεσε(a, b) { <~ a + b }
>> πρόσθεσε(3, 4) ¶        // → 7
```

```zymbol
παραγοντικό(n) {
    ? n <= 1 { <~ 1 }
    <~ n * παραγοντικό(n - 1)
}
>> παραγοντικό(5) ¶       // → 120
```

Μια συνάρτηση διαβάζει τις μεταβλητές του αρχείου κατά τιμή, και μια εγγραφή μέσα παραμένει μέσα:

```zymbol
όριο = 100
εντός(n) { <~ n < όριο }
>> εντός(42) ¶         // → #1
```

Δύο σημάδια το αλλάζουν αυτό, και τα δύο γράφονται **στην υπογραφή και στο σημείο κλήσης**:

```zymbol
αύξησε(μετρητής<~) { μετρητής = μετρητής + 1 }
άθροισμα = 0
αύξησε(άθροισμα<~)
>> άθροισμα ¶              // → 1
```

> Το `p~` είναι ένα αντίγραφο εργασίας — το σώμα μπορεί να το αναθέσει ξανά και ο καλών παραμένει άθικτος.
> Το `p<~` είναι μια παράμετρος εξόδου — η αλλαγή ταξιδεύει πίσω. Το `αύξησε(άθροισμα)` χωρίς το σημάδι είναι σημασιολογικό σφάλμα: η σχολίαση και η υπογραφή δεν μπορούν να αποκλίνουν.

## Lambda και Κλεισίματα

```zymbol
διπλασίασε = x -> x * 2
άθροισμα = (a, b) -> a + b
>> διπλασίασε(5) ¶          // → 10
>> άθροισμα(3, 7) ¶          // → 10
```

```zymbol
ταξινόμησε = x -> {
    ? x > 0 { <~ "θετικό" }
    _? x < 0 { <~ "αρνητικό" }
    <~ "μηδέν"
}
>> ταξινόμησε(-4) ¶         // → αρνητικό
```

```zymbol
παράγοντας = 3
τριπλασίασε = x -> x * παράγοντας
>> τριπλασίασε(7) ¶          // → 21
```

```zymbol
δημιούργησε_αθροιστή(n) { <~ x -> x + n }
πρόσθεσε10 = δημιούργησε_αθροιστή(10)
>> πρόσθεσε10(5) ¶           // → 15
```

Μια lambda μπορεί να μην παίρνει καθόλου παραμέτρους:

```zymbol
απάντηση = () -> 42
>> απάντηση() ¶           // → 42
```

> Μια lambda συλλαμβάνει τις μεταβλητές του αρχείου **όταν δημιουργείται**; μια ονομασμένη συνάρτηση τις διαβάζει **όταν καλείται**.

## Πίνακες

```zymbol
arr = [1, 2, 3, 4, 5]
>> arr[1] ¶       // → 1   η ευρετηρίαση είναι 1-βάσης
>> arr[-1] ¶      // → 5   το αρνητικό μετρά από το τέλος
>> arr$# ¶        // → 5   μήκος
```

```zymbol
arr = [1, 2, 3]
>> (arr$+ 6) ¶          // → [1, 2, 3, 6]   προσθήκη
>> (arr$+[2] 99) ¶      // → [1, 99, 2, 3]  εισαγωγή στη θέση 2
>> (arr$- 3) ¶          // → [1, 2]         αφαίρεση πρώτης εμφάνισης
>> (arr$-[1]) ¶         // → [2, 3]         αφαίρεση στο δείκτη 1
>> (arr$[1..2]) ¶       // → [1, 2]         φέτα, και τα δύο άκρα συμπεριλαμβάνονται
>> (arr$? 3) ¶          // → #1             περιέχει
```

Όλα ξεκινούν με `$`, το σημάδι της **συλλογής**, και συνεχίζουν με ένα σημάδι που λέει τι γίνεται μέσα της: `#` πόσα, `+` προσθήκη, `-` αφαίρεση, `?` ρώτα αν υπάρχει. Και όπως με το `??`, ο διπλασιασμός του σημαδιού σημαίνει να το κάνεις εξαντλητικά: το `$?` ρωτά *αν* μια τιμή είναι παρούσα, το `$??` ρωτά *σε πόσες θέσεις* και τις επιστρέφει όλες.

```zymbol
arr = [3, 1, 2]
>> (arr$^+) ¶     // → [1, 2, 3]   αύξουσα
>> (arr$^-) ¶     // → [3, 2, 1]   φθίνουσα
```

**Ο κανόνας του αποτελέσματος.** Ένας χειριστής, και το τι κάνει ο γύρω κώδικας με αυτό αποφασίζει: αν χρησιμοποιηθεί, **χτίζει** και αφήνει το πρωτότυπο άθικτο; αν πεταχτεί, **τροποποιεί**.

```zymbol
arr = [1, 2, 3]
αντίγραφο = arr[2]$~ 99
>> arr ¶                // → [1, 2, 3]
>> αντίγραφο ¶              // → [1, 99, 3]
arr[2]$~ 99
>> arr ¶                // → [1, 99, 3]
```

> **Το `=` δεν γράφει ποτέ σε μια συλλογή.** Το `arr[2] = 99` δεν είναι μορφή της Zymbol — το `=` δίνει μια τιμή σε ένα **ΟΝΟΜΑ**. Η αλλαγή μέρους μιας συλλογής είναι `$~`, σε κάθε συλλογή.

Το `[…]` περιέχει έναν τύπο και ελέγχεται; μια σκόπιμη μίξη **δηλώνεται** με `#[…]`:

```zymbol
μίξη = #[1, "δύο", #1]
>> μίξη ¶             // → [1, δύο, #1]
>> ([1, 2] == #[1, 2]) ¶ // → #1
```

---

## Πολυδιάστατη Ευρετηρίαση

Το `>` κατεβαίνει σε μια ένθετη δομή. Μια ομάδα αγκίστρων διευθυνσιοδοτεί ένα στοιχείο, ανεξάρτητα από το βάθος.

```zymbol
m = [[1,2,3], [4,5,6], [7,8,9]]
>> m[2>3] ¶        // → 6   γραμμή 2, στήλη 3
>> m[-1>-1] ¶      // → 9   τελευταία γραμμή, τελευταία στήλη
```

```zymbol
m = [[1,2,3], [4,5,6], [7,8,9]]
>> m[1>1 ; 2>2 ; 3>3] ¶          // → [1, 5, 9]          επίπεδη: η διαγώνιος
>> m[[1>1, 1>3] ; [3>1, 3>3]] ¶  // → [[1, 3], [7, 9]]   δομημένη: οι γωνίες
```

```zymbol
m = [[1,2,3], [4,5,6]]
>> (m[1>2]$~ 99) ¶      // → [[1, 99, 3], [4, 5, 6]]
```

> Το `m[1][2]` **δεν** είναι μορφή της Zymbol. Ο αλυσιδωτός δείκτης απορρίπτεται για ανάγνωση και εγγραφή — μια ομάδα αγκίστρων ανά προσπέλαση, και το `>` είναι αυτό που πηγαίνει ανάμεσα στα βήματα.

## Λεξικά

Μια πλειάδα με ονομασμένα πεδία είναι ένα λεξικό, και από την v0.0.9 γράφεται `#(…)`.

```zymbol
άτομο = #(όνομα: "Ελένη", ηλικία: 25)
>> άτομο.όνομα ¶        // → Ελένη
>> άτομο["ηλικία"] ¶    // → 25
```

```zymbol
άτομο = #(όνομα: "Ελένη", ηλικία: 25)
πεδίο = "όνομα"
>> άτομο[πεδίο] ¶     // → Ελένη
```

Είναι μεταβλητό, μπορούν να προστεθούν κλειδιά, και μπορεί να διατραβηχθεί:

```zymbol
απόθεμα = #(αχλάδι: 4)
απόθεμα["μήλο"]$~ 10
@ k:απόθεμα { >> k "=" απόθεμα[k] " " }
>> ¶                    // → αχλάδι=4 μήλο=10
```

```zymbol
απόθεμα = #(αχλάδι: 4, μήλο: 10)
@ (k, v):απόθεμα { >> k ":" v " " }
>> ¶                    // → αχλάδι:4 μήλο:10
```

> Το `#()` είναι το κενό λεξικό, που το `()` δεν μπορούσε να είναι — θα έπρεπε να είναι και η κενή πλειάδα. Το γυμνό `(x: 1)` απορρίπτεται με αυτό το μήνυμα: *a dictionary is written `#(…)`* — «ένα λεξικό γράφεται `#(…)`».
> Ένα λεξικό διευθυνσιοδοτείται με κλειδί, ποτέ με θέση, οπότε το `άτομο[1]` είναι σφάλμα.

## Πλειάδες

Οι πλειάδες είναι **αμετάβλητα** διατεταγμένα δοχεία που κρατούν τιμές διαφορετικών τύπων.

```zymbol
σημείο = (10, 20)
>> σημείο[1] ¶           // → 10
δεδομένα = (42, "Γεια", #1, 3.14)
>> δεδομένα[3] ¶            // → #1
```

```zymbol
t = (10, 20, 30)
t2 = t[2]$~ 999
>> t ¶                  // → (10, 20, 30)
>> t2 ¶                 // → (10, 999, 30)
```

> Κάθε προσπάθεια τροποποίησης μιας πλειάδας στη θέση της είναι σφάλμα, ανεξάρτητα από τον χειριστή — η αμεταβλητότητα είναι ιδιότητα της τιμής, όχι εξαίρεση μέσα σε κάθε `$`.

## Αποδόμηση

```zymbol
arr = [10, 20, 30, 40, 50]
[a, b, c] = arr
>> a " " b " " c ¶      // → 10 20 [30, 40, 50]
```

```zymbol
arr = [10, 20, 30, 40, 50]
[πρώτο, *υπόλοιπο] = arr
>> πρώτο ¶            // → 10
>> υπόλοιπο ¶              // → [20, 30, 40, 50]
```

```zymbol
σημείο = (100, 200)
(px, py) = σημείο
>> px " " py ¶          // → 100 200
```

```zymbol
άτομο = #(όνομα: "Άννα", ηλικία: 25)
#(όνομα: n, ηλικία: h) = άτομο
>> n " " h ¶            // → Άννα 25
```

> Το σχήμα των αγκίστρων είναι τυποποιημένο: `[…]` παίρνει πίνακα, `(…)` πλειάδα, `#(…)` λεξικό. Το τελευταίο όνομα **απορροφά το υπόλοιπο**, οπότε η αποδόμηση δεν αποτυγχάνει ποτέ λόγω μήκους — `(a, b, c) = (1,2,3,4,5)` δίνει `c = (3,4,5)`, και `##_` όταν δεν μένει τίποτα.

## Συναρτήσεις Ανώτερης Τάξης

```zymbol
αριθμοί = [1, 2, 3, 4, 5]
>> (αριθμοί$> (x -> x * 2)) ¶ // → [2, 4, 6, 8, 10]
>> (αριθμοί$| (x -> x % 2 == 0)) ¶ // → [2, 4]
>> (αριθμοί$< (0, (συσσώρευση, x) -> συσσώρευση + x)) ¶ // → 15
```

```zymbol
αριθμοί = [1, 2, 3, 4, 5, 6]
διπλασίασε(x) { <~ x * 2 }
είναι_μεγάλο(x) { <~ x > 3 }
>> (αριθμοί$> διπλασίασε) ¶    // → [2, 4, 6, 8, 10, 12]
>> (αριθμοί$| είναι_μεγάλο) ¶    // → [4, 5, 6]
```

```zymbol
βάση = [#(όνομα: "Κάρλα", ηλικία: 28), #(όνομα: "Άννα", ηλικία: 25)]
κατά_ηλικία = βάση$^ (a, b -> a.ηλικία < b.ηλικία)
>> κατά_ηλικία[1].όνομα ¶     // → Άννα
```

> Μια ονομασμένη συνάρτηση πηγαίνει σε HOF **χωρίς παρενθέσεις**: `αριθμοί$> διπλασίασε`. Το να γράψετε `αριθμοί$> (διπλασίασε)` είναι σφάλμα ανάλυσης, γιατί το `(` ανοίγει lambda.

```zymbol
διπλασίασε = x -> x * 2
πρόσθεσε = (a, b) -> a + b
αύξησε = x -> x + 1
>> (5 |> διπλασίασε(_)) ¶    // → 10
>> (10 |> πρόσθεσε(_, 5)) ¶  // → 15
>> (5 |> διπλασίασε(_) |> αύξησε(_)) ¶ // → 11
```

## Χειρισμός Σφαλμάτων

```zymbol
!? {
    x = 10 / 0
} :! ##Div {
    >> "διαίρεση με το μηδέν" ¶  // → διαίρεση με το μηδέν
} :! {
    >> "άλλο: " _err ¶
} :> {
    >> "πάντα εκτελείται" ¶        // → πάντα εκτελείται
}
```

| Είδος | Πότε |
|-------|------|
| `##Div` | Διαίρεση με το μηδέν |
| `##Index` | Δείκτης εκτός ορίων |
| `##Key` | Κλειδί που δεν υπάρχει σε λεξικό |
| `##Range` | Εκτός του ασφαλούς εύρους ακεραίων |
| `##Type` | Ασυμφωνία τύπων |
| `##Parse` | Ανάλυση δεδομένων |
| `##IO` | Αρχείο / σύστημα |
| `##Network` | Σφάλματα δικτύου |
| `##DB` | Βάση δεδομένων |
| `##Time` | Ημερομηνία που δεν υπάρχει |
| `##_` | Οποιοδήποτε σφάλμα (πιάνει τα πάντα) |

Το `!` είναι το σημάδι του **σφάλματος και της δύναμης**, και διαβάζεται το ίδιο και στις δύο οικογένειες: το `$!` ρωτά μια τιμή αν είναι σφάλμα; το `$!!`, με το σημάδι διπλό, το διαδίδει προς τα πάνω χωρίς να ρωτήσει.

> Οι αποτυχίες της τυπικής βιβλιοθήκης επιστρέφουν ως **μαλακές τιμές σφάλματος** που δοκιμάζετε με `$!` ή πιάνετε με `!?`, αντί να ματαιωθεί το πρόγραμμα. Το `$!!` διαδίδει ένα προς τον καλούντα.

## Modules

```zymbol
# υπολογισμός {
    #> { πρόσθεσε, PI }

    PI := 3.14159
    πρόσθεσε(a, b) { <~ a + b }
}
```

```zymbol
<# ./υπολογισμός => υ

>> υ::πρόσθεσε(5, 3) ¶
>> υ.PI ¶
```

```zymbol
# βιβλιοθήκη_μου {
    #> { εσωτερική_πρόσθεση => άθροισμα }

    εσωτερική_πρόσθεση(a, b) { <~ a + b }
}
```

Τα δύο σημάδια των modules είναι η ίδια ιδέα, τώρα εφαρμοσμένη σε αρχεία: το `#` είναι το επίπεδο της **δήλωσης** — τι *είναι* κάτι, όχι πόσο αξίζει — και το βέλος λέει προς ποια κατεύθυνση ταξιδεύει ο κώδικας:

```text
<#   το βέλος μπαίνει: εισαγωγή, φέρε από άλλο αρχείο
#>   το βέλος βγαίνει: εξαγωγή, πρόσφερε σε άλλα αρχεία
```

Ένα σημάδι κατεύθυνσης κάθεται πάντα στην άκρη που κοιτά προς την κατεύθυνση που δείχνει. Είναι ο ίδιος λόγος που το `<~` επιστρέφει αριστερά (έξω από τη συνάρτηση) και το `->` μπαίνει δεξιά (μέσα στο σώμα της lambda).

> **Ένα module δηλώνει τι εξάγει.** Το μπλοκ `#>` είναι υποχρεωτικό — η παράλειψή του είναι **E014**, και το `#> { }` είναι πώς ένα module λέει ότι η επιφάνειά του είναι κενή. Το `::` καλεί μια συνάρτηση, το `.` διαβάζει μια σταθερά. Μόνο εισαγωγές, το μπλοκ εξαγωγής, κυριολεκτικοί αρχικοποιητές και ορισμοί συναρτήσεων μπορούν να εμφανιστούν στο σώμα ενός module; οτιδήποτε εκτελέσιμο είναι **E013**.

## Τυπική Βιβλιοθήκη

Εγγενή modules, που εισάγονται όπως κάθε άλλο:

| Module | Συναρτήσεις |
|--------|-------------|
| `std/math` | `sqrt exp ln log pow abs ceil floor round min max sin cos tan asin acos atan atan2 sinh cosh tanh sigmoid` · `PI` `E` |
| `std/random` | `entero rango peso_f64` |
| `std/json` | `decode decode_map encode` |
| `std/io` | `read write append exists delete list mkdir` |
| `std/net` | `get post post_json head` |
| `std/db` | `connect exec query query_one tx commit rollback` … |
| `std/term` | `width pad_left pad_right center truncate` |
| `std/time` | `now today parts of format add diff` |

```zymbol
<# std/math => m

>> m::sqrt(16.0) ¶      // → 4
>> m.PI ¶               // → 3.141592653589793
```

```zymbol
<# std/term => t

>> t::width("手番") ¶            // → 4   δύο γλύφοι, τέσσερις στήλες
>> "|" t::center("go", 8) "|" ¶ // → |   go   |
```

```zymbol
<# std/time => T

ημέρα = T::of(2026, 1, 31)
>> T::format(ημέρα, "%Y-%m-%d") ¶ // → 2026-01-31
>> T::format(T::add(ημέρα, 1, "month"), "%Y-%m-%d") ¶ // → 2026-02-28
```

> Το `std/term` μετρά **στήλες εμφάνισης**, όχι χαρακτήρες: τα CJK και τα περισσότερα emoji είναι 2 στήλες, οπότε στρώστε έναν πίνακα με `t::width`, ποτέ με `$#`.
> Στο `std/time` μια στιγμή είναι χιλιοστά του δευτερολέπτου από την εποχή. Κάτω από μια μέρα είναι διάρκεια, από μια μέρα και πάνω είναι ημερολόγιο — οπότε ένας μήνας πέφτει στην ίδια μέρα του μήνα, περιορισμένος. Το `διαφορά(a, b)` είναι `a - b`, οπότε η προγενέστερη στιγμή πρώτη δίνει αρνητική απάντηση.

```bash
zymbol package έργο_μου/ --script main.zy -o έργο_μου.zyp

```

Το `zymbol run` το εξάγει σε έναν προσωρινό κατάλογο και εκτελεί από εκεί, οπότε ο κώδικας είναι αναλώσιμος ενώ ό,τι γράφει το σενάριο προσγειώνεται στον πραγματικό κατάλογο εργασίας σας. Το playground φορτώνει επίσης αρχεία `.zyp`.

## Αριθμητικές Λειτουργίες

Η Zymbol μπορεί να γράψει αριθμούς σε **69 σενάρια ψηφίων Unicode** — Devanagari, Αραβο-Ινδικό, Ταϊλανδέζικο, Klingon pIqaD, Μαθηματικά Έντονα, τμήματα LCD και άλλα. Η λειτουργία είναι καθολική για τη διεργασία και επηρεάζει την έξοδο; η αριθμητική δεν αλλάζει.

```zymbol
#०९#    // Devanagari   (U+0966–U+096F)
#٠٩#    // Αραβο-Ινδικό (U+0660–U+0669)
#๐๙#    // Ταϊλανδέζικο         (U+0E50–U+0E59)
#09#    // επαναφορά σε ASCII
```

```zymbol
x = 42
>> x ¶                  // → 42
#०९#
>> x ¶                  // → ४२
>> 3.14 ¶               // → ३.१४
>> #1 ¶                 // → #१
#09#
```

Τα ψηφία οποιουδήποτε υποστηριζόμενου σεναρίου είναι έγκυρα λεκτικά στον πηγαίο κώδικα:

```zymbol
#०९#
@ i:१..५ { >> i " " }
>> ¶                    // → १ २ ३ ४ ५
#09#
```

Η ανάγνωση είναι συμμετρική — ένα ψηφίο γίνεται κατανοητό σε οποιοδήποτε σενάριο:

```zymbol
>> #|"४२"| ¶            // → 42
>> #|'७'| ¶             // → 7
```

> Το `#` είναι πάντα ASCII, οπότε το `#0` παραμένει οπτικά διακριτό από το ψηφίο μηδέν σε κάθε σενάριο.
> Τα `#,` και `#^` γράφουν επίσης τα ψηφία τους στο ενεργό σενάριο, και τα διαχωριστικά το ακολουθούν — αλλά το ζεύγος δεν αντιστρέφεται ποτέ: το `,` ομαδοποιεί και το `.` διαιρεί, σε κάθε σενάριο.

## Χειριστές Δεδομένων

```zymbol
f = ##.42         // σε Κινητής υποδιαστολής
i = ###3.7        // σε Ακέραιο, στρογγυλοποιημένο  → 4
t = ##!3.7        // σε Ακέραιο, κομμένο  → 3
>> f " " i " " t ¶      // → 42 4 3
>> f#? ¶                // → (##., 2, 42)
```

> Ένας Κινητής υποδιαστολής εκτυπώνεται ως ψηφία, ποτέ ως εκθέτης, και απορρίπτει το τελικό `.0` — το `##.42` γράφει `42` και παραμένει Κινητής υποδιαστολής, όπως δείχνει το `f#?`.

```zymbol
>> #|"42"| ¶       // → 42
>> #|"abc"| ¶      // → abc   ασφαλής αποτυχία: επιστρέφει την είσοδο αμετάβλητη
>> ##!'A' ¶        // → 65    σημείο κώδικα ενός Χαρακτήρα
```

```zymbol
pi = 3.14159265
>> #.2|pi| ¶       // → 3.14          στρογγυλοποίηση σε 2 δεκαδικά
>> #!2|pi| ¶       // → 3.14          κοπή σε 2 δεκαδικά
>> #,|1234567| ¶   // → 1,234,567     διαχωριστικά χιλιάδων
>> #^|12345.678| ¶ // → 1.2345678e4   επιστημονική σημείωση
```

```zymbol
>> 0x41 ¶        // → A   δεκαεξαδικό
>> 0b01000001 ¶  // → A   δυαδικό
>> 0o101 ¶       // → A   οκταδικό
>> 0d65 ¶        // → A   δεκαδικό
```

> Ένα λεκτικό βάσης στο εύρος ASCII είναι ένας **Χαρακτήρας**: το `0d65 == 'A'` είναι `#1`, και το `0d65 == 65` είναι `#0`. Και οι τέσσερις βάσεις γράφουν τον ίδιο χαρακτήρα.

## Πώς Συνδυάζονται τα Σημάδια

Έχετε δει το ίδιο πράγμα σε όλο αυτό το εγχειρίδιο: **ένας χειριστής δεν είναι ένα σχέδιο προς απομνημόνευση, είναι πολλά σημάδια στη σειρά, και το καθένα συνεισφέρει τη σημασία του.** Τώρα που τα ξέρετε όλα, ορίστε το πλήρες μοτίβο.

Πρώτα έρχεται **σε ποιον κόσμο βρισκόμαστε**:

| Σημάδι | Κόσμος | Το είδατε σε |
|--------|--------|--------------|
| `$` | μια συλλογή | `$#` `$+` `$?` `$^-` |
| `@` | χρόνος, ό,τι επαναλαμβάνεται | `@!` `@>` `@~` |
| `#` | τι *είναι* κάτι, όχι η τιμή του | `#?` `#(…)` `<#` `#>` |
| `>>` | έξω από το πρόγραμμα | `>>` `>>!` `>>?` |
| `<<` | μέσα στο πρόγραμμα | `<<` `<<\|` `<<\|?` |
| `?` | ρωτώ, χωρίς δέσμευση | `?` `_?` `??` `$?` |
| `!` | δύναμη, ή σφάλμα | `@!` `$!` `!?` |

Μετά έρχεται **τι γίνεται εκεί**: `+` προσθέτει, `-` αφαιρεί, `^` ταξινομεί, `~` τροποποιεί, `#` μετρά, `|` μία μονάδα, `:` δένει ένα όνομα.

Και δύο κανόνες που δεν αποτυγχάνουν ποτέ:

**Ο διπλασιασμός ενός σημαδιού το κάνει εξαντλητικό.** Το `?` ρωτά μία φορά, το `??` δοκιμάζει πολλές περιπτώσεις. Το `$?` ρωτά αν μια τιμή είναι παρούσα, το `$??` επιστρέφει κάθε θέση όπου βρίσκεται. Το `!` επισημαίνει ένα σφάλμα, το `!!` το διαδίδει χωρίς να ρωτήσει.

**Το σημάδι της λειτουργίας έρχεται πάντα τελευταίο.** Όταν το `?` ή το `!` εμφανίζονται για να πουν *πώς* γίνεται κάτι — διστακτικά ή με δύναμη — είναι το τελευταίο σημάδι του χειριστή: `$??`, `$!!`, `<<|?`, `@!`, `##!`, `>>!`, `>>?`, `@:εξωτερικός!`. Δεν υπάρχει ποτέ πράξη μετά από αυτά.

Κάτι πρακτικό προκύπτει από αυτό: **ένας συνδυασμός που δεν έχετε ξαναδεί έχει ήδη νόημα πριν τον αναζητήσετε.** Αν το `$` είναι συλλογή και το `^` είναι διάταξη και το `-` είναι αντιστροφή, τότε το `$^-` ταξινομεί φθίνουσα, και κανείς δεν χρειάστηκε να σας το πει.

Δεν λειτουργεί έτσι ολόκληρο το ευρετήριο, και το να το πούμε είναι καλύτερο από το να προσποιηθούμε. Οι περισσότεροι χειριστές αποσυντίθενται καθαρά. Έξι αποσυντίθενται αλλά σημαίνουν περισσότερα από τα μέρη τους: `!?` `:!` `:>` `|>` `::` `$++`. Και δέκα πρέπει να απομνημονευτούν γιατί δεν αποσυντίθενται καθόλου: `¶` `><` `#1` `#0` `0x` `0b` `0o` `0d` `###` `°`.

> Το να μετράμε τα αδιαφανή αντί να υποθέτουμε ότι είναι λίγα είναι σκόπιμο: είναι το πραγματικό κόστος απομνημόνευσης της γλώσσας. Η πλήρης αναφορά — το ευρετήριο, οι δηλωμένοι ομόγραφοι και οι κανόνες που πρέπει να ικανοποιεί ένας νέος χειριστής για να υπάρξει — είναι στο `SYMBOLS.md`, στο αποθετήριο του διερμηνευτή.

## Αρχείο Αλλαγών Έκδοσης

### v0.0.9 — Οι Συλλογές Αποφάσισαν _(Σεπτέμβριος 2026)_

- **Σπάσιμο** Το λεξικό έχει τη δική του σημειογραφία: `#(κλειδί: τιμή)`. Το γυμνό `(x: 1)` απορρίπτεται, και το `#()` είναι το κενό λεξικό — που το `()` δεν μπορούσε ποτέ να είναι
- **Σπάσιμο** Η ευρετηριασμένη ανάθεση αποσύρθηκε: `arr[i] = v` και όλες οι σύνθετες μορφές. Το `=` δίνει μια τιμή σε ένα **ΟΝΟΜΑ**; η αλλαγή μέρους μιας συλλογής είναι `$~`
- **Σπάσιμο** Ο αλυσιδωτός δείκτης `m[i][j]` απορρίπτεται για ανάγνωση και εγγραφή — το `>` πηγαίνει ανάμεσα στα βήματα
- **Σπάσιμο** Ένα module πρέπει να δηλώνει τι εξάγει (**E014**); το `#> { }` είναι πώς ένα module λέει ότι η επιφάνειά του είναι κενή
- **Σπάσιμο** Ένας προσδιοριστής βρόχου είναι ένα πλήθος ή μια συνθήκη — χωρίς αληθεύτητα. Τα `@ []` και `@ 3.5` απορρίπτονται
- **Προστέθηκε** `##_` — το λεκτικό Μονάδας, και πώς ένα πρόγραμμα ρωτά αν κάτι απουσιάζει
- **Προστέθηκε** `#[…]` — ένας πίνακας του οποίου η μίξη τύπων στοιχείων δηλώνεται
- **Προστέθηκε** Το `#?` ξεχωρίζει τις τέσσερις συλλογές: `##]` `##[` `##)` `##(`
- **Προστέθηκε** `std/time` — το ρολόι και το αστικό ημερολόγιο, με ζώνες και ημερολογιακή αριθμητική
- **Προστέθηκε** Ένα `<~>` στο υψηλότερο επίπεδο είναι η κατάσταση εξόδου του προγράμματος
- **Προστέθηκε** `@ (k, v):ζεύγη` — ένα μοτίβο στην κεφαλή του βρόχου
- **Προστέθηκε** Το `#|c|` διαβάζει ένα ψηφίο σε οποιοδήποτε από τα 69 σενάρια; τα `#,` και `#^` γράφουν στο ενεργό
- **Άλλαξε** Ο `Ακέραιος` είναι ένας ασφαλής ακέραιος, ±(2⁵³ − 1), κλειστός σε αποτυχία σε κάθε μηχανή
- **Άλλαξε** Μια ονομασμένη συνάρτηση διαβάζει τις μεταβλητές του αρχείου τη στιγμή της κλήσης, κατά τιμή
- **Άλλαξε** Μια δήλωση που διαβάζει μόνο ένα όνομα προειδοποιεί αντί να περάσει σιωπηλά
- **Μηχανές** 660 από τα 666 αρχεία corpus συμφωνούν σε όλες τις τρεις μηχανές, 0 αποκλίνουν
