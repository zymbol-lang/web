## ຕົວປ່ຽນ ແລະ ຄ່າຄົງທີ່

```zymbol
x = ໑໐              // ຕົວປ່ຽນທີ່ປ່ຽນໄດ້
PI := ໓.໑໔໑໕໙       // ຄ່າຄົງທີ່ — ການກຳນົດຄືນໃໝ່ແມ່ນຂໍ້ຜິດພາດເວລາແລ່ນ
ຊື່ = "ສົມຈິດ"
ເຮັດວຽກ = #໑         // ບູລີນຄວາມຈິງ
👋 := "ສະບາຍດີ"
```

```zymbol
x = ໑໐    // ໑໐
x += ໕    // ໑໕
x -= ໓    // ໑໒
x *= ໒    // ໒໔
x /= ໓    // ໘
x %= ໓    // ໒
x ^= ໒    // ໔
x++       // ໕
x--       // ໔
```

`°` (ເຄື່ອງໝາຍອົງສາ, U+00B0) ຈະເລີ່ມຕົວປ່ຽນໂດຍອັດຕະໂນມັດດ້ວຍຄ່າກາງໃນການໃຊ້ຄັ້ງທຳອິດ:

```zymbol
ຕົວເລກ = [໓, ໑, ໔, ໑, ໕]
@ n:ຕົວເລກ {
    °ລວມ += n
}
>> ລວມ ¶              // → 14
```

> `°ຕົວປ່ຽນ` (ຄຳນຳໜ້າ) ຍຶດເໜືອວົງ — ຜົນອ່ານໄດ້ຫຼັງ `@`.
> `ຕົວປ່ຽນ°` (ຄຳຕໍ່ທ້າຍ) ຍຶດໃນວົງ — ມັນຕາຍເມື່ອວົງສິ້ນສຸດ.

ຄຳສັ່ງທີ່ເປັນພຽງຊື່ຈະອ່ານຕົວປ່ຽນ ແລະ ຖິ້ມຄ່າ, ດັ່ງນັ້ນມັນເຕືອນ:

```zymbol
ນັບ = ໕
ນັບ
```

ຕົວລວມຈະເຕືອນແບບນີ້ (ຂໍ້ຄວາມຂອງມັນເປັນພາສາອັງກິດສະເໝີ):

```text
warning: this statement does nothing: 'ນັບ' is read and discarded
  = help: remove it, or use it — `>> name ¶` to print it
```

ໝາຍຄວາມວ່າ: *«ຄຳສັ່ງນີ້ບໍ່ເຮັດຫຍັງເລີຍ: 'ນັບ' ຖືກອ່ານ ແລະ ຖິ້ມໄປ»*.

## ປະເພດຂໍ້ມູນ

| ປະເພດ | ຕົວໜັງສື | ແທັກ `#?` | ໝາຍເຫດ |
|------|---------|----------|-------|
| ຈຳນວນເຕັມ | `໔໒`, `-໗` | `###` | ຈຳນວນເຕັມປອດໄພ: ±(2⁵³ − 1) |
| ຈຸດລອຍ | `໓.໑໔`, `໑.໕e໑໐` | `##.` | IEEE-754 ຄູ່ |
| ສະຕຣິງ | `"ຂໍ້ຄວາມ"` | `##"` | ການແຊກ: `"ສະບາຍດີ {ຊື່}"` |
| ຕົວອັກສອນ | `'A'` | `##'` | ໜຶ່ງຈຸດລະຫັດ Unicode |
| ບູລີນ | `#໑`, `#໐` | `##?` | ບໍ່ແມ່ນຕົວເລກ — `#໑ ≠ ໑` |
| ອາເລ | `[໑, ໒, ໓]` | `##]` | ປະເພດດຽວ, ກວດແລ້ວ |
| ປະສົມທີ່ປະກາດ | `#[໑, "ສອງ"]` | `##[` | ປະເພດດຽວກັບ `[…]`, ບໍ່ກວດ |
| ທູເພິນ | `(a, b)` | `##)` | ຕາມຕຳແໜ່ງ, ປ່ຽນບໍ່ໄດ້ |
| ດິກຊັນນາຣີ | `#(x: ໑, y: ໒)` | `##(` | ຕາມກະແຈ, ປ່ຽນໄດ້ |
| ຟັງຊັນ | ການອ້າງຟັງຊັນຕັ້ງຊື່ | `##()` | ຊັ້ນທຳອິດ; ສະແດງ `<funct/N>` |
| ແລມດາ | `x -> x * ໒` | `##->` | ຊັ້ນທຳອິດ; ສະແດງ `<lambd/N>` |
| ຫົວໜ່ວຍ | `##_` | `##_` | ການຂາດ — ບໍ່ມີ null |

```zymbol
>> ໔໒#? ¶               // → (###, 2, 42)
>> [໑, ໒, ໓]#? ¶        // → (##], 3, [1, 2, 3])
>> #(x: ໑)#? ¶          // → (##(, 1, #(x: 1))
```

ຈຳນວນເຕັມທີ່ອອກຈາກຊ່ວງປອດໄພແມ່ນຂໍ້ຜິດພາດທີ່ຈັບໄດ້, ບໍ່ແມ່ນການຫົກຫຸ້ມແບບງຽບ:

```zymbol
!? {
    >> (໙໐໐໗໑໙໙໒໕໔໗໔໐໙໙໑ + ໑) ¶
} :! ##Range {
    >> "ນອກຊ່ວງ" ¶ // → ນອກຊ່ວງ
}
```

`##_` ແມ່ນວິທີທີ່ໂປຣແກຣມຖາມວ່າມີສິ່ງໃດຂາດຫາຍໄປຫຼືບໍ່:

```zymbol
ບໍ່ມີຫຍັງ() { }
ຄ່າ = ບໍ່ມີຫຍັງ()
>> (ຄ່າ == ##_) ¶     // → #1
```

## ຜົນລັບ ແລະ ການປ້ອນ

```zymbol
ຊື່ = "ສົມຈິດ"
ລວມ = ໓
>> "ສະບາຍດີ" ¶             // → ສະບາຍດີ
>> "a=" ຊື່ " b=" ລວມ ¶ // → a=ສົມຈິດ b=3
>> ລວມ#? ¶            // → (###, 1, 3)
```

```zymbol
<< ຊື່
<< "ປ້ອນຊື່ຂອງທ່ານ: " ຊື່
<< ###(໔) "ອາຍຸ: " ອາຍຸ
```

**ເບິ່ງຮູບຮ່າງຂອງສອງເຄື່ອງໝາຍ.** `>>` ຊີ້ອອກຂ້າງນອກ: ມັນເອົາຂໍ້ມູນອອກຈາກໂປຣແກຣມ. `<<` ຊີ້ເຂົ້າຂ້າງໃນ: ມັນເອົາຂໍ້ມູນເຂົ້າໃນໂປຣແກຣມ. ບໍ່ມີຫຍັງຕ້ອງຈື່ຢູ່ບ່ອນນີ້ — ລູກສອນສະແດງທິດທາງທີ່ຂໍ້ມູນເດີນທາງ, ແລະ ແນວຄິດດຽວກັນນີ້ກັບມາໃນທຸກເຄື່ອງໝາຍທີ່ເຄື່ອນຍ້າຍສິ່ງໃດໜຶ່ງ.

> `¶` ແລະ `\\` ແມ່ນເສັ້ນໃໝ່ທີ່ເທົ່າກັນ. `>>` ບໍ່ເພີ່ມອັນໃດເລີຍ.
> ຕົວກຳນົດປະເພດກ່ອນຄຳຖາມຈະກວດສອບເມື່ອອ່ານ ແລະ ຖາມຄືນຈົນກວ່າຄ່າຈະຖືກຕ້ອງ:
> `##.` ຈຸດລອຍ · `##.(T,D)` ທົດສະນິຍົມ · `###(N)` ຈຳນວນເຕັມ · `##"(N)"` ຂໍ້ຄວາມ · `##'` ໜຶ່ງຕົວອັກສອນ.

ຢູ່ລະດັບສູງສຸດຂອງໄຟລ໌, `<~` ແມ່ນສະຖານະອອກຂອງໂປຣແກຣມ:

```zymbol
>> "ກຳລັງກວດ" ¶      // → ກຳລັງກວດ
<~ ໐
```

## ອົງປະກອບ TUI

ໂອເປຣະເຕີອິນເຕີເຟສຕຣາມິນອລສຳລັບໂປຣແກຣມແບບໂຕ້ຕອບ. ສ່ວນໃຫຍ່ຕ້ອງການບລັອກ `>>| { }` (ໜ້າຈໍທາງເລືອກ + ຮູບແບບດິບ).

```zymbol
>>| {
    >>!
    >>~ (໑, ໑, ໐, ໑໐) > "ກຳລັງແລ່ນ"
    @~ ໑໐໐໐
    >>~ (໒, ໑) > "ສຳເລັດ."
}
```

```zymbol
>>| {
    [ແຖວ, ຖັນ] = >>?
    >>~ (໑, ໑) > "ຕຣາມິນອລ: " ແຖວ " x " ຖັນ
    <<| ປຸ່ມ
    >>~ (໒, ໑) > "ກົດ: " ປຸ່ມ
}
```

ຢູ່ນີ້ທ່ານຈະເຫັນວ່າເປັນຫຍັງເຄື່ອງໝາຍຈຶ່ງລວມກັນແທນທີ່ຈະຄູນກັນ. ທ່ານຮູ້ແລ້ວວ່າ `<<` ແມ່ນການປ້ອນ ແລະ `?` ຖາມໂດຍບໍ່ຜູກພັນ. ມີພຽງເຄື່ອງໝາຍດຽວທີ່ໃໝ່:

- `|` ແມ່ນ **ໜ່ວຍດຽວ**, ບໍ່ແມ່ນທັງໝົດຂອງກະແສ.

ດ້ວຍສິ່ງນີ້, ໂອເປຣະເຕີແປ້ນພິມທັງສອງກໍອ່ານຕົວເອງ:

```text
<<        |             ?
ການປ້ອນ  ໜ່ວຍດຽວ        ໂດຍບໍ່ຜູກພັນ

<<|   ເອົາປຸ່ມໜຶ່ງປຸ່ມ, ແລະ ລໍຖ້າຈົນກວ່າຈະມີໜຶ່ງ
<<|?  ເບິ່ງວ່າມີປຸ່ມຫຼືບໍ່, ແລະ ສືບຕໍ່ຖ້າບໍ່ມີ
```

ຄືກັນຢູ່ອີກຂ້າງໜຶ່ງ: `>>` ສົ່ງອອກ, `>>!` ສົ່ງອອກ **ດ້ວຍກຳລັງ** (ລຶບໜ້າຈໍທັງໝົດ), ໃນຂະນະທີ່ `>>?` **ຖາມ** ແທນທີ່ຈະຂຽນ (ຕຣາມິນອລໃຫຍ່ປານໃດ). ເຄື່ອງໝາຍຢູ່ເບື້ອງຂວາແມ່ນອັນທີ່ປ່ຽນຮູບແບບ, ແລະ ມັນມາສຸດທ້າຍສະເໝີ.

> `>>!` ລຶບໜ້າຈໍ. `>>?` ສົ່ງຄືນ `[ແຖວ, ຖັນ]`. `@~ N` ນອນ N ມິນລິວິນາທີ.
> `<<|` ອ່ານການກົດປຸ່ມໜຶ່ງຄັ້ງ (ສະກັດ); `<<|?` ສຳຫຼວດໂດຍບໍ່ສະກັດ (`'\0'` ຖ້າບໍ່ມີ).
> ປຸ່ມລູກສອນມາເປັນ `'↑' '↓' '←' '→'`; ESC ແມ່ນຈຸດລະຫັດ 27.
> ທູເພິນຜົນລັບຕາມຕຳແໜ່ງ: `(ແຖວ, ຖັນ, BKS, ໜ້າ, ຫຼັງ)` — ຊ່ອງໃດກໍໄດ້ຖືກລະໄວ້ດ້ວຍຈຸດ (`>>~ (,,, ໑໙໖) > "ແດງ"`).
> ບິດແມສ BKS: `1`=ຕົວໜາ, `2`=ຕົວອຽງ, `4`=ຂີດກ້ອງ. ພາເລດ ANSI 256 ສີ (`0`=ຄ່າເລີ່ມຕົ້ນຂອງຕຣາມິນອລ).

```zymbol
ຕ໒ = !#໑       // #໐
```

> `==` ບໍ່ເຄີຍບັງຄັບ: `"5" == 5` ແມ່ນ `#0`. ການຈັດລຳດັບບັງຄັບ: `"5" > 4` ແມ່ນ `#1`, ແລະ `"४२" > 5` ກໍເຊັ່ນກັນ — ຂໍ້ຄວາມຕົວເລກໃນໜຶ່ງໃນ 69 ອັກສອນຖືກປຽບທຽບເປັນຕົວເລກ.
> ຟັງຊັນເທົ່າກັບຕົວມັນເອງເທົ່ານັ້ນ, ບໍ່ເຄີຍເທົ່າກັບຟັງຊັນອື່ນທີ່ມີໂຕຄືກັນ.

## ສະຕຣິງ

```zymbol
ຊື່ = "ສົມຈິດ"
n = ໔໒
>> "ສະບາຍດີ " ຊື່ " ທ່ານມີ " n ¶ // → ສະບາຍດີ ສົມຈິດ ທ່ານມີ 42
ຄຳອະທິບາຍ = "ສະບາຍດີ {ຊື່}, ທ່ານມີ {n}"
>> ຄຳອະທິບາຍ ¶              // → ສະບາຍດີ ສົມຈິດ, ທ່ານມີ 42
```

```zymbol
s = "ສະບາຍດີໂລກ"
ຄວາມຍາວ = s$#                  // ໑໐
ຕອນ = s$[໑..໖]             // "ສະບາຍດ"
ມີ = s$? "ໂລກ"          // #໑
ພາກສ່ວນ = "a,b,c,d"$/ ','    // [a, b, c, d]
ທົດແທນ = s$~~["າ":"ໍ"]        // "ສະບໍຍດີໂລກ"
ເສັ້ນ = "─" $* ໒໐
```

> `+` ສຳລັບຕົວເລກເທົ່ານັ້ນ. ສຳລັບສະຕຣິງໃຫ້ໃຊ້ການວາງຄຽງ ຫຼື ການແຊກ.
> `\{` ແລະ `\}` ແມ່ນເຄື່ອງໝາຍວົງເລັບແທ້ — ການຫຼົບໜີສົມມາດ.

## ການຄວບຄຸມກະແສ

```zymbol
x = ໗
? x > ໑໐໐ {
    >> "ໃຫຍ່" ¶
} _? x > ໐ {
    >> "ບວກ" ¶     // → ບວກ
} _ {
    >> "ລົບ" ¶
}
```

ຢູ່ນີ້ມີສອງເຄື່ອງໝາຍໃໝ່, ແລະ ເຄື່ອງໝາຍທີສາມມາຈາກການລວມພວກມັນເຂົ້າກັນ:

- `?` ແມ່ນ **ຖາມ**: ມັນເປີດເງື່ອນໄຂ.
- `_` ແມ່ນ **ສິ່ງທີ່ບໍ່ໄດ້ລະບຸ**: ສາຂາທີ່ເຫຼືອເມື່ອບໍ່ມີຄຳຖາມໃດກົງກັນ.
- `_?` ແມ່ນທັງສອງຕິດກັນ: *ຖ້າບໍ່ມີອັນໃດກົງກັນ, ຖາມອີກຄັ້ງ*.

ນັ້ນແມ່ນເຫດຜົນທີ່ `_?` ຂຽນແບບນັ້ນ. ມັນບໍ່ແມ່ນສັນຍະລັກໃໝ່ທີ່ຈະຮຽນ — ມັນແມ່ນ `_` ຕາມດ້ວຍ `?`, ແລະ ມັນໝາຍຄວາມວ່າແທ້ໆຕາມທີ່ສອງສ່ວນຂອງມັນໝາຍຄວາມ, ອ່ານຕາມລຳດັບ.

> ວົງເລັບ `{ }` ແມ່ນ **ບັງຄັບ** ແມ່ນແຕ່ສຳລັບຄຳສັ່ງດຽວ.

## ການຈັບຄູ່

```zymbol
ຄະແນນ = ໘໕
ເກຣດ = ?? ຄະແນນ {
    ໙໐..໑໐໐ => 'A'
    ໘໐..໘໙  => 'B'
    _       => 'F'
}
>> ເກຣດ ¶              // → B
```

```zymbol
ອຸນຫະພູມ = -໕
ສະພາບ = ?? ອຸນຫະພູມ {
    < ໐  => "ນ້ຳກ້ອນ"
    < ໒໐ => "ເຢັນ"
    _    => "ຮ້ອນ"
}
>> ສະພາບ ¶              // → ນ້ຳກ້ອນ
```

ທ່ານຮູ້ແລ້ວວ່າ `?` ແມ່ນ "ຖາມ". **`??` ແມ່ນຖາມຫຼາຍຄັ້ງ**: ການຄູນເຄື່ອງໝາຍໃນທຸກບ່ອນໃນພາສາແມ່ນການເຮັດສິ່ງທີ່ເຄື່ອງໝາຍເຮັດໜຶ່ງຄັ້ງຫຼາຍຄັ້ງ. `?` ດຽວທົດສອບເງື່ອນໄຂດຽວ; `??` ທົດສອບກັບລາຍການຂອງກໍລະນີ.

ທາງເລືອກລວມກັນດ້ວຍ `||`, ແລະ ພວກມັນສາມາດປະສົມປະເພດແພັດເທິນ:

```zymbol
ປຸ່ມ = 'P'
ການກະທຳ = ?? ປຸ່ມ {
    'p' || 'P' => "ຢຸດຊົ່ວຄາວ"
    < ໐ || > ໑໐໐ => "ນອກຊ່ວງ"
    _ => "ຖືກລະເລີຍ"
}
>> ການກະທຳ ¶             // → ຢຸດຊົ່ວຄາວ
```

## ວົງ

```zymbol
@ i:໑..໔  { >> i " " }
>> ¶                    // → 1 2 3 4
@ i:໑..໙:໒ { >> i " " }
>> ¶                    // → 1 3 5 7 9
@ i:໕..໑:໑ { >> i " " }
>> ¶                    // → 5 4 3 2 1
```

```zymbol
n = ໑
@ n <= ໖໔ { n *= ໒ }
>> n ¶                  // → 128
```

```zymbol
ໝາກໄມ້ = ["ໝາກໂປມ", "ໝາກພຣ໌", "ໝາກອະງຸ່ນ"]
@ ມ:ໝາກໄມ້ { >> ມ " " }
>> ¶                    // → ໝາກໂປມ ໝາກພຣ໌ ໝາກອະງຸ່ນ
@ ອ:"ສະບາຍດີ" { >> ອ "-" }
>> ¶                    // → ສ-ະ-ບ-າ-ຍ-ດ-ີ-
```

```zymbol
@ i:໑..໑໐ {
    ? i % ໒ == ໐ { @> }
    ? i > ໗ { @! }
    >> i " "
}
>> ¶                    // → 1 3 5 7
```

```zymbol
ນັບ = ໐
@:ນອກ {
    ນັບ++
    ? ນັບ >= ໓ { @:ນອກ! }
}
>> ນັບ ¶             // → 3
```

`@` ແມ່ນເຄື່ອງໝາຍຂອງ **ເວລາ**: ທຸກສິ່ງທີ່ຊ້ຳຢູ່ໃນມັນ. ເພື່ອຕັດເວລານັ້ນ, ທ່ານຕື່ມເຄື່ອງໝາຍຢູ່ຂ້າງມັນ:

- `@!` — `!` ແມ່ນ **ກຳລັງ**: ອອກຈາກວົງດຽວນີ້.
- `@>` — `>` ດັນໄປຂ້າງໜ້າ: ໄປຮອບຕໍ່ໄປ.
- `@:ນອກ!` — `:` **ຜູກຊື່**, ດັ່ງນັ້ນມັນຕັດວົງທີ່ *ຊື່ວ່າ* ນອກ, ບໍ່ແມ່ນອັນທີ່ໃກ້ທີ່ສຸດ.

ສາມໂອເປຣະເຕີ, ແລະ ບໍ່ມີອັນໃດຕ້ອງຈື່ແຍກຕ່າງຫາກ: ພວກມັນແມ່ນ `@` ບວກກັບເຄື່ອງໝາຍທີ່ບອກແລ້ວວ່າມັນເຮັດຫຍັງ.

> **ຕົວກຳນົດແມ່ນການນັບ ຫຼື ເງື່ອນໄຂ.** `ຈຳນວນເຕັມ` ແມ່ນການນັບ, ປະເມີນໜຶ່ງຄັ້ງ — `@ ໐` ແລ່ນໂຕສູນຄັ້ງ. ອັນອື່ນໆແມ່ນເງື່ອນໄຂ. ບໍ່ມີຄວາມຈິງ: `@ []` ແລະ `@ ໓.໕` ຖືກປະຕິເສດ. ເພື່ອຜ່ານຄໍເລັກຊັນໃຫ້ໃຊ້ `@ x:ລາຍການ`; ເພື່ອນັບມັນ, `@ ລາຍການ$#`.

## ຟັງຊັນ

```zymbol
ບວກ(a, b) { <~ a + b }
>> ບວກ(໓, ໔) ¶        // → 7
```

```zymbol
ແຟັກທໍຣຽວ(n) {
    ? n <= ໑ { <~ ໑ }
    <~ n * ແຟັກທໍຣຽວ(n - ໑)
}
>> ແຟັກທໍຣຽວ(໕) ¶       // → 120
```

ຟັງຊັນອ່ານຕົວປ່ຽນຂອງໄຟລ໌ຕາມຄ່າ, ແລະ ການຂຽນຢູ່ພາຍໃນກໍຢູ່ພາຍໃນ:

```zymbol
ຂີດຈຳກັດ = ໑໐໐
ພາຍໃນ(n) { <~ n < ຂີດຈຳກັດ }
>> ພາຍໃນ(໔໒) ¶         // → #1
```

ສອງເຄື່ອງໝາຍປ່ຽນສິ່ງນີ້, ແລະ ທັງສອງຖືກຂຽນ **ໃນລາຍເຊັນ ແລະ ທີ່ບ່ອນເອີ້ນ**:

```zymbol
ເພີ່ມ(ນັບ<~) { ນັບ = ນັບ + ໑ }
ລວມ = ໐
ເພີ່ມ(ລວມ<~)
>> ລວມ ¶              // → 1
```

> `p~` ແມ່ນສຳເນົາເຮັດວຽກ — ໂຕສາມາດກຳນົດຄືນໄດ້ ແລະ ຜູ້ເອີ້ນບໍ່ຖືກກະທົບ.
> `p<~` ແມ່ນພາຣາມິເຕີຜົນລັບ — ການປ່ຽນແປງກັບມາ. `ເພີ່ມ(ລວມ)` ໂດຍບໍ່ມີເຄື່ອງໝາຍແມ່ນຂໍ້ຜິດພາດຄວາມໝາຍ: ຄຳອະທິບາຍ ແລະ ລາຍເຊັນແຍກອອກບໍ່ໄດ້.

## ແລມດາ ແລະ ການປິດ

```zymbol
ສອງເທົ່າ = x -> x * ໒
ຜົນບວກ = (a, b) -> a + b
>> ສອງເທົ່າ(໕) ¶          // → 10
>> ຜົນບວກ(໓, ໗) ¶          // → 10
```

```zymbol
ຈັດປະເພດ = x -> {
    ? x > ໐ { <~ "ບວກ" }
    _? x < ໐ { <~ "ລົບ" }
    <~ "ສູນ"
}
>> ຈັດປະເພດ(-໔) ¶         // → ລົບ
```

```zymbol
ຕົວຄູນ = ໓
ສາມເທົ່າ = x -> x * ຕົວຄູນ
>> ສາມເທົ່າ(໗) ¶          // → 21
```

```zymbol
ສ້າງຕົວບວກ(n) { <~ x -> x + n }
ບວກ໑໐ = ສ້າງຕົວບວກ(໑໐)
>> ບວກ໑໐(໕) ¶           // → 15
```

ແລມດາສາມາດບໍ່ຮັບພາຣາມິເຕີເລີຍ:


> ແລມດາຈັບຕົວປ່ຽນຂອງໄຟລ໌ **ເມື່ອຖືກສ້າງ**; ຟັງຊັນທີ່ມີຊື່ອ່ານພວກມັນ **ເມື່ອຖືກເອີ້ນ**.

## ອາເລ

```zymbol
ອາເລ = [໑, ໒, ໓, ໔, ໕]
>> ອາເລ[໑] ¶       // → 1   ດັດຊະນີເລີ່ມຈາກ 1
>> ອາເລ[-໑] ¶      // → 5   ລົບນັບຈາກທ້າຍ
>> ອາເລ$# ¶        // → 5   ຄວາມຍາວ
```

```zymbol
ອາເລ = [໑, ໒, ໓]
>> (ອາເລ$+ ໖) ¶          // → [1, 2, 3, 6]   ເພີ່ມ
>> (ອາເລ$+[໒] ໙໙) ¶      // → [1, 99, 2, 3]  ແຊກທີ່ຕຳແໜ່ງ 2
>> (ອາເລ$- ໓) ¶          // → [1, 2]         ລຶບເຫດການທຳອິດ
>> (ອາເລ$-[໑]) ¶         // → [2, 3]         ລຶບທີ່ດັດຊະນີ 1
>> (ອາເລ$[໑..໒]) ¶       // → [1, 2]         ຕັດສ່ວນ, ທັງສອງປາຍລວມ
>> (ອາເລ$? ໓) ¶          // → #1             ມີ
```

ທັງໝົດເລີ່ມດ້ວຍ `$`, ເຄື່ອງໝາຍຂອງ **ຄໍເລັກຊັນ**, ແລະ ສືບຕໍ່ດ້ວຍເຄື່ອງໝາຍທີ່ບອກວ່າເຮັດຫຍັງຢູ່ໃນມັນ: `#` ຈັກອັນ, `+` ເພີ່ມ, `-` ລຶບ, `?` ຖາມວ່າມີຫຼືບໍ່. ແລະ ຄືກັບ `??`, ການຄູນເຄື່ອງໝາຍໝາຍເຖິງການເຮັດຢ່າງຄົບຖ້ວນ: `$?` ຖາມ *ວ່າມີ* ຄ່າໜຶ່ງຫຼືບໍ່, `$??` ຖາມ *ຢູ່ຈັກບ່ອນ* ແລະ ສົ່ງຄືນທັງໝົດ.

```zymbol
ອາເລ = [໓, ໑, ໒]
>> (ອາເລ$^+) ¶     // → [1, 2, 3]   ຂຶ້ນ
>> (ອາເລ$^-) ¶     // → [3, 2, 1]   ລົງ
```

**ກົດຂອງຜົນລັບ.** ໜຶ່ງໂອເປຣະເຕີ, ແລະ ສິ່ງທີ່ໂຄ້ດອ້ອມຂ້າງເຮັດກັບມັນເປັນຕົວຕັດສິນ: ຖ້າໃຊ້ແລ້ວ, ມັນ **ສ້າງ** ແລະ ປ່ອຍຕົ້ນສະບັບໄວ້; ຖ້າຖິ້ມແລ້ວ, ມັນ **ດັດແປງ**.

```zymbol
ອາເລ = [໑, ໒, ໓]
ສຳເນົາ = ອາເລ[໒]$~ ໙໙
>> ອາເລ ¶                // → [1, 2, 3]
>> ສຳເນົາ ¶              // → [1, 99, 3]
ອາເລ[໒]$~ ໙໙
>> ອາເລ ¶                // → [1, 99, 3]
```

> **`=` ບໍ່ເຄີຍຂຽນໃນຄໍເລັກຊັນ.** `ອາເລ[໒] = ໙໙` ບໍ່ແມ່ນຮູບແບບຂອງ Zymbol — `=` ໃຫ້ຄ່າແກ່ **ຊື່**. ການປ່ຽນສ່ວນໜຶ່ງຂອງຄໍເລັກຊັນແມ່ນ `$~`, ໃນທຸກຄໍເລັກຊັນ.

`[…]` ມີປະເພດດຽວ ແລະ ຖືກກວດ; ການປະສົມແບບເຈດຕະນາ **ຖືກປະກາດ** ດ້ວຍ `#[…]`:

```zymbol
ປະສົມ = #[໑, "ສອງ", #໑]
>> ປະສົມ ¶             // → [1, ສອງ, #1]
>> ([໑, ໒] == #[໑, ໒]) ¶ // → #1
```

## ດັດຊະນີຫຼາຍມິຕິ

`>` ລົງໄປໃນໂຄງສ້າງທີ່ຊ້ອນກັນ. ກຸ່ມວົງເລັບໜຶ່ງກຸ່ມກ່າວເຖິງອົງປະກອບໜຶ່ງ, ບໍ່ວ່າຈະເລິກສ່ຳໃດ.

```zymbol
m = [[໑,໒,໓], [໔,໕,໖], [໗,໘,໙]]
>> m[໒>໓] ¶        // → 6   ແຖວ 2, ຖັນ 3
>> m[-໑>-໑] ¶      // → 9   ແຖວສຸດທ້າຍ, ຖັນສຸດທ້າຍ
```

```zymbol
m = [[໑,໒,໓], [໔,໕,໖], [໗,໘,໙]]
>> m[໑>໑ ; ໒>໒ ; ໓>໓] ¶          // → [1, 5, 9]          ແປ: ເສັ້ນທະແຍງ
>> m[[໑>໑, ໑>໓] ; [໓>໑, ໓>໓]] ¶  // → [[1, 3], [7, 9]]   ໂຄງສ້າງ: ມຸມ
```

```zymbol
m = [[໑,໒,໓], [໔,໕,໖]]
>> (m[໑>໒]$~ ໙໙) ¶      // → [[1, 99, 3], [4, 5, 6]]
```

> `m[໑][໒]` **ບໍ່ແມ່ນ** ຮູບແບບຂອງ Zymbol. ດັດຊະນີແບບໂສ້ຖືກປະຕິເສດທັງການອ່ານ ແລະ ການຂຽນ — ກຸ່ມວົງເລັບໜຶ່ງຕໍ່ການເຂົ້າເຖິງໜຶ່ງຄັ້ງ, ແລະ `>` ແມ່ນສິ່ງທີ່ໄປລະຫວ່າງຂັ້ນຕອນ.

## ດິກຊັນນາຣີ

ທູເພິນທີ່ມີຟິລດ໌ຕັ້ງຊື່ແມ່ນດິກຊັນນາຣີ, ແລະ ຕັ້ງແຕ່ v0.0.9 ມັນຖືກຂຽນເປັນ `#(…)`.

```zymbol
ບຸກຄົນ = #(ຊື່: "ສົມຈິດ", ອາຍຸ: ໒໕)
>> ບຸກຄົນ.ຊື່ ¶        // → ສົມຈິດ
>> ບຸກຄົນ["ອາຍຸ"] ¶    // → 25
```

```zymbol
ບຸກຄົນ = #(ຊື່: "ສົມຈິດ", ອາຍຸ: ໒໕)
ຟິລດ໌ = "ຊື່"
>> ບຸກຄົນ[ຟິລດ໌] ¶     // → ສົມຈິດ
```

ມັນປ່ຽນໄດ້, ກະແຈສາມາດຖືກເພີ່ມ, ແລະ ມັນສາມາດຖືກຜ່ານ:

```zymbol
ສະຕັອກ = #(ໝາກພຣ໌: ໔)
ສະຕັອກ["ໝາກໂປມ"]$~ ໑໐
@ k:ສະຕັອກ { >> k "=" ສະຕັອກ[k] " " }
>> ¶                    // → ໝາກພຣ໌=4 ໝາກໂປມ=10
```

```zymbol
ສະຕັອກ = #(ໝາກພຣ໌: ໔, ໝາກໂປມ: ໑໐)
@ (k, v):ສະຕັອກ { >> k ":" v " " }
>> ¶                    // → ໝາກພຣ໌:4 ໝາກໂປມ:10
```

> `#()` ແມ່ນດິກຊັນນາຣີຫວ່າງ, ເຊິ່ງ `()` ເປັນບໍ່ໄດ້ — ມັນຈະຕ້ອງເປັນທູເພິນຫວ່າງນຳ. `(x: 1)` ແບບປ່າປ້ອງຖືກປະຕິເສດດ້ວຍຂໍ້ຄວາມນີ້: *a dictionary is written `#(…)`* — «ດິກຊັນນາຣີຂຽນເປັນ `#(…)`».
> ດິກຊັນນາຣີຖືກກ່າວເຖິງດ້ວຍກະແຈ, ບໍ່ເຄີຍດ້ວຍຕຳແໜ່ງ, ດັ່ງນັ້ນ `ບຸກຄົນ[1]` ແມ່ນຂໍ້ຜິດພາດ.

## ທູເພິນ

ທູເພິນແມ່ນພາຊະນະທີ່ຈັດລຳດັບ **ປ່ຽນບໍ່ໄດ້** ທີ່ເກັບຄ່າຕ່າງປະເພດກັນ.

```zymbol
ຈຸດ = (໑໐, ໒໐)
>> ຈຸດ[໑] ¶           // → 10
ຂໍ້ມູນ = (໔໒, "ສະບາຍດີ", #໑, ໓.໑໔)
>> ຂໍ້ມູນ[໓] ¶            // → #1
```

```zymbol
t = (໑໐, ໒໐, ໓໐)
t2 = t[໒]$~ ໙໙໙
>> t ¶                  // → (10, 20, 30)
>> t2 ¶                 // → (10, 999, 30)
```

> ຄວາມພະຍາຍາມໃດໆທີ່ຈະປ່ຽນທູເພິນຢູ່ບ່ອນຂອງມັນແມ່ນຂໍ້ຜິດພາດ, ບໍ່ວ່າໂອເປຣະເຕີຈະເປັນຫຍັງ — ການປ່ຽນບໍ່ໄດ້ແມ່ນຄຸນສົມບັດຂອງຄ່າ, ບໍ່ແມ່ນຂໍ້ຍົກເວັ້ນໃນແຕ່ລະ `$`.

## ການຖອດໂຄງສ້າງ

```zymbol
ອາເລ = [໑໐, ໒໐, ໓໐, ໔໐, ໕໐]
[a, b, c] = ອາເລ
>> a " " b " " c ¶      // → 10 20 [30, 40, 50]
```

```zymbol
ອາເລ = [໑໐, ໒໐, ໓໐, ໔໐, ໕໐]
[ທຳອິດ, *ທີ່ເຫຼືອ] = ອາເລ
>> ທຳອິດ ¶            // → 10
>> ທີ່ເຫຼືອ ¶              // → [20, 30, 40, 50]
```

```zymbol
ຈຸດ = (໑໐໐, ໒໐໐)
(px, py) = ຈຸດ
>> px " " py ¶          // → 100 200
```

```zymbol
ບຸກຄົນ = #(ຊື່: "ສີຕາ", ອາຍຸ: ໒໕)
#(ຊື່: n, ອາຍຸ: a) = ບຸກຄົນ
>> n " " a ¶            // → ສີຕາ 25
```

> ຮູບຮ່າງຂອງວົງເລັບຖືກພິມ: `[…]` ເອົາອາເລ, `(…)` ທູເພິນ, `#(…)` ດິກຊັນນາຣີ. ຊື່ສຸດທ້າຍ **ດູດຊຶມສ່ວນທີ່ເຫຼືອ**, ດັ່ງນັ້ນການຖອດໂຄງສ້າງບໍ່ເຄີຍລົ້ມເຫຼວຍ້ອນຄວາມຍາວ — `(a, b, c) = (1,2,3,4,5)` ໃຫ້ `c = (3,4,5)`, ແລະ `##_` ເມື່ອບໍ່ມີຫຍັງເຫຼືອ.

## ຟັງຊັນລຳດັບສູງ

```zymbol
ຕົວເລກ = [໑, ໒, ໓, ໔, ໕]
>> (ຕົວເລກ$> (x -> x * ໒)) ¶ // → [2, 4, 6, 8, 10]
>> (ຕົວເລກ$| (x -> x % ໒ == ໐)) ¶ // → [2, 4]
>> (ຕົວເລກ$< (໐, (ສະສົມ, x) -> ສະສົມ + x)) ¶ // → 15
```

```zymbol
ຕົວເລກ = [໑, ໒, ໓, ໔, ໕, ໖]
ສອງເທົ່າ(x) { <~ x * ໒ }
ໃຫຍ່(x) { <~ x > ໓ }
>> (ຕົວເລກ$> ສອງເທົ່າ) ¶    // → [2, 4, 6, 8, 10, 12]
>> (ຕົວເລກ$| ໃຫຍ່) ¶    // → [4, 5, 6]
```

```zymbol
ຖານ = [#(ຊື່: "ຄາຣ໌ລາ", ອາຍຸ: ໒໘), #(ຊື່: "ສີຕາ", ອາຍຸ: ໒໕)]
ຕາມອາຍຸ = ຖານ$^ (a, b -> a.ອາຍຸ < b.ອາຍຸ)
>> ຕາມອາຍຸ[໑].ຊື່ ¶     // → ສີຕາ
```

> ຟັງຊັນທີ່ມີຊື່ໄປຫາ HOF **ໂດຍບໍ່ມີວົງເລັບ**: `ຕົວເລກ$> ສອງເທົ່າ`. ການຂຽນ `ຕົວເລກ$> (ສອງເທົ່າ)` ແມ່ນຂໍ້ຜິດພາດການແຍກ, ເພາະ `(` ເປີດແລມດາ.

## ການຈັດການຂໍ້ຜິດພາດ

```zymbol
!? {
    a = ໑໐ / ໐
} :! ##Div {
    >> "ຫານດ້ວຍສູນ" ¶  // → ຫານດ້ວຍສູນ
} :! {
    >> "ອື່ນໆ: " _err ¶
} :> {
    >> "ແລ່ນສະເໝີ" ¶        // → ແລ່ນສະເໝີ
}
```

| ປະເພດ | ເມື່ອ |
|------|------|
| `##Div` | ຫານດ້ວຍສູນ |
| `##Index` | ດັດຊະນີນອກຂອບ |
| `##Key` | ບໍ່ມີກະແຈໃນດິກຊັນນາຣີ |
| `##Range` | ນອກຊ່ວງຈຳນວນເຕັມປອດໄພ |
| `##Type` | ປະເພດບໍ່ກົງກັນ |
| `##Parse` | ການແຍກຂໍ້ມູນ |
| `##IO` | ໄຟລ໌ / ລະບົບ |
| `##Network` | ຂໍ້ຜິດພາດເຄືອຂ່າຍ |
| `##DB` | ຖານຂໍ້ມູນ |
| `##Time` | ວັນທີທີ່ບໍ່ມີ |
| `##_` | ຂໍ້ຜິດພາດໃດກໍໄດ້ (ຈັບທັງໝົດ) |

`!` ແມ່ນເຄື່ອງໝາຍຂອງ **ຂໍ້ຜິດພາດ ແລະ ກຳລັງ**, ແລະ ຖືກອ່ານຄືກັນໃນທັງສອງຄອບຄົວ: `$!` ຖາມຄ່າວ່າມັນແມ່ນຂໍ້ຜິດພາດຫຼືບໍ່; `$!!`, ດ້ວຍເຄື່ອງໝາຍຄູນ, ແຜ່ກະຈາຍມັນຂຶ້ນໂດຍບໍ່ຖາມ.

> ຄວາມລົ້ມເຫຼວຂອງຫ້ອງສະໝຸດມາດຕະຖານກັບມາເປັນ **ຄ່າຂໍ້ຜິດພາດອ່ອນ** ທີ່ທ່ານທົດສອບດ້ວຍ `$!` ຫຼື ຈັບດ້ວຍ `!?`, ແທນທີ່ຈະຍົກເລີກ. `$!!` ແຜ່ກະຈາຍໜຶ່ງໄປຫາຜູ້ເອີ້ນ.

## ມອດູນ

```zymbol
# ເຄື່ອງຄິດເລກ {
    #> { ບວກ, PI }

    PI := ໓.໑໔໑໕໙
    ບວກ(a, b) { <~ a + b }
}
```

```zymbol
<# ./ເຄື່ອງຄິດເລກ => ຄ

>> ຄ::ບວກ(໕, ໓) ¶
>> ຄ.PI ¶
```

```zymbol
# ຫ້ອງສະໝຸດຂອງຂ້ອຍ {
    #> { ບວກພາຍໃນ => ລວມ }

    ບວກພາຍໃນ(a, b) { <~ a + b }
}
```

ສອງເຄື່ອງໝາຍມອດູນແມ່ນແນວຄິດດຽວກັນ, ຕອນນີ້ນຳໃຊ້ກັບໄຟລ໌: `#` ແມ່ນລະດັບຂອງ **ການປະກາດ** — ສິ່ງທີ່ສິ່ງໜຶ່ງ *ເປັນ*, ບໍ່ແມ່ນຄ່າຂອງມັນ — ແລະ ລູກສອນບອກທິດທາງທີ່ໂຄ້ດໄປ:

```text
<#   ລູກສອນເຂົ້າ: ນຳເຂົ້າ, ເອົາມາຈາກໄຟລ໌ອື່ນ
#>   ລູກສອນອອກ: ສົ່ງອອກ, ສະເໜີໃຫ້ໄຟລ໌ອື່ນ
```

ເຄື່ອງໝາຍທິດທາງນັ່ງຢູ່ຂອບທີ່ປະເຊີນກັບທິດທີ່ມັນຊີ້ສະເໝີ. ນີ້ແມ່ນເຫດຜົນດຽວກັນທີ່ `<~` ກັບຊ້າຍ (ອອກຈາກຟັງຊັນ) ແລະ `->` ເຂົ້າຂວາ (ເຂົ້າໃນໂຕຂອງແລມດາ).

> **ມອດູນປະກາດສິ່ງທີ່ມັນສົ່ງອອກ.** ບລັອກ `#>` ແມ່ນບັງຄັບ — ການລະໄວ້ແມ່ນ **E014**, ແລະ `#> { }` ແມ່ນວິທີທີ່ມອດູນບອກວ່າໜ້າຂອງມັນຫວ່າງ. `::` ເອີ້ນຟັງຊັນ, `.` ອ່ານຄ່າຄົງທີ່. ພຽງແຕ່ການນຳເຂົ້າ, ບລັອກສົ່ງອອກ, ຕົວເລີ່ມຕົ້ນຕົວໜັງສື ແລະ ນິຍາມຟັງຊັນສາມາດປາກົດໃນໂຕມອດູນ; ສິ່ງໃດທີ່ສາມາດປະຕິບັດໄດ້ແມ່ນ **E013**.

## ຫ້ອງສະໝຸດມາດຕະຖານ

ມອດູນພື້ນເມືອງ, ນຳເຂົ້າຄືກັບອັນອື່ນ:

| ມອດູນ | ຟັງຊັນ |
|--------|-----------|
| `std/math` | `sqrt exp ln log pow abs ceil floor round min max sin cos tan asin acos atan atan2 sinh cosh tanh sigmoid` · `PI` `E` |
| `std/random` | `entero rango peso_f64` |
| `std/json` | `decode decode_map encode` |
| `std/io` | `read write append exists delete list mkdir` |
| `std/net` | `get post post_json head` |
| `std/db` | `connect exec query query_one tx commit rollback` … |
| `std/term` | `width pad_left pad_right center truncate` |
| `std/time` | `now today parts of format add diff` |

```zymbol
<# std/math => m

>> m::sqrt(໑໖.໐) ¶      // → 4
>> m.PI ¶               // → 3.141592653589793
```

```zymbol
<# std/term => t

>> t::width("手番") ¶            // → 4   ສອງ glyph, ສີ່ຖັນ
>> "|" t::center("go", 8) "|" ¶ // → |   go   |
```

```zymbol
<# std/time => T

ມື້ = T::of(໒໐໒໖, ໑, ໓໑)
>> T::format(ມື້, "%Y-%m-%d") ¶ // → 2026-01-31
>> T::format(T::add(ມື້, ໑, "month"), "%Y-%m-%d") ¶ // → 2026-02-28
```

> `std/term` ວັດແທກ **ຖັນສະແດງຜົນ**, ບໍ່ແມ່ນຕົວອັກສອນ: CJK ແລະ emoji ສ່ວນໃຫຍ່ແມ່ນ 2 ຖັນ, ດັ່ງນັ້ນຈັດຕາຕະລາງດ້ວຍ `t::width`, ບໍ່ເຄີຍ `$#`.
> ໃນ `std/time` ຊ່ວງໜຶ່ງແມ່ນມິນລິວິນາທີຈາກຍຸກ. ໜ້ອຍກວ່າໜຶ່ງມື້ແມ່ນໄລຍະເວລາ, ຕັ້ງແຕ່ໜຶ່ງມື້ຂຶ້ນໄປແມ່ນປະຕິທິນ — ດັ່ງນັ້ນເດືອນໜຶ່ງຕົກໃນມື້ດຽວກັນຂອງເດືອນ, ຖືກໜີບ. `ຄວາມແຕກຕ່າງ(a, b)` ແມ່ນ `a - b`, ດັ່ງນັ້ນຊ່ວງທີ່ກ່ອນໜ້າກວ່າກ່ອນໃຫ້ຄຳຕອບລົບ.

## ແພັກເກັດ

`.zyp` ຫຍິບໂປຣແກຣມຫຼາຍໄຟລ໌ເຂົ້າເປັນໄຟລ໌ດຽວທີ່ພົກພາໄດ້. ມັນແມ່ນບ່ອນເກັບ **ຕົ້ນສະບັບ**, ບໍ່ແມ່ນໄບນາຣີ, ດັ່ງນັ້ນມັນແລ່ນທຸກບ່ອນທີ່ໄບນາຣີ `zymbol` ແລ່ນ.

```bash
zymbol package ໂຄງການຂອງຂ້ອຍ/ --script main.zy -o ໂຄງການຂອງຂ້ອຍ.zyp
zymbol run ໂຄງການຂອງຂ້ອຍ.zyp
```

> ບ່ອນເກັບມີ manifest (`zyp.toml`) ທີ່ປະກາດສະຄຣິບທາງເຂົ້າ ແລະ ສະບັບເຄື່ອງຈັກທີ່ມັນຕ້ອງການ. `zymbol run` ສະກັດມັນໃສ່ໄດເຣັກຕອຣີຊົ່ວຄາວ ແລະ ແລ່ນຈາກບ່ອນນັ້ນ, ດັ່ງນັ້ນໂຄ້ດຖິ້ມໄດ້ ໃນຂະນະທີ່ສິ່ງທີ່ສະຄຣິບຂຽນຕົກໃສ່ໄດເຣັກຕອຣີເຮັດວຽກຈິງຂອງທ່ານ. ສະໜາມຫຼິ້ນກໍໂຫຼດໄຟລ໌ `.zyp` ນຳ.

## ຮູບແບບຕົວເລກ

Zymbol ສາມາດຂຽນຕົວເລກໃນ **69 ອັກສອນຕົວເລກ Unicode** — ເທວະນາຄະຣີ, ອາຣັບ-ອິນເດຍ, ໄທ, Klingon pIqaD, ຄະນິດສາດໜາ, ພາກ LCD ແລະ ອື່ນໆ. ຮູບແບບແມ່ນທົ່ວໂລກສຳລັບຂະບວນການ ແລະ ສົ່ງຜົນຕໍ່ຜົນລັບ; ເລກຄະນິດບໍ່ປ່ຽນແປງ.

```zymbol
#໐໙#    // ລາວ   (U+0ED0–U+0ED9)
#०९#    // ເທວະນາຄະຣີ   (U+0966–U+096F)
#٠٩#    // ອາຣັບ-ອິນເດຍ (U+0660–U+0669)
#09#    // ຣີເຊັດເປັນ ASCII
```

```zymbol
a = ໔໒
>> a ¶                  // → 42
#໐໙#
>> a ¶                  // → ໔໒
>> ໓.໑໔ ¶               // → ໓.໑໔
>> #໑ ¶                 // → #໑
#09#
```

ຕົວເລກຂອງອັກສອນທີ່ຮອງຮັບໃດກໍຕາມແມ່ນຕົວໜັງສືທີ່ຖືກຕ້ອງໃນຕົ້ນສະບັບ:

```zymbol
#໐໙#
@ i:໑..໕ { >> i " " }
>> ¶                    // → ໑ ໒ ໓ ໔ ໕
#09#
```

ການອ່ານສົມມາດ — ຕົວເລກຖືກເຂົ້າໃຈໃນອັກສອນໃດກໍໄດ້:

```zymbol
>> #|"४२"| ¶            // → 42
>> #|'७'| ¶             // → 7
```

> `#` ແມ່ນ ASCII ສະເໝີ, ດັ່ງນັ້ນ `#0` ຍັງແຍກອອກຈາກຕົວເລກສູນໃນທຸກອັກສອນ.
> `#,` ແລະ `#^` ກໍຂຽນຕົວເລກຂອງພວກມັນໃນອັກສອນທີ່ໃຊ້ງານຢູ່, ແລະ ຕົວແຍກກໍຕິດຕາມ — ແຕ່ຄູ່ບໍ່ເຄີຍກັບດ້ານ: `,` ຈັດກຸ່ມ ແລະ `.` ແບ່ງ, ໃນທຸກອັກສອນ.

## ໂອເປຣະເຕີຂໍ້ມູນ

```zymbol
f = ##.໔໒         // ໄປຈຸດລອຍ
i = ###໓.໗        // ໄປຈຳນວນເຕັມ, ປັດ  → 4
t = ##!໓.໗        // ໄປຈຳນວນເຕັມ, ຕັດ  → 3
>> f " " i " " t ¶      // → 42 4 3
>> f#? ¶                // → (##., 2, 42)
```

> ຈຸດລອຍຖືກພິມເປັນຕົວເລກ, ບໍ່ເຄີຍເປັນເລກຍົກກຳລັງ, ແລະ ຖິ້ມ `.0` ສຸດທ້າຍ — `##.42` ຂຽນ `42` ແລະ ຍັງເປັນຈຸດລອຍ, ດັ່ງທີ່ `f#?` ສະແດງ.

```zymbol
>> #|"42"| ¶       // → 42
>> #|"abc"| ¶      // → abc   ປອດໄພ: ສົ່ງຄືນຂໍ້ມູນໂດຍບໍ່ປ່ຽນ
>> ##!'A' ¶        // → 65    ຈຸດລະຫັດຂອງຕົວອັກສອນ
```

```zymbol
pi = ໓.໑໔໑໕໙໒໖໕
>> #.໒|pi| ¶       // → 3.14          ປັດເປັນ 2 ຕຳແໜ່ງ
>> #!໒|pi| ¶       // → 3.14          ຕັດເປັນ 2 ຕຳແໜ່ງ
>> #,|໑໒໓໔໕໖໗| ¶   // → 1,234,567     ຕົວແຍກພັນ
>> #^|໑໒໓໔໕.໖໗໘| ¶ // → 1.2345678e4  ສັນຍະລັກວິທະຍາສາດ
```

```zymbol
>> 0x41 ¶        // → A   ຖານສິບຫົກ
>> 0b01000001 ¶  // → A   ຖານສອງ
>> 0o101 ¶       // → A   ຖານແປດ
>> 0d65 ¶        // → A   ຖານສິບ
```

> ຕົວໜັງສືຖານໃນຊ່ວງ ASCII ແມ່ນ **ຕົວອັກສອນ**: `0d65 == 'A'` ແມ່ນ `#1`, ແລະ `0d65 == 65` ແມ່ນ `#0`. ທັງສີ່ຖານສະກົດຕົວອັກສອນດຽວກັນ.

## ເຄື່ອງໝາຍລວມກັນແນວໃດ

ທ່ານໄດ້ເຫັນສິ່ງດຽວກັນຕະຫຼອດຄູ່ມືນີ້: **ໂອເປຣະເຕີບໍ່ແມ່ນຮູບແຕ້ມທີ່ຈະຈື່, ມັນແມ່ນເຄື່ອງໝາຍຫຼາຍອັນຕິດກັນ, ແລະ ແຕ່ລະອັນປະກອບສ່ວນຄວາມໝາຍຂອງມັນ.** ຕອນນີ້ທ່ານຮູ້ທັງໝົດແລ້ວ, ນີ້ແມ່ນຮູບແບບຄົບຖ້ວນ.

ກ່ອນອື່ນມາ **ພວກເຮົາຢູ່ໃນໂລກໃດ**:

| ເຄື່ອງໝາຍ | ໂລກ | ທ່ານເຫັນມັນຢູ່ |
|--------|-------|----------------------------|
| `$` | ຄໍເລັກຊັນ | `$#` `$+` `$?` `$^-` |
| `@` | ເວລາ, ທຸກສິ່ງທີ່ຊ້ຳ | `@!` `@>` `@~` |
| `#` | ສິ່ງທີ່ສິ່ງໜຶ່ງ *ເປັນ*, ບໍ່ແມ່ນຄ່າ | `#?` `#(…)` `<#` `#>` |
| `>>` | ອອກຈາກໂປຣແກຣມ | `>>` `>>!` `>>?` |
| `<<` | ເຂົ້າໃນໂປຣແກຣມ | `<<` `<<\|` `<<\|?` |
| `?` | ຖາມ, ໂດຍບໍ່ຜູກພັນ | `?` `_?` `??` `$?` |
| `!` | ກຳລັງ, ຫຼື ຂໍ້ຜິດພາດ | `@!` `$!` `!?` |

ແລ້ວມາ **ເຮັດຫຍັງຢູ່ບ່ອນນັ້ນ**: `+` ເພີ່ມ, `-` ລຶບ, `^` ລຳດັບ, `~` ດັດແປງ, `#` ນັບ, `|` ໜ່ວຍດຽວ, `:` ຜູກຊື່.

ແລະ ສອງກົດທີ່ບໍ່ເຄີຍລົ້ມເຫຼວ:

**ການຄູນເຄື່ອງໝາຍເຮັດໃຫ້ມັນຄົບຖ້ວນ.** `?` ຖາມໜຶ່ງຄັ້ງ, `??` ທົດສອບຫຼາຍກໍລະນີ. `$?` ຖາມວ່າມີຄ່າ, `$??` ສົ່ງຄືນທຸກບ່ອນທີ່ມັນຢູ່. `!` ທຳເຄື່ອງໝາຍຂໍ້ຜິດພາດ, `!!` ແຜ່ກະຈາຍໂດຍບໍ່ຖາມ.

**ເຄື່ອງໝາຍຮູບແບບມາສຸດທ້າຍສະເໝີ.** ເມື່ອ `?` ຫຼື `!` ປາກົດເພື່ອບອກ *ວິທີ* ທີ່ສິ່ງໜຶ່ງຖືກເຮັດ — ຢ່າງລັງເລ ຫຼື ຢ່າງບັງຄັບ — ພວກມັນແມ່ນເຄື່ອງໝາຍສຸດທ້າຍຂອງໂອເປຣະເຕີ: `$??`, `$!!`, `<<|?`, `@!`, `##!`, `>>!`, `>>?`, `@:ນອກ!`. ບໍ່ມີການດຳເນີນການຫຼັງພວກມັນເລີຍ.

ບາງສິ່ງທີ່ໃຊ້ໄດ້ຜົນອອກມາຈາກນັ້ນ: **ການລວມທີ່ທ່ານບໍ່ເຄີຍເຫັນກໍມີຄວາມໝາຍກ່ອນທີ່ທ່ານຈະຊອກຫາມັນ.** ຖ້າ `$` ແມ່ນຄໍເລັກຊັນ ແລະ `^` ແມ່ນລຳດັບ ແລະ `-` ແມ່ນກັບດ້ານ, ດັ່ງນັ້ນ `$^-` ຈັດລຳດັບລົງ, ແລະ ບໍ່ມີໃຜຕ້ອງບອກທ່ານ.

ບໍ່ແມ່ນທັງໝົດໃນສາລະບານເຮັດວຽກແບບນັ້ນ, ແລະ ການເວົ້າເຊັ່ນນັ້ນດີກວ່າການເຮັດເປັນວ່າເປັນ. ໂອເປຣະເຕີສ່ວນໃຫຍ່ແຍກອອກຢ່າງສະອາດ. ຫົກແຍກອອກ ແຕ່ໝາຍຄວາມຫຼາຍກວ່າສ່ວນຂອງພວກມັນ: `!?` `:!` `:>` `|>` `::` `$++`. ແລະ ສິບຕ້ອງຈື່ ເພາະພວກມັນບໍ່ແຍກອອກເລີຍ: `¶` `><` `#1` `#0` `0x` `0b` `0o` `0d` `###` `°`.

> ການນັບອັນທີ່ບໍ່ຈະແຈ້ງ ແທນທີ່ຈະສົມມຸດວ່າມີໜ້ອຍແມ່ນເຈດຕະນາ: ພວກມັນແມ່ນຕົ້ນທຶນການຈື່ທີ່ແທ້ຈິງຂອງພາສາ. ເອກະສານອ້າງອີງຄົບຖ້ວນ — ສາລະບານ, homograph ທີ່ປະກາດ, ແລະ ກົດທີ່ໂອເປຣະເຕີໃໝ່ຕ້ອງຕອບສະໜອງເພື່ອມີຢູ່ — ແມ່ນ `SYMBOLS.md`, ໃນບ່ອນເກັບຕົວແປ.

- **ເພີ່ມ** `<~>` ທີ່ບ່ອນເອີ້ນແມ່ນບັງຄັບບ່ອນທີ່ຜູ້ຖືກເອີ້ນປະກາດພາຣາມິເຕີຜົນລັບ
- **ແກ້ໄຂ** ຄວາມເທົ່າກັນຂອງລະບົບມອດູນໃນ VM ຣີຈິສເຕີ

### v0.0.7 — ຫ້ອງສະໝຸດມາດຕະຖານພື້ນເມືອງ _(ກໍລະກົດ 2026)_

- **ເພີ່ມ** `std/json`, `std/io`, `std/net`, `std/db` (ODBC) — ທັງໝົດມີຄ່າຂໍ້ຜິດພາດອ່ອນ
