# راهنمای Zymbol-Lang

> **بازنگری‌شده برای v0.0.9 — 2026-09-07**

**Zymbol-Lang** یک زبان برنامه‌نویسی نمادین است. هیچ کلمه‌ای در دستور زبان آن وجود ندارد — هر ساختار یک نشانه است. در هر زبان انسانی یکسان کار می‌کند.

- بدون `if`، `while`، `return` — فقط `?`، `@`، `<~`
- یونیکد کامل — شناسه‌ها در هر زبان یا ایموجی
- مستقل از زبان انسانی — کد همه‌جا یکسان است

**نسخه مفسر**: v0.0.9 | **پوشش آزمون**: 660/666 (سه موتور توافق دارند، ۰ واگرا)

## متغیرها و ثابت‌ها

```zymbol
x = ۱۰              // متغیر قابل تغییر
PI := ۳.۱۴۱۵۹       // ثابت — تخصیص مجدد خطای زمان اجراست
نام = "علی"
فعال = #۱           // بولی درست
👋 := "سلام"
```

```zymbol
x = ۱۰    // ۱۰
x += ۵    // ۱۵
x -= ۳    // ۱۲
x *= ۲    // ۲۴
x /= ۳    // ۸
x %= ۳    // ۲
x ^= ۲    // ۴
x++       // ۵
x--       // ۴
```

`°` (نشانه درجه، U+00B0) در اولین استفاده متغیر را به مقدار خنثی آن به‌طور خودکار مقداردهی اولیه می‌کند:

```zymbol
اعداد = [۳, ۱, ۴, ۱, ۵]
@ n:اعداد {
    °جمع += n
}
>> جمع ¶              // → 14
```

> `°متغیر` (پیشوند) بالای حلقه لنگر می‌اندازد — نتیجه پس از `@` قابل خواندن است.
> `متغیر°` (پسوند) درون حلقه لنگر می‌اندازد — با پایان حلقه می‌میرد.

دستوری که فقط یک نام است، متغیر را می‌خواند و مقدار را دور می‌ریزد، بنابراین هشدار می‌دهد:

```zymbol
شمارش = ۵
شمارش
```

کامپایلر چنین هشدار می‌دهد (پیام‌هایش همیشه انگلیسی هستند):

```text
warning: this statement does nothing: 'شمارش' is read and discarded
  = help: remove it, or use it — `>> name ¶` to print it
```

یعنی: *«این دستور هیچ کاری نمی‌کند: 'شمارش' خوانده و دور ریخته شد»*.

## انواع داده

| نوع | مقدار ثابت | برچسب `#?` | یادداشت |
|------|---------|----------|-------|
| عدد صحیح | `۴۲`, `-۷` | `###` | عدد صحیح ایمن: ±(2⁵³ − 1) |
| عدد اعشاری | `۳.۱۴`, `۱.۵e۱۰` | `##.` | IEEE-754 دوگانه |
| رشته | `"متن"` | `##"` | درون‌یابی: `"سلام {نام}"` |
| نویسه | `'A'` | `##'` | یک کد نقطه یونیکد |
| بولی | `#۱`, `#۰` | `##?` | عددی نیست — `#۱ ≠ ۱` |
| آرایه | `[۱, ۲, ۳]` | `##]` | یک نوع، بررسی‌شده |
| ترکیب اعلام‌شده | `#[۱, "دو"]` | `##[` | همان نوع `[…]`، بدون بررسی |
| چندتایی | `(a, b)` | `##)` | مکانی، تغییرناپذیر |
| فرهنگ | `#(x: ۱, y: ۲)` | `##(` | کلیددار، قابل تغییر |
| تابع | ارجاع تابع نام‌دار | `##()` | درجه یک؛ نمایش `<funct/N>` |
| لامبدا | `x -> x * ۲` | `##->` | درجه یک؛ نمایش `<lambd/N>` |
| واحد | `##_` | `##_` | عدم — null وجود ندارد |

```zymbol
>> ۴۲#? ¶               // → (###, 2, 42)
>> [۱, ۲, ۳]#? ¶        // → (##], 3, [1, 2, 3])
>> #(x: ۱)#? ¶          // → (##(, 1, #(x: 1))
```

عدد صحیحی که از محدوده ایمن خارج شود خطای قابل گرفتن است، هرگز سرریز خاموش نیست:

```zymbol
!? {
    >> (۹۰۰۷۱۹۹۲۵۴۷۴۰۹۹۱ + ۱) ¶
} :! ##Range {
    >> "خارج از محدوده" ¶ // → خارج از محدوده
}
```

`##_` روشی است که یک برنامه می‌پرسد آیا چیزی غایب است:

```zymbol
هیچ_چیز() { }
مقدار = هیچ_چیز()
>> (مقدار == ##_) ¶     // → #1
```

## خروجی و ورودی

```zymbol
نام = "علی"
جمع = ۳
>> "سلام" ¶             // → سلام
>> "a=" نام " b=" جمع ¶ // → a=علی b=3
>> جمع#? ¶            // → (###, 1, 3)
```

```zymbol
<< نام
<< "نام خود را وارد کنید: " نام
<< ###(۴) "سن: " سن
```

**به شکل دو نشانه نگاه کنید.** `>>` به بیرون اشاره می‌کند: داده را از برنامه بیرون می‌برد. `<<` به درون اشاره می‌کند: داده را به برنامه وارد می‌کند. اینجا چیزی برای حفظ کردن نیست — پیکان نشان می‌دهد اطلاعات در کدام جهت حرکت می‌کند، و همان ایده در هر نشانه‌ای که چیزی را جابه‌جا می‌کند بازمی‌گردد.

> `¶` و `\\` خطوط جدید معادل هستند. `>>` هرگز یکی اضافه نمی‌کند.
> تعیین‌کننده نوع پیش از اعلان، هنگام خواندن اعتبارسنجی می‌کند و تا معتبر شدن مقدار دوباره می‌پرسد:
> `##.` اعشاری · `##.(T,D)` دهدهی · `###(N)` صحیح · `##"(N)"` متن · `##'` یک نویسه.

در سطح بالای یک فایل، `<~` وضعیت خروج برنامه است:

```zymbol
>> "بررسی" ¶      // → بررسی
<~ ۰
```

## ابتدایی‌های TUI

عملگرهای رابط ترمینال برای برنامه‌های تعاملی. بیشترشان به بلوک `>>| { }` نیاز دارند (صفحه جایگزین + حالت خام).

```zymbol
>>| {
    >>!
    >>~ (۱, ۱, ۰, ۱۰) > "در حال اجرا"
    @~ ۱۰۰۰
    >>~ (۲, ۱) > "تمام شد."
}
```

```zymbol
>>| {
    [سطرها, ستون‌ها] = >>?
    >>~ (۱, ۱) > "ترمینال: " سطرها " x " ستون‌ها
    <<| کلید
    >>~ (۲, ۱) > "فشرده شد: " کلید
}
```

اینجا می‌توانید ببینید چرا نشانه‌ها به‌جای ضرب شدن، ترکیب می‌شوند. شما می‌دانید که `<<` ورودی است و `?` بدون تعهد می‌پرسد. فقط یک نشانه جدید است:

- `|` یک **واحد منفرد** است، نه تمام جریان.

با این، هر دو عملگر صفحه‌کلید خودشان را می‌خوانند:

```text
<<        |             ?
ورودی     یک واحد      بدون تعهد

<<|   یک کلید بگیر، و تا آمدن یکی صبر کن
<<|?  نگاه کن آیا کلیدی هست، و اگر نیست ادامه بده
```

همین در طرف دیگر: `>>` می‌فرستد، `>>!` **به‌زور** می‌فرستد (تمام صفحه را پاک می‌کند)، در حالی که `>>?` به‌جای نوشتن **می‌پرسد** (ترمینال چه اندازه است). نشانه سمت راست همان است که حالت را تغییر می‌دهد و همیشه آخر می‌آید.

> `>>!` صفحه را پاک می‌کند. `>>?` `[سطرها, ستون‌ها]` را بازمی‌گرداند. `@~ N` N میلی‌ثانیه می‌خوابد.
> `<<|` یک فشردن کلید می‌خواند (مسدودکننده)؛ `<<|?` بدون مسدود کردن نظرسنجی می‌کند (`'\0'` اگر نباشد).
> کلیدهای جهت‌دار به‌صورت `'↑' '↓' '←' '→'` رمزگشایی می‌شوند؛ ESC کد نقطه ۲۷ است.
> چندتایی خروجی موقعیت‌دار: `(سطر, ستون, BKS, جلو, عقب)` — هر شکاف با کاما قابل حذف است (`>>~ (,,, ۱۹۶) > "قرمز"`).
> ماسک BKS: `1`=ضخیم، `2`=ایتالیک، `4`=زیرخط. پالت ANSI ۲۵۶ رنگ (`0`=پیش‌فرض ترمینال).

## عملگرها

```zymbol
a = ۱۰
b = ۳
ن۱ = a + b    // ۱۳
ن۲ = a - b    // ۷
ن۳ = a * b    // ۳۰
ن۴ = a / b    // ۳  (تقسیم صحیح)
ن۵ = a % b    // ۱
ن۶ = a ^ b    // ۱۰۰۰
```

```zymbol
a = ۱۰
b = ۳
م۱ = a == b    // #۰
م۲ = a <> b    // #۱
م۳ = a < b     // #۰
م۴ = a >= b    // #۱
ط۱ = #۱ && #۰  // #۰
ط۲ = !#۱       // #۰
```

> `==` هرگز اجبار نمی‌کند: `"5" == 5` برابر `#0` است. ترتیب اجبار می‌کند: `"5" > 4` برابر `#1` است، و `"४२" > 5` هم — متن عددی در هر یک از ۶۹ خط، به‌عنوان عدد مقایسه می‌شود.
> یک تابع فقط با خودش برابر است، هرگز با تابع دیگری با همان بدنه.

## رشته‌ها

```zymbol
نام = "علی"
n = ۴۲
>> "سلام " نام " شما " n " دارید" ¶ // → سلام علی شما 42 دارید
توضیح = "سلام {نام}، شما {n} دارید"
>> توضیح ¶              // → سلام علی، شما 42 دارید
```

```zymbol
s = "سلام دنیا"
طول = s$#                  // ۹
زیررشته = s$[۱..۴]             // "سلام"
دارد = s$? "دنیا"          // #۱
بخش‌ها = "a,b,c,d"$/ ','    // [a, b, c, d]
```

> `\{` و `\}` آکولاد حرفی هستند — فرار متقارن است.

## جریان کنترل

```zymbol
x = ۷
? x > ۱۰۰ {
    >> "بزرگ" ¶
} _? x > ۰ {
    >> "مثبت" ¶     // → مثبت
} _ {
    >> "منفی" ¶
}
```

اینجا دو نشانه جدید و یک سومی است که از ترکیب آنها می‌آید:

- `?` **پرسیدن** است: یک شرط باز می‌کند.
- `_` **آنچه تعیین نشده** است: شاخه‌ای که وقتی هیچ پرسشی مطابقت ندارد باقی می‌ماند.
- `_?` هر دو پشت سر هم: *اگر هیچ چیز مطابقت نکرد، دوباره بپرس*.

به همین دلیل `_?` این‌طور نوشته می‌شود. نشانه جدیدی برای یادگیری نیست — `_` است که `?` به دنبال دارد، و دقیقاً همان چیزی را معنی می‌دهد که دو بخشش به ترتیب خوانده شده معنی می‌دهند.

> آکولادها `{ }` حتی برای یک دستور **الزامی** هستند.

## تطبیق

```zymbol
امتیاز = ۸۵
نمره = ?? امتیاز {
    ۹۰..۱۰۰ => 'A'
    ۸۰..۸۹  => 'B'
    _       => 'F'
}
>> نمره ¶              // → B
```

```zymbol
دما = -۵
وضعیت = ?? دما {
    < ۰  => "یخ"
    < ۲۰ => "سرد"
    _    => "گرم"
}
>> وضعیت ¶              // → یخ
```

شما قبلاً می‌دانید که `?` «پرسیدن» است. **`??` پرسیدن چندین بار است**: دو برابر کردن یک نشانه، در هر جای زبان، یعنی انجام چندین بار کاری که نشانه یک بار انجام می‌دهد. یک `?` یک شرط را آزمایش می‌کند؛ `??` علیه فهرستی از موارد آزمایش می‌کند.

گزینه‌ها با `||` به هم می‌پیوندند و می‌توانند انواع الگو را مخلوط کنند:

```zymbol
کلید = 'P'
عمل = ?? کلید {
    'p' || 'P' => "توقف"
    < ۰ || > ۱۰۰ => "خارج از محدوده"
    _ => "نادیده"
}
>> عمل ¶             // → توقف
```

## حلقه‌ها

```zymbol
@ i:۱..۴  { >> i " " }
>> ¶                    // → 1 2 3 4
@ i:۱..۹:۲ { >> i " " }
>> ¶                    // → 1 3 5 7 9
@ i:۵..۱:۱ { >> i " " }
>> ¶                    // → 5 4 3 2 1
```

```zymbol
n = ۱
@ n <= ۶۴ { n *= ۲ }
>> n ¶                  // → 128
```

```zymbol
میوه‌ها = ["سیب", "گلابی", "انگور"]
@ م:میوه‌ها { >> م " " }
>> ¶                    // → سیب گلابی انگور
@ ن:"سلام" { >> ن "-" }
>> ¶                    // → س-ل-ا-م-
```

```zymbol
@ i:۱..۱۰ {
    ? i % ۲ == ۰ { @> }
    ? i > ۷ { @! }
    >> i " "
}
>> ¶                    // → 1 3 5 7
```

```zymbol
شمارش = ۰
@:بیرونی {
    شمارش++
    ? شمارش >= ۳ { @:بیرونی! }
}
>> شمارش ¶             // → 3
```

`@` نشانه **زمان** است: هر چیزی که تکرار می‌شود در آن زندگی می‌کند. برای کوتاه کردن آن زمان، نشانه‌ای کنارش اضافه می‌کنید:

- `@!` — `!` **قدرت** است: همین حالا حلقه را ترک کن.
- `@>` — `>` به جلو هل می‌دهد: به دور بعد برو.
- `@:بیرونی!` — `:` **یک نام را می‌بندد**، بنابراین این حلقه *به نام* بیرونی را قطع می‌کند، نه نزدیک‌ترین را.

سه عملگر، و هیچ‌کدام به‌طور جداگانه نیاز به حفظ کردن نداشتند: آنها `@` به‌علاوه نشانه‌ای هستند که از قبل می‌گوید چه می‌کند.

> **تعیین‌کننده یک شمارش یا یک شرط است.** یک `عدد صحیح` یک شمارش است، یک بار ارزیابی می‌شود — `@ ۰` بدنه را صفر بار اجرا می‌کند. هر چیز دیگری یک شرط است. صداقت وجود ندارد: `@ []` و `@ ۳.۵` رد می‌شوند. برای پیمایش یک مجموعه از `@ x:آیتم‌ها` استفاده کنید؛ برای شمارش آن، `@ آیتم‌ها$#`.

## توابع

```zymbol
جمع(a, b) { <~ a + b }
>> جمع(۳, ۴) ¶        // → 7
```

```zymbol
فاکتوریل(n) {
    ? n <= ۱ { <~ ۱ }
    <~ n * فاکتوریل(n - ۱)
}
>> فاکتوریل(۵) ¶       // → 120
```

تابع متغیرهای فایل را با مقدار می‌خواند، و نوشتن درون، درون می‌ماند:

```zymbol
حد = ۱۰۰
درون(n) { <~ n < حد }
>> درون(۴۲) ¶         // → #1
```

دو نشانه این را تغییر می‌دهند، و هر دو **در امضا و در محل فراخوانی** نوشته می‌شوند:

```zymbol
افزایش(شمارش<~) { شمارش = شمارش + ۱ }
جمع = ۰
افزایش(جمع<~)
>> جمع ¶              // → 1
```

> `p~` یک نسخه کاری است — بدنه می‌تواند دوباره به آن اختصاص دهد و فراخوان دست‌نخورده می‌ماند.
> `p<~` یک پارامتر خروجی است — تغییر برمی‌گردد. `افزایش(جمع)` بدون نشانه یک خطای معنایی است: حاشیه‌نویسی و امضا نمی‌توانند از هم جدا شوند.

## آرایه‌ها

```zymbol
آرایه = [۱, ۲, ۳, ۴, ۵]
>> آرایه[۱] ¶       // → 1   نمایه‌گذاری از ۱ شروع می‌شود
>> آرایه[-۱] ¶      // → 5   منفی از انتها می‌شمارد
>> آرایه$# ¶        // → 5   طول
```

```zymbol
آرایه = [۱, ۲, ۳]
>> (آرایه$+ ۶) ¶          // → [1, 2, 3, 6]   افزودن
>> (آرایه$+[۲] ۹۹) ¶      // → [1, 99, 2, 3]  درج در موقعیت ۲
>> (آرایه$- ۳) ¶          // → [1, 2]         حذف اولین وقوع
>> (آرایه$-[۱]) ¶         // → [2, 3]         حذف در نمایه ۱
>> (آرایه$[۱..۲]) ¶       // → [1, 2]         برش، هر دو انتها شامل
>> (آرایه$? ۳) ¶          // → #1             شامل
```

همه با `$` شروع می‌شوند، نشانه **مجموعه**، و با نشانه‌ای ادامه می‌یابند که می‌گوید در آن چه کاری انجام می‌شود: `#` چند، `+` افزودن، `-` حذف، `?` پرسیدن آیا هست. و مانند `??`، دو برابر کردن نشانه یعنی انجام جامع آن: `$?` می‌پرسد *آیا* مقداری هست، `$??` می‌پرسد *در چند جا* و همه را بازمی‌گرداند.

```zymbol
آرایه = [۳, ۱, ۲]
>> (آرایه$^+) ¶     // → [1, 2, 3]   صعودی
>> (آرایه$^-) ¶     // → [3, 2, 1]   نزولی
```

**قاعده نتیجه.** یک عملگر، و آنچه کد اطراف با آن می‌کند تصمیم می‌گیرد: اگر استفاده شود، **می‌سازد** و اصلی را دست‌نخورده می‌گذارد؛ اگر دور ریخته شود، **تغییر می‌دهد**.

```zymbol
آرایه = [۱, ۲, ۳]
نسخه = آرایه[۲]$~ ۹۹
>> آرایه ¶                // → [1, 2, 3]
>> نسخه ¶              // → [1, 99, 3]
آرایه[۲]$~ ۹۹
>> آرایه ¶                // → [1, 99, 3]
```

> **`=` هرگز در یک مجموعه نمی‌نویسد.** `آرایه[۲] = ۹۹` یک شکل از Zymbol نیست — `=` به یک **نام** مقدار می‌دهد. تغییر بخشی از یک مجموعه `$~` است، در هر مجموعه‌ای.

`[…]` یک نوع را نگه می‌دارد و بررسی می‌شود؛ ترکیب عامدانه با `#[…]` **اعلام** می‌شود:

```zymbol
ترکیب = #[۱, "دو", #۱]
>> ترکیب ¶             // → [1, دو, #1]
>> ([۱, ۲] == #[۱, ۲]) ¶ // → #1
```

---

## نمایه‌گذاری چندبعدی

`>` در ساختار تودرتو پایین می‌رود. یک گروه براکت یک عنصر را آدرس می‌دهد، هر چقدر هم که عمیق باشد.

```zymbol
م = [[۱,۲,۳], [۴,۵,۶], [۷,۸,۹]]
>> م[۲>۳] ¶        // → 6   سطر ۲، ستون ۳
>> م[-۱>-۱] ¶      // → 9   آخرین سطر، آخرین ستون
```

```zymbol
م = [[۱,۲,۳], [۴,۵,۶], [۷,۸,۹]]
>> م[۱>۱ ; ۲>۲ ; ۳>۳] ¶          // → [1, 5, 9]          صاف: قطر
>> م[[۱>۱, ۱>۳] ; [۳>۱, ۳>۳]] ¶  // → [[1, 3], [7, 9]]   ساختاریافته: گوشه‌ها
```

```zymbol
م = [[۱,۲,۳], [۴,۵,۶]]
>> (م[۱>۲]$~ ۹۹) ¶      // → [[1, 99, 3], [4, 5, 6]]
```

> `م[۱][۲]` یک شکل از Zymbol **نیست**. نمایه زنجیره‌ای هم برای خواندن و هم برای نوشتن رد می‌شود — یک گروه براکت برای هر دسترسی، و `>` آن چیزی است که بین گام‌ها می‌رود.

## فرهنگ‌ها

چندتایی با فیلدهای نام‌دار یک فرهنگ است، و از v0.0.9 به‌صورت `#(…)` نوشته می‌شود.

```zymbol
شخص = #(نام: "علی", سن: ۲۵)
>> شخص.نام ¶        // → علی
>> شخص["سن"] ¶    // → 25
```

```zymbol
شخص = #(نام: "علی", سن: ۲۵)
فیلد = "نام"
>> شخص[فیلد] ¶     // → علی
```

قابل تغییر است، کلیدها می‌توانند اضافه شوند، و می‌توان پیمایش کرد:

```zymbol
موجودی = #(گلابی: ۴)
موجودی["سیب"]$~ ۱۰
@ k:موجودی { >> k "=" موجودی[k] " " }
>> ¶                    // → گلابی=4 سیب=10
```

```zymbol
موجودی = #(گلابی: ۴, سیب: ۱۰)
@ (k, v):موجودی { >> k ":" v " " }
>> ¶                    // → گلابی:4 سیب:10
```

> `#()` فرهنگ خالی است، که `()` نمی‌توانست باشد — باید چندتایی خالی هم می‌بود. `(x: 1)` لخت با این پیام رد می‌شود: *a dictionary is written `#(…)`* — «فرهنگ به‌صورت `#(…)` نوشته می‌شود».
> یک فرهنگ با کلید آدرس داده می‌شود، هرگز با موقعیت، بنابراین `شخص[۱]` خطاست.

## چندتایی‌ها

چندتایی‌ها محفظه‌های مرتب **تغییرناپذیر** هستند که مقادیر انواع مختلف را نگه می‌دارند.

```zymbol
نقطه = (۱۰, ۲۰)
>> نقطه[۱] ¶           // → 10
داده = (۴۲, "سلام", #۱, ۳.۱۴)
>> داده[۳] ¶            // → #1
```

```zymbol
t = (۱۰, ۲۰, ۳۰)
t2 = t[۲]$~ ۹۹۹
>> t ¶                  // → (10, 20, 30)
>> t2 ¶                 // → (10, 999, 30)
```

> هر تلاشی برای تغییر یک چندتایی در جای خود خطاست، هر چه عملگر باشد — تغییرناپذیری خاصیت مقدار است، نه استثنایی درون هر `$`.

## ساختارشکنی

```zymbol
آرایه = [۱۰, ۲۰, ۳۰, ۴۰, ۵۰]
[a, b, c] = آرایه
>> a " " b " " c ¶      // → 10 20 [30, 40, 50]
```

```zymbol
آرایه = [۱۰, ۲۰, ۳۰, ۴۰, ۵۰]
[اول, *باقی] = آرایه
>> اول ¶            // → 10
>> باقی ¶              // → [20, 30, 40, 50]
```

```zymbol
نقطه = (۱۰۰, ۲۰۰)
(px, py) = نقطه
>> px " " py ¶          // → 100 200
```

```zymbol
شخص = #(نام: "زهرا", سن: ۲۵)
#(نام: n, سن: s) = شخص
>> n " " s ¶            // → زهرا 25
```

> شکل براکت نوع‌دار است: `[…]` آرایه می‌گیرد، `(…)` چندتایی، `#(…)` فرهنگ. نام آخر **باقی را جذب می‌کند**، بنابراین ساختارشکنی هرگز در طول شکست نمی‌خورد — `(a, b, c) = (1,2,3,4,5)` نتیجه می‌دهد `c = (3,4,5)`، و `##_` وقتی چیزی نمانده است.

## توابع درجه بالاتر

```zymbol
اعداد = [۱, ۲, ۳, ۴, ۵]
>> (اعداد$> (x -> x * ۲)) ¶ // → [2, 4, 6, 8, 10]
>> (اعداد$| (x -> x % ۲ == ۰)) ¶ // → [2, 4]
>> (اعداد$< (۰, (تجمع, x) -> تجمع + x)) ¶ // → 15
```

```zymbol
اعداد = [۱, ۲, ۳, ۴, ۵, ۶]
دو_برابر(x) { <~ x * ۲ }
بزرگ(x) { <~ x > ۳ }
>> (اعداد$> دو_برابر) ¶    // → [2, 4, 6, 8, 10, 12]
>> (اعداد$| بزرگ) ¶    // → [4, 5, 6]
```

```zymbol
پایه = [#(نام: "کارلا", سن: ۲۸), #(نام: "زهرا", سن: ۲۵)]
بر_اساس_سن = پایه$^ (a, b -> a.سن < b.سن)
>> بر_اساس_سن[۱].نام ¶     // → زهرا
```

> یک تابع نام‌دار به HOF **بدون پرانتز** می‌رود: `اعداد$> دو_برابر`. نوشتن `اعداد$> (دو_برابر)` خطای تجزیه است، زیرا `(` یک لامبدا باز می‌کند.

## مدیریت خطا

```zymbol
!? {
    x = ۱۰ / ۰
} :! ##Div {
    >> "تقسیم بر صفر" ¶  // → تقسیم بر صفر
} :! {
    >> "دیگر: " _err ¶
} :> {
    >> "همیشه اجرا می‌شود" ¶        // → همیشه اجرا می‌شود
}
```

| نوع | چه وقت |
|------|--------|
| `##Div` | تقسیم بر صفر |
| `##Index` | نمایه خارج از محدوده |
| `##Key` | کلید در فرهنگ نیست |
| `##Range` | خارج از محدوده صحیح ایمن |
| `##Type` | عدم تطابق نوع |
| `##Parse` | تجزیه داده |
| `##IO` | فایل / سیستم |
| `##Network` | خطاهای شبکه |
| `##DB` | پایگاه داده |
| `##Time` | تاریخی که وجود ندارد |
| `##_` | هر خطایی (همه‌گیر) |

`!` نشانه **خطا و قدرت** است، و در هر دو خانواده یکسان خوانده می‌شود: `$!` از یک مقدار می‌پرسد آیا خطاست؛ `$!!`، با نشانه دو برابر، بدون پرسیدن آن را به بالا منتشر می‌کند.

> شکست‌های کتابخانه استاندارد به‌عنوان **مقادیر خطای نرم** بازمی‌گردند که با `$!` آزمایش می‌کنید یا با `!?` می‌گیرید، به‌جای اینکه لغو کنید. `$!!` یکی را به فراخوان منتشر می‌کند.

## ماژول‌ها

```zymbol
# ماشین_حساب {
    #> { جمع, PI }

    PI := ۳.۱۴۱۵۹
    جمع(a, b) { <~ a + b }
}
```

```zymbol
<# ./ماشین_حساب => م

>> م::جمع(۵, ۳) ¶
>> م.PI ¶
```

```zymbol
# کتابخانه_من {
    #> { جمع_داخلی => مجموع }

    جمع_داخلی(a, b) { <~ a + b }
}
```

دو نشانه ماژول همان ایده هستند، اکنون روی فایل‌ها اعمال می‌شوند: `#` سطح **اعلان** است — اینکه یک چیز *چیست*، نه مقدارش — و پیکان می‌گوید کد در کدام جهت می‌رود:

```text
<#   پیکان وارد می‌شود: وارد کردن، آوردن از فایل دیگر
#>   پیکان خارج می‌شود: صادر کردن، ارائه به فایل‌های دیگر
```

نشانه جهت همیشه در لبه‌ای می‌نشیند که به سمتی که اشاره می‌کند رو دارد. همین دلیل است که `<~` به چپ بازمی‌گردد (بیرون از تابع) و `->` به راست وارد می‌شود (به بدنه لامبدا).

> **ماژول آنچه صادر می‌کند را اعلام می‌کند.** بلوک `#>` الزامی است — حذف آن **E014** است، و `#> { }` روشی است که ماژول می‌گوید سطحش خالی است. `::` تابعی را فراخوانی می‌کند، `.` ثابتی را می‌خواند. فقط واردات، بلوک صادرات، مقداردهی اولیه حرفی و تعاریف تابع می‌توانند در بدنه ماژول ظاهر شوند؛ هر چیز قابل اجرا **E013** است.

## کتابخانه استاندارد

ماژول‌های بومی، مانند هر دیگری وارد می‌شوند:

| ماژول | توابع |
|--------|-----------|
| `std/math` | `sqrt exp ln log pow abs ceil floor round min max sin cos tan asin acos atan atan2 sinh cosh tanh sigmoid` · `PI` `E` |
| `std/random` | `entero rango peso_f64` |
| `std/json` | `decode decode_map encode` |
| `std/io` | `read write append exists delete list mkdir` |
| `std/net` | `get post post_json head` |
| `std/db` | `connect exec query query_one tx commit rollback` … |
| `std/term` | `width pad_left pad_right center truncate` |
| `std/time` | `now today parts of format add diff` |

```zymbol
<# std/math => m

>> m::sqrt(۱۶.۰) ¶      // → 4
>> m.PI ¶               // → 3.141592653589793
```

```zymbol
<# std/term => t

>> t::width("手番") ¶            // → 4   دو گلیف، چهار ستون
>> "|" t::center("go", 8) "|" ¶ // → |   go   |
```

```zymbol
<# std/time => T

روز = T::of(۲۰۲۶, ۱, ۳۱)
>> T::format(روز, "%Y-%m-%d") ¶ // → 2026-01-31
>> T::format(T::add(روز, ۱, "month"), "%Y-%m-%d") ¶ // → 2026-02-28
```

> `std/term` **ستون‌های نمایش** را اندازه می‌گیرد، نه نویسه‌ها: CJK و بیشتر ایموجی‌ها ۲ ستون هستند، بنابراین جدول را با `t::width` بچینید، هرگز با `$#`.
> در `std/time` یک لحظه میلی‌ثانیه از مبدأ است. کمتر از یک روز مدت است، از یک روز به بالا تقویم است — بنابراین یک ماه در همان روز ماه می‌افتد، گیره‌خورده. `تفاوت(a, b)` برابر `a - b` است، بنابراین لحظه زودتر ابتدا پاسخ منفی می‌دهد.

## بسته‌ها

یک `.zyp` یک برنامه چندفایلی را در یک فایل قابل حمل بسته‌بندی می‌کند. این بایگانی **متن** است، نه باینری، بنابراین هر جا که باینری `zymbol` اجرا شود اجرا می‌شود.

```bash
zymbol package پروژه_من/ --script main.zy -o پروژه_من.zyp
zymbol run پروژه_من.zyp
```

> بایگانی یک مانیفست (`zyp.toml`) دارد که اسکریپت‌های ورودی و نسخه موتور مورد نیازش را اعلام می‌کند. `zymbol run` آن را به یک پوشه موقت استخراج می‌کند و از آنجا اجرا می‌کند، بنابراین کد یک‌بارمصرف است در حالی که آنچه اسکریپت می‌نویسد در پوشه کار واقعی شما می‌افتد. زمین بازی هم فایل‌های `.zyp` را بارگیری می‌کند.

## حالت‌های عددی

Zymbol می‌تواند اعداد را در **۶۹ خط رقم یونیکد** بنویسد — دیواناگری، عربی-هندی، تایلندی، کلینگون pIqaD، ضخیم ریاضی، بخش‌های LCD و بیشتر. حالت برای فرآیند جهانی است و بر خروجی تأثیر می‌گذارد؛ حساب تغییر نمی‌کند.

```zymbol
#०९#    // دیواناگری   (U+0966–U+096F)
#٠٩#    // عربی-هندی (U+0660–U+0669)
#๐๙#    // تایلندی     (U+0E50–U+0E59)
#09#    // بازنشانی به ASCII
```

```zymbol
x = ۴۲
>> x ¶                  // → 42
#٠٩#
>> x ¶                  // → ٤٢
>> ۳.۱۴ ¶               // → ٣٫١٤
>> #۱ ¶                 // → #١
#09#
```

ارقام هر خط پشتیبانی‌شده، مقادیر ثابت معتبری در متن هستند:

```zymbol
#٠٩#
@ i:۱..۵ { >> i " " }
>> ¶                    // → ١ ٢ ٣ ٤ ٥
#09#
```

خواندن متقارن است — یک رقم در هر خطی فهمیده می‌شود:

```zymbol
>> #|"४२"| ¶            // → 42
>> #|'७'| ¶             // → 7
```

> `#` همیشه ASCII است، بنابراین `#0` در هر خط از رقم صفر بصری متمایز می‌ماند.
> `#,` و `#^` هم ارقام خود را در خط فعال می‌نویسند، و جداکننده‌ها از آن پیروی می‌کنند — اما جفت هرگز معکوس نمی‌شود: `,` گروه‌بندی می‌کند و `.` تقسیم می‌کند، در هر خط.

## عملگرهای داده

```zymbol
f = ##.۴۲         // به اعشاری
i = ###۳.۷        // به صحیح، گردشده  → 4
t = ##!۳.۷        // به صحیح، بریده  → 3
>> f " " i " " t ¶      // → 42 4 3
>> f#? ¶                // → (##., 2, 42)
```

> یک اعشاری به‌صورت ارقام چاپ می‌شود، هرگز به‌صورت نمایی، و `.0` انتهایی را حذف می‌کند — `##.42` `42` می‌نویسد و هنوز اعشاری است، همان‌طور که `f#?` نشان می‌دهد.

```zymbol
>> #|"42"| ¶       // → 42
>> #|"abc"| ¶      // → abc   ایمن: ورودی را بدون تغییر بازمی‌گرداند
>> ##!'A' ¶        // → 65    کد نقطه یک نویسه
```

```zymbol
pi = ۳.۱۴۱۵۹۲۶۵
>> #.۲|pi| ¶       // → 3.14          گرد کردن به ۲ رقم اعشار
>> #!۲|pi| ¶       // → 3.14          بریدن به ۲ رقم اعشار
>> #,|۱۲۳۴۵۶۷| ¶   // → 1,234,567     جداکننده هزارگان
>> #^|۱۲۳۴۵.۶۷۸| ¶ // → 1.2345678e4   نماد علمی
```

```zymbol
>> 0x41 ¶        // → A   شانزده‌شانزدهی
>> 0b01000001 ¶  // → A   دودویی
>> 0o101 ¶       // → A   هشت‌هشتی
>> 0d65 ¶        // → A   ده‌دهی
```

> یک مقدار پایه در محدوده ASCII یک **نویسه** است: `0d65 == 'A'` برابر `#1`، و `0d65 == 65` برابر `#0`. هر چهار پایه همان نویسه را هجی می‌کنند.

## مثال کامل: FizzBuzz

```zymbol
طبقه‌بندی(عدد) {
    ? عدد % ۱۵ == ۰ { <~ "FizzBuzz" }
    _? عدد % ۳  == ۰ { <~ "Fizz" }
    _? عدد % ۵  == ۰ { <~ "Buzz" }
    <~ عدد
}

@ i:۱..۲۰ { >> طبقه‌بندی(i) ¶ }
// → 1 · 2 · Fizz · 4 · Buzz · Fizz · 7 · 8 · Fizz · Buzz · 11 · Fizz · 13 · 14 ·
//   FizzBuzz · 16 · 17 · Fizz · 19 · Buzz   (یکی در هر خط)
```

## چگونه نشانه‌ها ترکیب می‌شوند

شما در سراسر این راهنما یک چیز را دیده‌اید: **یک عملگر یک نقاشی برای حفظ کردن نیست، چندین نشانه پشت سر هم است، و هر کدام معنای خود را می‌افزاید.** حالا که همه را می‌شناسید، این الگوی کامل است.

ابتدا **در کدام دنیا هستیم** می‌آید:

| نشانه | دنیا | آن را دیدید در |
|--------|-------|----------------|
| `$` | یک مجموعه | `$#` `$+` `$?` `$^-` |
| `@` | زمان، هر چیزی که تکرار می‌شود | `@!` `@>` `@~` |
| `#` | اینکه یک چیز *چیست*، نه مقدارش | `#?` `#(…)` `<#` `#>` |
| `>>` | بیرون از برنامه | `>>` `>>!` `>>?` |
| `<<` | درون برنامه | `<<` `<<\|` `<<\|?` |
| `?` | پرسیدن، بدون تعهد | `?` `_?` `??` `$?` |
| `!` | زور، یا خطا | `@!` `$!` `!?` |

سپس **آنچه آنجا انجام می‌شود** می‌آید: `+` افزودن، `-` حذف، `^` ترتیب، `~` تغییر، `#` شمارش، `|` یک واحد، `:` بستن نام.

و دو قاعده که هرگز شکست نمی‌خورند:

**دو برابر کردن یک نشانه آن را جامع می‌کند.** `?` یک بار می‌پرسد، `??` چندین مورد را آزمایش می‌کند. `$?` می‌پرسد آیا مقداری هست، `$??` هر جایی که هست را بازمی‌گرداند. `!` خطایی را علامت می‌زند، `!!` بدون پرسیدن آن را منتشر می‌کند.

**نشانه حالت همیشه آخر می‌آید.** وقتی `?` یا `!` ظاهر می‌شوند تا بگویند چیزی *چگونه* انجام می‌شود — با تردید یا با زور — آنها آخرین نشانه عملگر هستند: `$??`، `$!!`، `<<|?`، `@!`، `##!`، `>>!`، `>>?`، `@:بیرونی!`. هرگز عملیاتی بعد از آنها نیست.

از این یک چیز عملی بیرون می‌آید: **ترکیبی که هرگز ندیده‌اید، پیش از آنکه دنبالش بگردید معنا دارد.** اگر `$` مجموعه و `^` ترتیب و `-` معکوس باشد، آنگاه `$^-` نزولی مرتب می‌کند، و هیچ‌کس مجبور نبود به شما بگوید.

تمام فهرست این‌طور کار نمی‌کند، و گفتنش بهتر از تظاهر کردن است. بیشتر عملگرها به‌طور تمیز از هم جدا می‌شوند. شش تا جدا می‌شوند اما بیشتر از اجزایشان معنا دارند: `!?` `:!` `:>` `|>` `::` `$++`. و ده تا باید حفظ شوند چون اصلاً جدا نمی‌شوند: `¶` `><` `#1` `#0` `0x` `0b` `0o` `0d` `###` `°`.

> شمردن آن‌های مات به‌جای فرض کردن اینکه کم هستند عمدی است: آنها هزینه واقعی حفظ زبان هستند. مرجع کامل — فهرست، هم‌نگارهای اعلام‌شده، و قواعدی که یک عملگر جدید برای وجود باید برآورده کند — در `SYMBOLS.md`، در مخزن مفسر است.

## مرجع نشانه‌ها

| نشانه | عملیات | نشانه | عملیات |
|--------|-----------|--------|-----------|
| `=` | متغیر | `$#` | طول |
| `:=` | ثابت | `$+` | افزودن |
| `>>` | خروجی | `$+[i]` | درج در نمایه (۱-پایه) |
| `<<` | ورودی | `$-` | حذف اولین با مقدار |
| `¶` / `\\` | خط جدید | `$--` | حذف همه با مقدار |
| `?` | اگر | `$-[i]` | حذف در نمایه (۱-پایه) |
| `_?` | وگرنه-اگر | `$-[i..j]` | حذف محدوده (۱-پایه) |
| `_` | وگرنه / نویسه جانشین | `$?` | شامل |
| `??` | تطبیق | `$??` | یافتن همه نمایه‌ها (۱-پایه) |
| `\|\|` | الگوی یا در شاخه تطبیق | `$[s..e]` | برش (۱-پایه) |
| `@` | حلقه | `$>` | نقشه |
| `@ N { }` | حلقه N بار | `$\|` | صافی |
| `@!` | شکستن | `$<` | کاهش |
| `@>` | ادامه | `$/ جداکننده` | تقسیم رشته |
| `@:نام { }` | حلقه برچسب‌دار | `$++ a b c` | ساختن با پیوند |
| `@:نام!` | شکستن برچسب | `$~~[p:r]` | جایگزینی رشته |
| `@:نام>` | ادامه برچسب | `$*` | تکرار رشته |
| `->` | لامبدا | `آرایه[i]$~ v` | تنها شکل به‌روزرسانی |
| `<~` | بازگشت / پارامتر خروجی | `~` | پارامتر نسخه کاری |
| `آرایه[i>j]` | نمایه ناوبری | `آرایه[p ; q]` | استخراج صاف |
| `$^+` | مرتب‌سازی صعودی | `$^-` | مرتب‌سازی نزولی |
| `$^` | مرتب‌سازی با مقایسه‌گر | `\|>` | لوله |
| `!?` | امتحان | `:!` | گرفتن |
| `:>` | در نهایت | `$!` | خطاست |
| `$!!` | انتشار خطا | `#1` / `#0` | درست / غلط |
| `##_` | واحد — عدم | `[…]` | آرایه، یک نوع |
| `#[…]` | آرایه، ترکیب اعلام‌شده | `#(…)` | فرهنگ |
| `(…)` | چندتایی مکانی | `#()` | فرهنگ خالی |
| `<#` | وارد کردن | `#>` | صادر کردن |
| `#` | اعلام ماژول | `::` | فراخوانی ماژول |
| `.` | دسترسی به فیلد / ثابت | `#?` | فراداده نوع |
| `#\|..\|` | تجزیه عدد | `##.` | تبدیل به اعشاری |
| `###` | تبدیل به صحیح (گرد) | `##!` | تبدیل به صحیح (برش) |
| `#.N\|..\|` | گرد کردن | `#!N\|..\|` | بریدن |
| `#,\|..\|` | جداکننده هزارگان | `#^\|..\|` | علمی |
| `#d0d9#` | تغییر حالت عددی | `#09#` | بازنشانی به ASCII |
| `<\ ..\>` | اجرای شل | `><` | آرگومان‌های CLI |
| `\ var` | نابودی متغیر | `°x` / `x°` | تعریف داغ |
| `>>\|` | بلوک TUI (صفحه جایگزین) | `>>~` | خروجی موقعیت‌دار |
| `>>!` | پاک کردن صفحه | `>>?` | پرسش اندازه ترمینال |
| `<<\|` | فشردن کلید مسدودکننده | `<<\|?` | فشردن کلید غیرمسدودکننده |
| `@~ N` | خواب N میلی‌ثانیه | `0d` `0x` `0o` `0b` | مقادیر پایه |

## گزارش تغییرات نسخه

### v0.0.9 — مجموعه‌ها تصمیم گرفتند _(سپتامبر ۲۰۲۶)_

- **شکستن** فرهنگ نماد خودش را دارد: `#(کلید: مقدار)`. `(x: 1)` لخت رد می‌شود، و `#()` فرهنگ خالی است — که `()` هرگز نمی‌توانست باشد
- **شکستن** تخصیص نمایه‌دار برداشته شد: `آرایه[i] = v` و همه شکل‌های مرکب. `=` به یک **نام** مقدار می‌دهد؛ تغییر بخشی از مجموعه `$~` است
- **شکستن** نمایه زنجیره‌ای `m[i][j]` هم برای خواندن و هم برای نوشتن رد می‌شود — `>` بین گام‌ها می‌رود
- **شکستن** ماژول باید آنچه صادر می‌کند را اعلام کند (**E014**)؛ `#> { }` روشی است که ماژول می‌گوید سطحش خالی است
- **شکستن** تعیین‌کننده حلقه یک شمارش یا شرط است — صداقت ندارد. `@ []` و `@ 3.5` رد می‌شوند
- **افزوده** `##_` — مقدار ثابت واحد، و روشی که برنامه می‌پرسد آیا چیزی غایب است
- **افزوده** `#[…]` — آرایه‌ای که ترکیب انواع عناصر آن اعلام شده
- **افزوده** `#?` چهار مجموعه را از هم تشخیص می‌دهد: `##]` `##[` `##)` `##(`
- **افزوده** `std/time` — ساعت و تقویم مدنی، با مناطق و حساب تقویمی
- **افزوده** `<~>` در سطح بالا وضعیت خروج برنامه است
- **افزوده** `@ (k, v):جفت‌ها` — الگو در سر حلقه
- **افزوده** `#|c|` رقمی در هر یک از ۶۹ خط می‌خواند؛ `#,` و `#^` در خط فعال می‌نویسند
- **تغییر** `عدد صحیح` یک عدد صحیح ایمن است، ±(2⁵³ − 1)، بسته-در-شکست در هر موتور
- **تغییر** تابع نام‌دار متغیرهای فایل را در زمان فراخوانی، با مقدار می‌خواند
- **تغییر** دستوری که فقط یک نام می‌خواند هشدار می‌دهد به‌جای عبور خاموش
- **موتورها** ۶۶۰ از ۶۶۶ فایل پیکره در سه موتور توافق دارند، ۰ واگرا

### v0.0.8 — آزادسازی خودکار، `std/term` و بسته‌ها _(اوت ۲۰۲۶)_

- **افزوده** نابودی خودکار در آخرین استفاده — نامرئی؛ فقط اوج حافظه را پایین می‌آورد

- **افزوده** `##!` روی `نویسه` — کد نقطه یونیکد آن
- **افزوده** الگوهای یا در تطبیق: `'p' || 'P' => …`، گزینه‌های هر نوع در یک شاخه
- **افزوده** بسته‌های Zymbol (`.zyp`) — `zymbol package` / `zymbol run pkg.zyp`
- **افزوده** `<~>` در محل فراخوانی الزامی است جایی که فراخوانی‌شده پارامتر خروجی اعلام می‌کند
- **رفع** برابری سیستم ماژول در VM ث暫
