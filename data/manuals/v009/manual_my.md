# Zymbol-Lang လမ်းညွှန်

> **v0.0.9 အတွက် ပြန်လည်စစ်ဆေးပြီး — 2026-09-07**

**Zymbol-Lang** သည် သင်္ကေတပရိုဂရမ်မင်းဘာသာစကားတစ်ခုဖြစ်သည်။ ၎င်း၏ သဒ္ဒါတွင် စကားလုံးများမရှိပါ — တည်ဆောက်မှုတိုင်းသည် အမှတ်အသားတစ်ခုဖြစ်သည်။ မည်သည့်လူ့ဘာသာစကားတွင်မဆို တူညီစွာအလုပ်လုပ်သည်။

- `if`၊ `while`၊ `return` မရှိ — ကေလ `?`၊ `@`၊ `<~` သာလျှင်
- အပြည့်အစုံ ယူနီကုဒ် — မည်သည့်ဘာသာစကား သို့မဟုတ် အီမိုဂျီတွင်မဆို အမည်များ

## ကိန်းရှင်များနှင့် ကိန်းသေများ

```zymbol
ကိန်းရှင် = ၁၀              // ပြောင်းလဲနိုင်သော ကိန်းရှင်
PI := ၃.၁၄၁၅၉       // ကိန်းသေ — ပြန်လည်သတ်မှတ်ခြင်းသည် runtime အမှားဖြစ်သည်
အမည် = "အောင်မြင့်"
တက်ကြွ = #၁         // ဘူလီယန် မှန်သည်
👋 := "မင်္ဂလာပါ"
```

```zymbol
ကိန်းရှင် = ၁၀    // ၁၀
ကိန်းရှင် += ၅    // ၁၅
ကိန်းရှင် -= ၃    // ၁၂
ကိန်းရှင် *= ၂    // ၂၄
ကိန်းရှင် /= ၃    // ၈
ကိန်းရှင် %= ၃    // ၂
ကိန်းရှင် ^= ၂    // ၄
ကိန်းရှင်++       // ၅
ကိန်းရှင်--       // ၄
```

`°` (ဒီဂရီအမှတ်အသား၊ U+00B0) သည် ပထမအကြိမ်အသုံးပြုချိန်တွင် ကိန်းရှင်ကို ၎င်း၏ကြားနေတန်ဖိုးသို့ အလိုအလျောက်စတင်ပေးသည်:

```zymbol
နံပါတ်များ = [၃, ၁, ၄, ၁, ၅]
@ n:နံပါတ်များ {
    °စုစုပေါင်း += n
}
>> စုစုပေါင်း ¶              // → 14
```

> `°ကိန်းရှင်` (ရှေ့ဆက်) သည် ကွင်းအပေါ်တွင် ကျောက်ချသည် — ရလဒ်ကို `@` ပြီးနောက် ဖတ်နိုင်သည်။
> `ကိန်းရှင်°` (နောက်ဆက်) သည် ကွင်းအတွင်းတွင် ကျောက်ချသည် — ကွင်းပြီးဆုံးသောအခါ သေဆုံးသည်။

အမည်သာဖြစ်သော ထုတ်ပြန်ချက်သည် ကိန်းရှင်ကိုဖတ်ပြီး တန်ဖိုးကိုစွန့်ပစ်သည်၊ ထို့ကြောင့် သတိပေးသည်:

```zymbol
အရေအတွက် = ၅
အရေအတွက်
```

ကွန်ပိုင်လာသည် ဤသို့ သတိပေးသည် (၎င်း၏စာများသည် အမြဲတမ်း အင်္ဂလိပ်လိုဖြစ်သည်):

```text
warning: this statement does nothing: 'အရေအတွက်' is read and discarded
  = help: remove it, or use it — `>> name ¶` to print it
```

ဆိုလိုသည်မှာ: *«ဤထုတ်ပြန်ချက်သည် ဘာမှမလုပ်ပါ: 'အရေအတွက်' ကိုဖတ်ပြီး စွန့်ပစ်လိုက်သည်»*။

## ဒေတာအမျိုးအစားများ

| အမျိုးအစား | စာလုံး | `#?` တံဆိပ် | မှတ်ချက် |
|------|---------|----------|-------|
| ကိန်းပြည့် | `၄၂`, `-၇` | `###` | လုံခြုံသော ကိန်းပြည့်: ±(2⁵³ − 1) |
| ဒသမ | `၃.၁၄`, `၁.၅e၁၀` | `##.` | IEEE-754 နှစ်ထပ် |
| စာလုံးအစု | `"စာသား"` | `##"` | ထည့်သွင်းခြင်း: `"မင်္ဂလာ {အမည်}"` |
| အက္ခရာ | `'A'` | `##'` | ယူနီကုဒ် ကုဒ်အမှတ်တစ်ခု |
| ဘူလီယန် | `#၁`, `#၀` | `##?` | ကိန်းဂဏန်းမဟုတ် — `#၁ ≠ ၁` |
| ခင်းကျင်း | `[၁, ၂, ၃]` | `##]` | အမျိုးအစားတစ်ခု၊ စစ်ဆေးပြီး |
| ကြေညာထားသော ရောနှော | `#[၁, "နှစ်"]` | `##[` | `[…]` နှင့်တူသောအမျိုးအစား၊ စစ်ဆေးမထား |
| တူပယ် | `(a, b)` | `##)` | အနေအထားအလိုက်၊ မပြောင်းလဲနိုင် |
| အဘိဓာန် | `#(x: ၁, y: ၂)` | `##(` | သော့ဖြင့်၊ ပြောင်းလဲနိုင် |
| လုပ်ဆောင်ချက် | အမည်ရှိလုပ်ဆောင်ချက်ရည်ညွှန်း | `##()` | ပထမတန်းစား; ပြသည် `<funct/N>` |
| လမ်းဘဒါ | `x -> x * ၂` | `##->` | ပထမတန်းစား; ပြသည် `<lambd/N>` |
| ယူနစ် | `##_` | `##_` | မရှိခြင်း — null မရှိ |

```zymbol
>> ၄၂#? ¶               // → (###, 2, 42)
>> [၁, ၂, ၃]#? ¶        // → (##], 3, [1, 2, 3])
>> #(x: ၁)#? ¶          // → (##(, 1, #(x: 1))
```

လုံခြုံသောအပိုင်းအခြားမှ ထွက်သွားသော ကိန်းပြည့်သည် ဖမ်းနိုင်သောအမှားဖြစ်သည်၊ ဘယ်တော့မှ တိတ်ဆိတ်စွာလုံးထွေးခြင်းမဟုတ်:

```zymbol
!? {
    >> (၉၀၀၇၁၉၉၂၅၄၇၄၀၉၉၁ + ၁) ¶
} :! ##Range {
    >> "အပိုင်းအခြားပြင်ပ" ¶ // → အပိုင်းအခြားပြင်ပ
}
```

`##_` သည် ပရိုဂရမ်တစ်ခုက တစ်စုံတစ်ခုမရှိကြောင်း မေးသည့်နည်းလမ်းဖြစ်သည်:

```zymbol
ဘာမှမရှိ() { }
တန်ဖိုး = ဘာမှမရှိ()
>> (တန်ဖိုး == ##_) ¶     // → #1
```

## အထွက်နှင့် အဝင်

```zymbol
အမည် = "အောင်မြင့်"
စုစုပေါင်း = ၃
>> "မင်္ဂလာပါ" ¶             // → မင်္ဂလာပါ
>> "a=" အမည် " b=" စုစုပေါင်း ¶ // → a=အောင်မြင့် b=3
>> စုစုပေါင်း#? ¶            // → (###, 1, 3)
```

```zymbol
<< အမည်
<< "သင့်အမည်ထည့်ပါ: " အမည်
<< ###(၄) "အသက်: " အသက်
```

**အမှတ်အသားနှစ်ခု၏ ပုံသဏ္ဌာန်ကိုကြည့်ပါ။** `>>` သည် အပြင်ဘက်သို့ညွှန်သည်: ဒေတာကို ပရိုဂရမ်မှ အပြင်သို့ထုတ်ယူသည်။ `<<` သည် အတွင်းဘက်သို့ညွှန်သည်: ဒေတာကို ပရိုဂရမ်ထဲသို့ ယူလာသည်။ ဤနေရာတွင် မှတ်ရန်ဘာမှမရှိပါ — မြှားသည် သတင်းအချက်အလက် မည်သည့်လမ်းကြောင်းသွားသည်ကို ပြသည်၊ ထိုအယူအဆသည် တစ်စုံတစ်ခုကို ရွှေ့သည့် အမှတ်အသားတိုင်းတွင် ပြန်လည်ပေါ်လာသည်။

> `¶` နှင့် `\\` သည် ညီမျှသော လိုင်းအသစ်များဖြစ်သည်။ `>>` သည် ဘယ်တော့မှ တစ်ခုမထည့်ပါ။
> Prompt ရှေ့ရှိ အမျိုးအစားသတ်မှတ်ချက်သည် ဖတ်စဉ်စစ်ဆေးပြီး တန်ဖိုးမှန်သည်အထိ ထပ်မံမေးသည်:
> `##.` ဒသမ · `##.(T,D)` ဒသမ · `###(N)` ကိန်းပြည့် · `##"(N)"` စာသား · `##'` အက္ခရာတစ်ခု။

ဖိုင်တစ်ခု၏ အထွတ်အထိပ်အဆင့်တွင် `<~>` သည် ပရိုဂရမ်၏ ထွက်ပေါက်အခြေအနေဖြစ်သည်:

```zymbol
>> "စစ်ဆေးနေသည်" ¶      // → စစ်ဆေးနေသည်
<~ ၀
```

## TUI အခြေခံအရာများ

အပြန်အလှန်ဆက်သွယ်သော ပရိုဂရမ်များအတွက် Terminal UI လုပ်ဆောင်ချက်များ။ အများစုသည် `>>| { }` ဘလောက်လိုအပ်သည် (အစားထိုးမျက်နှာပြင် + အကြမ်းမုဒ်)။

```zymbol
>>| {
    >>!
    >>~ (၁, ၁, ၀, ၁၀) > "အလုပ်လုပ်နေသည်"
    @~ ၁၀၀၀
    >>~ (၂, ၁) > "ပြီးပါပြီ။"
}
```

```zymbol
>>| {
    [လိုင်းများ, ကော်လံများ] = >>?
    >>~ (၁, ၁) > "Terminal: " လိုင်းများ " x " ကော်လံများ
    <<| ခလုတ်
    >>~ (၂, ၁) > "နှိပ်လိုက်သည်: " ခလုတ်
}
```

ဤနေရာတွင် အမှတ်အသားများ မည်သည့်အတွက် မြှောက်ခြင်းအစား ပေါင်းစည်းသည်ကို သင်မြင်နိုင်သည်။ `<<` သည် အထွက်ဖြစ်ပြီး `?` သည် ကတိမပြုဘဲမေးသည်ကို သင်သိပြီးဖြစ်သည်။ အမှတ်အသားတစ်ခုသာ အသစ်ဖြစ်သည်:

- `|` သည် **ယူနစ်တစ်ခု** ဖြစ်သည်၊ စီးကြောင်းတစ်ခုလုံးမဟုတ်။

ထိုဖြင့် ကီးဘုတ်လုပ်ဆောင်ချက်နှစ်ခုလုံး မိမိတို့ကိုယ်တိုင် ဖတ်နိုင်သည်:

```text
<<        |             ?
အထွက်     ယူနစ်တစ်ခု    ကတိမပြုဘဲ

<<|   ခလုတ်တစ်ခုယူပြီး တစ်ခုရောက်သည်အထိ စောင့်ပါ
<<|?  ခလုတ်ရှိမရှိကြည့်ပြီး မရှိလျှင် ဆက်လုပ်ပါ
```

အခြားတစ်ဖက်တွင်လည်း အလားတူပင်: `>>` ပေးပို့သည်၊ `>>!` သည် **အင်အားဖြင့်** ပေးပို့သည် (မျက်နှာပြင်တစ်ခုလုံးရှင်းလင်းသည်)၊ သို့သော် `>>?` သည် ရေးခြင်းအစား **မေးသည်** (terminal မည်မျှကြီးသည်)။ ညာဘက်ရှိ အမှတ်အသားသည် မုဒ်ကိုပြောင်းသည့်အရာဖြစ်ပြီး ၎င်းသည် အမြဲတမ်း နောက်ဆုံးတွင်လာသည်။

> `>>!` မျက်နှာပြင်ကို ရှင်းလင်းသည်။ `>>?` သည် `[လိုင်းများ, ကော်လံများ]` ပြန်ပေးသည်။ `@~ N` သည် N မီလီစက္ကန့် အိပ်သည်။
> `<<|` သည် ခလုတ်တစ်ခုနှိပ်ခြင်းကို ဖတ်သည် (ပိတ်ဆို့သည်); `<<|?` သည် ပိတ်ဆို့ခြင်းမရှိဘဲ စစ်ဆေးသည် (`'\0'` မရှိလျှင်)။
> မြှားခလုတ်များသည် `'↑' '↓' '←' '→'` အဖြစ် decode လုပ်ပြီးလာသည်; ESC သည် ကုဒ်အမှတ် 27 ဖြစ်သည်။
> တည်နေရာအထွက် တူပယ်: `(လိုင်း, ကော်လံ, BKS, ရှေ့, နောက်)` — မည်သည့်အပေါက်ကိုမဆို ကော်မာဖြင့်ချန်လှပ်နိုင်သည် (`>>~ (,,, ၁၉၆) > "အနီ"`)။
> BKS ဘစ်မတ်စ်: `1`=ထူ၊ `2`=စောင်း၊ `4`=အောက်မျဉ်း။ ANSI 256 အရောင် palette (`0`=terminal မူရင်း)။

## လုပ်ဆောင်ချက်များ

```zymbol
a = ၁၀
b = ၃
ရ၁ = a + b    // ၁၃
ရ၂ = a - b    // ၇
ရ၃ = a * b    // ၃၀
ရ၄ = a / b    // ၃  (ကိန်းပြည့်စားခြင်း)
ရ၅ = a % b    // ၁
ရ၆ = a ^ b    // ၁၀၀၀
```

```zymbol
a = ၁၀
b = ၃
နှ၁ = a == b    // #၀
နှ၂ = a <> b    // #၁
နှ၃ = a < b     // #၀
နှ၄ = a >= b    // #၁
ယ၁ = #၁ && #၀  // #၀
ယ၂ = !#၁       // #၀
```

> `==` သည် ဘယ်တော့မှ အတင်းအကြပ်မလုပ်ပါ: `"5" == 5` သည် `#0` ဖြစ်သည်။ အစီအစဉ်သည် အတင်းအကြပ်လုပ်သည်: `"5" > 4` သည် `#1` ဖြစ်ပြီး `"४२" > 5` လည်းဖြစ်သည် — script 69 ခုအနက် တစ်ခုခုရှိ ကိန်းဂဏန်းစာသားသည် ကိန်းဂဏန်းအဖြစ်နှိုင်းယှဉ်သည်။
> လုပ်ဆောင်ချက်တစ်ခုသည် မိမိနှင့်သာ ညီမျှသည်၊ တူညီသောကိုယ်ထည်ရှိသည့် အခြားလုပ်ဆောင်ချက်နှင့် ဘယ်တော့မှ ညီမျှမည်မဟုတ်။

## စာလုံးအစုများ

```zymbol
အမည် = "အောင်မြင့်"
n = ၄၂
>> "မင်္ဂလာပါ " အမည် " မင်းမှာ " n " ရှိသည်" ¶ // → မင်္ဂလာပါ အောင်မြင့် မင်းမှာ 42 ရှိသည်
ဖော်ပြချက် = "မင်္ဂလာပါ {အမည်}၊ မင်းမှာ {n} ရှိသည်"
>> ဖော်ပြချက် ¶              // → မင်္ဂလာပါ အောင်မြင့်၊ မင်းမှာ 42 ရှိသည်
```

```zymbol
s = "မင်္ဂလာကမ္ဘာ"
အရှည် = s$#                  // ၁၂
အပိုင်း = s$[၁..၆]             // "မင်္ဂလ"
ပါဝင် = s$? "ကမ္ဘာ"          // #၁
အပိုင်းများ = "a,b,c,d"$/ ','    // [a, b, c, d]
အစားထိုး = s$~~["ာ":"ါ"]        // "မင်္ဂလါကမ္ဘါ"
မျဉ်း = "─" $* ၂၀
```

> `+` သည် ကိန်းဂဏန်းများအတွက်သာဖြစ်သည်။ စာလုံးအစုများအတွက် ကပ်လျက်ထားခြင်း သို့မဟုတ် ထည့်သွင်းခြင်းကို အသုံးပြုပါ။
> `\{` နှင့် `\}` သည် စာလုံးအတိအကျ curly braces ဖြစ်သည် — escape သည် ညီမျှသည်။

## ထိန်းချုပ်မှုစီးကြောင်း

```zymbol
a = ၇
? a > ၁၀၀ {
    >> "ကြီး" ¶
} _? a > ၀ {
    >> "အပေါင်းလက္ခဏာ" ¶     // → အပေါင်းလက္ခဏာ
} _ {
    >> "အနုတ်လက္ခဏာ" ¶
}
```

ဤနေရာတွင် အမှတ်အသားအသစ်နှစ်ခုရှိပြီး တတိယတစ်ခုသည် ၎င်းတို့ကို ပေါင်းစည်းခြင်းမှ လာသည်:

- `?` သည် **မေးခြင်း** ဖြစ်သည်: အခြေအနေတစ်ခုကို ဖွင့်သည်။
- `_` သည် **မသတ်မှတ်ထားသောအရာ** ဖြစ်သည်: မည်သည့်မေးခွန်းမျှ မကိုက်ညီသောအခါ ကျန်ရစ်သောအခွဲ။
- `_?` သည် နှစ်ခုလုံး ဆက်တိုက်: *တစ်စုံတစ်ခုမျှမကိုက်ညီလျှင် ထပ်မံမေးပါ*။

ထို့ကြောင့် `_?` သည် ထိုသို့ရေးထားသည်။ ၎င်းသည် သင်ယူရန် သင်္ကေတအသစ်မဟုတ်ပါ — ၎င်းသည် `_` နောက်တွင် `?` ဖြစ်ပြီး ၎င်း၏အပိုင်းနှစ်ခုကို အစဉ်လိုက်ဖတ်သောအခါ ဆိုလိုသည့်အရာကို အတိအကျဆိုလိုသည်။

> Curly braces `{ }` သည် ထုတ်ပြန်ချက်တစ်ခုအတွက်ပင် **မဖြစ်မနေ** လိုအပ်သည်။

## ကိုက်ညီမှု

```zymbol
အမှတ် = ၈၅
အဆင့် = ?? အမှတ် {
    ၉၀..၁၀၀ => 'A'
    ၈၀..၈၉  => 'B'
    _       => 'F'
}
>> အဆင့် ¶              // → B
```

```zymbol
အပူချိန် = -၅
အခြေအနေ = ?? အပူချိန် {
    < ၀  => "ရေခဲ"
    < ၂၀ => "အေး"
    _    => "ပူ"
}
>> အခြေအနေ ¶              // → ရေခဲ
```

`?` သည် "မေးခြင်း" ဖြစ်သည်ကို သင်သိပြီးဖြစ်သည်။ **`??` သည် အကြိမ်များစွာမေးခြင်း** ဖြစ်သည်: ဘာသာစကားတွင် နေရာတိုင်း အမှတ်အသားတစ်ခုကို နှစ်ဆတိုးခြင်းသည် အမှတ်အသားတစ်ခုက တစ်ကြိမ်လုပ်သည့်အရာကို အကြိမ်များစွာလုပ်ခြင်းဖြစ်သည်။ `?` တစ်ခုသည် အခြေအနေတစ်ခုကို စမ်းသပ်သည်; `??` သည် ကိစ္စများစာရင်းနှင့် စမ်းသပ်သည်။

ရွေးချယ်စရာများသည် `||` ဖြင့် ပေါင်းစည်းပြီး ပုံစံအမျိုးအစားများကို ရောနှောနိုင်သည်:

```zymbol
ခလုတ် = 'P'
လုပ်ဆောင်ချက် = ?? ခလုတ် {
    'p' || 'P' => "ရပ်"
    < ၀ || > ၁၀၀ => "အပိုင်းအခြားပြင်ပ"
    _ => "လျစ်လျူရှု"
}
>> လုပ်ဆောင်ချက် ¶             // → ရပ်
```

## ကွင်းများ

```zymbol
@ i:၁..၄  { >> i " " }
>> ¶                    // → 1 2 3 4
@ i:၁..၉:၂ { >> i " " }
>> ¶                    // → 1 3 5 7 9
@ i:၅..၁:၁ { >> i " " }
>> ¶                    // → 5 4 3 2 1
```

```zymbol
n = ၁
@ n <= ၆၄ { n *= ၂ }
>> n ¶                  // → 128
```

```zymbol
သစ်သီးများ = ["ပန်းသီး", "သစ်တော်သီး", "စပျစ်သီး"]
@ သ:သစ်သီးများ { >> သ " " }
>> ¶                    // → ပန်းသီး သစ်တော်သီး စပျစ်သီး
@ အ:"မင်္ဂလာပါ" { >> အ "-" }
>> ¶                    // → မ-င-်-္-ဂ-လ-ာ-ပ-ါ-
```

```zymbol
@ i:၁..၁၀ {
    ? i % ၂ == ၀ { @> }
    ? i > ၇ { @! }
    >> i " "
}
>> ¶                    // → 1 3 5 7
```

```zymbol
အရေအတွက် = ၀
@:အပြင် {
    အရေအတွက်++
    ? အရေအတွက် >= ၃ { @:အပြင်! }
}
>> အရေအတွက် ¶             // → 3
```

`@` သည် **အချိန်** ၏ အမှတ်အသားဖြစ်သည်: ထပ်တလဲလဲဖြစ်သော အရာအားလုံးသည် ၎င်းအတွင်းတွင်နေထိုင်သည်။ ထိုအချိန်ကို ဖြတ်တောက်ရန် သင်သည် ၎င်း၏ဘေးတွင် အမှတ်အသားတစ်ခုထည့်သည်:

- `@!` — `!` သည် **အင်အား**: ယခုပင် ကွင်းမှထွက်ပါ။
- `@>` — `>` သည် ရှေ့သို့တွန်းသည်: နောက်တစ်ခေါက်သို့သွားပါ။
- `@:အပြင်!` — `:` သည် **အမည်တစ်ခုကို ချည်နှောင်သည်**၊ ထို့ကြောင့် ၎င်းသည် *အပြင်* အမည်ရှိကွင်းကို ဖြတ်သည်၊ အနီးဆုံးကိုမဟုတ်။

လုပ်ဆောင်ချက်သုံးခု၊ ၎င်းတို့အနက် တစ်ခုမှ သီးခြားမှတ်ရန်မလိုအပ်ခဲ့ပါ: ၎င်းတို့သည် `@` အပေါင်း ၎င်းဘာလုပ်သည်ကို ပြီးသားပြောသောအမှတ်အသားဖြစ်သည်။

> **သတ်မှတ်ချက်တစ်ခုသည် အရေအတွက် သို့မဟုတ် အခြေအနေဖြစ်သည်။** `ကိန်းပြည့်` သည် အရေအတွက်ဖြစ်ပြီး တစ်ကြိမ်တန်ဖိုးဖြတ်သည် — `@ ၀` သည် ကိုယ်ထည်ကို သုညအကြိမ်လုပ်သည်။ အခြားအရာအားလုံးသည် အခြေအနေဖြစ်သည်။ အမှန်တရားမရှိ: `@ []` နှင့် `@ ၃.၅` ကို ငြင်းပယ်သည်။ စုစည်းမှုတစ်ခုကို ဖြတ်သန်းရန် `@ x:အရာများ` ကိုသုံးပါ; ရေတွက်ရန် `@ အရာများ$#`။

## လုပ်ဆောင်ချက်များ

```zymbol
ပေါင်း(a, b) { <~ a + b }
>> ပေါင်း(၃, ၄) ¶        // → 7
```

```zymbol
အဆင့်မြှောက်(n) {
    ? n <= ၁ { <~ ၁ }
    <~ n * အဆင့်မြှောက်(n - ၁)
}
>> အဆင့်မြှောက်(၅) ¶       // → 120
```

လုပ်ဆောင်ချက်တစ်ခုသည် ဖိုင်၏ ကိန်းရှင်များကို တန်ဖိုးအလိုက်ဖတ်ပြီး အတွင်းရေးသားခြင်းသည် အတွင်းတွင်ကျန်သည်:

```zymbol
ကန့်သတ် = ၁၀၀
အတွင်း(n) { <~ n < ကန့်သတ် }
>> အတွင်း(၄၂) ¶         // → #1
```

အမှတ်အသားနှစ်ခုက ယင်းကိုပြောင်းပြီး နှစ်ခုလုံးကို **လက်မှတ်နှင့် ခေါ်ဆိုသည့်နေရာ** တွင် ရေးသည်:

```zymbol
တိုးမြှင့်(အရေအတွက်<~) { အရေအတွက် = အရေအတွက် + ၁ }
စုစုပေါင်း = ၀
တိုးမြှင့်(စုစုပေါင်း<~)
>> စုစုပေါင်း ¶              // → 1
```

> `p~` သည် အလုပ်စမိတ္တူဖြစ်သည် — ကိုယ်ထည်သည် ၎င်းကို ပြန်လည်သတ်မှတ်နိုင်ပြီး ခေါ်သူသည် မထိခိုက်ပါ။
> `p<~` သည် အထွက် parameter ဖြစ်သည် — ပြောင်းလဲမှုသည် ပြန်လာသည်။ အမှတ်အသားမပါဘဲ `တိုးမြှင့်(စုစုပေါင်း)` သည် အဓိပ္ပာယ်အမှားဖြစ်သည်: မှတ်ချက်နှင့် လက်မှတ်သည် ကွဲပြားနိုင်မည်မဟုတ်။

## Lambda နှင့် Closure များ

```zymbol
နှစ်ဆ = a -> a * ၂
ပေါင်းလဒ် = (a, b) -> a + b
>> နှစ်ဆ(၅) ¶          // → 10
>> ပေါင်းလဒ်(၃, ၇) ¶          // → 10
```

```zymbol
အမျိုးအစားခွဲ = a -> {
    ? a > ၀ { <~ "အပေါင်းလက္ခဏာ" }
    _? a < ၀ { <~ "အနုတ်လက္ခဏာ" }
    <~ "သုည"
}
>> အမျိုးအစားခွဲ(-၄) ¶         // → အနုတ်လက္ခဏာ
```

```zymbol
ဆခွဲ = ၃
သုံးဆ = a -> a * ဆခွဲ
>> သုံးဆ(၇) ¶          // → 21
```

```zymbol
ပေါင်းကိရိယာဖန်တီး(n) { <~ a -> a + n }
ပေါင်း၁၀ = ပေါင်းကိရိယာဖန်တီး(၁၀)
>> ပေါင်း၁၀(၅) ¶           // → 15
```

Lambda သည် parameter လုံးဝမယူနိုင်ပါ:

```zymbol
အဖြေ = () -> ၄၂
>> အဖြေ() ¶           // → 42
```

> Lambda သည် ဖိုင်၏ ကိန်းရှင်များကို **ဖန်တီးသည့်အခါ** ဖမ်းယူသည်; အမည်ရှိလုပ်ဆောင်ချက်သည် ၎င်းတို့ကို **ခေါ်သည့်အခါ** ဖတ်သည်။

## ခင်းကျင်းများ

```zymbol
ခင်းကျင်း = [၁, ၂, ၃, ၄, ၅]
>> ခင်းကျင်း[၁] ¶       // → 1   အညွှန်းသည် 1 အခြေခံ
>> ခင်းကျင်း[-၁] ¶      // → 5   အနုတ်သည် အဆုံးမှရေတွက်သည်
>> ခင်းကျင်း$# ¶        // → 5   အရှည်
```

```zymbol
ခင်းကျင်း = [၁, ၂, ၃]
>> (ခင်းကျင်း$+ ၆) ¶          // → [1, 2, 3, 6]   ထည့်
>> (ခင်းကျင်း$+[၂] ၉၉) ¶      // → [1, 99, 2, 3]  အနေအထား 2 တွင်ထည့်
>> (ခင်းကျင်း$- ၃) ¶          // → [1, 2]         ပထမပေါ်ပေါက်မှုကိုဖယ်
>> (ခင်းကျင်း$-[၁]) ¶         // → [2, 3]         အညွှန်း 1 တွင်ဖယ်
>> (ခင်းကျင်း$[၁..၂]) ¶       // → [1, 2]         slice၊ နှစ်ဖက်စွန်းပါဝင်
>> (ခင်းကျင်း$? ၃) ¶          // → #1             ပါဝင်
```

အားလုံးသည် `$` ဖြင့်စသည်၊ ၎င်းသည် **စုစည်းမှု** ၏အမှတ်အသားဖြစ်ပြီး အတွင်းတွင်ဘာလုပ်သည်ကိုပြောသောအမှတ်အသားဖြင့် ဆက်သည်: `#` ဘယ်နှစ်ခု၊ `+` ထည့်၊ `-` ဖယ်၊ `?` ရှိမရှိမေး။ ပြီးနောက် `??` ကဲ့သို့ အမှတ်အသားကို နှစ်ဆတိုးခြင်းသည် ပြည့်စုံစွာလုပ်ခြင်းကိုဆိုလိုသည်: `$?` သည် တန်ဖိုးတစ်ခု *ရှိမရှိ* မေးသည်၊ `$??` သည် *မည်သည့်နေရာများတွင်* ရှိသည်ကိုမေးပြီး အားလုံးကိုပြန်ပေးသည်။

```zymbol
ခင်းကျင်း = [၃, ၁, ၂]
>> (ခင်းကျင်း$^+) ¶     // → [1, 2, 3]   တက်
>> (ခင်းကျင်း$^-) ¶     // → [3, 2, 1]   ဆင်း
```

**ရလဒ်၏စည်းမျဉ်း။** လုပ်ဆောင်ချက်တစ်ခု၊ ပတ်ဝန်းကျင်ကုဒ်က ၎င်းနှင့်ဘာလုပ်သည်က ဆုံးဖြတ်သည်: အသုံးပြုလျှင် ၎င်းသည် **တည်ဆောက်** ပြီး မူရင်းကိုမထိဘဲထားသည်; စွန့်ပစ်လျှင် ၎င်းသည် **ပြောင်းလဲ** သည်။

```zymbol
ခင်းကျင်း = [၁, ၂, ၃]
မိတ္တူ = ခင်းကျင်း[၂]$~ ၉၉
>> ခင်းကျင်း ¶                // → [1, 2, 3]
>> မိတ္တူ ¶              // → [1, 99, 3]
ခင်းကျင်း[၂]$~ ၉၉
>> ခင်းကျင်း ¶                // → [1, 99, 3]
```

> **`=` သည် စုစည်းမှုတစ်ခုထဲသို့ ဘယ်တော့မှမရေးပါ။** `ခင်းကျင်း[၂] = ၉၉` သည် Zymbol ၏ပုံစံမဟုတ် — `=` သည် **အမည်** ကို တန်ဖိုးပေးသည်။ စုစည်းမှု၏အပိုင်းတစ်ခုကို ပြောင်းလဲခြင်းသည် `$~` ဖြစ်သည်၊ စုစည်းမှုတိုင်းတွင်။

`[…]` သည် အမျိုးအစားတစ်ခုကိုကိုင်ပြီး စစ်ဆေးသည်; တမင်ရောနှောခြင်းကို `#[…]` ဖြင့် **ကြေညာ** သည်:

```zymbol
ရောနှော = #[၁, "နှစ်", #၁]
>> ရောနှော ¶             // → [1, နှစ်, #1]
>> ([၁, ၂] == #[၁, ၂]) ¶ // → #1
```

## ဘက်စုံအညွှန်းကိန်း

`>` သည် nested ဖွဲ့စည်းမှုတစ်ခုထဲသို့ဆင်းသည်။ ကွင်းစုတစ်ခုသည် ဒြပ်စင်တစ်ခုကို လိပ်စာပေးသည်၊ မည်မျှနက်သော်လည်း။

```zymbol
m = [[၁,၂,၃], [၄,၅,၆], [၇,၈,၉]]
>> m[၂>၃] ¶        // → 6   လိုင်း 2၊ ကော်လံ 3
>> m[-၁>-၁] ¶      // → 9   နောက်ဆုံးလိုင်း၊ နောက်ဆုံးကော်လံ
```

```zymbol
m = [[၁,၂,၃], [၄,၅,၆], [၇,၈,၉]]
>> m[၁>၁ ; ၂>၂ ; ၃>၃] ¶          // → [1, 5, 9]          ပြား: ထောင့်ဖြတ်
>> m[[၁>၁, ၁>၃] ; [၃>၁, ၃>၃]] ¶  // → [[1, 3], [7, 9]]   ဖွဲ့စည်း: ထောင့်များ
```

```zymbol
m = [[၁,၂,၃], [၄,၅,၆]]
>> (m[၁>၂]$~ ၉၉) ¶      // → [[1, 99, 3], [4, 5, 6]]
```

> `m[၁][၂]` သည် Zymbol ၏ပုံစံ **မဟုတ်**။ ဆက်တိုက်အညွှန်းကို ဖတ်ခြင်းနှင့် ရေးခြင်းနှစ်ခုလုံးအတွက် ငြင်းပယ်သည် — ဝင်ရောက်မှုတစ်ခုလျှင် ကွင်းစုတစ်ခု၊ ပြီးနောက် `>` သည် အဆင့်များအကြားတွင်သွားသည်။

## အဘိဓာန်များ

အမည်ရှိအကွက်များပါသော တူပယ်သည် အဘိဓာန်ဖြစ်ပြီး v0.0.9 မှစ၍ `#(…)` အဖြစ်ရေးသည်။

```zymbol
လူ = #(အမည်: "အောင်မြင့်", အသက်: ၂၅)
>> လူ.အမည် ¶        // → အောင်မြင့်
>> လူ["အသက်"] ¶    // → 25
```

```zymbol
လူ = #(အမည်: "အောင်မြင့်", အသက်: ၂၅)
အကွက် = "အမည်"
>> လူ[အကွက်] ¶     // → အောင်မြင့်
```

၎င်းသည် ပြောင်းလဲနိုင်သည်၊ သော့များထည့်နိုင်ပြီး ၎င်းကိုဖြတ်သန်းနိုင်သည်:

```zymbol
သိုလှောင် = #(သစ်တော်သီး: ၄)
သိုလှောင်["ပန်းသီး"]$~ ၁၀
@ k:သိုလှောင် { >> k "=" သိုလှောင်[k] " " }
>> ¶                    // → သစ်တော်သီး=4 ပန်းသီး=10
```

```zymbol
သိုလှောင် = #(သစ်တော်သီး: ၄, ပန်းသီး: ၁၀)
@ (k, v):သိုလှောင် { >> k ":" v " " }
>> ¶                    // → သစ်တော်သီး:4 ပန်းသီး:10
```

> `#()` သည် အလွတ်အဘိဓာန်ဖြစ်ပြီး `()` မဖြစ်နိုင်ခဲ့ပါ — ၎င်းသည် အလွတ်တူပယ်လည်းဖြစ်ရမည်။ ကွင်းမပါသော `(a: 1)` ကို ဤစာဖြင့် ငြင်းပယ်သည်: *a dictionary is written `#(…)`* — «အဘိဓာန်ကို `#(…)` ဟုရေးသည်»။
> အဘိဓာန်ကို သော့ဖြင့်လိပ်စာပေးသည်၊ အနေအထားဖြင့် ဘယ်တော့မှမဟုတ်၊ ထို့ကြောင့် `လူ[1]` သည် အမှားဖြစ်သည်။

---

## တူပယ်များ

တူပယ်များသည် **မပြောင်းလဲနိုင်** သော အစီအစဉ်တကျ ကွန်တိန်နာများဖြစ်ပြီး အမျိုးအစားမတူညီသော တန်ဖိုးများကိုကိုင်သည်။

```zymbol
အမှတ် = (၁၀, ၂၀)
>> အမှတ်[၁] ¶           // → 10
ဒေတာ = (၄၂, "မင်္ဂလာပါ", #၁, ၃.၁၄)
>> ဒေတာ[၃] ¶            // → #1
```

```zymbol
t = (၁၀, ၂၀, ၃၀)
t2 = t[၂]$~ ၉၉၉
>> t ¶                  // → (10, 20, 30)
>> t2 ¶                 // → (10, 999, 30)
```

> တူပယ်တစ်ခုကို ၎င်း၏နေရာတွင် ပြောင်းလဲရန် မည်သည့်ကြိုးပမ်းမှုမဆို အမှားဖြစ်သည်၊ လုပ်ဆောင်ချက်မည်သည့်ဖြစ်ပါစေ — မပြောင်းလဲနိုင်ခြင်းသည် တန်ဖိုး၏ဂုဏ်သတ္တိဖြစ်သည်၊ `$` တစ်ခုချင်းစီအတွင်း ခြွင်းချက်မဟုတ်။

## ဖြိုခွဲခြင်း

```zymbol
ခင်းကျင်း = [၁၀, ၂၀, ၃၀, ၄၀, ၅၀]
[a, b, c] = ခင်းကျင်း
>> a " " b " " c ¶      // → 10 20 [30, 40, 50]
```

```zymbol
ခင်းကျင်း = [၁၀, ၂၀, ၃၀, ၄၀, ၅၀]
[ပထမ, *ကျန်] = ခင်းကျင်း
>> ပထမ ¶            // → 10
>> ကျန် ¶              // → [20, 30, 40, 50]
```

```zymbol
အမှတ် = (၁၀၀, ၂၀၀)
(px, py) = အမှတ်
>> px " " py ¶          // → 100 200
```

```zymbol
လူ = #(အမည်: "မြင့်မြင့်", အသက်: ၂၅)
#(အမည်: n, အသက်: a) = လူ
>> n " " a ¶            // → မြင့်မြင့် 25
```

> ကွင်း၏ပုံသဏ္ဌာန်သည် အမျိုးအစားခွဲထားသည်: `[…]` သည် ခင်းကျင်းယူသည်၊ `(…)` တူပယ်၊ `#(…)` အဘိဓာန်။ နောက်ဆုံးအမည်သည် **ကျန်ရစ်သည်ကို စုပ်ယူ** သည်၊ ထို့ကြောင့် ဖြိုခွဲခြင်းသည် အရှည်ကြောင့် ဘယ်တော့မှမကျရှုံးပါ — `(a, b, c) = (1,2,3,4,5)` သည် `c = (3,4,5)` ပေးသည်၊ ဘာမှမကျန်လျှင် `##_`။

## အဆင့်မြင့်လုပ်ဆောင်ချက်များ

```zymbol
နံပါတ်များ = [၁, ၂, ၃, ၄, ၅]
>> (နံပါတ်များ$> (a -> a * ၂)) ¶ // → [2, 4, 6, 8, 10]
>> (နံပါတ်များ$| (a -> a % ၂ == ၀)) ¶ // → [2, 4]
>> (နံပါတ်များ$< (၀, (စုစည်း, a) -> စုစည်း + a)) ¶ // → 15
```

```zymbol
နံပါတ်များ = [၁, ၂, ၃, ၄, ၅, ၆]
နှစ်ဆ(a) { <~ a * ၂ }
ကြီး(a) { <~ a > ၃ }
>> (နံပါတ်များ$> နှစ်ဆ) ¶    // → [2, 4, 6, 8, 10, 12]
>> (နံပါတ်များ$| ကြီး) ¶    // → [4, 5, 6]
```

```zymbol
အခြေခံ = [#(အမည်: "ကာလာ", အသက်: ၂၈), #(အမည်: "မြင့်မြင့်", အသက်: ၂၅)]
အသက်အလိုက် = အခြေခံ$^ (a, b -> a.အသက် < b.အသက်)
>> အသက်အလိုက်[၁].အမည် ¶     // → မြင့်မြင့်
```

> အမည်ရှိလုပ်ဆောင်ချက်သည် HOF သို့ **ကွင်းမပါဘဲ** သွားသည်: `နံပါတ်များ$> နှစ်ဆ`။ `နံပါတ်များ$> (နှစ်ဆ)` ရေးခြင်းသည် parse အမှားဖြစ်သည်၊ အကြောင်းမှာ `(` သည် lambda ကိုဖွင့်သည်။

## အမှားကိုင်တွယ်ခြင်း

```zymbol
!? {
    a = ၁၀ / ၀
} :! ##Div {
    >> "သုညဖြင့်စားခြင်း" ¶  // → သုညဖြင့်စားခြင်း
} :! {
    >> "အခြား: " _err ¶
} :> {
    >> "အမြဲလုပ်သည်" ¶        // → အမြဲလုပ်သည်
}
```

| အမျိုးအစား | ဘယ်အခါ |
|------|------|
| `##Div` | သုညဖြင့်စားခြင်း |
| `##Index` | အညွှန်းသည် နယ်နိမိတ်ပြင်ပ |
| `##Key` | အဘိဓာန်တွင် သော့မရှိ |
| `##Range` | လုံခြုံသောကိန်းပြည့်အပိုင်းအခြားပြင်ပ |
| `##Type` | အမျိုးအစားမကိုက်ညီ |
| `##Parse` | ဒေတာခွဲခြမ်းစိတ်ဖြာခြင်း |
| `##IO` | ဖိုင် / စနစ် |
| `##Network` | ကွန်ရက်အမှားများ |
| `##DB` | ဒေတာဘေ့စ် |
| `##Time` | မရှိသောရက်စွဲ |
| `##_` | မည်သည့်အမှား (အားလုံးဖမ်း) |

`!` သည် **အမှားနှင့် အင်အား** ၏အမှတ်အသားဖြစ်ပြီး မိသားစုနှစ်ခုလုံးတွင် အတူတူဖတ်သည်: `$!` သည် တန်ဖိုးတစ်ခုကို အမှားဟုတ်မဟုတ်မေးသည်; `$!!` သည် အမှတ်အသားနှစ်ဆဖြင့် မမေးဘဲ အပေါ်သို့ပြန့်ပွားစေသည်။

> Standard library ကျရှုံးမှုများသည် ရပ်တန့်စေခြင်းအစား `$!` ဖြင့်စမ်းသပ်နိုင်သော သို့မဟုတ် `!?` ဖြင့်ဖမ်းနိုင်သော **ပျော့အမှားတန်ဖိုးများ** အဖြစ်ပြန်လာသည်။ `$!!` သည် တစ်ခုကို ခေါ်သူထံပြန့်ပွားစေသည်။

## Module များ

```zymbol
# တွက်စက် {
    #> { ပေါင်း, PI }

    PI := ၃.၁၄၁၅၉
    ပေါင်း(a, b) { <~ a + b }
}
```

```zymbol
<# ./တွက်စက် => တ

>> တ::ပေါင်း(၅, ၃) ¶
>> တ.PI ¶
```

```zymbol
# ကျွန်ုပ်၏စာကြည့်တိုက် {
    #> { အတွင်းပေါင်း => ပေါင်းလဒ် }

    အတွင်းပေါင်း(a, b) { <~ a + b }
}
```

Module အမှတ်အသားနှစ်ခုသည် တူညီသောအယူအဆဖြစ်ပြီး ယခု ဖိုင်များတွင် အသုံးပြုသည်: `#` သည် **ကြေညာခြင်း** အဆင့်ဖြစ်သည် — အရာတစ်ခု *ဘာဖြစ်သည်*၊ ၎င်း၏တန်ဖိုးမဟုတ် — မြှားကမူ ကုဒ်မည်သည့်လမ်းကြောင်းသွားသည်ကိုပြသည်:

```text
<#   မြှားဝင်လာသည်: import လုပ်၊ အခြားဖိုင်မှယူလာ
#>   မြှားထွက်သွားသည်: export လုပ်၊ အခြားဖိုင်များသို့ပေးအပ်
```

လမ်းကြောင်းအမှတ်အသားသည် ၎င်းညွှန်သည့်လမ်းကြောင်းသို့ မျက်နှာမူသောအစွန်းတွင် အမြဲထိုင်သည်။ `<~` သည် ဘယ်သို့ပြန်လာခြင်း (လုပ်ဆောင်ချက်မှအပြင်) နှင့် `->` သည် ညာသို့ဝင်ခြင်း (lambda ၏ကိုယ်ထည်သို့) တို့သည် အလားတူအကြောင်းရင်းဖြစ်သည်။

> **Module သည် ၎င်းတင်ပို့သည့်အရာကို ကြေညာသည်။** `#>` ဘလောက်သည် မဖြစ်မနေလိုအပ်သည် — ၎င်းကိုချန်လှပ်ခြင်းသည် **E014** ဖြစ်ပြီး `#> { }` သည် module တစ်ခု၏မျက်နှာပြင်သည်အလွတ်ဖြစ်ကြောင်း ပြောသည့်နည်းလမ်းဖြစ်သည်။ `::` သည် လုပ်ဆောင်ချက်ကိုခေါ်သည်၊ `.` သည် ကိန်းသေကိုဖတ်သည်။ Module ကိုယ်ထည်တွင် import များ၊ export ဘလောက်၊ စာလုံးအတိအကျ initializer များနှင့် လုပ်ဆောင်ချက်အဓိပ္ပာယ်ဖွင့်ဆိုချက်များသာ ပေါ်နိုင်သည်; လုပ်ဆောင်နိုင်သောမည်သည့်အရာမဆို **E013** ဖြစ်သည်။

## Standard Library

Native module များ၊ အခြားများကဲ့သို့ import လုပ်သည်:

| Module | လုပ်ဆောင်ချက်များ |
|--------|-----------|
| `std/math` | `sqrt exp ln log pow abs ceil floor round min max sin cos tan asin acos atan atan2 sinh cosh tanh sigmoid` · `PI` `E` |
| `std/random` | `entero rango peso_f64` |
| `std/json` | `decode decode_map encode` |
| `std/io` | `read write append exists delete list mkdir` |
| `std/net` | `get post post_json head` |
| `std/db` | `connect exec query query_one tx commit rollback` … |
| `std/term` | `width pad_left pad_right center truncate` |
| `std/time` | `now today parts of format add diff` |

```zymbol
<# std/math => m

>> m::sqrt(၁၆.၀) ¶      // → 4
>> m.PI ¶               // → 3.141592653589793
```

```zymbol
<# std/term => t

>> t::width("手番") ¶            // → 4   glyph နှစ်ခု၊ ကော်လံလေးခု
>> "|" t::center("go", 8) "|" ¶ // → |   go   |
```

```zymbol
<# std/time => T

ရက် = T::of(၂၀၂၆, ၁, ၃၁)
>> T::format(ရက်, "%Y-%m-%d") ¶ // → 2026-01-31
>> T::format(T::add(ရက်, ၁, "month"), "%Y-%m-%d") ¶ // → 2026-02-28
```

> `std/term` သည် **ပြသသည့်ကော်လံများ** ကိုတိုင်းတာသည်၊ အက္ခရာများမဟုတ်: CJK နှင့် emoji အများစုသည် ကော်လံ 2 ဖြစ်သည်၊ ထို့ကြောင့် ဇယားကို `t::width` ဖြင့်ချပါ၊ `$#` ဘယ်တော့မှမဟုတ်။
> `std/time` တွင် ခဏတစ်ခုသည် epoch မှ မီလီစက္ကန့်ဖြစ်သည်။ တစ်ရက်အောက်သည်ကာလ၊ တစ်ရက်မှအထက်သည်ပြက္ခဒိန် — ထို့ကြောင့် တစ်လသည် လ၏တူညီသောရက်တွင်ကျပြီး ကလစ်လုပ်ထားသည်။ `ကွာခြား(a, b)` သည် `a - b` ဖြစ်သည်၊ ထို့ကြောင့် စောသောခဏကိုအရင်ပေးလျှင် အနုတ်အဖြေရသည်။

## Package များ

`.zyp` သည် ဖိုင်များစွာပါသောပရိုဂရမ်ကို သယ်ဆောင်နိုင်သောဖိုင်တစ်ခုအဖြစ် စုစည်းသည်။ ၎င်းသည် **ရင်းမြစ်** ၏ မော်ကွန်းဖြစ်သည်၊ binary မဟုတ်၊ ထို့ကြောင့် `zymbol` binary အလုပ်လုပ်သည့်နေရာတိုင်းတွင် ၎င်းအလုပ်လုပ်သည်။

```bash
zymbol package ကျွန်ုပ်၏စီမံကိန်း/ --script main.zy -o ကျွန်ုပ်၏စီမံကိန်း.zyp
zymbol run ကျွန်ုပ်၏စီမံကိန်း.zyp
```

> မော်ကွန်းတွင် manifest (`zyp.toml`) ပါပြီး ၎င်း၏ entry script များနှင့် လိုအပ်သော engine ဗားရှင်းကို ကြေညာသည်။ `zymbol run` သည် ၎င်းကို ယာယီလမ်းညွှန်သို့ ထုတ်ယူပြီး ထိုမှအလုပ်လုပ်သည်၊ ထို့ကြောင့် ကုဒ်သည် စွန့်ပစ်နိုင်သော်လည်း script ရေးသည့်အရာသည် သင့်အလုပ်လုပ်သည့်လမ်းညွှန်အစစ်ထဲသို့ကျသည်။ Playground သည်လည်း `.zyp` ဖိုင်များကို load လုပ်သည်။

## ကိန်းဂဏန်းမုဒ်များ

Zymbol သည် ကိန်းဂဏန်းများကို **ယူနီကုဒ်အက္ခရာ 69 မျိုး** ဖြင့်ရေးနိုင်သည် — မြန်မာ၊ ဒေဝနာဂရီ၊ အာရဗီ-အိန္ဒိယ၊ ထိုင်း၊ Klingon pIqaD၊ သင်္ချာအထူ၊ LCD အပိုင်းများနှင့် အခြားများ။ မုဒ်သည် process အတွက် ကမ္ဘာလုံးဆိုင်ရာဖြစ်ပြီး output ကိုသက်ရောက်သည်; သင်္ချာသည်မပြောင်းလဲ။

```zymbol
#၀၉#    // မြန်မာ   (U+1040–U+1049)
#०९#    // ဒေဝနာဂရီ   (U+0966–U+096F)
#٠٩#    // အာရဗီ-အိန္ဒိယ (U+0660–U+0669)
#09#    // ASCII သို့ပြန်လည်သတ်မှတ်
```

```zymbol
a = ၄၂
>> a ¶                  // → 42
#၀၉#
>> a ¶                  // → ၄၂
>> ၃.၁၄ ¶               // → ၃.၁၄
>> #၁ ¶                 // → #၁
#09#
```

ပံ့ပိုးထားသော မည်သည့်အက္ခရာ၏ ကိန်းဂဏန်းများမဆို ရင်းမြစ်တွင် တရားဝင်စာလုံးများဖြစ်သည်:

```zymbol
#၀၉#
@ i:၁..၅ { >> i " " }
>> ¶                    // → ၁ ၂ ၃ ၄ ၅
#09#
```

ဖတ်ခြင်းသည် ညီမျှသည် — ကိန်းဂဏန်းတစ်ခုကို မည်သည့်အက္ခရာတွင်မဆို နားလည်သည်:

```zymbol
>> #|"४२"| ¶            // → 42
>> #|'७'| ¶             // → 7
```

> `#` သည် အမြဲတမ်း ASCII ဖြစ်သည်၊ ထို့ကြောင့် `#0` သည် အက္ခရာတိုင်းတွင် သုညကိန်းဂဏန်းနှင့် အမြင်အားဖြင့်ကွဲပြားသည်။
> `#,` နှင့် `#^` သည်လည်း ၎င်းတို့၏ကိန်းဂဏန်းများကို လက်ရှိအက္ခရာတွင်ရေးပြီး separator များလည်း လိုက်နာသည် — သို့သော် အတွဲသည် ဘယ်တော့မှ ပြောင်းပြန်မဖြစ်: `,` အုပ်စုဖွဲ့ပြီး `.` ခွဲသည်၊ အက္ခရာတိုင်းတွင်။

## ဒေတာလုပ်ဆောင်ချက်များ

```zymbol
f = ##.၄၂         // ဒသမသို့
i = ###၃.၇        // ကိန်းပြည့်သို့၊ လုံးဝန်း  → 4
t = ##!၃.၇        // ကိန်းပြည့်သို့၊ ဖြတ်  → 3
>> f " " i " " t ¶      // → 42 4 3
>> f#? ¶                // → (##., 2, 42)
```

> ဒသမသည် ကိန်းဂဏန်းများအဖြစ် print ဖြစ်သည်၊ ထပ်ကိန်းအဖြစ် ဘယ်တော့မှမဟုတ်၊ နောက်ဆုံး `.0` ကိုချန်လှပ်သည် — `##.42` သည် `42` ရေးပြီး ဒသမအဖြစ်ရှိနေသည်၊ `f#?` ပြသည့်အတိုင်း။

```zymbol
>> #|"42"| ¶       // → 42
>> #|"abc"| ¶      // → abc   ကျရှုံးမှုလုံခြုံ: input ကိုမပြောင်းဘဲပြန်ပေးသည်
>> ##!'A' ¶        // → 65    အက္ခရာတစ်ခု၏ကုဒ်အမှတ်
```

```zymbol
pi = ၃.၁၄၁၅၉၂၆၅
>> #.၂|pi| ¶       // → 3.14          ဒသမ 2 နေရာအထိလုံးဝန်း
>> #!၂|pi| ¶       // → 3.14          ဒသမ 2 နေရာအထိဖြတ်
>> #,|၁၂၃၄၅၆၇| ¶   // → 1,234,567     ထောင်ဂဏန်းခွဲခြားများ
>> #^|၁၂၃၄၅.၆၇၈| ¶ // → 1.2345678e4  သိပ္ပံနည်းအမှတ်အသား
```

```zymbol
>> 0x41 ¶        // → A   ဆယ့်ခြောက်လီ
>> 0b01000001 ¶  // → A   ဒွိလီ
>> 0o101 ¶       // → A   အဋ္ဌလီ
>> 0d65 ¶        // → A   ဒသမ
```

> ASCII အပိုင်းအခြားရှိ အုပ်စာလုံးသည် **အက္ခရာ** ဖြစ်သည်: `0d65 == 'A'` သည် `#1`၊ `0d65 == 65` သည် `#0`။ လေးခုလုံးသည် တူညီသောအက္ခရာကို စာလုံးပေါင်းသည်။

အမျိုးအစားခွဲ(ကိန်း) {

## အမှတ်အသားများ မည်သို့ပေါင်းစည်းသည်

သင်သည် ဤလမ်းညွှန်တစ်လျှောက်လုံးတွင် တူညီသောအရာကို မြင်ခဲ့သည်: **လုပ်ဆောင်ချက်တစ်ခုသည် မှတ်ရန်ပုံဆွဲခြင်းမဟုတ်၊ ၎င်းသည် တစ်တန်းတည်းရှိ အမှတ်အသားများစွာဖြစ်ပြီး တစ်ခုချင်းစီသည် ၎င်း၏အဓိပ္ပာယ်ကို ပံ့ပိုးသည်။** ယခု သင်အားလုံးကိုသိပြီဖြစ်သောကြောင့် ဤသည်မှာ ပုံစံအပြည့်အစုံဖြစ်သည်။

ပထမဆုံးလာသည် **ကျွန်ုပ်တို့ မည်သည့်ကမ္ဘာတွင်ရှိသည်**:

| အမှတ်အသား | ကမ္ဘာ | သင်မြင်ခဲ့သည့်နေရာ |
|--------|-------|----------------------------|
| `$` | စုစည်းမှု | `$#` `$+` `$?` `$^-` |
| `@` | အချိန်၊ ထပ်တလဲလဲဖြစ်သည့်အရာ | `@!` `@>` `@~` |
| `#` | အရာတစ်ခု *ဘာဖြစ်သည်*၊ ၎င်း၏တန်ဖိုးမဟုတ် | `#?` `#(…)` `<#` `#>` |
| `>>` | ပရိုဂရမ်မှအပြင် | `>>` `>>!` `>>?` |
| `<<` | ပရိုဂရမ်သို့အတွင်း | `<<` `<<\|` `<<\|?` |
| `?` | မေးခြင်း၊ ကတိမပြုဘဲ | `?` `_?` `??` `$?` |
| `!` | အင်အား၊ သို့မဟုတ် အမှား | `@!` `$!` `!?` |

ပြီးနောက် **ထိုနေရာတွင် ဘာလုပ်သည** လာသည်: `+` ထည့်၊ `-` ဖယ်၊ `^` အစီအစဉ်၊ `~` ပြောင်း၊ `#` ရေ၊ `|` ယူနစ်တစ်ခု၊ `:` အမည်ချည်။

ဘယ်တော့မှမကျရှုံးသော စည်းမျဉ်းနှစ်ခု:

**အမှတ်အသားတစ်ခုကို နှစ်ဆတိုးခြင်းသည် ၎င်းကိုပြည့်စုံစေသည်။** `?` တစ်ကြိမ်မေးသည်၊ `??` ကိစ္စများစွာစမ်းသပ်သည်။ `$?` တန်ဖိုးရှိမရှိမေးသည်၊ `$??` ရှိသည့်နေရာတိုင်းပြန်ပေးသည်။ `!` အမှားအမှတ်အသားပြုသည်၊ `!!` မမေးဘဲပြန့်ပွားစေသည်။

**မုဒ်အမှတ်အသားသည် အမြဲတမ်းနောက်ဆုံးလာသည်။** `?` သို့မဟုတ် `!` သည် တစ်စုံတစ်ခု *မည်သို့* လုပ်သည်ကိုပြောရန် ပေါ်လာသောအခါ — တုံ့ဆိုင်းစွာဖြင့် သို့မဟုတ် အတင်းအကြပ်ဖြင့် — ၎င်းတို့သည် လုပ်ဆောင်ချက်၏နောက်ဆုံးအမှတ်အသားဖြစ်သည်: `$??`၊ `$!!`၊ `<<|?`၊ `@!`၊ `##!`၊ `>>!`၊ `>>?`၊ `@:အပြင်!`။ ၎င်းတို့နောက်တွင် လုပ်ဆောင်မှု ဘယ်တော့မှမရှိ။

ထိုမှ လက်တွေ့ကျသောအရာတစ်ခုထွက်လာသည်: **သင်တစ်ခါမှမမြင်ဖူးသောပေါင်းစပ်မှုသည် သင်ရှာမကြည့်မီကပင် အဓိပ္ပာယ်ရှိပြီးဖြစ်သည်။** `$` စုစည်းမှုဖြစ်ပြီး `^` အစီအစဉ်ဖြစ်ပြီး `-` ပြောင်းပြန်ဖြစ်လျှင် `$^-` သည် ဆင်းသက်စွာစီပြီး မည်သူမျှ သင့်ကိုပြောရန်မလိုခဲ့ပါ။

စာရင်းအားလုံး ဤနည်းဖြင့်မလုပ်ပါ၊ ထိုသို့ပြောခြင်းသည် ဟန်ဆောင်ခြင်းထက်ပိုကောင်းသည်။ လုပ်ဆောင်ချက်အများစုသည် သပ်ရပ်စွာကွဲသည်။ ခြောက်ခုသည် ကွဲသော်လည်း ၎င်းတို့၏အပိုင်းများထက်ပိုအဓိပ္ပာယ်ရသည်: `!?` `:!` `:>` `|>` `::` `$++`။ ဆယ်ခုမှာ လုံးဝမကွဲသောကြောင့် အလွတ်ကျက်ရမည်: `¶` `><` `#1` `#0` `0x` `0b` `0o` `0d` `###` `°`။

> မှောင်မိုက်သောအရာများကို နည်းသည်ဟုယူဆခြင်းအစား ရေတွက်ခြင်းသည် တမင်ဖြစ်သည်: ၎င်းတို့သည် ဘာသာစကား၏ အမှန်တကယ်ကျက်မှတ်မှုကုန်ကျစရိတ်ဖြစ်သည်။ ရည်ညွှန်းချက်အပြည့်အစုံ — စာရင်း၊ ကြေညာထားသော homograph များနှင့် လုပ်ဆောင်ချက်အသစ်တစ်ခု တည်ရှိရန်ဖြည့်ဆည်းရမည့်စည်းမျဉ်းများ — သည် စကားပြန်သိုလှောင်ရုံရှိ `SYMBOLS.md` တွင်ရှိသည်။

### v0.0.9 — စုစည်းမှုများ ဆုံးဖြတ်သည် _(စက်တင်ဘာ 2026)_

- **ချိုးဖျက်** အဘိဓာန်သည် ကိုယ်ပိုင်အမှတ်အသားရှိသည်: `#(သော့: တန်ဖိုး)`။ ကွင်းမပါသော `(a: 1)` ကိုငြင်းပယ်ပြီး `#()` သည် အလွတ်အဘိဓာန်ဖြစ်သည် — `()` ဘယ်တော့မှမဖြစ်နိုင်ခဲ့ပါ
- **ချိုးဖျက်** အညွှန်းသတ်မှတ်ခြင်းကို ရုပ်သိမ်းလိုက်သည်: `arr[i] = v` နှင့် compound ပုံစံအားလုံး။ `=` သည် **အမည်** ကိုတန်ဖိုးပေးသည်; စုစည်းမှု၏အပိုင်းတစ်ခုကိုပြောင်းခြင်းသည် `$~`
- **ချိုးဖျက်** ဆက်တိုက်အညွှန်း `m[i][j]` ကို ဖတ်ခြင်းနှင့်ရေးခြင်းနှစ်ခုလုံးအတွက် ငြင်းပယ်သည် — `>` သည် အဆင့်များအကြားသွားသည်

- **ပြင်ဆင်** register VM တွင် module-system parity

### v0.0.7 — Native Standard Library _(ဇူလိုင် 2026)_

- **ထည့်** `std/json`၊ `std/io`၊ `std/net`၊ `std/db` (ODBC) — အားလုံးသည် ပျော့အမှားတန်ဖိုးများဖြင့်
- **ထည့်** Typed/validated input: `<< ##.(5,2) "စျေးနှုန်း: " p`
- **ထည့်** `>>` တွင် postfix operator များတိုက်ရိုက် — ကွင်းမလိုအပ်
- **ပြောင်း** Fail-closed formatter: ပြန်မဖတ်နိုင်သော output ရေးရန်ငြင်းသည်

### v0.0.6 — ပြုပြင်မွမ်းမံခြင်းနှင့် Scientific Stdlib _(ဇွန် 2026)_

- **ချိုးဖျက်** `=>` သည် match arm များတွင် `:` နှင့် import/export alias များတွင် `<=` ကိုအစားထိုးသည်
- **ထည့်** `std/math` နှင့် `std/random`
- **ထည့်** သော့ဖြင့်အဘိဓာန် update: `d["k"]$~ တန်ဖိုး`

### v0.0.5 — TUI အခြေခံအရာများနှင့် Hot Definition _(မေ 2026)_

- **ထည့်** TUI ဘလောက် `>>| { }`၊ တည်နေရာအထွက် `>>~`၊ ခလုတ်အထွက် `<<|` နှင့် `<<|?`
- **ထည့်** `>>!` မျက်နှာပြင်ရှင်း၊ `>>?` terminal အရွယ်၊ `@~ N` အိပ်
- **ထည့်** Hot definition `°x` / `x°` နှင့် စာလုံးအစုထပ် `$*`

### v0.0.4 — 1 အခြေခံအညွှန်းနှင့် ပထမတန်းစားလုပ်ဆောင်ချက် _(ဧပြီ 2026)_

- **ထည့်** ဘက်စုံအညွှန်း `arr[i>j>k]` နှင့် ပြားထုတ်ယူမှု `arr[p ; q]`

### v0.0.3 — ယူနီကုဒ်ကိန်းစနစ်များ _(ဧပြီ 2026)_
