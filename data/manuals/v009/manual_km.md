## អថេរ និងថេរ

```zymbol
x = ១០              // អថេរអាចផ្លាស់ប្តូរ
PI := ៣.១៤១៥៩       // ថេរ — ការផ្តល់តម្លៃឡើងវិញគឺជាកំហុសពេលដំណើរការ
ឈ្មោះ = "សុភា"
សកម្ម = #១           // ប៊ូលីនពិត
👋 := "សួស្តី"
```

```zymbol
x = ១០    // ១០
x += ៥    // ១៥
x -= ៣    // ១២
x *= ២    // ២៤
x /= ៣    // ៨
x %= ៣    // ២
x ^= ២    // ៤
x++       // ៥
x--       // ៤
```

`°` (សញ្ញាដឺក្រេ U+00B0) ចាប់ផ្តើមអថេរដោយស្វ័យប្រវត្តិទៅតម្លៃអព្យាក្រឹតរបស់វានៅពេលប្រើលើកដំបូង៖

```zymbol
លេខ = [៣, ១, ៤, ១, ៥]
@ n:លេខ {
    °សរុប += n
}
>> សរុប ¶              // → 14
```

> `°អថេរ` (បុព្វបទ) ភ្ជាប់នៅខាងលើរង្វិល — លទ្ធផលអាចអានបានបន្ទាប់ពី `@`។
> `អថេរ°` (បច្ច័យ) ភ្ជាប់នៅខាងក្នុងរង្វិល — វាស្លាប់នៅពេលរង្វិលបញ្ចប់។

សេចក្តីថ្លែងការណ៍ដែលមានតែឈ្មោះ នឹងអានអថេរ និងបោះតម្លៃចោល ដូច្នេះវាព្រមាន៖

```zymbol
ចំនួន = ៥
ចំនួន
```

អ្នកចងក្រងព្រមានដូចនេះ (សាររបស់វាតែងតែជាភាសាអង់គ្លេស)៖

```text
warning: this statement does nothing: 'ចំនួន' is read and discarded
  = help: remove it, or use it — `>> name ¶` to print it
```

ន័យថា៖ *«សេចក្តីថ្លែងការណ៍នេះមិនធ្វើអ្វីទេ៖ 'ចំនួន' ត្រូវបានអាន និងបោះចោល»*។

## ប្រភេទទិន្នន័យ

| ប្រភេទ | តម្លៃផ្ទាល់ | ស្លាក `#?` | ចំណាំ |
|------|---------|----------|-------|
| ចំនួនគត់ | `៤២`, `-៧` | `###` | ចំនួនគត់សុវត្ថិភាព៖ ±(2⁵³ − 1) |
| ចំនួនទសភាគ | `៣.១៤`, `១.៥e១០` | `##.` | IEEE-754 ទ្វេ |
| ខ្សែអក្សរ | `"អត្ថបទ"` | `##"` | ការជ្រៀតជ្រែក៖ `"សួស្តី {ឈ្មោះ}"` |
| តួអក្សរ | `'A'` | `##'` | ចំណុចកូដ Unicode មួយ |
| ប៊ូលីន | `#១`, `#០` | `##?` | មិនមែនលេខ — `#១ ≠ ១` |
| អារេ | `[១, ២, ៣]` | `##]` | ប្រភេទតែមួយ បានពិនិត្យ |
| លាយដែលបានប្រកាស | `#[១, "ពីរ"]` | `##[` | ប្រភេទដូច `[…]` មិនបានពិនិត្យ |
| ធុប៉ូល | `(a, b)` | `##)` | តាមទីតាំង មិនអាចផ្លាស់ប្តូរ |
| វចនានុក្រម | `#(x: ១, y: ២)` | `##(` | តាមកូនសោ អាចផ្លាស់ប្តូរ |
| អនុគមន៍ | ឯកសារយោងអនុគមន៍មានឈ្មោះ | `##()` | ថ្នាក់ទីមួយ បង្ហាញ `<funct/N>` |
| ឡាំបដា | `x -> x * ២` | `##->` | ថ្នាក់ទីមួយ បង្ហាញ `<lambd/N>` |
| ឯកតា | `##_` | `##_` | អវត្តមាន — គ្មាន null |

```zymbol
>> ៤២#? ¶               // → (###, 2, 42)
>> [១, ២, ៣]#? ¶        // → (##], 3, [1, 2, 3])
>> #(x: ១)#? ¶          // → (##(, 1, #(x: 1))
```

ចំនួនគត់ដែលចេញពីជួរសុវត្ថិភាព គឺជាកំហុសអាចចាប់បាន មិនដែលជាការរុំស្ងាត់៖

```zymbol
!? {
    >> (៩០០៧១៩៩២៥៤៧៤០៩៩១ + ១) ¶
} :! ##Range {
    >> "ក្រៅជួរ" ¶ // → ក្រៅជួរ
}
```

`##_` គឺជាវិធីដែលកម្មវិធីសួរថាតើមានអ្វីអវត្តមាន៖

```zymbol
គ្មាន_អ្វី() { }
តម្លៃ = គ្មាន_អ្វី()
>> (តម្លៃ == ##_) ¶     // → #1
```

## លទ្ធផល និងការបញ្ចូល

```zymbol
ឈ្មោះ = "សុភា"
សរុប = ៣
>> "សួស្តី" ¶             // → សួស្តី
>> "a=" ឈ្មោះ " b=" សរុប ¶ // → a=សុភា b=3
>> សរុប#? ¶            // → (###, 1, 3)
```

```zymbol
<< ឈ្មោះ
<< "បញ្ចូលឈ្មោះរបស់អ្នក៖ " ឈ្មោះ
<< ###(៤) "អាយុ៖ " អាយុ
```

**មើលរូបរាងសញ្ញាទាំងពីរ។** `>>` ចង្អុលទៅខាងក្រៅ៖ វាយកទិន្នន័យចេញពីកម្មវិធី។ `<<` ចង្អុលទៅខាងក្នុង៖ វានាំទិន្នន័យចូលក្នុងកម្មវិធី។ គ្មានអ្វីត្រូវចងចាំទេ — ព្រួញបង្ហាញទិសដៅដែលព័ត៌មានធ្វើដំណើរ ហើយគំនិតដូចគ្នានេះត្រឡប់មកវិញនៅក្នុងរាល់សញ្ញាដែលផ្លាស់ទីអ្វីមួយ។

> `¶` និង `\\` គឺជាបន្ទាត់ថ្មីសមមូល។ `>>` មិនដែលបន្ថែមមួយទេ។
> អ្នកកំណត់ប្រភេទមុនសំណួរ ផ្ទៀងផ្ទាត់ពេលអាន និងសួរឡើងវិញរហូតតម្លៃត្រឹមត្រូវ៖
> `##.` ចំនួនទសភាគ · `##.(T,D)` ទសភាគ · `###(N)` ចំនួនគត់ · `##"(N)"` អត្ថបទ · `##'` តួអក្សរមួយ។

នៅកម្រិតខ្ពស់បំផុតនៃឯកសារ `<~` គឺជាស្ថានភាពចេញរបស់កម្មវិធី៖

```zymbol
>> "កំពុងពិនិត្យ" ¶      // → កំពុងពិនិត្យ
<~ ០
```

## ព្រីមីទីវ TUI

ប្រតិបត្តិករចំណុចប្រទាក់ស្ថានីយសម្រាប់កម្មវិធីអន្តរកម្ម។ ភាគច្រើនត្រូវការប្លុក `>>| { }` (អេក្រង់ជំនួស + របៀបឆៅ)។

```zymbol
>>| {
    >>!
    >>~ (១, ១, ០, ១០) > "កំពុងដំណើរការ"
    @~ ១០០០
    >>~ (២, ១) > "រួចរាល់។"
}
```

```zymbol
>>| {
    [ជួរ, ជួរឈរ] = >>?
    >>~ (១, ១) > "ស្ថានីយ៖ " ជួរ " x " ជួរឈរ
    <<| គន្លឹះ
    >>~ (២, ១) > "បានចុច៖ " គន្លឹះ
}
```

នៅទីនេះ អ្នកអាចមើលឃើញហេតុអ្វីបានជាសញ្ញារួមបញ្ចូលគ្នាជាជាងគុណ។ អ្នកដឹងរួចហើយថា `<<` គឺជាការបញ្ចូល ហើយ `?` សួរដោយមិនប្តេជ្ញា។ មានតែសញ្ញាមួយប៉ុណ្ណោះដែលថ្មី៖

- `|` គឺជា **ឯកតាតែមួយ** មិនមែនលំហូរទាំងមូលទេ។

ជាមួយនោះ ប្រតិបត្តិករក្តារចុចទាំងពីរអានខ្លួនឯង៖

```text
<<        |             ?
ការបញ្ចូល  ឯកតាតែមួយ   ដោយមិនប្តេជ្ញា

<<|   យកគន្លឹះមួយ ហើយរង់ចាំរហូតមានមួយ
<<|?  មើលថាតើមានគន្លឹះឬអត់ ហើយបន្តបើគ្មាន
```

ដូចគ្នានៅខាងផ្សេងទៀត៖ `>>` ផ្ញើ `>>!` ផ្ញើ **ដោយកម្លាំង** (លុបអេក្រង់ទាំងមូល) ខណៈ `>>?` **សួរ** ជំនួសការសរសេរ (ស្ថានីយធំប៉ុណ្ណា)។ សញ្ញានៅខាងស្តាំ គឺជាសញ្ញាដែលផ្លាស់ប្តូររបៀប ហើយវាតែងតែមកចុងក្រោយ។

> `>>!` លុបអេក្រង់។ `>>?` ផ្តល់ត្រឡប់ `[ជួរ, ជួរឈរ]`។ `@~ N` គេង N មិល្លីវិនាទី។
> `<<|` អានការចុចគន្លឹះមួយ (ទប់ស្កាត់) `<<|?` ស្ទង់មើលដោយមិនទប់ស្កាត់ (`'\0'` បើគ្មាន)។
> គន្លឹះព្រួញមកដល់ជាកូដ `'↑' '↓' '←' '→'` ESC គឺជាចំណុចកូដ 27។
> ធុប៉ូលលទ្ធផលទីតាំង៖ `(ជួរ, ជួរឈរ, BKS, ខាងមុខ, ខាងក្រោយ)` — រន្ធណាមួយអាចបោះបង់ដោយសញ្ញាក្បៀស (`>>~ (,,, ១៩៦) > "ក្រហម"`)។
> របាំងប៊ីត BKS៖ `1`=ដិត `2`=ទ្រេត `4`=គូសបន្ទាត់ក្រោម។ ក្ដារពណ៌ ANSI 256 ពណ៌ (`0`=លំនាំដើមស្ថានីយ)។

## ប្រតិបត្តិករ

```zymbol
a = ១០
b = ៣
ល១ = a + b    // ១៣
ល២ = a - b    // ៧
ល៣ = a * b    // ៣០
ល៤ = a / b    // ៣  (ការចែកចំនួនគត់)
ល៥ = a % b    // ១
ល៦ = a ^ b    // ១០០០
```

```zymbol
a = ១០
b = ៣
ប១ = a == b    // #០
ប២ = a <> b    // #១
ប៣ = a < b     // #០
ប៤ = a >= b    // #១
គ១ = #១ && #០  // #០
គ២ = !#១       // #០
```

> `==` មិនដែលបង្ខំ៖ `"5" == 5` គឺ `#0`។ លំដាប់បង្ខំ៖ `"5" > 4` គឺ `#1` ហើយ `"४२" > 5` ក៏ដូចគ្នា — អត្ថបទលេខនៅក្នុងអក្សរណាមួយក្នុង 69 ប្រៀបធៀបជាលេខ។
> អនុគមន៍ស្មើនឹងខ្លួនវាប៉ុណ្ណោះ មិនដែលស្មើនឹងអនុគមន៍ផ្សេងដែលមានតួដូចគ្នា។

## ខ្សែអក្សរ

```zymbol
ឈ្មោះ = "សុភា"
n = ៤២
>> "សួស្តី " ឈ្មោះ " អ្នកមាន " n ¶ // → សួស្តី សុភា អ្នកមាន 42
ការពិពណ៌នា = "សួស្តី {ឈ្មោះ} អ្នកមាន {n}"
>> ការពិពណ៌នា ¶              // → សួស្តី សុភា អ្នកមាន 42
```

```zymbol
s = "សួស្តីពិភពលោក"
ប្រវែង = s$#                  // ១៣
ផ្នែក = s$[១..៦]             // "សួស្តី"
មាន = s$? "ពិភពលោក"          // #១
ផ្នែកតូច = "a,b,c,d"$/ ','    // [a, b, c, d]
ជំនួស = s$~~["ៅ":"ា"]        // "សួស្តីពិភពលោក"
បន្ទាត់ = "─" $* ២០
```

> `+` សម្រាប់លេខប៉ុណ្ណោះ។ សម្រាប់ខ្សែអក្សរប្រើការដាក់ជាប់គ្នា ឬការជ្រៀតជ្រែក។
> `\{` និង `\}` គឺជាដង្កៀបពិត — ការរត់គេចគឺស៊ីមេទ្រី។

## លំហូរត្រួតពិនិត្យ

```zymbol
x = ៧
? x > ១០០ {
    >> "ធំ" ¶
} _? x > ០ {
    >> "វិជ្ជមាន" ¶     // → វិជ្ជមាន
} _ {
    >> "អវិជ្ជមាន" ¶
}
```

នៅទីនេះមានសញ្ញាថ្មីពីរ ហើយទីបីមកពីការដាក់វាជាមួយគ្នា៖

- `?` គឺ **សួរ**៖ វាបើកលក្ខខណ្ឌ។
- `_` គឺ **អ្វីដែលមិនបានកំណត់**៖ សាខាដែលនៅសល់ពេលគ្មានសំណួរត្រូវគ្នា។
- `_?` គឺទាំងពីរជាប់គ្នា៖ *បើគ្មានអ្វីត្រូវគ្នា សួរម្តងទៀត*។

នោះជាហេតុផលដែល `_?` ត្រូវបានសរសេរដូច្នេះ។ វាមិនមែនជានិមិត្តសញ្ញាថ្មីត្រូវរៀនទេ — វាគឺ `_` បន្តដោយ `?` ហើយវាមានន័យដូចអ្វីដែលផ្នែកទាំងពីររបស់វាមានន័យ អានតាមលំដាប់។

> ដង្កៀប `{ }` គឺ **ចាំបាច់** ទោះសម្រាប់សេចក្តីថ្លែងការណ៍តែមួយ។

## ការផ្គូផ្គង

```zymbol
ពិន្ទុ = ៨៥
និទ្ទេស = ?? ពិន្ទុ {
    ៩០..១០០ => 'A'
    ៨០..៨៩  => 'B'
    _       => 'F'
}
>> និទ្ទេស ¶              // → B
```

```zymbol
សីតុណ្ហភាព = -៥
ស្ថានភាព = ?? សីតុណ្ហភាព {
    < ០  => "ទឹកកក"
    < ២០ => "ត្រជាក់"
    _    => "ក្តៅ"
}
>> ស្ថានភាព ¶              // → ទឹកកក
```

អ្នកដឹងរួចហើយថា `?` គឺ "សួរ"។ **`??` គឺសួរច្រើនដង**៖ ការបង្កើនសញ្ញាទ្វេ នៅកន្លែងណាក្នុងភាសា គឺធ្វើច្រើនដងនូវអ្វីដែលសញ្ញាធ្វើម្តង។ `?` មួយសាកល្បងលក្ខខណ្ឌមួយ `??` សាកល្បងប្រឆាំងនឹងបញ្ជីករណី។

ជម្រើសផ្សេងៗភ្ជាប់ដោយ `||` ហើយពួកវាអាចលាយប្រភេទលំនាំ៖

```zymbol
គន្លឹះ = 'P'
សកម្មភាព = ?? គន្លឹះ {
    'p' || 'P' => "ផ្អាក"
    < ០ || > ១០០ => "ក្រៅជួរ"
    _ => "មិនអើពើ"
}
>> សកម្មភាព ¶             // → ផ្អាក
```

## រង្វិល

```zymbol
@ i:១..៤  { >> i " " }
>> ¶                    // → 1 2 3 4
@ i:១..៩:២ { >> i " " }
>> ¶                    // → 1 3 5 7 9
@ i:៥..១:១ { >> i " " }
>> ¶                    // → 5 4 3 2 1
```

```zymbol
n = ១
@ n <= ៦៤ { n *= ២ }
>> n ¶                  // → 128
```

```zymbol
ផ្លែឈើ = ["ផ្លែប៉ោម", "ផ្លែពែរ", "ផ្លែទំពាំងបាយជូរ"]
@ ផ:ផ្លែឈើ { >> ផ " " }
>> ¶                    // → ផ្លែប៉ោម ផ្លែពែរ ផ្លែទំពាំងបាយជូរ
@ ត:"សួស្តី" { >> ត "-" }
>> ¶                    // → ស-ួ-ស-្-ត-ី-
```

```zymbol
@ i:១..១០ {
    ? i % ២ == ០ { @> }
    ? i > ៧ { @! }
    >> i " "
}
>> ¶                    // → 1 3 5 7
```

```zymbol
ចំនួន = ០
@:ខាងក្រៅ {
    ចំនួន++
    ? ចំនួន >= ៣ { @:ខាងក្រៅ! }
}
>> ចំនួន ¶             // → 3
```

`@` គឺជាសញ្ញានៃ **ពេលវេលា**៖ អ្វីៗដែលកើតឡើងម្តងទៀតរស់នៅក្នុងវា។ ដើម្បីកាត់ពេលវេលានោះ អ្នកបន្ថែមសញ្ញាមួយនៅជាប់វា៖

- `@!` — `!` គឺ **កម្លាំង**៖ ចេញពីរង្វិលឥឡូវនេះ។
- `@>` — `>` រុញទៅមុខ៖ ទៅវដ្តបន្ទាប់។
- `@:ខាងក្រៅ!` — `:` **ចងឈ្មោះ** ដូច្នេះវាកាត់រង្វិលដែល *ឈ្មោះ* ខាងក្រៅ មិនមែនរង្វិលជិតបំផុត។

ប្រតិបត្តិករបី ហើយគ្មានមួយណាត្រូវចងចាំដោយឡែក — ពួកវាគឺ `@` បូកនឹងសញ្ញាដែលប្រាប់រួចហើយថាវាធ្វើអ្វី។

> **អ្នកកំណត់គឺជាចំនួន ឬលក្ខខណ្ឌ។** `ចំនួនគត់` គឺជាចំនួន វាយតម្លៃម្តង — `@ 0` ដំណើរការតួសូន្យដង។ អ្វីផ្សេងទៀតគឺលក្ខខណ្ឌ។ គ្មានការពិតទេ៖ `@ []` និង `@ 3.5` ត្រូវបានបដិសេធ។ ដើម្បីឆ្លងកាត់បណ្តុំ ប្រើ `@ x:ធាតុ` ដើម្បីរាប់ `@ ធាតុ$#`។

## អនុគមន៍

```zymbol
បូក(a, b) { <~ a + b }
>> បូក(៣, ៤) ¶        // → 7
```

```zymbol
ហ្វាក់តូរីយែល(n) {
    ? n <= ១ { <~ ១ }
    <~ n * ហ្វាក់តូរីយែល(n - ១)
}
>> ហ្វាក់តូរីយែល(៥) ¶       // → 120
```

អនុគមន៍អានអថេរឯកសារតាមតម្លៃ ហើយការសរសេរនៅខាងក្នុងនៅតែនៅខាងក្នុង៖

```zymbol
ដែនកំណត់ = ១០០
ខាងក្នុង(n) { <~ n < ដែនកំណត់ }
>> ខាងក្នុង(៤២) ¶         // → #1
```

សញ្ញាពីរផ្លាស់ប្តូរនោះ ហើយទាំងពីរត្រូវបានសរសេរ **ក្នុងហត្ថលេខា និងនៅកន្លែងហៅ**៖

```zymbol
បង្កើន(ចំនួន<~) { ចំនួន = ចំនួន + ១ }
សរុប = ០
បង្កើន(សរុប<~)
>> សរុប ¶              // → 1
```

> `p~` គឺជាច្បាប់ចម្លងការងារ — តួអាចផ្តល់តម្លៃឡើងវិញ ហើយអ្នកហៅនៅតែមិនប៉ះពាល់។
> `p<~` គឺជាប៉ារ៉ាម៉ែត្រលទ្ធផល — ការផ្លាស់ប្តូរត្រឡប់មកវិញ។ `បង្កើន(សរុប)` ដោយគ្មានសញ្ញាគឺជាកំហុសន័យ៖ ការកត់ត្រា និងហត្ថលេខាមិនអាចបែកគ្នា។

## ឡាំបដា និងការបិទ

```zymbol
ទ្វេគុណ = x -> x * ២
សរុប = (a, b) -> a + b
>> ទ្វេគុណ(៥) ¶          // → 10
>> សរុប(៣, ៧) ¶          // → 10
```

```zymbol
ចាត់ថ្នាក់ = x -> {
    ? x > ០ { <~ "វិជ្ជមាន" }
    _? x < ០ { <~ "អវិជ្ជមាន" }
    <~ "សូន្យ"
}
>> ចាត់ថ្នាក់(-៤) ¶         // → អវិជ្ជមាន
```

```zymbol
កត្តា = ៣
បីដង = x -> x * កត្តា
>> បីដង(៧) ¶          // → 21
```

```zymbol
បង្កើត_អ្នកបូក(n) { <~ x -> x + n }
បូក១០ = បង្កើត_អ្នកបូក(១០)
>> បូក១០(៥) ¶           // → 15
```

ឡាំបដាអាចមិនយកប៉ារ៉ាម៉ែត្រទាល់តែសោះ៖

```zymbol
ចម្លើយ = () -> ៤២
>> ចម្លើយ() ¶           // → 42
```

> ឡាំបដាចាប់យកអថេរឯកសារ **ពេលវាត្រូវបានបង្កើត** អនុគមន៍មានឈ្មោះអានពួកវា **ពេលវាត្រូវបានហៅ**។

## អារេ

```zymbol
អារេ = [១, ២, ៣, ៤, ៥]
>> អារេ[១] ¶       // → 1   សន្ទស្សន៍ចាប់ពី 1
>> អារេ[-១] ¶      // → 5   អវិជ្ជមានរាប់ពីចុង
>> អារេ$# ¶        // → 5   ប្រវែង
```

```zymbol
អារេ = [១, ២, ៣]
>> (អារេ$+ ៦) ¶          // → [1, 2, 3, 6]   បន្ថែម
>> (អារេ$+[២] ៩៩) ¶      // → [1, 99, 2, 3]  បញ្ចូលត្រង់ទីតាំង 2
>> (អារេ$- ៣) ¶          // → [1, 2]         លុបការកើតឡើងដំបូង
>> (អារេ$-[១]) ¶         // → [2, 3]         លុបនៅសន្ទស្សន៍ 1
>> (អារេ$[១..២]) ¶       // → [1, 2]         កាត់យក ទាំងពីរចុងរាប់បញ្ចូល
>> (អារេ$? ៣) ¶          // → #1             មាន
```

ពួកវាទាំងអស់ចាប់ផ្តើមដោយ `$` ដែលជាសញ្ញានៃ **បណ្តុំ** ហើយបន្តដោយសញ្ញាដែលប្រាប់ថាធ្វើអ្វីក្នុងនោះ៖ `#` ប៉ុន្មាន `+` បន្ថែម `-` លុប `?` សួរថាតើមានឬអត់។ ហើយដូច `??` ការបង្កើនសញ្ញាទ្វេ គឺធ្វើវាឱ្យបានគ្រប់ជ្រុងជ្រោយ៖ `$?` សួរថា *តើ* តម្លៃមួយមានឬអត់ `$??` សួរថា *នៅប៉ុន្មានកន្លែង* ហើយផ្តល់ត្រឡប់ទាំងអស់។

```zymbol
អារេ = [៣, ១, ២]
>> (អារេ$^+) ¶     // → [1, 2, 3]   ឡើង
>> (អារេ$^-) ¶     // → [3, 2, 1]   ចុះ
```

**ច្បាប់នៃលទ្ធផល។** ប្រតិបត្តិករមួយ ហើយអ្វីដែលកូដជុំវិញធ្វើជាមួយវាសម្រេច៖ បើប្រើ **សាងសង់** ហើយទុកដើមដដែល បើបោះចោល **កែប្រែ**។

```zymbol
អារេ = [១, ២, ៣]
ច្បាប់ចម្លង = អារេ[២]$~ ៩៩
>> អារេ ¶                // → [1, 2, 3]
>> ច្បាប់ចម្លង ¶              // → [1, 99, 3]
អារេ[២]$~ ៩៩
>> អារេ ¶                // → [1, 99, 3]
```

> **`=` មិនដែលសរសេរចូលបណ្តុំ។** `អារេ[២] = ៩៩` មិនមែនជាទម្រង់របស់ Zymbol — `=` ផ្តល់តម្លៃទៅ **ឈ្មោះ**។ ការផ្លាស់ប្តូរផ្នែកនៃបណ្តុំគឺ `$~` នៅក្នុងគ្រប់បណ្តុំ។

`[…]` មានប្រភេទតែមួយហើយត្រូវបានពិនិត្យ ការលាយដោយចេតនា **ត្រូវបានប្រកាស** ដោយ `#[…]`៖

```zymbol
លាយ = #[១, "ពីរ", #១]
>> លាយ ¶             // → [1, ពីរ, #1]
>> ([១, ២] == #[១, ២]) ¶ // → #1
```

## សន្ទស្សន៍ពហុវិមាត្រ

`>` ចុះទៅក្នុងរចនាសម្ព័ន្ធបង្កប់។ ក្រុមដង្កៀបមួយដោះស្រាយធាតុមួយ មិនថាជ្រៅប៉ុណ្ណា។

```zymbol
m = [[១,២,៣], [៤,៥,៦], [៧,៨,៩]]
>> m[២>៣] ¶        // → 6   ជួរទី 2 ជួរឈរទី 3
>> m[-១>-១] ¶      // → 9   ជួរចុងក្រោយ ជួរឈរចុងក្រោយ
```

```zymbol
m = [[១,២,៣], [៤,៥,៦], [៧,៨,៩]]
>> m[១>១ ; ២>២ ; ៣>៣] ¶          // → [1, 5, 9]          រាបស្មើ៖ អង្កត់ទ្រូង
>> m[[១>១, ១>៣] ; [៣>១, ៣>៣]] ¶  // → [[1, 3], [7, 9]]   រចនាសម្ព័ន្ធ៖ ជ្រុង
```

```zymbol
m = [[១,២,៣], [៤,៥,៦]]
>> (m[១>២]$~ ៩៩) ¶      // → [[1, 99, 3], [4, 5, 6]]
```

> `m[១][២]` **មិនមែន** ជាទម្រង់របស់ Zymbol។ សន្ទស្សន៍ជាប់គ្នាត្រូវបានបដិសេធ ទាំងការអាន និងការសរសេរ — ក្រុមដង្កៀបមួយសម្រាប់ការចូលប្រើមួយ ហើយ `>` គឺជាអ្វីដែលទៅរវាងជំហាន។

## វចនានុក្រម

ធុប៉ូលដែលមានវាលឈ្មោះ គឺជាវចនានុក្រម ហើយតាំងពី v0.0.9 វាត្រូវបានសរសេរ `#(…)`។

```zymbol
មនុស្ស = #(ឈ្មោះ: "សុភា", អាយុ: ២៥)
>> មនុស្ស.ឈ្មោះ ¶        // → សុភា
>> មនុស្ស["អាយុ"] ¶    // → 25
```

```zymbol
មនុស្ស = #(ឈ្មោះ: "សុភា", អាយុ: ២៥)
វាល = "ឈ្មោះ"
>> មនុស្ស[វាល] ¶     // → សុភា
```

វាអាចផ្លាស់ប្តូរ កូនសោអាចបន្ថែម ហើយវាអាចឆ្លងកាត់បាន៖

```zymbol
ស្តុក = #(ផ្លែពែរ: ៤)
ស្តុក["ផ្លែប៉ោម"]$~ ១០
@ k:ស្តុក { >> k "=" ស្តុក[k] " " }
>> ¶                    // → ផ្លែពែរ=4 ផ្លែប៉ោម=10
```

```zymbol
ស្តុក = #(ផ្លែពែរ: ៤, ផ្លែប៉ោម: ១០)
@ (k, v):ស្តុក { >> k ":" v " " }
>> ¶                    // → ផ្លែពែរ:4 ផ្លែប៉ោម:10
```

> `#()` គឺជាវចនានុក្រមទទេ ដែល `()` មិនអាចជា — វានឹងត្រូវជាធុប៉ូលទទេផងដែរ។ `(x: 1)` អាក្រាតត្រូវបានបដិសេធដោយសារនេះ៖ *a dictionary is written `#(…)`* — «វចនានុក្រមត្រូវបានសរសេរ `#(…)`»។
> វចនានុក្រមត្រូវបានដោះស្រាយដោយកូនសោ មិនដែលដោយទីតាំង ដូច្នេះ `មនុស្ស[1]` គឺជាកំហុស។

## ធុប៉ូល

ធុប៉ូលគឺជាធុងរៀបជាលំដាប់ **មិនអាចផ្លាស់ប្តូរ** ដែលផ្ទុកតម្លៃប្រភេទផ្សេងៗគ្នា។

```zymbol
ចំណុច = (១០, ២០)
>> ចំណុច[១] ¶           // → 10
ទិន្នន័យ = (៤២, "សួស្តី", #១, ៣.១៤)
>> ទិន្នន័យ[៣] ¶            // → #1
```

```zymbol
t = (១០, ២០, ៣០)
t2 = t[២]$~ ៩៩៩
>> t ¶                  // → (10, 20, 30)
>> t2 ¶                 // → (10, 999, 30)
```

> ការប៉ុនប៉ងណាមួយដើម្បីកែប្រែធុប៉ូលនៅនឹងកន្លែង គឺជាកំហុស មិនថាប្រតិបត្តិករណា — ភាពមិនអាចផ្លាស់ប្តូរគឺជាលក្ខណសម្បត្តិនៃតម្លៃ មិនមែនជាការលើកលែងក្នុង `$` នីមួយៗទេ។

## ការបំបែករចនាសម្ព័ន្ធ

```zymbol
អារេ = [១០, ២០, ៣០, ៤០, ៥០]
[a, b, c] = អារេ
>> a " " b " " c ¶      // → 10 20 [30, 40, 50]
```

```zymbol
អារេ = [១០, ២០, ៣០, ៤០, ៥០]
[ទីមួយ, *នៅសល់] = អារេ
>> ទីមួយ ¶            // → 10
>> នៅសល់ ¶              // → [20, 30, 40, 50]
```

```zymbol
ចំណុច = (១០០, ២០០)
(px, py) = ចំណុច
>> px " " py ¶          // → 100 200
```

```zymbol
មនុស្ស = #(ឈ្មោះ: "ដារា", អាយុ: ២៥)

>> n " " a ¶            // → ដារា 25
```

> រូបរាងដង្កៀបត្រូវបានកំណត់ប្រភេទ៖ `[…]` យកអារេ `(…)` ធុប៉ូល `#(…)` វចនានុក្រម។ ឈ្មោះចុងក្រោយ **ស្រូបយកអ្វីដែលនៅសល់** ដូច្នេះការបំបែកមិនដែលបរាជ័យដោយសារប្រវែង — `(a, b, c) = (1,2,3,4,5)` ផ្តល់ `c = (3,4,5)` ហើយ `##_` ពេលគ្មានអ្វីនៅសល់។

## អនុគមន៍ថ្នាក់ខ្ពស់

```zymbol
លេខ = [១, ២, ៣, ៤, ៥]
>> (លេខ$> (x -> x * ២)) ¶ // → [2, 4, 6, 8, 10]
>> (លេខ$| (x -> x % ២ == ០)) ¶ // → [2, 4]
>> (លេខ$< (០, (បូកបន្ថែម, x) -> បូកបន្ថែម + x)) ¶ // → 15
```

```zymbol
លេខ = [១, ២, ៣, ៤, ៥, ៦]
ទ្វេគុណ(x) { <~ x * ២ }
ធំ(x) { <~ x > ៣ }
>> (លេខ$> ទ្វេគុណ) ¶    // → [2, 4, 6, 8, 10, 12]
>> (លេខ$| ធំ) ¶    // → [4, 5, 6]
```

```zymbol
មូលដ្ឋាន = [#(ឈ្មោះ: "កាឡា", អាយុ: ២៨), #(ឈ្មោះ: "ដារា", អាយុ: ២៥)]
តាមអាយុ = មូលដ្ឋាន$^ (a, b -> a.អាយុ < b.អាយុ)
>> តាមអាយុ[១].ឈ្មោះ ¶     // → ដារា
```

> អនុគមន៍មានឈ្មោះទៅ HOF **ដោយគ្មានដង្កៀប**៖ `លេខ$> ទ្វេគុណ`។ ការសរសេរ `លេខ$> (ទ្វេគុណ)` គឺជាកំហុសញែកចេញ ព្រោះ `(` បើកឡាំបដា។

> ការបរាជ័យបណ្ណាល័យស្តង់ដារត្រឡប់មកវិញជា **តម្លៃកំហុសទន់** ដែលអ្នកសាកល្បងដោយ `$!` ឬចាប់ដោយ `!?` ជំនួសការបញ្ឈប់។ `$!!` ផ្សព្វផ្សាយមួយទៅអ្នកហៅ។

## ម៉ូឌុល

```zymbol
# គណនា {
    #> { បូក, PI }

    PI := ៣.១៤១៥៩
    បូក(a, b) { <~ a + b }
}
```

```zymbol
<# ./គណនា => គ

>> គ::បូក(៥, ៣) ¶
>> គ.PI ¶
```

```zymbol
# បណ្ណាល័យខ្ញុំ {
    #> { បូកខាងក្នុង => សរុប }

    បូកខាងក្នុង(a, b) { <~ a + b }
}
```

សញ្ញាម៉ូឌុលទាំងពីរគឺជាគំនិតដូចគ្នា ឥឡូវនេះអនុវត្តចំពោះឯកសារ៖ `#` គឺជាកម្រិតនៃ **ការប្រកាស** — អ្វីដែលវត្ថុមួយ *ជា* មិនមែនតម្លៃរបស់វា — ហើយព្រួញប្រាប់ទិសដៅដែលកូដធ្វើដំណើរ៖

```text
<#   ព្រួញចូល៖ នាំចូល យកពីឯកសារផ្សេង
#>   ព្រួញចេញ៖ នាំចេញ ផ្តល់ជូនឯកសារផ្សេង
```

សញ្ញាទិសដៅតែងតែអង្គុយនៅគែមដែលបែរមុខទៅទិសដែលវាចង្អុល។ នេះជាហេតុផលដូចគ្នាដែល `<~` ត្រឡប់ទៅឆ្វេង (ចេញពីអនុគមន៍) ហើយ `->` ចូលទៅស្តាំ (ចូលក្នុងតួឡាំបដា)។

> **ម៉ូឌុលប្រកាសអ្វីដែលវានាំចេញ។** ប្លុក `#>` គឺចាំបាច់ — ការបោះបង់វាគឺ **E014** ហើយ `#> { }` គឺជាវិធីដែលម៉ូឌុលប្រាប់ថាផ្ទៃរបស់វាទទេ។ `::` ហៅអនុគមន៍ `.` អានថេរ។ មានតែការនាំចូល ប្លុកនាំចេញ ការចាប់ផ្តើមផ្ទាល់ និងនិយមន័យអនុគមន៍ប៉ុណ្ណោះដែលអាចបង្ហាញក្នុងតួម៉ូឌុល អ្វីដែលអាចប្រតិបត្តិបានគឺ **E013**។

## បណ្ណាល័យស្តង់ដារ

## របៀបលេខ

Zymbol អាចសរសេរលេខជា **អក្សរលេខយូនីកូដ 69** — ទេវនាគរី អារ៉ាប់-ឥណ្ឌា ថៃ គ្លីនហ្គុន pIqaD គណិតវិទ្យាដិត ចម្រៀក LCD និងច្រើនទៀត។ របៀបគឺសកលសម្រាប់ដំណើរការ ហើយប៉ះពាល់លទ្ធផល នព្វន្ធមិនផ្លាស់ប្តូរទេ។

```zymbol
#០៩#    // ខ្មែរ       (U+17E0–U+17E9)
#०९#    // ទេវនាគរី    (U+0966–U+096F)
#٠٩#    // អារ៉ាប់-ឥណ្ឌា (U+0660–U+0669)
#09#    // កំណត់ត្រឡប់ទៅ ASCII
```

```zymbol
x = ៤២
>> x ¶                  // → 42
#០៩#
>> x ¶                  // → ៤២
>> ៣.១៤ ¶               // → ៣.១៤
>> #១ ¶                 // → #១
#09#
```

ខ្ទង់នៃអក្សរដែលគាំទ្រណាមួយ គឺជាតម្លៃផ្ទាល់ត្រឹមត្រូវក្នុងប្រភព៖

```zymbol
#០៩#
@ i:១..៥ { >> i " " }
>> ¶                    // → ១ ២ ៣ ៤ ៥
#09#
```

ការអានគឺស៊ីមេទ្រី — ខ្ទង់ត្រូវបានយល់ក្នុងអក្សរណាមួយ៖

```zymbol
>> #|"४२"| ¶            // → 42
>> #|'७'| ¶             // → 7
```

> `#` គឺ ASCII ជានិច្ច ដូច្នេះ `#0` នៅតែខុសគ្នាដោយមើលឃើញពីខ្ទង់សូន្យក្នុងរាល់អក្សរ។
> `#,` និង `#^` ក៏សរសេរខ្ទង់របស់ពួកវាក្នុងអក្សរសកម្ម ហើយអ្នកបំបែកដើរតាមវា — ប៉ុន្តែគូមិនដែលបញ្ច្រាស់ទេ៖ `,` ដាក់ក្រុម ហើយ `.` បែងចែក ក្នុងរាល់អក្សរ។

## ប្រតិបត្តិករទិន្នន័យ

```zymbol
f = ##.៤២         // ទៅចំនួនទសភាគ
i = ###៣.៧        // ទៅចំនួនគត់ បង្គត់  → 4
t = ##!៣.៧        // ទៅចំនួនគត់ កាត់  → 3
>> f " " i " " t ¶      // → 42 4 3
>> f#? ¶                // → (##., 2, 42)
```

> ចំនួនទសភាគបោះពុម្ពជាខ្ទង់ មិនដែលជានិទស្សន្ត ហើយបោះបង់ `.0` ចុងក្រោយ — `##.42` សរសេរ `42` ហើយនៅតែជាចំនួនទសភាគ ដូច `f#?` បង្ហាញ។

```zymbol
>> #|"42"| ¶       // → 42
>> #|"abc"| ¶      // → abc   សុវត្ថិភាព៖ ផ្តល់ត្រឡប់ការបញ្ចូលដោយមិនប្តូរ
>> ##!'A' ¶        // → 65    ចំណុចកូដនៃតួអក្សរ
```

```zymbol
pi = ៣.១៤១៥៩២៦៥
>> #.២|pi| ¶       // → 3.14          បង្គត់ទៅ 2 ខ្ទង់ទសភាគ
>> #!២|pi| ¶       // → 3.14          កាត់ទៅ 2 ខ្ទង់ទសភាគ
>> #,|១២៣៤៥៦៧| ¶   // → 1,234,567     សញ្ញាបំបែកពាន់
>> #^|១២៣៤៥.៦៧៨| ¶ // → 1.2345678e4  ការសរសេរវិទ្យាសាស្ត្រ
```

```zymbol
>> 0x41 ¶        // → A   គោលដប់ប្រាំមួយ
>> 0b01000001 ¶  // → A   គោលពីរ
>> 0o101 ¶       // → A   គោលប្រាំបី
>> 0d65 ¶        // → A   គោលដប់
```

> តម្លៃផ្ទាល់គោលក្នុងជួរ ASCII គឺជា **តួអក្សរ**៖ `0d65 == 'A'` គឺ `#1` ហើយ `0d65 == 65` គឺ `#0`។ គោលទាំងបួនសរសេរតួអក្សរដូចគ្នា។

## របៀបដែលសញ្ញារួមបញ្ចូលគ្នា

អ្នកបានឃើញរឿងដូចគ្នាពេញសៀវភៅនេះ៖ **ប្រតិបត្តិករមួយមិនមែនជាគំនូរត្រូវចងចាំទេ វាជាសញ្ញាជាច្រើនជាប់គ្នា ហើយម្នាក់ៗរួមចំណែកអត្ថន័យរបស់វា។** ឥឡូវនេះអ្នកស្គាល់ពួកវាទាំងអស់ នេះគឺជាលំនាំពេញលេញ។

ដំបូងមក **យើងនៅក្នុងពិភពណា**៖

| សញ្ញា | ពិភព | អ្នកបានឃើញវានៅ |
|--------|-------|----------------------------|
| `$` | បណ្តុំមួយ | `$#` `$+` `$?` `$^-` |
| `@` | ពេលវេលា អ្វីៗដែលកើតឡើងម្តងទៀត | `@!` `@>` `@~` |
| `#` | អ្វីដែលវត្ថុមួយ *ជា* មិនមែនតម្លៃរបស់វា | `#?` `#(…)` `<#` `#>` |
| `>>` | ចេញពីកម្មវិធី | `>>` `>>!` `>>?` |
| `<<` | ចូលក្នុងកម្មវិធី | `<<` `<<\|` `<<\|?` |
| `?` | សួរ ដោយមិនប្តេជ្ញា | `?` `_?` `??` `$?` |
| `!` | កម្លាំង ឬកំហុស | `@!` `$!` `!?` |

បន្ទាប់មក **អ្វីដែលធ្វើនៅទីនោះ**៖ `+` បន្ថែម `-` លុប `^` តម្រៀប `~` កែប្រែ `#` រាប់ `|` ឯកតាមួយ `:` ចងឈ្មោះ។

ហើយច្បាប់ពីរដែលមិនដែលបរាជ័យ៖

**ការបង្កើនសញ្ញាទ្វេ ធ្វើឱ្យវាគ្រប់ជ្រុងជ្រោយ។** `?` សួរម្តង `??` សាកល្បងករណីច្រើន។ `$?` សួរថាតើតម្លៃមាន `$??` ផ្តល់ត្រឡប់គ្រប់កន្លែងដែលវាមាន។ `!` សម្គាល់កំហុស `!!` ផ្សព្វផ្សាយវាដោយមិនសួរ។

**សញ្ញារបៀបមកចុងក្រោយជានិច្ច។** ពេល `?` ឬ `!` លេចឡើងដើម្បីប្រាប់ *របៀប* ដែលអ្វីមួយត្រូវធ្វើ — ដោយសង្ស័យ ឬដោយកម្លាំង — ពួកវាជាសញ្ញាចុងក្រោយនៃប្រតិបត្តិករ៖ `$??` `$!!` `<<|?` `@!` `##!` `>>!` `>>?` `@:ខាងក្រៅ!`។ គ្មានប្រតិបត្តិការណាមួយបន្ទាប់ពីពួកវាទេ។

អ្វីដែលជាក់ស្តែងកើតឡើងពីនោះ៖ **ការរួមបញ្ចូលដែលអ្នកមិនធ្លាប់ឃើញ មានន័យរួចហើយមុនពេលអ្នកមើលវា។** បើ `$` ជាបណ្តុំ ហើយ `^` ជាលំដាប់ ហើយ `-` ជាបញ្ច្រាស នោះ `$^-` តម្រៀបចុះ ហើយគ្មាននរណាត្រូវប្រាប់អ្នកទេ។

មិនមែនបញ្ជីទាំងមូលដំណើរការដូច្នេះទេ ហើយការនិយាយបែបនេះប្រសើរជាងការធ្វើពុត។ ប្រតិបត្តិករភាគច្រើនបំបែកចេញយ៉ាងស្អាត។ ប្រាំមួយបំបែកចេញ ប៉ុន្តែមានន័យលើសពីផ្នែករបស់វា៖ `!?` `:!` `:>` `|>` `::` `$++`។ ហើយដប់ត្រូវចងចាំ ព្រោះវាមិនបំបែកចេញទាល់តែសោះ៖ `¶` `><` `#1` `#0` `0x` `0b` `0o` `0d` `###` `°`។
