## ಚರಗಳು ಮತ್ತು ಸ್ಥಿರಾಂಕಗಳು

```zymbol
ಚರ = ೧೦              // ಬದಲಾಯಿಸಬಹುದಾದ ಚರ
PI := ೩.೧೪೧೫೯       // ಸ್ಥಿರಾಂಕ — ಮರು ನಿಯೋಜನೆ ರನ್‌ಟೈಮ್ ದೋಷ
ಹೆಸರು = "ಅರ್ಜುನ"
ಸಕ್ರಿಯ = #೧         // ಬೂಲಿಯನ್ ಸತ್ಯ
👋 := "ನಮಸ್ಕಾರ"
```

```zymbol
ಚರ = ೧೦    // ೧೦
ಚರ += ೫    // ೧೫
ಚರ -= ೩    // ೧೨
ಚರ *= ೨    // ೨೪
ಚರ /= ೩    // ೮
ಚರ %= ೩    // ೨
ಚರ ^= ೨    // ೪
ಚರ++       // ೫
ಚರ--       // ೪
```

`°` (ಡಿಗ್ರಿ ಚಿಹ್ನೆ, U+00B0) ಮೊದಲ ಬಳಕೆಯಲ್ಲಿ ಚರವನ್ನು ಅದರ ತಟಸ್ಥ ಮೌಲ್ಯಕ್ಕೆ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಪ್ರಾರಂಭಿಸುತ್ತದೆ:

```zymbol
ಸಂಖ್ಯೆಗಳು = [೩, ೧, ೪, ೧, ೫]
@ n:ಸಂಖ್ಯೆಗಳು {
    °ಒಟ್ಟು += n
}
>> ಒಟ್ಟು ¶              // → 14
```

> `°ಚರ` (ಉಪಸರ್ಗ) ಲೂಪ್‌ನ ಮೇಲೆ ಆಂಕರ್ ಮಾಡುತ್ತದೆ — ಫಲಿತಾಂಶ `@` ನಂತರ ಓದಬಹುದಾಗಿದೆ.
> `ಚರ°` (ಪ್ರತ್ಯಯ) ಲೂಪ್‌ನ ಒಳಗೆ ಆಂಕರ್ ಮಾಡುತ್ತದೆ — ಲೂಪ್ ಮುಗಿದಾಗ ಅದು ಸಾಯುತ್ತದೆ.

ಕೇವಲ ಹೆಸರಾಗಿರುವ ಹೇಳಿಕೆ ಚರವನ್ನು ಓದಿ ಮೌಲ್ಯವನ್ನು ಎಸೆಯುತ್ತದೆ, ಆದ್ದರಿಂದ ಎಚ್ಚರಿಕೆ ನೀಡುತ್ತದೆ:

```zymbol
ಎಣಿಕೆ = ೫
ಎಣಿಕೆ
```

ಸಂಕಲಕ ಈ ರೀತಿ ಎಚ್ಚರಿಕೆ ನೀಡುತ್ತದೆ (ಅದರ ಸಂದೇಶಗಳು ಯಾವಾಗಲೂ ಇಂಗ್ಲಿಷ್‌ನಲ್ಲಿರುತ್ತವೆ):

```text
warning: this statement does nothing: 'ಎಣಿಕೆ' is read and discarded
  = help: remove it, or use it — `>> name ¶` to print it
```

ಅಂದರೆ: *«ಈ ಹೇಳಿಕೆ ಏನನ್ನೂ ಮಾಡುವುದಿಲ್ಲ: 'ಎಣಿಕೆ' ಓದಲಾಗಿ ವಿಸರ್ಜಿಸಲಾಗಿದೆ»*.

## ಡೇಟಾ ಪ್ರಕಾರಗಳು

| ಪ್ರಕಾರ | ಅಕ್ಷರಶಃ | `#?` ಟ್ಯಾಗ್ | ಟಿಪ್ಪಣಿಗಳು |
|------|---------|----------|-------|
| ಪೂರ್ಣಾಂಕ | `೪೨`, `-೭` | `###` | ಸುರಕ್ಷಿತ ಪೂರ್ಣಾಂಕ: ±(2⁵³ − 1) |
| ದಶಮಾಂಶ | `೩.೧೪`, `೧.೫e೧೦` | `##.` | IEEE-754 ದ್ವಿಗುಣ |
| ಸ್ಟ್ರಿಂಗ್ | `"ಪಠ್ಯ"` | `##"` | ಅಂತರ್ವೇಶನ: `"ನಮಸ್ಕಾರ {ಹೆಸರು}"` |
| ಅಕ್ಷರ | `'A'` | `##'` | ಒಂದು ಯುನಿಕೋಡ್ ಕೋಡ್ ಪಾಯಿಂಟ್ |
| ಬೂಲಿಯನ್ | `#೧`, `#೦` | `##?` | ಸಂಖ್ಯಾತ್ಮಕ ಅಲ್ಲ — `#೧ ≠ ೧` |
| ಶ್ರೇಣಿ | `[೧, ೨, ೩]` | `##]` | ಒಂದು ಪ್ರಕಾರ, ಪರಿಶೀಲಿಸಲಾಗಿದೆ |
| ಘೋಷಿತ ಮಿಶ್ರಣ | `#[೧, "ಎರಡು"]` | `##[` | `[…]` ನಂತೆಯೇ ಪ್ರಕಾರ, ಪರಿಶೀಲನೆ ಇಲ್ಲ |
| ಟ್ಯೂಪಲ್ | `(a, b)` | `##)` | ಸ್ಥಾನಿಕ, ಬದಲಾಯಿಸಲಾಗದ |
| ನಿಘಂಟು | `#(a: ೧, b: ೨)` | `##(` | ಕೀ-ಆಧಾರಿತ, ಬದಲಾಯಿಸಬಹುದಾದ |
| ಫಂಕ್ಷನ್ | ಹೆಸರಿನ ಫಂಕ್ಷನ್ ಉಲ್ಲೇಖ | `##()` | ಪ್ರಥಮ-ದರ್ಜೆ; ತೋರಿಸುತ್ತದೆ `<funct/N>` |
| ಲ್ಯಾಂಬ್ಡಾ | `a -> a * ೨` | `##->` | ಪ್ರಥಮ-ದರ್ಜೆ; ತೋರಿಸುತ್ತದೆ `<lambd/N>` |
| ಘಟಕ | `##_` | `##_` | ಅನುಪಸ್ಥಿತಿ — null ಇಲ್ಲ |

```zymbol
>> ೪೨#? ¶               // → (###, 2, 42)
>> [೧, ೨, ೩]#? ¶        // → (##], 3, [1, 2, 3])
>> #(a: ೧)#? ¶          // → (##(, 1, #(a: 1))
```

ಸುರಕ್ಷಿತ ವ್ಯಾಪ್ತಿಯಿಂದ ಹೊರಗೆ ಹೋಗುವ ಪೂರ್ಣಾಂಕವು ಹಿಡಿಯಬಹುದಾದ ದೋಷ, ಎಂದಿಗೂ ಮೌನ ಸುತ್ತುವಿಕೆ ಅಲ್ಲ:

```zymbol
!? {
    >> (೯೦೦೭೧೯೯೨೫೪೭೪೦೯೯೧ + ೧) ¶
} :! ##Range {
    >> "ವ್ಯಾಪ್ತಿಯ ಹೊರಗೆ" ¶ // → ವ್ಯಾಪ್ತಿಯ ಹೊರಗೆ
}
```

`##_` ಒಂದು ಪ್ರೋಗ್ರಾಂ ಏನಾದರೂ ಇಲ್ಲವೇ ಎಂದು ಕೇಳುವ ವಿಧಾನ:

```zymbol
ಏನೂ_ಇಲ್ಲ() { }
ಮೌಲ್ಯ = ಏನೂ_ಇಲ್ಲ()
>> (ಮೌಲ್ಯ == ##_) ¶     // → #1
```

## ಔಟ್‌ಪುಟ್ ಮತ್ತು ಇನ್‌ಪುಟ್

```zymbol
ಹೆಸರು = "ಅರ್ಜುನ"
ಒಟ್ಟು = ೩
>> "ನಮಸ್ಕಾರ" ¶             // → ನಮಸ್ಕಾರ
>> "a=" ಹೆಸರು " b=" ಒಟ್ಟು ¶ // → a=ಅರ್ಜುನ b=3
>> ಒಟ್ಟು#? ¶            // → (###, 1, 3)
```

```zymbol
<< ಹೆಸರು
<< "ನಿಮ್ಮ ಹೆಸರು ನಮೂದಿಸಿ: " ಹೆಸರು
<< ###(೪) "ವಯಸ್ಸು: " ವಯಸ್ಸು
```

**ಎರಡು ಚಿಹ್ನೆಗಳ ಆಕಾರವನ್ನು ನೋಡಿ.** `>>` ಹೊರಕ್ಕೆ ತೋರಿಸುತ್ತದೆ: ಅದು ಡೇಟಾವನ್ನು ಪ್ರೋಗ್ರಾಂನಿಂದ ಹೊರತೆಗೆಯುತ್ತದೆ. `<<` ಒಳಕ್ಕೆ ತೋರಿಸುತ್ತದೆ: ಅದು ಡೇಟಾವನ್ನು ಪ್ರೋಗ್ರಾಂಗೆ ತರುತ್ತದೆ. ಇಲ್ಲಿ ನೆನಪಿಡಲು ಏನೂ ಇಲ್ಲ — ಬಾಣವು ಮಾಹಿತಿ ಯಾವ ದಿಕ್ಕಿನಲ್ಲಿ ಚಲಿಸುತ್ತದೆ ಎಂದು ತೋರಿಸುತ್ತದೆ, ಮತ್ತು ಅದೇ ಕಲ್ಪನೆ ಏನನ್ನಾದರೂ ಚಲಿಸುವ ಪ್ರತಿ ಚಿಹ್ನೆಯಲ್ಲೂ ಮರಳಿ ಬರುತ್ತದೆ.

> `¶` ಮತ್ತು `\\` ಸಮಾನ ಹೊಸ ಸಾಲುಗಳು. `>>` ಎಂದಿಗೂ ಒಂದನ್ನು ಸೇರಿಸುವುದಿಲ್ಲ.
> ಪ್ರಾಂಪ್ಟ್‌ನ ಮೊದಲು ಪ್ರಕಾರ ನಿರ್ದಿಷ್ಟಕವು ಓದುವಾಗ ಮೌಲ್ಯವನ್ನು ಪರಿಶೀಲಿಸುತ್ತದೆ ಮತ್ತು ಮೌಲ್ಯ ಮಾನ್ಯವಾಗುವವರೆಗೆ ಮತ್ತೆ ಕೇಳುತ್ತದೆ:
> `##.` ದಶಮಾಂಶ · `##.(T,D)` ದಶಮ · `###(N)` ಪೂರ್ಣಾಂಕ · `##"(N)"` ಪಠ್ಯ · `##'` ಒಂದು ಅಕ್ಷರ.

ಫೈಲ್‌ನ ಮೇಲ್ಮಟ್ಟದಲ್ಲಿ, `<~>` ಪ್ರೋಗ್ರಾಂನ ನಿರ್ಗಮನ ಸ್ಥಿತಿ:

```zymbol
>> "ಪರಿಶೀಲಿಸುತ್ತಿದೆ" ¶      // → ಪರಿಶೀಲಿಸುತ್ತಿದೆ
<~ ೦
```

## TUI ಆದಿಮಗಳು

ಸಂವಾದಾತ್ಮಕ ಪ್ರೋಗ್ರಾಂಗಳಿಗಾಗಿ ಟರ್ಮಿನಲ್ UI ನಿರ್ವಾಹಕಗಳು. ಬಹುಪಾಲು `>>| { }` ಬ್ಲಾಕ್ ಅಗತ್ಯವಿದೆ (ಪರ್ಯಾಯ ಪರದೆ + ಕಚ್ಚಾ ಮೋಡ್).

```zymbol
>>| {
    >>!
    >>~ (೧, ೧, ೦, ೧೦) > "ಚಾಲನೆಯಲ್ಲಿದೆ"
    @~ ೧೦೦೦
    >>~ (೨, ೧) > "ಮುಗಿಯಿತು."
}
```

```zymbol
>>| {
    [ಸಾಲುಗಳು, ಅಂಕಣಗಳು] = >>?
    >>~ (೧, ೧) > "ಟರ್ಮಿನಲ್: " ಸಾಲುಗಳು " x " ಅಂಕಣಗಳು
    <<| ಕೀಲಿ
    >>~ (೨, ೧) > "ಒತ್ತಿದ್ದೀರಿ: " ಕೀಲಿ
}
```

ಇಲ್ಲಿ ಚಿಹ್ನೆಗಳು ಏಕೆ ಗುಣಿಸುವ ಬದಲು ಸೇರಿಕೊಳ್ಳುತ್ತವೆ ಎಂದು ನೀವು ನೋಡಬಹುದು. `<<` ಇನ್‌ಪುಟ್ ಮತ್ತು `?` ಬದ್ಧತೆ ಇಲ್ಲದೆ ಕೇಳುತ್ತದೆ ಎಂದು ನಿಮಗೆ ಈಗಾಗಲೇ ತಿಳಿದಿದೆ. ಕೇವಲ ಒಂದು ಚಿಹ್ನೆ ಹೊಸದು:

- `|` ಒಂದು **ಏಕ ಘಟಕ**, ಇಡೀ ಹರಿವಲ್ಲ.

ಅದರೊಂದಿಗೆ, ಎರಡೂ ಕೀಬೋರ್ಡ್ ನಿರ್ವಾಹಕಗಳು ತಾವೇ ಓದಿಕೊಳ್ಳುತ್ತವೆ:

```text
<<        |             ?
ಇನ್‌ಪುಟ್  ಒಂದು ಘಟಕ      ಬದ್ಧತೆ ಇಲ್ಲದೆ

<<|   ಒಂದು ಕೀಲಿ ತೆಗೆದುಕೊಳ್ಳಿ, ಮತ್ತು ಒಂದು ಬರುವವರೆಗೆ ಕಾಯಿರಿ
<<|?  ಒಂದು ಕೀಲಿ ಇದೆಯೇ ಎಂದು ನೋಡಿ, ಇಲ್ಲದಿದ್ದರೆ ಮುಂದುವರಿಸಿ
```

ಇನ್ನೊಂದು ಬದಿಯಲ್ಲೂ ಅದೇ: `>>` ಕಳುಹಿಸುತ್ತದೆ, `>>!` **ಬಲವಂತವಾಗಿ** ಕಳುಹಿಸುತ್ತದೆ (ಇಡೀ ಪರದೆಯನ್ನು ಅಳಿಸುತ್ತದೆ), ಆದರೆ `>>?` ಬರೆಯುವ ಬದಲು **ಕೇಳುತ್ತದೆ** (ಟರ್ಮಿನಲ್ ಎಷ್ಟು ದೊಡ್ಡದು). ಬಲಭಾಗದಲ್ಲಿರುವ ಚಿಹ್ನೆ ಮೋಡ್ ಅನ್ನು ಬದಲಾಯಿಸುವುದು, ಮತ್ತು ಅದು ಯಾವಾಗಲೂ ಕೊನೆಯಲ್ಲಿ ಬರುತ್ತದೆ.

> `>>!` ಪರದೆಯನ್ನು ಅಳಿಸುತ್ತದೆ. `>>?` `[ಸಾಲುಗಳು, ಅಂಕಣಗಳು]` ಹಿಂತಿರುಗಿಸುತ್ತದೆ. `@~ N` N ಮಿಲಿಸೆಕೆಂಡುಗಳು ನಿದ್ರಿಸುತ್ತದೆ.
> `<<|` ಒಂದು ಕೀಲಿ ಒತ್ತುವಿಕೆಯನ್ನು ಓದುತ್ತದೆ (ನಿರ್ಬಂಧಿಸುವ); `<<|?` ನಿರ್ಬಂಧಿಸದೆ ಪೋಲ್ ಮಾಡುತ್ತದೆ (`'\0'` ಯಾವುದೂ ಇಲ್ಲದಿದ್ದರೆ).
> ಬಾಣ ಕೀಲಿಗಳು `'↑' '↓' '←' '→'` ಎಂದು ಡಿಕೋಡ್ ಆಗುತ್ತವೆ; ESC ಕೋಡ್ ಪಾಯಿಂಟ್ 27.
> ಸ್ಥಾನಿಕ ಔಟ್‌ಪುಟ್ ಟ್ಯೂಪಲ್: `(ಸಾಲು, ಅಂಕಣ, BKS, ಮುಂಭಾಗ, ಹಿಂಭಾಗ)` — ಯಾವುದೇ ಸ್ಲಾಟ್ ಅನ್ನು ಅಲ್ಪವಿರಾಮದಿಂದ ಬಿಡಬಹುದು (`>>~ (,,, ೧೯೬) > "ಕೆಂಪು"`).
> BKS ಬಿಟ್‌ಮಾಸ್ಕ್: `1`=ದಪ್ಪ, `2`=ಓರೆ, `4`=ಅಡಿಗೆರೆ. ANSI 256-ಬಣ್ಣಗಳ ಪ್ಯಾಲೆಟ್ (`0`=ಟರ್ಮಿನಲ್ ಡಿಫಾಲ್ಟ್).

## ನಿರ್ವಾಹಕಗಳು

```zymbol
a = ೧೦
b = ೩
ಫ೧ = a + b    // ೧೩
ಫ೨ = a - b    // ೭
ಫ೩ = a * b    // ೩೦
ಫ೪ = a / b    // ೩  (ಪೂರ್ಣಾಂಕ ವಿಭಜನೆ)
ಫ೫ = a % b    // ೧
ಫ೬ = a ^ b    // ೧೦೦೦
```

```zymbol
a = ೧೦
b = ೩
ಹ೧ = a == b    // #೦
ಹ೨ = a <> b    // #೧
ಹ೩ = a < b     // #೦
ಹ೪ = a >= b    // #೧
ತ೧ = #೧ && #೦  // #೦
ತ೨ = !#೧       // #೦
```

> `==` ಎಂದಿಗೂ ಬಲವಂತ ಮಾಡುವುದಿಲ್ಲ: `"5" == 5` ಎಂಬುದು `#0`. ಕ್ರಮವು ಬಲವಂತ ಮಾಡುತ್ತದೆ: `"5" > 4` ಎಂಬುದು `#1`, ಮತ್ತು `"४२" > 5` ಕೂಡ — 69 ಲಿಪಿಗಳಲ್ಲಿ ಯಾವುದಾದರೂ ಸಂಖ್ಯಾತ್ಮಕ ಪಠ್ಯವು ಸಂಖ್ಯೆಯಾಗಿ ಹೋಲಿಕೆ ಮಾಡುತ್ತದೆ.
> ಒಂದು ಫಂಕ್ಷನ್ ತನಗೆ ಮಾತ್ರ ಸಮಾನ, ಅದೇ ದೇಹವನ್ನು ಹೊಂದಿರುವ ಇನ್ನೊಂದು ಫಂಕ್ಷನ್‌ಗೆ ಎಂದಿಗೂ ಸಮಾನವಲ್ಲ.

## ಸ್ಟ್ರಿಂಗ್‌ಗಳು

```zymbol
ಹೆಸರು = "ಅರ್ಜುನ"
n = ೪೨
>> "ನಮಸ್ಕಾರ " ಹೆಸರು " ನಿಮ್ಮ ಬಳಿ " n " ಇದೆ" ¶ // → ನಮಸ್ಕಾರ ಅರ್ಜುನ ನಿಮ್ಮ ಬಳಿ 42 ಇದೆ
ವಿವರಣೆ = "ನಮಸ್ಕಾರ {ಹೆಸರು}, ನಿಮ್ಮ ಬಳಿ {n} ಇದೆ"
>> ವಿವರಣೆ ¶              // → ನಮಸ್ಕಾರ ಅರ್ಜುನ, ನಿಮ್ಮ ಬಳಿ 42 ಇದೆ
```

```zymbol
s = "ನಮಸ್ಕಾರ ಜಗತ್ತು"
ಉದ್ದ = s$#                  // ೧೪
ಭಾಗ = s$[೧..೬]             // "ನಮಸ್ಕಾ"
ಇದೆ = s$? "ಜಗತ್ತು"          // #೧
ತುಣುಕುಗಳು = "a,b,c,d"$/ ','    // [a, b, c, d]
ಬದಲಾವಣೆ = s$~~["ಾ":"ೀ"]        // "ನಮಸ್ಕೀರ ಜಗತ್ತು"
ರೇಖೆ = "─" $* ೨೦
```

> `+` ಸಂಖ್ಯೆಗಳಿಗೆ ಮಾತ್ರ. ಸ್ಟ್ರಿಂಗ್‌ಗಳಿಗೆ ಪಕ್ಕಪಕ್ಕ ಅಥವಾ ಅಂತರ್ವೇಶನ ಬಳಸಿ.
> `\{` ಮತ್ತು `\}` ಅಕ್ಷರಶಃ ಸುರುಳಿ ಆವರಣಗಳು — ತಪ್ಪಿಸುವಿಕೆ ಸಮ್ಮಿತೀಯ.

## ನಿಯಂತ್ರಣ ಹರಿವು

```zymbol
a = ೭
? a > ೧೦೦ {
    >> "ದೊಡ್ಡದು" ¶
} _? a > ೦ {
    >> "ಧನಾತ್ಮಕ" ¶     // → ಧನಾತ್ಮಕ
} _ {
    >> "ಋಣಾತ್ಮಕ" ¶
}
```

ಇಲ್ಲಿ ಎರಡು ಹೊಸ ಚಿಹ್ನೆಗಳಿವೆ, ಮತ್ತು ಮೂರನೆಯದು ಅವುಗಳನ್ನು ಒಟ್ಟಿಗೆ ಇಟ್ಟಾಗ ಬರುತ್ತದೆ:

- `?` **ಕೇಳುವುದು**: ಅದು ಷರತ್ತನ್ನು ತೆರೆಯುತ್ತದೆ.
- `_` **ನಿರ್ದಿಷ್ಟಪಡಿಸದಿರುವುದು**: ಯಾವ ಪ್ರಶ್ನೆಯೂ ಹೊಂದಿಕೆಯಾಗದಿದ್ದಾಗ ಉಳಿಯುವ ಶಾಖೆ.
- `_?` ಎರಡೂ ಸತತವಾಗಿ: *ಏನೂ ಹೊಂದಿಕೆಯಾಗದಿದ್ದರೆ, ಮತ್ತೆ ಕೇಳಿ*.

ಅದಕ್ಕೇ `_?` ಈ ರೀತಿ ಬರೆಯಲಾಗುತ್ತದೆ. ಇದು ಕಲಿಯಲು ಹೊಸ ಚಿಹ್ನೆ ಅಲ್ಲ — ಇದು `_` ನಂತರ `?`, ಮತ್ತು ಅದರ ಎರಡು ಭಾಗಗಳು ಕ್ರಮವಾಗಿ ಓದಿದಾಗ ಏನನ್ನು ಅರ್ಥೈಸುತ್ತವೆಯೋ ಅದನ್ನೇ ನಿಖರವಾಗಿ ಅರ್ಥೈಸುತ್ತದೆ.

> ಸುರುಳಿ ಆವರಣಗಳು `{ }` ಒಂದೇ ಹೇಳಿಕೆಗೂ **ಕಡ್ಡಾಯ**.

## ಹೊಂದಾಣಿಕೆ

```zymbol
ಅಂಕ = ೮೫
ಶ್ರೇಣಿ = ?? ಅಂಕ {
    ೯೦..೧೦೦ => 'A'
    ೮೦..೮೯  => 'B'
    _       => 'F'
}
>> ಶ್ರೇಣಿ ¶              // → B
```

```zymbol
ತಾಪಮಾನ = -೫
ಸ್ಥಿತಿ = ?? ತಾಪಮಾನ {
    < ೦  => "ಮಂಜುಗಡ್ಡೆ"
    < ೨೦ => "ತಣ್ಣಗೆ"
    _    => "ಬಿಸಿ"
}
>> ಸ್ಥಿತಿ ¶              // → ಮಂಜುಗಡ್ಡೆ
```

`?` "ಕೇಳುವುದು" ಎಂದು ನಿಮಗೆ ಈಗಾಗಲೇ ತಿಳಿದಿದೆ. **`??` ಹಲವು ಬಾರಿ ಕೇಳುವುದು**: ಭಾಷೆಯಲ್ಲಿ ಎಲ್ಲಿಯಾದರೂ ಒಂದು ಚಿಹ್ನೆಯನ್ನು ದ್ವಿಗುಣಗೊಳಿಸುವುದು, ಆ ಚಿಹ್ನೆ ಒಮ್ಮೆ ಮಾಡುವುದನ್ನು ಹಲವು ಬಾರಿ ಮಾಡುವುದು. ಒಂದು `?` ಒಂದು ಷರತ್ತನ್ನು ಪರೀಕ್ಷಿಸುತ್ತದೆ; `??` ಪ್ರಕರಣಗಳ ಪಟ್ಟಿಯ ವಿರುದ್ಧ ಪರೀಕ್ಷಿಸುತ್ತದೆ.

ಪರ್ಯಾಯಗಳು `||` ನೊಂದಿಗೆ ಸೇರುತ್ತವೆ, ಮತ್ತು ಅವು ಮಾದರಿ ಪ್ರಕಾರಗಳನ್ನು ಮಿಶ್ರ ಮಾಡಬಹುದು:

```zymbol
ಕೀಲಿ = 'P'
ಕ್ರಿಯೆ = ?? ಕೀಲಿ {
    'p' || 'P' => "ವಿರಾಮ"
    < ೦ || > ೧೦೦ => "ವ್ಯಾಪ್ತಿಯ ಹೊರಗೆ"
    _ => "ನಿರ್ಲಕ್ಷಿಸಲಾಗಿದೆ"
}
>> ಕ್ರಿಯೆ ¶             // → ವಿರಾಮ
```

## ಲೂಪ್‌ಗಳು

```zymbol
@ i:೧..೪  { >> i " " }
>> ¶                    // → 1 2 3 4
@ i:೧..೯:೨ { >> i " " }
>> ¶                    // → 1 3 5 7 9
@ i:೫..೧:೧ { >> i " " }
>> ¶                    // → 5 4 3 2 1
```

```zymbol
n = ೧
@ n <= ೬೪ { n *= ೨ }
>> n ¶                  // → 128
```

```zymbol
ಹಣ್ಣುಗಳು = ["ಸೇಬು", "ಪೇರಲೆ", "ದ್ರಾಕ್ಷಿ"]
@ ಹ:ಹಣ್ಣುಗಳು { >> ಹ " " }
>> ¶                    // → ಸೇಬು ಪೇರಲೆ ದ್ರಾಕ್ಷಿ
@ ಅ:"ನಮಸ್ಕಾರ" { >> ಅ "-" }
>> ¶                    // → ನ-ಮ-ಸ-್-ಕ-ಾ-ರ-
```

```zymbol
@ i:೧..೧೦ {
    ? i % ೨ == ೦ { @> }
    ? i > ೭ { @! }
    >> i " "
}
>> ¶                    // → 1 3 5 7
```

```zymbol
ಎಣಿಕೆ = ೦
@:ಹೊರಗಿನ {
    ಎಣಿಕೆ++
    ? ಎಣಿಕೆ >= ೩ { @:ಹೊರಗಿನ! }
}
>> ಎಣಿಕೆ ¶             // → 3
```

`@` **ಸಮಯ**ದ ಚಿಹ್ನೆ: ಪುನರಾವರ್ತನೆಯಾಗುವ ಎಲ್ಲವೂ ಅದರಲ್ಲಿ ವಾಸಿಸುತ್ತದೆ. ಆ ಸಮಯವನ್ನು ಕಡಿತಗೊಳಿಸಲು ಅದರ ಪಕ್ಕದಲ್ಲಿ ಒಂದು ಚಿಹ್ನೆಯನ್ನು ಸೇರಿಸಿ:

- `@!` — `!` **ಬಲ**ವಾಗಿದೆ: ಈಗ ಲೂಪ್‌ನಿಂದ ನಿರ್ಗಮಿಸಿ.
- `@>` — `>` ಮುಂದಕ್ಕೆ ತಳ್ಳುತ್ತದೆ: ಮುಂದಿನ ಸುತ್ತಿಗೆ ಹೋಗಿ.
- `@:ಹೊರಗಿನ!` — `:` **ಒಂದು ಹೆಸರನ್ನು ಬಂಧಿಸುತ್ತದೆ**, ಆದ್ದರಿಂದ ಇದು *ಹೊರಗಿನ* ಎಂಬ ಹೆಸರಿನ ಲೂಪ್ ಅನ್ನು ಕತ್ತರಿಸುತ್ತದೆ, ಹತ್ತಿರದದ್ದನ್ನು ಅಲ್ಲ.

ಮೂರು ನಿರ್ವಾಹಕಗಳು, ಮತ್ತು ಯಾವುದನ್ನೂ ಪ್ರತ್ಯೇಕವಾಗಿ ನೆನಪಿಡಬೇಕಾಗಿಲ್ಲ: ಅವು `@` ಜೊತೆಗೆ ಅದು ಏನು ಮಾಡುತ್ತದೆ ಎಂದು ಈಗಾಗಲೇ ಹೇಳುವ ಒಂದು ಚಿಹ್ನೆ.

> **ನಿರ್ದಿಷ್ಟಕವು ಎಣಿಕೆ ಅಥವಾ ಷರತ್ತು.** ಒಂದು `ಪೂರ್ಣಾಂಕ` ಒಂದು ಎಣಿಕೆ, ಒಮ್ಮೆ ಮೌಲ್ಯಮಾಪನ ಮಾಡಲಾಗುತ್ತದೆ — `@ ೦` ದೇಹವನ್ನು ಶೂನ್ಯ ಬಾರಿ ಚಲಾಯಿಸುತ್ತದೆ. ಉಳಿದ ಎಲ್ಲವೂ ಒಂದು ಷರತ್ತು. ಸತ್ಯತೆ ಇಲ್ಲ: `@ []` ಮತ್ತು `@ ೩.೫` ತಿರಸ್ಕರಿಸಲಾಗುತ್ತದೆ. ಸಂಗ್ರಹವನ್ನು ಸಾಗಿಸಲು `@ x:ವಸ್ತುಗಳು` ಬಳಸಿ; ಎಣಿಸಲು, `@ ವಸ್ತುಗಳು$#`.

## ಫಂಕ್ಷನ್‌ಗಳು

```zymbol
ಕೂಡಿಸು(a, b) { <~ a + b }
>> ಕೂಡಿಸು(೩, ೪) ¶        // → 7
```

```zymbol
ಶ್ರೇಣಿಗುಣಿತ(n) {
    ? n <= ೧ { <~ ೧ }
    <~ n * ಶ್ರೇಣಿಗುಣಿತ(n - ೧)
}
>> ಶ್ರೇಣಿಗುಣಿತ(೫) ¶       // → 120
```

ಒಂದು ಫಂಕ್ಷನ್ ಫೈಲ್‌ನ ಚರಗಳನ್ನು ಮೌಲ್ಯದಿಂದ ಓದುತ್ತದೆ, ಮತ್ತು ಒಳಗಿನ ಬರವಣಿಗೆ ಒಳಗೇ ಉಳಿಯುತ್ತದೆ:

```zymbol
ಮಿತಿ = ೧೦೦
ಒಳಗೆ(n) { <~ n < ಮಿತಿ }
>> ಒಳಗೆ(೪೨) ¶         // → #1
```

ಎರಡು ಚಿಹ್ನೆಗಳು ಅದನ್ನು ಬದಲಾಯಿಸುತ್ತವೆ, ಮತ್ತು ಎರಡೂ **ಸಹಿ ಮತ್ತು ಕರೆ ಸ್ಥಳದಲ್ಲಿ** ಬರೆಯಲಾಗುತ್ತದೆ:

```zymbol
ಹೆಚ್ಚಿಸು(ಎಣಿಕೆ<~) { ಎಣಿಕೆ = ಎಣಿಕೆ + ೧ }
ಒಟ್ಟು = ೦
ಹೆಚ್ಚಿಸು(ಒಟ್ಟು<~)
>> ಒಟ್ಟು ¶              // → 1
```

> `p~` ಒಂದು ಕೆಲಸದ ಪ್ರತಿ — ದೇಹವು ಅದನ್ನು ಮರು ನಿಯೋಜಿಸಬಹುದು ಮತ್ತು ಕರೆದವರು ಅಸ್ಪೃಷ್ಟರಾಗಿರುತ್ತಾರೆ.
> `p<~` ಒಂದು ಔಟ್‌ಪುಟ್ ನಿಯತಾಂಕ — ಬದಲಾವಣೆ ಹಿಂತಿರುಗುತ್ತದೆ. ಚಿಹ್ನೆ ಇಲ್ಲದೆ `ಹೆಚ್ಚಿಸು(ಒಟ್ಟು)` ಒಂದು ಅರ್ಥ ದೋಷ: ವ್ಯಾಖ್ಯಾನ ಮತ್ತು ಸಹಿ ಬೇರೆಯಾಗಲು ಸಾಧ್ಯವಿಲ್ಲ.

## ಲ್ಯಾಂಬ್ಡಾಗಳು ಮತ್ತು ಕ್ಲೋಸರ್‌ಗಳು

```zymbol
ಎರಡು_ಪಟ್ಟು = a -> a * ೨
ಮೊತ್ತ = (a, b) -> a + b
>> ಎರಡು_ಪಟ್ಟು(೫) ¶          // → 10
>> ಮೊತ್ತ(೩, ೭) ¶          // → 10
```

```zymbol
ವರ್ಗೀಕರಣ = a -> {
    ? a > ೦ { <~ "ಧನಾತ್ಮಕ" }
    _? a < ೦ { <~ "ಋಣಾತ್ಮಕ" }
    <~ "ಸೊನ್ನೆ"
}
>> ವರ್ಗೀಕರಣ(-೪) ¶         // → ಋಣಾತ್ಮಕ
```

```zymbol
ಅಂಶ = ೩
ಮೂರು_ಪಟ್ಟು = a -> a * ಅಂಶ
>> ಮೂರು_ಪಟ್ಟು(೭) ¶          // → 21
```

```zymbol
ಕೂಡಿಸುವವನು_ರಚಿಸು(n) { <~ a -> a + n }
ಕೂಡಿಸು೧೦ = ಕೂಡಿಸುವವನು_ರಚಿಸು(೧೦)
>> ಕೂಡಿಸು೧೦(೫) ¶           // → 15
```

ಒಂದು ಲ್ಯಾಂಬ್ಡಾ ಯಾವುದೇ ನಿಯತಾಂಕಗಳನ್ನು ತೆಗೆದುಕೊಳ್ಳದಿರಬಹುದು:

```zymbol
ಉತ್ತರ = () -> ೪೨
>> ಉತ್ತರ() ¶           // → 42
```

> ಒಂದು ಲ್ಯಾಂಬ್ಡಾ ಫೈಲ್‌ನ ಚರಗಳನ್ನು **ರಚಿಸಿದಾಗ** ಸೆರೆಹಿಡಿಯುತ್ತದೆ; ಹೆಸರಿನ ಫಂಕ್ಷನ್ ಅವುಗಳನ್ನು **ಕರೆದಾಗ** ಓದುತ್ತದೆ.

## ಶ್ರೇಣಿಗಳು

```zymbol
ಶ್ರೇಣಿ = [೧, ೨, ೩, ೪, ೫]
>> ಶ್ರೇಣಿ[೧] ¶       // → 1   ಸೂಚ್ಯಂಕ 1-ಆಧಾರಿತ
>> ಶ್ರೇಣಿ[-೧] ¶      // → 5   ಋಣ ಕೊನೆಯಿಂದ ಎಣಿಸುತ್ತದೆ
>> ಶ್ರೇಣಿ$# ¶        // → 5   ಉದ್ದ
```

```zymbol
ಶ್ರೇಣಿ = [೧, ೨, ೩]
>> (ಶ್ರೇಣಿ$+ ೬) ¶          // → [1, 2, 3, 6]   ಸೇರಿಸು
>> (ಶ್ರೇಣಿ$+[೨] ೯೯) ¶      // → [1, 99, 2, 3]  ಸ್ಥಾನ 2 ಕ್ಕೆ ಸೇರಿಸು
>> (ಶ್ರೇಣಿ$- ೩) ¶          // → [1, 2]         ಮೊದಲ ಸಂಭವವನ್ನು ತೆಗೆ
>> (ಶ್ರೇಣಿ$-[೧]) ¶         // → [2, 3]         ಸೂಚ್ಯಂಕ 1 ರಲ್ಲಿ ತೆಗೆ
>> (ಶ್ರೇಣಿ$[೧..೨]) ¶       // → [1, 2]         ತುಣುಕು, ಎರಡೂ ತುದಿ ಸೇರಿ
>> (ಶ್ರೇಣಿ$? ೩) ¶          // → #1             ಹೊಂದಿದೆ
```

ಎಲ್ಲವೂ `$` ನಿಂದ ಪ್ರಾರಂಭವಾಗುತ್ತವೆ, ಅದು **ಸಂಗ್ರಹ**ದ ಚಿಹ್ನೆ, ಮತ್ತು ಅದರಲ್ಲಿ ಏನು ಮಾಡಲಾಗುತ್ತದೆ ಎಂದು ಹೇಳುವ ಚಿಹ್ನೆಯೊಂದಿಗೆ ಮುಂದುವರಿಯುತ್ತದೆ: `#` ಎಷ್ಟು, `+` ಸೇರಿಸು, `-` ತೆಗೆ, `?` ಇದೆಯೇ ಎಂದು ಕೇಳು. ಮತ್ತು `??` ನಂತೆ, ಚಿಹ್ನೆಯನ್ನು ದ್ವಿಗುಣಗೊಳಿಸುವುದು ಅದನ್ನು ಸಂಪೂರ್ಣವಾಗಿ ಮಾಡುವುದು: `$?` ಒಂದು ಮೌಲ್ಯ *ಇದೆಯೇ* ಎಂದು ಕೇಳುತ್ತದೆ, `$??` *ಎಷ್ಟು ಸ್ಥಳಗಳಲ್ಲಿ* ಇದೆ ಎಂದು ಕೇಳಿ ಎಲ್ಲವನ್ನೂ ಹಿಂತಿರುಗಿಸುತ್ತದೆ.

```zymbol
ಶ್ರೇಣಿ = [೩, ೧, ೨]
>> (ಶ್ರೇಣಿ$^+) ¶     // → [1, 2, 3]   ಏರಿಕೆ
>> (ಶ್ರೇಣಿ$^-) ¶     // → [3, 2, 1]   ಇಳಿಕೆ
```

**ಫಲಿತಾಂಶದ ನಿಯಮ.** ಒಂದು ನಿರ್ವಾಹಕ, ಮತ್ತು ಸುತ್ತಮುತ್ತಲಿನ ಕೋಡ್ ಅದರೊಂದಿಗೆ ಏನು ಮಾಡುತ್ತದೆ ಎಂಬುದು ನಿರ್ಧರಿಸುತ್ತದೆ: ಬಳಸಿದರೆ, ಅದು **ನಿರ್ಮಿಸುತ್ತದೆ** ಮತ್ತು ಮೂಲವನ್ನು ಮುಟ್ಟದೆ ಬಿಡುತ್ತದೆ; ಎಸೆದರೆ, ಅದು **ಬದಲಾಯಿಸುತ್ತದೆ**.

```zymbol
ಶ್ರೇಣಿ = [೧, ೨, ೩]
ಪ್ರತಿ = ಶ್ರೇಣಿ[೨]$~ ೯೯
>> ಶ್ರೇಣಿ ¶                // → [1, 2, 3]
>> ಪ್ರತಿ ¶              // → [1, 99, 3]
ಶ್ರೇಣಿ[೨]$~ ೯೯
>> ಶ್ರೇಣಿ ¶                // → [1, 99, 3]
```

> **`=` ಎಂದಿಗೂ ಸಂಗ್ರಹದಲ್ಲಿ ಬರೆಯುವುದಿಲ್ಲ.** `ಶ್ರೇಣಿ[೨] = ೯೯` Zymbol ನ ಒಂದು ರೂಪವಲ್ಲ — `=` ಒಂದು **ಹೆಸರಿಗೆ** ಮೌಲ್ಯವನ್ನು ನೀಡುತ್ತದೆ. ಸಂಗ್ರಹದ ಒಂದು ಭಾಗವನ್ನು ಬದಲಾಯಿಸುವುದು `$~`, ಪ್ರತಿ ಸಂಗ್ರಹದಲ್ಲಿ.

`[…]` ಒಂದು ಪ್ರಕಾರವನ್ನು ಹೊಂದಿದೆ ಮತ್ತು ಪರಿಶೀಲಿಸಲಾಗುತ್ತದೆ; ಉದ್ದೇಶಪೂರ್ವಕ ಮಿಶ್ರಣವನ್ನು `#[…]` ನೊಂದಿಗೆ **ಘೋಷಿಸಲಾಗುತ್ತದೆ**:

```zymbol
ಮಿಶ್ರಣ = #[೧, "ಎರಡು", #೧]
>> ಮಿಶ್ರಣ ¶             // → [1, ಎರಡು, #1]
>> ([೧, ೨] == #[೧, ೨]) ¶ // → #1
```

## ಬಹುಆಯಾಮೀಯ ಸೂಚ್ಯಂಕ

`>` ಒಂದು ನೆಸ್ಟ್ ಮಾಡಿದ ರಚನೆಯಲ್ಲಿ ಇಳಿಯುತ್ತದೆ. ಒಂದು ಆವರಣ ಗುಂಪು ಒಂದು ಅಂಶವನ್ನು ಉದ್ದೇಶಿಸುತ್ತದೆ, ಅದು ಎಷ್ಟೇ ಆಳವಾಗಿದ್ದರೂ.

```zymbol
m = [[೧,೨,೩], [೪,೫,೬], [೭,೮,೯]]
>> m[೨>೩] ¶        // → 6   ಸಾಲು 2, ಅಂಕಣ 3
>> m[-೧>-೧] ¶      // → 9   ಕೊನೆಯ ಸಾಲು, ಕೊನೆಯ ಅಂಕಣ
```

```zymbol
m = [[೧,೨,೩], [೪,೫,೬], [೭,೮,೯]]
>> m[೧>೧ ; ೨>೨ ; ೩>೩] ¶          // → [1, 5, 9]          ಸಮತಟ್ಟು: ಕರ್ಣ
>> m[[೧>೧, ೧>೩] ; [೩>೧, ೩>೩]] ¶  // → [[1, 3], [7, 9]]   ರಚನಾತ್ಮಕ: ಮೂಲೆಗಳು
```

```zymbol
m = [[೧,೨,೩], [೪,೫,೬]]
>> (m[೧>೨]$~ ೯೯) ¶      // → [[1, 99, 3], [4, 5, 6]]
```

> `m[೧][೨]` Zymbol ನ ಒಂದು ರೂಪ **ಅಲ್ಲ**. ಸರಪಳಿ ಸೂಚ್ಯಂಕವು ಓದುವುದಕ್ಕೆ ಮತ್ತು ಬರೆಯುವುದಕ್ಕೆ ಎರಡಕ್ಕೂ ತಿರಸ್ಕರಿಸಲಾಗುತ್ತದೆ — ಪ್ರತಿ ಪ್ರವೇಶಕ್ಕೆ ಒಂದು ಆವರಣ ಗುಂಪು, ಮತ್ತು `>` ಎಂಬುದು ಹಂತಗಳ ನಡುವೆ ಹೋಗುವುದು.

## ನಿಘಂಟುಗಳು

ಹೆಸರಿನ ಕ್ಷೇತ್ರಗಳನ್ನು ಹೊಂದಿರುವ ಟ್ಯೂಪಲ್ ಒಂದು ನಿಘಂಟು, ಮತ್ತು v0.0.9 ರಿಂದ ಅದನ್ನು `#(…)` ಎಂದು ಬರೆಯಲಾಗುತ್ತದೆ.

```zymbol
ವ್ಯಕ್ತಿ = #(ಹೆಸರು: "ಅರ್ಜುನ", ವಯಸ್ಸು: ೨೫)
>> ವ್ಯಕ್ತಿ.ಹೆಸರು ¶        // → ಅರ್ಜುನ
>> ವ್ಯಕ್ತಿ["ವಯಸ್ಸು"] ¶    // → 25
```

```zymbol
ವ್ಯಕ್ತಿ = #(ಹೆಸರು: "ಅರ್ಜುನ", ವಯಸ್ಸು: ೨೫)
ಕ್ಷೇತ್ರ = "ಹೆಸರು"
>> ವ್ಯಕ್ತಿ[ಕ್ಷೇತ್ರ] ¶     // → ಅರ್ಜುನ
```

ಅದು ಬದಲಾಯಿಸಬಹುದಾದದ್ದು, ಕೀಗಳನ್ನು ಸೇರಿಸಬಹುದು, ಮತ್ತು ಅದನ್ನು ಸಾಗಿಸಬಹುದು:

```zymbol
ದಾಸ್ತಾನು = #(ಪೇರಲೆ: ೪)
ದಾಸ್ತಾನು["ಸೇಬು"]$~ ೧೦
@ k:ದಾಸ್ತಾನು { >> k "=" ದಾಸ್ತಾನು[k] " " }
>> ¶                    // → ಪೇರಲೆ=4 ಸೇಬು=10
```

```zymbol
ದಾಸ್ತಾನು = #(ಪೇರಲೆ: ೪, ಸೇಬು: ೧೦)
@ (k, v):ದಾಸ್ತಾನು { >> k ":" v " " }
>> ¶                    // → ಪೇರಲೆ:4 ಸೇಬು:10
```

> `#()` ಖಾಲಿ ನಿಘಂಟು, ಅದು `()` ಆಗಿರಲು ಸಾಧ್ಯವಿಲ್ಲ — ಅದು ಖಾಲಿ ಟ್ಯೂಪಲ್ ಕೂಡ ಆಗಿರಬೇಕಿತ್ತು. ಬರಿ `(a: 1)` ಈ ಸಂದೇಶದೊಂದಿಗೆ ತಿರಸ್ಕರಿಸಲಾಗುತ್ತದೆ: *a dictionary is written `#(…)`* — «ನಿಘಂಟನ್ನು `#(…)` ಎಂದು ಬರೆಯಲಾಗುತ್ತದೆ».
> ನಿಘಂಟನ್ನು ಕೀ ಮೂಲಕ ಉದ್ದೇಶಿಸಲಾಗುತ್ತದೆ, ಸ್ಥಾನದಿಂದ ಎಂದಿಗೂ ಅಲ್ಲ, ಆದ್ದರಿಂದ `ವ್ಯಕ್ತಿ[1]` ಒಂದು ದೋಷ.

---

## ಟ್ಯೂಪಲ್‌ಗಳು

ಟ್ಯೂಪಲ್‌ಗಳು **ಬದಲಾಯಿಸಲಾಗದ** ಕ್ರಮಬದ್ಧ ಧಾರಕಗಳು, ವಿವಿಧ ಪ್ರಕಾರಗಳ ಮೌಲ್ಯಗಳನ್ನು ಹಿಡಿದಿಡುತ್ತವೆ.

```zymbol
ಬಿಂದು = (೧೦, ೨೦)
>> ಬಿಂದು[೧] ¶           // → 10
ದತ್ತಾಂಶ = (೪೨, "ನಮಸ್ಕಾರ", #೧, ೩.೧೪)
>> ದತ್ತಾಂಶ[೩] ¶            // → #1
```

```zymbol
t = (೧೦, ೨೦, ೩೦)
t2 = t[೨]$~ ೯೯೯
>> t ¶                  // → (10, 20, 30)
>> t2 ¶                 // → (10, 999, 30)
```

> ಒಂದು ಟ್ಯೂಪಲ್ ಅನ್ನು ಅದರ ಸ್ಥಳದಲ್ಲೇ ಬದಲಾಯಿಸುವ ಯಾವುದೇ ಪ್ರಯತ್ನವು ದೋಷ, ನಿರ್ವಾಹಕ ಯಾವುದೇ ಆಗಿರಲಿ — ಬದಲಾಯಿಸಲಾಗದಿರುವಿಕೆ ಮೌಲ್ಯದ ಗುಣ, ಪ್ರತಿ `$` ನೊಳಗಿನ ವಿನಾಯಿತಿ ಅಲ್ಲ.

## ವಿಭಜನೆ

```zymbol
ಶ್ರೇಣಿ = [೧೦, ೨೦, ೩೦, ೪೦, ೫೦]
[a, b, c] = ಶ್ರೇಣಿ
>> a " " b " " c ¶      // → 10 20 [30, 40, 50]
```

```zymbol
ಶ್ರೇಣಿ = [೧೦, ೨೦, ೩೦, ೪೦, ೫೦]
[ಮೊದಲ, *ಉಳಿದ] = ಶ್ರೇಣಿ
>> ಮೊದಲ ¶            // → 10
>> ಉಳಿದ ¶              // → [20, 30, 40, 50]
```

```zymbol
ಬಿಂದು = (೧೦೦, ೨೦೦)
(px, py) = ಬಿಂದು
>> px " " py ¶          // → 100 200
```

```zymbol
ವ್ಯಕ್ತಿ = #(ಹೆಸರು: "ಪ್ರಿಯಾ", ವಯಸ್ಸು: ೨೫)
#(ಹೆಸರು: n, ವಯಸ್ಸು: v) = ವ್ಯಕ್ತಿ
>> n " " v ¶            // → ಪ್ರಿಯಾ 25
```

> ಆವರಣದ ಆಕಾರವು ಟೈಪ್ ಆಗಿದೆ: `[…]` ಶ್ರೇಣಿ ತೆಗೆದುಕೊಳ್ಳುತ್ತದೆ, `(…)` ಟ್ಯೂಪಲ್, `#(…)` ನಿಘಂಟು. ಕೊನೆಯ ಹೆಸರು **ಉಳಿದದ್ದನ್ನು ಹೀರಿಕೊಳ್ಳುತ್ತದೆ**, ಆದ್ದರಿಂದ ವಿಭಜನೆ ಎಂದಿಗೂ ಉದ್ದದಿಂದ ವಿಫಲವಾಗುವುದಿಲ್ಲ — `(a, b, c) = (1,2,3,4,5)` `c = (3,4,5)` ನೀಡುತ್ತದೆ, ಮತ್ತು ಏನೂ ಉಳಿಯದಿದ್ದಾಗ `##_`.

## ಉನ್ನತ-ಕ್ರಮ ಫಂಕ್ಷನ್‌ಗಳು

```zymbol
ಸಂಖ್ಯೆಗಳು = [೧, ೨, ೩, ೪, ೫]
>> (ಸಂಖ್ಯೆಗಳು$> (a -> a * ೨)) ¶ // → [2, 4, 6, 8, 10]
>> (ಸಂಖ್ಯೆಗಳು$| (a -> a % ೨ == ೦)) ¶ // → [2, 4]
>> (ಸಂಖ್ಯೆಗಳು$< (೦, (ಸಂಗ್ರಹ, a) -> ಸಂಗ್ರಹ + a)) ¶ // → 15
```

```zymbol
ಸಂಖ್ಯೆಗಳು = [೧, ೨, ೩, ೪, ೫, ೬]
ಎರಡು_ಪಟ್ಟು(a) { <~ a * ೨ }
ದೊಡ್ಡದು(a) { <~ a > ೩ }
>> (ಸಂಖ್ಯೆಗಳು$> ಎರಡು_ಪಟ್ಟು) ¶    // → [2, 4, 6, 8, 10, 12]
>> (ಸಂಖ್ಯೆಗಳು$| ದೊಡ್ಡದು) ¶    // → [4, 5, 6]
```

```zymbol
ಮೂಲ = [#(ಹೆಸರು: "ಕಾರ್ಲಾ", ವಯಸ್ಸು: ೨೮), #(ಹೆಸರು: "ಪ್ರಿಯಾ", ವಯಸ್ಸು: ೨೫)]
ವಯಸ್ಸಿನ_ಪ್ರಕಾರ = ಮೂಲ$^ (a, b -> a.ವಯಸ್ಸು < b.ವಯಸ್ಸು)
>> ವಯಸ್ಸಿನ_ಪ್ರಕಾರ[೧].ಹೆಸರು ¶     // → ಪ್ರಿಯಾ
```

> ಹೆಸರಿನ ಫಂಕ್ಷನ್ HOF ಗೆ **ಆವರಣಗಳಿಲ್ಲದೆ** ಹೋಗುತ್ತದೆ: `ಸಂಖ್ಯೆಗಳು$> ಎರಡು_ಪಟ್ಟು`. `ಸಂಖ್ಯೆಗಳು$> (ಎರಡು_ಪಟ್ಟು)` ಬರೆಯುವುದು ಒಂದು ಪಾರ್ಸ್ ದೋಷ, ಏಕೆಂದರೆ `(` ಒಂದು ಲ್ಯಾಂಬ್ಡಾವನ್ನು ತೆರೆಯುತ್ತದೆ.

## ಪೈಪ್ ನಿರ್ವಾಹಕ

```zymbol
ಎರಡು_ಪಟ್ಟು = a -> a * ೨
ಕೂಡಿಸು = (a, b) -> a + b
ಒಂದು_ಹೆಚ್ಚಿಸು = a -> a + ೧
>> (೫ |> ಎರಡು_ಪಟ್ಟು(_)) ¶    // → 10
>> (೧೦ |> ಕೂಡಿಸು(_, ೫)) ¶  // → 15
>> (೫ |> ಎರಡು_ಪಟ್ಟು(_) |> ಒಂದು_ಹೆಚ್ಚಿಸು(_)) ¶ // → 11
```

## ದೋಷ ನಿರ್ವಹಣೆ

```zymbol
!? {
    a = ೧೦ / ೦
} :! ##Div {
    >> "ಸೊನ್ನೆಯಿಂದ ಭಾಗಾಕಾರ" ¶  // → ಸೊನ್ನೆಯಿಂದ ಭಾಗಾಕಾರ
} :! {
    >> "ಇತರೆ: " _err ¶
} :> {
    >> "ಯಾವಾಗಲೂ ಚಲಿಸುತ್ತದೆ" ¶        // → ಯಾವಾಗಲೂ ಚಲಿಸುತ್ತದೆ
}
```

| ಪ್ರಕಾರ | ಯಾವಾಗ |
|------|------|
| `##Div` | ಸೊನ್ನೆಯಿಂದ ಭಾಗಾಕಾರ |
| `##Index` | ಸೂಚ್ಯಂಕ ವ್ಯಾಪ್ತಿಯ ಹೊರಗೆ |
| `##Key` | ನಿಘಂಟಿನಲ್ಲಿ ಕೀ ಇಲ್ಲ |
| `##Range` | ಸುರಕ್ಷಿತ ಪೂರ್ಣಾಂಕ ವ್ಯಾಪ್ತಿಯ ಹೊರಗೆ |
| `##Type` | ಪ್ರಕಾರ ಹೊಂದಿಕೆಯಾಗದಿರುವುದು |
| `##Parse` | ಡೇಟಾ ಪಾರ್ಸಿಂಗ್ |
| `##IO` | ಫೈಲ್ / ವ್ಯವಸ್ಥೆ |
| `##Network` | ನೆಟ್‌ವರ್ಕ್ ದೋಷಗಳು |
| `##DB` | ಡೇಟಾಬೇಸ್ |
| `##Time` | ಅಸ್ತಿತ್ವದಲ್ಲಿಲ್ಲದ ದಿನಾಂಕ |
| `##_` | ಯಾವುದೇ ದೋಷ (ಎಲ್ಲವನ್ನೂ ಹಿಡಿಯುವ) |

`!` **ದೋಷ ಮತ್ತು ಬಲ**ದ ಚಿಹ್ನೆ, ಮತ್ತು ಎರಡೂ ಕುಟುಂಬಗಳಲ್ಲಿ ಒಂದೇ ರೀತಿ ಓದಲಾಗುತ್ತದೆ: `$!` ಒಂದು ಮೌಲ್ಯವನ್ನು ಅದು ದೋಷವೇ ಎಂದು ಕೇಳುತ್ತದೆ; `$!!`, ಚಿಹ್ನೆಯನ್ನು ದ್ವಿಗುಣಗೊಳಿಸಿ, ಕೇಳದೆ ಅದನ್ನು ಮೇಲಕ್ಕೆ ಹರಡುತ್ತದೆ.

> ಪ್ರಮಾಣಿತ ಗ್ರಂಥಾಲಯದ ವೈಫಲ್ಯಗಳು ನಿಲ್ಲಿಸುವ ಬದಲು **ಮೃದು ದೋಷ ಮೌಲ್ಯಗಳಾಗಿ** ಮರಳಿ ಬರುತ್ತವೆ, ಅವುಗಳನ್ನು ನೀವು `$!` ನಿಂದ ಪರೀಕ್ಷಿಸುತ್ತೀರಿ ಅಥವಾ `!?` ನಿಂದ ಹಿಡಿಯುತ್ತೀರಿ. `$!!` ಒಂದನ್ನು ಕರೆದವರಿಗೆ ಹರಡುತ್ತದೆ.

## ಮಾಡ್ಯೂಲ್‌ಗಳು

```zymbol
# ಕ್ಯಾಲ್ಕ್ {
    #> { ಕೂಡಿಸು, PI }

    PI := ೩.೧೪೧೫೯
    ಕೂಡಿಸು(a, b) { <~ a + b }
}
```

```zymbol
<# ./ಕ್ಯಾಲ್ಕ್ => c

>> c::ಕೂಡಿಸು(೫, ೩) ¶
>> c.PI ¶
```

```zymbol
# ನನ್ನ_ಗ್ರಂಥಾಲಯ {
    #> { ಒಳಗಿನ_ಕೂಡಿಸು => ಮೊತ್ತ }

    ಒಳಗಿನ_ಕೂಡಿಸು(a, b) { <~ a + b }
}
```

ಎರಡು ಮಾಡ್ಯೂಲ್ ಚಿಹ್ನೆಗಳು ಒಂದೇ ಕಲ್ಪನೆ, ಈಗ ಫೈಲ್‌ಗಳಿಗೆ ಅನ್ವಯಿಸಲಾಗಿದೆ: `#` **ಘೋಷಣೆ**ಯ ಮಟ್ಟ — ಒಂದು ವಸ್ತು *ಏನು*, ಅದರ ಮೌಲ್ಯವಲ್ಲ — ಮತ್ತು ಬಾಣವು ಕೋಡ್ ಯಾವ ದಿಕ್ಕಿನಲ್ಲಿ ಚಲಿಸುತ್ತದೆ ಎಂದು ಹೇಳುತ್ತದೆ:

```text
<#   ಬಾಣ ಪ್ರವೇಶಿಸುತ್ತದೆ: ಆಮದು, ಇನ್ನೊಂದು ಫೈಲ್‌ನಿಂದ ತರು
#>   ಬಾಣ ನಿರ್ಗಮಿಸುತ್ತದೆ: ರಫ್ತು, ಇತರ ಫೈಲ್‌ಗಳಿಗೆ ನೀಡು
```

ದಿಕ್ಕಿನ ಚಿಹ್ನೆ ಯಾವಾಗಲೂ ತಾನು ತೋರಿಸುವ ದಿಕ್ಕಿಗೆ ಎದುರಾಗಿರುವ ಅಂಚಿನಲ್ಲಿ ಕುಳಿತುಕೊಳ್ಳುತ್ತದೆ. `<~` ಎಡಕ್ಕೆ ಮರಳುವುದು (ಫಂಕ್ಷನ್‌ನಿಂದ ಹೊರಗೆ) ಮತ್ತು `->` ಬಲಕ್ಕೆ ಪ್ರವೇಶಿಸುವುದು (ಲ್ಯಾಂಬ್ಡಾದ ದೇಹಕ್ಕೆ) ಇದಕ್ಕೆ ಅದೇ ಕಾರಣ.

> **ಒಂದು ಮಾಡ್ಯೂಲ್ ತಾನು ಏನನ್ನು ರಫ್ತು ಮಾಡುತ್ತದೆ ಎಂದು ಘೋಷಿಸುತ್ತದೆ.** `#>` ಬ್ಲಾಕ್ ಕಡ್ಡಾಯ — ಅದನ್ನು ಬಿಟ್ಟುಬಿಡುವುದು **E014**, ಮತ್ತು `#> { }` ಒಂದು ಮಾಡ್ಯೂಲ್ ತನ್ನ ಮೇಲ್ಮೈ ಖಾಲಿ ಎಂದು ಹೇಳುವ ವಿಧಾನ. `::` ಒಂದು ಫಂಕ್ಷನ್ ಅನ್ನು ಕರೆಯುತ್ತದೆ, `.` ಒಂದು ಸ್ಥಿರಾಂಕವನ್ನು ಓದುತ್ತದೆ. ಮಾಡ್ಯೂಲ್ ದೇಹದಲ್ಲಿ ಆಮದುಗಳು, ರಫ್ತು ಬ್ಲಾಕ್, ಅಕ್ಷರಶಃ ಆರಂಭಿಕಗಳು ಮತ್ತು ಫಂಕ್ಷನ್ ವ್ಯಾಖ್ಯಾನಗಳು ಮಾತ್ರ ಕಾಣಿಸಬಹುದು; ಕಾರ್ಯಗತಗೊಳಿಸಬಹುದಾದ ಯಾವುದೂ **E013**.

## ಪ್ರಮಾಣಿತ ಗ್ರಂಥಾಲಯ

ಸ್ಥಳೀಯ ಮಾಡ್ಯೂಲ್‌ಗಳು, ಯಾವುದೇ ಇತರರಂತೆ ಆಮದು ಮಾಡಲಾಗುತ್ತದೆ:

| ಮಾಡ್ಯೂಲ್ | ಫಂಕ್ಷನ್‌ಗಳು |
|--------|-----------|
| `std/math` | `sqrt exp ln log pow abs ceil floor round min max sin cos tan asin acos atan atan2 sinh cosh tanh sigmoid` · `PI` `E` |
| `std/random` | `entero rango peso_f64` |
| `std/json` | `decode decode_map encode` |
| `std/io` | `read write append exists delete list mkdir` |
| `std/net` | `get post post_json head` |
| `std/db` | `connect exec query query_one tx commit rollback` … |
| `std/term` | `width pad_left pad_right center truncate` |
| `std/time` | `now today parts of format add diff` |

```zymbol
<# std/math => m

>> m::sqrt(೧೬.೦) ¶      // → 4
>> m.PI ¶               // → 3.141592653589793
```

```zymbol
<# std/term => t

>> t::width("手番") ¶            // → 4   ಎರಡು ಗ್ಲಿಫ್, ನಾಲ್ಕು ಅಂಕಣ
>> "|" t::center("go", 8) "|" ¶ // → |   go   |
```

```zymbol
<# std/time => T

ದಿನ = T::of(೨೦೨೬, ೧, ೩೧)
>> T::format(ದಿನ, "%Y-%m-%d") ¶ // → 2026-01-31
>> T::format(T::add(ದಿನ, ೧, "month"), "%Y-%m-%d") ¶ // → 2026-02-28
```

> `std/term` **ಪ್ರದರ್ಶನ ಅಂಕಣಗಳನ್ನು** ಅಳೆಯುತ್ತದೆ, ಅಕ್ಷರಗಳನ್ನಲ್ಲ: CJK ಮತ್ತು ಬಹುಪಾಲು ಎಮೋಜಿಗಳು 2 ಅಂಕಣ, ಆದ್ದರಿಂದ `t::width` ನಿಂದ ಟೇಬಲ್ ಜೋಡಿಸಿ, ಎಂದಿಗೂ `$#` ಅಲ್ಲ.
> `std/time` ನಲ್ಲಿ ಒಂದು ಕ್ಷಣವು ಯುಗದಿಂದ ಮಿಲಿಸೆಕೆಂಡುಗಳು. ಒಂದು ದಿನಕ್ಕಿಂತ ಕಡಿಮೆ ಅವಧಿ, ಒಂದು ದಿನದಿಂದ ಮೇಲೆ ಕ್ಯಾಲೆಂಡರ್ — ಆದ್ದರಿಂದ ಒಂದು ತಿಂಗಳು ಅದೇ ದಿನದಂದು ಬರುತ್ತದೆ, ಕ್ಲ್ಯಾಂಪ್ ಮಾಡಲಾಗಿದೆ. `ವ್ಯತ್ಯಾಸ(a, b)` ಎಂಬುದು `a - b`, ಆದ್ದರಿಂದ ಹಿಂದಿನ ಕ್ಷಣವನ್ನು ಮೊದಲು ನೀಡಿದರೆ ಋಣಾತ್ಮಕ ಉತ್ತರ ಸಿಗುತ್ತದೆ.

## ಪ್ಯಾಕೇಜ್‌ಗಳು

ಒಂದು `.zyp` ಬಹು-ಫೈಲ್ ಪ್ರೋಗ್ರಾಂ ಅನ್ನು ಒಂದೇ ಪೋರ್ಟಬಲ್ ಫೈಲ್‌ನಲ್ಲಿ ಬಂಡಲ್ ಮಾಡುತ್ತದೆ. ಇದು **ಮೂಲ**ದ ಆರ್ಕೈವ್, ಬೈನರಿ ಅಲ್ಲ, ಆದ್ದರಿಂದ `zymbol` ಬೈನರಿ ಚಲಿಸುವ ಎಲ್ಲಿಯಾದರೂ ಚಲಿಸುತ್ತದೆ.

```bash
zymbol package ನನ್ನ_ಯೋಜನೆ/ --script main.zy -o ನನ್ನ_ಯೋಜನೆ.zyp
zymbol run ನನ್ನ_ಯೋಜನೆ.zyp
```

> ಆರ್ಕೈವ್ ಒಂದು ಮ್ಯಾನಿಫೆಸ್ಟ್ (`zyp.toml`) ಅನ್ನು ಹೊಂದಿದೆ, ಅದು ಅದರ ಪ್ರವೇಶ ಸ್ಕ್ರಿಪ್ಟ್‌ಗಳು ಮತ್ತು ಅಗತ್ಯವಿರುವ ಇಂಜಿನ್ ಆವೃತ್ತಿಯನ್ನು ಘೋಷಿಸುತ್ತದೆ. `zymbol run` ಅದನ್ನು ತಾತ್ಕಾಲಿಕ ಡೈರೆಕ್ಟರಿಗೆ ಹೊರತೆಗೆದು ಅಲ್ಲಿಂದ ಚಲಾಯಿಸುತ್ತದೆ, ಆದ್ದರಿಂದ ಕೋಡ್ ವಿಲೇವಾರಿ ಮಾಡಬಹುದಾದದ್ದು, ಸ್ಕ್ರಿಪ್ಟ್ ಬರೆಯುವುದು ನಿಮ್ಮ ನಿಜವಾದ ಕೆಲಸದ ಡೈರೆಕ್ಟರಿಯಲ್ಲಿ ಬೀಳುತ್ತದೆ. ಆಟದ ಮೈದಾನವೂ `.zyp` ಫೈಲ್‌ಗಳನ್ನು ಲೋಡ್ ಮಾಡುತ್ತದೆ.

## ಸಂಖ್ಯಾ ಮೋಡ್‌ಗಳು

Zymbol ಸಂಖ್ಯೆಗಳನ್ನು **69 ಯುನಿಕೋಡ್ ಅಂಕಿ ಲಿಪಿಗಳಲ್ಲಿ** ಬರೆಯಬಹುದು — ದೇವನಾಗರಿ, ಅರೇಬಿಕ್-ಭಾರತೀಯ, ಥಾಯ್, ಕ್ಲಿಂಗನ್ pIqaD, ಗಣಿತ ದಪ್ಪ, LCD ವಿಭಾಗಗಳು, ಮತ್ತು ಇನ್ನಷ್ಟು. ಮೋಡ್ ಪ್ರಕ್ರಿಯೆಗೆ ಜಾಗತಿಕ ಮತ್ತು ಔಟ್‌ಪುಟ್ ಮೇಲೆ ಪರಿಣಾಮ ಬೀರುತ್ತದೆ; ಅಂಕಗಣಿತ ಬದಲಾಗುವುದಿಲ್ಲ.

```zymbol
#೦೯#    // ಕನ್ನಡ   (U+0CE6–U+0CEF)
#०९#    // ದೇವನಾಗರಿ   (U+0966–U+096F)
#٠٩#    // ಅರೇಬಿಕ್-ಭಾರತೀಯ (U+0660–U+0669)
#09#    // ASCII ಗೆ ಮರುಹೊಂದಿಸು
```

```zymbol
a = ೪೨
>> a ¶                  // → 42
#೦೯#
>> a ¶                  // → ೪೨
>> ೩.೧೪ ¶               // → ೩.೧೪
>> #೧ ¶                 // → #೧
#09#
```

ಯಾವುದೇ ಬೆಂಬಲಿತ ಲಿಪಿಯ ಅಂಕಿಗಳು ಮೂಲದಲ್ಲಿ ಮಾನ್ಯ ಅಕ್ಷರಶಃ:

```zymbol
#೦೯#
@ i:೧..೫ { >> i " " }
>> ¶                    // → ೧ ೨ ೩ ೪ ೫
#09#
```

ಓದುವಿಕೆ ಸಮ್ಮಿತೀಯ — ಒಂದು ಅಂಕಿಯು ಯಾವುದೇ ಲಿಪಿಯಲ್ಲಿ ಅರ್ಥವಾಗುತ್ತದೆ:

```zymbol
>> #|"४२"| ¶            // → 42
>> #|'७'| ¶             // → 7
```

> `#` ಯಾವಾಗಲೂ ASCII, ಆದ್ದರಿಂದ `#0` ಪ್ರತಿ ಲಿಪಿಯಲ್ಲೂ ಅಂಕಿ ಶೂನ್ಯದಿಂದ ದೃಶ್ಯವಾಗಿ ಭಿನ್ನವಾಗಿರುತ್ತದೆ.
> `#,` ಮತ್ತು `#^` ಕೂಡ ತಮ್ಮ ಅಂಕಿಗಳನ್ನು ಸಕ್ರಿಯ ಲಿಪಿಯಲ್ಲಿ ಬರೆಯುತ್ತವೆ, ಮತ್ತು ವಿಭಾಜಕಗಳು ಅದನ್ನು ಅನುಸರಿಸುತ್ತವೆ — ಆದರೆ ಜೋಡಿ ಎಂದಿಗೂ ತಲೆಕೆಳಗಾಗುವುದಿಲ್ಲ: `,` ಗುಂಪು ಮಾಡುತ್ತದೆ ಮತ್ತು `.` ವಿಭಜಿಸುತ್ತದೆ, ಪ್ರತಿ ಲಿಪಿಯಲ್ಲಿ.

## ಡೇಟಾ ನಿರ್ವಾಹಕಗಳು

```zymbol
f = ##.೪೨         // ದಶಮಾಂಶಕ್ಕೆ
i = ###೩.೭        // ಪೂರ್ಣಾಂಕಕ್ಕೆ, ಸುತ್ತಿಸು  → 4
t = ##!೩.೭        // ಪೂರ್ಣಾಂಕಕ್ಕೆ, ಕತ್ತರಿಸು  → 3
>> f " " i " " t ¶      // → 42 4 3
>> f#? ¶                // → (##., 2, 42)
```

> ಒಂದು ದಶಮಾಂಶವು ಅಂಕಿಗಳಾಗಿ ಮುದ್ರಿಸಲಾಗುತ್ತದೆ, ಎಂದಿಗೂ ಘಾತವಾಗಿ ಅಲ್ಲ, ಮತ್ತು ಕೊನೆಯ `.0` ಅನ್ನು ಬಿಡುತ್ತದೆ — `##.42` `42` ಎಂದು ಬರೆಯುತ್ತದೆ ಮತ್ತು ಇನ್ನೂ ದಶಮಾಂಶ, `f#?` ತೋರಿಸಿದಂತೆ.

```zymbol
>> #|"42"| ¶       // → 42
>> #|"abc"| ¶      // → abc   ವಿಫಲ-ಸುರಕ್ಷಿತ: ಇನ್‌ಪುಟ್ ಅನ್ನು ಬದಲಾಗದೆ ಹಿಂತಿರುಗಿಸುತ್ತದೆ
>> ##!'A' ¶        // → 65    ಅಕ್ಷರದ ಕೋಡ್ ಪಾಯಿಂಟ್
```

```zymbol
pi = ೩.೧೪೧೫೯೨೬೫
>> #.೨|pi| ¶       // → 3.14          2 ದಶಮಾಂಶ ಸ್ಥಾನಗಳಿಗೆ ಸುತ್ತಿಸು
>> #!೨|pi| ¶       // → 3.14          2 ದಶಮಾಂಶ ಸ್ಥಾನಗಳಿಗೆ ಕತ್ತರಿಸು
>> #,|೧೨೩೪೫೬೭| ¶   // → 1,234,567     ಸಾವಿರ ವಿಭಾಜಕಗಳು
>> #^|೧೨೩೪೫.೬೭೮| ¶ // → 1.2345678e4  ವೈಜ್ಞಾನಿಕ ಸಂಕೇತ
```

```zymbol
>> 0x41 ¶        // → A   ಷೋಡಶ
>> 0b01000001 ¶  // → A   ದ್ವಿಮಾನ
>> 0o101 ¶       // → A   ಅಷ್ಟ
>> 0d65 ¶        // → A   ದಶ
```

> ASCII ವ್ಯಾಪ್ತಿಯಲ್ಲಿನ ಆಧಾರ ಅಕ್ಷರಶಃ ಒಂದು **ಅಕ್ಷರ**: `0d65 == 'A'` ಎಂಬುದು `#1`, ಮತ್ತು `0d65 == 65` ಎಂಬುದು `#0`. ನಾಲ್ಕೂ ಆಧಾರಗಳು ಒಂದೇ ಅಕ್ಷರವನ್ನು ಕಾಗುಣಿತ ಮಾಡುತ್ತವೆ.

## ಸಂಪೂರ್ಣ ಉದಾಹರಣೆ: FizzBuzz

```zymbol
ವರ್ಗೀಕರಣ(ಸಂಖ್ಯೆ) {
    ? ಸಂಖ್ಯೆ % ೧೫ == ೦ { <~ "FizzBuzz" }
    _? ಸಂಖ್ಯೆ % ೩  == ೦ { <~ "Fizz" }
    _? ಸಂಖ್ಯೆ % ೫  == ೦ { <~ "Buzz" }
    <~ ಸಂಖ್ಯೆ
}

@ i:೧..೨೦ { >> ವರ್ಗೀಕರಣ(i) ¶ }
// → 1 · 2 · Fizz · 4 · Buzz · Fizz · 7 · 8 · Fizz · Buzz · 11 · Fizz · 13 · 14 ·
//   FizzBuzz · 16 · 17 · Fizz · 19 · Buzz   (ಪ್ರತಿ ಸಾಲಿಗೆ ಒಂದು)
```

## ಚಿಹ್ನೆಗಳು ಹೇಗೆ ಸೇರುತ್ತವೆ

ಈ ಇಡೀ ಕೈಪಿಡಿಯಲ್ಲಿ ನೀವು ಒಂದೇ ವಿಷಯವನ್ನು ನೋಡುತ್ತಿದ್ದೀರಿ: **ಒಂದು ನಿರ್ವಾಹಕವು ನೆನಪಿಡಲು ಒಂದು ಚಿತ್ರವಲ್ಲ, ಅದು ಒಂದು ಸಾಲಿನಲ್ಲಿ ಹಲವು ಚಿಹ್ನೆಗಳು, ಮತ್ತು ಪ್ರತಿಯೊಂದೂ ತನ್ನ ಅರ್ಥವನ್ನು ನೀಡುತ್ತದೆ.** ಈಗ ನೀವು ಅವೆಲ್ಲವನ್ನೂ ತಿಳಿದಿದ್ದೀರಿ, ಇಲ್ಲಿ ಸಂಪೂರ್ಣ ಮಾದರಿ.

ಮೊದಲು ಬರುತ್ತದೆ **ನಾವು ಯಾವ ಜಗತ್ತಿನಲ್ಲಿದ್ದೇವೆ**:

| ಚಿಹ್ನೆ | ಜಗತ್ತು | ನೀವು ಅದನ್ನು ಎಲ್ಲಿ ನೋಡಿದ್ದೀರಿ |
|--------|-------|----------------------------|
| `$` | ಒಂದು ಸಂಗ್ರಹ | `$#` `$+` `$?` `$^-` |
| `@` | ಸಮಯ, ಪುನರಾವರ್ತನೆಯಾಗುವ ಎಲ್ಲವೂ | `@!` `@>` `@~` |
| `#` | ಒಂದು ವಸ್ತು *ಏನು*, ಅದರ ಮೌಲ್ಯವಲ್ಲ | `#?` `#(…)` `<#` `#>` |
| `>>` | ಪ್ರೋಗ್ರಾಂನಿಂದ ಹೊರಗೆ | `>>` `>>!` `>>?` |
| `<<` | ಪ್ರೋಗ್ರಾಂನೊಳಗೆ | `<<` `<<\|` `<<\|?` |
| `?` | ಕೇಳುವುದು, ಬದ್ಧತೆ ಇಲ್ಲದೆ | `?` `_?` `??` `$?` |
| `!` | ಬಲ, ಅಥವಾ ದೋಷ | `@!` `$!` `!?` |

ನಂತರ ಬರುತ್ತದೆ **ಅಲ್ಲಿ ಏನು ಮಾಡಲಾಗುತ್ತದೆ**: `+` ಸೇರಿಸು, `-` ತೆಗೆ, `^` ಕ್ರಮ, `~` ಬದಲಾಯಿಸು, `#` ಎಣಿಸು, `|` ಒಂದು ಘಟಕ, `:` ಹೆಸರು ಬಂಧಿಸು.

ಮತ್ತು ಎಂದಿಗೂ ವಿಫಲವಾಗದ ಎರಡು ನಿಯಮಗಳು:

**ಒಂದು ಚಿಹ್ನೆಯನ್ನು ದ್ವಿಗುಣಗೊಳಿಸುವುದು ಅದನ್ನು ಸಂಪೂರ್ಣಗೊಳಿಸುತ್ತದೆ.** `?` ಒಮ್ಮೆ ಕೇಳುತ್ತದೆ, `??` ಅನೇಕ ಪ್ರಕರಣಗಳನ್ನು ಪರೀಕ್ಷಿಸುತ್ತದೆ. `$?` ಒಂದು ಮೌಲ್ಯ ಇದೆಯೇ ಎಂದು ಕೇಳುತ್ತದೆ, `$??` ಅದು ಇರುವ ಪ್ರತಿ ಸ್ಥಳವನ್ನೂ ಹಿಂತಿರುಗಿಸುತ್ತದೆ. `!` ಒಂದು ದೋಷವನ್ನು ಗುರುತಿಸುತ್ತದೆ, `!!` ಕೇಳದೆ ಅದನ್ನು ಹರಡುತ್ತದೆ.

**ಮೋಡ್ ಚಿಹ್ನೆ ಯಾವಾಗಲೂ ಕೊನೆಯಲ್ಲಿ ಬರುತ್ತದೆ.** `?` ಅಥವಾ `!` ಏನಾದರೂ *ಹೇಗೆ* ಮಾಡಲಾಗುತ್ತದೆ — ಸಂಕೋಚದಿಂದ ಅಥವಾ ಬಲವಂತದಿಂದ — ಎಂದು ಹೇಳಲು ಕಾಣಿಸಿಕೊಂಡಾಗ, ಅವು ನಿರ್ವಾಹಕದ ಕೊನೆಯ ಚಿಹ್ನೆಗಳು: `$??`, `$!!`, `<<|?`, `@!`, `##!`, `>>!`, `>>?`, `@:ಹೊರಗಿನ!`. ಅವುಗಳ ನಂತರ ಎಂದಿಗೂ ಒಂದು ಕಾರ್ಯಾಚರಣೆ ಇರುವುದಿಲ್ಲ.

ಅದರಿಂದ ಒಂದು ಪ್ರಾಯೋಗಿಕ ವಿಷಯ ಹೊರಬರುತ್ತದೆ: **ನೀವು ಎಂದಿಗೂ ನೋಡದ ಸಂಯೋಜನೆಯು, ಅದನ್ನು ನೋಡುವ ಮೊದಲೇ ಅರ್ಥಪೂರ್ಣವಾಗಿರುತ್ತದೆ.** `$` ಸಂಗ್ರಹ ಮತ್ತು `^` ಕ್ರಮ ಮತ್ತು `-` ವಿಲೋಮವಾಗಿದ್ದರೆ, `$^-` ಇಳಿಕೆ ಕ್ರಮದಲ್ಲಿ ಜೋಡಿಸುತ್ತದೆ, ಮತ್ತು ಯಾರೂ ನಿಮಗೆ ಹೇಳಬೇಕಾಗಿಲ್ಲ.

ಸಂಪೂರ್ಣ ಪಟ್ಟಿ ಈ ರೀತಿ ಕೆಲಸ ಮಾಡುವುದಿಲ್ಲ, ಮತ್ತು ಅದನ್ನು ಹೇಳುವುದು ನಟಿಸುವುದಕ್ಕಿಂತ ಉತ್ತಮ. ಬಹುಪಾಲು ನಿರ್ವಾಹಕಗಳು ಸ್ವಚ್ಛವಾಗಿ ಬೇರ್ಪಡುತ್ತವೆ. ಆರು ಬೇರ್ಪಡುತ್ತವೆ ಆದರೆ ಅವುಗಳ ಭಾಗಗಳಿಗಿಂತ ಹೆಚ್ಚು ಅರ್ಥೈಸುತ್ತವೆ: `!?` `:!` `:>` `|>` `::` `$++`. ಮತ್ತು ಹತ್ತು ನೆನಪಿಟ್ಟುಕೊಳ್ಳಬೇಕು ಏಕೆಂದರೆ ಅವು ಯಾವುದೇ ರೀತಿಯಲ್ಲಿ ಬೇರ್ಪಡುವುದಿಲ್ಲ: `¶` `><` `#1` `#0` `0x` `0b` `0o` `0d` `###` `°`.

> ಅಪಾರದರ್ಶಕವಾದವುಗಳನ್ನು ಎಣಿಸುವುದು, ಅವು ಕಡಿಮೆ ಎಂದು ಊಹಿಸುವ ಬದಲು ಉದ್ದೇಶಪೂರ್ವಕ: ಅವು ಭಾಷೆಯ ನಿಜವಾದ ಕಂಠಪಾಠ ವೆಚ್ಚ. ಸಂಪೂರ್ಣ ಉಲ್ಲೇಖ — ಪಟ್ಟಿ, ಘೋಷಿತ ಸಮಾನಾಕ್ಷರಗಳು, ಮತ್ತು ಹೊಸ ನಿರ್ವಾಹಕವು ಅಸ್ತಿತ್ವದಲ್ಲಿರಲು ಪೂರೈಸಬೇಕಾದ ನಿಯಮಗಳು — ಇಂಟರ್ಪ್ರಿಟರ್ ರೆಪೊಸಿಟರಿಯಲ್ಲಿ `SYMBOLS.md` ನಲ್ಲಿದೆ.

## ಬಿಡುಗಡೆ ಬದಲಾವಣೆಗಳ ದಾಖಲೆ

### v0.0.9 — ಸಂಗ್ರಹಗಳು ನಿರ್ಧರಿಸಿದವು _(ಸೆಪ್ಟೆಂಬರ್ 2026)_

- **ಮುರಿಯುವ** ನಿಘಂಟಿಗೆ ತನ್ನದೇ ಆದ ಸಂಕೇತವಿದೆ: `#(ಕೀ: ಮೌಲ್ಯ)`. ಬರಿ `(a: 1)` ತಿರಸ್ಕರಿಸಲಾಗುತ್ತದೆ, ಮತ್ತು `#()` ಖಾಲಿ ನಿಘಂಟು — ಅದು `()` ಆಗಿರಲು ಸಾಧ್ಯವಿರಲಿಲ್ಲ
- **ಮುರಿಯುವ** ಸೂಚ್ಯಂಕ ನಿಯೋಜನೆ ಹಿಂಪಡೆಯಲಾಗಿದೆ: `ಶ್ರೇಣಿ[i] = v` ಮತ್ತು ಎಲ್ಲಾ ಸಂಯುಕ್ತ ರೂಪಗಳು. `=` ಒಂದು **ಹೆಸರಿಗೆ** ಮೌಲ್ಯವನ್ನು ನೀಡುತ್ತದೆ; ಸಂಗ್ರಹದ ಒಂದು ಭಾಗವನ್ನು ಬದಲಾಯಿಸುವುದು `$~`
- **ಮುರಿಯುವ** ಸರಪಳಿ ಸೂಚ್ಯಂಕ `m[i][j]` ಓದಲು ಮತ್ತು ಬರೆಯಲು ಎರಡಕ್ಕೂ ತಿರಸ್ಕರಿಸಲಾಗುತ್ತದೆ — `>` ಎಂಬುದು ಹಂತಗಳ ನಡುವೆ ಹೋಗುವುದು
- **ಮುರಿಯುವ** ಒಂದು ಮಾಡ್ಯೂಲ್ ತಾನು ಏನನ್ನು ರಫ್ತು ಮಾಡುತ್ತದೆ ಎಂದು ಘೋಷಿಸಬೇಕು (**E014**); `#> { }` ಒಂದು ಮಾಡ್ಯೂಲ್ ತನ್ನ ಮೇಲ್ಮೈ ಖಾಲಿ ಎಂದು ಹೇಳುವ ವಿಧಾನ
- **ಮುರಿಯುವ** ಲೂಪ್ ನಿರ್ದಿಷ್ಟಕ ಎಣಿಕೆ ಅಥವಾ ಷರತ್ತು — ಸತ್ಯತೆ ಇಲ್ಲ. `@ []` ಮತ್ತು `@ 3.5` ತಿರಸ್ಕರಿಸಲಾಗುತ್ತದೆ
- **ಸೇರಿಸಲಾಗಿದೆ** `##_` — ಘಟಕ ಅಕ್ಷರಶಃ, ಮತ್ತು ಒಂದು ಪ್ರೋಗ್ರಾಂ ಏನಾದರೂ ಅನುಪಸ್ಥಿತವೇ ಎಂದು ಕೇಳುವ ವಿಧಾನ
- **ಸೇರಿಸಲಾಗಿದೆ** `#[…]` — ಒಂದು ಶ್ರೇಣಿ, ಅದರ ಅಂಶ ಪ್ರಕಾರಗಳ ಮಿಶ್ರಣವನ್ನು ಘೋಷಿಸಲಾಗಿದೆ
- **ಸೇರಿಸಲಾಗಿದೆ** `#?` ನಾಲ್ಕು ಸಂಗ್ರಹಗಳನ್ನು ಪ್ರತ್ಯೇಕಿಸುತ್ತದೆ: `##]` `##[` `##)` `##(`
- **ಸೇರಿಸಲಾಗಿದೆ** `std/time` — ಗಡಿಯಾರ ಮತ್ತು ನಾಗರಿಕ ಕ್ಯಾಲೆಂಡರ್, ವಲಯಗಳು ಮತ್ತು ಕ್ಯಾಲೆಂಡರ್ ಅಂಕಗಣಿತದೊಂದಿಗೆ
- **ಸೇರಿಸಲಾಗಿದೆ** ಉನ್ನತ ಮಟ್ಟದ `<~>` ಪ್ರೋಗ್ರಾಂನ ನಿರ್ಗಮನ ಸ್ಥಿತಿ
- **ಸೇರಿಸಲಾಗಿದೆ** `@ (k, v):ಜೋಡಿಗಳು` — ಲೂಪ್ ಶೀರ್ಷಿಕೆಯಲ್ಲಿ ಮಾದರಿ
- **ಸೇರಿಸಲಾಗಿದೆ** `#|c|` 69 ಲಿಪಿಗಳಲ್ಲಿ ಯಾವುದಾದರೂ ಅಂಕಿಯನ್ನು ಓದುತ್ತದೆ; `#,` ಮತ್ತು `#^` ಸಕ್ರಿಯ ಲಿಪಿಯಲ್ಲಿ ಬರೆಯುತ್ತವೆ
- **ಬದಲಾಗಿದೆ** `ಪೂರ್ಣಾಂಕ` ಒಂದು ಸುರಕ್ಷಿತ ಪೂರ್ಣಾಂಕ, ±(2⁵³ − 1), ಪ್ರತಿ ಇಂಜಿನ್‌ನಲ್ಲಿ ವಿಫಲ-ಮುಚ್ಚು
- **ಬದಲಾಗಿದೆ** ಹೆಸರಿನ ಫಂಕ್ಷನ್ ಕರೆ ಸಮಯದಲ್ಲಿ ಫೈಲ್‌ನ ಚರಗಳನ್ನು ಮೌಲ್ಯದಿಂದ ಓದುತ್ತದೆ
- **ಬದಲಾಗಿದೆ** ಕೇವಲ ಹೆಸರನ್ನು ಓದುವ ಹೇಳಿಕೆ ಮೌನವಾಗಿ ಹಾದುಹೋಗುವ ಬದಲು ಎಚ್ಚರಿಸುತ್ತದೆ
- **ಇಂಜಿನ್‌ಗಳು** 666 ಕಾರ್ಪಸ್ ಫೈಲ್‌ಗಳಲ್ಲಿ 660 ಮೂರು ಇಂಜಿನ್‌ಗಳಲ್ಲಿ ಒಪ್ಪುತ್ತವೆ, 0 ಭಿನ್ನ

### v0.0.8 — ಸ್ವಯಂ-ಮುಕ್ತಿ, `std/term` ಮತ್ತು ಪ್ಯಾಕೇಜ್‌ಗಳು _(ಆಗಸ್ಟ್ 2026)_

- **ಸೇರಿಸಲಾಗಿದೆ** ಕೊನೆಯ ಬಳಕೆಯಲ್ಲಿ ಸ್ವಯಂಚಾಲಿತ ವಿನಾಶ — ಅಗೋಚರ; ಗರಿಷ್ಠ ಮೆಮೊರಿಯನ್ನು ಮಾತ್ರ ಕಡಿಮೆ ಮಾಡುತ್ತದೆ
- **ಸೇರಿಸಲಾಗಿದೆ** `std/term` — ಟರ್ಮಿನಲ್ ಅಂಕಣಗಳಲ್ಲಿ ಪ್ರದರ್ಶನ ಮೆಟ್ರಿಕ್ಸ್
- **ಸೇರಿಸಲಾಗಿದೆ** ಒಂದು `ಅಕ್ಷರ` ಮೇಲೆ `##!` — ಅದರ ಯುನಿಕೋಡ್ ಕೋಡ್ ಪಾಯಿಂಟ್
- **ಸೇರಿಸಲಾಗಿದೆ** ಹೊಂದಾಣಿಕೆಯಲ್ಲಿ ಅಥವಾ-ಮಾದರಿ: `'p' || 'P' => …`, ಯಾವುದೇ ರೀತಿಯ ಪರ್ಯಾಯಗಳು ಒಂದು ಶಾಖೆಯಲ್ಲಿ
- **ಸೇರಿಸಲಾಗಿದೆ** Zymbol ಪ್ಯಾಕೇಜ್‌ಗಳು (`.zyp`) — `zymbol package` / `zymbol run pkg.zyp`
- **ಸೇರಿಸಲಾಗಿದೆ** ಕರೆ ಸ್ಥಳದಲ್ಲಿ `<~>` ಕಡ್ಡಾಯ, ಕರೆಯಲ್ಪಟ್ಟವನು ಔಟ್‌ಪುಟ್ ನಿಯತಾಂಕವನ್ನು ಘೋಷಿಸಿದಾಗ
- **ಸರಿಪಡಿಸಲಾಗಿದೆ** ರಿಜಿಸ್ಟರ್ VM ನಲ್ಲಿ ಮಾಡ್ಯೂಲ್ ಸಿಸ್ಟಮ್ ಸಮಾನತೆ

### v0.0.7 — ಸ್ಥಳೀಯ ಪ್ರಮಾಣಿತ ಗ್ರಂಥಾಲಯ _(ಜುಲೈ 2026)_

- **ಸೇರಿಸಲಾಗಿದೆ** `std/json`, `std/io`, `std/net`, `std/db` (ODBC) — ಎಲ್ಲವೂ ಮೃದು ದೋಷ ಮೌಲ್ಯಗಳೊಂದಿಗೆ
- **ಸೇರಿಸಲಾಗಿದೆ** ಟೈಪ್/ಪರಿಶೀಲಿತ ಇನ್‌ಪುಟ್: `<< ##.(5,2) "ಬೆಲೆ: " p`
- **ಸೇರಿಸಲಾಗಿದೆ** `>>` ನಲ್ಲಿ ನೇರವಾಗಿ ಪ್ರತ್ಯಯ ನಿರ್ವಾಹಕಗಳು — ಆವರಣಗಳ ಅಗತ್ಯವಿಲ್ಲ
- **ಬದಲಾಗಿದೆ** ವಿಫಲ-ಮುಚ್ಚು ಸ್ವರೂಪಕ: ಮತ್ತೆ ಓದಲಾಗದ ಔಟ್‌ಪುಟ್ ಬರೆಯಲು ನಿರಾಕರಿಸುತ್ತದೆ

### v0.0.6 — ಪರಿಷ್ಕರಣೆ ಮತ್ತು ವೈಜ್ಞಾನಿಕ Stdlib _(ಜೂನ್ 2026)_

- **ಮುರಿಯುವ** `=>` ಹೊಂದಾಣಿಕೆ ಶಾಖೆಗಳಲ್ಲಿ `:` ಮತ್ತು ಆಮದು/ರಫ್ತು ಅಲಿಯಾಸ್‌ಗಳಲ್ಲಿ `<=` ಅನ್ನು ಬದಲಾಯಿಸುತ್ತದೆ
- **ಸೇರಿಸಲಾಗಿದೆ** `std/math` ಮತ್ತು `std/random`
- **ಸೇರಿಸಲಾಗಿದೆ** ಕೀ ಮೂಲಕ ನಿಘಂಟು ನವೀಕರಣ: `d["k"]$~ ಮೌಲ್ಯ`

### v0.0.5 — TUI ಆದಿಮಗಳು ಮತ್ತು ಬಿಸಿ ವ್ಯಾಖ್ಯಾನ _(ಮೇ 2026)_

- **ಸೇರಿಸಲಾಗಿದೆ** TUI ಬ್ಲಾಕ್ `>>| { }`, ಸ್ಥಾನಿಕ ಔಟ್‌ಪುಟ್ `>>~`, ಕೀಲಿ ಇನ್‌ಪುಟ್ `<<|` ಮತ್ತು `<<|?`
- **ಸೇರಿಸಲಾಗಿದೆ** `>>!` ಪರದೆ ಅಳಿಸು, `>>?` ಟರ್ಮಿನಲ್ ಗಾತ್ರ, `@~ N` ನಿದ್ರಿಸು
- **ಸೇರಿಸಲಾಗಿದೆ** ಬಿಸಿ ವ್ಯಾಖ್ಯಾನ `°x` / `x°`, ಮತ್ತು ಸ್ಟ್ರಿಂಗ್ ಪುನರಾವರ್ತನೆ `$*`

### v0.0.4 — 1-ಆಧಾರಿತ ಸೂಚ್ಯಂಕ ಮತ್ತು ಪ್ರಥಮ-ದರ್ಜೆ ಫಂಕ್ಷನ್‌ಗಳು _(ಏಪ್ರಿಲ್ 2026)_

- **ಮುರಿಯುವ** ಎಲ್ಲಾ ಸೂಚ್ಯಂಕ **1-ಆಧಾರಿತ** — `ಶ್ರೇಣಿ[1]` ಮೊದಲ ಅಂಶ
- **ಸೇರಿಸಲಾಗಿದೆ** ಹೆಸರಿನ ಫಂಕ್ಷನ್‌ಗಳು ಪ್ರಥಮ-ದರ್ಜೆ ಮೌಲ್ಯಗಳಾಗಿ; ಮಾಡ್ಯೂಲ್ ಬ್ಲಾಕ್ ವಾಕ್ಯರಚನೆ `# ಹೆಸರು { }`
- **ಸೇರಿಸಲಾಗಿದೆ** ಬಹುಆಯಾಮೀಯ ಸೂಚ್ಯಂಕ `ಶ್ರೇಣಿ[i>j>k]` ಮತ್ತು ಸಮತಟ್ಟು ಹೊರತೆಗೆಯುವಿಕೆ `ಶ್ರೇಣಿ[p ; q]`

### v0.0.3 — ಯುನಿಕೋಡ್ ಸಂಖ್ಯಾ ವ್ಯವಸ್ಥೆಗಳು _(ಏಪ್ರಿಲ್ 2026)_

- **ಸೇರಿಸಲಾಗಿದೆ** 69 ಯುನಿಕೋಡ್ ಅಂಕಿ ಬ್ಲಾಕ್‌ಗಳು ಮೋಡ್-ಸ್ವಿಚ್ ಟೋಕನ್ `#d0d9#` ನೊಂದಿಗೆ
- **ಸೇರಿಸಲಾಗಿದೆ** ಯಾವುದೇ ಲಿಪಿಯಲ್ಲಿ ಬೂಲಿಯನ್ ಅಕ್ಷರಶಃಗಳು — `#१` / `#०`
