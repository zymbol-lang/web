# Zymbol-Lang માર્ગદર્શિકા

> **v0.0.9 માટે સુધારેલ — 2026-09-07**

**Zymbol-Lang** એક પ્રતીકાત્મક પ્રોગ્રામિંગ ભાષા છે. તેના વ્યાકરણમાં કોઈ શબ્દ નથી — દરેક રચના એક ચિહ્ન છે. કોઈપણ માનવ ભાષામાં સમાન રીતે કાર્ય કરે છે.

- `if`, `while`, `return` નથી — ફક્ત `?`, `@`, `<~`
- સંપૂર્ણ યુનિકોડ — કોઈપણ ભાષા કે ઇમોજીમાં ઓળખકર્તા

## ચલો અને સ્થિરાંકો

```zymbol
ચલ = ૧૦              // બદલી શકાય તેવું ચલ
PI := ૩.૧૪૧૫૯       // સ્થિરાંક — ફરી સોંપણી એ રનટાઇમ ભૂલ છે
નામ = "અમિત"
સક્રિય = #૧         // બુલિયન સત્ય
👋 := "નમસ્તે"
```

```zymbol
ચલ = ૧૦    // ૧૦
ચલ += ૫    // ૧૫
ચલ -= ૩    // ૧૨
ચલ *= ૨    // ૨૪
ચલ /= ૩    // ૮
ચલ %= ૩    // ૨
ચલ ^= ૨    // ૪
ચલ++       // ૫
ચલ--       // ૪
```

`°` (ડિગ્રી ચિહ્ન, U+00B0) પ્રથમ ઉપયોગ પર ચલને તેના તટસ્થ મૂલ્ય પર આપમેળે પ્રારંભ કરે છે:

```zymbol
આંકડા = [૩, ૧, ૪, ૧, ૫]
@ n:આંકડા {
    °કુલ += n
}
>> કુલ ¶              // → 14
```

> `°ચલ` (ઉપસર્ગ) લૂપની ઉપર એન્કર કરે છે — પરિણામ `@` પછી વાંચી શકાય છે.
> `ચલ°` (પ્રત્યય) લૂપની અંદર એન્કર કરે છે — લૂપ સમાપ્ત થાય ત્યારે તે મૃત્યુ પામે છે.

એક વિધાન જે ફક્ત નામ છે તે ચલ વાંચે છે અને મૂલ્ય ફેંકી દે છે, તેથી ચેતવણી આપે છે:

```zymbol
ગણતરી = ૫
ગણતરી
```

કમ્પાઇલર આ પ્રમાણે ચેતવણી આપે છે (તેના સંદેશા હંમેશા અંગ્રેજીમાં હોય છે):

```text
warning: this statement does nothing: 'ગણતરી' is read and discarded
  = help: remove it, or use it — `>> name ¶` to print it
```

એટલે: *«આ વિધાન કંઈ કરતું નથી: 'ગણતરી' વાંચવામાં આવ્યું અને ફેંકી દીધું»*.

## ડેટા પ્રકારો

| પ્રકાર | શાબ્દિક | `#?` ટેગ | નોંધ |
|------|---------|----------|-------|
| પૂર્ણાંક | `૪૨`, `-૭` | `###` | સુરક્ષિત પૂર્ણાંક: ±(2⁵³ − 1) |
| દશાંશ | `૩.૧૪`, `૧.૫e૧૦` | `##.` | IEEE-754 ડબલ |
| શબ્દમાળા | `"લખાણ"` | `##"` | આંતરબોધ: `"નમસ્તે {નામ}"` |
| અક્ષર | `'A'` | `##'` | એક યુનિકોડ કોડ પોઇન્ટ |
| બુલિયન | `#૧`, `#૦` | `##?` | સંખ્યાત્મક નથી — `#૧ ≠ ૧` |
| એરે | `[૧, ૨, ૩]` | `##]` | એક પ્રકાર, ચકાસાયેલ |
| જાહેર કરેલ મિશ્રણ | `#[૧, "બે"]` | `##[` | `[…]` જેવો પ્રકાર, ચકાસાયેલ નથી |
| ટ્યુપલ | `(a, b)` | `##)` | સ્થિતિસ્થાપક, અપરિવર્તનીય |
| શબ્દકોશ | `#(a: ૧, b: ૨)` | `##(` | કી-આધારિત, બદલી શકાય |
| ફંક્શન | નામવાળું ફંક્શન સંદર્ભ | `##()` | પ્રથમ-શ્રેણી; દર્શાવે `<funct/N>` |
| લેમ્બડા | `a -> a * ૨` | `##->` | પ્રથમ-શ્રેણી; દર્શાવે `<lambd/N>` |
| એકમ | `##_` | `##_` | ગેરહાજરી — null નથી |

```zymbol
>> ૪૨#? ¶               // → (###, 2, 42)
>> [૧, ૨, ૩]#? ¶        // → (##], 3, [1, 2, 3])
>> #(a: ૧)#? ¶          // → (##(, 1, #(a: 1))
```

સુરક્ષિત શ્રેણીની બહાર જતો પૂર્ણાંક એ પકડી શકાય તેવી ભૂલ છે, ક્યારેય શાંત વળાંક નથી:

```zymbol
!? {
    >> (૯૦૦૭૧૯૯૨૫૪૭૪૦૯૯૧ + ૧) ¶
} :! ##Range {
    >> "શ્રેણીની બહાર" ¶ // → શ્રેણીની બહાર
}
```

`##_` એ કાર્યક્રમ પૂછવાની રીત છે કે કંઈક ગેરહાજર છે કે નહીં:

```zymbol
કંઈ_નથી() { }
મૂલ્ય = કંઈ_નથી()
>> (મૂલ્ય == ##_) ¶     // → #1
```

## આઉટપુટ અને ઇનપુટ

```zymbol
નામ = "અમિત"
કુલ = ૩
>> "નમસ્તે" ¶             // → નમસ્તે
>> "a=" નામ " b=" કુલ ¶ // → a=અમિત b=3
>> કુલ#? ¶            // → (###, 1, 3)
```

```zymbol
<< નામ
<< "તમારું નામ દાખલ કરો: " નામ
<< ###(૪) "ઉંમર: " ઉંમર
```

**બે ચિહ્નોનો આકાર જુઓ.** `>>` બહાર તરફ નિર્દેશ કરે છે: તે ડેટાને કાર્યક્રમની બહાર લે છે. `<<` અંદર તરફ નિર્દેશ કરે છે: તે ડેટાને કાર્યક્રમમાં લાવે છે. અહીં યાદ રાખવા જેવું કંઈ નથી — તીર બતાવે છે કે માહિતી કઈ દિશામાં મુસાફરી કરે છે, અને તે જ વિચાર દરેક ચિહ્નમાં પાછો આવે છે જે કંઈક ખસેડે છે.

> `¶` અને `\\` સમાન નવી લાઇનો છે. `>>` ક્યારેય એક ઉમેરતું નથી.
> પ્રોમ્પ્ટ પહેલાંનું પ્રકાર નિર્દેશક વાંચતી વખતે માન્ય કરે છે અને મૂલ્ય માન્ય થાય ત્યાં સુધી ફરી પૂછે છે:
> `##.` દશાંશ · `##.(T,D)` દશાંશ · `###(N)` પૂર્ણાંક · `##"(N)"` લખાણ · `##'` એક અક્ષર.

ફાઇલના ઉપલા સ્તરે, `<~>` કાર્યક્રમની બહાર નીકળવાની સ્થિતિ છે:

```zymbol
>> "ચકાસી રહ્યું છે" ¶      // → ચકાસી રહ્યું છે
<~ ૦
```

## TUI આદિમ

ઇન્ટરેક્ટિવ કાર્યક્રમો માટે ટર્મિનલ UI ઓપરેટર. મોટાભાગના માટે `>>| { }` બ્લોક જરૂરી છે (વૈકલ્પિક સ્ક્રીન + કાચી સ્થિતિ).

```zymbol
>>| {
    >>!
    >>~ (૧, ૧, ૦, ૧૦) > "ચાલી રહ્યું છે"
    @~ ૧૦૦૦
    >>~ (૨, ૧) > "પૂર્ણ."
}
```

```zymbol
>>| {
    [પંક્તિઓ, સ્તંભો] = >>?
    >>~ (૧, ૧) > "ટર્મિનલ: " પંક્તિઓ " x " સ્તંભો
    <<| કી
    >>~ (૨, ૧) > "દબાવ્યું: " કી
}
```

અહીં તમે જોઈ શકો છો કે ચિહ્નો કેમ ગુણાકાર થવાને બદલે જોડાય છે. તમે પહેલેથી જાણો છો કે `<<` ઇનપુટ છે અને `?` પ્રતિબદ્ધતા વિના પૂછે છે. ફક્ત એક ચિહ્ન નવું છે:

- `|` એ **એક એકમ** છે, આખો પ્રવાહ નથી.

તેની સાથે, બંને કીબોર્ડ ઓપરેટર પોતાને વાંચે છે:

```text
<<        |             ?
ઇનપુટ     એક એકમ        પ્રતિબદ્ધતા વિના

<<|   એક કી લો, અને એક આવે ત્યાં સુધી રાહ જુઓ
<<|?  જુઓ કે કી છે કે નહીં, અને ન હોય તો ચાલુ રાખો
```

બીજી બાજુ પણ એ જ: `>>` મોકલે છે, `>>!` **જબરદસ્તીથી** મોકલે છે (આખી સ્ક્રીન સાફ કરે છે), જ્યારે `>>?` લખવાને બદલે **પૂછે** છે (ટર્મિનલ કેટલું મોટું છે). જમણી બાજુનું ચિહ્ન તે છે જે સ્થિતિ બદલે છે, અને તે હંમેશા છેલ્લે આવે છે.

> `>>!` સ્ક્રીન સાફ કરે છે. `>>?` `[પંક્તિઓ, સ્તંભો]` પરત આપે છે. `@~ N` N મિલિસેકન્ડ સૂએ છે.
> `<<|` એક કી દબાવવાનું વાંચે છે (અવરોધક); `<<|?` અવરોધ કર્યા વિના પોલ કરે છે (`'\0'` જો કોઈ નથી).
> તીર કી `'↑' '↓' '←' '→'` તરીકે ડિકોડ થાય છે; ESC કોડ પોઇન્ટ 27 છે.
> સ્થિતિ આઉટપુટ ટ્યુપલ: `(પંક્તિ, સ્તંભ, BKS, આગળ, પાછળ)` — કોઈપણ સ્લોટ અલ્પવિરામથી છોડી શકાય (`>>~ (,,, ૧૯૬) > "લાલ"`).
> BKS બિટમાસ્ક: `1`=જાડું, `2`=તિર્યક, `4`=નીચે લીટી. ANSI 256-રંગ પેલેટ (`0`=ટર્મિનલ ડિફોલ્ટ).

## ઓપરેટર

```zymbol
a = ૧૦
b = ૩
પ૧ = a + b    // ૧૩
પ૨ = a - b    // ૭
પ૩ = a * b    // ૩૦
પ૪ = a / b    // ૩  (પૂર્ણાંક ભાગાકાર)
પ૫ = a % b    // ૧
પ૬ = a ^ b    // ૧૦૦૦
```

```zymbol
a = ૧૦
b = ૩
સ૧ = a == b    // #૦
સ૨ = a <> b    // #૧
સ૩ = a < b     // #૦
સ૪ = a >= b    // #૧
લ૧ = #૧ && #૦  // #૦
લ૨ = !#૧       // #૦
```

> `==` ક્યારેય દબાણ કરતું નથી: `"5" == 5` એ `#0` છે. ક્રમ દબાણ કરે છે: `"5" > 4` એ `#1` છે, અને `"४२" > 5` પણ — 69 લિપિઓમાંથી કોઈપણમાં સંખ્યાત્મક લખાણ સંખ્યા તરીકે સરખાવે છે.
> ફંક્શન ફક્ત પોતાની સાથે સમાન છે, કદી સમાન શરીર ધરાવતા બીજા ફંક્શન સાથે સમાન નથી.

```zymbol

n = ૪૨
>> "નમસ્તે " નામ " તમારી પાસે " n " છે" ¶ // → નમસ્તે અમિત તમારી પાસે 42 છે
```

```zymbol
s = "નમસ્તે દુનિયા"
લંબાઈ = s$#                  // ૧૩
```

## નિયંત્રણ પ્રવાહ

```zymbol
a = ૭
? a > ૧૦૦ {
    >> "મોટું" ¶
} _? a > ૦ {
    >> "ધન" ¶     // → ધન
} _ {
    >> "ઋણ" ¶
}
```

અહીં બે નવા ચિહ્નો છે, અને ત્રીજું તેમને એકસાથે મૂકવાથી આવે છે:

- `?` **પૂછવું** છે: તે શરત ખોલે છે.
- `_` **જે નિર્દિષ્ટ નથી** તે છે: જ્યારે કોઈ પ્રશ્ન મેળ ખાતો નથી ત્યારે બાકી રહેતી શાખા.
- `_?` બંને સળંગ: *જો કંઈ મેળ ન ખાય, ફરી પૂછો*.

તેથી જ `_?` આ રીતે લખાય છે. તે શીખવા માટેનું નવું પ્રતીક નથી — તે `_` પછી `?` છે, અને તેનો અર્થ બરાબર તેના બે ભાગોનો અર્થ છે, ક્રમમાં વાંચેલા.

> કૌંસ `{ }` એક વિધાન માટે પણ **ફરજિયાત** છે.

## મેળ

```zymbol
ગુણ = ૮૫
શ્રેણી = ?? ગુણ {
    ૯૦..૧૦૦ => 'A'
    ૮૦..૮૯  => 'B'
    _       => 'F'
}
>> શ્રેણી ¶              // → B
```

```zymbol
તાપમાન = -૫
સ્થિતિ = ?? તાપમાન {
    < ૦  => "બરફ"
    < ૨૦ => "ઠંડું"
    _    => "ગરમ"
}
>> સ્થિતિ ¶              // → બરફ
```

તમે પહેલેથી જાણો છો કે `?` "પૂછવું" છે. **`??` ઘણી વાર પૂછવું** છે: ભાષામાં ક્યાંય પણ ચિહ્નને બમણું કરવું એ ચિહ્ન જે એક વાર કરે છે તે ઘણી વાર કરવું છે. એક `?` એક શરત ચકાસે છે; `??` કેસોની યાદી સામે ચકાસે છે.

વૈકલ્પિકો `||` સાથે જોડાય છે, અને પેટર્ન પ્રકારોને મિશ્ર કરી શકે છે:

```zymbol
કી = 'P'
ક્રિયા = ?? કી {
    'p' || 'P' => "થોભો"
    < ૦ || > ૧૦૦ => "શ્રેણીની બહાર"
    _ => "અવગણેલ"
}
>> ક્રિયા ¶             // → થોભો
```

## લૂપ

```zymbol
@ i:૧..૪  { >> i " " }
>> ¶                    // → 1 2 3 4
@ i:૧..૯:૨ { >> i " " }
>> ¶                    // → 1 3 5 7 9
@ i:૫..૧:૧ { >> i " " }
>> ¶                    // → 5 4 3 2 1
```

```zymbol
n = ૧
@ n <= ૬૪ { n *= ૨ }
>> n ¶                  // → 128
```

```zymbol
ફળ = ["સેબ", "નાસપતી", "દ્રાક્ષ"]
@ ફ:ફળ { >> ફ " " }
>> ¶                    // → સેબ નાસપતી દ્રાક્ષ
@ અ:"નમસ્તે" { >> અ "-" }
>> ¶                    // → ન-મ-સ-્-ત-ે-
```

```zymbol
@ i:૧..૧૦ {
    ? i % ૨ == ૦ { @> }
    ? i > ૭ { @! }
    >> i " "
}
>> ¶                    // → 1 3 5 7
```

```zymbol
ગણતરી = ૦
@:બહાર {
    ગણતરી++
    ? ગણતરી >= ૩ { @:બહાર! }
}
>> ગણતરી ¶             // → 3
```

`@` **સમય**નું ચિહ્ન છે: જે પુનરાવર્તન થાય છે તે બધું તેમાં જીવે છે. તે સમયને કાપવા માટે તમે તેની બાજુમાં એક ચિહ્ન ઉમેરો છો:

- `@!` — `!` **જબરદસ્તી** છે: હવે લૂપ છોડો.
- `@>` — `>` આગળ ધકેલે છે: આગળના વળાંક પર જાઓ.
- `@:બહાર!` — `:` **નામ બાંધે છે**, તેથી આ *બહાર* નામના લૂપને કાપે છે, નજીકના એકને નહીં.

ત્રણ ઓપરેટર, અને તેમાંથી કોઈને અલગથી યાદ રાખવાની જરૂર ન પડી: તે `@` વત્તા એક ચિહ્ન છે જે પહેલેથી જ કહે છે કે તે શું કરે છે.

> **નિર્દેશક એ ગણતરી કે શરત છે.** `પૂર્ણાંક` એ ગણતરી છે, એક વાર મૂલ્યાંકન થાય છે — `@ ૦` શરીરને શૂન્ય વાર ચલાવે છે. બાકીનું બધું શરત છે. સત્યતા નથી: `@ []` અને `@ ૩.૫` નકારાય છે. સંગ્રહને પસાર કરવા `@ x:વસ્તુઓ` વાપરો; ગણવા માટે, `@ વસ્તુઓ$#`.

## ફંક્શન

```zymbol
સરવાળો(a, b) { <~ a + b }
>> સરવાળો(૩, ૪) ¶        // → 7
```

```zymbol
ફેક્ટોરિયલ(n) {
    ? n <= ૧ { <~ ૧ }
    <~ n * ફેક્ટોરિયલ(n - ૧)
}
>> ફેક્ટોરિયલ(૫) ¶       // → 120
```

ફંક્શન ફાઇલના ચલોને મૂલ્ય દ્વારા વાંચે છે, અને અંદરનું લખાણ અંદર જ રહે છે:

```zymbol
મર્યાદા = ૧૦૦
અંદર(n) { <~ n < મર્યાદા }
>> અંદર(૪૨) ¶         // → #1
```

બે ચિહ્નો તેને બદલે છે, અને બંને **સહી અને કૉલ સાઇટ** પર લખાય છે:

```zymbol
વધારો(ગણતરી<~) { ગણતરી = ગણતરી + ૧ }
કુલ = ૦
વધારો(કુલ<~)
>> કુલ ¶              // → 1
```

> `p~` એ કાર્યકારી નકલ છે — શરીર તેને ફરી સોંપી શકે છે અને કૉલર અસ્પૃષ્ટ રહે છે.
> `p<~` એ આઉટપુટ પરિમાણ છે — ફેરફાર પાછો આવે છે. ચિહ્ન વગરનું `વધારો(કુલ)` એ અર્થશાસ્ત્રીય ભૂલ છે: નોંધ અને સહી અલગ થઈ શકતી નથી.

## લેમ્બડા અને ક્લોઝર

```zymbol
બમણું = a -> a * ૨
સરવાળો = (a, b) -> a + b
>> બમણું(૫) ¶          // → 10
>> સરવાળો(૩, ૭) ¶          // → 10
```

```zymbol
વર્ગીકરણ = a -> {
    ? a > ૦ { <~ "ધન" }
    _? a < ૦ { <~ "ઋણ" }
    <~ "શૂન્ય"
}
>> વર્ગીકરણ(-૪) ¶         // → ઋણ
```

```zymbol
અવયવ = ૩
ત્રણગણું = a -> a * અવયવ
>> ત્રણગણું(૭) ¶          // → 21
```

```zymbol
સરવાળો_બનાવો(n) { <~ a -> a + n }
સરવાળો૧૦ = સરવાળો_બનાવો(૧૦)
>> સરવાળો૧૦(૫) ¶           // → 15
```

લેમ્બડા કોઈ પણ પરિમાણ ન લે:

```zymbol
જવાબ = () -> ૪૨
>> જવાબ() ¶           // → 42
```

> લેમ્બડા ફાઇલના ચલોને **બનાવવામાં આવે ત્યારે** પકડે છે; નામવાળું ફંક્શન તેમને **બોલાવવામાં આવે ત્યારે** વાંચે છે.

## એરે

```zymbol
એરે = [૧, ૨, ૩, ૪, ૫]
>> એરે[૧] ¶       // → 1   અનુક્રમણિકા 1-આધારિત છે
>> એરે[-૧] ¶      // → 5   ઋણ અંતથી ગણે છે
>> એરે$# ¶        // → 5   લંબાઈ
```

```zymbol
એરે = [૧, ૨, ૩]
>> (એરે$+ ૬) ¶          // → [1, 2, 3, 6]   ઉમેરો
>> (એરે$+[૨] ૯૯) ¶      // → [1, 99, 2, 3]  સ્થાન 2 પર દાખલ કરો
>> (એરે$- ૩) ¶          // → [1, 2]         પ્રથમ ઘટના દૂર કરો
>> (એરે$-[૧]) ¶         // → [2, 3]         અનુક્રમણિકા 1 પર દૂર કરો
>> (એરે$[૧..૨]) ¶       // → [1, 2]         સ્લાઇસ, બંને છેડા સમાવેશ
>> (એરે$? ૩) ¶          // → #1             સમાવે છે
```

બધા `$` થી શરૂ થાય છે, જે **સંગ્રહ**નું ચિહ્ન છે, અને તેમાં શું થાય છે તે કહેતા ચિહ્ન સાથે ચાલુ રહે છે: `#` કેટલા, `+` ઉમેરો, `-` દૂર કરો, `?` છે કે નહીં પૂછો. અને `??` ની જેમ, ચિહ્નને બમણું કરવું એ તેને સંપૂર્ણ રીતે કરવું છે: `$?` પૂછે છે કે મૂલ્ય *છે* કે નહીં, `$??` પૂછે છે *કેટલી જગ્યાએ* અને તે બધા પરત આપે છે.

```zymbol
એરે = [૩, ૧, ૨]
>> (એરે$^+) ¶     // → [1, 2, 3]   ચઢતું
>> (એરે$^-) ¶     // → [3, 2, 1]   ઉતરતું
```

**પરિણામનો નિયમ.** એક ઓપરેટર, અને આસપાસનો કોડ તેની સાથે શું કરે છે તે નક્કી કરે છે: વપરાય તો તે **બાંધે** છે અને મૂળને અસ્પૃષ્ટ રાખે છે; ફેંકાય તો તે **બદલે** છે.

```zymbol
એરે = [૧, ૨, ૩]
નકલ = એરે[૨]$~ ૯૯
>> એરે ¶                // → [1, 2, 3]
>> નકલ ¶              // → [1, 99, 3]
એરે[૨]$~ ૯૯
>> એરે ¶                // → [1, 99, 3]
```

> **`=` ક્યારેય સંગ્રહમાં લખતું નથી.** `એરે[૨] = ૯૯` એ Zymbol નું સ્વરૂપ નથી — `=` એ **નામ**ને મૂલ્ય આપે છે. સંગ્રહનો ભાગ બદલવો એ `$~` છે, દરેક સંગ્રહમાં.

`[…]` એક પ્રકાર ધરાવે છે અને ચકાસાય છે; ઇરાદાપૂર્વકનું મિશ્રણ `#[…]` સાથે **જાહેર** થાય છે:

```zymbol
મિશ્રણ = #[૧, "બે", #૧]
>> મિશ્રણ ¶             // → [1, બે, #1]
>> ([૧, ૨] == #[૧, ૨]) ¶ // → #1
```

## બહુપરિમાણીય અનુક્રમણિકા

`>` નેસ્ટેડ રચનામાં નીચે જાય છે. કૌંસનું એક જૂથ એક તત્વને સંબોધે છે, ભલે તે કેટલું ઊંડું હોય.

```zymbol
m = [[૧,૨,૩], [૪,૫,૬], [૭,૮,૯]]
>> m[૨>૩] ¶        // → 6   પંક્તિ 2, સ્તંભ 3
>> m[-૧>-૧] ¶      // → 9   છેલ્લી પંક્તિ, છેલ્લો સ્તંભ
```

```zymbol
m = [[૧,૨,૩], [૪,૫,૬], [૭,૮,૯]]
>> m[૧>૧ ; ૨>૨ ; ૩>૩] ¶          // → [1, 5, 9]          સપાટ: કર્ણ
>> m[[૧>૧, ૧>૩] ; [૩>૧, ૩>૩]] ¶  // → [[1, 3], [7, 9]]   રચનાબદ્ધ: ખૂણા
```

```zymbol
m = [[૧,૨,૩], [૪,૫,૬]]
>> (m[૧>૨]$~ ૯૯) ¶      // → [[1, 99, 3], [4, 5, 6]]
```

> `m[૧][૨]` એ Zymbol નું સ્વરૂપ **નથી**. શૃંખલાબદ્ધ અનુક્રમણિકા વાંચવા અને લખવા બંને માટે નકારાય છે — પ્રતિ એક્સેસ એક કૌંસ જૂથ, અને `>` એ છે જે પગલાંઓ વચ્ચે જાય છે.

## શબ્દકોશ

નામવાળા ક્ષેત્રોવાળું ટ્યુપલ એક શબ્દકોશ છે, અને v0.0.9 થી તે `#(…)` તરીકે લખાય છે.

```zymbol
વ્યક્તિ = #(નામ: "અમિત", ઉંમર: ૨૫)
>> વ્યક્તિ.નામ ¶        // → અમિત
>> વ્યક્તિ["ઉંમર"] ¶    // → 25
```

```zymbol
વ્યક્તિ = #(નામ: "અમિત", ઉંમર: ૨૫)
ક્ષેત્ર = "નામ"
>> વ્યક્તિ[ક્ષેત્ર] ¶     // → અમિત
```

તે બદલી શકાય છે, કી ઉમેરી શકાય છે, અને તેને પસાર કરી શકાય છે:

```zymbol
સ્ટોક = #(નાસપતી: ૪)
સ્ટોક["સેબ"]$~ ૧૦
@ k:સ્ટોક { >> k "=" સ્ટોક[k] " " }
>> ¶                    // → નાસપતી=4 સેબ=10
```

```zymbol
સ્ટોક = #(નાસપતી: ૪, સેબ: ૧૦)
@ (k, v):સ્ટોક { >> k ":" v " " }
>> ¶                    // → નાસપતી:4 સેબ:10
```

> `#()` ખાલી શબ્દકોશ છે, જે `()` હોઈ શકતું નથી — તે ખાલી ટ્યુપલ પણ હોવું પડશે. નગ્ન `(a: 1)` આ સંદેશ સાથે નકારાય છે: *a dictionary is written `#(…)`* — «શબ્દકોશ `#(…)` લખાય છે».
> શબ્દકોશ કી દ્વારા સંબોધાય છે, કદી સ્થિતિ દ્વારા નહીં, તેથી `વ્યક્તિ[1]` એ ભૂલ છે.

## ટ્યુપલ

ટ્યુપલ **અપરિવર્તનીય** ક્રમબદ્ધ કન્ટેનર છે જે વિવિધ પ્રકારોની કિંમતો રાખે છે.

```zymbol
બિંદુ = (૧૦, ૨૦)
>> બિંદુ[૧] ¶           // → 10
ડેટા = (૪૨, "નમસ્તે", #૧, ૩.૧૪)
>> ડેટા[૩] ¶            // → #1
```

```zymbol
t = (૧૦, ૨૦, ૩૦)
t2 = t[૨]$~ ૯૯૯
>> t ¶                  // → (10, 20, 30)
>> t2 ¶                 // → (10, 999, 30)
```

> ટ્યુપલને તેની જગ્યાએ બદલવાનો કોઈપણ પ્રયાસ એ ભૂલ છે, ઓપરેટર ગમે તે હોય — અપરિવર્તનીયતા મૂલ્યની મિલકત છે, દરેક `$` ની અંદર અપવાદ નથી.

## ઉચ્ચ-ક્રમ ફંક્શન

```zymbol
સંખ્યાઓ = [૧, ૨, ૩, ૪, ૫]
>> (સંખ્યાઓ$> (a -> a * ૨)) ¶ // → [2, 4, 6, 8, 10]
>> (સંખ્યાઓ$| (a -> a % ૨ == ૦)) ¶ // → [2, 4]
>> (સંખ્યાઓ$< (૦, (સંચય, a) -> સંચય + a)) ¶ // → 15
```

```zymbol
સંખ્યાઓ = [૧, ૨, ૩, ૪, ૫, ૬]

મોટું(a) { <~ a > ૩ }
>> (સંખ્યાઓ$> બમણું) ¶    // → [2, 4, 6, 8, 10, 12]
>> (સંખ્યાઓ$| મોટું) ¶    // → [4, 5, 6]
```

```zymbol
આધાર = [#(નામ: "કાર્લા", ઉંમર: ૨૮), #(નામ: "પ્રિયા", ઉંમર: ૨૫)]
```

## ભૂલ સંચાલન

```zymbol
!? {
    a = ૧૦ / ૦
} :! ##Div {
    >> "શૂન્ય દ્વારા ભાગાકાર" ¶  // → શૂન્ય દ્વારા ભાગાકાર
```

| `##Range` | સુરક્ષિત પૂર્ણાંક શ્રેણીની બહાર |
| `##Type` | પ્રકાર મેળ નથી |
| `##Parse` | ડેટા પાર્સિંગ |
| `##IO` | ફાઇલ / સિસ્ટમ |
| `##Network` | નેટવર્ક ભૂલો |
| `##DB` | ડેટાબેસ |
| `##Time` | અસ્તિત્વમાં ન હોય તેવી તારીખ |
| `##_` | કોઈપણ ભૂલ (બધું પકડનાર) |

`!` **ભૂલ અને જબરદસ્તી**નું ચિહ્ન છે, અને તે બંને કુટુંબોમાં સમાન રીતે વંચાય છે: `$!` મૂલ્યને પૂછે છે કે તે ભૂલ છે કે નહીં; `$!!`, ચિહ્ન બમણું કરીને, પૂછ્યા વિના તેને ઉપર ફેલાવે છે.

> પ્રમાણભૂત લાઇબ્રેરીની નિષ્ફળતાઓ **નરમ ભૂલ મૂલ્યો** તરીકે પાછી આવે છે જેને તમે `$!` થી ચકાસો છો અથવા `!?` થી પકડો છો, બંધ કરવાને બદલે. `$!!` એકને કૉલર સુધી ફેલાવે છે.

## મોડ્યુલ

```zymbol
# કેલ્ક {
    #> { સરવાળો, PI }

    PI := ૩.૧૪૧૫૯
    સરવાળો(a, b) { <~ a + b }
}
```

```zymbol
<# ./કેલ્ક => c

>> c::સરવાળો(૫, ૩) ¶
>> c.PI ¶
```

```zymbol
# મારી_લાઇબ્રેરી {
    #> { આંતરિક_સરવાળો => કુલ }

    આંતરિક_સરવાળો(a, b) { <~ a + b }
}
```

બંને મોડ્યુલ ચિહ્નો એક જ વિચાર છે, હવે ફાઇલો પર લાગુ થાય છે: `#` **જાહેરાત**નું સ્તર છે — વસ્તુ *શું છે*, તેની કિંમત નહીં — અને તીર કહે છે કે કોડ કઈ દિશામાં મુસાફરી કરે છે:

```text
<#   તીર પ્રવેશે છે: આયાત કરો, બીજી ફાઇલમાંથી લાવો
#>   તીર બહાર નીકળે છે: નિકાસ કરો, બીજી ફાઇલોને ઓફર કરો
```

દિશા ચિહ્ન હંમેશા તે ધાર પર બેસે છે જે તે તરફ નિર્દેશ કરે છે. `<~` ડાબે પાછું આવવાનું (ફંક્શનની બહાર) અને `->` જમણે પ્રવેશ કરવાનું (લેમ્બડાના શરીરમાં) તે જ કારણ છે.

> **મોડ્યુલ જાહેર કરે છે કે તે શું નિકાસ કરે છે.** `#>` બ્લોક ફરજિયાત છે — તેને છોડવું **E014** છે, અને `#> { }` એ મોડ્યુલ તેની સપાટી ખાલી છે તે કહેવાની રીત છે. `::` ફંક્શન બોલાવે છે, `.` સ્થિરાંક વાંચે છે. મોડ્યુલ શરીરમાં ફક્ત આયાત, નિકાસ બ્લોક, શાબ્દિક પ્રારંભિક અને ફંક્શન વ્યાખ્યાઓ દેખાઈ શકે છે; કોઈપણ ચલાવી શકાય તેવી વસ્તુ **E013** છે.

## અંકીય સ્થિતિઓ

Zymbol સંખ્યાઓને **69 યુનિકોડ અંક લિપિઓ**માં લખી શકે છે — દેવનાગરી, અરબી-ભારતીય, થાઈ, ક્લિંગન pIqaD, ગાણિતિક બોલ્ડ, LCD સેગમેન્ટ, અને વધુ. સ્થિતિ પ્રક્રિયા માટે વૈશ્વિક છે અને આઉટપુટને અસર કરે છે; અંકગણિત બદલાતું નથી.

```zymbol
#૦૯#    // ગુજરાતી   (U+0AE6–U+0AEF)
#०९#    // દેવનાગરી   (U+0966–U+096F)
#٠٩#    // અરબી-ભારતીય (U+0660–U+0669)
#09#    // ASCII પર ફરી સેટ
```

```zymbol
a = ૪૨
>> a ¶                  // → 42
#૦૯#
>> a ¶                  // → ૪૨
>> ૩.૧૪ ¶               // → ૩.૧૪
>> #૧ ¶                 // → #૧
#09#
```

કોઈપણ સમર્થિત લિપિના અંકો સ્રોતમાં માન્ય શાબ્દિક છે:

```zymbol
#૦૯#
@ i:૧..૫ { >> i " " }
>> ¶                    // → ૧ ૨ ૩ ૪ ૫
#09#
```

વાંચન સમપ્રમાણ છે — અંક કોઈપણ લિપિમાં સમજાય છે:

```zymbol
>> #|"४२"| ¶            // → 42
>> #|'७'| ¶             // → 7
```

> `#` હંમેશા ASCII છે, તેથી `#0` દરેક લિપિમાં અંક શૂન્યથી દૃશ્યતઃ અલગ રહે છે.
> `#,` અને `#^` પણ તેમના અંકો સક્રિય લિપિમાં લખે છે, અને વિભાજકો તેને અનુસરે છે — પણ જોડી કદી ઉલટાતી નથી: `,` જૂથ બનાવે છે અને `.` વિભાજિત કરે છે, દરેક લિપિમાં.

## ડેટા ઓપરેટર

```zymbol

>> 0b01000001 ¶  // → A   દ્વિસંખ્યા
>> 0o101 ¶       // → A   અષ્ટ
>> 0d65 ¶        // → A   દશ
```

> ASCII શ્રેણીમાંનું આધાર શાબ્દિક એક **અક્ષર** છે: `0d65 == 'A'` એ `#1` છે, અને `0d65 == 65` એ `#0` છે. ચારેય આધારો એક જ અક્ષરની જોડણી કરે છે.

## ચિહ્નો કેવી રીતે જોડાય છે

તમે આ સમગ્ર માર્ગદર્શિકામાં એક જ વસ્તુ જોઈ રહ્યા છો: **ઓપરેટર યાદ રાખવા માટેનું ચિત્ર નથી, તે એક પંક્તિમાં ઘણા ચિહ્નો છે, અને દરેક તેનો અર્થ આપે છે.** હવે જ્યારે તમે તે બધા જાણો છો, અહીં સંપૂર્ણ પેટર્ન છે.

પહેલા આવે છે **આપણે કઈ દુનિયામાં છીએ**:

| ચિહ્ન | દુનિયા | તમે તેને ક્યાં જોયું |
|--------|-------|----------------------------|
| `$` | એક સંગ્રહ | `$#` `$+` `$?` `$^-` |
| `@` | સમય, જે પુનરાવર્તન થાય | `@!` `@>` `@~` |
| `#` | વસ્તુ *શું છે*, તેની કિંમત નહીં | `#?` `#(…)` `<#` `#>` |
| `>>` | કાર્યક્રમની બહાર | `>>` `>>!` `>>?` |
| `<<` | કાર્યક્રમમાં અંદર | `<<` `<<\|` `<<\|?` |
| `?` | પૂછવું, પ્રતિબદ્ધતા વિના | `?` `_?` `??` `$?` |
| `!` | જબરદસ્તી, અથવા ભૂલ | `@!` `$!` `!?` |

પછી આવે છે **ત્યાં શું થાય છે**: `+` ઉમેરો, `-` દૂર કરો, `^` ક્રમ, `~` સુધારો, `#` ગણો, `|` એક એકમ, `:` નામ બાંધો.

અને બે નિયમો જે કદી નિષ્ફળ થતા નથી:

**ચિહ્નને બમણું કરવું તેને સંપૂર્ણ બનાવે છે.** `?` એક વાર પૂછે છે, `??` ઘણા કેસ ચકાસે છે. `$?` પૂછે છે કે મૂલ્ય છે કે નહીં, `$??` તે જ્યાં છે તે દરેક જગ્યા પરત આપે છે. `!` ભૂલ ચિહ્નિત કરે છે, `!!` પૂછ્યા વિના તેને ફેલાવે છે.

**સ્થિતિ ચિહ્ન હંમેશા છેલ્લે આવે છે.** જ્યારે `?` અથવા `!` એ કહેવા માટે દેખાય કે કંઈક *કેવી રીતે* થાય છે — અનિશ્ચિતતાથી અથવા જબરદસ્તીથી — તે ઓપરેટરના છેલ્લા ચિહ્નો છે: `$??`, `$!!`, `<<|?`, `@!`, `##!`, `>>!`, `>>?`, `@:બહાર!`. તેમના પછી કદી કોઈ કામગીરી હોતી નથી.

તેમાંથી એક વ્યવહારુ વસ્તુ નીકળે છે: **તમે કદી ન જોયું હોય તેવું સંયોજન, તમે તેને શોધો તે પહેલાં જ અર્થપૂર્ણ છે.** જો `$` સંગ્રહ છે અને `^` ક્રમ છે અને `-` ઉલટું છે, તો `$^-` ઉતરતા ક્રમમાં ગોઠવે છે, અને કોઈએ તમને કહેવાની જરૂર ન પડી.

આખી યાદી આ રીતે કામ કરતી નથી, અને તે કહેવું નાટક કરવા કરતાં સારું છે. મોટાભાગના ઓપરેટર સ્વચ્છ રીતે વિભાજિત થાય છે. છ વિભાજિત થાય છે પણ તેમના ભાગો કરતાં વધુ અર્થ ધરાવે છે: `!?` `:!` `:>` `|>` `::` `$++`. અને દસ યાદ રાખવા પડે છે કારણ કે તે બિલકુલ વિભાજિત થતા નથી: `¶` `><` `#1` `#0` `0x` `0b` `0o` `0d` `###` `°`.

> અસ્પષ્ટને ગણવું, તે ઓછા છે એમ ધારવાને બદલે, ઇરાદાપૂર્વક છે: તે ભાષાની વાસ્તવિક યાદશક્તિની કિંમત છે. સંપૂર્ણ સંદર્ભ — યાદી, જાહેર કરેલા સમાનાક્ષરો, અને નવા ઓપરેટરે અસ્તિત્વમાં રહેવા માટે પૂરા કરવાના નિયમો — ઇન્ટરપ્રિટર રિપોઝિટરીમાં `SYMBOLS.md` માં છે.

## પ્રકાશન ફેરફાર લોગ

### v0.0.9 — સંગ્રહોએ નિર્ણય લીધો _(સપ્ટેમ્બર 2026)_

- **બ્રેકિંગ** શબ્દકોશની પોતાની નોંધ છે: `#(કી: મૂલ્ય)`. નગ્ન `(a: 1)` નકારાય છે, અને `#()` ખાલી શબ્દકોશ છે — જે `()` કદી હોઈ શકતું નથી
- **બ્રેકિંગ** અનુક્રમિત સોંપણી પાછી ખેંચાઈ: `એરે[i] = v` અને બધા સંયુક્ત સ્વરૂપો. `=` એ **નામ**ને મૂલ્ય આપે છે; સંગ્રહનો ભાગ બદલવો એ `$~` છે
- **બ્રેકિંગ** શૃંખલાબદ્ધ અનુક્રમણિકા `m[i][j]` વાંચવા અને લખવા બંને માટે નકારાય છે — `>` એ છે જે પગલાંઓ વચ્ચે જાય છે
- **બ્રેકિંગ** મોડ્યુલ જાહેર કરે કે તે શું નિકાસ કરે (**E014**); `#> { }` એ મોડ્યુલ તેની સપાટી ખાલી છે તે કહેવાની રીત છે
- **બ્રેકિંગ** લૂપ નિર્દેશક ગણતરી કે શરત છે — સત્યતા નથી. `@ []` અને `@ 3.5` નકારાય છે
- **ઉમેર્યું** `##_` — એકમ શાબ્દિક, અને કાર્યક્રમ પૂછવાની રીત કે કંઈક ગેરહાજર છે કે નહીં
- **ઉમેર્યું** `#[…]` — એરે જેનું તત્વ પ્રકારોનું મિશ્રણ જાહેર કરેલ છે
- **ઉમેર્યું** `#?` ચાર સંગ્રહોને અલગ પાડે છે: `##]` `##[` `##)` `##(`
- **ઉમેર્યું** `std/time` — ઘડિયાળ અને નાગરિક કેલેન્ડર, ઝોન અને કેલેન્ડર અંકગણિત સાથે
- **ઉમેર્યું** ટોચના સ્તરે `<~>` કાર્યક્રમની બહાર નીકળવાની સ્થિતિ છે
- **ઉમેર્યું** `@ (k, v):જોડીઓ` — લૂપ હેડરમાં પેટર્ન
- **ઉમેર્યું** `#|c|` 69 લિપિઓમાંથી કોઈપણમાં અંક વાંચે છે; `#,` અને `#^` સક્રિય લિપિમાં લખે છે
- **બદલ્યું** `પૂર્ણાંક` સુરક્ષિત પૂર્ણાંક છે, ±(2⁵³ − 1), દરેક એન્જિનમાં નિષ્ફળ-બંધ
- **બદલ્યું** નામવાળું ફંક્શન ફાઇલના ચલોને કૉલ સમયે, મૂલ્ય દ્વારા વાંચે છે
- **બદલ્યું** ફક્ત નામ વાંચતું વિધાન ચૂપચાપ પસાર થવાને બદલે ચેતવણી આપે છે
- **એન્જિન** 666 કોર્પસ ફાઇલોમાંથી 660 ત્રણ એન્જિનમાં સહમત, 0 ભિન્ન

### v0.0.8 — સ્વયં-મુક્તિ, `std/term` અને પેકેજ _(ઓગસ્ટ 2026)_

- **ઉમેર્યું** છેલ્લા ઉપયોગ પર સ્વયંસંચાલિત વિનાશ — અદૃશ્ય; ફક્ત શિખર મેમરી ઘટાડે છે
- **ઉમેર્યું** `std/term` — ટર્મિનલ સ્તંભોમાં ડિસ્પ્લે મેટ્રિક્સ
- **ઉમેર્યું** એક `અક્ષર` પર `##!` — તેનો યુનિકોડ કોડ પોઇન્ટ
- **ઉમેર્યું** મેચમાં અથવા-પેટર્ન: `'p' || 'P' => …`, કોઈપણ પ્રકારના વૈકલ્પિક એક શાખામાં
- **ઉમેર્યું** Zymbol પેકેજ (`.zyp`) — `zymbol package` / `zymbol run pkg.zyp`
- **ઉમેર્યું** કૉલ સાઇટ પર `<~>` ફરજિયાત છે જ્યાં કૉલી આઉટપુટ પરિમાણ જાહેર કરે
- **સુધાર્યું** રજિસ્ટર VM માં મોડ્યુલ સિસ્ટમ સમાનતા

### v0.0.7 — મૂળ પ્રમાણભૂત લાઇબ્રેરી _(જુલાઈ 2026)_

- **ઉમેર્યું** `std/json`, `std/io`, `std/net`, `std/db` (ODBC) — બધા નરમ ભૂલ મૂલ્યો સાથે
- **ઉમેર્યું** પ્રકાર/ચકાસાયેલ ઇનપુટ: `<< ##.(5,2) "કિંમત: " p`
- **ઉમેર્યું** `>>` માં સીધા પોસ્ટફિક્સ ઓપરેટર — કૌંસની જરૂર નથી
- **બદલ્યું** નિષ્ફળ-બંધ ફોર્મેટર: તે આઉટપુટ લખવાનો ઇનકાર કરે છે જે ફરી વાંચી શકાય નહીં

### v0.0.6 — શુદ્ધિકરણ અને વૈજ્ઞાનિક Stdlib _(જૂન 2026)_

- **બ્રેકિંગ** `=>` મેચ શાખાઓમાં `:` અને આયાત/નિકાસ ઉપનામોમાં `<=` ની જગ્યાએ લે છે
- **ઉમેર્યું** `std/math` અને `std/random`
- **ઉમેર્યું** કી દ્વારા શબ્દકોશ અદ્યતન: `d["k"]$~ મૂલ્ય`

### v0.0.5 — TUI આદિમ અને ગરમ વ્યાખ્યા _(મે 2026)_

- **ઉમેર્યું** TUI બ્લોક `>>| { }`, સ્થિતિ આઉટપુટ `>>~`, કી ઇનપુટ `<<|` અને `<<|?`
- **ઉમેર્યું** `>>!` સ્ક્રીન સાફ કરો, `>>?` ટર્મિનલ કદ, `@~ N` સૂઓ
- **ઉમેર્યું** ગરમ વ્યાખ્યા `°x` / `x°`, અને શબ્દમાળા પુનરાવર્તન `$*`

### v0.0.4 — 1-આધારિત અનુક્રમણિકા અને પ્રથમ-શ્રેણી ફંક્શન _(એપ્રિલ 2026)_

- **બ્રેકિંગ** બધી અનુક્રમણિકા **1-આધારિત** છે — `એરે[1]` પ્રથમ તત્વ છે
- **ઉમેર્યું** નામવાળા ફંક્શન પ્રથમ-શ્રેણી મૂલ્યો તરીકે; મોડ્યુલ બ્લોક સિન્ટેક્સ `# નામ { }`
- **ઉમેર્યું** બહુપરિમાણીય અનુક્રમણિકા `એરે[i>j>k]` અને સપાટ નિષ્કર્ષણ `એરે[p ; q]`

### v0.0.3 — યુનિકોડ અંક પ્રણાલીઓ _(એપ્રિલ 2026)_

- **ઉમેર્યું** 69 યુનિકોડ અંક બ્લોક મોડ-સ્વિચ ટોકન `#d0d9#` સાથે
- **ઉમેર્યું** કોઈપણ લિપિમાં બુલિયન શાબ્દિક — `#१` / `#०`

### v0.0.2 — સંગ્રહ API ફરી ડિઝાઇન _(માર્ચ 2026)_

- **ઉમેર્યું** એરે અને શબ્દમાળાઓ માટે `$` ઓપરેટર પરિવાર
- **ઉમેર્યું** વિઘટન સોંપણી, અને ઋણ અનુક્રમણિકાઓ
