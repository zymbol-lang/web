## ചരങ്ങളും സ്ഥിരാങ്കങ്ങളും

```zymbol
ചരം = ൧൦              // മാറ്റാവുന്ന ചരം
PI := ൩.൧൪൧൫൯       // സ്ഥിരാങ്കം — വീണ്ടും നൽകൽ റൺടൈം പിശകാണ്
പേര് = "അനൂപ്"
സജീവം = #൧         // ബൂളിയൻ ശരി
👋 := "നമസ്കാരം"
```

```zymbol
ചരം = ൧൦    // ൧൦
ചരം += ൫    // ൧൫
ചരം -= ൩    // ൧൨
ചരം *= ൨    // ൨൪
ചരം /= ൩    // ൮
ചരം %= ൩    // ൨
ചരം ^= ൨    // ൪
ചരം++       // ൫
ചരം--       // ൪
```

`°` (ഡിഗ്രി ചിഹ്നം, U+00B0) ആദ്യ ഉപയോഗത്തിൽ ഒരു ചരത്തെ അതിന്റെ നിഷ്പക്ഷ മൂല്യത്തിലേക്ക് സ്വയമേവ ആരംഭിക്കുന്നു:

```zymbol
സംഖ്യകൾ = [൩, ൧, ൪, ൧, ൫]
@ n:സംഖ്യകൾ {
    °ആകെ += n
}
>> ആകെ ¶              // → 14
```

> `°ചരം` (ഉപസർഗ്ഗം) ലൂപ്പിന് മുകളിൽ നങ്കൂരമിടുന്നു — ഫലം `@` ന് ശേഷം വായിക്കാം.
> `ചരം°` (പ്രത്യയം) ലൂപ്പിനുള്ളിൽ നങ്കൂരമിടുന്നു — ലൂപ്പ് അവസാനിക്കുമ്പോൾ അത് മരിക്കുന്നു.

പേര് മാത്രമുള്ള ഒരു പ്രസ്താവന ചരം വായിച്ച് മൂല്യം ഉപേക്ഷിക്കുന്നു, അതിനാൽ മുന്നറിയിപ്പ് നൽകുന്നു:

```zymbol
എണ്ണം = ൫
എണ്ണം
```

കംപൈലർ ഇപ്രകാരം മുന്നറിയിപ്പ് നൽകുന്നു (അതിന്റെ സന്ദേശങ്ങൾ എപ്പോഴും ഇംഗ്ലീഷിലാണ്):

```text
warning: this statement does nothing: 'എണ്ണം' is read and discarded
  = help: remove it, or use it — `>> name ¶` to print it
```

അതായത്: *«ഈ പ്രസ്താവന ഒന്നും ചെയ്യുന്നില്ല: 'എണ്ണം' വായിക്കുകയും ഉപേക്ഷിക്കുകയും ചെയ്തു»*.

## ഡാറ്റ തരങ്ങൾ

| തരം | ലിറ്ററൽ | `#?` ടാഗ് | കുറിപ്പുകൾ |
|------|---------|----------|-------|
| പൂർണ്ണസംഖ്യ | `൪൨`, `-൭` | `###` | സുരക്ഷിത പൂർണ്ണസംഖ്യ: ±(2⁵³ − 1) |
| ദശാംശം | `൩.൧൪`, `൧.൫e൧൦` | `##.` | IEEE-754 ഇരട്ട |
| സ്ട്രിംഗ് | `"പാഠം"` | `##"` | ഇന്റർപൊളേഷൻ: `"നമസ്കാരം {പേര്}"` |
| അക്ഷരം | `'A'` | `##'` | ഒരു യൂണികോഡ് കോഡ് പോയിന്റ് |
| ബൂളിയൻ | `#൧`, `#൦` | `##?` | സംഖ്യാത്മകമല്ല — `#൧ ≠ ൧` |
| അറേ | `[൧, ൨, ൩]` | `##]` | ഒരു തരം, പരിശോധിച്ചത് |
| പ്രഖ്യാപിത മിശ്രണം | `#[൧, "രണ്ട്"]` | `##[` | `[…]` പോലെ അതേ തരം, പരിശോധിക്കാത്തത് |
| ട്യൂപ്പിൾ | `(a, b)` | `##)` | സ്ഥാനാധിഷ്ഠിതം, മാറ്റാനാവാത്തത് |
| നിഘണ്ടു | `#(x: ൧, y: ൨)` | `##(` | കീ-അധിഷ്ഠിതം, മാറ്റാവുന്നത് |
| ഫംഗ്ഷൻ | പേരുള്ള ഫംഗ്ഷൻ റഫറൻസ് | `##()` | പ്രഥമ-ശ്രേണി; കാണിക്കുന്നു `<funct/N>` |
| ലാംഡ | `x -> x * ൨` | `##->` | പ്രഥമ-ശ്രേണി; കാണിക്കുന്നു `<lambd/N>` |
| യൂണിറ്റ് | `##_` | `##_` | അഭാവം — null ഇല്ല |

```zymbol
>> ൪൨#? ¶               // → (###, 2, 42)
>> [൧, ൨, ൩]#? ¶        // → (##], 3, [1, 2, 3])
>> #(x: ൧)#? ¶          // → (##(, 1, #(x: 1))
```

സുരക്ഷിത പരിധിക്ക് പുറത്തുപോകുന്ന ഒരു പൂർണ്ണസംഖ്യ പിടിക്കാവുന്ന പിശകാണ്, ഒരിക്കലും നിശ്ശബ്ദ വെട്ടിച്ചുരുക്കലല്ല:

```zymbol
!? {
    >> (൯൦൦൭൧൯൯൨൫൪൭൪൦൯൯൧ + ൧) ¶
} :! ##Range {
    >> "പരിധിക്ക് പുറത്ത്" ¶ // → പരിധിക്ക് പുറത്ത്
}
```

`##_` ഒരു പ്രോഗ്രാം എന്തെങ്കിലും ഇല്ലേ എന്ന് ചോദിക്കുന്ന വിധമാണ്:

```zymbol
ഒന്നുമില്ല() { }
മൂല്യം = ഒന്നുമില്ല()
>> (മൂല്യം == ##_) ¶     // → #1
```

## ഔട്ട്പുട്ടും ഇൻപുട്ടും

```zymbol
പേര് = "അനൂപ്"
ആകെ = ൩
>> "നമസ്കാരം" ¶             // → നമസ്കാരം
>> "a=" പേര് " b=" ആകെ ¶ // → a=അനൂപ് b=3
>> ആകെ#? ¶            // → (###, 1, 3)
```

```zymbol
<< പേര്
<< "നിങ്ങളുടെ പേര് നൽകുക: " പേര്
<< ###(൪) "പ്രായം: " പ്രായം
```

**രണ്ട് അടയാളങ്ങളുടെ ആകൃതി നോക്കുക.** `>>` പുറത്തേക്ക് ചൂണ്ടുന്നു: ഡാറ്റ പ്രോഗ്രാമിൽ നിന്ന് പുറത്തെടുക്കുന്നു. `<<` ഉള്ളിലേക്ക് ചൂണ്ടുന്നു: ഡാറ്റ പ്രോഗ്രാമിലേക്ക് കൊണ്ടുവരുന്നു. ഇവിടെ ഓർക്കാൻ ഒന്നുമില്ല — അമ്പ് വിവരങ്ങൾ ഏത് ദിശയിൽ സഞ്ചരിക്കുന്നു എന്ന് കാണിക്കുന്നു, അതേ ആശയം എന്തെങ്കിലും നീക്കുന്ന എല്ലാ അടയാളത്തിലും തിരികെ വരുന്നു.

> `¶`, `\\` എന്നിവ തുല്യമായ പുതിയ വരികളാണ്. `>>` ഒരിക്കലും ഒന്ന് ചേർക്കുന്നില്ല.
> പ്രോംപ്റ്റിന് മുമ്പുള്ള തരം നിർദ്ദിഷ്ടകം വായിക്കുമ്പോൾ സാധൂകരിക്കുകയും മൂല്യം സാധുവാകുന്നതുവരെ വീണ്ടും ചോദിക്കുകയും ചെയ്യുന്നു:
> `##.` ദശാംശം · `##.(T,D)` ദശാംശം · `###(N)` പൂർണ്ണസംഖ്യ · `##"(N)"` പാഠം · `##'` ഒരു അക്ഷരം.

ഒരു ഫയലിന്റെ ഏറ്റവും ഉയർന്ന തലത്തിൽ, `<~>` പ്രോഗ്രാമിന്റെ എക്സിറ്റ് സ്റ്റാറ്റസ് ആണ്:

```zymbol
>> "പരിശോധിക്കുന്നു" ¶      // → പരിശോധിക്കുന്നു
<~ ൦
```

## TUI പ്രാഥമികങ്ങൾ

ഇന്ററാക്ടീവ് പ്രോഗ്രാമുകൾക്കുള്ള ടെർമിനൽ UI ഓപ്പറേറ്ററുകൾ. മിക്കതിനും `>>| { }` ബ്ലോക്ക് ആവശ്യമാണ് (ബദൽ സ്ക്രീൻ + റോ മോഡ്).

```zymbol
>>| {
    >>!
    >>~ (൧, ൧, ൦, ൧൦) > "പ്രവർത്തിക്കുന്നു"
    @~ ൧൦൦൦
    >>~ (൨, ൧) > "പൂർത്തിയായി."
}
```

```zymbol
>>| {
    [വരികൾ, നിരകൾ] = >>?
    >>~ (൧, ൧) > "ടെർമിനൽ: " വരികൾ " x " നിരകൾ
    <<| കീ
    >>~ (൨, ൧) > "അമർത്തിയത്: " കീ
}
```

ഇവിടെ അടയാളങ്ങൾ ഗുണിക്കുന്നതിനുപകരം സംയോജിക്കുന്നത് എന്തുകൊണ്ടെന്ന് കാണാം. `<<` ഇൻപുട്ടാണെന്നും `?` പ്രതിബദ്ധതയില്ലാതെ ചോദിക്കുന്നു എന്നും നിങ്ങൾക്ക് ഇതിനകം അറിയാം. ഒരു അടയാളം മാത്രം പുതിയതാണ്:

- `|` ഒരു **ഏക യൂണിറ്റ്** ആണ്, മുഴുവൻ സ്ട്രീമല്ല.

അതോടെ, രണ്ട് കീബോർഡ് ഓപ്പറേറ്ററുകളും സ്വയം വായിക്കുന്നു:

```text
<<        |             ?
ഇൻപുട്ട്   ഏക യൂണിറ്റ്   പ്രതിബദ്ധതയില്ലാതെ

<<|   ഒരു കീ എടുത്ത്, ഒന്ന് വരുന്നതുവരെ കാത്തിരിക്കുക
<<|?  ഒരു കീ ഉണ്ടോ എന്ന് നോക്കി, ഇല്ലെങ്കിൽ തുടരുക
```

മറുവശത്തും അതുതന്നെ: `>>` അയയ്ക്കുന്നു, `>>!` **ബലം പ്രയോഗിച്ച്** അയയ്ക്കുന്നു (മുഴുവൻ സ്ക്രീനും മായ്ക്കുന്നു), `>>?` എഴുതുന്നതിനുപകരം **ചോദിക്കുന്നു** (ടെർമിനൽ എത്ര വലുതാണ്). വലതുവശത്തുള്ള അടയാളം മോഡ് മാറ്റുന്നതാണ്, അത് എപ്പോഴും അവസാനം വരുന്നു.

> `>>!` സ്ക്രീൻ മായ്ക്കുന്നു. `>>?` `[വരികൾ, നിരകൾ]` നൽകുന്നു. `@~ N` N മില്ലിസെക്കൻഡ് ഉറങ്ങുന്നു.
> `<<|` ഒരു കീ അമർത്തൽ വായിക്കുന്നു (ബ്ലോക്കിംഗ്); `<<|?` ബ്ലോക്ക് ചെയ്യാതെ പോൾ ചെയ്യുന്നു (`'\0'` ഒന്നുമില്ലെങ്കിൽ).
> അമ്പടയാള കീകൾ `'↑' '↓' '←' '→'` ആയി ഡീകോഡ് ചെയ്യുന്നു; ESC കോഡ് പോയിന്റ് 27 ആണ്.
> സ്ഥാന ഔട്ട്പുട്ട് ട്യൂപ്പിൾ: `(വരി, നിര, BKS, മുൻ, പിൻ)` — ഏത് സ്ലോട്ടും കോമ ഉപയോഗിച്ച് ഒഴിവാക്കാം (`>>~ (,,, ൧൯൬) > "ചുവപ്പ്"`).
> BKS ബിറ്റ്മാസ്ക്: `1`=കട്ടിയുള്ള, `2`=ചരിഞ്ഞ, `4`=അടിവര. ANSI 256-നിറ പാലറ്റ് (`0`=ടെർമിനൽ സ്ഥിരസ്ഥിതി).

## ഓപ്പറേറ്ററുകൾ

```zymbol
a = ൧൦
b = ൩
ഫ1 = a + b    // ൧൩
ഫ2 = a - b    // ൭
ഫ3 = a * b    // ൩൦
ഫ4 = a / b    // ൩  (പൂർണ്ണസംഖ്യ വിഭജനം)
ഫ5 = a % b    // ൧
ഫ6 = a ^ b    // ൧൦൦൦
```

```zymbol
a = ൧൦
b = ൩
ത1 = a == b    // #൦
ത2 = a <> b    // #൧
ത3 = a < b     // #൦
ത4 = a >= b    // #൧
യ1 = #൧ && #൦  // #൦
യ2 = !#൧       // #൦
```

> `==` ഒരിക്കലും നിർബന്ധിക്കുന്നില്ല: `"5" == 5` എന്നത് `#0` ആണ്. ക്രമം നിർബന്ധിക്കുന്നു: `"5" > 4` എന്നത് `#1` ആണ്, `"४२" > 5` ഉം അതുതന്നെ — 69 ലിപികളിൽ ഏതെങ്കിലുമുള്ള സംഖ്യാ പാഠം ഒരു സംഖ്യയായി താരതമ്യം ചെയ്യുന്നു.
> ഒരു ഫംഗ്ഷൻ സ്വയം മാത്രമേ തുല്യമാകൂ, ഒരേ ശരീരമുള്ള മറ്റൊരു ഫംഗ്ഷനോട് ഒരിക്കലും തുല്യമാകില്ല.

## സ്ട്രിംഗുകൾ

```zymbol
പേര് = "അനൂപ്"
n = ൪൨
>> "നമസ്കാരം " പേര് " നിങ്ങൾക്ക് " n " ഉണ്ട്" ¶ // → നമസ്കാരം അനൂപ് നിങ്ങൾക്ക് 42 ഉണ്ട്
വിവരണം = "നമസ്കാരം {പേര്}, നിങ്ങൾക്ക് {n} ഉണ്ട്"
>> വിവരണം ¶              // → നമസ്കാരം അനൂപ്, നിങ്ങൾക്ക് 42 ഉണ്ട്
```

```zymbol
s = "നമസ്കാരം ലോകം"
നീളം = s$#                  // ൧൩
ഭാഗം = s$[൧..൭]             // "നമസ്കാര"
ഉണ്ട് = s$? "ലോകം"          // #൧
ഭാഗങ്ങൾ = "a,b,c,d"$/ ','    // [a, b, c, d]
മാറ്റം = s$~~["ാ":"ി"]        // "നമസ്കിരം ലോകം"
വര = "─" $* ൨൦
```

> `+` സംഖ്യകൾക്ക് മാത്രമാണ്. സ്ട്രിംഗുകൾക്ക് ഒരുമിച്ച് വയ്ക്കൽ അല്ലെങ്കിൽ ഇന്റർപൊളേഷൻ ഉപയോഗിക്കുക.
> `\{`, `\}` എന്നിവ അക്ഷരീയ ബ്രേസുകളാണ് — എസ്കേപ്പ് സമമിതമാണ്.

## നിയന്ത്രണ പ്രവാഹം

```zymbol
a = ൭
? a > ൧൦൦ {
    >> "വലുത്" ¶
} _? a > ൦ {
    >> "പോസിറ്റീവ്" ¶     // → പോസിറ്റീവ്
} _ {
    >> "നെഗറ്റീവ്" ¶
}
```

ഇവിടെ രണ്ട് പുതിയ അടയാളങ്ങളും, അവ ഒരുമിച്ച് വയ്ക്കുന്നതിൽ നിന്ന് വരുന്ന മൂന്നാമത്തേതും ഉണ്ട്:

- `?` **ചോദിക്കൽ** ആണ്: ഒരു വ്യവസ്ഥ തുറക്കുന്നു.
- `_` **വ്യക്തമാക്കാത്തത്** ആണ്: ഒരു ചോദ്യവും പൊരുത്തപ്പെടാത്തപ്പോൾ ബാക്കിയുള്ള ശാഖ.
- `_?` രണ്ടും തുടർച്ചയായി: *ഒന്നും പൊരുത്തപ്പെട്ടില്ലെങ്കിൽ, വീണ്ടും ചോദിക്കുക*.

അതുകൊണ്ടാണ് `_?` അങ്ങനെ എഴുതിയിരിക്കുന്നത്. ഇത് പഠിക്കാൻ പുതിയ ചിഹ്നമല്ല — `_` കഴിഞ്ഞ് `?`, അതിന്റെ രണ്ട് ഭാഗങ്ങളും ക്രമത്തിൽ വായിക്കുമ്പോൾ അർത്ഥമാക്കുന്നത് അതേ അർത്ഥമാണ്.

> ബ്രേസുകൾ `{ }` ഒരു പ്രസ്താവനയ്ക്കും **നിർബന്ധമാണ്**.

## പൊരുത്തം

```zymbol
സ്കോർ = ൮൫
ഗ്രേഡ് = ?? സ്കോർ {
    ൯൦..൧൦൦ => 'A'
    ൮൦..൮൯  => 'B'
    _       => 'F'
}
>> ഗ്രേഡ് ¶              // → B
```

```zymbol
താപനില = -൫
അവസ്ഥ = ?? താപനില {
    < ൦  => "ഐസ്"
    < ൨൦ => "തണുപ്പ്"
    _    => "ചൂട്"
}
>> അവസ്ഥ ¶              // → ഐസ്
```

`?` "ചോദിക്കൽ" ആണെന്ന് നിങ്ങൾക്ക് ഇതിനകം അറിയാം. **`??` പലതവണ ചോദിക്കൽ** ആണ്: ഭാഷയിൽ എവിടെയെങ്കിലും ഒരു അടയാളം ഇരട്ടിപ്പിക്കുന്നത്, ആ അടയാളം ഒരിക്കൽ ചെയ്യുന്നത് പലതവണ ചെയ്യലാണ്. ഒരു `?` ഒരു വ്യവസ്ഥ പരിശോധിക്കുന്നു; `??` കേസുകളുടെ പട്ടികയ്ക്കെതിരെ പരിശോധിക്കുന്നു.

ബദലുകൾ `||` ഉപയോഗിച്ച് ചേരുന്നു, പാറ്റേൺ തരങ്ങൾ കലർത്താനും കഴിയും:

```zymbol
കീ = 'P'
പ്രവർത്തനം = ?? കീ {
    'p' || 'P' => "താൽക്കാലികം"
    < ൦ || > ൧൦൦ => "പരിധിക്ക് പുറത്ത്"
    _ => "അവഗണിച്ചു"
}
>> പ്രവർത്തനം ¶             // → താൽക്കാലികം
```

## ലൂപ്പുകൾ

```zymbol
@ i:൧..൪  { >> i " " }
>> ¶                    // → 1 2 3 4
@ i:൧..൯:൨ { >> i " " }
>> ¶                    // → 1 3 5 7 9
@ i:൫..൧:൧ { >> i " " }
>> ¶                    // → 5 4 3 2 1
```

```zymbol
n = ൧
@ n <= ൬൪ { n *= ൨ }
>> n ¶                  // → 128
```

```zymbol
പഴങ്ങൾ = ["ആപ്പിൾ", "പിയർ", "മുന്തിരി"]
@ പ:പഴങ്ങൾ { >> പ " " }
>> ¶                    // → ആപ്പിൾ പിയർ മുന്തിരി
@ അ:"നമസ്കാരം" { >> അ "-" }
>> ¶                    // → ന-മ-സ-്-ക-ാ-ര-ം-
```

```zymbol
@ i:൧..൧൦ {
    ? i % ൨ == ൦ { @> }
    ? i > ൭ { @! }
    >> i " "
}
>> ¶                    // → 1 3 5 7
```

```zymbol
എണ്ണം = ൦
@:പുറം {
    എണ്ണം++
    ? എണ്ണം >= ൩ { @:പുറം! }
}
>> എണ്ണം ¶             // → 3
```

`@` **സമയത്തിന്റെ** അടയാളമാണ്: ആവർത്തിക്കുന്നതെല്ലാം അതിൽ ജീവിക്കുന്നു. ആ സമയം വെട്ടിച്ചുരുക്കാൻ നിങ്ങൾ അതിനരികിൽ ഒരു അടയാളം ചേർക്കുന്നു:

- `@!` — `!` **ബലം**: ഇപ്പോൾ ലൂപ്പിൽ നിന്ന് പുറത്തുകടക്കുക.
- `@>` — `>` മുന്നോട്ട് തള്ളുന്നു: അടുത്ത റൗണ്ടിലേക്ക് പോകുക.
- `@:പുറം!` — `:` **ഒരു പേര് ബന്ധിക്കുന്നു**, അതിനാൽ ഇത് *പുറം* എന്ന പേരുള്ള ലൂപ്പ് മുറിക്കുന്നു, അടുത്തുള്ളതിനെയല്ല.

മൂന്ന് ഓപ്പറേറ്ററുകൾ, അവയിൽ ഒന്നും വെവ്വേറെ മനഃപാഠമാക്കേണ്ടതില്ല: അവ `@` കൂടാതെ അത് എന്ത് ചെയ്യുന്നു എന്ന് ഇതിനകം പറയുന്ന ഒരു അടയാളമാണ്.

> **ഒരു നിർദ്ദിഷ്ടകം ഒരു എണ്ണമോ വ്യവസ്ഥയോ ആണ്.** ഒരു `പൂർണ്ണസംഖ്യ` ഒരു എണ്ണമാണ്, ഒരിക്കൽ വിലയിരുത്തുന്നു — `@ 0` ശരീരം പൂജ്യം തവണ പ്രവർത്തിപ്പിക്കുന്നു. മറ്റെല്ലാം ഒരു വ്യവസ്ഥയാണ്. സത്യത്വമില്ല: `@ []`, `@ 3.5` എന്നിവ നിരസിക്കുന്നു. ഒരു ശേഖരം കടന്നുപോകാൻ `@ x:ഇനങ്ങൾ` ഉപയോഗിക്കുക; എണ്ണാൻ `@ ഇനങ്ങൾ$#`.

## ഫംഗ്ഷനുകൾ

```zymbol
കൂട്ടുക(a, b) { <~ a + b }
>> കൂട്ടുക(൩, ൪) ¶        // → 7
```

```zymbol
ഫാക്ടോറിയൽ(n) {
    ? n <= ൧ { <~ ൧ }
    <~ n * ഫാക്ടോറിയൽ(n - ൧)
}
>> ഫാക്ടോറിയൽ(൫) ¶       // → 120
```

ഒരു ഫംഗ്ഷൻ ഫയലിന്റെ ചരങ്ങൾ മൂല്യം പ്രകാരം വായിക്കുന്നു, ഉള്ളിലെ എഴുത്ത് ഉള്ളിൽ തന്നെ തുടരുന്നു:

```zymbol
പരിധി = ൧൦൦
ഉള്ളിൽ(n) { <~ n < പരിധി }
>> ഉള്ളിൽ(൪൨) ¶         // → #1
```

രണ്ട് അടയാളങ്ങൾ ഇത് മാറ്റുന്നു, രണ്ടും **ഒപ്പിലും വിളിക്കുന്ന സ്ഥലത്തും** എഴുതുന്നു:

```zymbol
വർദ്ധിപ്പിക്കുക(എണ്ണം<~) { എണ്ണം = എണ്ണം + ൧ }
ആകെ = ൦
വർദ്ധിപ്പിക്കുക(ആകെ<~)
>> ആകെ ¶              // → 1
```

> `p~` ഒരു പ്രവർത്തന പകർപ്പാണ് — ശരീരത്തിന് അത് വീണ്ടും നൽകാം, വിളിക്കുന്നയാൾ സ്പർശിക്കപ്പെടുന്നില്ല.
> `p<~` ഒരു ഔട്ട്പുട്ട് പാരാമീറ്ററാണ് — മാറ്റം തിരികെ വരുന്നു. അടയാളമില്ലാതെ `വർദ്ധിപ്പിക്കുക(ആകെ)` ഒരു അർത്ഥ പിശകാണ്: അനോട്ടേഷനും ഒപ്പും വേർപെടാൻ പാടില്ല.

## ലാംഡകളും ക്ലോസറുകളും

```zymbol
ഇരട്ടി = x -> x * ൨
തുക = (a, b) -> a + b
>> ഇരട്ടി(൫) ¶          // → 10
>> തുക(൩, ൭) ¶          // → 10
```

```zymbol
തരംതിരിക്കുക = x -> {
    ? x > ൦ { <~ "പോസിറ്റീവ്" }
    _? x < ൦ { <~ "നെഗറ്റീവ്" }
    <~ "പൂജ്യം"
}
>> തരംതിരിക്കുക(-൪) ¶         // → നെഗറ്റീവ്
```

```zymbol
ഘടകം = ൩
മൂന്നിരട്ടി = x -> x * ഘടകം
>> മൂന്നിരട്ടി(൭) ¶          // → 21
```

```zymbol
കൂട്ടിച്ചേർക്കൽ_സൃഷ്ടിക്കുക(n) { <~ x -> x + n }
കൂട്ടുക10 = കൂട്ടിച്ചേർക്കൽ_സൃഷ്ടിക്കുക(൧൦)
```

## അറേകൾ

```zymbol
അറേ = [൧, ൨, ൩, ൪, ൫]
>> അറേ[൧] ¶       // → 1   സൂചിക 1-അധിഷ്ഠിതം
>> അറേ[-൧] ¶      // → 5   നെഗറ്റീവ് അവസാനത്തിൽ നിന്ന് എണ്ണുന്നു
>> അറേ$# ¶        // → 5   നീളം
```

```zymbol
അറേ = [൧, ൨, ൩]
>> (അറേ$+ ൬) ¶          // → [1, 2, 3, 6]   ചേർക്കുക
>> (അറേ$+[൨] ൯൯) ¶      // → [1, 99, 2, 3]  സ്ഥാനം 2 ൽ ചേർക്കുക
>> (അറേ$- ൩) ¶          // → [1, 2]         ആദ്യ സംഭവം നീക്കുക
>> (അറേ$-[൧]) ¶         // → [2, 3]         സൂചിക 1 ൽ നീക്കുക
>> (അറേ$[൧..൨]) ¶       // → [1, 2]         സ്ലൈസ്, രണ്ട് അറ്റങ്ങളും ഉൾപ്പെടെ
>> (അറേ$? ൩) ¶          // → #1             ഉൾക്കൊള്ളുന്നു
```

എല്ലാം `$` ൽ തുടങ്ങുന്നു, അത് **ശേഖരത്തിന്റെ** അടയാളമാണ്, അതിൽ എന്ത് ചെയ്യുന്നു എന്ന് പറയുന്ന അടയാളത്തോടെ തുടരുന്നു: `#` എത്ര, `+` ചേർക്കുക, `-` നീക്കുക, `?` ഉണ്ടോ എന്ന് ചോദിക്കുക. `??` പോലെ, അടയാളം ഇരട്ടിപ്പിക്കുന്നത് അത് സമഗ്രമായി ചെയ്യലാണ്: `$?` ഒരു മൂല്യം *ഉണ്ടോ* എന്ന് ചോദിക്കുന്നു, `$??` *എത്ര സ്ഥലങ്ങളിൽ* ഉണ്ടെന്ന് ചോദിച്ച് എല്ലാം നൽകുന്നു.

```zymbol
അറേ = [൩, ൧, ൨]
>> (അറേ$^+) ¶     // → [1, 2, 3]   ആരോഹണം
>> (അറേ$^-) ¶     // → [3, 2, 1]   അവരോഹണം
```

**ഫലത്തിന്റെ നിയമം.** ഒരു ഓപ്പറേറ്റർ, ചുറ്റുമുള്ള കോഡ് അതിനോട് എന്ത് ചെയ്യുന്നു എന്നത് തീരുമാനിക്കുന്നു: ഉപയോഗിച്ചാൽ, അത് **നിർമ്മിക്കുന്നു** ഒറിജിനൽ അതേപടി വിടുന്നു; ഉപേക്ഷിച്ചാൽ, അത് **മാറ്റുന്നു**.

```zymbol
അറേ = [൧, ൨, ൩]
പകർപ്പ് = അറേ[൨]$~ ൯൯
>> അറേ ¶                // → [1, 2, 3]
>> പകർപ്പ് ¶              // → [1, 99, 3]
അറേ[൨]$~ ൯൯
>> അറേ ¶                // → [1, 99, 3]
```

> **`=` ഒരിക്കലും ഒരു ശേഖരത്തിൽ എഴുതുന്നില്ല.** `അറേ[൨] = ൯൯` Zymbol-ന്റെ ഒരു രൂപമല്ല — `=` ഒരു **പേരിന്** മൂല്യം നൽകുന്നു. ഒരു ശേഖരത്തിന്റെ ഒരു ഭാഗം മാറ്റുന്നത് `$~` ആണ്, എല്ലാ ശേഖരത്തിലും.

`[…]` ഒരു തരം ഉൾക്കൊള്ളുന്നു, പരിശോധിക്കുന്നു; മനഃപൂർവ്വമുള്ള മിശ്രണം `#[…]` ഉപയോഗിച്ച് **പ്രഖ്യാപിക്കുന്നു**:

```zymbol
മിശ്രണം = #[൧, "രണ്ട്", #൧]
>> മിശ്രണം ¶             // → [1, രണ്ട്, #1]
>> ([൧, ൨] == #[൧, ൨]) ¶ // → #1
```

## ബഹുമാന സൂചിക

`>` ഒരു കൂടുതൽ ഘടനയിലേക്ക് ഇറങ്ങുന്നു. ഒരു ബ്രാക്കറ്റ് ഗ്രൂപ്പ് ഒരു ഘടകത്തെ അഭിസംബോധന ചെയ്യുന്നു, എത്ര ആഴമുള്ളതായാലും.

```zymbol
m = [[൧,൨,൩], [൪,൫,൬], [൭,൮,൯]]
>> m[൨>൩] ¶        // → 6   വരി 2, നിര 3
>> m[-൧>-൧] ¶      // → 9   അവസാന വരി, അവസാന നിര
```

```zymbol
m = [[൧,൨,൩], [൪,൫,൬], [൭,൮,൯]]
>> m[൧>൧ ; ൨>൨ ; ൩>൩] ¶          // → [1, 5, 9]          പരന്നത്: ഡയഗണൽ
>> m[[൧>൧, ൧>൩] ; [൩>൧, ൩>൩]] ¶  // → [[1, 3], [7, 9]]   ഘടനയുള്ളത്: കോണുകൾ
```

```zymbol
m = [[൧,൨,൩], [൪,൫,൬]]
>> (m[൧>൨]$~ ൯൯) ¶      // → [[1, 99, 3], [4, 5, 6]]
```

> `m[൧][൨]` Zymbol-ന്റെ ഒരു രൂപം **അല്ല**. ശൃംഖലാ സൂചിക വായനയ്ക്കും എഴുത്തിനും നിരസിക്കുന്നു — ഓരോ ആക്സസിനും ഒരു ബ്രാക്കറ്റ് ഗ്രൂപ്പ്, ഒപ്പം `>` ഘട്ടങ്ങൾക്കിടയിൽ പോകുന്നത്.

## നിഘണ്ടുക്കൾ

പേരിട്ട ഫീൽഡുകളുള്ള ഒരു ട്യൂപ്പിൾ ഒരു നിഘണ്ടുവാണ്, v0.0.9 മുതൽ അത് `#(…)` എന്ന് എഴുതുന്നു.

```zymbol
വ്യക്തി = #(പേര്: "അനൂപ്", പ്രായം: ൨൫)
>> വ്യക്തി.പേര് ¶        // → അനൂപ്
>> വ്യക്തി["പ്രായം"] ¶    // → 25
```

```zymbol
വ്യക്തി = #(പേര്: "അനൂപ്", പ്രായം: ൨൫)
ഫീൽഡ് = "പേര്"
>> വ്യക്തി[ഫീൽഡ്] ¶     // → അനൂപ്
```

ഇത് മാറ്റാവുന്നതാണ്, കീകൾ ചേർക്കാം, കടന്നുപോകാനും കഴിയും:

```zymbol
ശേഖരം = #(പിയർ: ൪)
ശേഖരം["ആപ്പിൾ"]$~ ൧൦
@ k:ശേഖരം { >> k "=" ശേഖരം[k] " " }
>> ¶                    // → പിയർ=4 ആപ്പിൾ=10
```

```zymbol
ശേഖരം = #(പിയർ: ൪, ആപ്പിൾ: ൧൦)
@ (k, v):ശേഖരം { >> k ":" v " " }
>> ¶                    // → പിയർ:4 ആപ്പിൾ:10
```

> `#()` ശൂന്യ നിഘണ്ടുവാണ്, `()` ആകാൻ കഴിയാത്തത് — അത് ശൂന്യ ട്യൂപ്പിളും ആകേണ്ടതുണ്ട്. നഗ്നമായ `(x: 1)` ഈ സന്ദേശത്തോടെ നിരസിക്കുന്നു: *a dictionary is written `#(…)`* — «ഒരു നിഘണ്ടു `#(…)` എന്ന് എഴുതുന്നു».
> ഒരു നിഘണ്ടു കീ ഉപയോഗിച്ച് അഭിസംബോധന ചെയ്യുന്നു, സ്ഥാനം കൊണ്ട് ഒരിക്കലുമല്ല, അതിനാൽ `വ്യക്തി[1]` ഒരു പിശകാണ്.

## ട്യൂപ്പിളുകൾ

ട്യൂപ്പിളുകൾ വിവിധ തരങ്ങളിലുള്ള മൂല്യങ്ങൾ ഉൾക്കൊള്ളുന്ന **മാറ്റാനാവാത്ത** ക്രമീകൃത കണ്ടെയ്നറുകളാണ്.

```zymbol
ബിന്ദു = (൧൦, ൨൦)
>> ബിന്ദു[൧] ¶           // → 10
ഡാറ്റ = (൪൨, "നമസ്കാരം", #൧, ൩.൧൪)
>> ഡാറ്റ[൩] ¶            // → #1
```

```zymbol
t = (൧൦, ൨൦, ൩൦)
t2 = t[൨]$~ ൯൯൯
>> t ¶                  // → (10, 20, 30)
>> t2 ¶                 // → (10, 999, 30)
```

> ഒരു ട്യൂപ്പിൾ അതിന്റെ സ്ഥാനത്ത് തന്നെ മാറ്റാനുള്ള ഏത് ശ്രമവും ഒരു പിശകാണ്, ഓപ്പറേറ്റർ ഏതായാലും — മാറ്റാനാവാത്തത് മൂല്യത്തിന്റെ ഒരു സ്വത്താണ്, ഓരോ `$` നുള്ളിലെ ഒരു അപവാദമല്ല.

## വിഘടനം

```zymbol
അറേ = [൧൦, ൨൦, ൩൦, ൪൦, ൫൦]
[a, b, c] = അറേ
>> a " " b " " c ¶      // → 10 20 [30, 40, 50]
```

```zymbol
അറേ = [൧൦, ൨൦, ൩൦, ൪൦, ൫൦]
[ആദ്യം, *ബാക്കി] = അറേ
>> ആദ്യം ¶            // → 10
>> ബാക്കി ¶              // → [20, 30, 40, 50]
```

```zymbol
ബിന്ദു = (൧൦൦, ൨൦൦)
(px, py) = ബിന്ദു
>> px " " py ¶          // → 100 200
```

```zymbol
വ്യക്തി = #(പേര്: "മീര", പ്രായം: ൨൫)
#(പേര്: n, പ്രായം: a) = വ്യക്തി
>> n " " a ¶            // → മീര 25
```

> ബ്രാക്കറ്റിന്റെ ആകൃതി ടൈപ്പ് ചെയ്തതാണ്: `[…]` അറേ എടുക്കുന്നു, `(…)` ട്യൂപ്പിൾ, `#(…)` നിഘണ്ടു. അവസാന പേര് **ബാക്കി ആഗിരണം ചെയ്യുന്നു**, അതിനാൽ വിഘടനം ഒരിക്കലും നീളത്തിൽ പരാജയപ്പെടുന്നില്ല — `(a, b, c) = (1,2,3,4,5)` `c = (3,4,5)` നൽകുന്നു, ഒന്നും ബാക്കിയില്ലെങ്കിൽ `##_`.

## ഉയർന്ന-ക്രമ ഫംഗ്ഷനുകൾ

```zymbol
സംഖ്യകൾ = [൧, ൨, ൩, ൪, ൫]
>> (സംഖ്യകൾ$> (x -> x * ൨)) ¶ // → [2, 4, 6, 8, 10]
>> (സംഖ്യകൾ$| (x -> x % ൨ == ൦)) ¶ // → [2, 4]
>> (സംഖ്യകൾ$< (൦, (ശേഖരണം, x) -> ശേഖരണം + x)) ¶ // → 15
```

```zymbol
സംഖ്യകൾ = [൧, ൨, ൩, ൪, ൫, ൬]
ഇരട്ടി(x) { <~ x * ൨ }
വലുത്(x) { <~ x > ൩ }
>> (സംഖ്യകൾ$> ഇരട്ടി) ¶    // → [2, 4, 6, 8, 10, 12]
>> (സംഖ്യകൾ$| വലുത്) ¶    // → [4, 5, 6]
```

```zymbol
അടിസ്ഥാനം = [#(പേര്: "കാർല", പ്രായം: ൨൮), #(പേര്: "മീര", പ്രായം: ൨൫)]
പ്രായപ്രകാരം = അടിസ്ഥാനം$^ (a, b -> a.പ്രായം < b.പ്രായം)
>> പ്രായപ്രകാരം[൧].പേര് ¶     // → മീര
```

> പേരുള്ള ഫംഗ്ഷൻ HOF-ലേക്ക് **ബ്രാക്കറ്റുകളില്ലാതെ** പോകുന്നു: `സംഖ്യകൾ$> ഇരട്ടി`. `സംഖ്യകൾ$> (ഇരട്ടി)` എന്ന് എഴുതുന്നത് ഒരു പാഴ്സ് പിശകാണ്, കാരണം `(` ഒരു ലാംഡ തുറക്കുന്നു.

```zymbol
ഇരട്ടി = x -> x * ൨
```

## പിശക് കൈകാര്യം ചെയ്യൽ

```zymbol
!? {
    a = ൧൦ / ൦
} :! ##Div {
    >> "പൂജ്യം കൊണ്ട് ഹരണം" ¶  // → പൂജ്യം കൊണ്ട് ഹരണം
} :! {
    >> "മറ്റുള്ളവ: " _err ¶
} :> {
    >> "എപ്പോഴും പ്രവർത്തിക്കുന്നു" ¶        // → എപ്പോഴും പ്രവർത്തിക്കുന്നു
}
```

| തരം | എപ്പോൾ |
|------|------|
| `##Div` | പൂജ്യം കൊണ്ട് ഹരണം |
| `##Index` | സൂചിക പരിധിക്ക് പുറത്ത് |
| `##Key` | നിഘണ്ടുവിൽ കീയില്ല |
| `##Range` | സുരക്ഷിത പൂർണ്ണസംഖ്യ പരിധിക്ക് പുറത്ത് |
| `##Type` | തരം പൊരുത്തക്കേട് |
| `##Parse` | ഡാറ്റ പാഴ്സിംഗ് |
| `##IO` | ഫയൽ / സിസ്റ്റം |
| `##Network` | നെറ്റ്വർക്ക് പിശകുകൾ |
| `##DB` | ഡാറ്റാബേസ് |
| `##Time` | നിലവിലില്ലാത്ത ഒരു തീയതി |
| `##_` | ഏത് പിശകും (എല്ലാം പിടിക്കുന്നു) |

`!` **പിശകിന്റെയും ബലത്തിന്റെയും** അടയാളമാണ്, രണ്ട് കുടുംബങ്ങളിലും ഒരേപോലെ വായിക്കുന്നു: `$!` ഒരു മൂല്യത്തോട് അത് ഒരു പിശകാണോ എന്ന് ചോദിക്കുന്നു; `$!!`, അടയാളം ഇരട്ടിപ്പിച്ച്, ചോദിക്കാതെ അതിനെ മുകളിലേക്ക് പ്രചരിപ്പിക്കുന്നു.

> സ്റ്റാൻഡേർഡ് ലൈബ്രറി പരാജയങ്ങൾ അവസാനിപ്പിക്കുന്നതിനുപകരം `$!` ഉപയോഗിച്ച് പരിശോധിക്കാവുന്ന അല്ലെങ്കിൽ `!?` ഉപയോഗിച്ച് പിടിക്കാവുന്ന **സോഫ്റ്റ് പിശക് മൂല്യങ്ങളായി** തിരികെ വരുന്നു. `$!!` ഒന്നിനെ വിളിക്കുന്നയാളിലേക്ക് പ്രചരിപ്പിക്കുന്നു.

## മൊഡ്യൂളുകൾ

```zymbol
# കണക്ക് {
    #> { കൂട്ടുക, PI }

    PI := ൩.൧൪൧൫൯
    കൂട്ടുക(a, b) { <~ a + b }
}
```

```zymbol
<# ./കണക്ക് => ക

>> ക::കൂട്ടുക(൫, ൩) ¶
>> ക.PI ¶
```

```zymbol
# എന്റെ_ലൈബ്രറി {
    #> { ആന്തരിക_കൂട്ടൽ => തുക }

    ആന്തരിക_കൂട്ടൽ(a, b) { <~ a + b }
}
```

രണ്ട് മൊഡ്യൂൾ അടയാളങ്ങളും ഒരേ ആശയമാണ്, ഇപ്പോൾ ഫയലുകളിൽ പ്രയോഗിച്ചിരിക്കുന്നു: `#` **പ്രഖ്യാപനത്തിന്റെ** തലമാണ് — ഒരു വസ്തു *എന്താണ്*, അതിന്റെ മൂല്യമല്ല — അമ്പ് കോഡ് ഏത് ദിശയിൽ സഞ്ചരിക്കുന്നു എന്ന് പറയുന്നു:

```text
<#   അമ്പ് പ്രവേശിക്കുന്നു: ഇമ്പോർട്ട് ചെയ്യുക, മറ്റൊരു ഫയലിൽ നിന്ന് കൊണ്ടുവരിക
#>   അമ്പ് പുറപ്പെടുന്നു: എക്സ്പോർട്ട് ചെയ്യുക, മറ്റ് ഫയലുകൾക്ക് വാഗ്ദാനം ചെയ്യുക
```

ദിശാ അടയാളം എപ്പോഴും അത് ചൂണ്ടുന്ന ദിശയിലേക്ക് അഭിമുഖീകരിക്കുന്ന അരികിൽ ഇരിക്കുന്നു. `<~` ഇടത്തേക്ക് തിരികെ വരാനും (ഫംഗ്ഷനിൽ നിന്ന് പുറത്ത്) `->` വലത്തേക്ക് പ്രവേശിക്കാനും (ലാംഡയുടെ ശരീരത്തിലേക്ക്) ഇതേ കാരണമാണ്.

> **ഒരു മൊഡ്യൂൾ അത് എക്സ്പോർട്ട് ചെയ്യുന്നത് പ്രഖ്യാപിക്കുന്നു.** `#>` ബ്ലോക്ക് നിർബന്ധമാണ് — അത് ഒഴിവാക്കുന്നത് **E014** ആണ്, `#> { }` ഒരു മൊഡ്യൂൾ അതിന്റെ ഉപരിതലം ശൂന്യമാണെന്ന് പറയുന്ന വിധമാണ്. `::` ഒരു ഫംഗ്ഷനെ വിളിക്കുന്നു, `.` ഒരു സ്ഥിരാങ്കം വായിക്കുന്നു. ഇമ്പോർട്ടുകൾ, എക്സ്പോർട്ട് ബ്ലോക്ക്, അക്ഷരീയ ഇനിഷ്യലൈസറുകൾ, ഫംഗ്ഷൻ നിർവചനങ്ങൾ എന്നിവ മാത്രമേ മൊഡ്യൂൾ ശരീരത്തിൽ പ്രത്യക്ഷപ്പെടാവൂ; എക്സിക്യൂട്ട് ചെയ്യാവുന്ന എന്തും **E013** ആണ്.

## സ്റ്റാൻഡേർഡ് ലൈബ്രറി

നേറ്റീവ് മൊഡ്യൂളുകൾ, മറ്റുള്ളവപോലെ ഇമ്പോർട്ട് ചെയ്യുന്നു:

| മൊഡ്യൂൾ | ഫംഗ്ഷനുകൾ |
|--------|-----------|
| `std/math` | `sqrt exp ln log pow abs ceil floor round min max sin cos tan asin acos atan atan2 sinh cosh tanh sigmoid` · `PI` `E` |
| `std/random` | `entero rango peso_f64` |
| `std/json` | `decode decode_map encode` |
| `std/io` | `read write append exists delete list mkdir` |
| `std/net` | `get post post_json head` |
| `std/db` | `connect exec query query_one tx commit rollback` … |
| `std/term` | `width pad_left pad_right center truncate` |
| `std/time` | `now today parts of format add diff` |

```zymbol
<# std/math => m

>> m::sqrt(൧൬.൦) ¶      // → 4
>> m.PI ¶               // → 3.141592653589793
```

```zymbol
<# std/term => t

>> t::width("手番") ¶            // → 4   രണ്ട് ഗ്ലിഫുകൾ, നാല് നിരകൾ
>> "|" t::center("go", 8) "|" ¶ // → |   go   |
```

```zymbol
<# std/time => T

ദിവസം = T::of(൨൦൨൬, ൧, ൩൧)
>> T::format(ദിവസം, "%Y-%m-%d") ¶ // → 2026-01-31
>> T::format(T::add(ദിവസം, ൧, "month"), "%Y-%m-%d") ¶ // → 2026-02-28
```

> `std/term` **പ്രദർശന നിരകൾ** അളക്കുന്നു, അക്ഷരങ്ങളല്ല: CJK-യും മിക്ക ഇമോജികളും 2 നിരകളാണ്, അതിനാൽ `t::width` ഉപയോഗിച്ച് ഒരു പട്ടിക വിന്യസിക്കുക, `$#` ഒരിക്കലുമല്ല.
> `std/time` ൽ ഒരു നിമിഷം യുഗത്തിൽ നിന്നുള്ള മില്ലിസെക്കൻഡുകളാണ്. ഒരു ദിവസത്തിൽ കുറവ് ദൈർഘ്യമാണ്, ഒരു ദിവസം മുതൽ മുകളിൽ കലണ്ടറാണ് — അതിനാൽ ഒരു മാസം അതേ ദിവസത്തിൽ വീഴുന്നു, ക്ലാംപ് ചെയ്തത്. `വ്യത്യാസം(a, b)` `a - b` ആണ്, അതിനാൽ മുൻപത്തെ നിമിഷം ആദ്യം നൽകിയാൽ നെഗറ്റീവ് ഉത്തരം ലഭിക്കുന്നു.

## പാക്കേജുകൾ

ഒരു `.zyp` ഒരു ബഹു-ഫയൽ പ്രോഗ്രാമിനെ ഒരു പോർട്ടബിൾ ഫയലായി ബണ്ടിൾ ചെയ്യുന്നു. ഇത് **സ്രോതസ്സിന്റെ** ഒരു ആർക്കൈവാണ്, ബൈനറിയല്ല, അതിനാൽ `zymbol` ബൈനറി പ്രവർത്തിക്കുന്ന എവിടെയും ഇത് പ്രവർത്തിക്കുന്നു.

```bash
zymbol package എന്റെ_പ്രോജക്റ്റ്/ --script main.zy -o എന്റെ_പ്രോജക്റ്റ്.zyp
zymbol run എന്റെ_പ്രോജക്റ്റ്.zyp
```

> ആർക്കൈവിൽ ഒരു മാനിഫെസ്റ്റ് (`zyp.toml`) ഉണ്ട്, അത് അതിന്റെ എൻട്രി സ്ക്രിപ്റ്റുകളും ആവശ്യമായ എഞ്ചിൻ പതിപ്പും പ്രഖ്യാപിക്കുന്നു. `zymbol run` അതിനെ ഒരു താൽക്കാലിക ഡയറക്ടറിയിലേക്ക് വേർതിരിച്ചെടുത്ത് അവിടെ നിന്ന് പ്രവർത്തിപ്പിക്കുന്നു, അതിനാൽ കോഡ് ഡിസ്പോസിബിൾ ആണ്, സ്ക്രിപ്റ്റ് എഴുതുന്നത് നിങ്ങളുടെ യഥാർത്ഥ പ്രവർത്തന ഡയറക്ടറിയിൽ വീഴുന്നു. പ്ലേഗ്രൗണ്ടും `.zyp` ഫയലുകൾ ലോഡ് ചെയ്യുന്നു.

## സംഖ്യാ മോഡുകൾ

Zymbol സംഖ്യകൾ **69 യൂണികോഡ് അക്ക ലിപികളിൽ** എഴുതാം — മലയാളം, ദേവനാഗരി, അറബി-ഇന്ത്യൻ, തായ്, ക്ലിംഗോൺ pIqaD, ഗണിത കട്ടിയുള്ള, LCD വിഭാഗങ്ങൾ, കൂടാതെ മറ്റുള്ളവയും. മോഡ് പ്രക്രിയയ്ക്ക് ആഗോളമാണ്, ഔട്ട്പുട്ടിനെ സ്വാധീനിക്കുന്നു; ഗണിതം മാറുന്നില്ല.

```zymbol
#൦൯#    // മലയാളം   (U+0D66–U+0D6F)
#०९#    // ദേവനാഗരി   (U+0966–U+096F)
#٠٩#    // അറബി-ഇന്ത്യൻ (U+0660–U+0669)
#09#    // ASCII ലേക്ക് പുനഃസജ്ജമാക്കുക
```

```zymbol
a = ൪൨
>> a ¶                  // → 42
#൦൯#
>> a ¶                  // → ൪൨
>> ൩.൧൪ ¶               // → ൩.൧൪
>> #൧ ¶                 // → #൧
#09#
```

പിന്തുണയുള്ള ഏത് ലിപിയുടെയും അക്കങ്ങൾ സ്രോതസ്സിൽ സാധുവായ ലിറ്ററലുകളാണ്:

```zymbol
#൦൯#
@ i:൧..൫ { >> i " " }
>> ¶                    // → ൧ ൨ ൩ ൪ ൫
#09#
```

വായന സമമിതമാണ് — ഒരു അക്കം ഏത് ലിപിയിലും മനസ്സിലാക്കുന്നു:

```zymbol
>> #|"४२"| ¶            // → 42
>> #|'७'| ¶             // → 7
```

> `#` എപ്പോഴും ASCII ആണ്, അതിനാൽ `#0` എല്ലാ ലിപിയിലും പൂജ്യം അക്കത്തിൽ നിന്ന് ദൃശ്യമായി വ്യത്യസ്തമായി നിലകൊള്ളുന്നു.
> `#,`, `#^` എന്നിവ അവയുടെ അക്കങ്ങൾ സജീവ ലിപിയിലും എഴുതുന്നു, വിഭജനങ്ങൾ അതിനെ പിന്തുടരുന്നു — എന്നാൽ ജോഡി ഒരിക്കലും വിപരീതമാകുന്നില്ല: `,` ഗ്രൂപ്പ് ചെയ്യുന്നു, `.` വിഭജിക്കുന്നു, എല്ലാ ലിപിയിലും.

## ഡാറ്റ ഓപ്പറേറ്ററുകൾ

```zymbol
f = ##.൪൨         // ദശാംശത്തിലേക്ക്
i = ###൩.൭        // പൂർണ്ണസംഖ്യയിലേക്ക്, റൗണ്ട്  → 4
t = ##!൩.൭        // പൂർണ്ണസംഖ്യയിലേക്ക്, ട്രങ്കേറ്റ്  → 3
>> f " " i " " t ¶      // → 42 4 3
>> f#? ¶                // → (##., 2, 42)
```

> ഒരു ദശാംശം അക്കങ്ങളായി അച്ചടിക്കുന്നു, ഒരിക്കലും എക്സ്പോണന്റായി അല്ല, അവസാനത്തെ `.0` ഉപേക്ഷിക്കുന്നു — `##.42` `42` എന്ന് എഴുതുന്നു, ഇപ്പോഴും ദശാംശമാണ്, `f#?` കാണിക്കുന്നതുപോലെ.

```zymbol
>> #|"42"| ¶       // → 42
>> #|"abc"| ¶      // → abc   പരാജയ-സുരക്ഷിതം: ഇൻപുട്ട് മാറ്റാതെ തിരികെ നൽകുന്നു
>> ##!'A' ¶        // → 65    ഒരു അക്ഷരത്തിന്റെ കോഡ് പോയിന്റ്
```

```zymbol
pi = ൩.൧൪൧൫൯൨൬൫
>> #.൨|pi| ¶       // → 3.14          2 ദശാംശ സ്ഥാനങ്ങളിലേക്ക് റൗണ്ട്
>> #!൨|pi| ¶       // → 3.14          2 ദശാംശ സ്ഥാനങ്ങളിലേക്ക് ട്രങ്കേറ്റ്
>> #,|൧൨൩൪൫൬൭| ¶   // → 1,234,567     ആയിരം വിഭജനങ്ങൾ
>> #^|൧൨൩൪൫.൬൭൮| ¶ // → 1.2345678e4  ശാസ്ത്രീയ നൊട്ടേഷൻ
```

```zymbol
>> 0x41 ¶        // → A   ഷോഡശ
>> 0b01000001 ¶  // → A   ദ്വയം
>> 0o101 ¶       // → A   അഷ്ടം
>> 0d65 ¶        // → A   ദശം
```

> ASCII പരിധിയിലുള്ള ഒരു അടിസ്ഥാന ലിറ്ററൽ ഒരു **അക്ഷരം** ആണ്: `0d65 == 'A'` എന്നത് `#1` ആണ്, `0d65 == 65` എന്നത് `#0` ആണ്. നാല് അടിസ്ഥാനങ്ങളും ഒരേ അക്ഷരം അക്ഷരവിന്യാസം ചെയ്യുന്നു.

## അടയാളങ്ങൾ എങ്ങനെ സംയോജിക്കുന്നു

ഈ സഹായിയിലുടനീളം നിങ്ങൾ ഒരേ കാര്യം കണ്ടു: **ഒരു ഓപ്പറേറ്റർ ഓർക്കാനുള്ള ഒരു ചിത്രമല്ല, അത് ഒരു വരിയിൽ നിരവധി അടയാളങ്ങളാണ്, ഓരോന്നും അതിന്റെ അർത്ഥം നൽകുന്നു.** ഇപ്പോൾ നിങ്ങൾ അവയെല്ലാം അറിയുന്നു, ഇതാ പൂർണ്ണ പാറ്റേൺ.

ആദ്യം വരുന്നത് **നാം ഏത് ലോകത്താണ്**:

| അടയാളം | ലോകം | നിങ്ങൾ അത് എവിടെ കണ്ടു |
|--------|-------|----------------------------|
| `$` | ഒരു ശേഖരം | `$#` `$+` `$?` `$^-` |
| `@` | സമയം, ആവർത്തിക്കുന്നതെല്ലാം | `@!` `@>` `@~` |
| `#` | ഒരു വസ്തു *എന്താണ്*, അതിന്റെ മൂല്യമല്ല | `#?` `#(…)` `<#` `#>` |
| `>>` | പ്രോഗ്രാമിൽ നിന്ന് പുറത്തേക്ക് | `>>` `>>!` `>>?` |
| `<<` | പ്രോഗ്രാമിലേക്ക് ഉള്ളിലേക്ക് | `<<` `<<\|` `<<\|?` |
| `?` | ചോദിക്കുക, പ്രതിബദ്ധതയില്ലാതെ | `?` `_?` `??` `$?` |
| `!` | ബലം, അല്ലെങ്കിൽ പിശക് | `@!` `$!` `!?` |

പിന്നെ വരുന്നത് **അവിടെ എന്ത് ചെയ്യുന്നു**: `+` ചേർക്കുക, `-` നീക്കുക, `^` ക്രമം, `~` മാറ്റുക, `#` എണ്ണുക, `|` ഒരു യൂണിറ്റ്, `:` ഒരു പേര് ബന്ധിക്കുക.

ഒരിക്കലും പരാജയപ്പെടാത്ത രണ്ട് നിയമങ്ങൾ:

**ഒരു അടയാളം ഇരട്ടിപ്പിക്കുന്നത് അതിനെ സമഗ്രമാക്കുന്നു.** `?` ഒരിക്കൽ ചോദിക്കുന്നു, `??` പല കേസുകൾ പരിശോധിക്കുന്നു. `$?` ഒരു മൂല്യം ഉണ്ടോ എന്ന് ചോദിക്കുന്നു, `$??` അത് ഉള്ള എല്ലാ സ്ഥലവും നൽകുന്നു. `!` ഒരു പിശക് അടയാളപ്പെടുത്തുന്നു, `!!` ചോദിക്കാതെ അതിനെ പ്രചരിപ്പിക്കുന്നു.

**മോഡ് അടയാളം എപ്പോഴും അവസാനം വരുന്നു.** `?` അല്ലെങ്കിൽ `!` എന്തെങ്കിലും *എങ്ങനെ* ചെയ്യുന്നു എന്ന് പറയാൻ പ്രത്യക്ഷപ്പെടുമ്പോൾ — സംശയത്തോടെയോ ബലത്തോടെയോ — അവ ഓപ്പറേറ്ററിന്റെ അവസാന അടയാളങ്ങളാണ്: `$??`, `$!!`, `<<|?`, `@!`, `##!`, `>>!`, `>>?`, `@:പുറം!`. അവയ്ക്ക് ശേഷം ഒരിക്കലും ഒരു പ്രവർത്തനമില്ല.

അതിൽ നിന്ന് പ്രായോഗികമായ ഒരു കാര്യം വരുന്നു: **നിങ്ങൾ ഒരിക്കലും കാണാത്ത ഒരു സംയോജനം, നിങ്ങൾ അത് നോക്കുന്നതിന് മുമ്പുതന്നെ അർത്ഥവത്താണ്.** `$` ഒരു ശേഖരവും `^` ഒരു ക്രമവും `-` വിപരീതവും ആണെങ്കിൽ, `$^-` അവരോഹണത്തിൽ ക്രമീകരിക്കുന്നു, ആരും നിങ്ങളോട് പറയേണ്ടതില്ല.

മുഴുവൻ ഇൻവെന്ററിയും ഇപ്രകാരം പ്രവർത്തിക്കുന്നില്ല, അത് പറയുന്നത് നടിക്കുന്നതിനേക്കാൾ നല്ലതാണ്. മിക്ക ഓപ്പറേറ്ററുകളും വൃത്തിയായി വേർതിരിയുന്നു. ആറെണ്ണം വേർതിരിയുന്നു, പക്ഷേ അവയുടെ ഭാഗങ്ങളേക്കാൾ കൂടുതൽ അർത്ഥമാക്കുന്നു: `!?` `:!` `:>` `|>` `::` `$++`. പത്തെണ്ണം മനഃപാഠമാക്കണം, കാരണം അവ തീർത്തും വേർതിരിയുന്നില്ല: `¶` `><` `#1` `#0` `0x` `0b` `0o` `0d` `###` `°`.

> അതാര്യമായവ കുറവാണെന്ന് അനുമാനിക്കുന്നതിനുപകരം എണ്ണുന്നത് മനഃപൂർവ്വമാണ്: അവ ഭാഷയുടെ യഥാർത്ഥ മനഃപാഠ ചെലവാണ്. പൂർണ്ണ റഫറൻസ് — ഇൻവെന്ററി, പ്രഖ്യാപിത ഹോമോഗ്രാഫുകൾ, ഒരു പുതിയ ഓപ്പറേറ്റർ നിലനിൽക്കാൻ പാലിക്കേണ്ട നിയമങ്ങൾ — ഇന്റർപ്രിറ്റർ റെപ്പോസിറ്ററിയിലെ `SYMBOLS.md` ൽ ഉണ്ട്.

- **ചേർത്തു** `#?` നാല് ശേഖരങ്ങളെ വേർതിരിക്കുന്നു: `##]` `##[` `##)` `##(`

- **മാറ്റി** ഒരു പേര് മാത്രം വായിക്കുന്ന ഒരു പ്രസ്താവന നിശ്ശബ്ദമായി കടന്നുപോകുന്നതിനുപകരം മുന്നറിയിപ്പ് നൽകുന്നു

### v0.0.8 — ഓട്ടോ-ഫ്രീ, `std/term` കൂടാതെ പാക്കേജുകൾ _(ഓഗസ്റ്റ് 2026)_

- **ചേർത്തു** അവസാന ഉപയോഗത്തിൽ സ്വയമേവ നശിപ്പിക്കൽ — കാണാനാവാത്തത്; പീക്ക് മെമ്മറി മാത്രം കുറയ്ക്കുന്നു
- **ചേർത്തു** `std/term` — ടെർമിനൽ നിരകളിൽ പ്രദർശന അളവുകൾ
- **ചേർത്തു** ഒരു `അക്ഷരത്തിൽ` `##!` — അതിന്റെ യൂണികോഡ് കോഡ് പോയിന്റ്
- **ചേർത്തു** മാച്ചിൽ or-pattern: `'p' || 'P' => …`, ഏത് തരത്തിലുള്ള ബദലുകളും ഒരു ശാഖയിൽ
- **ചേർത്തു** Zymbol പാക്കേജുകൾ (`.zyp`) — `zymbol package` / `zymbol run pkg.zyp`
- **ചേർത്തു** വിളിക്കുന്ന സ്ഥലത്ത് `<~>` നിർബന്ധമാണ്, വിളിക്കപ്പെടുന്നവൻ ഔട്ട്പുട്ട് പാരാമീറ്റർ പ്രഖ്യാപിക്കുമ്പോൾ
- **പരിഹരിച്ചു** രജിസ്റ്റർ VM-ൽ മൊഡ്യൂൾ സിസ്റ്റം പാരിറ്റി

### v0.0.7 — നേറ്റീവ് സ്റ്റാൻഡേർഡ് ലൈബ്രറി _(ജൂലൈ 2026)_

- **ചേർത്തു** `std/json`, `std/io`, `std/net`, `std/db` (ODBC) — എല്ലാം സോഫ്റ്റ് പിശക് മൂല്യങ്ങളോടെ
- **ചേർത്തു** ടൈപ്പ്/വാലിഡേറ്റഡ് ഇൻപുട്ട്: `<< ##.(5,2) "വില: " p`
- **ചേർത്തു** `>>` ൽ നേരിട്ട് പോസ്റ്റ്ഫിക്സ് ഓപ്പറേറ്ററുകൾ — ബ്രാക്കറ്റുകൾ ആവശ്യമില്ല
- **മാറ്റി** fail-closed ഫോർമാറ്റർ: വീണ്ടും വായിക്കാൻ കഴിയാത്ത ഔട്ട്പുട്ട് എഴുതാൻ വിസമ്മതിക്കുന്നു

### v0.0.6 — പരിഷ്കരണവും ശാസ്ത്രീയ Stdlib-ഉം _(ജൂൺ 2026)_

- **ബ്രേക്കിംഗ്** `=>` മാച്ച് ശാഖകളിലെ `:` കൂടാതെ ഇമ്പോർട്ട്/എക്സ്പോർട്ട് അലിയാസുകളിലെ `<=` മാറ്റിസ്ഥാപിക്കുന്നു
- **ചേർത്തു** `std/math` കൂടാതെ `std/random`
- **ചേർത്തു** കീ പ്രകാരം നിഘണ്ടു അപ്ഡേറ്റ്: `d["k"]$~ മൂല്യം`

### v0.0.5 — TUI പ്രാഥമികങ്ങളും ഹോട്ട് ഡെഫനിഷനും _(മേയ് 2026)_

- **ചേർത്തു** TUI ബ്ലോക്ക് `>>| { }`, സ്ഥാന ഔട്ട്പുട്ട് `>>~`, കീ ഇൻപുട്ട് `<<|`, `<<|?`

- **ചേർത്തു** ഹോട്ട് ഡെഫനിഷൻ `°x` / `x°`, സ്ട്രിംഗ് ആവർത്തനം `$*`
