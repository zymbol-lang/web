Windows

MSI installer with automatic PATH setup. Download and run — no manual configuration needed.

MSI installer — adds zymbol to PATH automatically. Run the installer and you're done.

Arch Download SHA256
x86_64 ↓ zymbol_lang_v0.0.11_x86_64_windows.msi
3b60b6818297
# After installing, open a new terminal and verify:
zymbol --version
Code signed: the Windows .msi carries a digital signature (Authenticode, SHA-256) made with the project's own self-signed certificate, CN=zymbol-lang. It proves the file is the one that was built and has not been altered; it does not make Windows treat the publisher as trusted, so SmartScreen may still warn. The zymbol.exe inside is not signed. You can read the signature under the file's Properties → Digital Signatures, or check the SHA256 above.

Native binaries — no installer needed. Download, make executable, run.

x86_64 Intel ↓ zymbol_lang_v0.0.11_x86_64_macos

# Make it executable and run (replace _aarch64_ with _x86_64_ for Intel)
chmod +x zymbol_lang_v0.0.11_aarch64_macos
./zymbol_lang_v0.0.11_aarch64_macos run hello.zy

# (Optional) Install system-wide
sudo install -m755 zymbol_lang_v0.0.11_aarch64_macos /usr/local/bin/zymbol
First launch warning: the binary is not signed with a Developer ID and not notarized, so Gatekeeper blocks it the first time. Clear the quarantine attribute: xattr -d com.apple.quarantine ./zymbol_lang_v0.0.11_aarch64_macos — or open System Settings → Privacy & Security and choose Open Anyway after the first refusal. The Finder's right-click → Open works for apps, not reliably for a command-line binary.

Compile from Source

Works on Linux, macOS, and Windows. Requires Rust stable (rustup).

1
# Clone the interpreter repository
git clone https://github.com/zymbol-lang/interpreter
cd interpreter
2
# Build optimized release binary
cargo build --release
# Binary: target/release/zymbol
3
# (Optional) Install system-wide on Linux / macOS
sudo install -m755 target/release/zymbol /usr/local/bin/zymbol
4
# Verify
zymbol --version
